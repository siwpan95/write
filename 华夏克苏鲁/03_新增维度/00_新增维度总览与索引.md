## 一、为什么补这十一个维度

写完前四轮之后，设定集能回答"世界怎么运转"，但答不上演员每天要碰到的几类问题：

| 缺口 | 具体表现 | 由哪个维度补 |
|---|---|---|
| **谁管活人** | 只有玉虚宫与傩坛，没有官府；可"登记权"若没有阳间对应物，冲突就悬空 | 01 官制律法与阴阳两衙 |
| **一年怎么过** | 有历史年表，没有日历；章节排不进季节，节令写不出集体感 | 02 岁时节令与生活史 |
| **人怎么说话** | FL-01 是"说出全名就被定位"，但角色总得说话——没有话术层，铁律等于逼人闭嘴 | 03 语言称谓与行话切口 |
| **伤怎么治** | 有代价表，没有病；角色受伤只能"养几天"，无法制造"治与不治都错"的场面 | 04 医药身体与祝由 |
| **日子怎么选** | T-03"上梁不可中断"缺一套择日与仪轨，写起来像随口编 | 05 术数历法与择日营造 |
| **东西凭什么灵** | 有 I-01～I-07 七件物，但没有"物为什么能作证"的通则 | 06 器物法器与材料 |
| **怪怎么分类** | 有 G-01～G-13 十三张卡，但没有分类学；写第二只狐就与第一只打架 | 07 异类谱与非人分类学 |
| **章节怎么排** | 设定齐了，落笔仍可能前三章讲设定、十章不结账 | 08 叙事技法与章节工程 |
| **为什么写这个** | 有精神内核一句话，没有可验证的主题命题；容易写成"设定炫技" | 09 主题母题与互文 |
| **谁在打、怎么打** | 有势力表，没有军队；清剿司"怎么执行"一直是空的 | 10 军事武备与武举 |
| **人怎么往上走** | 有阶层，没有上升通道；一个想改命的年轻人只能"奇遇" | 11 教育科举与学籍 |

一句话：**前四轮建的是世界，第五轮建的是"人在世界里的一天"，第六轮建的是"人怎么被记上、又怎么被划掉"。**

## 三、三种读法

### 3.1 作者动笔前（15 分钟）

0. **先看首卷章纲**：`../04_章纲/00_首卷章纲-残神旧仙-三十章.md`——每章的时间、规矩、账、簿子、钩子已经排好，照表写即可。
1. 读 `08` 的 §2.1（单章三段配比）与 §3.2（20 个章末钩子）——先定这一章的骨架。
2. 查 `02` 的 §2.2 全境年历总表——这一章发生在哪个月，能办什么事、不能办什么事。
3. 查 `01` 的 GZ-03／GZ-06——这一章若死人、若出远门，手续缺哪一枚印。

### 3.2 写到具体场面时（按场查）

| 要写什么 | 查哪一节 |
|---|---|
| 一场官司、一次验尸、一张状纸 | `01` §2 GZ-09～GZ-11；§3.2 对白①②③ |
| 一场年节、一次婚礼丧礼、一顿饭 | `02` §2.2、SN-11～SN-13；§3.1 感官 |
| 一段对白、一个称呼、一句犯忌的话 | `03` §2.2 五州对照、§2.3 禁语表、§3.2 对白 |
| 一个人病了、一个产妇、一场疫 | `04` §2.1 病类学、§2.3 代价归属、§3.3 场景 |
| 一次上梁、一次迁坟、一次择日 | `05` §2 SL-05～SL-10；§3.3 场景 |
| 一件法器坏了、一块牌丢了、一把尺不准了 | `06` §2.1 品级、§2.2 条目、§2.4 一器一证 |
| 一只怪、一张档案、一次"它为什么这样" | `07` §2 五分法、§2.6 十张卡、§4.2 写崩预警 |
| 一章写崩了要复盘 | `08` §4 五种禁用写法＋改法 |
| 不确定这段该不该给答案 | `09` §2.7 六命题交叉自检；`08` §2.6 红线→操作 |

### 3.3 交稿前（30 分钟）

1. `01` §4.1、`02` §4.1……逐文件的"冲突自检表"过一遍（九份，每份 8 条）。
2. `08` §2.6 九条红线→写作操作表：确认没有一处把"不解释"写成了"解释"。
3. 各文件 §五"未核实与风险清单"：凡标〔存疑〕的句子，正文里是否被写成了肯定句。

## 九、未核实项汇总（诚实标注）

共 **43 处**标〔存疑〕，集中在这五类，正文引用时须降格为"人物说法"或"某一说"：

1. **地方志卷次未核**（乾隆《辰州府志》、光绪《龙山县志》等）——原文大意可用，卷次不写。
2. **条例原文未见**（乾隆十六年时宪书开禁、检验用尺"照工部制尺制造"、《刑部题定验尸图格》成书年）——只写"律有明条"，不引原文。
3. **方言分区有争议**（辰州话归属、湘西官话边界、"满／晚"本字）——不写"某县属某区"，写成人物口音差异。
4. **术数细节各家不一**（土王用事十八日、七十二龙空格数、神煞总数）——只给判定逻辑，不给"标准答案"。
5. **现代理论只作作者层**（韦伯"卡地裁判"、弗雷泽、蔡格尼克效应）——署名、不进人物台词、不称"规律"。
