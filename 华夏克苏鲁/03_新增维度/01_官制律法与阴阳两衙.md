# 01 · 官制律法与阴阳两衙

> **本文件解决什么**：一个人的"存在"要盖两个印，而这两个印互相不承认；以及一个走脚匠为什么非得把路引与铜牌缝在贴肉的地方。

## 〇、先划三条界

**1. 本维度只管什么、不管什么。**

本维度只管"登记权"落到纸上的那一层：谁有印、印盖在哪张纸上、盖缺了会怎样、谁有资格说"这个人我认"。具体是三样东西——**印**（官印与法印）、**文书**（黄册、鱼鳞图册、路引、铜牌号、殃榜、尸格、状尾、日课）、**人**（知县与佐贰、六房典吏、幕友、三班衙役、仵作、官代书、阴阳训术、城隍庙的庙祝与掌法箓者）。

本维度**不管**：傩坛内部的科仪环节（归 `民俗行当与禁忌.md` §二）；境界与代价的账目（归 `境界与代价.md`）；法器本身的制作与开光（归器物维度）；择日的技术细节（归本批 `05_术数历法与择日营造.md`，两文件在 GZ-14／SL-05 处咬合，互不重复）。"这个人为什么会有两个名字"在这里答，"这两个名字为什么都算数"必须去 R 表里答。

**2. 本维度可判定的是什么，永不解释的是什么。**

可判定：一枚印盖在哪、盖了几枚、印文与簿册是否相符、少了哪一枚、少的那一枚能不能补盖、补盖以后从哪一天开始算。这五问都有答案，都能被读者跟着数。

永不解释：两印互不承认的**源头**。这件事只能追到 H-03 道隐之劫"登记簿散佚"为止，再往前不问。同样不解释：那道"两衙不得同时对印"的禁令为何没有留下理由；销名为何须两衙具文而拒签不必给理由。写到这里必须收笔，改用一句人物的回避带过——"上辈子的事，我哪知道。"

**3. 本维度最容易写错的一件事。**

最容易写错的，是把阴阳两衙写成"一个管活人、一个管死人"的分工。**不是。**

阴阳两衙管的是**同一个人的两半**：阳衙管人身与田土（你占多大地方、纳多少粮、欠谁的钱、在哪条路上走），阴衙管名籍与魂魄（你叫什么、谁给你起的、死了以后往哪去）。一个人活着的时候，两半都在；死了以后，两半要**合起来才能过关**。所以本书里"死"不是一件事，是两道手续：阳衙出一张纸（尸格或除名），阴衙出一张纸（殃榜或入祠），两张纸上的名字若对不上，这个人就卡在中间——**既不能点主，也不能入土**，只能"在"着。

写"过不了关"的恐怖，不要写鬼叫，要写**两张纸上写的不是同一个名字**。

### 1.3 本书的改造声明

以下六处明确是〔构〕，改的理由一并写明。

**（一）双衙双印制。** 把"官印"与"法印"从器物层提升为存在论的两个必要条件。底本很扎实：城隍印确曾仿府县官印而铸，且由掌法箓的宫观颁发；县官确曾在除夕封印、正月十八开印，三跪九叩用印。本书只做了一件事——把两个印的**效力范围**划开，且让它们互相不认。理由是 FL-04 需要一个可数的动作：读者能看见"盖了"与"没盖"，却看不见"为什么这一枚不算"。

**（二）过关须两印俱全。** 完全〔构〕。底本只能是"点主要请阴阳先生写讳、殃榜要贴、路引要验"这三件散碎手续；本书把它们串成一条链：人死了要过关，关上有两个衙门的门房，各要一张纸。

**（三）铜牌编号入 R1。** 半〔构〕。底本是《大明律》把"夜巡铜牌"与印信、历日、茶盐引并列为"伪造即斩"之物——说明铜牌在明代确实是有编号、有官信、可伪造的凭据；另一半底本是既有设定"滩爷铜牌可世袭转卖"。本书在这里加了一句：**牌认号不认人**。

**（四）尺斗秤即登记权。** 〔构〕，但底本极硬：明律"虽平而不经官司校勘印烙者，笞四十"已经把"准确"与"有印"分开了；礼泉县"弓口窄小，积有余地，加算粮……后遂造入全书"更是直接给了本书一个现成情节——尺子短一点，地就多出来，多出来的地写进册子，从此就归了别人。

**（五）阴阳训术是"唯一同时持两套日子的人"。** 〔构〕。底本是县训术"掌选日"与"禁左道惑世"这两条职责写在同一段记文里：一个人既负责给日子，又负责指哪些日子是妖日。本书把这两件事捏成一件事：**他有给日子的权，也有不给日子的权**。

**（六）"无戳不阅"上升为"冤不成立"。** 〔构〕。底本是黄岩档案里知县那两笔批词——"无戳不阅""无戳特斥"，以及赤贫者贴"无力用戳"求免。本书只把结果推到底：不是衙门懒得看，是**这张纸从来没有进过任何一本簿子**，按 R2，它连"发生过"都不算。

## 三、可直接写进正文的素材

### 3.1 感官清单

1. **印按下去**：手腕要沉。纸背凸起一道，指腹能摸出"县"字那一竖钩的勾尖，勾尖钝。
2. **铜牌**：边缘被掌心磨成镜面，中间那个号被摸得发亮，号四周却黑。牌背面有一道深划痕，是某一任持牌人自己刻的，刻什么没人知道。
3. **开黄册箱**：樟木盖子一掀，不是响，是鼻子里先凉一下。纸是脆的，翻页要用指腹推，不能用指尖挑。
4. **尸格**：朱笔尖在"致命"两字上停了半息，笔尖抖了一下，落下一个比字略大的红点。旁边人不敢看官的手。
5. **官代书戳记**：红的，但不是朱砂红，是发暗的胭脂红。按在状尾，当事人的指印盖在它左下角，两个红挨着，一深一浅。
6. **路引**：折过四折，折痕处纸薄得透光。"所往"一栏的字比别处用力，墨透到了背面。

### 3.2 对白与口气

**① 刑房典吏（对苦主，不看人，只看纸）**
"戳在这儿。没戳，我不看。不是我不看——是它没进过门。"

**② 阴阳训术（对上梁的主家，把日子簿合上）**
"我不是不给你择。我是不能给这个日子写字。你把话听完：这日子在皇历上是个好日子，在我这本上不是。我签了，将来出事，那张纸上就是我的字。"

**③ 官代书（对一个掏不出钱的老妇，压低声）**
"状我给你写。写得多实，你回去问问邻里就知道。戳——我盖不起。我这戳是衙门给的，用一次要给衙门记一笔，我自己也要吃一口饭。"

**④ 滩爷（对新入帮的后生，把铜牌翻过来给他看背面）**
"牌在，人在。牌不在，你走夜路别回头。看这个号——号不是你的，是这块牌的。你哪天不干了，牌留下，号还是这个号。所以你别在牌上刻自己名字，刻了就是哑牌，哑牌不出门。"

**⑤ 玉虚宫掌籍执事（对州县官，行的是平礼，不是下礼）**
"大人的印管田土，管到四至为止。他的名，在本宫。大人若要这个名字在黄册上留一行，须得本宫先销一行。这两件事，谁先谁后，旧例写着，我不必念给大人听。"

### 3.3 场景骨架

**场景甲｜尸格与告阴状（第一卷可用）**
一具无引的尸停在义庄偏屋。正印官来了，仵作蹲下，唱报："仰面，左肋，斜长三寸二分，阔一寸，青紫，系钝物所伤。"官问："致命不致命？"仵作停了一下，说："不致命。"官落笔。苦主在门外喊"是打死的"，被皂隶按住。状子递上来，状尾空白——没有戳。官批两字："不阅。"
夜里的城隍庙，苦主把状纸烧了。第二天，那张尸格上的"不致命"三个字，被上面的红点洇开，看上去像改过。
**写这一段只写三个动作**：唱报、落笔、烧纸。不要写"阴衙如何受理"，一写就崩（见 §四预警一）。

**场景乙｜验引关（第二卷可用）**
走脚铺接了一趟出百里的活。过关时，前头的人把引摊在关吏手上，关吏对着光看纸的背面，看墨透没透。轮到主角，引上的"所往"写的是"送丧"，关吏问："几具？"答："一具。"关吏往他身后看，看了很久。
同行的一个帮工，副联不见了。他把铜牌递上去，关吏翻过来看背面，又翻回来，说："哑牌。"
**这一段不要出现打斗**。全部张力在"关吏往他身后看"这一眼。

**场景丙｜籍库对印（第三卷可用）**
玉虚宫籍库，樟木架到顶，无窗。州县户房典吏抬来一只箱子，箱里是黄册的抄本。两边各摊一册，同一行名字，一个写"赵海"，一个写"赵海儿"。掌籍执事说："这不算差。差的是生辰。"典吏翻到那一栏，空着。
掌籍执事拿出销名的具文，两份，一份给自己，一份给户房。户房典吏不签。他不需要说为什么，他只是把笔放下了。
**结尾写"把笔放下"这一个动作，不要写理由**。理由属于红线。

## 四、与铁律和既有文件的接口

### 4.1 冲突自检表

| 铁律 | 本维度是否触线 | 需加的限定 |
|---|---|---|
| **FL-01** 描述即被注意 | 不冲突 | 文书上永远只有"名"与"号"。本书所有簿册的栏目设计本来就是**为了不凑齐三项**（黄册只记丁口年甲，殃榜只记讳与生肖，尸格只记伤）——三册合看才凑得齐，所以同时翻三册就是一次自杀 |
| **FL-02** 代价不可解 | 不冲突，且被强化 | 每一次用印都是一次调用：盖印者要付一项可观测损失（多为"归属"或"记忆"）。补印、覆检、告阴状，各付一次，不许合并 |
| **FL-03** 没有复活只有替 | 不冲突 | GZ-03 的"寄印"是 R22 补缺机制的正门：寄满三年互换位置，是"顶了那个位置"，不是回来 |
| **FL-04** 仪式即立法 | 完全一致 | 本维度是 FL-04 的行政实现层：印即承认 |
| **FL-05** 境界是额度 | 不冲突 | 阴阳训术、官代书、仵作都是凡人，无境界；他们的权力来自印，不来自修为。这正是本书"力量与地位负相关"的另一面 |
| **FL-06** 仙不仁也不撒谎 | **需加最重限定** | 阴衙的一切行为必须能归因于"编制"与"缺额"，不能归因于好恶。见 §4.3 预警二 |
| **FL-07** 邪神不上身 | 不冲突 | 城隍庙里的木主是"职位的座位"，不是容器；谁坐上去就按那个位子的规矩办事，与人格无关 |

### 4.2 与既有编号的对应

### 4.3 若被误写会怎样（三条写崩预警）

**预警一：把阴衙写成"另一个官府"。**
一旦让阴衙有"判"的权力，故事立刻变成两套官僚斗法，读者会开始问"那阴间的知府是谁管的"，而这个问题的答案只能通向红线。**限定**：阴衙只有用印权，没有发令权。它可以不签、拖着不签、让一张纸停在半路——但它不能命令任何人做任何事。所有"阴衙的决定"，在正文里都必须表现为"某个衙役没来""某枚印不在""某本簿子锁着"。

**预警二：让某一位神或某一位职司"看你不顺眼"。**
一旦写出"城隍恼了他"，FL-06 立刻破，本书降级为善恶有报的故事。**限定**：任何一次不利结果，都必须能算出一笔账——缺一枚印、晚了一天、号与人不对、册子少一页。它不恨你，它只是按册子办事；册子上没有你，它就办不了你的事，这就是全部的恶意。

**预警三：把"无引者成 R2"写成报应。**
"谁让你不带引，活该"——这样写，FL-04 就从"立法"变成"惩罚"，本书的冷酷就没了。**限定**：无引者不是被罚，是**从来没有被记过**。他不是"罪人"，他是"没有"。不许写他受苦，要写旁人在处理他时**找不到可以填的格子**：仵作唱报到"姓名"一节停住，官问"什么名"，仵作说"纸上没有"。
