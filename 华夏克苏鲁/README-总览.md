## 一、三分钟上手

1. **先读** `01_bible/00_铁律表.md`（8 条，一页）。这是全书的宪法，其余一切不得与它冲突。
2. **再读** `01_bible/world-bible.md` §1（基础设定卡）与 §2（R 规则表）。你会知道这个世界"什么能发生、什么永远不能"。
3. **接着读** `01_bible/world-bible.md` §15（新增维度交叉引用总表）。一张表告诉你十一个维度分别接在哪一节、缺哪一本簿子会怎样。
4. **要动笔就读** `04_章纲/00_首卷章纲-残神旧仙-三十章.md`：每章四件事已写死——哪个月、用哪条规矩、谁付什么账、动哪本簿子。
5. **最后读** `03_新增维度/00_新增维度总览与索引.md` §三"三种读法"。它会告诉你动笔前查哪三节、写到某场面查哪一段、交稿前过哪三张表。

## 三、两轮新增了什么

前一轮建"人在世界里的一天"（九个维度）；这一轮补两个仍空着的维度，并把全部编号回填进 bible。

### 3.1 第一轮：九个生活与制度维度（118 条）

| 维度 | 一句话 | 最硬的一条 |
|---|---|---|
| 官制 | 阳衙管人身田土，阴衙管名籍魂魄 | 死人过关须两印俱全；只一印者成"关外客"，不腐不入土 |
| 岁时 | 一年是一张"今天能不能办事"的表 | 封印二十六日；三个弛禁时辰里，登记与"描述即被注意"同时失效 |
| 语言 | "只说一半"是可数的手艺 | 报几项有底表；不说＝不被承认，说全＝被定位 |
| 医药 | 病分身病、名病、祟病 | 医者只能"延"不能"还"；救回者必有一处对不上 |
| 术数 | 择日是发证，上梁是登记 | 上梁中断＝登记未完成＝房子降为"未登记" |
| 器物 | 器物不是装备，是凭证 | 看"最近一次替它作证的是谁"定品级 |
| 异类 | 按登记状态分类，不按物种 | 档案卡无名号栏、无来历栏——补栏即成谶 |
| 叙事 | 设定变成可勾选的章节工程 | 三章一次代价结算，一卷一次规则升级 |
| 主题 | 六个可验证的命题 | 手续的尊严：规矩是弱者唯一造得出来的东西 |

### 3.2 第二轮（本轮）：两个维度 + 一次回填

| 维度 | 一句话 | 最硬的一条 |
|---|---|---|
| **10 军事武备与武举** | 军籍是第三本簿子；打仗打的不是杀伤，是"谁被点名" | **JS-11**：死于两军之间、无人收殓点名者，就地成 R2 无籍尸；战后只能靠唱名"少一个"来数死人 |
| **11 教育科举与学籍** | 学册是第四本簿子；读书是普通人唯一合法的改名换命 | **JY-06**：冒籍不只是作弊，是盗用他人的登记位——被冒者籍上会多出一个不属于他的功名 |

**回填**：`world-bible.md` §2／§6／§7／§8／§10／§11／§12 各节末加一行「新增维度接口」，并新增 **§15 交叉引用总表**（含"四本簿子"表与四处诚实留白）。**bible 原有条目、铁律、五州籍、八阶一字未改**，仅加引用，见 CHG-036～038。

**合计 146 条可判定条目**（GZ／SN／YY／YB／SL／QW／YL／NS／ZT／JS／JY 十一段）。

### 3.3 四本簿子：本书"存在"的完整算法

| 簿子 | 掌簿者 | 管什么 | 缺了会怎样 |
|---|---|---|---|
| **黄册** | 州县（阳衙） | 丁口、田土、籍贯、年甲 | 不能置田立契、不能领路引 |
| **箓牒** | 玉虚宫（阴衙） | 名籍、魂魄、讳与生辰 | 不能点主、不能超度、不能入土 |
| **军籍** | 都司／卫所 | 从军来历、调补年月、在营丁口 | 饷止、不入阵亡册、死后按 R2 |
| **学册** | 学政／教官 | 功名、学名、应试资格 | 只能用小名与排行，不能应乡试 |

**同名不同册者，即是四个人。** 全书所有的身份危机，最终都能化成一句：你缺的是哪一本？

## 五、使用纪律（六条，贴在显示器上）

1. **引文必带出处**。设定里出现古籍书名、篇名、原句，须能在 `考据勘误与设定变更登记.md` §三查到；查不到的降〔构〕。
2. **地域必标注**。出马（东北）／香头（华北）／端公（川渝黔鄂西）／掌坛师（湘西）／五营（闽台）／放排（长江上游·赣江）——同一段混用两地称谓即为硬伤。
3. **学者观点不当古人口传**。王明、余嘉锡、启功、陆群、凌纯声、詹石窗、张云、郭培贵等是现代研究者；在架空世界里只能写"某派据一部更古的经书"。
4. **托名典一律标"托名"**：《黄庭内景经》托名大道玉晨君、《阴符经》托名黄帝、《太乙金华宗旨》托名吕洞宾。
5. **九条红线永不解释**：十三之数、代价语义、外道之熵、主角体内庙宇等。可解释的只有"触发／后果／例外／真实度"四栏的判定方法。
6. **合规优先**：不写可复刻的仪式步骤、不指认现实民族与现存宗教团体、不评判正邪、不写活祭。
7. **正文不出现真实地名**：只用 L-01 砂埠·走脚铺／L-03 上峒·柳木坛；"沅陵""辰州"只留在文献层（`地理与势力.md` §〇.2）。
8. **人物用泛称**：职能＋一件物（掌籍执事总拿着一本不是自己的簿子）；龙套只写"行当＋甲／乙"，不跨章复用（`人物卡.md` §0.1）。

## 七、下一步建议

1. **写首章**：按 `04_章纲` 第 1 章的三段配比落笔（异常信号 700–850／规则确认 1,000–1,150／结算 450–550／钩子 200–250 字，按 2,500 字档）；写作时手边放三样——`06_文风与章节/00-文风卡`、`07_护航与质检/00-连载护航台账`、`04_章纲`。写完先过文风卡 §9 自检十项。
