# 资料包：仙侠惯例与克苏鲁范式

> **《华夏克苏鲁》世界观设定集·参考资料包**

---

## 用途

本资料包为《华夏克苏鲁》（虚构中文网络小说）的世界观设定提供**外部行业参照**，具体解决三个问题：

1. **避免"以为自己是原创"**：本书的境界体系若沿用「练气→筑基→金丹→元婴→化神…」这条线，它在网文史上已是 2002 年以来的行业默认解；本包 A 部分逐条区分「有典籍/有出处的」与「网文自创后被当常识的」，供本书判断哪些是行业惯例、哪些才是可用差异点。
2. **避免"重复既有作品"**：本包 B 部分严格核实了「仙侠×克苏鲁」「民俗恐怖×克苏鲁」「规则怪谈×民俗」三条赛道上确实存在的作品、作者、平台与做法（未能核实的直接标注，未编造任何作品名或作者名），供本书判断"切入角度空白在哪里"。
3. **避免"设定堆砌"**：本包 C 部分给出可直接落地的操作建议——三层信息分配、设定集管理、避免民俗沦为符号堆砌的具体手法。

**本包不含任何小说正文**，不含为本书原创的设定提案（差异化建议只给方向与依据，不给具体等级表）。

# A 部分：仙侠境界体系的行业惯例

> **本部分的核心用途**：区分「有典籍/有出处的」与「网文自创后被当常识的」。
> 这条区分线决定了本书境界体系哪些环节是"不能声称原创"的地带，哪些是可以下手的空白地带。

## A1. 主流境界链的出处与普及时间

### A1.1 结论速览

| 说法 | 核实结论 |
|---|---|
| 「练气→筑基→金丹→元婴→化神→炼虚→合体→大乘→渡劫→仙」是道教自古传下的境界体系 | **不成立。** 道教内丹典籍中的实际次第是「炼精化气 → 炼气化神 → 炼神还虚 → 炼虚合道」四阶段，术语与网文完全不同 |
| 这条线出自《修真门派掌门路》 | **不成立。** 《修真门派掌门路》（齐休）沿用的是「练气→筑基→金丹→元婴→化神→炼虚」，本身是**采用**而非**发明**；该书的贡献在于"灵根/本命/同参三者合一"的差异化设定与严谨的突破逻辑 |
| 出自《仙逆》 | **不成立。** 《仙逆》（耳根）用的是完全另一套体系：凝气（分十五层）→筑基→结丹→元婴→化神→**婴变**→**问鼎** →（阴虚阳实）→ 窥涅/净涅/碎涅 →（天人五衰/破空五指）→ 空涅/空灵/空玄/空劫 → 踏天。《仙逆》贡献的是"化凡、意境、道心"词汇与"顺为凡，逆为仙"的哲学骨架，不是境界阶梯本身 |
| 出自《凡人修仙传》 | **部分成立但不完整。** 《凡人修仙传》（忘语，2008）把体系**定型并普及**为今天的通用版，但**首创者不是它** |
| 真正首创者 | **《飘渺之旅》（萧潜，2002 年起连载）**。光明网"中国网络小说好看榜"书评明确写道："沿用至今的名词，竟然几乎全部都是由《飘邈之旅》创造的"，并列出其原始十一个境界：旋照、开光、融合、心动、灵寂（金丹）、元婴、出窍、分神、合体、渡劫、大乘 |

### A1.2 传播路径（三段式）

1. **民国武侠埋种子**：《蜀山剑侠传》（还珠楼主）已有"修道—渡劫—飞升"的骨架，但用"道行/修为深浅/法力高低"模糊描述，**没有分级表**。
2. **网文时代定型（2002）**：《飘渺之旅》把"炼气、筑基、金丹、元婴、化神"这一串顺序固定下来，是第一套标准化、层级化的修仙境界体系。其划时代之处在于为每个境界写清了实力、突破条件、寿命上限——**"可量化的等级"本身就是网文发明的产物**。
3. **国民级普及（2008）**：《凡人修仙传》未改动核心顺序，只做细节优化（细分层数、增加瓶颈设定、明确境界差距），把它推到了全民常识的位置。

### A1.3 现有"最常见版本"（读者默认认知）

以《凡人修仙传》定型的版本为准：

- **下境界（人界）**：炼气（13 层）→ 筑基（初/中/后/巅峰）→ 结丹 → 元婴 → 化神
- **中境界（灵界）**：炼虚 → 合体 → 大乘
- **渡劫**：作为突破仙界的关口层
- **仙界篇（续作设定）**：真仙 → 金仙 → 太乙 → 大罗 → 道祖

注意：**"金丹"与"结丹"是同物异名**，《凡人修仙传》原著用"结丹"，网文口语普遍用"金丹"。本书选用哪个词，本身就是一个风格信号（详见 D 部分建议 1）。

## A2. 其他常见分法

### A2.1 斗气大陆式（《斗破苍穹》，天蚕土豆）

完整等级（每阶一至九星）：

> 斗之气 → 斗者 → 斗师 → 大斗师 → 斗灵 → 斗王 → 斗皇 → 斗宗 → 斗尊 → 斗尊巅峰（一至十转）→ 半圣（低/中/高）→ 斗圣 → 斗帝

**设计意义**：把"境界"从**道教词汇**彻底换成**异世界通用语**（斗气/斗者/斗师），去掉了所有宗教色彩，同时保留"一至九星"这种万能的细分刻度。这是"西式玄幻+中式修仙"的典型融合路径。

### A2.2 《玄鉴仙族》式（季越人）——**本书最重要的对标样本**

> 胎息（分六轮：玄景轮、承明轮、周行轮、青元轮、玉京轮、灵初轮；玉京轮开辟上丹田生神识）→ 练气（1–9 层，采"正气/杂气"）→ 筑基（又名道基，修出本道统的仙基）→ 紫府（修满五道神通）→ 金丹（**求金法**，证得一缕金性）→ 道胎

关键创新：
- **境界名来自道教却按新规则重排**——紫府在金丹之前，与主流网文（金丹→元婴→化神）顺序相反
- **果位制**：金丹分果位/闰位/余位，"一个道统的果位金丹只可能有一人"。果位同时是**资源位**，天然产生世界级冲突（道统争果位），而非单纯的战力刻度
- **56 种已知仙基**（阴阳五行十二炁排列组合），修士仙基各不相同

洪荒文学的评语可作本书的标尺："**通常的修仙文，大部分走的是《缥缈之旅》最先带头的那条路子**……而季越人则在《玄鉴仙族》里重构了一套逻辑自洽并与文章内容完美绑定的修炼体系"，并特别指出"很多时候编辑都会建议我们用读者熟知的力量体系，接受度高，进入剧情快，而作者自己琢磨出来的力量体系要么拖剧情后腿，要么陷入自嗨"。

> **对本书的直接含义**：《玄鉴仙族》证明了"改境界体系"可行且能出爆款，但也点明了它的门槛——新体系必须**与内容绑定**，且**不能拖慢入戏速度**。见 C5。

### A2.3 寿元对应关系

**关键结论：网文流传的"金丹500、元婴1500、化神3000"没有任何公认来源，是网文自创后被当成常识的数字。**

证据一：同一批起点问答里，"修真境界寿命"给出的是一套**另一组**数字：
> 锻体 100 / 练气 100 / 筑基 200–500 / 金丹 500 / 元婴 2000 / 化神 4000 / 返虚 6000 / 合体 8000 / 渡劫 10000

证据二：《凡人修仙传》原作为结丹 500 / 元婴 1000+ / 化神 2000+；另一部《我在修仙界长生不死》的对应表则是练气 150 / 筑基 200 / 金丹 500 / 元婴 1000–1500 / 化神 2000–3000 / 返虚 5000–9000。

证据三：《斗破苍穹》《遮天》各自有完全独立的寿元表（斗尊 500、斗尊九转 1000、斗圣 5000；遮天魂斗罗 100、封号斗罗 200–1000……）。

**判断**：寿元数字是**逐书逐作者独立约定**的，任何"公认寿元表"都不存在。这带来一个可操作的杠杆——**本书若给出自己的寿元表并让它服务于剧情，就不存在"抄错了"的风险，只存在"是否自洽"的问题**。这是自由度，不是风险。

## A3. 天劫的类型学与"渡劫失败兵解"

### A3.1 有典籍支撑的部分

**道教劫灾观**（道教之音·《劫災》条目，附《灵宝无量度人上品妙经》《太上洞渊神咒经》《云笈七签》等典据）：

- **三灾**：火灾（劫火/阳火，焚至初禅天）→ 水灾（劫水淹至二禅天）→ 风灾（劫风吹坏至三禅天）；另有小三灾：兵灾、瘟疫、饥馑
- **劫期体系**：《度人经》系统阐述龙汉、延康、赤明、开皇等年号劫期
- **宇宙四阶段**：成、住、坏、空；劫灾发生在"坏劫"

**三重天劫**（百度百科·天劫条目）：
> 第一劫：天雷击顶之灾 → 第二劫（再五百年）：阴火焚身之灾 → 第三劫（再五百年）：风解体之灾

注意这三劫的表述与《抱朴子》三灾（火、水、风）**并不完全一致**，而《渡劫》条目又记载"飞升成功者根据修为分为'白日飞升''尸解仙''兵解仙'等不同层次"。

**结论**：**"三灾"与"三重天劫"有道教典据支撑**；但后世网文里"雷劫/心魔劫/风火劫"这套**分类学**是混合了佛教"劫"概念与全真教再阐释的通俗化产物，"心魔劫"一词尤其晚出。

### A3.2 "渡劫失败兵解"的典据状况

**有典据的部分**：
- 道教确有"尸解/兵解"体系。搜狗百科"兵解"条目载：道教术语，魔教仪规；教主临死前须由部下割下头颅方能脱体飞升；"道家的说法大凡死掉都叫做尸解。淹死的叫水解，刀砍的叫兵解"；尸解又有**棺解**（于棺中失其尸体，唯留爪发）、水解、火解、杖解等多种；并引古龙《圆月弯刀》"若是经由雷火天劫，就会形神俱灭了"。
- 兵解有**三类用途**：一是飞升（功候已足但需兵解方能飞升）；二是渡劫（自知扛不过天劫，恐形神俱灭，故在劫前借他人之手兵解）；三是消孽（借故兵解死在有夙孽的人手里消解前孽）。

**必须澄清的两点**：
1. "兵解"在道教里**不是"渡劫失败后的备选方案"这么简单**——它是主动选择的、以元神脱壳为核心的技术，兵解后元神离躯不能长存，需重新投胎或另觅肉身。
2. **"渡劫失败→兵解→转散仙→每万年渡一次散仙劫、共九次"的完整设定链是网文自创**。起点问答中列出的"12,960 年为一劫…共需渡过九次才能飞升仙界"未见任何典籍来源，属网文自创并已被视为常识。

> **对本书的含义**："渡劫失败兵解"是**典籍与网文各占一半**的地带。若本书要用，最稳的做法是保留"兵解是主动技术、需付代价（元神不能久居无肉之身）"的道教内核，而不要照搬"九次散仙劫"这条已被网文固化的支线。

## A4. 称谓的行业用法

| 称谓 | 行业用法 | 出处状况 |
|---|---|---|
| **真人** | 金丹期修士的尊称；也用于泛指"得道者" | **有典籍**。道教神仙谱系中"真人"是正式位阶 |
| **真君** | 元婴期尊称（通行说法："元婴真君"）；《玄鉴仙族》把金丹称"真君" | **有典籍**。陶弘景《登真隐诀》载："三清九宫并有僚属，例左胜于右，其高总称曰道君，次真人、真公、真君"（见《太平御览》卷六六二引） |
| **道君** | 通用最高尊称（起点《道君》即以此为主角称号） | **有典籍**，但原义是道教高位仙官的尊称（如元始天尊又称"虚皇道君"），且古代亦用作对皇帝的美称。网文给它加了"修为最高者"的固定含义 |
| **大能** | 化神期及以上的尊称 | **网文自创**。无宗教典籍来源，是纯口语化敬称 |
| **老怪物** | 对活得很久、手段诡谲的高阶老修士的戏谑/忌惮称呼 | **网文自创**。无典籍，纯口语 |
| **福地 / 洞天** | 指灵气充沛、适合修炼的地理区块；也用作副本名 | **部分有典籍**：道教"洞天福地"是真实概念（洞天即别有洞天之天，福地即神仙所居之福地），《云笈七签》等有记载。但**网文用法已变异**——现多指"某洞天/某福地=一个可争夺的资源区块"，且已成固定副本命名模块 |
| **秘境** | 泛指有危险/异象的隐秘之地 | **网文自创/泛化**，非道教专名 |
| **大能/前辈/道友** | 交往称谓体系 | "道友"有道教渊源（道门同门互称），网文沿用；"前辈"是纯网文/武侠通用语 |

> **对本书的含义**：**「真君」「真人」「道君」有典据可用，「大能」「老怪物」是网文口语。** 一本叫《华夏克苏鲁》的书若大量使用「大能」「老怪物」，会立刻落入网文通用语，削弱"华夏"质感；若混用「道君/真君/真人」并给出自己的位阶映射，则能同时拿到"有典据"的踏实感和"自创体系"的差异化。

## A5. 功法品级分级的普及来源

**黄/玄/地/天 的来源与定型**：

- **典籍根**：成语/典故"天地玄黄"（《千字文》"天地玄黄，宇宙洪荒"）。网文把"天地玄黄"**倒序**成"黄玄地天"，再各分上/中/下/极品四档。
- **定型之作**：《斗破苍穹》（天蚕土豆）明确分**天、地、玄、黄**四阶，每阶分高中低三档（《帝印诀》为地阶高级功法）。
- **后续扩展**：仙阶/神阶/圣阶/至尊/帝阶/仙阶/神阶……层层加码，是网文通用做法。起点问答确认："在《斗破苍穹》中，功法等级被划分为天、地、玄、黄四个级别""在某些设定中还有更详尽（的划分）"。实际操作中常见"黄阶→玄阶→地阶→天阶→仙阶→神阶"，以及"凡/黄/玄/地/天/仙/神"七阶。
- **注意**：《修真门派掌门路》用的是另一套（结合原著的"一阶中品/一品极品""二阶上品""三阶中品"等），并把功法品阶与**本命/同参**绑定——这又是一次重新分级的成功样本。

> **对本书的含义**：黄玄地天是**读者零学习成本**的资产（免费），但也是**零差异**的资产（人人都用）。本书若沿用，至少要在**品阶与民俗/禁忌挂钩**上做区分——例如"品阶不由灵气浓度决定，而由这门法事能承担多少禁忌反噬决定"，把品级从"强弱刻度"改成"风险刻度"。

## A6. 内景/外景、五脏神、存思、守一、斩三尸——网文常见用法与误用

这是本书最容易"用错就露怯"的一组词。逐条给出**原典义**与**网文误用**：

| 词 | 原典义（有出处） | 网文常见用法 | 误用风险 |
|---|---|---|---|
| **内景 / 外景** | 《黄庭内景玉经》（上清经，梁丘子注）。梁丘子注："内者，心也；景者，象也……心居身内，存观一体之象色，故曰内景也"；"黄庭"指天中、人中、地中／脑中、心中、脾中。《黄庭经》有内景篇与外景篇之分 | 《一世之尊》式的"内景/外景"武学境界；泛指"内在修为 vs 外在表现" | **中**。若本书用"内景"作境界名而不点出《黄庭经》脉络，会显得像通用玄幻词；点明则立刻有质感 |
| **五脏神** | 《太平经》已有五脏神观念；《黄庭经》吸收之，发展为**三部八景二十四神**，认为人体各部位都有神灵居住，存思身中神真可调息五脏 | 网文里常被简化成"五脏对应五行对应五种力量"的属性表 | **高**。这是最容易被内行一眼看出的误用：原典是**神祇图谱与存思对象**，不是属性对应表 |
| **存思**（存想） | 上清经传统。分**存身内之神**与**存身外之神**两类；《金阙帝君三元真一经》载三丹田中神（天帝、丹皇、元王）监统身中二十四气；《云笈七签·升斗法》有具体存想次第 | 常用作"冥想/打坐/观想"的同义词，或直接写成技能名 | **中**。存思有严格的"对象—次第—感应"结构，写成"闭眼冥想"就丢掉了它的全部特色 |
| **守一** | 《老子》"抱一"、《庄子》"守一"；道教"守一存真"。《黄庭内景玉经注》将"守一"列为修持指令之一 | 用作"守住心神/专注本心"的极简说法 | **低中**。可用，但若要显厚，最好点出"守一"与"三丹田/一念"的对应 |
| **斩三尸** | 道教确有"三尸"（三彭）概念，源于人身内的三尸九虫；后世内丹与通俗读物演化出"斩三尸"为修行目标 | 网文常把"斩三尸"写成"斩断贪嗔痴三欲"或"斩三具分身"，甚至直接等同于"斩心魔" | **高**。原典三尸与佛教三毒、贪嗔痴的混同，本身就是通俗读物（尤其《黄庭经》注疏传统与后世内丹）的产物；若本书把它写成"斩三尸=斩贪嗔痴"，基本等同于宣告没做功课 |

> **重要参考**：潇湘书院《逆炼参同》的作品百科条目里有一段对"三尸教"的批判，正好点明了这个误用的发生机制——"三尸教将《黄庭经》'三尸'概念曲解为必须斩杀的邪祟"。这句话反向证明：**"三尸"的正确原义不是"该杀的邪祟"**，而是**内丹家视为必须炼化的自身习气**。作者可以引用这个视角来给自己的人物/设定提供思想深度。
>
> **对本书的含义**：这五个词是**低成本高回报**的差异化素材。绝大多数"华夏克苏鲁"网文只会用"灵气、丹药、天劫"，很少有人肯在"存思五脏神""守一""三尸"上做考据级使用。但要用对，成本在**读原典**（黄庭经可全文读，成本极低），不在写作技巧。

# B 部分：克苏鲁神话与中式融合的既有实践

## B1. 克苏鲁神话核心设定（可靠信息）

### B1.1 原典起点

- **霍华德·菲利普·洛夫克拉夫特（Lovecraft）**，《克苏鲁的呼唤》（The Call of Cthulhu），**1928 年**发表于廉价通俗杂志《诡丽幻谭》（Weird Tales）。"克苏鲁"一词源自这篇短篇中最早出场的远古邪神之名，其神话体系也肇始于此。
- 洛夫克拉夫特本人从未试图建立封闭教义式的神话体系，他多次强调"这些创作纯属虚构，并未打算构筑严整神学"。

### B1.2 神话体系的两个阶段（重要区分）

1. **原生期（洛夫克拉夫特在世）**：洛氏与同时代作者形成松散的互文创作网络，彼此借用虚构书籍、神祇名与设定元素。其精神核心是"**宇宙的冷漠**"与"**人类的渺小**"。原文名句："人类面 对宇宙中存在的威胁显得很渺小，甚至毫不重要"；以及几乎可视作整个体系哲学摘要的一句："**人类最仁慈的处境在于无法把所有已知事物联系起来**"（这句直译影响极广，戈革、倪匡一系的"克苏鲁式恐怖"评论常引）。
   - 研究者普遍认定：**洛夫克拉夫特本人是无神论者，倾向机械唯物论立场**。宇宙没有目的，也没有道德预设；人类并非被注视的对象，只是宇宙运作中的偶然产物。**恐怖来自尺度落差，而非报复或诅咒。**
2. **整理期（洛氏身后）**：版权继承者**奥古斯特·威廉·德雷斯（August Derleth）**系统化原本松散的设定。他提出"**古神**"与"**旧日支配者**"的对立，把原本非道德、非人格化的宇宙架构转为较接近善恶二元的模型，并引入元素分类法（按水火风地划分阵营）。GQ 的分析明确指出：**这种分类在文本依据上并不稳固，且与洛夫克拉夫特原有的无道德宇宙观存在明显张力。**

> **对本书的含义**：**这是一个可被读者识别的"知识点差"。** 绝大多数中文克系网文（包括《道诡异仙》《道祖是克苏鲁》这类优秀作品）采用的是德雷斯之后的体系。知道"古神 vs 旧日支配者"是德雷斯的二次建构、并理解洛氏原本的"无道德/无目的"底色，本身就是设定深度的信号。

### B1.3 核心要素清单（可靠）

| 要素 | 内容 |
|---|---|

## B3. 民俗恐怖/志怪在华语网文中的做法特点

### B3.1 核实到的代表作与做法

| 作品 | 做法特点（已核实） |
|---|---|
| **《鬼吹灯》（天下霸唱）** | **行当化**——把盗墓拆成四大流派，每派有自己的历史、传承与做人规矩；**风水作为知识体系**（半本《十六字阴阳风水秘术》贯穿全书）；**悬念必有逻辑解释**，主线顺畅，但被指出"结构单一" |
| **《捞尸人》（纯洁滴小龙）** | **职业即入口**——捞尸人（走江人）的行当规矩（捞尸三不捞）就是世界观的入口；**单元故事 + 长线主业**双层结构；**以人性为鬼的成因**（"鬼晓人心毒"）；背景锚定长江流域水乡，行当细节扎实，不靠 jump scare 靠雾气与白事禁忌 |
| **《十日终焉》（杀虫队队员）** | **规则即谜题**——每个"死亡游戏"有严密逻辑链；**倒计时结构**（十日重启）天然产生紧迫感；**群像 + 智力博弈**，主角靠规则洞察而非金手指硬闯；融合国风元素（十二生肖）与存在主义议题 |
| **《诡舍》（夜来风雨声丶）** | **副本即单元 + 中式民俗场景库**（祈雨村、古宅、长春高校）；**规则怪谈与民俗恐怖合流**；每个副本的怪谈背后是人间悲剧（"祈雨村里贪生怕死的村民将活人活埋以求自保，人情味比厉鬼更让人不寒而栗"）；主角"见鬼不跑，先找规律"，靠规则缝隙求生 |
| **《我有一座恐怖屋》（我会修空调）** | **收容式建制**——把恐怖场景变成可运营、可参观的"鬼屋"（恐怖屋+ 员工+ 道具库+ 鬼怪等级）；恐怖来自**日常细节的不合理**，不靠血浆；单元副本 + 主线（父母失踪）双线 |
| **《道诡异仙》（狐尾的笔）** | **不可靠叙述者 + 双世界互为镜像**；**"心素"体质**作为核心设定（能看见一切，也能被一切看见）；把坐忘道（欺骗之神斗姥太阴）的"靠骗术修行"与克苏鲁的认知污染对接；现代精神病院（现实中国）与诡异修仙世界双轨，读者无法确定哪边为真 |
| **《诡秘之主》（乌贼）** | **序列 + 扮演法 + 特性守恒**三重机制；把超凡力量嵌入**完整社会经济结构**（物价、阶层、教会与国家机器）——起点总编辑李晓亮的评价："《诡秘》的成功在于让一个高武世界有了经济体系与经济结构" |
| **《神秘复苏》（佛前献花）** | **规则即生存杠杆**：每只鬼有固定杀人规律，破解规律才能活；鬼与鬼之间可组合出新的逻辑死循环与衍生能力 |

### B3.2 可提炼的"做法特征"（跨作品共性）

1. **职业/行当即世界观入口**：捞尸人（走江人）、盗墓四大流派、纸扎匠、阴阳先生、赶尸人、香烛纸马——读者通过一个具体的手艺进入一整套规则体系。**这是本书最值得直接继承的做法**。
2. **单元剧 + 隐藏主线**：《捞尸人》《十日终焉》《鬼吹灯》《镇龙棺》全用这个结构。单元保证节奏，主线保证追读。
3. **恐怖来自"规则被违反"，不是"怪物出现"**：《神秘复苏》《诡舍》《十日终焉》都把恐惧放在"你不知道规矩就会死"上。
4. **鬼怪是人间悲剧的投影**：《捞尸人》的"鬼晓人心毒"、《诡舍》的活人活埋民俗、《鬼吹灯》的主题定位在人心上的贪欲与恶念。这是**规避"符号堆砌"最有效的单一手法**。
5. **代价必须写出**：《傩面，纸嫁衣》的"施术必有代价"、《长生志异》的"修行界第一定律"、《诡秘之主》的非凡特性守恒。
6. **认知/感官失序是克系中式的接口**：《道诡异仙》的"心素"体质与真假难辨，是把洛夫克拉夫特的"理智代价"翻译成汉语语境的最成功案例。

## B5. 国外"民俗学恐怖"（folk horror）浪潮对中文创作的影响

### B5.1 folk horror 的可靠信息

**词源与命名史（英文维基，可靠）**：
- 最早用例（指涉一件器物而非类型）出现在 John Fowles 1965 年小说《The Magus》
- **1970 年**，影评人 Rod Cooper 在影刊《Kine Weekly》评论 Piers Haggard 的《The Devil's Touch》（后改名《Blood on Satan's Claw》）时使用该词
- **导演 Piers Haggard 本人**在 2004 年《Fangoria》访谈中采用该词描述自己的影片，并说："我拍的是一部民俗恐怖片……不是那种露骨夸张的。"
- **术语流行**：作家兼演员 **Mark Gatiss** 在 2010 年 BBC 纪录片系列《A History of Horror》第 2 集"Home Counties Horror"中推广，引《Blood on Satan's Claw》(1971)、《Witchfinder General》(1968)、《The Wicker Man》(1973) 三部为类型奠基作

**类型的核心定义（三要素）**：
1. **与世隔绝的乡村/共同体**（isolated community / rural setting）
2. **根植于民间传说的信仰体系**（folk religion / pagan tradition / superstition）
3. **外来者闯入一个自己无法解码的道德秩序**（outsider protagonist），且**威胁通常来自集体而非单一怪物**

关键的类型学区分（StudioBinder 归纳，与英文维基一致）：
- 与 **backwoods horror**（砍杀类）的区别：后者威胁来自暴力个体，前者**整个社区参与施加威胁**
- 与 **supernatural horror** 的区别：后者中心是外部邪恶力量，前者**即便有超自然成分，真正的恐惧引擎仍是人所持有的信念**
- 核心要素：乡村隔绝、封闭共同体与自定习俗、古代神话/异教传统、仪式推动主线、外来者主角、集体性危险

**"不神圣三联"（The Unholy Trinity）**：英国 1968–1973 年三部片——《Witchfinder General》(Michael Reeves, 1968)、《Blood on Satan's Claw》(Piers Haggard, 1971)、《The Wicker Man》(Robin Hardy, 1973)。注意其共同性：**《Witchfinder General》片中并无真正的巫术**，写的是 17 世纪英格兰猎巫恐慌的社会现实；《Blood on Satan's Claw》则把魔鬼写为真实存在。两种方向都成立，这正是 folk horror 的弹性所在。

### B5.2 复兴期的代表作

- **Robert Eggers《The Witch》(2015)**，副题《A New England Folktale》——1630 年代新英格兰，一个被逐出清教徒共同体的家庭；老山羊黑菲利普；Anya Taylor-Joy 主演。Eggers 为此做了**大量历史考据**：请木工搭建史实正确的房屋、请服装设计师用当时材料；演员使用史实方言，甚至一度难懂。成本 400 万美元，桑德森斯收获 4000 万美元。评论界普遍视其为 2010 年代最强的导演处女作。
- **Robert Eggers《The Lighthouse》(2019)**——19 世纪新英格兰无名小岛上的两名灯塔看守人；近乎方形的 1.19:1 画幅、纯黑白、使用 1930 年代的正色片镜头拍摄；语言借用 19 世纪新英格兰方言（Eggers 说取材于缅因作家 Sarah Orne Jewett 的作品）。风格上深植海事神话与希腊悲剧。
- Eggers 其余作品：《The Northman》(2022, 改编自 Amleth 传说，即《哈姆雷特》母题)、《Nosferatu》(2024)、**《Werwulf》(2026-12-25 北美上映，全片中古英语)**。
- **Ari Aster《Midsommar》(2019)**——瑞典仲夏、斯堪的纳维亚异教崇拜与人祭，把 folk horror 推向当代恐怖商业片的核心。

### B5.3 对中文创作的影响（中文语境的接受与转化）

**可核实的在地转化路径**：
1. **《诡秘之主》**（乌贼，中国作家网访谈明确其灵感"来自克苏鲁神话体系"），把克系放进维多利亚社会——这是"西方民俗恐怖"最直接的本土化。
2. **《道诡异仙》**——将西方"理智崩坏/不可名状"与**佛教、道教、民俗知识**大量融合，业内评论称其"将中式恐怖与克苏鲁的疯狂绝望完美融合，呈现出独特的风味"。
3. **《捞尸人》**——把 folk horror 的**共同体结构**（封闭水乡、行当禁忌、世代传承）与中国本土行业细节结合，被读者称为"中式克苏鲁"。
4. **《十日终焉》**——规则怪谈 + 神系 + 国风元素，被官方表述为"融合了悬疑烧脑、极限博弈、**国风元素**与存在主义议题"。
5. **《我在精神病院学斩神》**——多神话体系同框（希腊/北欧/圣经/日本/中国/印度/埃及），"中西结合：庞大的世界观架构"是其被中国作家网专题分析的核心特征。

**日式 folk horror 的谱系（另一条输入线）**：
- **上田秋成《雨月物语》**（初稿 1768，出版 1776）：取材**中国**《剪灯新话》《三言》，九篇志怪；北京大学《比较文学研究》论文专门比对《剪灯新话·爱卿传》与《雨月物语·夜宿破茅屋》，确认后者受前者影响，但上田秋成**并非简单搬用，而是"以日本社会为背景，采取虚实结合的写法，重新结构情节"**——这本身就是"外来民俗素材本土化"的教科书案例。
- **柳田国男**《远野物语》《日本昔话》《妖怪谈义》——日本民俗学奠基人的田野调查记录。
- **京极夏彦《百鬼夜行系列》**（讲谈社；首作《姑获鸟之夏》直接促成了梅菲斯特奖的设立）——"作品内富含民俗学（鬼怪传说）、伦理学等相关知识"。
- 《剪灯新话》（明·瞿佑，1378）本身的命运颇具讽刺：**中国古代第一部被明文禁毁的小说，却因《御伽俾子》与《雨月物语》的改编而在日本存活六百年，并在 20 世纪 20 年代才"从日本重新进口"回中国**，影响了《聊斋志异》。

**乌克兰/斯拉夫民俗恐怖（另一条输入线）**：
- **果戈理**是乌克兰与俄罗斯恐怖的开端。《Viy》(1967, Ershov/Kropachyov) 是公认的苏联首部恐怖片，其 1909 年无声改编是史上第一部俄罗斯恐怖片。果戈理取材自乌克兰民间传说与**木偶戏（vertep）**传统。
- 乌克兰"诗意电影"运动（《Тіні забутих предків》1965 等）以民俗与现代主义结合闻名。相关学术研究指出的批评模式很有价值：**"对文化代码元素的解读只作为艺术上的'拐杖'……民俗母题缺乏必要的深度，只是背景而非情节的独立元素"**——这几乎是**对"符号堆砌"这一批评的学术版复述**。
- 乌克兰本土恐怖片：《The Gateway》(2017, 切尔诺贝利禁区, Rusalka/Lisovyk)、《Pagan Magic》(2019, 喀尔巴阡山区手持纪录片)、《Lizaveta》(2018, 女巫猎捕与乡村偏见的交汇)、《The Curse of the Witch》(2017)、《The Uninvited Guest》(2019, 乌克兰丧葬仪式)。

## B6. 常见批评：考据不足 / 符号堆砌 / 猎奇化

**这是本书最需要正面回应的一节。批评不是零散的，而是已经形成了官媒定性与行业共识。**

### B6.1 官媒定性（人民网，2026-07-11）

《人民锐评："民俗恐怖"折射乡土文化传播困局》——**这是目前中文语境下最权威、最可引用的批评文本**，核心论点：

1. **现象**：纸人、冥婚、荒庙、巫蛊等意象频繁跃上各大文娱榜单，"民俗恐怖"成为流量密码。
2. **问题定性**："**大量作品剥离了文化内核，以恐怖为卖点拼命堆砌惊吓桥段，硬生生将中华乡土民俗推入了'恐怖谷'**"；"**这种逮着民俗只做恐怖文章的路径，折射出民俗与乡土文化在当代传播中面临的困局**"。
3. **根本病灶**："**无需深耕史料，不必挖掘人文底色，只需提取民俗里的小众诡异符号，拼接惊吓镜头，便能快速产出作品撬动流量。这种功利化改编只取恐怖之形、抽空精神内核，将厚重的乡土文化简化为吓人工具，看似'活化传统'，实则是买椟还珠。**"
4. **原生价值观**："民间祭祀、岁时节令、地方信仰扎根于民众的生产生活，其内核是**慎终追远、驱邪向善、祈福安民**。""即便民间传说里的鬼神叙事，底色也多是**劝善惩恶的朴素道德教化**。"
5. **社会危害**：长期浸泡在"荒村、冥婚、邪庙"叙事中，年轻人易默认民俗等于封建糟粕、诡异邪祟，**消解非遗传承的群众基础**；作品放大"乡村落后、民风诡异"的刻板印象，制造城乡认知隔阂。
6. **出路**："创作者当跳出猎奇套路，**深耕民俗史料与地方文史，挖掘传说背后的时代背景、民众生存状态与人文情感**，让民俗回归其承载的生活智慧与情感温度；平台要优化算法推荐……学界与非遗保护力量应深度介入文娱内容前置把关。"

### B6.2 行业评论的批评（三条独立来源，指向同一处）

**批评一：民俗学知识变成"堆砌"和"内卷"**（《一缕庄闲话也谈中式恐怖》，评《烟火》《三伏》等）：

> "这些模仿品对中式恐怖的理解变味了，他们力图在一些传统的怪力乱神边边角角里找出一些考据性的知识，然后拼凑起来。不得不承认他们很用心，一草一木一笔一画都有出处，天罡地煞八卦阴阳煞费苦心。殊不知这**无非就是民俗学知识的堆砌和内卷**。"

并给出一个反向标准（正面结论，用于本书）：
> "《__校》之所以是神作，是因为它**一不借助世界观的叠加，二不依托那么多犄角旮旯里的传统元素**，而非常灵活而完美地将恐怖融入到了一个时代的民俗生活之中……整个游戏并不是贯穿着纸人纸马、道教符咒，这些东西只是编织故事的针线……**《__校》最成功的一点是，并不堆砌灵异元素，而将恐惧刻入人的内心。**"
> "唯独中式恐怖，应该**因与现实生活的重叠感**取胜。这种'最熟悉的恐怖'之所以是中式的，原因就在中国民俗文化的根深蒂固。"

**批评二：世界观膨胀反而消解中式恐怖的独特性**（同上）：

> "现在出现的所谓中式恐怖另一大特点是**世界观的膨胀**……这些中式恐怖都对构建一个纯粹虚构的邪神乐此不疲……宏大的世界观看似给整个故事增光添彩，但实际上在无形之中**消解了中式恐怖的独特性**——事实上，宏大的世界观创造出的隔离于现实生活的闭锁空间，从而加剧逃脱不掉的窒息感，**这恰恰是日式恐怖的特点**。"
> "对读者而言，每次都要捏着鼻子服用这种巨大的世界观，这一过程造成的疲倦已经是对热情的消磨。"

**批评三：三点平台红线已经开始收网**（自媒体对官方定性的跟进，B27）：

> "早在今年年初，**番茄、七猫等主流免费站就已经明确：现代背景下的真灵异、真鬼怪内容，直接按宣扬封建迷信处理，轻则屏蔽章节，重则直接封书；晋江、起点等平台，民俗类内容的审核尺度也一再加严**，详细描写封建迷信仪式、刻意渲染乡土愚昧阴暗面的内容，基本过不了审。"
>
> 三条红线：
> 1. **现代背景绝对不能写"真灵异"**——所有超自然鬼怪内容最后必须落到人为作案、心理错觉、科学解释上
> 2. **绝对不能拿民俗当恐怖工具**——别再把正常的婚丧嫁娶、节气民俗全往邪性、诡异方向写
> 3. **别碰有引导性的封建迷信内容**——笔仙碟仙、驱邪改命、算命消灾这类**可复刻**的迷信内容，不管什么背景都别碰
>
> 合规出路："写民俗悬疑，把所有诡异事件落在人心阴谋、旧案真相上；写民俗传承，讲扎纸匠、唢呐匠这些老手艺里的人情世故和时代变迁；哪怕写架空志怪，也往传统文化内核、正向价值上靠。"

### B6.3 平台官方规则（可核对的一手来源）

**番茄小说《内容安全须知》**（官方）明令禁止发布的内容包括：
> "破坏国家宗教政策、破坏民族团结、煽动民族仇恨、**宣扬邪教、封建迷信**"；"危害社会公德，如散播谣言扰乱社会秩序，破坏社会稳定，**宣扬淫秽色情、赌博、吸毒，渲染暴力、恐怖**等违法活动"；"侵害民族风俗习惯、**歪曲民族历史**和民族历史人物"。

**七猫中文网《原创作品登载规则和服务约定》**（官方）禁止内容含："破坏国家宗教政策、**宣扬邪教和愚昧迷信的**"；"发布淫秽色情、赌博、暴力、凶杀、恐怖或者教唆犯罪的"。

**补充的操作性提示**（来自番茄写作指南类整理文章，B27/B38，属行业实践而非官方条文，可作参考不作依据）：现代背景下"灵异悬疑可以写诡异传闻，但不能宣扬鬼魂索命、诅咒真实生效，最终要解释为人为设计"；仙侠类"不能把飞升、成仙写成真实宗教得道；邪修不能写活人献祭、噬魂修炼细节；尽量架空仙庭，避开真实佛道神祇"。

> **对本书的三条硬性含义**：
> 1. **本书是"华夏"而非"现代"背景**——架空古代/近代华夏世界，避开了"现代真灵异"这条最严的红线，这是本书相对都市灵异（如《捞尸人》《诡舍》《神秘复苏》部分内容）的一项结构性优势。
> 2. **不得把真实民俗仪式写成可操作、可复刻的教程**（"笔仙碟仙、驱邪改命"被点名）。本书可以写**规则的约束与后果**，但不应写成**读者可照做的步骤**。
> 3. **"施术必有代价"既是文学原则也是合规护城河**——强调代价与代价的可承担性，等于把"宣扬迷信"转为"展示因果"。

# C 部分：世界观设定方法论（可直接用于本书的操作建议）

## C1. 三层世界观与冰山模型

### C1.1 表述的准确澄清（重要）

**必须先说明的一点**："诺兰三层世界观"这一说法在中文写作圈流传甚广，但**并非诺兰本人的原话或理论命名**。

可核实的诺兰原始表述有以下几条（C4–C6）：

1. **规则是为限制而设**（FilmJuice 访谈，C5）：
   > "The rules of the world were designed to put limits on the thing."（世界的规则被设计出来，是为了限制那个东西。）
2. **"卖兔子洞"**（Nolan 在 Inception 拍摄剧本注释中的表述，经 Jonathan Wakeham 转录，C6）：
   > 观众需要知道自己所在世界的规则，才能投入故事；如果把故事设定在一个"什么都可能发生"的世界里，它会变得无法与观众产生关联，最终无法引人入胜。"最好的奇幻作品我们希望读者**臣服于它的逻辑**。"
   > C6 转录者补充其理论根源为博尔赫斯的"自治世界"（orbe autonomo）概念。
3. **作者双重身份**（Deadline 访谈，C4）：Nolan 自称在故事中有时是"**观察者（writer as observer）**"，有时是"**操控者（writer as manipulator）**"。
4. **"三层梦境"的解释**（同一访谈，C4）：他向片方解释如何让观众在交叉剪辑中始终分清梦境层级——一层是雨中的城市、一层是夜晚的室内、一层是雪中的户外，**用视觉特征而非台词来区分层级**。

**因此**：中文语境中常说的"三层世界观"，实际是**把《盗梦空间》的三层嵌套结构 + 诺兰的"规则限制"原则 + 一套自发的写作方法论**混合后的通俗产物。它在《诡秘之主》的评论中已被广泛使用（B10 相关推文即以"三层世界观"来概括 22 序列途径 / 扮演法 / 特性守恒）。

**作者若在设定集里引用"Nolan 三层世界观"，建议采用以下稳妥表述**（既保留实用价值，又不虚构出处）：

> **表层（可见层）**：读者能看见的——人物、场所、技艺、器物、当前的麻烦。
> **中层（规则层）**：这个世界的运行规则——力量从哪来、代价是什么、什么绝对不能做。
> **深层（源流层）**：这个世界"为何如此"的历史与神话——它解释了中层规则为什么是这个形状。

而**诺兰真正可引用的**，是那两条原创原则：**"规则是为了限制而设"**、**"要卖掉兔子洞"（先让读者接受规则，再在规则内制造惊讶）**。

### C1.2 冰山模型

**来源明确**：海明威的冰山理论。用于世界观建构时的标准表述（C12）：
> **你设定的内容应该是写进小说的 5–10 倍。** 不是要写十万字的设定百科（那是另一个极端的坑），而是要脑中保有足够的"底层逻辑"，让你在写作时做出一致的决定。

**中文写作圈更常用的通俗版**（C7）：
> "如果你只写了水面上的 10%，连水下那 90% 自己都没想清楚——角色的行为会前后矛盾，势力的逻辑会站不住脚，读者翻到后面就会发现'这个世界经不起推敲'。"
> "**你说的越少，读者想象的越多。**"
> 四个维度（须自己列一份大纲，然后**锁进抽屉**）：法则（世界的底层规则）、历史（重大事件如何塑造今天的格局）、势力（权力结构与利益纠葛）、危机（什么东西随时可能崩塌）。

## C2. Sanderson 三法则的准确表述与出处

**出处**：布兰登·桑德森（Brandon Sanderson）个人博客的三篇连载短文，2007 年前后陆续发布，官方页面为 brandonsanderson.com。三篇均为 **magic system**（魔法系统）理论，非世界观通论。

### 第一法则（原文，FEBRUARY 2007）
> **"An author's ability to solve conflict with magic is DIRECTLY PROPORTIONAL to how well the reader understands said magic."**
> （作者用魔法解决冲突的能力，与读者对该魔法的理解程度成正比。）

作者自陈出处：他在第一次 Worldcon 会议上被同台嘉宾反驳"魔法不能有规则，否则会失去奇迹感"后总结而来。并自述其系统是"约 80% hard magic"。

### 第二法则
> **"Limitations > Powers"**（限制比能力更重要）

作者补充的关键限定：
- "**none of these 'laws' are absolute**"（这些法则没有一条是绝对的）
- 代价若**过于严酷**，会导致魔法几乎无法使用，限制情节灵活性
- "having a rule-based magic system isn't about **rationality**, but **consistency**"（规则化魔法系统的要点不是合乎理性，而是**一致性**）
- "This law is meant for **writers**."（这条法则只写给作者看，读者可能根本注意不到）

### 第三法则
> **"Expand what you already have before you add something new."**
> 结论口号：**"Expand, Don't Add."**

三个操作方向：
1. **Extrapolate（外推）**：问"当……会发生什么？"——"一个巫师改信基督教会怎样？""当魔法能凭空造出食物，战争形态会怎样改变？"
2. **Interconnect（互连）**：把不同的能力、文化、主题绑在一起，而不是各自孤立。
3. **Streamline（精简）**：问"哪里可以合并？"——与其造十个新宗教，不如写一个既有宗教的分裂；与其造十个新法术体系，不如设定**一种这个世界特有的魔法行为**，让每个文化以不同方式使用它。

作者同时提出**"worldbuilder's disease"（世界观建造者疾病）**：花数年打磨设定、却很少练习写作本身，"你不是在学弹一首曲子，你是在聚会里表演"。

### 对本书的三条直接推论
1. **本书的"克苏鲁"部分应当是 hard magic**：读者必须能理解规则，才能享受恐惧。《神秘复苏》《诡舍》《十日终焉》都做到了这一点——读者能背出鬼的杀人规律。
2. **"不可名状"与"硬魔法"存在张力，必须解决**。这是本书的核心技术难题（详见 C5.3）。
3. **严格遵守第一法则 = 先解释，后惊讶**。本书不应在第一卷用大段旁白讲设定；应在读者已经因为"某条规矩救命/死人"而好奇时，再揭示它背后的原理。

## C3. "设定即负担"的批评

### C3.1 设定反噬的三个预警信号（C7，可直接用作自检表）

> 如果你发现自己出现以下三个信号，说明设定已经开始反噬：
> 1. **更新变慢了**——你每写一章都要花大量时间查自己之前写的设定，怕前后矛盾。说明你的设定已复杂到自己都记不住了——读者怎么可能跟得上？
> 2. **读者开始懵了**——评论区出现"这个势力是干嘛的？""这段看不懂"——不是读者理解力差，是你在一章里塞了太多新信息。
> 3. **剧情在给设定让路**——有些章节存在的唯一理由，是解释某个设定的来龙去脉。角色没有新的冲突，情节没有推进，整章都在"介绍背景"。

**处方**："砍掉'想展示'的冲动。你的设定文档可能有十万字，但正文不是设定文档。问自己一个问题：**'如果删掉这段设定介绍，剧情还能不能继续？'答案是能，就删。**"
**节奏原则**：**"一章一设定"——每一章最多引入一个新的世界观信息点。**

### C3.2 设定臃肿的三种典型症状（C9）
1. **大段旁白式世界观铺垫**（开篇几千字疯狂介绍大陆历史、势力分布、修炼规则）
2. **尴尬的解释性对话**（让本该熟知世界规则的本地人互相一本正经讲基础设定）
3. **设定压过人物与剧情**（读者记住复杂的力量等级与势力规则，却记不住主角性格与剧情进展）

**四条减法原则（C9）**：
- 所有设定只为剧情服务（唯一标准：是否推动当前剧情、塑造人物、制造冲突）
- **优先展示，拒绝直白解释**（对比示例：❌"修炼者通过吸收天地灵气提升修为" / ✅"他盘膝落座，丝丝清凉灵气顺着毛孔钻入体内……"）
- **渐进式披露，留白吊足好奇**
- **区分"作者设定"和"读者内容"**："你自己整理的完整世界观、势力关系、战力细则、背景故事，是给自己看的备案文档……**其中至少 80% 的内容，不需要出现在正文。**"

### C3.3 更根本的一条（C8）
> "**世界观设定不是百科全书，而是服务于剧情的底层规则。**"
> "世界观的第一个坑叫设定堆砌……第二个坑叫**设定打架**。前面白纸黑字写了这个世界不能用热武器，写到后面主角突然掏枪扫射……**读者一旦发现规则可以被作者随手打破，信任感直接归零**，追读率跟着崩。"
> "读者追一本书，跟搬进你造的世界住差不多，默认你这个'造物主'说话算数。"

### C3.4 与本书高度相关的具体先例（见 B3.1）
**《捞尸人》的中后期转向**是"设定/民俗膨胀导致品类漂移"的完整案例：书单评语明确指出"逐渐转向术法斗法、闯关打怪，灵异悬疑的氛围感下降""部分副本桥段套路化""庞大主线能否平稳收尾存在不确定性"。**这是本书可以直接规避的坑。**

## C4. 长篇网文设定集/设定圣经的管理实践

### C4.1 通行的问题定义（C10）
> "**吃书**是网文圈用语，指作品设定前后矛盾、作者忘了或改了自己先前写的设定。"
> "长篇会吃书是必然——设定会变、会交叉、会跟正文脱节，任何十万字以上的作品都会走到那个门槛。"

### C4.2 三条治本原则（C10）
1. **以正文为准，让设定库追得上正文**（而非反过来）。改正文里的设定后立刻同步到设定库；不要让设定库"漂移"。
2. **给会变和会交叉的设定留对的位置**：
   - 记录**变更时点**（不是只记现值），这样能回得去任何一版
   - 设置**关联网络**，顺着关联查整张图，而不是一条条分开找
3. **把查阅摩擦压到最低**：设定库要放在写作界面旁边、随手可调出；否则"同步全靠记得"这一环迟早偷懒，漂移必然回来。

**三个常见误区**：
- 设定集建好就不动——不同步一定漂移（设定集是**活文件**）
- 想重读全书逐字校对——不现实，以正文为准，只抓接下来会用到的冲突点
- 把脑补跟正文设定混在一起——没写进正文的背景脑补单独丢一份废案笔记，**别淹没在每天要信的设定库里**

### C4.3 最实用的一招：**铁律表**（C11）
一位作者自述的做法，恰好精准命中本书需求：
> "我排过一份'世界观设定集'，Word 档，洋洋洒洒：魔法体系、地理、种族、政治。写得时候很有成就感，像在盖一本百科。**问题是它太大了。三十页的设定集，跟'我此刻正在写的这句话会不会违规'之间，隔着三十页。没有人会为了写一句对话，回去翻三十页百科确认。于是设定集变成一个写一次、再也不打开的档。**"
>
> **有效做法**：不管设定集多大，把其中**"破了世界就崩"的那几条单独拉出来**，放进设定表的"规则"栏，立成一张**一眼扫得完的短表**。一条规则一句话：
> - "死者不能复活。"
> - "魔法每施一次，折一年寿。"
> - "神不能直接干预人间。"
>
> 旁边标一句代价或例外：有没有唯一的破例条件？破了会怎样？
>
> "它管的是'铁律'，不是'资料'。国王叫什么、首都在哪，那是查得到就好的设定；**铁律是你每写一场关键戏都要瞄一眼的承重墙。**"

**配套自检习惯**（C11）：
> "每次你写得特别爽——主角突然变超强、死人突然回回来、某个限制突然消失——**停一秒。爽，往往是因为你正在偷偷松掉一条规则来换爽。**"

### C4.4 目录结构范式（C9 / 常见做法）
```
项目/
├── 01_世界观设定/  （地理 / 力量体系 / 势力 / 历史年表）
├── 02_人物档案/    （主角 / 主要角色 / 配角列表）
├── 03_剧情大纲/    （总大纲 / 分卷大纲 / 伏笔清单）
├── 04_章节内容/
├── 05_风格指南/    （风格手册 / prompt 模板库）
└── 06_数据记录/    （每日数据 / 读者反馈）
```
同类型文档统一模板、统一排版，"阅读清晰、修改便捷、**AI识别更精准**"。

### C4.5 伏笔管理（可直接借用的实践）
- **伏笔要入库，不要靠记性**（C10）：每条线索连同"埋在哪、指向什么"一起记录
- **人物卡 + 关系图谱**：动笔前翻一遍人物卡，判断"他此刻会不会这么做"；把主要角色拖进一张关系图，看谁跟谁有仇、哪条线是单箭头——写不下去时十有八九卡在关系上（C10）
- **形象按参考锁定**：出场前核对一次参考立绘，避免"前三章琥珀色眼睛、第八章变成灰色"这类自己看不见、读者看得见的穿帮

## C5. 给本书的操作性建议

### C5.1 境界体系：本书该在哪里下手

**三个可选切口（按差异化强度排序）：**

| 切口 | 做法 | 依据 | 风险 |
|---|---|---|---|
| **① 境界与"民俗/禁忌"绑定（推荐）** | 境界不是灵力刻度，而是**能承担多少禁忌反噬**的刻度。练气者能担的禁忌少，所以禁忌多；化神者能担得多，但每担一次就不可逆地"不是人了"。**境界越高越接近"不可名状"** | 《不可名状的道尊》已被读者接受并公认其核心创意是"境界越高异化程度越高"；《道祖是克苏鲁》把"道"设为污染源。本书若也走此路，需在**机制层面差异化**（不是污染"道"，而是污染"人间性"） | 中。已被两本书做过，需要找到第三种说法 |
| **② 借用《玄鉴仙族》的"果位制"思路** | 境界不只是高低，还是**稀缺且排他的名额**。谁能占某个位格由某种社会机制决定（神职/香火/册封/天庭编制），因此"突破"变成政治行为而非技术行为 | 《玄鉴仙族》证明可行且爆款；洪荒文学分析指出其"果位是资源的设定，使得世界天然存在冲突和矛盾" | 中高。会让本书偏"家族/势力流"，与"民俗恐怖"定位有拉扯 |
| **③ 干脆重命名、改顺序，做"非主流阶梯"** | 例如把"元婴"放到"金丹"之前（紫府在前）；或把"仙"放在最底（凡人即仙）。**《仙逆》《玄鉴仙族》都证明读者能接受** | 《玄鉴仙族》用紫府在金丹之前，照样均订 10w+ | **高**。这是本书明确要避开的：本书定位是"仙侠×克苏鲁×民俗"，若体系太怪，读者入戏成本高，与"克系恐怖"需要的认知负担叠加 |

**本书的具体建议（综合）**：
- **保留主流阶梯的骨架**（练气/筑基/金丹/元婴/化神…），因为读者的认知成本已经付过了，把预算花在"机制"上而不是"名字"上；
- **改变阶梯的"读数"**：每个境界对应**能做什么**与**会变成什么**，而不是单纯战力；
- **"克苏鲁"必须写进升级的代价里**，而不是作为背景板。**这是本书最核心的技术承诺**；
- **命名策略**：用有典据的尊称（真人/真君/道君）作位阶称谓，避免通篇"大能/老怪物"，以拉开质感差距（见 A4）。

### C5.2 让"民俗"不是符号堆砌：六条可执行做法

| # | 做法 | 具体操作 | 依据 |
|---|---|---|---|
| **1** | **行当即入口** | 选 1–2 个具体手艺作为世界观入口（捞尸/纸扎/赶尸/阴阳先生/出马/殓葬），把该行当的**真实规矩**写进设定（如"捞尸三不捞"、朱砂点七窍、朱砂镇"老屋场"、苗医草药熏蒸防腐） | 《捞尸人》《鬼吹灯》《第七铺》共同验证；赶尸的考据结论（"职业真实而非技术真实"）来自陆群《湘西赶尸》 |
| **2** | **每个民俗符号必须绑定一个人际冲突** | 一条规矩 = 一次交易、一次拒绝、一次背叛、一次失去。禁止"为了吓人"而出现的符号 | 人民网锐评"只取恐怖之形、抽空精神内核"；李奉三"民俗学知识的堆砌和内卷" |
| **3** | **恐怖要有正向底色** | 民俗的内核是"慎终追远、驱邪向善、祈福安民""劝善惩恶的朴素道德教化"。让至少一部分"怪异"其实是**护佑性的**——它之所以可怕，是因为它在一板一眼地履行一项职责 | 人民网锐评原文；《捞尸人》"人知鬼恐怖，鬼晓人心毒" |
| **4** | **恐惧刻入人心，不刻入符号** | 每个恐怖单元的真相应落在**人间悲剧**（贪欲、背叛、隐瞒、时代的恶）上，鬼怪是结果的承载者 | 《捞尸人》《诡舍》祈雨村单元；《鬼吹灯》主题定位在人心；《__校》"并不堆砌灵异元素，而将恐惧刻入人的内心" |
| **5** | **把"宏观世界观"压缩，把"微观生活"放大** | folk horror 的核心是"最熟悉的恐怖"；同时有评论者指出"宏大的世界观创造出的隔离于现实生活的闭锁空间……这恰恰是日式恐怖的特点"，会消解中式特色。**本书应让规则贴近读者的日常生活经验** | Cagey Films / StudioBinder 的 folk horror 定义；李奉三对"世界观膨胀"的批评 |
| **6** | **不写可复刻的仪式步骤** | 只写规则的**约束与后果**，不写操作步骤。这既是文学原则也是合规要求 | 番茄/七猫官方规则；三条平台红线中"可复刻的迷信内容"被点名 |

### C5.3 本书必须正面解决的技术难题：**"不可名状"与"硬魔法"的张力**

这是本书设计上最难的一处矛盾，必须提前决策：

- **克苏鲁神话的精髓**（B1.3）是"不可名状"——存在无法被语言与认知把握；
- **Sanderson 第一法则**（C2）要求读者**理解**魔法才能享受解谜；
- **folk horror 的类型定义**（B5.1）反而要求"信念本身就是引擎"，即规则必须**可被人相信并遵守**。

**可行的三种解法（供选）**：

| 解法 | 说明 | 代价 |
|---|---|---|
| **A. 分层不可名状** | 底层规则**极其清晰可推**（读者能破局），但规则的**来源与本体**不可名状。读者能破解"怎么活"，但永远不知道"那是什么"。这正是《神秘复苏》《诡舍》做的事 | 需要极强的规则设计能力 |
| **B. 视角不可名状** | 规则清晰，但**观察者视角会崩溃**。修士的认知、记忆、五感在修行中被逐步改写，所以"越强的人越描述不清" | 需要强叙事控制 |
| **C. 代价不可名状** | 每次调用超自然力量都要支付代价，而**代价的语义永远不被解释**。规则可学，代价不可解释 | 需要设定留白纪律 |

> **建议**：C 与 A 的组合，即"**规则可推、代价不可解**"。这既保住克系内核（不可名状不是无知，而是有知而不可承受），又保住网文可读性（读者有解题快感）。

### C5.4 三层信息分配表（本书自用模板）

| 层 | 内容 | 放在哪 | 读者能知道多少 |
|---|---|---|---|
| **表层** | 人物、手艺、场所、器物、当下的麻烦 | 正文 | 全部 |
| **中层（规则层）** | 力量来源、代价、禁忌、什么绝对不能做 | 作者设定（铁律表）+ 正文逐步展示 | 通过事件展示，不通过旁白宣讲 |
| **深层（源流层）** | 为何如此的历史、民俗的由来、"不可名状"是什么 | 作者设定 | **永远不完整**，且是全书最终谜底 |

**配套的"冰山"指标**：作者设定总量 ≈ 写进正文内容的 **5–10 倍**（C12）。

**披露节奏**（C14 的三法，可直接沿用）：
1. **跟主角认知走**——韩立刚入七玄门时，读者也以为江湖武功最强。设定随主角认知升级而升级（《凡人修仙传》未开篇介绍修仙体系）
2. **用冲突带出设定**——通过一个人的傲慢与一个人的屈辱，读者就理解了等级观念，无需作者说"弱肉强食"（《斗破苍穹》退婚桥段）
3. **留白创造想象**——《诡秘之主》先告诉你 9 到 1，再慢慢透露 0、真神、旧日；更妙的是没说的：为什么有序列？谁创造的？

# 本书差异化定位建议（基于以上调研）

> 每条均附**依据**，依据来自上文已核实的来源。凡涉及具体作品的地方，均为已核实项。

## 差异点 1：把"境界"重定义为**承载禁忌的额度**，并让"不可名状程度"成为境界的主坐标

**主张**：本书不设"战力刻度"式的境界，而设"**人性能被抵押掉多少**"的刻度。每突破一境，修士能调用的禁忌更多、覆盖的范围更广，但作为"人"的属性逐项失效——记忆、语言、面孔、亲缘、姓名，直到某一级他连"自己能被指认"这件事都做不到。

**依据**：
- 《不可名状的道尊》的核心已被读者接受为"**境界越高，自身异化程度越高**"，且被起点专栏评为"克系修仙"代表作之一（B3）。
- 《道祖是克苏鲁》把"道"本身设为污染源，突破境界即"裂开头颅、撕裂肋骨、化出肉翅"（B4）。
- 本书要做的**差异化**是把"异化"从"恐怖的形象变化"改写为"**民俗意义上的失格**"——失的是**作为人的社会资格**（不能被供、不能被叫名字、不能进祠堂、不能主持丧事、不能被超度），而不是外形。这既接住了洛夫克拉夫特"宇宙对人类残酷而陌生"、人类渺小的底色（B1.3），又接住了民俗学里"人与鬼之间的边界由仪式资格划定"的真实质感（C5.2-3）。
- 同时避开了《捞尸人》"中后期转向术法斗法"的品类漂移风险（B3.1 评语）。

## 差异点 2：让"民俗"承担**世界观合法性**，而不承担**恐怖素材库**

**主张**：本书中的民俗不是恐怖素材，而是**世界观的立法程序**。这个世界之所以是"华夏"，不是因为有纸人和赶尸，而是因为**万物都必须经过一套仪式才被承认存在**——不被仪式承认的东西，就是不可名状的东西。民俗禁忌因此是"世界的语法"，克苏鲁则是"语法失效处"。

**依据**：
- 人民网锐评的核心批评正是"**只取恐怖之形、抽空精神内核**""将厚重的乡土文化简化为吓人工具"（B6.1）；行业评论进一步指出"民俗学知识的堆砌和内卷"（B6.2）。
- folk horror 的类型定义本身就要求"**威胁来自共同体持有的信念**"，而非符号（B5.1）——这与"民俗是语法、怪物是语法失效"是同构的。
- 上田秋成《雨月物语》与《剪灯新话》的关系，提供了"外来素材本土化"的成功范式：**不是照搬，而是"以本地社会为背景重新结构情节"**（B5.3）。
- 中国学者对乌克兰诗意电影的批评（"民俗母题缺乏必要深度，只是背景而非情节的独立元素"，B5.3）是本书必须避开的失败模式的学术表述。

## 差异点 3：用**"具体手艺"而非"境界阶梯"作为读者的入场券

**主张**：本书的第一卷不以"介绍境界体系"开场，而以"一个具体手艺人的一天"开场——让读者先学会一门手艺的规矩，再发现这门手艺的规矩在这个世界里不够用了。

**依据**：
- 《捞尸人》《鬼吹灯》《第七铺》《傩面，纸嫁衣》均以具体行当（捞尸人/摸金四大流派/纸扎铺/纸扎匠）进入世界观（B3.1）。
- 这些作品的共同成功机制：**行当规矩本身就是完整的规则系统**，读者无需先背境界表。
- 同时这也是"克系恐怖"最经济的入口：规矩被破坏的那一刻，就是不可名状介入的那一刻。
- 反面教材是《捞尸人》中后期"转向术法斗法"（B3.1）——**入场券必须一直留在读者手里**，不能在中途换成战力刻度。

## 差异点 4：把"民俗禁忌"做成**可验证的规则系统**，正面硬魔法化

**主张**：本书的禁忌必须满足三项——**可学（读者能总结）、可破（读者能推理）、有代价（破了要付账）**。每条禁忌给出一个"触发条件 / 后果 / 例外"的三段式。

**依据**：
- Sanderson 第一法则："作者用魔法解决冲突的能力，与读者对该魔法的理解程度成正比"（C2）。
- 《神秘复苏》的鬼有"固定的杀人规律"、《诡舍》每个副本有"规则"、《十日终焉》每个游戏有"规则"——**读者能背出规则**是这三本书共同的成功点（B3.1）。
- 民俗学界对湘西赶尸的结论（**"赶尸不在于技术的真实，而在于职业的真实"**，陆群）是本书"民俗规矩可总结、但民俗 supernatural 不可解释"的最有力范式（B4）。
- 合规上这同时满足"不写可复刻的仪式步骤、只写约束与后果"（B6.2-3）。

## 差异点 5：以**"不可名状 = 有知而不可承受"**定位本书的克系内核，并与"宇宙冷漠"而非"善恶二元"对齐

**主张**：本书采用**洛夫克拉夫特原典**的立场，而非德雷斯系统化后的立场——不可名状者**不邪恶、不关注人类、也未被人类触怒**；恐怖来自尺度落差与认知成本，不来自复仇或诅咒。本书的"神"不做善恶二分，因此中国式"驱邪向善、祈福安民"的民俗底色可以**自然共存**：在本书里，驱邪不是因为它坏，而是因为**它不在乎你**。

**依据**：
- GQ 的分析明确：洛夫克拉夫特是**无神论者、机械唯物论立场**，宇宙没有目的也没有道德预设，**恐怖来自尺度落差而非报复或诅咒**；"古神 vs 旧日支配者"是**德雷斯的二次建构**，且与洛氏原意"存在明显张力"（B1.2）。
- 绝大多数中文克系网文采用德雷斯之后的善恶二元体系——**知道这一层差异本身就是设定深度的信号**。
- 人民网锐评强调民俗的内核是"驱邪向善、祈福安民""劝善惩恶"（B6.1）。把"驱邪"的动机从"善"改成"不在乎"，**既保留了中国民俗的行为逻辑，又保留了克苏鲁的宇宙恐怖底色**——这是本书能同时满足两套读者的关键设计。
- 权威性支持：人民网锐评把"**深耕民俗史料与地方文史，挖掘传说背后的时代背景、民众生存状态与人文情感**"列为出路（B6.1），这为差异点 2 提供了官方背书。

## 差异点 6（附加）：以**"吃书"的反面**——设定集的可维护性——作为作者的工艺承诺

**主张**：本书的设定集以"**铁律表 + 三层信息分配 + 伏笔入库 + 废案隔离**"四件套维护，作者承诺：**每一卷交稿时，铁律表不得被悄悄修改**；若必须修改，必须在正文里显式给出"世界规则发生了改变"的事件。

**依据**：
- C4.2–4.4 的全部实践（以正文为准的同步机制、变更时点记录、伏笔入库、废案隔离、目录模板）。
- C4.3 的"铁律表"方法，直接来自一位作者对自己"三十页设定集"失败的复盘。
- C3.1 的三个预警信号（更新变慢/读者懵/剧情给设定让路）可作为本书每卷的自检项。
- C3.3 的"设定打架→读者信任感归零"是长篇崩盘最常见的机制。
- 《玄鉴仙族》的成功经验（洪荒文学分析）：**新体系必须与内容绑定**，且不能拖慢入戏速度——设定集的可维护性正是"与内容绑定"的技术前提。
