## 一、主角 · 赵海

| 字段 | 内容 |
|---|---|
| 职能 | 破庙中的**架庙人**；表象身份：本该在红白事上唱神调、跳傩戏的年轻弟马，游走十三诡境为人驱邪做法事糊口 |
| 一句话 | 他能修好所有人的庙，唯独看不见自己的 |
| **欲望（想要什么）** | 重塑体内那尊无头神像之首——不是想变强，是想知道**自己原来叫什么** |
| **恐惧（最怕什么）** | 被人叫出全名（R5 定位／R3 销名）。具体感受：颈上那道穿堂风忽然停了 |
| **误信（他的错）** | 他以为只要把别人的庙修得够多，总会有人愿意替他看一眼。真相是：替他看的那一眼，就是把他交出去的那一眼 |
| 核心天赋 | 架庙眼（R15 / P-01）：目视活人胸腹三息，见其四梁八柱虚实裂痕 |
| 特殊体质 | 体内小庙：**无窗无柱**（与天道隔绝）、**四梁纵横状若牢笼**（本源被外力扭曲封锁）、**香案倾倒**（与内外神明供奉关系断绝）、**无头陶土神像**（本我之神被斩首），颈上黑洞非虚空 |
| 人间性余额 | **开场 4/6**（先天已失记忆、亲缘），不可回退 |
| **代价与副作用** | 每看一次掉一瞬记忆；每次架庙按 R16 掉一样东西且不可挑；远期熟人一个个叫不出名字，最后没人能替他点主 |
| **失效条件** | 对象是死人／自己／R2 状态者看不见；对方遮胸腹或不出声应允修不了；上梁中断则 30 日全失效且已付代价不退 |
| 暴露风险 | R18：洞每吞一次攻击就记住一个来源，残神不必找他，只要**不断派东西来打** |
| 与世界规则的冲突 | 替人重立登记在本世界是**越权**（§3.3），他天生是玉虚宫要销名的对象 |
| 弧光起跳点 | 他一开场就**付不起**了。要修自己须破 T-01／T-02／T-06 三条禁；破禁即失去自己 |
| 三条成长路径（原稿保留） | ① **重构神躯**：重塑神像之首，继承斩首前底蕴；② **化身容器**：无人引导则洞吞尽自我，成残神重生的完美容器；③ **自成无首之神**：走极端战狂／涅槃路，以乳为目、以脐为口，类刑天，开心武之新道 |
| 首次登场 | 第 1 章，沅陵走脚铺；**不点破**无头神像，只写他颈上怕风 |

### 1.1 意象（修辞，不进 R 表）

原稿称他"活着的文明墓碑""行走的上古禁忌"。〔构〕保留作意象栏，见 `world-bible.md` §2.6 U-04。**不可观测，不得当设定用**。

### 1.2 首章可用的三个具体细节（不解释设定）

1. 他替人看庙时，会先请对方把衣襟解开三寸，然后**自己先眨眼**——因为看满三息要掉一瞬记忆，他习惯把那一下眨在前面。
2. 他收工钱从不数，只把铜钱压在香炉底下（〔考〕香头旧俗），转身时衣领往上拢一下。
3. 有人喊他全名，他答应得比谁都快——**因为他怕慢一拍，对方会再喊一遍**。

## 二、无首神骸（F-06）

| 字段 | 内容 |
|---|---|
| 职能 | 主角最关键的伙伴／镜像；体内同样残破、如野兽般跟随他 |
| 一句话 | 它是那场斩首落下的**另一块残件**，不是宠物、不是外挂、不是前世 |
| **欲望** | 无（FL-06：无动机）。它只有**趋向**：朝赵海颈上的洞靠 |
| **恐惧** | 无 |
| 能力 | R18 / P-10：赵海濒死时被动吞一次外来攻击；洞"记住"来源，该来源此后可绕过 R5 定位赵海 |
| **代价** | 它吞得越多，赵海越可被定位——**它护他的方式，正是把他交出去的方式** |
| **反制** | 唯一的反制是**不攻击它**。这使所有反派陷入两难：打，就暴露；不打，就杀不死 |
| 失效 | 赵海未濒死时不触发；不可主动关闭 |
| 首次揭示 | 第一卷末落洞崖：洞第一次主动吞噬，发出无声咆哮，**所有残神旧仙战栗**——"那个本该彻底寂灭的古神，醒了" |
| 与主角关系 | 跟随 → 互为镜像 → 终局二选一（重塑其首／合一成无首之神） |
| 依据 | 原稿 §十末段；〔构〕R18 规则化 |

> ⚠️ 一致性提醒：FL-06 要求超自然存在无动机，**"它保护赵海"不能写成情义**。正文只写现象："攻击没了，赵海还站着"，不写"它替他挡了一下"。

## 三、五位伙伴（心武五宗）

> 原稿只给职能，本轮不命名。每人补上**欲望／恐惧／代价／弧光／与主角关系的动态词**，避免"五个工具人"。
> 模板要求"与主角关系用动态词，别写死敌"：本项目统一采用三段式 `雇主／利用 → 怀疑 → 收编或反噬`。

### 3.1 神明武者（可靠的盾）

| 项 | 内容 |
|---|---|
| 路线 | 存思五脏神（P-03）；〔典〕《黄庭内景经》心神章第八 |
| 欲望 | 想把师父那套身神名讳**抄全**——他手里的本子缺了两页 |
| 恐惧 | 有一天存思时，叫出的神名不是自己师门的 |
| 代价 | 每存一次，一种情绪变淡一分（不可逆）；终局他将**完全不会怕**，这既是盾也是失去 |
| 反制 | 玉虚宫以内丹法门破存思，令其神名错乱 |
| 与主角 | 受雇护送 → 怀疑赵海替人架庙是越权 → 第三卷替他看了一眼自己的庙（触发 R5） |
| 弧光 | 从"想把本子抄全"到"承认有两页本来就该空着" |

### 3.2 战狂武者（最利的矛）

| 项 | 内容 |
|---|---|
| 路线 | 解放心猿意马、炼为战斗狂神 |
| 欲望 | 想打一次不必收力的架 |
| 恐惧 | 收力之后发现自己已经不想停 |
| 代价 | 不可逆地失去一种情绪（第 4 档） |
| 反制 | 面具／堂单被收走即失势；**最易沦为残神容器（R13）** |
| 与主角 | 同行 → 理念相左 → **部分堕落**，成为中期反派（原稿"堕落的战狂武者"） |
| 弧光 | 从"想不收力"到"最后一次主动收了力"，或彻底不收 |

### 3.3 弈心者（团队大脑）

| 项 | 内容 |
|---|---|
| 路线 | 〔典〕《阴符经》"观天之道，执天之行"；推三步因果 |
| 欲望 | 想把 H-07 无首之夜那盘棋**复盘出来** |
| 恐惧 | 复盘到最后，发现自己也在棋盘上，且是被人摆上去的 |
| 代价 | 推算一次，自己的一段未来被写死 |
| 反制 | 承负律：算得越准，三代内的账越厚（反制来自法律体系） |
| 与主角 | 利用赵海当变量 → 怀疑变量不受控 → **棋手入魔**，成为后期反派（原稿"玩弄众生命运的弈心者"） |
| 弧光 | 从"想复盘"到"承认有的棋没有下过" |

### 3.4 战境师（规则辅助）

| 项 | 内容 |
|---|---|
| 路线 | P-09 规则领域，心至虚 |
| 欲望 | 想造一片**不会少东西**的地方（对应 R25 减损） |
| 恐惧 | 领域撤销后，被改过的规则不还原——他怕自己造的每一片地方都在悄悄欠账 |
| 代价 | 第 4 档最重：世界永久少一条规矩 |
| 反制 | 只要有人能背诵该领域的原规则，领域即塌（反制是"记性"） |
| 与主角 | 受雇 → 信任 → 第三卷为救人开了一片领域，**从此全书少一条规则**，转入长线负罪 |
| 弧光 | 从"想造完整的地方"到"愿意替别人记住原规则" |

### 3.5 涅槃行者（生命导师）

| 项 | 内容 |
|---|---|
| 路线 | 假死／破而后立；入门条件是"死过一次且**未被判定为死**"（FL-03 例外） |
| 欲望 | 想知道自己那次到底算不算死了 |
| 恐惧 | 假死太久，回来时无人认领 → 直接 R2（无籍） |
| 代价 | 每次假死掉一项人间性且不可选 |
| 反制 | 殃榜一贴，就再没人能替他证明"没死" |
| 与主角 | 师友 → 替赵海指出"你和我是同一类"→ 第四卷**自愿替他看一眼**（R5 触发点） |
| 弧光 | 从"想被判定"到"愿意不被判定" |

> **五人结构校验**：五条路线各有独立的代价与反制，且**至少两条通向反派**（战狂、弈心），符合模板"反派梯队自动长出来"。✅

## 四、反派与秩序侧

### 4.1 玉虚宫掌籍执事（理念型对手，非恶人）

| 项 | 内容 |
|---|---|
| 职能 | F-01 的中层，负责籍库与销名；**是"认同这套秩序的人"**（§3.4 必答题） |
| 他认同的理由 | "没有簿子，去年那场减损里连谁没了都不知道。"——**秩序确实在保护人**，这才是它难推翻的地方 |
| 欲望 | 把三套互不承认的登记法统一成一部 |
| 恐惧 | 自己署不了名（§8.2 社会后果：高阶法师必须借低阶弟子的籍办事） |
| 代价 | 每销一个名，自己家族的一段往事被记到别人账上 |
| 与主角 | 漠视 → 怀疑 → 围剿 → **第四卷不得不请赵海替宫里点一次主** |
| 弧光 | 从"统一簿子"到"亲手烧掉自己那本" |

> ⚠️ 一致性：他不邪恶、不公报私仇（FL-06 只约束超自然存在，但本世界的人也不该写成脸谱反派）。他的残酷来自**流程**。

### 4.2 堕落的战狂武者 / 棋手入魔

见 §3.2、§3.3。二者都是"内部道路的清洗与正名之战"（原稿 §十一），不是外部妖魔。

### 4.3 当年斩去神像之首的上古势力

| 项 | 内容 |
|---|---|
| 状态 | **仍在世，且名字已从所有登记簿上消失**（R3）→ R2 状态 |
| 动机 | 按 FL-06 不得写成"因为忌惮所以加害"。改为：那是 H-02 未竟仪式中的一道**程序**，执行者只是在履职 |
| 与主角 | 主角追查的对象；真相是"查到他的名字"这件事本身就是把他重新登记 |
| 首次揭示 | 第三卷籍库；终局才知"执行者不止一个" |

### 4.4 残神旧仙（F-03）

按 FL-06 / R4：**无动机、无善恶、不可直接动手**。它们的全部行为只有三种：凝视、诱导、借替。不得写"震怒""报复""觊觎"之类人格动词（原稿"各怀鬼胎""觊觎人间容器"已按此校正，见勘误台账）。
