## 为什么单独成文件

长篇设定集最常见的崩盘方式，是三十页设定里悄悄改了最根本的那一条，而没有任何记录。铁律表把"不能动的东西"压缩到一页，每卷交稿前逐条对照一次。它与 `world-bible.md` §2 的关系是：

- **铁律**＝世界观的宪法，管"哪些事永远不可能"；
- **R 规则**＝可执行法条，管"具体触发什么、结果是什么"；
- R 规则可以增补、可以作废（保留编号），但**不得与铁律冲突**；冲突时以铁律为准并登记。

## 八条铁律

### FL-01 · 描述即被注意

> **不可名状之物不可被完整描述；任何角色试图完整指称它，即被它注意。**

| 项 | 内容 |
|---|---|
| 可判定形式 | 主体：任何有名字的角色／条件：说或写出某一存在的完整名号、形貌、来历，三项齐备／结果：该存在即刻获得对此人的"定位"，此后此人无法凭躲藏、改名、易容摆脱 |
| 例外 | 只描述**一项**（只说形貌、或只说它做过什么）不触发；仪式性称名（傩坛请神、点主书讳）在坛内不触发，出坛即触发 |
| 违反后果 | 不是立刻死亡，而是"被登记"。后果在后续章节以**关系损失**形式结算（见 `world-bible.md` §9.2 代价表） |
| 写作落地 | 正文永远用感官细节替代名词：不写"它是什么"，只写"灯焰转绿""羊臊气先到""香灰朝内倒卷" |
| 依据 | 〔构〕本书核心机制；参考洛氏原典"不可名状"与资料包 C5.3 解法 A「分层不可名状」 |

### FL-02 · 规则可推，代价不可解

> **超自然力量每一次调用都必须付代价；代价的现象可写，代价的语义永不解释。**

| 项 | 内容 |
|---|---|
| 可判定形式 | 主体：任何调用 R 规则中 P 类能力者／条件：完成一次调用／结果：立即发生一项**可观测、不可撤销**的损失，且全书不给出该损失的"为什么" |
| 例外 | 无。没有任何一次调用是免费的，包括主角、包括救命、包括反派 |
| 违反后果 | 若某次调用未付代价，视为该能力**根本没有生效**（不是白嫖，是无效果） |
| 写作落地 | 只写"他从此认不出三姐的脸"，不写"因为魂魄被取走一缕所以认不出" |
| 依据 | 〔构〕；直接对应资料包 C5.3 建议解法 **C + A 组合**「规则可推、代价不可解」 |
| **下位补强（C-03）** | `FL-02-a`／`FL-02-b` 见 `world-bible.md` §2.7：结算不以见证者为条件；禁止代付／分摊／转移／抵押／预付／延期；R18 攻击者获得定位资格明定为**独立结果**，不是代价。八条铁律正文未改 |

### FL-03 · 没有复活，只有"替"

> **本世界不存在死者复生；一切看似复生的现象，都是别的东西顶了那个位置。**

| 项 | 内容 |
|---|---|
| 可判定形式 | 主体：任何已死者／条件：出现"其人归来"的观感／结果：归来者必是替身、借身、拟形或制度补缺之一，且**必有一处对不上**（气味、影子、忌讳、称谓、旧伤） |
| 例外 | 心武道"涅槃行者"的假死不是复活：他是活人主动走到边界再回来，期间从未被判定为死 |
| 违反后果 | 若写出真正复活，则"天道有缺"这一总纲失效 → 整本书的危机前提崩塌 |
| 依据 | 〔考〕《子不语》卷九《鬼争替身人因得脱》、卷三《打破鬼例》"阴司向例如此……犹之人间补廪补官必待缺出"；〔考〕茅人替身、纸扎、点主、过阴等民俗；资料包 C5.5 铁律候选第 3 条 |

### FL-04 · 仪式即立法

> **万物须经一套仪式才被承认存在；未被仪式承认者，即为不可名状。**

| 项 | 内容 |
|---|---|
| 可判定形式 | 主体：任何存在／条件：是否被本地共同体的仪式登记（名字入堂单、点主入木主、勾愿入愿簿、受箓入箓牒、滩爷铜牌编号）／结果：已登记者受本世界规则保护与约束；未登记者不受规则约束，也**不受规则保护** |
| 例外 | 残神旧仙曾受上古之礼，属"已登记但登记簿已毁"，故处于夹缝：既不放逐也不受护 |
| 违反后果 | 未登记者不能被点主、不能被超度、不能进祠堂——它没死，也没活，只会持续地"在" |
| 依据 | 〔考〕点主、殃榜、堂单马道、受箓品级、滩爷铜牌可世袭转卖；〔构〕把它上升为世界本体论。**本书"华夏"二字的定义所在**：不是因为有纸人和赶尸，而是因为万物要过手续 |

### FL-05 · 境界是额度，不是战力

> **境界刻度量的不是有多强，而是还能承担多少禁忌反噬、还剩多少"人间性"。**

| 项 | 内容 |
|---|---|
| 可判定形式 | 主体：任何修士／条件：跨过一境／结果：可调用的禁忌条目数 +1～2，**同时永久失去一项人间性**（姓名／面孔／言语／记忆／亲缘／归属，六项按境递进），且不可回退 |
| 例外 | 无。散圣·混元之境是六项尽失，不是"强到极处"，是"再也不是人" |
| 违反后果 | 若写成"境界越高战力越高、其余不变"，则本书与主流升级流无差别，克系内核归零 |
| 依据 | 〔构〕；资料包 C5.1 切口①与差异点 1（并与《不可名状的道尊》"境界越高异化越高"作机制差异化：**失的是社会资格，不是外形**） |

### FL-06 · 仙不仁，也不撒谎

> **超自然存在不邪恶、不关注人类、也未被人类触怒；它只是按一套人看不懂的流程办事。**

| 项 | 内容 |
|---|---|
| 可判定形式 | 主体：任何残神／仙家／阴司职司／条件：与人类发生交互／结果：其行为**一律可归因于某项流程或编制**，不得出于复仇、嫉妒、戏弄、惩罚等人格动机 |
| 例外 | 已化为人身、或被人間仪式长期供奉而获得人格者，可有人格动机——但它此时已受 FL-04 约束，不再是"它" |
| 违反后果 | 一旦出现"因为主角冒犯了它所以报复"，克系恐怖降级为鬼怪复仇故事 |
| 依据 | 〔考〕洛氏原典立场（资料包 B1.2：无神论、机械唯物、恐怖来自尺度落差而非诅咒；"古神 vs 旧日支配者"是德雷斯二次建构）；〔考〕冥界官僚制度化 |

### FL-07 · 邪神不上身

> **民间巫者可请、可役、可借，但不得以外来野神为"本我之神"入驻自身庙宇。非不能，乃不敢。**

| 项 | 内容 |
|---|---|
| 可判定形式 | 主体：任何已"起柱架庙"者／条件：让未被本共同体登记（FL-04）的存在占据庙宇主位／结果：本我神像被置换，此人的**姓名从所有登记簿上同时消失**（不是被杀，是从未被登记过） |
| 例外 | 傩坛戴面具"搬神"是**临时**上身，仪式结束须送神、倒坛、封洞；未走完送神程序即视同违反 |
| 违反后果 | 成为残神旧仙的容器（见 `world-bible.md` §9 赵海成长路径 B） |
| 依据 | 〔考〕傩仪"送神／封洞／倒坛"结构、"请神容易送神难"（**原稿误作"请仙容易送仙难"，见勘误 E-14**）、出马堂口"旗印剑令"的手续观念；〔构〕把民俗规矩升格为铁律 |

### FL-08 · 入界者必留价

> **界外不可入；凡越界而来者，必在此界留下一样东西，且自己不知道留的是什么。**

| 项 | 内容 |
|---|---|
| 可判定形式 | 主体：任何来自"界外"的存在或物／条件：进入本界／结果：随机失去其一项属性并遗留在本界，成为某件"说不清来历"的器物、地名或俗语；该存在**无法察觉自己少了什么** |
| 例外 | 上古化道的仙佛不是"入界"，他们是本界自身的一部分，不适用 |
| 违反后果 | 若"外道之熵"被写成有意志、有目的、可交涉的入侵者，则与 FL-06 冲突 |
| 依据 | 〔构〕；C-04 已裁定：保留「外道之熵」一词，但降为玉虚宫清傩之议（H-06）的**官方讹称／人为假想敌**（R25-a～d）；R25 仍是无意志的规则漏损，其"留价"正是十三诡境与无首空洞的来历 |

## 八条之间的关系（防互相打架）

```
FL-04 仪式即立法  ──定义──> 什么是"存在"
      │
      ├── FL-01 描述即被注意 ──> 未被登记者如何被"点名"
      ├── FL-03 没有复活只有替 ──> 登记簿如何补缺
      └── FL-07 邪神不上身 ──> 登记簿如何被篡改
      │
FL-06 仙不仁也不撒谎 ──定义──> 它们的动机（无动机）
      │
      └── FL-08 入界者必留价 ──> 它们留下的东西，就是本书全部"怪"
      │
FL-02 规则可推代价不可解 ──定义──> 人调用力量时的账
      │
      └── FL-05 境界是额度 ──> 账能赊到多大
```

**自检**：任意写一段剧情，问三句——
1. 有没有谁没付代价就动了力量？（违 FL-02）
2. 有没有哪个"它"因为生气才害人？（违 FL-06）
3. 有没有人真的死而复生？（违 FL-03）

三句都过，铁律就算守住。
