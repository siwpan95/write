## 〇、一处需要处理的结构问题

原稿标题写「**八荒地理**」，正文却只列 **5 处**：东胜神洲、北俱芦洲、西牛贺洲、中央钧天、南疆瘴地。且前三者借用了《西游记》四大部洲之名（缺南赡部洲），与"华夏"底色有张力。

**本轮处置**（不擅自删改用户资产，登记待裁定）：
- 保留**五洲**格局与全部名称（原稿既定）；
- 在设定内给出解释：H-03 道隐之劫后旧地图散佚，世人只剩五份能互相走通的"洲籍"，**"八荒"是旧称，不是实数**——把数目矛盾写成世界观本身的一处残缺（与 R25「减损」呼应）；
- 《西游记》式洲名在正文中**不作佛典引用**，只作架空地名，避免宗教考据硬伤。
- 【待裁定 C-06】是否改用纯架空洲名（如"辰州、江州、山左、关外、瘴南"）。

## 二、八处关键地点详表（`world-bible.md` §6 L-01～L-08 的展开）

| 编号 | 地点 | 所属 | 进入条件 | 路上有什么危险 | 内部权限 | 首次出场 |
|---|---|---|---|---|---|---|
| **L-01** | 沅陵·走脚铺 | 南疆瘴地 | 无（主舞台） | — | 后院停灵房只有掌事能进；门后苕帚恒在 | 第 1 章 |
| **L-02** | 落洞崖 | 南疆瘴地 | 步行半日，雨后山道不通 | **路上不能回头**（T-05）；纸床纸柜、烧过嫁妆的焦味、奇异香味 | 洞口无门，但"进去"要有人喊名字 | 第 4 章 |
| **L-03** | 辰州傩坛 | 南疆瘴地 | 水路一日半；船上忌"沉"音，姓陈／程者改姓 | 说错忌字＝散排；夜泊须关门拴狗 | 内坛阴戏：只有掌坛师与六师可入；外坛阳戏：人人可看 | 第 9 章 |
| **L-04** | 赣江排帮码头 | 中央钧天／东胜神洲交界 | 顺流三日 | 滩爷铜牌编号对不上，整排不放行 | 铜牌可世袭转卖；无牌者不得上排 | 第二卷 |
| **L-05** | 老爷府（山林） | 北俱芦洲 | 陆路半月 | 喊山没人接 ⇒ 山里少了东西（R25） | 三块石即最小登记处，谁都能拜，谁都不许挪 | 第二卷 |
| **L-06** | 玉虚宫·籍库 | 东胜神洲 | **三道箓牒** | 无牒者可借"送神未竟"的缺口混入，但**出来时须留下一样东西**（R8） | 掌籍执事 → 授箓法师 → 记名弟子；无窗、樟木、长明灯 | 第三卷 |
| **L-07** | 龙尾关·阴阳街 | 西牛贺洲 | 只在 R24 时点可入 | 抬头／回头即被阴司登记（R20） | 无权限概念；这是一支永不散的战场 | 第三卷 |
| **L-08** | 无首神骸沉睡处 | 不在任何洲 | **距离不可丈量** | 无风、无回声、没有影子 | 无 | 第四卷 |

**动线量化校验**
- L-01 → L-02：步行半日（≈ 30 里），雨后不通。
- L-01 → L-03：水路一日半；船行速度按赣江／沅水放排常规，不写死里数以免与章节时间线穿帮。
- L-03 → L-12 中央钧天：顺流转入，约六日；**每过一次州界须重新登记一次**（H-04 的直接后果，是放排／走脚行当最大的成本）。
- L-08：**刻意不可量化**——这是它最恐怖的属性，也是 FL-01「描述即被注意」的地理化。谁要是量出了距离，就等于把它说全了。

> 〔考〕L-02 落洞的民俗底本：沈从文《湘西》、陆群 2006 研究、凌纯声 1933 田野。姑娘美、聪慧、爱洁、未婚、易幻想；被洞神看中后喜独处、渐不进食；家人**不办丧事，办婚礼**，在洞口烧嫁妆，或搭茅屋扎纸床纸柜写生辰八字。〔考〕沈从文原句："死时女子必觉得洞神已派人前来迎接她……间或在肉体上放散一种奇异香味含笑死去"——**落洞的全部恐怖都在这一句里**。本书按 FL-06 处理：洞神无意志、无爱欲，它只是**一个位置缺了一个人**（R22 补缺）。

## 三、势力详表（先写"缺什么"）

### F-01 玉虚宫 · 古典修仙正统

| 项 | 内容 |
|---|---|
| 定位 | 绝对秩序派；理念"天道有常，万物皆有其位" |
| 控制资源 | 受箓权、籍库（L-06）、雷部科仪、〔典〕《天坛玉格》授箓品级（正一～正七品） |
| **缺什么** | **民间接入**——它的簿子管不到不认它的人；越高阶越无籍，连自己的名字都署不了（§8.2 社会后果） |
| 执行手段 | 正统法脉 + 清剿司；**以戒律破术**：〔考〕正一道"神不饮食，师不受钱"可破民间血祭猖（P-05 反制） |
| 三级结构 | 掌籍执事 → 授箓法师 → 记名弟子；**清洗机制＝销名**（R3），不是处死 |
| 晋升 | 加授箓牒，逐品升；每次升授都再失一项人间性 |
| 对外 | 与 F-04 血仇（H-06 清傩之议）；与 F-05 利益交换（要铜牌编号，给度牒）；与 F-03 有一桩没人记得的秘密（H-07） |
| 与主角 | 漠视 → 怀疑 → 围剿 → 第四卷不得不请他点主 |
| 理念色 | 白（秩序），但**白得发灰**——簿子旧了 |

### F-02 心武五宗 · 失传道统的残火

| 项 | 内容 |
|---|---|
| 定位 | 五宗脉各自为政、暗中传承；理念"人人可自建庙宇，自成神明" |
| 控制资源 | 五宗秘法、架庙术、无间禅牢、规则领域 |
| **缺什么** | **合法性**——没有登记权，修得再好也是"无籍" |
| 执行 | 五脉各一（见 `人物卡.md` §三） |
| 三级 | 宗主 → 传度师 → 递补弟子；晋升靠〔考〕**抛牌奏职**出师大典（迎接法官→盘道斗法→祭旗游街→发猖破庙→辞别六亲→道台授教→捉鬼入牌→抛牌过法；末日九皈十戒） |
| 与主角 | 收编 → 利用 → 分道；其中两脉走向反派 |
| 理念色 | 赤（自建），但**赤里带黑**——"自成神明"与 FL-07 只隔一步 |

### F-03 残神旧仙 · 上古苟活者

| 项 | 内容 |
|---|---|
| 定位 | H-03 后沦为规则漏洞者；**不是反派组织，是一种状态** |
| 控制资源 | 对规则漏洞的知识、凝视 |
| **缺什么** | **容器**（R13）——自己无法再被登记，必须借人身 |
| 执行 | 按 R4 **不可直接动手**；只有凝视、诱导、借替三种行为 |
| 结构 | 无（彼此不通消息） |
| 与主角 | 凝视 → 诱导 → 争夺容器 |
| 理念 | **无**（FL-06）。⚠️ 原稿"各怀鬼胎""觊觎人间容器"已按此校正 |
| 写法红线 | 禁用"震怒、报复、忌惮、觊觎、阴谋"等人格动词 |

### F-04 民间巫傩世家 · 夹缝存古法

| 项 | 内容 |
|---|---|
| 定位 | 端公／师公／土老师世代传承；首卷最重要的盟友与压力源 |
| 控制资源 | 地方登记权、傩坛（L-03）、面具、猖兵、〔考〕辰州上岗教 37 场法事全名目 |
| **缺什么** | **经**——有仪轨无典据，被玉虚宫斥为"野法" |
| 执行 | 掌坛师 → 引见／接法／唱度／证明／保具／封神**六师** → 坛众；上刀梯、煞铧、顶凹、开红山 |
| 三级结构与清洗 | 出师须抛牌奏职；**破坏规矩者不是被逐，是被"不勾愿"**——从此他的法事没人认 |
| 与主角 | 雇主 → 师承 → 庇护；但六师中至少一人主张把赵海交出去换一部经 |
| 理念色 | 青（手续），"手续比法力大" |
| 〔考〕可用组织原型 | 元皇派神榜名号："正一启教玄皇会上赵侯圣主"（文坛）／"轩辕启教玄皇会上赵侯圣主"（武坛）；一炷香教（董四海，嘉道间被取缔而难尽根株）——**作为"被取缔但仍在地下"的架空原型，不指认现实教派** |

### F-05 行当帮会 · 走脚／捞尸／放排／跑山

| 项 | 内容 |
|---|---|
| 定位 | 十二行当的联合体；读者最长时间待的地方 |
| 控制资源 | 行规、暗号、滩爷铜牌（I-02）、避险知识、〔考〕临清会馆与临江木帮制度 |
| **缺什么** | **岸**——永远在水上、路上，没有一处能点主的土地 |
| 执行 | 行规 + 廉价器物（苕帚、朱砂、桃木、遮子／竹篠行话）；**无超常武力** |
| 三级 | 滩爷／把头 → 头盘／二盘／三盘／四盘 → 帮工；铜牌可世袭转卖 |
| 与主角 | 同行 → 情报 → 背叛（一次铜牌转卖引发整条江编号错乱） |
| 理念色 | 褐（手艺） |

### F-06 无首神骸 / F-07 规则漏损

见 `人物卡.md` §二、`world-bible.md` §7。**F-07 不是势力、无意志、无结构**，列在势力表只为让"世界不靠主角也在变坏"这件事有个编号。

## 四、关系图与必然冲突

```
F-01 玉虚宫 ══血仇══ F-04 巫傩世家      〔H-06 清傩之议，争"谁能点主"〕
   │  ──利益──> F-05 行当帮会           〔要铜牌编号 ⇄ 要度牒〕
   │  ····秘密···· F-03 残神旧仙         〔H-07 执行者名字已从籍库消失〕
   │
F-02 心武五宗 ──同源── F-04             〔"架庙"与"起柱上梁"本是一事〕
   │  ══内部清洗══ 战狂／弈心            〔两条路线通向反派〕
   │
F-03 ····凝视···· 全员                 〔不对话、不交易、不动手〕
   │
F-06 ══镜像══ 主角                     〔同一场斩首的两个残件〕
   │
F-07 规则漏损 ──环境压力── 所有地点      〔R25，无意志〕
```

**"缺什么"→ 冲突闭环校验**

| 两家 | 争的同一件稀缺资源 | 是否必然 |
|---|---|---|
| F-01 vs F-04 | **一部没被毁掉的登记簿**（§10 稀缺资源①） | ✅ H-04 已分籍、H-06 已打过一次，不是潜在冲突 |
| F-01 vs F-05 | 铜牌编号 ⇄ 度牒 | ✅ 每一次过州界都要重新登记，天天在发生 |
| F-02 vs F-01 | 合法性 | ✅ 心武道"自建庙宇"直接否掉受箓垄断 |
| F-03 vs 全体 | 容器 / 簿子 | ✅ R13 与 R4 决定它只能借、只能诱 |
