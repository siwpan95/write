## 3. 世界四层建构表（全书级）

### 3.1 自然环境层

| 提问 | 回答 |
|---|---|
| 地形/气候 | 江畔二线城市：夏闷热冬湿冷，梅雨季对枪械/电子设备是天然损耗源（暗线战术资源） |
| 资源 | 现代都市资源充沛；**最稀缺的是"隐世"本身**——不被监控、不被记录的通道（旧城改造区、废弃厂区） |
| 物种/灾难 | 常规现实生态；周期性"灾难"=城市改造与资本洗牌（把老势力连根拔起） |
| → 生存方式 | 决定了隐世组织寄生在**商业灰产**里：皮包公司、地下钱庄、旧厂区据点 |

### 3.2 社会结构层

| 提问 | 回答 |
|---|---|
| 政治/经济 | 现实秩序；明面权力=资本+法务，暗面权力=谁掌握"对方的罪证" |
| 军事/暴力 | 官方垄断暴力；隐世武力天花板=职业杀手（一对一可胜正规武装小队，无法对抗体系） |
| 法律 | 一条命=法定偿命刑责；灰市"买凶"有行价（见 §10） |
| 阶层 | 明面上升通道=商战；隐世世界上升通道=组织功勋 |
| → 必然冲突 | 组织要"干净的钱"洗白 → 必然寄生企业 → 必然与企业管理层（楚嫣然）相撞 |

### 3.3 文化表层

| 提问 | 回答 |
|---|---|
| 信仰/行话 | 师门信"灵枢济世"（U-01）；隐世行话："放风"（情报）、"洗地"（销证据）、"锁眼"（监视）；徽训"刀不出鞘则已"（U-02） |
| 日常/审美 | 普通人打工通勤过日子；隐世圈以"低调"为体面、以"见光"为耻辱 |
| 禁忌 | 见 §3.5 |
| → 越界 | "见光"=组织性死亡；谁先公开谁先亡——双方都在比谁藏得深 |

### 3.4 个人经验层

| 提问 | 回答 |
|---|---|
| 主角身体最先感到的 | 肋下旧伤在阴雨天抽痛（H-03 围杀的物理留痕，随身携带的历史） |
| 最怕的具体是什么 | 妻子在他看不见的地方遇袭——由 R5（动用组织=暴露）造成：他越保护越暴露 |
| 认同这套秩序的配角 | 张伯：信"寄人篱下就守寄人篱下的规矩"，理由=保全家平安（后被催眠利用，反讽） |
