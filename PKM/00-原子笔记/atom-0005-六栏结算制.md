# 六栏结算制（完稿后的回填机制）

> **原子笔记**：一条**完稿流程机制** —— 卷/篇完稿后强制回填六类台账，
> 保证「正文写了但台账没记」不会积累成债。

## 事实

原型出处：《点子库》法则权能系列。

> 每卷正文完稿后按【人物 → 支线 → 台账 → 实体 → 风格 → 方法】回填一章补遗
> （编号接续：23、24……）

| 栏 | 内容 | 典型回填物 |
|---|---|---|
| **人物** | 本卷人物的成长/立场变化 | 「卫蒹新增『观测非管控』立场并**关闭采集**（外勤生涯的转折动作）」 |
| **支线** | 支线的状态推进 | 「S14 残响印正式发芽」「S7 阿钉行市塌方」 |
| **台账** | 数值/量度/制度的可计量变化 | 「全城校准误差 **+12% 且扩大**」「三公报同日沉默（均势加速崩坏）」 |
| **实体** | 新实体与世界观机制 | 「不可判定域『庇护效应』：赖账者与漏登者的迁入」 |
| **风格** | 文风承诺的兑现情况 | 「Kafka 条目兑现」「洛氏余韵：卫蒹『它抬了抬眼皮』」 |
| **方法** | 本卷用到的/新学到的技法 | 「铁律+七项微调白名单、原型映射表、四步审计、五权矩阵」 |

**沿革**：初为四栏（人物→支线→台账→实体），21 章追加「风格与方法」两栏，
自此按**六栏**结算。（出处：`点子库/01-设定集/21-参考资料反哺-四份资料的吸收与入典.md` 末行）

## 为什么值得单独抽出

它解决网文创作最常见的隐性债：**正文写了，台账没记**。
到几百章时，「某个伏笔到底收没收」「这个数值后来变过几次」已经无法从正文回忆。

六栏的妙处在于**每栏对应一个不同的追问**：

| 追问 | 对应栏 |
|---|---|
| 人变了吗？ | 人物 |
| 线索推进到哪了？ | 支线 |
| 数字动过没有？ | 台账 |
| 世界多出新东西了吗？ | 实体 |
| 承诺兑现了吗？ | 风格 |
| 这卷我学到了什么新技法？ | 方法 |

「方法」栏是**元层** —— 它让每卷的产出不仅推进故事，还沉淀方法论。
这正是 [[atom-0002 通用模板包]] 「模板 → 实填 → 反哺」闭环能持续跑下去的原因。

## 配套做法

- **结算即入典** —— 补遗章不是流水账，而是**新实体入典的通道**：
  「新实体入典先过『现实原型是什么』一问」（见 [[atom-0004 基准系统＋白名单]]）。
- **角色卡也要回填** —— 卡随正文六栏结算回填；卡规三则：
  ①卡片 1–3 句/项，写不满或写爆都说明没想好；②卡随正文六栏结算回填；
  ③配角不围绕主角运转 —— 每人都有独立于主线的生活轨道。
  （出处：`点子库/01-设定集/24-角色卡总册.md`）
