# 通用模板包（跨项目方法论资产）

> **原子笔记**：本仓**唯一**的方法论真理源。任何新书立项都从这里进，不另起模板。

## 事实

`通用模板包/` 是**创作室通用模板包 v3.12**（2026-11-13），`00`~`18` 共 19 份模板，使用路径 A~F。

流程主干（路径 A~F）：
立项定位 → 大纲 → 世界观 → 人物 → 文风 → 连载护航 → 章节创作 → 立项书 → 节拍表/黄金三章 → 合规一致性 → 品类IP前置 → 世界先行与地图叙事 → 喜剧节奏与无厘头 → 字数增密与紫罗兰散文防控 → 程序化创作与算法脚本

## 关键机制

1. **反哺闭环**：模板 → 实填 → 验出不足 → 反哺模板 → 版本升级。
   已验证样本：Tserena（覆盖率 `4/14 → 8/14 → 11/14`）、华夏克苏鲁（8 份实填）。
   **结论**：「模板不适用」是**阶段属性**，不是项目属性。
2. **防回归**：`通用模板包/MANIFEST.sha256` 按 **blob（LF）字节**计算，
   在干净克隆里 `sha256sum -c` 须 27/27 通过（按工作区字节算会 3/27 失配）。
3. **N/A 三态**：全包 `- [N/A]`，分母重算。
4. **零改动回填**：反哺一律**追加式**修订，不删改既有正文行。
