# 《格物录》——凡人修仙传同人 · 理工男修仙逆袭

> **一句话定位**：一个死在自己手里的放大工程师，穿越到修仙界，发现这个世界其实已经是一个"未形式化的经验科学"——它有真知识，但没有让知识累积的制度。他要做的不是推翻这套体系，而是给它补上对照、统计、盲法、同行评议与复现机制，然后让五灵根也能筑基。

> **Logline**：他们靠出身与奇遇修仙，他靠**把知识变成可累积的公开知识**；他们靠一个不可复制的奇遇走到极致，他靠一套任何人都能学会的工序走得更远——并且走得更稳。

> **文档状态**：v2.0 设定集（系统规则 / 主角目标 / 约 600 字人物小传）。v1.0 的"创作红线"一章已删除，理由见 §0。

## 0. 本书性质与设定自由度声明

### 0.1 这是一部什么样的同人

同人的本质是**基于原作世界观的二次创作**，创作自由度远大于商业原创：既可以延续原剧情，也可以改头换面重写，甚至只借用人物姓名而另立背景与主线（《上海文化》网络同人小说研究专题、维基百科"同人（ACG）"条目均有此论）。因此本书**不设"创作红线"**，但为读者便利，仍把设定来源分四层标注：

| 层级 | 内容 | 处置 |
|---|---|---|
| **A 原著基线** | 境界、灵根、丹药、符箓、阵法、傀儡、灵石、势力、地理、人物 | 沿用，不改写其规则 |
| **B 原著深化** | 在 A 的空白处补上机制与因果，使原有设定从"传闻"变"可解释" | **深化，不是推翻**——见 §1.3 |
| **C 跨作品引入** | 道教内丹/丹经/道医体系、其他仙侠网文的通用设定语汇（工业体系、学术门派、灵兽养殖、机关傀儡等） | 按需引入，标明出处 |
| **D 本书原创** | 青石门、验方行、《格物录》、主角与人物、事件 | 原创 |

### 0.2 关于"深化"与"推翻"

上一版设定把"不推翻原著设定"写成了一条禁令，这是编辑思维，方向错了。**正确的关系是：主角介入这个世界后，原著设定从"作者写下的结论"变成"世界运行的规律被逐步揭示"**——例如：

- 原著说"五灵根修炼极慢"，那是**现象**。主角揭示的是**机制**（五灵根是"最难定向但上限最高"的灵气亲和谱），现象没变，解释变了。
- 原著说"很多丹方失传"，那是**结果**。主角揭示的是**制度成因**（失传源于记录文化缺失、垄断与无同行评议），结果没变，成因被补上。
- 原著写韩立的谨慎、囤药、跑路，主角不否定这些，反而从决策科学角度给出解释（证据不足时的贝叶斯决策、期权思维、止损纪律）。**韩立不是被超越的对象，而是方法论同源、资源不同的另一个样本。**

> 因此本书的"逆袭"不是"我比原著聪明"，而是**"我把这个世界从经验科学推到了现代科学"**。原著人物在这个过程中照样赢、照样死，只是有些事的成因被重新解释。

### 0.3 允许的介入方式

1. **隔代影响（首选）**：主角在越国西陲的作坊产出的标准化符箓、丹药流入坊市，被不知名的散修买去；若干年后那人的研究成果出现在另一处。主角本人可能一辈子不知道。
2. **二阶影响**：主角的《格物录》抄本流散，被某个卡在瓶颈期的人当成"胡言乱语"，但其中一条土法真的管用。
3. **擦肩**：韩立（或其他原著人物）在某处看到"药奴出身的炼器师"这一则坊间传闻，跳过，不感兴趣。
4. **体系外溢**：主角的作坊规模一旦起来，周边门派的丹价、符价、筑基丹黑市价格会被压低，间接影响某些原著事件的成本结构。

> 主角**不夺取**韩立的掌天瓶、青元剑诀、大衍诀等机缘——理由不是红线，是**这样做就没法写同人了**：双主角分账会杀死本书的主题（同人真正的乐趣在于"同一个世界里多了一个变量"）。

### 0.4 同人的义务边界：设定合同 vs 创作自由区

同人是**二次创作**，不是续写，也不是仿原作者写番外。这条区别必须写死，否则会一路错到正文里。

| | **设定合同（必须承接）** | **创作自由区（完全自主）** |
|---|---|---|
| 内容 | 世界规则、修炼体系与境界、灵根与资质逻辑、丹药/符箓/阵法/傀儡的规则、灵石与经济结构、势力版图与地缘、既有事实（韩立存在、黄枫谷存在、魔道六宗终将南下、升仙大会存在） | 叙事腔调与文体、叙述人称与时态、主角身份与路线、主线结构与节奏、金手指形态、是否与原著人物同框、交集方式与次数、配角原创度、是否沿用原著的道德秩序 |
| 理由 | 这是读者进门的门槛。读者是**带着这个世界的记忆**来读同人的；灵气守恒、灵根决定资质、筑基丹被七派垄断这些一旦被改写，同人就不再是同人 | 这些是原作**没有写的东西**。原著没写主角是药奴、没写实验记录体、没写教内丹学——写出来不是"不像原著"，是"原创" |

**判据（一句话）**：
> 若某处改动**违反了世界内部的自洽性**（灵气不能凭空产生、灵根不能改、稀缺资源不能无限），那是设定错误，必须改；
> 若某处改动只是**"原作者没这么写"**，那不是问题，是同人的本职。

**由此得出的三条硬约束**：

1. **不模仿原作者的笔法**。本书采用第一人称实验记录体，与原著的第三人称限知叙事在语感上应明显不同。刻意追求"像凡人修仙传"是本末倒置——那会同时损失本书的文体辨识度与原著的独特性。
2. **不复述原著剧情**。原著的重大事件（血色试炼、魔道南下、大修士典礼等）按其原有因果与时间发生，主角可以处在洪流里，但不接管、不改写、不充当解说员。**本书提供的是新变量，不是新版本。**
3. **韩立是背景，不是镜像**。本书不写"另一个韩立"，也不以"韩立的另一种可能"来自我标榜。主角与韩立之间**没有师徒、传承、对手或道统关系**——他们互不知晓，世界因他们各自而不同。

> **一句话总结本书的体裁身份**：*这是一部"用科学方法重写修仙界"的同人小说，它的文体是实验报告，它的敌人是垄断知识的制度，它的赌注是"让下一个五灵根不必被灌药试死"。*

### 0.5 赛道坐标：本书在"理工男 + 修仙"赛道中的位置

**"理工男 + 修仙"是成熟但小众的既有赛道**（联网核验结论）。它的四个成熟分支如下——本书不与之对立，而是**取一个分支（科学方法论）× 换一个母体（凡人修仙传）× 换一条路线（制度而非个人）**：

| 分支 | 代表作 | 主角设定 | 核心手法 |
|---|---|---|---|
| **代码/程序流** | 《C 语言修仙》《码农修真》《天道之宰》《超神制卡师》《大数据修仙》《非典型修仙》《科学修仙》《赤城》 | 程序员/码农 | 功法=程序，法术=可编译指令，BUG=破绽，元神=硬件 |
| **物理/科研流** | 《走进修仙》（今法修 vs 古法修阵营）、《新格物致道》《修仙科学院》《我缔造上古天庭的那些年》 | 物理学博士/理科生/科研人员 | 用现代物理数学解释灵气，划"今法修"与"古法修" |
| **工业/基建流** | 《修真大工业时代》《修真四万年》《屠魔工业》《科技大仙宗》《仙界基建狂魔》 | 快递工/矿工/土木狗 | 流水线、标准化、规模化生产 |
| **兵器/符箓流** | 《核动力剑仙》《修真枪械师》《这个符师竟然搞科研》 | 兵器工程师/符师 | 火器、动能定理、符箓模块化 |

**本书在这条赛道中的差异化（三个坐标）**：

1. **母体换血**：以上几乎全部是原创世界（多为"多世界"或"独立修仙界"）。本书是**《凡人修仙传》同人**——有韩立、有黄枫谷、有魔道六宗南下、有升仙大会这一整套原著制度作为压力测试场。**原著的制度性压迫（筑基丹被七派垄断、升仙大会名额、秘传垄断）恰好是本书命题最好的靶子。**
2. **路线换道**：赛道主流是"**主角获得技术优势 → 个人碾压**"（俗称"挂"). 本书走"**方法论优势 → 制度碾压**"：主角不靠独家技术取胜，他靠**让技术可被复制**取胜。系统《格物录》甚至**不允许他保有不可复现的优势**（规则三：教学计入认知点）。这使本书的爽点从"我比你强"变成"**我让你也能强，而因此我赢了整个游戏**"。
3. **接口换道**：赛道主流对接的是**现代物理/计算机**。本书对接的是**道教内丹学**——这个赛道里几乎没人碰的接口，而它恰恰是《凡人修仙传》修仙语汇（炼气、精气神、性命、心魔、悟道）的**原生母体**。用现代科学与内丹学做"同构对话"，比用物理学解释灵气更贴原著，也更难被写过。

**已知最接近的竞品与本书的区分**：

| 竞品 | 相似处 | 本书的区分 |
|---|---|---|
| **《我在凡人科学修仙》（洛青子，723 万字，已完结）** | **同为凡人同人 + 科学思维 + 伪灵根 + 无小瓶 + 改良符箓/功法** | 竞品是"**改良功法以提升个人战力**"（个人变强流）；本书是"**建工序卡、建作坊、建标准、公开知识**"（制度普及流）。竞品主角仍在黄枫谷里爬；本书主角在越国西陲办了个改变行业规则的作坊。此外本书多三个变量：五灵根（比伪灵根更极端）、道教内丹接口、钢铁直男人设 |
| **《走进修仙》今法修阵营** | 划出"科学 vs 玄学"的两派对立 | 竞品的"今法修"是**精英路线**（懂科学的人更强）；本书的"格物派"是**普及路线**（懂科学之后必须教给别人），且本书明确指出：**今法修一旦普及，七派的筑基丹垄断就完了**——所以本书的核心冲突不是"谁对谁错"，而是"**一旦对了，代价由谁承担**" |
| **《让穿越，你用代码炼气修仙！》结局"开源修真协议"** | 同样指向"知识平民化"的终局 | 竞品靠"代码"这个统一抽象；本书靠**三件套：工序卡 + 验收标准 + 同行评议**，且系统的核心机制是"**不可判定**"而非"开源代码"——本书认为可开源的是方法，不是可以一键复制的成品 |
| **《非典型修仙》（非战斗型 / 调试优于修炼）** | 同样拒绝"变强=唯一价值" | 竞品走医疗/系统重构的技术官僚路线；本书走**降本与普及**，且主角有明确的思想冲突（直男 vs 人情世故） |

> **结论**：本书是"理工男 + 修仙"赛道与"凡人修仙传同人"的结合与变种。**卖点不与赛道主流冲突，但赛道主流已把"科学修仙"的可能性教育给读者**——本书要做的是在读者已经接受这个设定之后，给出一个他们还没见过的答案：**科学修仙的下一步不是让主角更强，而是让这个世界的方法论可以被所有人复制。**

## 2. 科学性论证：为什么修仙界是"未形式化的经验科学"

这是本书的立论基础，须先立住。

### 2.1 它已经具备科学的五个特征

| 特征 | 修仙界的证据 |
|---|---|
| **可重复性** | 同一张丹方在不同宗门、不同丹师处能炼出同品级丹；同一门功法在不同人身上效果一致 |
| **变量已被识别** | 灵根属性、功法品阶、药材年份、丹炉火力、炼气时长对成品的影响，是修仙界公认的常识 |
| **可证伪** | 筑基失败、丹炉炸炉、突破走火入魔、天劫殒命，都是明确的证伪事件，且被当作经验教训流传 |
| **承认误差** | 资质有高低、运气有好坏、"机缘"一说，本身就是修仙界对不可控误差项的显式承认 |
| **动态修正** | 丹方被改良、功法被迭代、门派因经验积累而兴衰（魔道六宗中鬼灵门最弱最终被群起而攻） |

### 2.2 它缺的正是"现代形式"的六件事

| 缺失 | 修仙界的现状（原著可查） | 后果 |
|---|---|---|
| **随机化对照** | 谁试药全凭门内长辈指派 | 混淆变量无法排除，疗效归因靠"神农尝百草"式传说 |
| **统计量** | "三成把握""十拿九稳"是传闻不是数据 | 失败率无记录，经验无法累积 |
| **盲法** | "灵光一闪"是典型未受控的主观报告 | 幸存者偏差、确认偏误全无过滤 |
| **同行评议** | 秘方不外传，见面只谈价钱不谈数据 | 伪法与真法混在一起流通 |
| **记录文化** | 失传即永灭 | 知识不能累积，文明靠个人天赋续命 |
| **复现机制** | 一炉丹只此一炉 | 不可重复者不可信，却仍被奉为圭臬 |

### 2.3 结论

**修仙界是一门前科学（proto-science）：有真知识、缺制度装置。**它缺的六件事，恰好是 20 世纪科学方法论补上的那六件事。所以本书的主角不是来"揭穿迷信"的——他自己在这个世界的第一年就会发现**炼气期对身心状态的敏感度远超现代医学对人的理解**，而**内丹学对意识层级的区分（常意识/潜意识/元意识）在认知科学看来比同时代任何体系都精细**。

> 胡孚琛在道协会官网的表述可作本书方法论的引子：内丹学是一项"凝炼常意识、净化潜意识、开发元意识的系统工程"，"只有在自然科学能够充分地解释人的大脑神经的奥秘时，才可能在实证的层面获得突破性进展"。**这句话本身就是主角的路线图。**

### 2.4 因此主角的"逆袭"有了严格定义

> **不是变强。是把修仙界推入一个知识可累积的时代。**
> 他个人的修为提升只是副产品；真正的成果是：**当一个五灵根修士也能凭公开的、可复现的工序筑基时，修仙界的入场券规则就变了。**

## 3. 系统规则：《格物录》

### 3.1 系统性质

它不是外挂，是**主角自己的实验记录系统**——穿越时随意识一同烙下的那套工作习惯，被具象成了一台仪表。它的界面语气像实验记录软件：**冷、精确、从不恭维、也从不鼓励**。

**它永远不做的事**（这一节比它会什么更重要）：

- 不给功法、丹药、法宝、灵石、寿元、运气；
- 不预知危险、不指路、不报方位、不读心；
- **不告诉主角"这个世界的规律是什么"**——它连《格物录》的目录都不给；
- **不验证结论，只标注"此结论目前不可判定"**——它是一台否证机器，不是一台许愿机。

### 3.2 七条规则

**规则一：观测优先，结论需对照**
系统只做三件事：①把主角的模糊感受翻译成**可读参数**（丹田五行残留量级、药性相冲顺序、每日排毒时段差异、灵气吸纳效率、批次一致性……）；②标出**变量关系**；③列出**未受控变量与缺失对照**。
任何"改进方案"必须由主角亲手实验 + 设定对照后，才可能被判为有效。**系统提供假说，绝不提供答案。**

> 代价：解析消耗**神识**与**实物材料**；对象越复杂、观测越深，消耗越大。神识透支造成幻视、耳鸣、记忆错位——他前世"过劳"的修仙版账单。

**规则二：否证优先，系统只说"不可判定"**
系统采用波普尔式否证逻辑：
- 主角提出的假说，系统列出"什么样的结果能证明它错"；
- 主角的结论若缺乏对照，系统直接标红**"不可判定"**，并拒绝让他写进正式记录；
- 主角想抄近路，系统不会阻止，但会永久留下**"未经对照"**标记，且此后所有引用该数据的结论都继承这个污点。

> 这是全书的机械核心：**系统不阻止他说谎，但系统会记住他没做对照。**修仙界最缺的就是这个记录。

**规则三：无赠送、无代劳**
系统不产出任何资源。系统的唯一"货币"是**认知点**，来源只有三种：

| 来源 | 说明 | 为何重要 |
|---|---|---|
| **亲手实测** | 第一次完成某一类实验（失败也计） | 逼他动手，不许空想 |
| **复现他人成果** | 把别人偶然做成的事变成任何人都能重复的流程 | 把"秘传"变"标准" |
| **教学与传承** | 他人依其方法**稳定复现**成功 | 逼他必须把手艺公开出去 |

> **教学计入认知点**，是本书最重要的一条设计：主角想变强，唯一的路是**让自己的东西被别人学会**。这把"逆袭"从"打赢谁"重新定义为"改变谁的游戏规则"。

**规则四：可复现性门槛**
任何改进计入认知，须满足：**同一方法在不同批次/不同人身上复现成功 ≥ 2 次**。只在他自己身上有效 = 不可复现 = 不计入。
这直接构成全书难度：修仙界一切皆"手艺人绝技"——依赖师承、天赋与不可言说的经验。连韩立本人也长期受制于此：青元剑诀是残本，掌天瓶不可复制，许多机缘一去不返。**主角要对抗的不是某个更强的敌人，而是整个"知识不可传播"的体系。**

**规则五：可观测边界——心与缘暂不可判定**
系统能解析物、灵、功、法、丹、器、阵、符的**结构与效率层**；对**心魔、机缘、气运、情绪、誓言**只输出"不可判定"。
> 注意措辞是"暂不可判定"而非"不可观测"——这是本书与普通科学修仙文的分水岭：主角后期的核心工作之一，就是给"心魔"造出**可操作的量表**（把"心魔"翻译成可自评的信号强度、触发条件、可中断性），把"机缘"翻译成**未观测混杂变量**。道教内丹学在这件事上是他最好的老师（见 §3.5）。

**规则六：降本必有 trade-off，且不可归零**
系统的意义是把成本从"天灵根 + 大宗门垄断"降到"四灵根散修可承受"。但原材料与时间成本不可归零，且每次降本都在牺牲某项性能。系统强制显示权衡表：

> 例：改良后的"稳灵丹"保质期从三十年降到八年（更易失败但成本降六成）；改良后的"净灵散"吸纳效率提升 22%，代价是每日服用剂量翻倍（总成本不降反升）。

> 代价越小的改进越稀有。**每次进步都要付账。**

**规则七：解析留痕，强者可辨**
每次深度解析，主角身上残留可被高阶修士察觉的**解析杂纹**（灵力波形上的细微噪点），用得越多越明显。
> 张力：他越强就越"不像本地人"，越容易被当作**夺舍者/异界来客/邪修**追杀。这与原著"低调"铁律呼应——但他不能像韩立那样一个人躲起来，因为他的东西需要很多人一起做。

### 3.3 面板调性（可直接引用的写作格式）

```
【格物录】
观测项：丹田五行残留 | 金 0.7 木 1.4 水 0.9 火 1.6 土 1.1
假说 H-03：相冲顺序为 火→木→金→水→土
  决定性实验：若顺序反向，则五行残留的衰减速率应呈对称分布
  当前状态：缺 n≥5 重复样本，不可判定
未受控变量：服药时辰 / 饮食 / 情绪 / 当日灵气浓度（4 项）
Trade-off：均质化换效率（-18% 吸纳效率 / +40% 稳定性）
认知点：12 | 解析痕迹：3 级（筑基期可辨）
```

### 3.4 系统的第一次真正应用：五灵根不是死局

原著设定：五灵根修炼极慢、自然止步炼气六七层；同时原著亦设定**五行灵根在炼虚期"五行合一"上反而有优势**。主角不可能改动设定，但可以重新解读它。

**系统给的只是变量**：五灵根 = 五条通道并行、每条带宽都低、且属性之间在体内互冲。
**主角的解法（工程化，且完全在原著设定内）**：把"五行相生"（木→火→土→金→水）读成**级联精制塔**——不是五条路各走各的，而是**让前一级过滤掉下一级的干扰项，级联提纯**，最终合成一条高纯度主通道。
> 于是"互冲"变成"分工"，"带宽低"变成"需分五级放大"。这是化工厂精馏塔的逻辑，也是他前世熟悉的活儿：*不是让每一级都变强，而是让级与级之间不互相污染。*

**关键戏剧性**：这个解法**不是系统告诉他的**。系统只列出五行残留量与相冲序；"级联"这个念头来自主角自己，且**第一次试错是失败的**（他先想到"泄去四属性只留一属性"，结果三日后经脉寸断，靠一个药奴同伴的土属灵力吊住命）。**灵根互冲由此被具体化为可操作的工程问题，而"试错—失败—修正"正是本书的叙事节奏。**

### 3.5 与道教内丹学的对接：把"前科学"接上"现代形式"

这是本书最见功力的部分，也是主角区别于普通"科技流"主角的地方——**他不KO古人，他给古人补方法**。

| 内丹学原生概念（C 层引入） | 现代科学可对接处 | 主角的"增补"（不否定） |
|---|---|---|
| 炼精化气·炼气化神·炼神还虚 | 能量层级转换；神经可塑性（长期训练改变结构与功能） | 给出**可测量的中间指标**（而非只给证悟体验） |
| 性命双修（性=元神/心性，命=元炁/形体） | 心身交互影响；自主神经与内分泌 | 提出**性功/命功的剂量-效应关系**，并记录失败案例 |
| 取坎填离／还精补脑 | 内分泌—性腺—垂体轴；条件反射与神经可塑性 | 把"感觉"改写成**可自评量表** |
| 攒簇五行／五行颠倒术 | 五脏之气集中调节 ≈ 系统论"涌现性"；非平衡态的新和谐 | 提供**对照训练法**（练攒簇五行 vs 不练的差异） |
| 三田反复（精自下田入上田…） | 能量代谢（ATP 生成与消耗）的古典意象 | 引入**代谢指标**做旁证 |
| 元神/阴神/阳神；常意识/潜意识/元意识 | 意识层级划分 | 引入**可重复的任务表现测试**替代"见性"自陈 |

> **方法论底线（刻意保留的"不可约性"）**：道教以**证量与转化**为目标，神经科学以**测量与再现**为目标。二者是**同构对话，不是还原论等价**。主角不得宣布"古人说的是错的"，也不得宣布"古人早就知道答案了"。他要说的是第三句：
> **"你们的路径是真的，你们的方法不是唯一的；现在给这条路装上测量和复现的工具。"**

## 4. 主角目标：理论线 / 应用线 / 人生线

全哥提出的框架：**科学对应两点——理论是知识体系，应用是产品落地。**主角的两条主线由此分开，且互相牵制。

### 4.1 理论线：把经验知识形式化为可检验的模型

**T1 · 给修仙界装上量表（0–3 年）**
从最基础的开始：**测量工具**。他先做的不是理论，是尺子、量杯、温度、称重、重复。
- 可检验：自制一套能在灵药与丹药上工作的**最低限度量具组**（浓度、纯度、存放时长的量化替代）；并给出**误差范围**。
- 意义：这是所有科学的第一步，也是他区别于"靠感觉的修士"的起点——**他让"感觉灵光"变成一条可以被打上问号的记录。**

**T2 · 建立可累积的记录体系（2–8 年）**
- 可检验：产出一套**可被他人接续的记录格式**（对象 / 条件 / 操作 / 结果 / 未受控变量 / 可否判定），并让至少三人独立使用这套格式记录同一类对象。
- 意义：这才是"知识能累积"的制度装置。它比任何一项具体技术都重要，也最像原著韩立"留给后来人"的暗线（原著中韩立的功法、典籍、遗产对后世影响巨大）——**主角做的是同一件事，只是做成了制度。**

**T3 · 揭示灵根与心魔的机制（5–20 年）**
- 可检验：给出**灵气亲和谱**（灵根作为可测量的属性分布，而非玄学分类）；给出**心魔的可操作定义**（触发条件、可观测信号、可中断性）。
- 意义：T3 是全书理论层的最高峰，也是对原著"炼气期身心极度敏感"这一设定的正面回应。

### 4.2 应用线：把模型变成可复制的产品

**A1 · 丹药的标准化与批次一致性（1–6 年）**
- 目标：把"秘方"变成**有公差的产品**——同品级丹的批间差异从"看运气"变成"在公差内"。
- 可检验：连续 ≥ 20 炉，同品级丹药的关键指标落在约定公差内；并对外公布公差表与检测方法。
- 意义：这是"科学"在"应用"侧最典型的落地——**可测量的质量承诺**。

**A2 · 符箓与阵法的模块化（3–12 年）**
- 目标：把符箓与阵法做成**可批量刻制、可拼装、可互换**的模块（原著已点明符箓与阵法在刻画纹路上相通——这是现成的接口）。
- 可检验：同一模块在不同符纸上可互换使用；阵眼有冗余设计，破阵成本可估算。

**A3 · 筑基工序卡（2–12 年，与 T2 同步）**
- 目标：**把筑基从"买彩票"变成"工序"**。
- 技术内核：筑基是一次**放大过程**——丹田灵气压缩液化、纯度、经脉承载、体内杂质、以及"爆体"风险。
  - 韩立的破法在工程意义上是"硬堆"：连吞八颗筑基丹，以过量药力强行冲关。
  - 主角的破法是**先做安全的放大**：分步加载（先清杂质 → 再提纯度 → 后加压）、在线监测（以神识当传感器）、失败保护（预留泄压路径）。
  - **而他前世正是死于一次放大失败**（见 §5.1）。这是全书最重的一处反讽：上一世他没控住放大，这一世他第一件事就是先把放大做安全。
- 可检验：**他以五灵根自身完成筑基**；且在观察过他人筑基（含失败案例）后，能总结出一份别人照做也能走通的**《筑基工序卡》**。

**A4 · 组织形态：从作坊到"验方行"（6–30 年）**
- 目标：一个人做不完所有工序。要把工艺变成产业，必须有**载体**：抄本、工坊、学徒、协会、验收规则。
- 具体形态：办一间对外承接炼器、试药、检测外包的**验方行**——对内收无灵根的流民学徒（只做称量、控温、洗器、记录这些修仙界不屑一顾的脏活），以**图纸 + 工序卡 + 验收标准**替代师徒口授。
- 可检验：三年内出产的批次一致性达到名门水平；学徒中至少一人能**独立复现**某项工艺并署名于工序卡。

### 4.3 人生线：钢铁直男的代价与回报

| 阶段 | 困境 | 变化 |
|---|---|---|
| 前期 | **直男税**：修仙界靠话术吃饭——虚张声势、道德绑架、结义算计。他一句实话能毁掉一场交易；在长老面前认真指出"你的功法第四十二步存在未受控变量"，等于当众打脸。他屡次因"不会说话"损失实际利益。 | 但他有一项**直男红利**：因为不会撒谎，所以他的数据、承诺、交易条件可信度极高。在一个普遍失信的世界里，"此人不骗人"是稀缺资产 |
| 中期 | 他仍不理解"为什么有人愿意为一个萍水相逢的人拼命"。这让他早期错过了几次建立真正羁绊的机会。他的关心方式始终是**解决问题**：你脸色不对→我给你做个检测；你要死了→我给你一份能落地的方案 | 他学会的不是"变会说话"，而是**"不绕过人的情感去谈合作"**——承认有些变量无法被优化 |
| 后期 | 他的方法论本身成为威胁：一个能公开复现的筑基法，等于抽掉门派与家族的最后一道护城河 | 他第一次为了保护别人而主动**隐藏**自己的成果——一个直男学会说谎，是全书最重的一次人物成长 |

> **诚实作为方法论的副产品**（人物内核的锚点）：他不是"道德洁癖"才不撒谎，而是**撒谎会污染数据**。伪造一个对照结果，等于把自己变成下一个不知情的被试者。这条逻辑让"钢铁直男"从性格标签升格为**方法论必然**——也是本书所有科学与技术情节的伦理地基。

### 4.4 阻力结构（"逆袭"要有具体的敌人，且不止一种）

| 势力 | 为什么与他为敌 | 惯用手段 |
|---|---|---|
| **门派垄断者**（青石门 → 越国七派体系） | "无丹筑基"若成立，等于废掉升仙大会与筑基丹的定价权 | 扣帽子"魔修"、联合绞杀、封禁坊市、收购作坊 |
| **秘传家族与老匠人** | 公开化=摧毁"秘方不外传"的护城河与祖传地位 | 暗杀、下毒、栽赃偷师、破家灭门 |
| **名额竞争者** | 筑基变容易=竞争者变多=他们的机会变少 | 擂台设局、约战、匿名举报 |
| **老丹师与"老规矩"持有者** | 他的记录体系会让"凭手感"的老手艺显得不严谨——**对手未必是坏人，只是护犊子** | 当众质疑、拒收检验、不肯签验收单 |
| **他自己** | 控制欲与前世未了的执念 | 前期为"数据完整"冒险、拿人做试验、延误救援 → 心魔的来源 |

### 4.5 失败线（提前锁死，避免后期崩设定）

1. **寿元压迫**：炼气寿元仅约百岁。他必须在一个身体约百年的时限内完成"改革"，这是**赛跑而非长征**。前世他死于 29 岁；这一世他要在百岁前跑完全程。
2. **解析痕迹**：用得越多越显眼，最终必须面对"是否隐姓埋名保平安"的诱惑——**放弃系统、放弃成果、做一个安分的炼气散修**，是他必须抵抗的最强诱惑。
3. **可判定边界**：他始终无法证明"机缘"是否存在。有可能他的一切成功只是运气，而他用数据把它误读成了因果。（这条留到后期，作为对读者与主角的双重反转。）

## 5. 主角人物小传（穿越前 / 穿越后，合计约 600 字）

> 本章即用户所指的"约 600 字人物小传"（穿越前后两段合计，不含小标题）。实测：**正文净汉字 628 字**（含标点共 738 字符）。第 3 章系统规则、第 4 章主角目标为独立章节，不计入此 600 字。

### 5.1 穿越前｜沈维，29 岁，生物制药工艺开发工程师

沈维，二十九岁，生物制药企业工艺开发部工程师，负责单抗原液线从二十升放大到五百升中试的批次验证。同事的评价是：话少、记数字、要数据不要形容词。他把交接写成三栏——已控、未控、待证；会上让人做主，散会却能指出谁假设里没有证据。他无法忍受"说不清"：局面失控时本能是砍变量而非找人说话。他不是冷漠，是笨拙：他表达关心，是给你一份拆到第三级、可执行的清单。

他的"直"是训练出来的：同事报喜他问样本量多少，领导说"风险可控"他递三页失效模式分析；有人恼他，他不自知。他也不会撒谎，因为撒谎会污染数据。

缺陷也清楚：他太相信"任何过程都能拆成可控步骤"，别人凭直觉立住的地方，他偏判定对方错。中试线批间一致性崩溃：效价合格，收率塌七成，杂质谱浮出一个没人认识的新峰。有人说属正常波动，他坚持留厂取样——釜内残料温控时析出他没料到的固体，随温压骤释。他最后记下的不是伤口，是手写板上没写完的那句：**放大不是复制，是另一种反应。**

### 5.2 穿越后｜"石九"，16 岁，五灵根药奴

醒来时他趴在没有窗的石屋里，嘴里的渣滂味是洗髓丹残渣，五脏像塞了五种不相容的火。药奴的命：买来的、试坏了的、资质太差的都归这里。他叫石九——编号，也是名字。

他知道不是巧合：他死在一次放大失败上，睁眼就躺在一场失败的"洗髓"里。这世界把他的老本行又考了一遍，考题不再是反应釜，是他这具五行俱全的身体。

意识里多了一台东西，不发号令不赠予，只把他看见的翻译成条目，并在他想下结论时冷冷回一句"未设对照，不可判定"。他试了三次，骗不过它——机器不认口供，只认数据。他反而松了口气：这世上第一样不靠人情运转的东西。

他写下的第一条规矩和上一世一样：**不写"应该"，只写"测过了什么"。**

先活过这个月；再以五灵根之身筑基；再然后——让下一个五灵根不必被灌药试死。

## 7. 开篇钩子（第一场戏的骨架）

### 场景一｜废丹（第一章）
石屋，七名药奴，两人一槽。主角醒在第三个槽。上一槽的人刚被抬走，槽底留着一层干涸的褐色药渣。
- 《格物录》首次启动：他不问"我是谁"，先做**物证勘查**——摸温度、看药渣结晶、对着光看、用指甲刮下一粒结晶。
- 第一批"观测项"：丹田五行残留（火 1.6 / 木 1.4 / 金 0.7 / 水 0.9 / 土 1.1）与"未受控变量：服药时辰、饮食、情绪、当日灵气浓度"。
- 他想要的第一个实验材料：**死者的药渣**——他必须让下一批药奴"吃坏"，才能拿到对照样本。
- 章末钩子：管事宣布明日有新一批"料"要试，其中一个孩子是昨天被抬走那人的兄妹。主角必须在"配合"与"下手"之间做第一次选择。
- **直男名场面**：管事威胁"谁再多嘴，明天的料就多一碗"，他举手问："多一碗会死得快吗？我想知道概率。"全场安静。

### 场景二｜对照（第二至三章）
主角用矿脉捡来的矿粉、金属屑与不同比例的药材残渣做**体外对照实验**（他唯一能自由支配的实验场），首次验证"相冲顺序"假说；第一次尝试"泄去四属性只留一属性"导致经脉寸断，被同槽的药奴女孩（真灵根三属性）用土属灵力吊住命——**他欠下第一条人命债**，也第一次见到"变量互相扶持"的活例。

### 场景三｜级联（第四至五章）
他推翻自己的第一假说，提出级联精制假说并小试：以自身经脉为反应器，按木→火→土→金→水顺序引导药性，每一级过滤干扰项。

## 8. 正文文体规格：实验报告体（v2.2 新增）

### 8.1 体裁定位与先例

**文体原型链**：实验报告规范（科研原始记录）→ SCP 基金会"临床腔"（去口语化、精确简练、无主观情绪）→ 《火星救援》第一人称日志体 → 国内网文实验报告体（《科学修行笔记》《修仙从研究基因开始》《蓝星升维实验报告》）。

**已核验的本土实践特征**（用于对齐，避免自创一套读者不认的格式）：

| 特征 | 已被验证的做法 |
|---|---|
| 章节标题 | 不用章节序号，用**实验编号 / 观测方案 / 记录条次**（如"癸卯年六月初十观测预案""残片初步分析完成"） |
| 段落结构 | "条件设定—操作步骤—结果观测—数据记录"四段式 |
| 语体 | 去诗意化技术说明书；术语化表达；**无主观形容词** |
| 数据 | 所有状态可量化；每章末必含一个可量化参数作为节奏锚点 |
| 人物 | 性格通过"实验选择"展现，不写心理活动；对话如访谈实录 |
| 悬念 | 靠"未解释的异常"维持，而非靠情绪 |

### 8.2 本书的文体决策：三层嵌套（关键）

先厘清一件容易搞混的事：**本书是同人小说，不是续写或番外**。同人的义务是承接原作的**世界规则**，而不是模仿原作者的**叙事腔**。所以本书不必追求"像《凡人修仙传》"——反而要主动走开：原著是第三人称限知叙事，本书是**第一人称实验记录**，两者的语感本就应当明显不同。

在这个前提下，纯报告体的真正短板是**文体自身的两个缺陷**，与原著无关：

1. **人物扁平**：性格只能通过"实验选择"展现，人物会退化成功能键。
2. **情绪真空**：全篇只有数据和判读，读者得不到"有人在场"的实感，情感浓度趋近于零。

因此本书采用**三层嵌套**，每层承担不同职责，互不稀释：

| 层 | 载体 | 文体 | 占比 | 职责 |
|---|---|---|---|---|
| **A 层 · 观测日志** | 主角自用记录本（皮质簿子 / 《格物录》手抄本） | **实验报告体**：条件—步骤—观测—数据—判读 | 约 55% | 承载知识线：假说、实验、数据、结论 |
| **B 层 · 现场批注** | 主角口述的**原始记录人**旁白（药奴同伴、后来的学徒、对手） | **口述实录**：人称混杂、方言、断句、有错别字与误解 | 约 25% | 承载情感线与人味；直男在此暴露 |
| **C 层 · 官方文书** | 门派公文、宗门卷宗、坊市告示、青石门执事呈报 | **公文/clinical 腔**：格式死板、避重就轻、官样文章 | 约 20% | 承载压迫感与制度性冲突；"官方版本"与 A 层记录的**矛盾**本身就是冲突源 |

**为什么 B 层不可省**：解法不是加抒情，而是**让一个不懂科学的人去转述科学记录**——他的转述必然失真、必然带偏见、必然漏掉关键。B 层的"错误转述"与 A 层的"精确记录"逐条对照，读者自动获得：
- 情感（有人在替他记住那些被官方抹掉的东西）
- 人味（转述者的语气、方言、偏见）
- **主题回响**（真相与记录之间的落差，正是本书命题）

**为什么 C 层不可省**：C 层制造**"档案性失真"**——门派文书里写"试药童子九人，殁七"，A 层写"第七槽的人昨夜被抬走，未记录死因"。两条并置，无需一字评论，读者自行完成愤怒。

**关于"直男"与幽默**：参照《火星救援》——主角的自嘲承担全部幽默与人味，正文保持冷硬说明书调性。本书的对应位是**让直男的技术性发言本身就好笑**（"多一碗会死得快吗？我想知道概率"），作者不代为抖机灵。

### 8.3 每章的标准骨架（可直接套用）

```
【格物录 · 记录 No.0XX】
时间：越国历 XXX 年 X 月 X 日 夜（石梁坊，青石门外院药圃）
天气/环境：阴，灵气浓度低于昨日约 ——（此列为修仙界独有的"环境参数"）
观测对象：XXX
假说 H-XX：……
  决定性实验：若……则应观察到……
材料与来源：XXX（残渣，取自第七槽）
步骤：1. …… 2. ……
数据：
  | 样本 | 变量 | 读数 | 备注 |
  | n=1 | | | |
  | n=2 | | | |
异常与处置：……
判读：不可判定（缺对照，n=3）
下一步：……
（夹注，字迹与正文不同）：一句 B 层转述，或一句 C 层公文引文
```

**硬性约束（每章必须满足）**：

1. **每章至少一个可量化参数**（读数、比例、时长、温度、次数），作为节奏锚点。
2. **每章至少一处"不可判定"或"待复核"**——维持否证优先的系统调性，也是本书区别于爽文的关键手感。
3. **每章至少一处失败/异常**——不得只有成功，否则违反"可复现性"设定，且失去张力。
4. **每章至多一处抒情**，且必须落在 B 层或夹注里；A 层禁止出现"我感到""我很痛苦"这类词，改写为客观指标（如"心率上升至 ___；记录：失眠"）。
5. **章末必须有一个未解释的异常项**（对标《火星救援》的"下一个问题"结构与《科学修行笔记》的章节标题即宣言）。

### 8.4 冷硬语体的具体规则

**允许**：术语化、量化、被动句式、条件句、"本记录不构成结论"、"此处数据缺失"、"按 §3.4 级联次序"。

**禁止**：
- 抒情形容词与副词（"阴森的""极其""美丽"）→ 一律改为可测量的物理描述（"石屋温度低于体感三度；药渣表面反光"）
- 心理活动的直陈 → 改写为行为记录 + 结果数据（"他没有说话。第三次记录尝试后停止书写"）
- "众人皆知""自古以来" → 一律改为"门内册载""据卷宗抄本"
- 战斗中的华丽描写 → 用机制与参数写（"剑气接触护罩后 0.3 息内出现三条应力纹；护罩未破"）

**参照《火星救援》的核心手法**：主角的吐槽与自嘲承担了全部幽默与人味，而正文保持冷硬说明书调性。**本书的对应位**：让"直男"承担这一功能——他的直白技术性发言本身就好笑（"多一碗会死得快吗？我想知道概率"），且不需要作者代为抖机灵。

### 8.5 AI 创作友好性设计（生产流程价值）

这种体裁对 AI 辅助写作**极其友好**，因为它把"创作"降维成了"填表"：

1. **结构固定**：每章九段式骨架，提示词可固化，AI 每次产出格式一致，不会漂移。
2. **状态可续接**：主角的实验编号、假说编号、数据台账构成**外置记忆**——AI 无需记住前文细节，只需读取台账表即可续写，不会写崩。
3. **冲突可枚举**：每章的"异常与处置"栏位强制要求给出一个可解决的工程问题，杜绝水文。
4. **语气可锚定**：A/B/C 三层各有 12 条语体规则（§8.4），构成可检验的风格约束。
5. **可增量修订**：某章结论推翻时，只需改台账对应行 + 增补一条记录，不必重写全章。

### 8.6 配套产出：《台账》（Master Ledger）

本书需同步维护一份外置台账，作为"格物录"在读者可见层的实体化。字段固定：

| 字段 | 说明 |
|---|---|
| 记录编号 | No.0XX，全书唯一，跨章连续 |
| 时间 | 越国历 + 年月日 + 时辰 |
| 假说 | H-0XX 编号，跨章引用 |
| 决定性实验 | 一句话，写明"什么结果能证明它错" |
| 数据 | 关键读数或表格摘要 |
| 判读 | 结论状态：已确证 / 已否证 / 不可判定 / 待复核 |
| 状态 | 是否已公开（决定该结论能否被他人引用） |
| 影响 | 若确证，将改动哪一层目标线（理论线 / 应用线 / 人生线） |

**台账的三条纪律**（与 §3.2 规则二对应）：
1. **否证项永不删除**，只在状态栏标注"已否证"及否证它的记录编号。知识的方向性由被推翻的假说保留，不由被推翻的记录消失。
2. **"未经对照"标记永久继承**。凡引用了带此标记的数据而得出的结论，自身也继承此标记，并向下传递。
3. **公开状态单独一栏**。未公开的结论不计入认知点。这条让"藏一手"成为有代价的选择，而不是无成本的小聪明。

**读者可见性设计**：建议每卷卷末附一次台账节选（正文已含部分），使读者能像审稿人一样复核主角的推理链条——这是本赛道少见的"可互动性"，也是本书相对于纯爽文型科学修仙文的体验增量。

**AI 续写用法**：每次生成新章前，向 AI 提交三样东西——①本章所属卷的目标线与卷内阶段；②上一章的台账全文；③本章的九段式骨架提示（§8.3）+ 语体规则（§8.4）。台账即外置记忆，可避免长程生成的设定漂移。
