# 观测与量表

> 分类轴：**本书工具**。用途：《格物录》面板字段定义、观测手段、误差来源——**本书原创的核心机制表**。
> 这是本书相对同类"系统文"最不同的地方：系统不提供答案，只提供**观测口径**。

## 一、面板字段定义（系统唯一职责）

| 字段 | 含义 | 读数类型 | 可否由系统直接给出 |
|---|---|---|---|
| 观测项 | 被测对象的某项属性 | 连续量（带单位） | 部分（需主角先测） |
| 相冲序／关联序 | 各属性之间的抑制或放大关系 | 序 | 假设，须验证 |
| 未受控变量 | 本次观测中未被固定的干扰项 | 计数 | 可列出，但须由主角确认 |
| Trade-off | 某项改进必牺牲的性能 | 成对数值 | 是（系统强制显示） |
| 判读状态 | 结论是否成立 | 枚举 | 是 |
| 认知点 | 主角的认知资本 | 整数 | 是 |
| 解析痕迹 | 深度解析留下的可被强者察觉的噪点 | 等级 | 是 |

**判读状态枚举**（本书核心）：
| 值 | 含义 | 触发条件 |
|---|---|---|
| **已确证** | 有对照、跨批次／跨人复现成功 | 规则三 + 规则四 |
| **已否证** | 有明确反例 | 保留否证记录，不删除 |
| **不可判定** | 证据不足以支持任一方向 | n 不足／缺对照／有未受控变量 |
| **待复核** | 结论依赖他处结论，而该结论尚未确证 | 引用链追溯 |

> **不可判定 ≠ 不可观测**。这是本书与普通科学修仙文的分水岭：心魔、机缘、气运在前期标"不可判定"，后期建出量表后转"可测"。

## 二、观测手段清单（修仙界可实现版）

| 观测目标 | 手段 | 精度／分辨率 | 成本 | 误差来源 |
|---|---|---|---|---|
| 丹田五行残留量级 | 《格物录》直接读数 | 粗（相对量级） | 零（但耗神识） | 神识状态／解析深度 |
| 药渣色·味·粒径·结晶 | 肉眼＋月光＋指甲碾压 | 粗（定性） | 零 | 光照条件／判断者主观 |
| 药渣体外响应 | 矿粉＋金属屑＋药材残渣体外混合 | 中（可重复） | 低 | 配比不精确／环境湿度 |
| 体内外对照 | 同一槽不同人残渣 vs 本人体内读数 | 中 | 低 | 服药时辰差 |
| 溶出／浸液效应 | 浸液组 vs 未浸液组比值 | 中 | 低 | 浸液次数不可控 |
| 服药时辰效应 | 同批不同时辰者配对比较 | 中 | 中 | 需知情者配合 |
| 灵气吸纳效率 | 定时打坐＋前后残留量差 | 中 | 中 | 当日灵气浓度波动 |
| 丹方批次一致性 | 同品级丹关键指标分布 | 细（需多炉） | **高** | 炉火／称量器具误差 |
| 灵根属性构成 | 测灵根石／门派检测 | 中 | 低 | 检测法本身是门派秘技 |
| 心魔信号 | 自评量表（触发条件／信号强度／可中断性） | 粗→中（可迭代） | 零 | **自评偏差**（本书最难项） |
| 运气／机缘 | 归入未观测混杂变量 | **不可测** | — | 只能靠 n 增大后统计识别 |

## 三、误差来源清单（写正文时对照用）

| 误差类型 | 修仙界表现 | 处置 |
|---|---|---|
| 仪器误差 | 旧制铜戥称量（原著：称量器具为旧制，误差不可控） | 记录并标注"误差不可控" |
| 抽样误差 | 样本来自同一槽、同一批 | 记录 n 与批次号 |
| 系统误差 | 同一批料本身配伍不匀（原著："批次内含量不匀"） | 换批重复 |
| 混杂变量 | 服药时辰／饮食／情绪／当日灵气浓度 | 列出并尽量固定 |
| 期望效应 | 修炼者"感觉灵光" | 双盲或编号盲判 |
| 记录误差 | 事后凭回忆补记 | **当场记录**（原著规范：不得作废页、不得加页挖补） |
| 观察者误差 | 主角的判断偏好 | 关键项用可复核的客观指标替代 |

## 四、面板调性（可直接引用的写作格式）

```
【格物录】
观测项：丹田五行残留 | 金 0.7 木 1.4 水 0.9 火 1.6 土 1.1
相冲序：火→木→金→水→土（假设，待验证）
  决定性实验：若顺序反向，则五行残留的衰减速率应呈对称分布
  当前状态：缺 n≥5 重复样本，不可判定
未受控变量：服药时辰 / 饮食 / 情绪 / 当日灵气浓度（4 项）
Trade-off：均质化换效率（-18% 吸纳效率 / +40% 稳定性）
认知点：12 | 解析痕迹：3 级（筑基期可辨）
```

## 五、心魔量表（本书原创·待建）

道教内丹学对心性有精细分层（见 11 表），但缺可操作定义。本书拟建四条观测项：

| 观测项 | 定义草案 | 量表形式 | 当前状态 |
|---|---|---|---|
| 触发条件 | 出现心魔前可复述的固定情境 | 枚举＋频次 | 未建 |
| 信号强度 | 主观强度 0~10 的自评 | 序数 | 未建 |
| 可中断性 | 从出现到消退所需时长 | 时长 | 未建 |
| 事后记忆 | 事后对该情境的重构偏差 | 文本比对 | 未建 |

> **难点**：自评偏差无法用技术手段消除。这条留给中期，且是主角"直男"缺陷的集中暴露点。
