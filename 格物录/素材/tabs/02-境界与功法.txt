# 境界与功法

> 分类轴：**进程刻度**。用途：记录单的刻度对照表——任何读数都要落在某个刻度上。
> 取材：原著设定＋公开设定整理。

## 一、境界表

| 境界 | 分段 | 寿元 | 核心特征 | 可观测标志 | 记录单用途 |
|---|---|---|---|---|---|
| 炼气 | 1~13 层 | ≈100 岁 | 引气入体，灵气气态流转 | 五感发达、可御使符箓与基础法术 | **本书前期主战场** |
| 筑基 | 初/中/后/大圆满 | 200~250 岁 | 灵气液化，可御剑飞行、辟谷 | 真元外放、可炼丹炼器 | 主角第一道大关 |
| 结丹 | 初/中/后/大圆满 | ≈500 岁 | 凝液化固成金丹，可炼本命法宝 | 领域压制低阶 | |
| 元婴 | 初/中/后/大圆满 | 1000~1200 岁 | 丹破婴生，元婴可离体，夺舍重生 | 神魂独立 | |
| 化神 | 初/中/后/大圆满 | ≈2000 岁 | 沟通天地元气，肉身不灭 | 出手即大损寿元 | |
| 炼虚 | — | 近无限 | 元神化虚影，可分身 | 五行合一 | |
| 合体 | — | ≈10 万年 | 虚影显真身，可借法则 | | |
| 大乘 | — | ≈2 万年 | 肉身重铸 | | |

> **本书进度提示**：炼气期寿元仅百岁。主角必须在**一个身体约百年的时限内**完成"改革"——这是赛跑而非长征（见 02 表 §4.5）。

## 二、功法表（已见者）

| 功法 | 层级／层数 | 性质 | 与本书的关系 |
|---|---|---|---|
| 长春功 | 木属性基础，完整十三层 | 炼气期通用 | 主角最可能接触到的入门功法（残本） |
| 青元剑诀 | 剑修，九层→十三层（大圆满） | 主角体系专属 | **不可触碰**（韩立专属） |
| 大衍诀 | 神识修至四层 | 炼气→元婴 | **不可触碰** |
| 三转重元功 | 散功重修、夯实基础 | 结丹 | 原著机制＝迭代优化，本书予以追认 |
| 眨眼剑法／罗烟步／缠丝手 | 世俗武功 | 韩立早期 | 世俗武学＝**工程思维的前身**，本书主角会注意到这条 |
| 龟息功 | 敛息 | | 隐匿技术 |
| 真灵决 | 木属性基础 | | |
| 引气诀 | 入门吐纳 | | 主角的起点可能功法 |

> **本书观察**：多数功法口诀是"怎么做"，极少数说"为什么"。**缺的是参数**——层数与层数之间跳多少？何时是瓶颈？主角的工作是把功法当**待标注的技术文档**。

## 三、功法可标注的变量（本书工作项）

| 变量 | 说明 | 记录方式 |
|---|---|---|
| 层间增益 | 每一层相比上一层的效果增量 | 自身前后测 |
| 瓶颈位置 | 第几层开始吸纳效率显著下降 | 效率—层数曲线 |
| 副作用 | 各层对身体的影响（经脉/神识/寿元） | 逐层记录 |
| 药材依赖 | 是否有必须服用的丹 | 停药对照 |
| 伪灵根适配 | 伪灵根／五灵根修此功法的效率差异 | 与他人同功法对照 |
