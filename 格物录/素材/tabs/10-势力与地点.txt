# 势力与地点

> 分类轴：**制度地理**。用途：抽样框——谁在哪、找谁取样、哪些地方制度最严。
> 取材：原著势力版图＋公开设定整理。

## 一、天南四大势力

| 势力 | 所在 | 构成 | 对本书的意义 |
|---|---|---|---|
| **天道盟** | 天南北部（溪国等十余国） | 鸾鸣宗、古剑门、百巧院、倪航斋、落云宗 | 联盟性质，防御性自保；**落云宗入门门槛最低、炼丹最负盛名**（定灵丹） |
| **魔道六宗** | 天罗国、元武国 | 合欢宗（盟主合欢老魔·元婴后期）、御灵宗、魔焰门、千幻宗、鬼灵门（最弱）、天煞宗 | 鬼灵门最弱最终被群起而攻 → **"弱者被淘汰"是本世界的默认结局** |
| **正道盟** | 风都国 | 太真门（盟主至阳上人·元婴后期）、天极门、浩然阁、岚海宗 | |
| **九国盟** | 天南南部 | 化意门（盟主魏无涯·元婴后期）、贝叶宗、越国七派 | 越国七派：掩月宗、灵兽山、清虚门、黄枫谷、巨剑门、化刀坞、天阙堡 |

> **天南三大修士**：合欢老魔（元婴后期）、魏无涯（元婴后期）、至阳上人（元婴后期）。

## 二、天道盟三巨头与落云宗

| 宗门 | 特点 | 对本书的意义 |
|---|---|---|
| 鸾鸣宗 | 龙晗·凤冰夫妇（元婴中期巅峰），鸾凤双环＋天鸣琴，可敌元婴后期 | 顶级战力，与本书主线无涉 |
| 古剑门 | 御剑之术，太白剑诀；**资质要求极高，故弟子最少** | "资质门槛"的极端案例 |
| 倪航斋 | 况姓老者（元婴中期） | |
| **百巧院** | **善炼制各阶法器**，藏数种顶尖法宝炼制之法；地肺火脉；**主要招收修仙家族弟子，极少对外招收** | **A1/A2 的直接对手**：器道技术垄断者 |
| **落云宗** | 云梦山东脉；**功法杂而不精，炼丹术负盛名，定灵丹只有此派几位长老能炼**；招弟子最多、门槛最低 | 主角早期最可能接触的宗门；**定灵丹＝心魔化学干预的强证据** |

## 三、越国与散修生态

| 要素 | 设定 | 与本书直接相关 |
|---|---|---|
| 黄枫谷 | 太岳山脉西侧；李化元（韩立师）、马老头（百药园筑基） | 原著主角舞台，主角**不加入** |
| 升仙大会 | 十年一次，擂台战，向散修招四十岁以下炼气修士，每派十名，赏筑基丹 | **筑基丹的分配阀门** |
| 升仙令 | 持令者免试入门并获筑基丹 | 稀缺性来源 |
| 太南小会 | 五年一次，岚州太南谷，散修集市 | 主角早期可接触的交易所 |
| 血禁试炼 | 五年一次，七派结丹师祖带队，仅约四分之一生还 | 筑基丹主材产地 |
| 七玄门 | 越国镜州彩霞山，江湖门派；墨大夫（墨居仁） | 原著起点；**主角**在越国西陲**青石门**，非同门 |

## 四、本书的地理设定（原创）

| 地点 | 设定 | 功能 |
|---|---|---|
| **越国西陲** | 远离黄枫谷／太南谷／天道盟核心区 | 制度真空带——**垄断管不到的地方最适合试药** |
| **青石门** | 原创小门派，实为"药圃＋坊市中介"性质 | 主角起点；有药圃（原料）、有坊市（交易）、有执事（压迫） |
| **石梁坊** | 青石门外院所在 | 交易与信息场所 |
| **试药石屋** | 七槽（每槽二人），漏雨 | **第一章场景**；第九章再取样时将起冲突 |
| **外峰试炉** | 废料去处 | 制度性"处理失败品"的流水线 |

## 五、抽样框原则（本书工作项）

在哪儿取样，决定结论的可推广性：

| 想验证什么 | 该去哪儿 | 风险 |
|---|---|---|
| 五行级联的普遍性 | 多地药圃／多批料 | 跨地制度不同，批次不可比 |
| 丹药批次一致性 | 同门同一丹方连续多炉 | 需长期潜伏身份 |
| 符箓模块兼容性 | 多家符师同款符 | 各家秘传，不肯给配方 |
| 心魔量表 | 同批新弟子（资质相近） | 需建立信任，且易暴露 |

## 六、来源

- 原文综合：《〈凡人修仙传〉中的知识点》、起点问答《韩老魔人界总结之天南》、天南修仙界势力深度拆解（天道盟／魔道六宗／正道盟／九国盟）、天南大陆 26 大宗门盘点、落云宗词条（百度百科／搜狗百科）
- 原著：升仙大会与太南小会规则（升仙大会十年一次，各派招十名四十岁以下炼气修士并赏筑基丹；太南小会五年一次，越国南部岚州太南谷，筑基修士主持，参会者绝大多数为炼气期）；血禁试炼五年一次、约四分之一生还；百巧院极少对外招收
- 本书原创：青石门、石梁坊、试药石屋、外峰试炉四处
