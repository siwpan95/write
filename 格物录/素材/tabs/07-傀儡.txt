# 傀儡

> 分类轴：**外部执行体**。用途：精度—成本权衡的对象；也是"把工序交给非修士执行"的先例。
> 取材：原著傀儡等级与造价体系。

## 一、等级与造价（原著核心表）

| 等级 | 战力当量 | 代表 | 造价 | 主材／材料 |
|---|---|---|---|---|
| 一级 | 炼气七层 | — | 极低 | — |
| 二级 | 炼气九~十二层 | 弓箭手、刀斧手傀儡、狼虎兽型、蜥蜴傀儡 | 与高阶攻击法器相当：**60~100 灵石** | 云精石（炼二级傀儡材料） |
| 三级 | 筑基初中期 | 巨猿傀儡（双手释放光束） | 与普通顶阶攻击法器相当：**200~400 灵石** | 百年铁木 |
| 四级 | 筑基中后期 | 巨虎傀儡（一击耗一枚中阶灵石，威力超筑基巅峰全力一击） | 与极品顶阶攻击法器相当：**500~2000 灵石** | |
| 五级 | **与五级妖兽同级** | 青猿傀儡（巨猿强化版）、魂石白狼／红牛／青蛇傀儡 | 上升 | 魂石（兽精） |
| 六级 | 近元婴初期遁速，可撕裂结丹护罩 | 虎妖傀儡（高速近战，爪芒半尺） | 相当于普通结丹级法宝：**5000~8000 灵石** | |
| 七级 | 结丹中期水平 | 蛇妖傀儡（青铜戈与软鞭）、巨龟傀儡（雷火球／冰柱） | 高于普通结丹级法宝：**10000~15000 灵石** | |

> **原著材料线索**：云精石（炼二级傀儡）、铁木（制作傀儡材料之一，万年铁木为上古元婴级傀儡原料）、血凤木（炼元婴级傀儡）、魂石／魄石（阴冥兽晶，上古傀儡术必须）、五光木·火锡木·铁角犀灵角·雷灵晶（炼大衍人形傀儡）、化一神泥（幻形膏，随意变形制器，受损可自修复）

## 二、本书的五个可标注参数

| 参数 | 说明 | 本书意义 |
|---|---|---|
| **战力当量** | 对应哪一境修士 | 决定"能不能替代人干活" |
| **造价** | 灵石当量 | **A4 验方行的成本模型核心** |
| **操纵精度** | 受修士等级与神识双重限制 | **精度瓶颈在哪一级** |
| **维修成本** | 受伤后需材料修复 | **运维成本 vs 采购成本** |
| **智识程度** | 是否自主判断 | 傀儡不能自主 → 工序中"判断"环节仍需人 |

> **本书的读法**：傀儡体系的真正价值不是战力，是它**证明了这个世界已经存在"把执行权交给外部载体"的先例**。A4 验方行要做的事（把工序交给无灵根的流民学徒）比傀儡更激进——**人是活的、可学习的、可传世的，傀儡不是**。这正是"教学计入认知点"能成立的前提。

## 三、造价梯度作为本书的"降本曲线"参照

| 阶 | 造价（灵石） | 相对二级 |
|---|---|---|
| 二级 | 60~100 | 1× |
| 三级 | 200~400 | ≈4× |
| 四级 | 500~2000 | ≈10× |
| 六级 | 5000~8000 | ≈80× |
| 七级 | 10000~15000 | ≈180× |

> 等级每升一级，造价近似**指数上升**。这与"修仙界知识垄断"是同一个结构：**能力越高，代价越指数级，且不可通过努力绕过**——只能靠"找到降本路径"绕过。

## 四、来源

- 《凡人修仙传资料宝物阵法篇》（b 站资料帖）：傀儡一至七级战力当量、造价、主材；炼傀（天都尸）
- 起点作品介绍：材料篇（云精石、铁木、魂石、血凤木、化一神泥等）
- 《凡人修仙传的各种修仙材料介绍》（头条）：傀儡材料与上古傀儡术
- 原著拍卖会：二级傀儡机关兽一对（战力堪比炼气九层）底价一百灵石，实拍九百灵石＋一块铁精（上品铁精值两千灵石）
