# 内丹学术语

> 分类轴：**本土母体**。用途：把修仙界的"玄学"翻译成可测量项的对照表。
> **定位声明**：本书**不否定内丹学**。胡孚琛（道协会）原话：内丹学是"凝炼常意识、净化潜意识、开发元意识的系统工程"，"只有在自然科学能够充分地解释人的大脑神经的奥秘时，才可能在实证的层面获得突破性进展"。
> **方法论底线**：道教以**证量与转化**为目标，神经科学以**测量与再现**为目标 —— 二者是**同构对话，不是还原论等价**。
> 主角对内丹家的态度：**"你们的路径是真的，你们的方法不是唯一的；现在给这条路装上测量和复现的工具。"**

## 一、三宝与阶次

| 术语 | 原义 | 现代可对接处 | 本书拟加的测量项 | 备注 |
|---|---|---|---|---|
| 精 | 最物质性的生命能量，与体液、生殖、体力相关 | 代谢底物、内分泌 | 可测：体力、耐受、恢复速率 | 最易测 |
| 炁（气） | 精微能量，与呼吸、循环、神经调节相关 | 自主神经、呼吸代谢 | 可测：呼吸频率、心率变异 | 媒介层 |
| 神 | 最精微的能量，与意识、觉察、心智相关 | 注意力网络、DMN | 可测：任务表现、干扰抗性 | 最难测 |
| 炼精化气 | 物质性能量→精微能量 | 代谢转化 | 过程可测，方向不可测 | |
| 炼气化神 | 精微能量→意识能量 | 神经可塑性 | 训练剂量—效应关系 | |
| 炼神还虚 | 意识能量融入整体 | 意识层级调节 | | 文始派下手即此层 |
| 筑基 | 奠定基础，调理身心 | 全身状态基线 | 可作"前测基线" | |
| 炼虚合道 | 最高境界 | — | | |

> 《金丹大要》："何谓逆？万物含三，三归二，二归一，知此道者怡神守形，养形炼精，积精化气，炼气合神，炼神还虚，金丹乃成。"

## 二、性命双修

| 术语 | 原义 | 现代可对接处 | 本书拟加的测量项 |
|---|---|---|---|
| 性 | 元神：理、心、意、德 | 意识、觉察、道德工夫 | 心性自评量表 |
| 命 | 元炁：法、息、形、功 | 形体、气脉、生理机能 | 体能与恢复速率 |
| 性命双修 | 二者并重，"无命则性无依，无性则命无主" | 心身交互影响 | **剂量—效应关系**：命功剂量 vs 性功表现 |
| 炼形养心 | 调形正体＋调息调神 | 自主神经与内分泌 | |

> **本书的增值点**：内丹家说"双修"，但不给配比。本书要问的是：**命功与性功各投入多少，收益如何分别计量？**

## 四、可直接转成实验的四个抓手

| 抓手 | 内丹原语 | 转成的实验设计 | 需要的对照 |
|---|---|---|---|
| **玄关一窍** | 脐后肾前一穴，意到即开 | 定位刺激 → 观测丹田残留变化 | 有刺激／无刺激；位置随机 |
| **取坎填离** | 下位能量上行 | 分步引导 → 观测上部／下部残留此消彼长 | 顺序正向／反向（**互为镜像实验**） |
| **攒簇五行** | 五气集中调节 | 训练组 vs 不训练组，测五行残留分布熵 | 自身前后测 + 平行组 |
| **火候·沐浴** | 真气薰蒸、神水灌溉 | 控时 vs 不控时的产出率差异 | 时间窗口固定 |

> **这四行是本书最重要的接口**：它们把道教千年的"过程控制语言"接到了现代"实验设计语言"上。**主角不是要证明古人错了，是要给古人的方法装上对照与复现。**

## 五、意识层级的现代对应

| 内丹分层 | 原义 | 神经科学对应 | 可测性 | 本书态度 |
|---|---|---|---|---|
| 常意识 | 日常思维 | 表层意识 | 易测 | |
| 潜意识 | 情绪与习惯 | 自动化加工 | 中测 | |
| 元意识 | "一点灵明"，遗传本能意识库 | 自我觉察的核心 | 难测 | |
| 阴神 | 人格化的潜意识 | — | **不可测** | 暂标"不可判定" |
| 阳神 | 元神的凝聚体，成熟人格 | — | **不可测** | 暂标"不可判定" |

> **本书立场**：阴神／阳神**不否认、不证实**。系统标"不可判定"，主角不硬下结论——这正是 §4.5 失败线第 3 条"可判定边界"的技术落点。
