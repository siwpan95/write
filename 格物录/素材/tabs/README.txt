# 素材 tabs · 使用规范

> 与 `00-索引.txt` 配套。索引说"有什么"，本文件说"怎么用"。

## 一、三条硬纪律

### 1. 名称必须具体，不许模糊
正文出现某实体时，**必须从 tabs 取具体名称**。
- ✗ 他服了一颗丹药，疗效不错。
- ✓ 他服了一颗**固本培元丹**，当日排毒时段缩短约两刻。

**理由**：实验报告体的公信力来自具体。模糊名＝未观测。

### 2. 原创必标 `〔原〕`
原著名词与本书原创条目在正文中不加区分，读者会误以为原著有载。
- 原著既有 → 直接用名
- 本书原创 → 首次出现时括注，如"青石门〔原〕"

**理由**：同人最忌"把原创当原著"——这会误导考据读者。

### 3. 查不到就说查不到
tabs 里没有的，**写"未见明确记载"**，不臆造。
修仙界资料本身残缺（大量丹方失传、灵草无载），**这份残缺本身就是本书的命题**。

**理由**：§4.5 失败线第 3 条——"他始终无法证明机缘是否存在"。作者自己不能作弊。

## 三、新增条目的规矩

1. 先查是否已有；确需新增则**补进对应文件**，标 `〔原〕`。
2. 每张表末尾的**来源栏必须同步更新**。
3. 新增后回 `00-索引.txt` 检查是否需要改分类轴说明。
4. **不动既有条目的内容**——已入表即为"已核实"，改动须在来源栏注明订正与日期。

## 四、AI 续写时的提交清单

每次生成新章前，向 AI 提交：
1. 本章所属卷的目标线与卷内阶段（见 `02-世界观圣经` §4）
2. 上一章的《台账》（Master Ledger）
3. 本章涉及的 tabs 文件（按上表"写作时按类取用"挑选，不必全给）
4. `03-文体规格` §1.3 九段式骨架 + §1.4 语体规则

**理由**：tabs ＋ 台账＝外置记忆。AI 不必携带全书设定，只携带"本章用得上的"，可大幅降低设定漂移与设定膨胀。

## 五、本目录的边界

- 本目录是**素材**，不是 SSOT。**设定冲突以 `02-世界观圣经-格物录.md` 为准**（工作区规范 §四）。
- 本目录**不收正文**，只收可查的实体与规则。
- 本目录**随正文推进增补**，不预先穷举——修仙界的资料本来就不全。
