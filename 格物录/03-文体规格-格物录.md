## §1 正文文体规格：实验报告体

### §1.1 体裁定位与先例

**文体原型链**：实验报告规范（科研原始记录）→ SCP 基金会"临床腔"（去口语化、精确简练、无主观情绪）→ 《火星救援》第一人称日志体 → 国内网文实验报告体（《科学修行笔记》《修仙从研究基因开始》《蓝星升维实验报告》）。

**已核验的本土实践特征**（用于对齐，避免自创一套读者不认的格式）：

| 特征 | 已被验证的做法 |
|---|---|
| 章节标题 | 不用章节序号，用**实验编号 / 观测方案 / 记录条次**（如"癸卯年六月初十观测预案""残片初步分析完成"） |
| 段落结构 | "条件设定—操作步骤—结果观测—数据记录"四段式 |
| 语体 | 去诗意化技术说明书；术语化表达；**无主观形容词** |
| 数据 | 所有状态可量化；每章末必含一个可量化参数作为节奏锚点 |
| 人物 | 性格通过"实验选择"展现，不写心理活动；对话如访谈实录 |
| 悬念 | 靠"未解释的异常"维持，而非靠情绪 |

### §1.2 本书的文体决策：三层嵌套（关键）

先厘清一件容易搞混的事：**本书是同人小说，不是续写或番外**。同人的义务是承接原作的**世界规则**，而不是模仿原作者的**叙事腔**。所以本书不必追求"像《凡人修仙传》"——反而要主动走开：原著是第三人称限知叙事，本书是**第一人称实验记录**，两者的语感本就应当明显不同。

在这个前提下，纯报告体的真正短板是**文体自身的两个缺陷**，与原著无关：

1. **人物扁平**：性格只能通过"实验选择"展现，人物会退化成功能键。
2. **情绪真空**：全篇只有数据和判读，读者得不到"有人在场"的实感，情感浓度趋近于零。

因此本书采用**三层嵌套**，每层承担不同职责，互不稀释：

| 层 | 载体 | 文体 | 占比 | 职责 |
|---|---|---|---|---|
| **A 层 · 观测日志** | 主角自用记录本（皮质簿子 / 《格物录》手抄本） | **实验报告体**：条件—步骤—观测—数据—判读 | 约 55% | 承载知识线：假说、实验、数据、结论 |
| **B 层 · 现场批注** | 主角口述的**原始记录人**旁白（药奴同伴、后来的学徒、对手） | **口述实录**：人称混杂、方言、断句、有错别字与误解 | 约 25% | 承载情感线与人味；直男在此暴露 |
| **C 层 · 官方文书** | 门派公文、宗门卷宗、坊市告示、青石门执事呈报 | **公文/clinical 腔**：格式死板、避重就轻、官样文章 | 约 20% | 承载压迫感与制度性冲突；"官方版本"与 A 层记录的**矛盾**本身就是冲突源 |

**为什么 B 层不可省**：解法不是加抒情，而是**让一个不懂科学的人去转述科学记录**——他的转述必然失真、必然带偏见、必然漏掉关键。B 层的"错误转述"与 A 层的"精确记录"逐条对照，读者自动获得：
- 情感（有人在替他记住那些被官方抹掉的东西）
- 人味（转述者的语气、方言、偏见）
- **主题回响**（真相与记录之间的落差，正是本书命题）

**为什么 C 层不可省**：C 层制造**"档案性失真"**——门派文书里写"试药童子九人，殁七"，A 层写"第七槽的人昨夜被抬走，未记录死因"。两条并置，无需一字评论，读者自行完成愤怒。

**关于"直男"与幽默**：参照《火星救援》——主角的自嘲承担全部幽默与人味，正文保持冷硬说明书调性。本书的对应位是**让直男的技术性发言本身就好笑**（"多一碗会死得快吗？我想知道概率"），作者不代为抖机灵。

### §1.3 每章的标准骨架（可直接套用）

```
【格物录 · 记录 No.0XX】
时间：越国历 XXX 年 X 月 X 日 夜（石梁坊，青石门外院药圃）
天气/环境：阴，灵气浓度低于昨日约 ——（此列为修仙界独有的"环境参数"）
观测对象：XXX
假说 H-XX：……
  决定性实验：若……则应观察到……
材料与来源：XXX（残渣，取自第七槽）
步骤：1. …… 2. ……
数据：
  | 样本 | 变量 | 读数 | 备注 |
  | n=1 | | | |
  | n=2 | | | |
异常与处置：……
判读：不可判定（缺对照，n=3）
下一步：……
（夹注，字迹与正文不同）：一句 B 层转述，或一句 C 层公文引文
```

**硬性约束（每章必须满足）**：

1. **每章至少一个可量化参数**（读数、比例、时长、温度、次数），作为节奏锚点。
2. **每章至少一处"不可判定"或"待复核"**——维持否证优先的系统调性，也是本书区别于爽文的关键手感。
3. **每章至少一处失败/异常**——不得只有成功，否则违反"可复现性"设定，且失去张力。
4. **每章至多一处抒情**，且必须落在 B 层或夹注里；A 层禁止出现"我感到""我很痛苦"这类词，改写为客观指标（如"心率上升至 ___；记录：失眠"）。
5. **章末必须有一个未解释的异常项**（对标《火星救援》的"下一个问题"结构与《科学修行笔记》的章节标题即宣言）。

### §1.4 冷硬语体的具体规则

**允许**：术语化、量化、被动句式、条件句、"本记录不构成结论"、"此处数据缺失"、"按 §3.4 级联次序"。

**禁止**：
- 抒情形容词与副词（"阴森的""极其""美丽"）→ 一律改为可测量的物理描述（"石屋温度低于体感三度；药渣表面反光"）
- 心理活动的直陈 → 改写为行为记录 + 结果数据（"他没有说话。第三次记录尝试后停止书写"）
- "众人皆知""自古以来" → 一律改为"门内册载""据卷宗抄本"
- 战斗中的华丽描写 → 用机制与参数写（"剑气接触护罩后 0.3 息内出现三条应力纹；护罩未破"）

**参照《火星救援》的核心手法**：主角的吐槽与自嘲承担了全部幽默与人味，而正文保持冷硬说明书调性。**本书的对应位**：让"直男"承担这一功能——他的直白技术性发言本身就好笑（"多一碗会死得快吗？我想知道概率"），且不需要作者代为抖机灵。

### §1.5 AI 创作友好性设计（生产流程价值）

这种体裁对 AI 辅助写作**极其友好**，因为它把"创作"降维成了"填表"：

1. **结构固定**：每章九段式骨架，提示词可固化，AI 每次产出格式一致，不会漂移。
2. **状态可续接**：主角的实验编号、假说编号、数据台账构成**外置记忆**——AI 无需记住前文细节，只需读取台账表即可续写，不会写崩。
3. **冲突可枚举**：每章的"异常与处置"栏位强制要求给出一个可解决的工程问题，杜绝水文。
4. **语气可锚定**：A/B/C 三层各有 12 条语体规则（§1.4），构成可检验的风格约束。
5. **可增量修订**：某章结论推翻时，只需改台账对应行 + 增补一条记录，不必重写全章。

### §1.6 配套产出：《台账》（Master Ledger）

本书需同步维护一份外置台账，作为"格物录"在读者可见层的实体化。字段固定：

| 字段 | 说明 |
|---|---|
| 记录编号 | No.0XX，全书唯一，跨章连续 |
| 时间 | 越国历 + 年月日 + 时辰 |
| 假说 | H-0XX 编号，跨章引用 |
| 决定性实验 | 一句话，写明"什么结果能证明它错" |
| 数据 | 关键读数或表格摘要 |
| 判读 | 结论状态：已确证 / 已否证 / 不可判定 / 待复核 |
| 状态 | 是否已公开（决定该结论能否被他人引用） |
| 影响 | 若确证，将改动哪一层目标线（理论线 / 应用线 / 人生线） |

**台账的三条纪律**（与 §3.2 规则二对应）：
1. **否证项永不删除**，只在状态栏标注"已否证"及否证它的记录编号。知识的方向性由被推翻的假说保留，不由被推翻的记录消失。
2. **"未经对照"标记永久继承**。凡引用了带此标记的数据而得出的结论，自身也继承此标记，并向下传递。
3. **公开状态单独一栏**。未公开的结论不计入认知点。这条让"藏一手"成为有代价的选择，而不是无成本的小聪明。

**读者可见性设计**：建议每卷卷末附一次台账节选（正文已含部分），使读者能像审稿人一样复核主角的推理链条——这是本赛道少见的"可互动性"，也是本书相对于纯爽文型科学修仙文的体验增量。

**AI 续写用法**：每次生成新章前，向 AI 提交三样东西——①本章所属卷的目标线与卷内阶段；②上一章的台账全文；③本章的九段式骨架提示（§1.3）+ 语体规则（§1.4）。台账即外置记忆，可避免长程生成的设定漂移。
