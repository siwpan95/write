## 纪律

1. **正文与素材分开**：成稿正文只放卷/章文件，废稿与中间版本进 `_archive/` 或 `杂项/历史/`。
2. **分析报告与素材同放但命名可辨**：报告用 `《作品名》…分析报告.md`，素材用原名 `.txt`。
3. **每个作品项目有入口总览**：`项目梳理总览.md` / `作品总览.md` 为唯一顶层索引，结构变更须同步更新。
4. **`作家助手/LocalHistory/` 是编辑器产物**，不是版本控制手段 —— 正文/设定已由 git 仓（`siwpan/write`）版本化，LocalHistory 不进版本库。
5. **已冻结/完结卷不回改前文**：废土旅法师五卷完结；综网第一卷冻结 —— 漏洞一律用后文或补漏任务表解决。
