## 一、许可口径

1. 本仓（`siwpan/write`）为作者自有工作区，仓内 14 部小说均为作者自有或同人创作；零件库是**作者对自己作品的自我提炼**，不存在第三方授权问题。
2. 涉及原作 IP 的项目（战锤42、廓者未名夜用战锤四神体系；蜀山用原著事实底座）**只提炼本项目原创的机制骨架**，不提炼原作表达；来源文件本身已按各项目 IP 合规前置模板处理。
3. 外部方法论来源（抽象阶梯、思想／表达二分、Sanderson 三定律、Narrative Legos 等）见 `07-调研` 的 S1–S18，本表只登记**零件提炼自哪部自有作品**。
4. **借用边界**：所有零件只到 L1/L2；L0 内容（专名、台词、具体情节链）留在本表作溯源，不进可调用零件描述。

## 四、调色盘自检（交付前必做）

1. 检查每张零件的「一句话定义」「压力机制」是否出现原书专名 → 有则退回。
2. 检查同一零件的来源是否只有单一作品 → 若只有一源，确认 `借用方式` 已写明切断点／主题综合，且 `适配基线` 已填。
3. 检查 L0 内容是否只在本表出现 → 零件分册里出现原文台词即违规。
4. 涉及 IP 的零件（记录即存在、职格互斥等）确认只借机制骨架，不含原作表达。
5. **结构同构检查（`00` §六之后，人工必做）**：本零件的咬合闭环与来源作品是否**一一对应**？
   环数／承压者／代价物／出路四项中至少一项必须不同。**全同＝L0 换名，不是 L2 抽象，退回重炼。**
   > 前四条查「有没有抄句子」，这一条查「有没有抄结构」——**只过前四条不算过**。
