# 08 · 调用记录 M-01：蜀山卷四《幻波池》（376–500）

> 建立：2026-11-19｜**本库第一次真实课题调用**
> 目的：不是设计新剧情，而是用零件库的语言**复验一个已经写好的卷纲**，看它能不能解释、能不能预测、在哪里卡住。
> 依据：`蜀山之撼天凡蚁登天路漫漫/03E-卷四章纲-逐章.md`（125 章逐章章纲，卷四尚未开写）。
> 结论先行：**三件主件全部命中，但暴露出 5 处字段摩擦——其中 1 处是该卡激活线枚举不全的实质缺陷。**

---

## 一、课题（严格照 `13` §1.5 的三问填写）

| 项 | 填写 |
|---|---|
| **课题** | 一个人获得了「改写他人命运」的权力，而这个世界判定「改写必付代价、代价按次从他身上扣」——他会在写谁的时候停下？ |
| **体验目标** | **不安的期待**：读者看着他一步步逼近一条线，而他自己不觉得 |
| **核心循环** | 每写一个人 → 事成（他要的结果拿到）→ 身上少一样「认得出人」的东西 → 他记不清那个人为什么重要 → **于是更能下手** → 直到写到自己 |
| **课题性质** | 压力命题（可被结构矛盾回答）✅ 不是主题陈述 |

> **与卷三的区别**：卷三是"他没有资格，世界不认他"（外部施压）；卷四是"他有资格了，代价开始从内部扣"（内部流失）。
> **这就是为什么原有 19 件不够用**——19 件全部是「世界逼你」，没有一件是「你自己想写，世界只负责收账」。

## 三、挑件与验通电

| 件 | 角色 | 通电检验（`00` §五 D） | 结论 |
|---|---|---|---|
| `WB-INST-0001` 记录即存在 | **前提**：写人入局能生效，是因为"被写成什么"决定人怎么活 | 主角一接入就被卡：他自己只有半个名（卷三末状态） | ✅ 是 |
| `WB-INST-0002` 不可逆代价 | **结算**：每次写必付，且不可赖、不可代付 | 第一次改别人的名（423 章）当场付，且付的东西当场可验 | ✅ 是 |
| `WB-MECH-0020` 越用越像它 | **驱动**：付的代价是「认得出人」的能力，越写越认不出 | 主角第一次写人后，旁人先看出他"不太一样"（436–439 章：他记不住脸） | ✅ 是（**但见摩擦 1**） |
| `WB-IFACE-0018` 通电接口 | **元零件**：验幻波池／谱房位置是否成立 | 主角接入幻波池（376–380）：池水认出他、水里有字、池底有碑 | ✅ 成立 |

**未调用但考虑过的**：

| 件 | 为何不调 |
|---|---|
| `WB-HIST-0013` 焚卷旧账 | 卷四的"应焚之物"是**他自己写的**，不是历史遗留的焚卷——用了会变成"查旧账"，不是"写自己" |
| `WB-INFO-0017` 划名机制 | 卷四的手段是**改写**，不是划除；调用它会把"改"写成"删"，损失核心 |
| `WB-ECON-0012` 名分兑换率 | 卷四不涉及资源兑换，名分只作刻度（由 `0016` 承担） |

## 四、咬合（三件如何互咬，用 `00` §五 A 的二元组格式）

```
WB-INST-0001 记录即存在
   │
   ├─制度隶属→ WB-INST-0002 不可逆代价     「改写要付账」
   │                    │
   │                    └─资源依赖→ WB-MECH-0020 越用越像它   「付的账是认得出人」
   │                                        │
   └─制度隶属────────────────────────────────┘
                                    「而认得出人，正是他还能被写进册的前提」
```

**闭环**：

```
他要让人得到应有的结果
   → 必须改写记录（0001 允许，0002 收费）
   → 收费方式是从他身上扣「认得出人」（0020）
   → 认不出人之后，他改谁都不再犹豫（因为那个人对他不再重要）
   → 于是写得更快
   → 直到他认不出自己 → 写下「应焚之物」（468 章）
```

> **这就是「不用作者安排反派，世界自己逼角色做选择」在卷四的形态**：反派是**代价的复利**，不是人。

## 五、拼装与白盒（`13` §8.6 三问）

| 白盒三问 | 答 |
|---|---|
| ① 本站核心压力机制，一句话说清？ | **「他能改别人的名，但每改一次就认不出一个人；要确认自己还是自己，他必须继续写——而继续写就更快认不出。」** ✅ 一句话，不需要说明段 |
| ② 主角碰撞一次，逼出可信且两难的选择？ | 451–453：执事确实失察，但"不至于是这个错"——写，还是写？他犹豫三天，最后写了，**落笔时手不抖**（454） ✅ 两难且可信 |
| ③ 这个选择只能在此站发生？ | ✅ 只有幻波池能照出他的名字（379–380 水里有字、池记得他；401 池底有碑）——**别处他看不见自己的名，就写不了自己** |

**适配基线落地**（改了什么／没改什么）：

| 项 | 处置 |
|---|---|
| 记录载体 | 改为「册／牌／墙上的印」（卷四实际用了木牌 441、墙上的字 495） |
| 代价物 | 改为「认得出人的能力」（不是原作的人性／记忆碎片）——**这是本项目自研的切断点以下** |
| 计量方式 | 改为「一人一格」的**非数值计数**（少了七个／一百块木牌） |
| **未改** | 「越长进越不像人」「改写必付不可逆代价」「被写才算数」三条内核 |

## 六、实战摩擦（**本次调用最有价值的产出**）

> 这一节比上面五节都重要。**摩擦点不改，字段规范就只是纸面规范。**

### 摩擦 1：`施压就绪` 没有区分「压力生效」与「压力可见」

| 项 | 内容 |
|---|---|
| 现象 | `WB-MECH-0020` 填的是「第一次动用高阶能力，旁人当场看出他不太一样」。但卷四实际是：**第一次看不出来（423 写人后无明显异常），第三次才被旁人发现（436 他记不住脸）** |
| 性质 | 不是填错，是**字段表达力不足**。同化型压力的特征是**延迟累积**，用「立刻」这个词会误导调用者 |
| 处置 | `00` §五 D 补一句：**「若压力是累积型的，写「首次生效」与「首次可见」两个时点」**。本卡已改为「是——首次写人即记账；首次被旁人看出在第三次（记不住脸）」 |

### 摩擦 2：`落地接口` 的「计量物」隐含了「可数」，装不下「能力型代价」

| 项 | 内容 |
|---|---|
| 现象 | `WB-INST-0002` 的落地接口写「`资源依赖`→ 计量单位（能折算成什么）」。卷四的代价是「认得出人的能力」——它**不可数、不可折算**，只是"少了一样" |
| 性质 | 措辞窄化。原写法推着使用者去找「几斤几两」，而好代价常常是**能力／关系／资格** |
| 处置 | `落地接口` 的承载物表述改为「**可折算的计量物或可指认的减项**」。卡内不改（原文已够用），在 `00` §五 A 补注 |

### 摩擦 3：`WB-IFACE-0018` 没区分「位置型接口」与「动作型接口」

| 项 | 内容 |
|---|---|
| 现象 | 卷四主角接入的不是"幻波池这个地方"，而是**"能写人"这个动作**。池子只是让他看见名字的条件，不是接口本身 |
| 性质 | 接口类型未分级。用「位置」一词会让调用者去找地点，而真正可接入的常是**一件可做的事／一个可承的身份／一次可做的交易** |
| 处置 | `WB-IFACE-0018` 卡内补一行：接口四型＝**位置／差事／身份／交易**；判据不变（接入即被卡） |

### 摩擦 4：`调用记录` 的触发条件原设「复用 ≥2 次」，实战第一次就没处记

| 项 | 内容 |
|---|---|
| 现象 | 卷四是**首次调用**，按原规则「≥2 次才填」→ 第一次的经验无处落地 |
| 性质 | 规则设反了。**第一次调用才是摩擦最密集的时候**，恰恰最该记 |
| 处置 | 已在 `00` 字段 16 改为「**复用 ≥1 次即填**」。本次即为第一条记录 |

### 摩擦 5：`WB-INST-0001` 的「行程激活差异」只列了三条线，漏了「改写」

| 项 | 内容 |
|---|---|
| 现象 | 该卡写的是三条线：补录（加法）／划名（减法）／焚卷（归零）。但卷四用的是**第四条线：改写**——不改数量、不改有无，只改"写成什么"（把执事写成"失察"） |
| 性质 | **实质缺陷**，不是措辞问题。原三线是「有没有／有多少」，漏了「是什么」。而"改内容"恰恰是记录类世界最常用的施压方式 |
| 处置 | 该卡补第四条线：「**改写线（改性质）**→ 名还在、人还在，但"他被写成什么"变了；不可申诉之物＝改后的版本会覆盖改前的，见证者只能靠旧行并存来追」 |

## 七、调用结论

| 项 | 结论 |
|---|---|
| 三件主件能否解释卷四的驱动力 | ✅ 能，且能预测"他必然写到自己"（因为代价是认不出人，而认不出人会加速写） |
| 卷四原有设计是否需要改 | ❌ **不需要改一字**。零件库只是给它补了一套语言，证明该设计自洽 |
| 库是否需要补件 | ✅ 已补 `WB-MECH-0020`（本卷第一需求）。若没有它，卷四只能用"代价记账法"硬套，会丢掉"代价改变的是人本身"这一层 |
| 剩余风险 | 卷四开写时若把代价写成"可数的记忆条数"，会退化成 `WB-MECH-0004` 记账法，失去 0020 的同化性质 → **开写前须在施工单标注：代价按「人」计，不按「条」计** |
