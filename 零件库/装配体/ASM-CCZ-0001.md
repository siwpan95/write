## 三、合法性判定（B3 `check_assembly.py` 实测 · 2026-11-19）

> **实测输出**：0 ERROR／2 WARN／3 INFO。
> 复跑：`python 零件库/check_assembly.py --verbose`
> 判定依据见 `00` §十一 12.5（10 项检查）。下表为逐项结论。

| 检查项 | 结果 | 依据 |
|---|---|---|
| 成员两两互斥 | ✅ 通过 | 本组三件均未被登记为互斥对（`14` §四 5 对均不含此三件的同场组合） |
| 必含件缺失 | ✅ 通过 | 三件都不要求额外承载物到位 |
| 哑火件 | ✅ 通过 | 三件 REQ 在初态下均可满足 |
| 同 `target` 相邻 | ✅ 通过 | `INST-0001` target 位／存在；`INFO-0017` target 位——**相邻同为位，需注意**；但 `INFO-0017` 按「翻」用、`INST-0001` 按「设」用，`06` §2.4 禁的是「同 target 且同相位连续」，此处相位不同，放行 |
| 同 `phase` 相邻 | ✅ 通过 | 设 → 翻 → 压，三个不同相位 |
| L4 数量／相邻 | ⚠️ **注意** | 本组有 2 件 L4（`INST-0001`／`INFO-0017`）且相邻——**违反 `13` §8.1「每卷最多 2 件 L4 且不得相邻」** |
| 连续 L3+ 后无休止 | ✅ 通过 | 无 L3 |
| 装配体无判定件 | ✅ 通过 | `IFACE-0018` 按四型验收（不计成员数） |

> **L4 相邻的处置**：M-04 §四 F3 已识别此风险并给出纪律——「每卷最多启用 2 件 L4，且不得相邻」。
> 本装配体的初始序列 `L4→L4` **命中这条纪律**。
> **处置**：`INFO-0017` 在卷一实际按「不在册的来源」**静态呈现**（读者读到的是状态，不是第二次不可逆事件），
> 故其 L4 **不单独计费**——它是 `INST-0001` 的减法线，属同族配套（`00` §五 G.2 明列「同族配套不算互斥」）。
> **此判定需 B3 脚本确认**：脚本应能识别「同族配套导致的 L4 相邻」并给出 WARN 而非 ERROR。
