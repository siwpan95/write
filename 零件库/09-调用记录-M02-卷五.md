# 09 · 调用记录 M-02：蜀山卷五《光明境》（501–625）押名线

> 建立：2026-11-19｜**第二次真实课题调用**
> 与 M-01 的区别：M-01 是**复验**（卷四章纲已写好，用零件库解释它）；**M-02 是补缺设计**（卷五章纲缺押名线，用零件库补上）。
> 依据：`蜀山之撼天凡蚁登天路漫漫/03F-卷五章纲-逐章.md`（125 章逐章，卷五未开写）＋ `02E` 卷五段要求。
> 硬约束（`03F` 头部原文）：**「03F 当前不押名 → 若直接照 03F 写，这条线在卷五断掉，卷末交付落空。」「未补齐不得开工。」**

---

## 一、课题

| 项 | 填写 |
|---|---|
| **课题** | 一个人只有「半个名字」，因此他没有自己的名可以抵押；要办成事只能借力，而借力必须押上别人的名字——他会在第几次借的时候，开始拿不愿意的人去押？ |
| **体验目标** | **不安的期待**（比卷四更强：卷四他损耗自己，卷五他损耗别人） |
| **核心循环** | 想办成 → 押一个名字 → 事成 → 债主来收 → 要还就得借更大的力 → 押更重的名字 → **债务螺旋** |
| **课题性质** | 压力命题 ✅ 且比卷四更硬：卷四的代价是「他自己」，卷五的代价是「别人」 |

> **为什么这是卷五的真课题**：`03F` 的卷任务是「极昼白光让阙文彻底消失，他第一次什么都看不见；他选择不写结局」。
> 但「不写」不是因为高尚——是因为**他没得写了**（`WB-GEO-0023` 专长归零），而没得写之后还要办事，就只能借力。
> **「借力 → 押名 → 还不上」是「不写」这个选择的经济基础。** 没有押名线，卷五的「不写」会变成道德姿态。

---

## 二、检索

| 步 | 动作 | 结果 |
|---|---|---|
| 1 | 课题要什么压力 | 交易（借力）＋施压（还不上）＋阻碍（没有自己的名可押） |
| 2 | 查 `01` 功能轴 | 交易 3 件、施压 9 件、阻碍 4 件 |
| 3 | 初筛 | `WB-ECON-0012` 名分兑换率（自己的身份折资源）、`WB-INFO-0016` 名分阶梯、`WB-INST-0001` 记录即存在 |
| 4 | **发现缺口** | `0012` 讲的是**自己的**身份换资源，讲不了「拿别人的名字去押」；`WB-INFO-0017` 划名机制讲的是**抹除**，不是**抵押**。两者都不覆盖 |
| 5 | 处置 | 补 `WB-ECON-0022` 押名担保（本卷第一需求，v1.3 新增） |

> **这是本轮扩容的第一处拉动**：押名不是"为补分类表"，是卷五缺它就不能开工。
> 而且它暴露了 v1.2 的一个合并错误——「押名」原先被并进 `WB-INFO-0017` 的来源叙述（写作「蜀山押名／销名链」），
> 属**合并过头**：被押者并没有被抹除，他只是被**转手**了。

## 三、挑件与验通电

### 核心咬合三件

| 件 | 角色 | 通电检验 | 结论 |
|---|---|---|---|
| `WB-ECON-0022` 押名担保 | **核心**：借力的抵押物是他人的名 | 主角第一次借力，当场被要求「押一个名字」 | ✅ 是 |
| `WB-INST-0001` 记录即存在 | **前提**：押名能成立，因为名在册、能被划 | 他自己只有半个名（卷一至今），一接入就被"你不在册"卡 | ✅ 是 |
| `WB-INFO-0016` 名分阶梯 | **刻度**：能借多少力，取决于他被承认到哪一级 | 办事被问「你算几级」 | ✅ 是 |

### 环境前提一件（**分层说明，非第四件核心**）

| 件 | 角色 | 说明 |
|---|---|---|
| `WB-GEO-0023` 专长归零 | **环境**：光明境让他看不见阙文，所以"自己写"这条路断了 | 它不是咬合件，是**使咬合成为必然**的条件。没有它，主角可以自己写，不必借力 |

### 元零件一件

| 件 | 角色 | 判定 |
|---|---|---|
| `WB-IFACE-0018` 通电接口 | 验「借力」这件事本身是不是接口 | ✅ 成立——它是**动作型接口**（M-01 补的四型之一），不是地点 |

## 四、咬合

```
WB-GEO-0023 专长归零（环境）
   │「他看不见阙文了，自己写不了」
   ↓
WB-ECON-0022 押名担保 ←─制度隶属─ WB-INST-0001 记录即存在
   │「借力须押名」              「名在册才押得动」
   │
   └─制度隶属─→ WB-INFO-0016 名分阶梯
                    「能借多少，看他被承认到几级」
```

**闭环**：

```
他要办事（查清那本三十年前的册为什么有自己的笔迹）
   → 专长归零，自己写不了（0023）
   → 只能借力，借力须押名（0022）
   → 他自己只有半个名，押不了（0001 的"你不在册"）
   → 只能押别人的 → 押了就得还 → 还不上，那个名字就没了
   → 他要还债，只能借更大的力 → 押更重的名字
```

> **与卷四的对照**：卷四是「他损耗自己」（`WB-MECH-0020` 同化），卷五是「他损耗别人」（`WB-ECON-0022` 押名）。
> **同一个主角，两卷的压力方向相反**——这是长篇里避免"重复受难"的关键，也是本库最该被复用的地方。

## 五、行程激活差异的实战验证（**本件的核心发现**）

`WB-ECON-0022` 的 `行程激活差异` 一栏填了四种探针。本次调用发现：**同一个零件在两卷里的激活方式完全不同**，而这正是该栏的价值。

| 卷 | 激活方式 | 主角的处境 | 压力方向 |
|---|---|---|---|
| **卷三**（290 押于建） | **主动型**：他有能力自己写，但不想自己付代价，所以押别人 | 「我能做，但我不想付」 | 省代价 |
| **卷五**（押章南姑） | **被迫型**：他专长归零，自己写不了，只能借力 | 「我不能做，只能求人」 | 没得选 |

> **判据兑现**：`00` §五 C 要求「≥2 种探针，后果必须不同」。
> 这里得到更强的一条：**同一零件在不同卷可以由不同"处境"激活，且压力性质随之改变**（省代价 → 没得选）。
> 建议在 `00` §五 C 补一句：探针不必限于身份（逃亡者／执法者），也可以是**同一角色在不同处境下的不同读取**。

## 七、落点建议（**只给结构位置，不代写剧情**）

`03F` 未标押名落点。按零件库的咬合逻辑，三个候选位置各有不同代价，供作者裁定：

| 候选 | 结构位置 | 该位置的压力性质 | 代价 |
|---|---|---|---|
| **甲** | C10–C12（546–560，挖出写着"应焚之物"的旧册之后） | 他**想查清**这本册，但查不了 → 借力 | 动机最强；但可能挤压"上一世"这条线 |
| **乙** | C13–C20（561–590，看不见之后） | 他**想办事**但能力没了 → 借力 | 最贴合 `0023`；但中段已有较重情节 |
| **丙** | C21 前后（601–605，他说给人听之后） | 他**想让人记住** → 借力 | 与卷六「名与事不同寿」呼应最强；但离卷末太近，还债来不及 |

> **推荐乙**：它是唯一让「专长归零 → 必须借力」这条因果**当场闭合**的位置，且「还不上」的压力可以延到卷六，
> 与卷六的「他写事不写名」形成债务与偿还的对照。

**三条不可省的写法（零件卡 `适配基线` 落到正文）**：

1. **押名要写全名**——半个名押不动（否则 `0001` 的"你不在册"就白立了）。
2. **立约不可撤**——不许出现"事后赎回"或"换一个人押"（`0022` 的 `不可申诉之物`）。
3. **销牌时看见刻着谁**——卷三 370 已立此写法，卷五须同一口径（`02E` 明确要求）。

## 八、实战摩擦

### 摩擦 1：`WB-ECON-0012` 与 `WB-ECON-0022` 极易混用

| 项 | 内容 |
|---|---|
| 现象 | 初筛时我第一反应是调 `0012` 名分兑换率——因为都涉及"名分换资源" |
| 性质 | 两者只差一个字：`0012` 换的是**自己的**名分，`0022` 押的是**别人的**名。**字段层面没有防混机制** |
| 处置 | `0022` 卡内已加「与 0012 的区别」对照块；建议 `01` 台账的功能轴表把两者并列标注（`0012` 标「自名换资源」、`0022` 标「他名作抵押」） |

### 摩擦 2：`可咬合零件` 只记「能咬」，不记「咬的顺序」

| 项 | 内容 |
|---|---|
| 现象 | 三件都能互咬（0001↔0022↔0016），但实际拼装时有**严格顺序**：先有 0023 使能力失效，才轮到 0022；先有 0001 使名可押，才谈得上 0022 |
| 性质 | 字段缺"前置依赖"维度。咬合是**图**，现有字段只能表达**边**，表达不了**拓扑序** |
| 处置 | 本记录用「核心三件 / 环境前提 / 元零件」三层分组解决。建议 `00` §五 A 补一句：**拼装时须标注"哪件是使能条件（没有它另几件不成立）"** |

### 摩擦 3：`落地接口` 装不下「可被质押的名」这种复合物

| 项 | 内容 |
|---|---|
| 现象 | `0022` 落地要「可被质押的名」，而"名"既不是资源也不是机构——它是 `0001` 的产物 |
| 性质 | `落地接口` 的四类枚举假设承载物是**世界侧的东西**，但实际承载物可能是**另一个零件的产物** |
| 处置 | 本卡已在 `落地接口` 写「可被质押的名（须是能被划掉的东西）」并指向 `0001`。建议 `00` §五 A 补注：承载物可以是另一零件的输出，此时须写出该零件 ID |

### 摩擦 4：卷五「押名」缺章号，`调用记录` 无处落点

| 项 | 内容 |
|---|---|
| 现象 | M-01 的调用记录可写「423–468」；M-02 只能写到「卷五」，因为 03F 缺押名章号 |
| 性质 | **这不是字段缺陷，是上游缺口**——恰恰证明 `02E` 那句「未补齐不得开工」是对的 |
| 处置 | 本记录第七节给三个候选位置与推荐，供裁定后回填章号 |

## 九、调用结论

| 项 | 结论 |
|---|---|
| 零件库能否补上卷五的缺口 | ✅ 能，且给出三个候选落点与推荐（乙） |
| 是否需要改卷五已有章纲 | ❌ 不改。只在 C13–C20 之间插入押名动作，原有 125 章结构不动 |
| 库是否需要补件 | ✅ 已补 `WB-ECON-0022`（本卷第一需求）＋ `WB-GEO-0023`（卷五环境）＋ `WB-HIST-0024`（卷六结局） |
| 最大收获 | **发现 `0012` 与 `0022` 的混用风险**，以及"咬合是图、字段只能表边"这个结构性局限 |
| 与 M-01 的关系 | M-01 验"库能否解释已写的"，M-02 验"库能否补上没写的"——**两次都通过了，但 M-02 更接近真实使用场景** |
