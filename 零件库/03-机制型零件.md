# 03 · 机制族零件卡

> 机制族回答"世界靠什么因果链施压"：代价如何结算、能力边界在哪、什么条件下失效。
> **v1.2 起含两个分族**：机制族 5 件（`0004`–`0008`）＋ **诱惑族 2 件**（`0020`–`0021`，补功能轴「诱惑」空洞）。
> 字段定义见 `00`；来源逐条见 `99`。**均为 L1/L2 抽象，不含原书专名与数值。**

| 抽象层 | **L2** |
| 来源登记 | `SRC-002`（蜀山 机制台账 M-05）＋`SRC-014`（奇门遁甲 字债五档）｜提炼至 L2 |
| 借用方式 | 主题综合 |
| 借用范围 | 借「代价须可数、可累加、归因唯一、逐档递进不可跳档」的记账纪律；**未借**原书档名、具体数值、计量物 |
| 双标签 | `技术·规则 × 施压` |
| 一句话定义 | 每一次超常行为的代价都记入一本可查的账，数额可数、逐次累加，且每笔只能归因于一个确定原因 |
| 内核层 | 玩法层（账目随剧情累加，但记账规则属基础层） |

| 可咬合零件 | `WB-INST-0002` 不可逆代价（`制度隶属`）、`WB-INST-0001` 记录即存在（`制度隶属`） |
| 装配角色 | **参与**——装配体的常规成员，自身施压 |
| 互斥零件 | `WB-MECH-0008`（`前提取消`）——代价记账法要求每笔代价「归因唯一」；代价不可解要求语义永不解释——不可解释的代价无从归因，A 的唯一归因前提被取消 |
| 落地接口 | `制度隶属`→ 记账人／审计机构；`资源依赖`→ 可被折算的计量物 |
| 压力机制 | 想动用超常能力须先登记代价（**权限**）；账目累积到阈值触发不可逆后果（**代价**）；想继续用与想保住自我相冲突（**矛盾**） |
| band | **L2**（recover 判定）｜target: 财／身 ｜ recover: 条件（还账） ｜ 记在账上可还，但账可累积到不可还（那时升为 **L4**） |
| phase | **设 → 压**——先立「用必上账」，后按账额递增 |
| rule | REQ: 使用超常能力 ｜ EFF: 账上多一笔，数额当场可数 ｜ Δ: 财 −1（按量）；累计到阈值 → 身 −2 ｜ ELSE: 无（用了就上账） |
| 行程激活差异 | 审计者读到「账目是否平」；使用者读到「还剩几次机会」；旁观者读到「谁欠谁」——三种人看到同一本账的不同页 |
| 不可申诉之物 | 归因唯一——同一后果不得拆给多个原因，堵死"甩锅" |
| 施压时序 | **累积**｜第 2 次（账累到阈值才见后果）；原描述： 是——第一次使用即上账，数额当场可数 |
| 适配基线 | 须重写：计量单位、记账载体、阈值后果；**"归因唯一"这条不得改**（改了会引发跨批语义冲突） |

| 适配基线 | 换题材须重写三层的具体载体；**三层必须同时在场**这条是内核 |

> **生产教训**（来自卷三回检）：曾有批次把归因写成"墨老旧"，与已定的"手的问题"正面冲突——**三层归因法就是为防这类跨批语义漂移而立**。

## 机制族咬合示范

```
认知不可通约（基础层单常数：理解须重复才成立）
   └─资源依赖→ 重复次数即货币（玩法层经济）
   └─资源依赖→ 记录即存在（谁的话被写进册，谁的话才算数）

描述即约束 ──→ 篡改痕迹符号系统 ──→ 代价不可解 ──→ 代价记账法
    （文本有法律效力）      （改文本有痕迹）    （改了必付账）   （账可数可追）
```

> **关键区分**：`WB-INST-0002` 不可逆代价是**制度法**（不许赖账）；`WB-MECH-0008` 代价不可解是**认识论律**（不许问为什么）。两者咬合后，"求情"和"找捷径"两条出路同时被堵死。

## 诱惑族（v1.2 补功能轴空洞）

> **为什么单列**：原 19 件里，「诱惑」这个功能没有任何零件覆盖——所有零件都是"世界逼你"，没有一件是"你自己想变强，世界顺势收账"。
> 这类压力在长篇里不可替代：**反派缺席时，故事靠它推进**。
> 两件的共同结构：**给的正是你要的，收的正是你没想到的**。
