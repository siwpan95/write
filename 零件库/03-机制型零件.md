# 03 · 机制族零件卡

> 机制族回答"世界靠什么因果链施压"：代价如何结算、能力边界在哪、什么条件下失效。
> 字段定义见 `00`；来源逐条见 `99`。**均为 L1/L2 抽象，不含原书专名与数值。**

---

## `WB-MECH-0004` 代价记账法

| 字段 | 填写 |
|---|---|
| 零件名 | 代价记账法（可数、可累加、归因唯一） |
| 抽象层 | **L2** |
| 来源登记 | `SRC-002`（蜀山 机制台账 M-05）＋`SRC-014`（奇门遁甲 字债五档）｜提炼至 L2 |
| 借用方式 | 主题综合 |
| 借用范围 | 借「代价须可数、可累加、归因唯一、逐档递进不可跳档」的记账纪律；**未借**原书档名、具体数值、计量物 |
| 双标签 | `技术·规则 × 施压` |
| 一句话定义 | 每一次超常行为的代价都记入一本可查的账，数额可数、逐次累加，且每笔只能归因于一个确定原因 |
| 层归属 | 玩法层（账目随剧情累加，但记账规则属基础层） |
| 可咬合零件 | `WB-INST-0002` 不可逆代价、`WB-INST-0001` 记录即存在 |
| 咬合条件 | `制度隶属`→ 记账人／审计机构；`资源依赖`→ 可被折算的计量物 |
| 压力机制 | 想动用超常能力须先登记代价（**权限**）；账目累积到阈值触发不可逆后果（**代价**）；想继续用与想保住自我相冲突（**矛盾**） |
| 行程激活差异 | 审计者读到「账目是否平」；使用者读到「还剩几次机会」；旁观者读到「谁欠谁」——三种人看到同一本账的不同页 |
| 不可申诉之物 | 归因唯一——同一后果不得拆给多个原因，堵死"甩锅" |
| 通电状态 | 是——第一次使用即上账，数额当场可数 |
| 适配基线 | 须重写：计量单位、记账载体、阈值后果；**"归因唯一"这条不得改**（改了会引发跨批语义冲突） |

## `WB-MECH-0005` 归因链三层（源头／位置／触发）

| 字段 | 填写 |
|---|---|
| 零件名 | 归因链三层 |
| 抽象层 | **L2** |
| 来源登记 | `SRC-002`（蜀山 机制台账 M-01a ①源头／②位置／③触发）｜提炼至 L2 |
| 借用方式 | 切断点：借「三层归因不可混」的框架，自研切断点以下的具体缺陷 |
| 借用范围 | 借「一个身体／器物缺陷的完整因果必须分源头、位置、触发三层写，且三层同时在场」；**未借**原书的虎口墨渗、specific 字画、墨稀稠 |
| 双标签 | `技术·规则 × 揭示` |
| 一句话定义 | 任何持续性缺陷的成因都要拆成"从哪来／在哪发作／何时触发"三层，缺一层就会在不同批次里说法打架 |
| 层归属 | 基础层 |
| 可咬合零件 | `WB-MECH-0004` 代价记账法、`WB-INFO-0016` 名分阶梯 |
| 咬合条件 | `技术·规则`→ 缺陷载体（身体／工具）；`历史旧账`→ 缺陷如何来的 |
| 压力机制 | 想掩盖缺陷须先搞清三层归因（**权限**）；只写一层会被读者/机制反噬（**代价**）；"是手的错还是墨的错"两种归因相冲突（**矛盾**） |
| 行程激活差异 | 匠人读到「怎么修」；受害者读到「为什么是我」；调查者读到「哪层在说谎」 |
| 适配基线 | 换题材须重写三层的具体载体；**三层必须同时在场**这条是内核 |

> **生产教训**（来自卷三回检）：曾有批次把归因写成"墨老旧"，与已定的"手的问题"正面冲突——**三层归因法就是为防这类跨批语义漂移而立**。

## `WB-MECH-0006` 认知不可通约（单一常数推出文明）

| 字段 | 填写 |
|---|---|
| 零件名 | 认知不可通约 |
| 抽象层 | **L2**（基础层只有一个常数，玩法层自然长出整套文明——"基础层／玩法层分离"的示范样本） |
| 来源登记 | `SRC-019`（十三叩 χ 常数）＋`SRC-020`（译权制度／四十遍制／复述当量）｜提炼至 L2 |
| 借用方式 | 即插即用后重写咬合：借"单一变量推出全 civilization"的运作逻辑，变量本身全换 |
| 借用范围 | 借「理解无法共享 → 传达率可量化 → 制度／经济／礼仪三层都要补偿」的推演链；**未借**原作常数数值、城邦名、仪器名 |
| 双标签 | `技术·规则 × 施压`／`文化·信仰 × 揭示` |
| 一句话定义 | 一个物理或认知层面的微扰使"理解"无法直接共享，任何传达都必须付出重复／清空／校准的成本 |
| 层归属 | **基础层**（常数不动；由它长出的制度属玩法层） |
| 可咬合零件 | `WB-ECON-0011` 重复次数即货币、`WB-INST-0001` 记录即存在、`WB-MECH-0006` 仪器撒谎 |
| 咬合条件 | `技术·规则`→ 传达率常数；`制度隶属`→ 译权／校准机构；`资源依赖`→ 重复次数作为稀缺资源 |
| 压力机制 | 想让别人理解须先清空其旧知识（**权限／代价**）；传达率有硬上限，超过即失真（**矛盾**）；要教会一个人，先弄瞎他一部分 |
| 行程激活差异 | 宣讲者读到「要重复多少遍」；听众读到「我忘了什么」；伪造者读到「重复次数可以套利」 |
| 适配基线 | 须重写：常数是什么、传达率多少、由它推出的三项制度；**"从单一变量推出文明"的推演纪律不得改** |

## `WB-MECH-0007` 描述即约束（文字关住异常）

| 字段 | 填写 |
|---|---|
| 零件名 | 描述即约束 |
| 抽象层 | **L2** |
| 来源登记 | `SRC-018`（奇门遁甲旧案A §1 描述即约束）＋`SRC-013`（华夏克苏鲁 FL-01 描述即被注意）｜提炼至 L2 |
| 借用方式 | 主题综合 |
| 借用范围 | 借「语言／文字与超常对象之间存在因果：描述它就会约束或惊动它」的命题；**未借**原书的牢笼设定、不可名状之物名称 |
| 双标签 | `信息 × 施压` |
| 一句话定义 | 对异常的完整描述会改变异常本身——要么把它固定住，要么让它注意到你；删改描述等于改动现实 |
| 层归属 | 基础层 |
| 可咬合零件 | `WB-ART-0019` 篡改痕迹符号系统、`WB-HIST-0013` 焚卷旧账、`WB-INST-0002` 不可逆代价 |
| 咬合条件 | `信息`→ 文本有法律效力；`历史旧账`→ 旧版本与现版本的差异；`资源依赖`→ 谁能读／写这份文本 |
| 压力机制 | 想约束异常须写出准确描述（**权限**）；写错一处即反噬（**代价**）；"说清它"与"不惊动它"相冲突（**矛盾**） |
| 行程激活差异 | 记录者读到「一个字都不能错」；逃离者读到「别回头看别念出声」；篡改者读到「空白即机会」 |
| 不可申诉之物 | 描述一旦成立即成为现实的一部分，不可"收回来说错了" |

## `WB-MECH-0008` 代价不可解（现象可写，语义不解释）

| 字段 | 填写 |
|---|---|
| 零件名 | 代价不可解 |
| 抽象层 | **L2** |
| 来源登记 | `SRC-013`（华夏克苏鲁 FL-02）｜提炼至 L2 |
| 借用方式 | 切断点：借"代价不解释语义"的纪律，自研代价现象 |
| 借用范围 | 借「代价的现象可写、语义永不解释；未付代价视为能力未生效」；**未借**原书的具体器官／关系损失 |
| 双标签 | `技术·规则 × 揭示` |
| 一句话定义 | 超常力量每次调用都留下可观测的损失，但全书不给"为什么会这样损失"的解释 |
| 层归属 | 基础层 |
| 可咬合零件 | `WB-INST-0002` 不可逆代价、`WB-MECH-0004` 代价记账法 |
| 咬合条件 | `技术·规则`→ 能力调用；`信息`→ 叙述视角限制（只能写现象） |
| 压力机制 | 想用力量须接受一个永远不懂的代价（**代价**）；没有解释＝没有议价余地（**权限**）；想理解与不许理解相冲突（**矛盾**） |
| 行程激活差异 | 使用者读到「又少了什么」；旁观者读到「他好像变了」；研究者读到「无法建立因果模型」 |
| 不可申诉之物 | 语义永不解释——这是对读者与角色的双重纪律，破例即世界观崩塌 |

## 机制族咬合示范

```
认知不可通约（基础层单常数）
   └─→ 重复次数即货币（玩法层经济）
   └─→ 译权三派（玩法层制度）
   └─→ 仪器撒谎（器物层接口）

描述即约束 ──→ 篡改痕迹符号系统 ──→ 代价不可解 ──→ 代价记账法
    （文本有法律效力）      （改文本有痕迹）    （改了必付账）   （账可数可追）
```

> **关键区分**：`WB-INST-0002` 不可逆代价是**制度法**（不许赖账）；`WB-MECH-0008` 代价不可解是**认识论律**（不许问为什么）。两者咬合后，"求情"和"找捷径"两条出路同时被堵死。
