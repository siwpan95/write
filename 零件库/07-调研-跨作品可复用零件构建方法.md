## 3. 抽象分级规范

### 3.1 四级抽象（L0–L3）

借鉴 Hayakawa 抽象阶梯 [S7] 与法律界的「作品金字塔」[S11]，建议零件库采用四级：

| 级 | 名称 | 内容 | 可否入库 | 说明 |
|---|---|---|---|---|
| **L0** | 具体文本层 | 专名、台词、具体场景描写、独特情节链 | **禁止** | 属受保护的「表达」；照搬即抄袭 [S11/S12] |
| **L1** | 情节功能层 | 这个零件在故事里「做什么」：施压／阻碍／诱惑／揭示／供给 | **可入库（最低）** | 「角色名会变，功能不变」[S8]；属思想层 |
| **L2** | 结构模式层 | 功能如何连成可复用结构：门槛守卫、资源稀缺→信任重算、零和关系 [S4] | **推荐入库** | 对应 design pattern；可跨题材复用 |
| **L3** | 通用命题层 | 可被多世界复用的命题：「任何稀缺资源都会重算信任成本」 | **另册登记** | 这是「命题/主题」不是「零件」；只做校验参照，不按零件调用 |

> 判据：入库零件**至少到 L1，建议到 L2**；到 L3 应移入「命题库」而非零件库，避免零件库被抽象命题污染成空话。

### 3.2 提炼动作

- **剥离**：删去专名、台词、具体情节链，只留功能与结构 [S8/S12]。
- **爬梯**：按 S7，提炼时向上爬（去具体），复用时向下爬（落到本项目的具体文本）——只停一层会失衡。
- **换壳验证**：把零件放进完全不同的题材/地理，若仍成立＝已到 L1 以上；若不成立＝仍是 L0 的伪装。

### 3.3 借用与抄袭的边界（有出处的说法）

- **[有出处]** 思想/表达二分法：**题材、主题、文风、通用设定、历史事实不受保护；具体台词、情节链、人物关系受保护** [S11/S12]。
- **[有出处]** 抽象概括法（Learned Hand）：不断剔除具体细节，越往上越通用；到某临界点不再受版权保护 [S11]。
- **[有出处]** 固定场景（scenes a faire）：处理同一主题时自然出现、表达方式有限的桥段，不受保护 [S11]。
- **[有出处]** 「融梗」是灰区：法律只看独创表达是否实质相似；零散借一两个非核心桥段通常难认定，核心桥段/人设/结构大量对应可判「高级抄袭」[S12]。
- **[经验]** 本项目操作线：**零件库只收 L1/L2；任何 L0 内容只作「来源原文」留档在来源登记表，不进入可调用零件库**。

### 3.4 来源登记与许可

每条零件的来源登记必须回答四问（对接 `14`）：

1. 提炼自哪部作品／哪段文本？（可追溯 ID）
2. 抽象到哪一层？（L0 留档 / L1 功能 / L2 结构）
3. 借用范围？（借了什么、**没借什么**）
4. 借用方式？（切断点／主题综合／即插即用／自研；对应 §1.6）

> **[有出处]** Kitbashing 的原始纪律就是「借鉴部分、标注全部出处，即使不强制」[S2]。本项目把这条纪律制度化。

## 5. 分类法建议：双轴交叉

**建议：类型轴（名词，what it is）＋功能轴（动词，what it does），两轴交叉定位。**

| 轴 | 枚举（受控词表） | 作用 |
|---|---|---|
| **类型轴**（主轴） | 地理／制度／经济／历史／技术·规则／文化·信仰／组织·势力／信息 | 保证检索完备、不重不漏；回答「可以出现什么」 [S14] |
| **功能轴**（副轴） | 施压／阻碍／诱惑／揭示／供给／交易／催化 | 直接服务接口三问第 2 问；回答「咬合后施加什么压力」 [S13] |

**理由：**

1. **只用类型轴 → 名词垃圾场。** 中文素材库商品普遍按「角色/地理/历史/势力」分类，条目众多但普遍缺少「咬合/压力」字段 [S17]。Adazing 明确警告：工作表「不是剪贴簿，而是压力系统」[S13]。
2. **只用功能轴 → 失去世界质感与可检索性。** 同一「施压」在盐碱地、配给制、债契里是完全不同的手感。
3. **交叉后每零件有唯一坐标**（如 `制度×施压`、`地理×阻碍`、`信息×揭示`），既方便按类型查全，也方便按功能找「下一站需要一个施压件」。
4. **[有出处]** Sanderson 第三定律的 Interconnect 要求魔力彼此及与主题互联 [S9]——只有功能轴能表达这种跨类型咬合。
5. **[经验]** 两轴都用**受控枚举**，不放自由文本；新增枚举值需评审，防止分类法漂移。

## 6. 咬合条件与压力机制的填写规范 + 3 示例

### 6.1 填写规范（可操作）

**A. 咬合条件（字段 11）**
- 必须从四类枚举中选 ≥1：**地理邻接／制度隶属／历史旧账／资源依赖**。
- 写成二元组：`零件A —[条件类型]→ 零件B`。
- **禁止**写「与 X 有关联」「可配合」等不可检验表述。

**B. 压力机制（字段 12）**
- 必须落到三类 ≥1：**权限／代价／矛盾**。
- 必须写成可检验句式：**「进入者若想[目的]，须先[动作]，否则失去[具体物]」**。
- **禁止**写「增加紧张感」「营造压迫氛围」——不可证伪，判定为无效字段。

**C. 行程激活差异（字段 13）**
- 写明 ≥2 种探针（如 逃亡者／执法者／投机者／学习者）及各自后果。
- 只写一种 → 判定背景板，退回。

**D. 通电检验（字段 15）**
- 用 §8.5 问句：「主角一接入，世界是否立刻施压？」权限/代价/矛盾至少一项立刻生效才算合格。

### 6.2 三个填写示例

**示例 A｜`WB-INST-0042` 配给资格制（制度 × 施压）**

| 字段 | 填写 |
|---|---|
| 一句话定义 | 把生存资料与身份绑定、退出即失去生存资格的制度 |
| 抽象层 / 来源 | L2；`SRC-011`，提炼自某废土题材作品的「公司配给」，已剥离专名 |
| 借用方式/范围 | 主题综合；只借「身份绑定生存资料」的结构，未借原作历史与人名 |
| 咬合条件 | `资源依赖`→ 净水/医药；`制度隶属`→ 身份档案、检查站 |
| 压力机制 | 想领配给须交出身份档案（**权限**）；退出即注销资格、断供（**代价**）；公司要可管理劳动力、居民要离开公司的活路（**矛盾**） |
| 行程激活差异 | 逃亡者读到「封锁」；投机者读到「伪造档案的套利空间」；本地人读到「熟悉的羞辱」 |
| 不可申诉之物 | 身份档案注销后不可恢复 |

**示例 B｜`WB-GEO-0018` 无补给盐碱地（地理 × 阻碍）**

| 字段 | 填写 |
|---|---|
| 一句话定义 | 地表碱化、无自然水源，离开配给点即慢性失水的地带 |
| 抽象层 / 来源 | L1→L2；`SRC-004`，提炼自的区域包方法，去专名 |
| 借用方式/范围 | 切断点；借「地理逼人依附系统」的上层现成类型语法，自研切断点以下的摩擦层 |
| 咬合条件 | `地理邻接`→ 配给站；`资源依赖`→ 水与毒尘过滤 |
| 压力机制 | 想活过三天须待在配给点半径内（**权限**）；离开即持续损血、必须折返（**代价**）；"可通行的路"与"可生存的路"不重合（**矛盾**） |
| 行程激活差异 | 缺水者读到「必须折返」；走私者读到「检查站盲区＝路线」 |
| 层归属 | 基础层（地理不因剧情改） |

**示例 C｜`WB-INFO-0073` 实名短缺名单（信息 × 揭示／诱惑）**

| 字段 | 填写 |
|---|---|
| 一句话定义 | 一份以「一户一个」为原则的撤离名单，记载谁能离开 |
| 抽象层 / 来源 | L2；`SRC-022`，提炼自某历史题材的名单桥段，结构保留、事件全换 |
| 借用方式/范围 | 即插即用后重写咬合；借运作逻辑（名额制），但把资源从"船票"改为"撤离资格" |
| 咬合条件 | `历史旧账`→ 抄名者；`制度隶属`→ 登记处；`资源依赖`→ 名额稀缺 |
| 压力机制 | 想上名单须提交户口（**权限**）；改名单即抹去一人的"来路"（**代价**）；"名单求公平"与"执行者必徇私"相冲（**矛盾**） |
| 行程激活差异 | 名单内者读到「保全」；名单外者读到「收买机会」；后来者读到「被篡改的痕迹」 |
| 适配基线 | 须重写「名额的稀缺来源」与「改名的代价」 |

## 7. 提炼与复用工序 + 验收门

| 工序 | 动作 | 输出 | 验收门（不过即退回） |
|---|---|---|---|
| **1 找** | 扫描已有作品，标出反复出现且「能让人为难受」的设定/桥段 | 候选清单 | 能说出「它让谁为难受」；说不出→不是候选 |
| **2 抽象** | 按 §3 从 L0 提到 L1/L2；剥离专名、台词、独特情节链 | 抽象描述 | 不含原作专名；换题材后仍成立 |
| **3 验证** | 过接口三问（字段 10–13）＋通电检验（字段 15） | 验证记录 | 三问全过；≥2 探针生成不同后果；否则降级为背景板/素材箱 |
| **4 登记** | 填字段 1–6，指向 `14` | 溯源记录 | 来源可追溯；借用方式与范围明确；L0 原文只留档不入库 |
| **5 入库** | 填全字段表，双轴分类，挂咬合条件 | 零件卡 | 必填 13 项齐全；双标签齐；≥1 条咬合条件 |
| **6 复用** | 按 §1.5 课题，只为「下一站」调取拼装；调用后留痕 | 站点的模块组 | 调用能回答当前课题/体验目标；玩法层变更留痕；基础层未为凑剧情改动 |

### 7.1 与 §1.5 的对接

- **课题先于零件、零件先于地图**：课题/体验目标是「选择器」，零件库是「可调用资源池」；没有当前课题就不调用零件。
- **不为完备性调用**：只为「主角将要到达的下一站」拼装，主角离开后玩法层可卸载/替换，基础层保持连续（§1.6 第四动作）。
- **调用判据**：本次调用若不能回答 §1.5 锁定课题，或换到另一站同样成立，则该站未咬住主角 → 零件选错或该零件实为背景板。
- **[有出处]** 这正是涌现式叙事的纪律：故事由机制交互后生成，而非预写 [S5]；也是 Etudes 系统「独立节点、按需激活」的写法 [S6]。

## 8. 反例与风险防治

| 风险 | 后果 | 防治（有出处/经验） |
|---|---|---|
| **零件库膨胀／名词垃圾场** | 设定倾倒、info-dump、写作瘫痪 | [有出处] Sanderson 第三定律「先扩展再加新」，追求 deep 而非 wide [S9]；「worldbuilder's disease」=只建不写 [S9/S10]。[有出处] easyclaw「建立足够基础以自信决策；有趣但未用→停放」[S15]；Adazing「工作表不是剪贴簿而是压力系统」[S13]。[经验] 硬门：填不出压力机制即删出零件库。 |
| **万能贴导致世界观失真** | 跨学科/跨类型硬套，两套规则互相拆台 | [有出处] §1.6 四种动作各有调校代价：「即插即用调校重，须重写与基础层咬合，否则两套规则互相拆台」。[经验] 强制填「借用范围：没借什么」与「适配基线」；字段 5/6/17 不全不得入库。 |
| **版权／融梗风险** | 「高级抄袭」认定 | [有出处] 思想/表达二分法、抽象概括法、固定场景 [S11/S12]；[经验] 零件库只收 L1/L2，L0 只在来源登记留档；交付前做「调色盘」自检（核心情节/人设是否大面积对应）。 |
| **背景板冒充接口** | 零件可调用但不施压，站点变成观光 | [有出处] §8.5 通电检验「主角一接入立刻被施压」；[经验] 字段 13 必须 ≥2 探针生成不同后果。 |
| **玩法层污染基础层** | 为凑剧情改地理/核心法则，世界失真 | [有出处] §1.6 第四动作＋`03` 变更登记；[有出处] Etudes 系统用层级/优先级/依赖避免节点互相踩踏 [S6]。[经验] 字段 9 与字段 18 成对使用。 |
