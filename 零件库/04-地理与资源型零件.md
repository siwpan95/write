## `WB-GEO-0009` 无补给地带（地理逼人依附系统）

| 字段 | 填写 |
|---|---|
| 零件名 | 无补给地带 |
| 抽象层 | **L2** |
| 来源登记 | `SRC-004`（废土旅法师 区域包方法）＋`SRC-005`（点子库十二模块 模块3 法则资源观）｜提炼至 L2 |
| 借用方式 | 切断点：借"地理逼人依附系统"的上层类型语法，自研切断点以下的摩擦层 |
| 借用范围 | 借「地表不可用 → 生存资料只能来自固定点 → 离开即慢性损耗」三项；**未借**原作的地名、辐射设定、具体距离 |
| 双标签 | `地理 × 阻碍` |
| 一句话定义 | 环境本身不可维持生命，可通行的路和可生存的路不重合，人必须依附某套分配系统 |
| 内核层 | **基础层**（地理不因剧情改） |
| 参数可换度 | **中**——须换不可用的资源与分配点形态 |
| 可咬合零件 | `WB-INST-0001` 记录即存在（`资源依赖`）、`WB-ECON-0010` 配给资格制（其检查站是落地形态）（`地理邻接`） |
| 装配角色 | **参与**——装配体的常规成员，自身施压 |
| 互斥零件 | 无 |
| 落地接口 | `地理邻接`→ 分配点；`资源依赖`→ 水／药／过滤物 |
| 压力机制 | 想活过若干天须待在分配点半径内（**权限**）；离开即持续损耗必须折返（**代价**）；能走的路与能活的路不重合（**矛盾**） |
| band | **L4**（recover 判定）｜target: 身 ｜ recover: 不可逆 ｜ 离开分配点即慢性死亡，不可补 |
| phase | **设**——建立「路不重合」；不作「压」（环境不会加压，只会一直在） |
| rule | REQ: 离开分配点 ｜ EFF: 持续损耗，必须折返 ｜ Δ: 身 −1／日 ｜ ELSE: 无（环境不改） |
| 行程激活差异 | 缺水者读到「必须折返」；走私者读到「检查站盲区＝路线」；本地人读到「熟悉的羞辱」 |
| 不可申诉之物 | 路不重合——可通行的路与可生存的路永不合并，找到捷径也不改变这一点 |
| 施压时序 | **立刻**｜是——主角一进入就被"能不能活过三天"卡住 |
| 适配基线 | 须重写：不可用资源是什么、分配点形态、损耗速度；**"路不重合"这条内核不得改** |

| 施压时序 | **立刻**｜是——没档领不到资源，第一顿饭就被卡 |
| 不可申诉之物 | 身份档案注销后不可恢复 |
| 适配基线 | 须重写：资源类型、验档方式、退出代价 |

## `WB-ECON-0011` 重复次数即货币

| 借用范围 | 借「法律／礼仪／交易都以有效重复次数计价」；**未借**原作的具体遍数、货币名、常数数值 |
| 双标签 | `经济 × 交易`／`文化·信仰 × 施压` |
| 一句话定义 | 在一个理解难以共享的世界里，"要重复多少遍才算数"成为通用计量单位，贯穿法律、礼仪与交易 |
| 内核层 | 玩法层 |
| 参数可换度 | **中**——须换计量对象（遍数／次数／字符数） |
| 可咬合零件 | `WB-MECH-0006` 认知不可通约（`资源依赖`）、`WB-INST-0001` 记录即存在（`制度隶属`） |
| 装配角色 | **参与**——装配体的常规成员，自身施压 |
| 互斥零件 | 无 |
| 落地接口 | `资源依赖`→ 传达率常数；`制度隶属`→ 宣读／认证机构 |
| 压力机制 | 想让约定生效须重复规定次数（**权限**）；少一遍即无效、前功尽弃（**代价**）；要传达与要保密相冲突（**矛盾**） |
| band | **L2**（recover 判定）｜target: 时 ｜ recover: 自动（下次再诵） ｜ 拿走时间，可补但每次都要付 |
| phase | **设**——建立「少一遍即无效」；「压」的表现是遍数上涨 |
| rule | REQ: 想订约 ｜ EFF: 须重复到规定遍数，少一遍即无效 ｜ Δ: 时 −1 ｜ ELSE: 若 财 ≥ 3 → 买「代诵」，Δ 财 −2 |
| 行程激活差异 | 宣讲者读到「成本」；听众读到「我记不住」；伪造者读到「重复次数可套利」 |
| 不可申诉之物 | 生效遍数不可打折——少一遍即无效，没有「意思到了」这一说 |
| 施压时序 | **立刻**｜是——第一次订约就要重复到规定遍数，否则约定不成立 |
| 适配基线 | 须重写：计量单位、生效遍数、三项应用（法律／礼仪／交易） |

|---|---|
| 零件名 | 名分兑换率 |
| 抽象层 | **L2** |
| 来源登记 | `SRC-001`（蜀山 03 §10 名分兑换率／命价）｜提炼至 L2 |
| 借用方式 | 切断点：借"身份可折资源但不可购买"的约束，自研兑换表 |
| 借用范围 | 借「身份等级决定资源配额、补偿以划名结算、无名者不计价」；**未借**原作阶名、兑换数值 |
| 双标签 | `经济 × 交易`／`制度 × 施压` |
| 一句话定义 | 承认程度可折算为资源配额，但不能用资源反向购买；赔偿以"抹除承认"结算 |

| band | **L2**（recover 判定）｜target: 位／财 ｜ recover: 条件（升级可换回） ｜ 拿走配额与待遇，可补 |
| phase | **设 → 压**——先立兑换率；后在「换不起」时加压 |
| rule | REQ: 想换资源 且位不足 ｜ EFF: 配额按位折算，且不可反向购买 ｜ Δ: 位 −1；财 +1 ｜ ELSE: 若 名 ≥ 3 → 可借名折算，Δ 名 −1 |

| 不可申诉之物 | 不可反向购买——这条堵死"暴发户洗白"捷径 |
| 调用记录 | **M-04**／《创造主们的战争》立项级调用（`15`）：卷三／名分折配额，不可反向购买 |

| 适配基线 | 须重写：纹样载体、次数上限、作废后的判定后果 |

## 地理／资源／历史族咬合示范

```
无补给地带 ──地理邻接──→ 配给资格制 ──制度隶属──→ 认纹不认人
   （路不重合）            （身份绑生存）           （纹不认人）
        ↓                       ↓                       ↓
                   记录即存在（谁算数）＋名分兑换率（值多少）
                                   ↓
                   焚卷旧账（另一种结局被抹掉）→ 主角发现自己的空架
```

> **复用纪律**：地理族属**基础层**，一旦写入不因剧情改；配给／名分／使用次数属**玩法层**，逐站加载卸载并留痕。两者不可混层（见 `00` §三字段 9、§八风险防治）。

| 落地接口 | `制度隶属`→ 记账与销账的机构；`资源依赖`→ 可被质押的「名」（须是能被划掉的东西） |
| 压力机制 | 若想借到超出自己资格的力量，则须押上别人的名字——**成事与被押者安全，两者不可兼得**（**诱惑／代价**）；押名不可撤，违约时消失的不是你的东西（**矛盾**） |
| band | **L3**（recover 判定）｜target: 位（他人） ｜ recover: 不可完全补（只能换人押） ｜ 拿走的是「被押者的身份」，不可完全补，只能替换成另一个人。对「已有名可押」者不构成压力 |
| phase | **设 → 压**——先立「借力须押名」的规则；后在「押不出来」时加压 |
| rule | REQ: 位 ≤ 1 且 财 < 2 ｜ EFF: 债主上门：「押一个名字，我就借你」 ｜ Δ: 债 +2（派生量）；位（被押者）−1 ｜ ELSE: 若 势 ≥ 2 → 有人愿联名，但联名＝共债；对方要你先押一个名字作「诚意」，Δ 位（他人）−1；债 +2 |
| 行程激活差异 | 借力者读到「先成事再说」；被押者读到「我的名字在他手里」；执法者读到「手续齐全，按约执行」；旁观者读到「别把名字借人」 |
| 不可申诉之物 | 立约不可撤——不存在「事后赎回」或「换一个人押」 |
| 施压时序 | **立刻**｜是——主角第一次借力，当场被要求「押一个名字」 |
| 适配基线 | 须重写：押的是什么（名／寿／亲缘／信用）、债主是谁、违约如何执行；**「抵押物是他人的身份」这条内核不得改** |
| 调用记录 | **M-02**／蜀山卷五（押章南姑的名，接卷三 290 押于建）／与 `WB-INST-0001`、`WB-INFO-0017` 咬合／**M-04**／《创造主们的战争》立项级调用（`15`）：卷三／押妹妹的册页（ELSE 负向化后首用） |

> **与 `WB-ECON-0012` 名分兑换率的区别（易混，务必分清）**：
> `0012` 是**自己的**身份折成资源，单向、不可反向购买；`0022` 是**别人的**身份作抵押，成事后那个人归债主。
> 前者是"你值多少"，后者是"你能拿谁去换"。
>
> **与 `WB-INFO-0017` 划名机制的区别**：`0017` 是**抹除**（减法，让一个人从未存在）；`0022` 是**抵押**（转移，把一个名字的使用权交给债主）。
> 两者常被混为一谈，但压力方向相反：`0017` 的恐惧是"我不见了"，`0022` 的恐惧是"我还活着，但我的名字在别人手里"。
>
> **本件的由来**：v1.2 前，「押名」被并进 `WB-INFO-0017` 的来源叙述（写作「蜀山押名／销名链」），
> 属**合并过头**。卷五「借力能成事、力要还、还的是别人的名字」这条卷末交付，用 `0017` 解释不了——
> 因为被押者并没有被抹除，他只是被**转手**了。这是由真实课题拉动补件的典型例子。

| 调用记录 | — |

> **为什么它不是 `WB-ART-0014` 认纹不认人（消耗型）**：
> `0014` 有**明确额度**（能用 N 次，用一次少一次，用完即止）；
> 本件**没有额度上限**，但有**供能频率**（不按时投入就归零）。
> 前者怕"用完了"，后者怕"断供了"。**消耗品会耗尽，依赖品会断供——两种恐惧完全不同。**
>
> **为什么它不是 `WB-MECH-0020` 越用越像它**：
> `0020` 收的是**你本身**（越用越不像人，代价是身份）；
> 本件收的是**你的投入**（越用越要投，代价是资源与自由）。你始终是你，只是停不下来。
>
> **本件的由来（跨项目验证）**：霜语的"资源成环"（力量体系的四件套之一）、
> 点子库的"资源循环"（每一笔授权费都要回流到仲裁与分摊）、廓者的"矫正工具"（他靠系统工作，系统靠他维持）——
> 三个项目在三个题材里独立发明了同一个"停不下来"的结构。
> **这也是「关系轴」最典型的一件：压力不在物上，在"人与循环的绑定"上。**
