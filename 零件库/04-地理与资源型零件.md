# 04 · 地理与资源族零件卡

> 地理不是布景，是"谁 vs 谁、因为什么稀缺"的答案来源。
> 字段定义见 `00`；来源逐条见 `99`。**均为 L1/L2 抽象，不含原书专名与数值。**

---

## `WB-GEO-0009` 无补给地带（地理逼人依附系统）

| 字段 | 填写 |
|---|---|
| 零件名 | 无补给地带 |
| 抽象层 | **L2** |
| 来源登记 | `SRC-004`（废土旅法师 区域包方法）＋`SRC-005`（点子库十二模块 模块3 法则资源观）｜提炼至 L2 |
| 借用方式 | 切断点：借"地理逼人依附系统"的上层类型语法，自研切断点以下的摩擦层 |
| 借用范围 | 借「地表不可用 → 生存资料只能来自固定点 → 离开即慢性损耗」三项；**未借**原作的地名、辐射设定、具体距离 |
| 双标签 | `地理 × 阻碍` |
| 一句话定义 | 环境本身不可维持生命，可通行的路和可生存的路不重合，人必须依附某套分配系统 |
| 层归属 | **基础层**（地理不因剧情改） |
| 可咬合零件 | `WB-INST-0001` 记录即存在、`WB-ECON-0010` 配给资格制、`WB-ECON-0010` 检查站 |
| 咬合条件 | `地理邻接`→ 分配点；`资源依赖`→ 水／药／过滤物 |
| 压力机制 | 想活过若干天须待在分配点半径内（**权限**）；离开即持续损耗必须折返（**代价**）；能走的路与能活的路不重合（**矛盾**） |
| 行程激活差异 | 缺水者读到「必须折返」；走私者读到「检查站盲区＝路线」；本地人读到「熟悉的羞辱」 |
| 通电状态 | 是——主角一进入就被"能不能活过三天"卡住 |
| 适配基线 | 须重写：不可用资源是什么、分配点形态、损耗速度；**"路不重合"这条内核不得改** |

## `WB-ECON-0010` 配给资格制（身份绑定生存资料）

| 字段 | 填写 |
|---|---|
| 零件名 | 配给资格制 |
| 抽象层 | **L2** |
| 来源登记 | `SRC-004`（废土旅法师 §2b/§2c）＋`SRC-021`（点子库 三制）｜提炼至 L2 |
| 借用方式 | 主题综合 |
| 借用范围 | 借「生存资料与身份绑定、退出即失去生存资格」；**未借**原作的公司名、券名、计量单位 |
| 双标签 | `经济 × 施压`／`制度 × 施压` |
| 一句话定义 | 把生存资料与身份档案绑定，领取须验档，退出即注销资格并断供 |
| 层归属 | 玩法层（资格状态随剧情变，制度本身属基础层） |
| 可咬合零件 | `WB-INST-0001` 记录即存在、`WB-GEO-0009` 无补给地带、`WB-ART-0014` 认纹不认人 |
| 咬合条件 | `资源依赖`→ 净水／药物；`制度隶属`→ 身份档案、检查站 |
| 压力机制 | 想领配给须交出身份档案（**权限**）；退出即注销资格、断供（**代价**）；管理者要可管理劳动力、居民要离开系统的活路（**矛盾**） |
| 行程激活差异 | 逃亡者读到「封锁」；投机者读到「伪造档案的套利空间」；本地人读到「熟悉的羞辱」 |
| 不可申诉之物 | 身份档案注销后不可恢复 |
| 适配基线 | 须重写：资源类型、验档方式、退出代价 |

## `WB-ECON-0011` 重复次数即货币

| 字段 | 填写 |
|---|---|
| 零件名 | 重复次数即货币 |
| 抽象层 | **L2** |
| 来源登记 | `SRC-020`（十三叩 四十遍制／复述当量）｜提炼至 L2 |
| 借用方式 | 即插即用后重写咬合：借"传达成本作货币"的运作逻辑，常数与面额全换 |
| 借用范围 | 借「法律／礼仪／交易都以有效重复次数计价」；**未借**原作的具体遍数、货币名、常数数值 |
| 双标签 | `经济 × 交易`／`文化·信仰 × 施压` |
| 一句话定义 | 在一个理解难以共享的世界里，"要重复多少遍才算数"成为通用计量单位，贯穿法律、礼仪与交易 |
| 层归属 | 玩法层 |
| 可咬合零件 | `WB-MECH-0006` 认知不可通约、`WB-INST-0001` 记录即存在 |
| 咬合条件 | `技术·规则`→ 传达率常数；`制度隶属`→ 宣读／认证机构 |
| 压力机制 | 想让约定生效须重复规定次数（**权限**）；少一遍即无效、前功尽弃（**代价**）；要传达与要保密相冲突（**矛盾**） |
| 行程激活差异 | 宣讲者读到「成本」；听众读到「我记不住」；伪造者读到「重复次数可套利」 |
| 适配基线 | 须重写：计量单位、生效遍数、三项应用（法律／礼仪／交易） |

## `WB-ECON-0012` 名分兑换率（身份折资源不可买）

| 字段 | 填写 |
|---|---|
| 零件名 | 名分兑换率 |
| 抽象层 | **L2** |
| 来源登记 | `SRC-001`（蜀山 03 §10 名分兑换率／命价）｜提炼至 L2 |
| 借用方式 | 切断点：借"身份可折资源但不可购买"的约束，自研兑换表 |
| 借用范围 | 借「身份等级决定资源配额、补偿以划名结算、无名者不计价」；**未借**原作阶名、兑换数值 |
| 双标签 | `经济 × 交易`／`制度 × 施压` |
| 一句话定义 | 承认程度可折算为资源配额，但不能用资源反向购买；赔偿以"抹除承认"结算 |
| 层归属 | 玩法层 |
| 可咬合零件 | `WB-INST-0001` 记录即存在、`WB-INFO-0016` 名分阶梯、`WB-INST-0002` 不可逆代价 |
| 咬合条件 | `制度隶属`→ 名分体系；`资源依赖`→ 配额来源 |
| 压力机制 | 想换资源须先被承认到某级（**权限**）；偿付以降级／划名结算（**代价**）；"钱能买一切"与"身份买不到"相冲突（**矛盾**） |
| 行程激活差异 | 有身份者读到「配额」；无身份者读到「一文不值」；执法者读到「赔得起赔不起」 |
| 不可申诉之物 | 不可反向购买——这条堵死"暴发户洗白"捷径 |

|---|---|
| 零件名 | 焚卷旧账 |
| 抽象层 | **L2** |
| 来源登记 | `SRC-001`（蜀山 03 §5 H-04）＋`SRC-018`（奇门遁甲 蚀值判定）｜提炼至 L2 |
| 借用方式 | 主题综合 |
| 借用范围 | 借「前代写过异端版本、卷与人同焚、留一处空架与可辨残留」；**未借**原作卷名、机构名、具体事件 |
| 双标签 | `历史 × 揭示`／`信息 × 催化` |
| 一句话定义 | 历史上有人写过"另一种结局"，卷与执笔者一同被销毁，只留下空位与残留痕迹 |
| 层归属 | 基础层（历史事实不因剧情改） |
| 可咬合零件 | `WB-MECH-0007` 描述即约束、`WB-ART-0019` 篡改痕迹符号系统、`WB-INST-0002` 不可逆代价 |
| 咬合条件 | `历史旧账`→ 异端版本；`信息`→ 残留载体（空架／纸灰／偏差值）；`制度隶属`→ 焚卷执行者 |
| 压力机制 | 想知道真相须先找到残留痕迹（**权限**）；复述即触发禁忌（**代价**）；"记录真相"与"保全自己"相冲突（**矛盾**） |
| 行程激活差异 | 考古者读到「缺页」；执法者读到「必须焚」；主角读到「我曾被写成另一种人」 |
| 不可申诉之物 | 被焚的版本不可复原，只能通过残留间接推断 |

## `WB-ART-0014` 认纹不认人（凭证用一次少一次）

| 字段 | 填写 |
|---|---|
| 零件名 | 认纹不认人 |
| 抽象层 | **L2** |
| 来源登记 | `SRC-004`（废土旅法师 §2b）｜提炼至 L2 |
| 借用方式 | 即插即用后重写咬合：借运作逻辑，载体全换 |
| 借用范围 | 借「凭证只验纹样不验活人、每用一次留一笔、记满即作废并定持有者为已死」；**未借**原作纹样、次数、身份设定 |
| 双标签 | `器物 × 施压`／`制度 × 阻碍` |
| 一句话定义 | 凭证验证的是可复制的纹样而非活人，每次使用都消耗自身，用完即把持有者判定为不存在 |
| 层归属 | 玩法层 |
| 可咬合零件 | `WB-INST-0001` 记录即存在、`WB-ECON-0010` 配给资格制、`WB-MECH-0004` 代价记账法 |
| 咬合条件 | `制度隶属`→ 验证机构；`器物`→ 纹样载体；`资源依赖`→ 使用次数即资源 |
| 压力机制 | 想通过验证须持有有效纹样（**权限**）；每用一次少一次、记满即作废（**代价**）；可复制的纹与不可复制的人相冲突（**矛盾**） |
| 行程激活差异 | 持纹者读到「还能用几次」；顶罪者读到「被判已死」；伪造者读到「复制纹样的机会」 |
| 适配基线 | 须重写：纹样载体、次数上限、作废后的判定后果 |

## 地理／资源／历史族咬合示范

```
无补给地带 ──地理邻接──→ 配给资格制 ──制度隶属──→ 认纹不认人
   （路不重合）            （身份绑生存）           （纹不认人）
        ↓                       ↓                       ↓
                   记录即存在（谁算数）＋名分兑换率（值多少）
                                   ↓
                   焚卷旧账（另一种结局被抹掉）→ 主角发现自己的空架
```

> **复用纪律**：地理族属**基础层**，一旦写入不因剧情改；配给／名分／使用次数属**玩法层**，逐站加载卸载并留痕。两者不可混层（见 `00` §三字段 9、§八风险防治）。
