# 跨项目世界零件库 · README

> 建立：2026-11-19｜适用：仓内 14 部小说共享｜形态：**抽象零件 + 接口规则**，不是设定摘抄
> 定位：通用模板包 `13-世界先行与地图叙事模板.md` §1.6「拼装而非一体成型」的**实体资产**
> 关系：模板包给**形式与判据**（空白骨架，不填实书内容）；本库给**可被调取的零件**（含来源与抽象层）

---

## 一、为什么要有这个库

仓库里已有 14 部小说、多套成体系的世界观。它们长期是**孤岛**——A 书 SOLVE 过的问题，B 书从头再想一遍；同一个"名分／账册／代价"的结构在不同书里被反复发明。

零件库把这些已验证的结构**抽象到可迁移层**，让新项目可以「拼装」而不是「从零发明」，也使 `13` 号模板的 §1.5（课题先于地图）真正可落地——**先定课题，再从库里挑能施加相应压力的零件**，而不是先画完大陆。

**核心判据**（与模板 §1.6 一致）：一个零件只有能**施加压力**才算零件；施加不出压力的只是名词，不入库。

---

## 二、三条铁律

1. **抽象，不摘抄**：入库的是**结构命题**（"职务与名分互斥"），不是原书的具体专名、数值、情节。原书专名只出现在「来源」列用于溯源，**不得进入零件的可调用描述**。
2. **可溯源**：每条零件必须登记来源项目 + 文件 + 章节 + 抽象层 + 借用范围。来源缺失＝不入库。
3. **不碰冻结正文**：本库只读引用各小说的设定文件；**不修改任何小说正文或已冻结卷**（见仓根 `README.md` 纪律 5）。

## 四、与模板包的接口

```
新书立项 → 13 §1.5 锁定课题/体验目标/核心循环
        → 本库按「压力类型」检索候选零件
        → 13 §1.6 拼装（切断点／主题综合／即插即用／基础层-玩法层分离）
        → 13 §2 区域包（零件咬合成地图）
        → 13 §8.6 风险白盒验证（换站不成立才算通过）
        → 06 §11.3a 卷末交付对账（正文落点列）
```

**注意**：模板包自身保持空白骨架。本库是独立资产，**不写进模板包正文**；模板包只在 `13` §1.6 与 `14` 来源登记里保留一个指针。
