# 05 · 接口与文本族零件卡

> 接口族回答"主角一接入，世界立刻卡他什么"；文本族是接口最常见的载体。
> 字段定义见 `00`；来源逐条见 `99`。**均为 L1/L2 抽象，不含原书专名与数值。**

## `WB-IFACE-0018` 通电接口（主角一接入即被卡）

| 字段 | 填写 |
|---|---|
| 零件名 | 通电接口 |
| 卡面版本 | **v2.3**——本卡按 v2.3 字段口径填写（24 项：五组 21 项＋F 组 2 项＋卡面版本） |
| 抽象层 | **L2** |
| 来源登记 | `SRC-018`（项目 `13` 模板 §8.5 叙事接口＝通电的压力点）｜提炼至 L2 |
| 借用方式 | 自研（由项目内模板抽象而来） |
| 借用范围 | 借「空白不产生主角，只有被规则与矛盾通电的空白才可接入」；无外部借用 |
| 双标签 | `组织·势力 × 施压` |
| 一句话定义 | 一个可供主角接入的位置，必须立刻施加权限、代价或矛盾之一，否则只是布景 |
| 内核层 | 基础层（判定纪律） |
| 参数可换度 | **低**——元零件不随题材改写；只保留三问判据 |
| 可咬合零件 | 判定工具——本件验收的是**装配体**（一个位置能不能让主角接入），不是单件，故**不产生咬合边**、不列入任何装配体成员清单。「所有其他零件」指的是**它验的对象范围**，不是咬合边 |
| 接口签名 | 无——判定件不进装配体，没有可拼接口 |
| 可换参数清单 | 无——判定件不随题材改写，只保留三问判据 |
| 装配角色 | **判定**——判定工具：判「这个位置能不能让主角接入」，不进入任何装配体，不产生咬合边 |
| 互斥零件 | 无 |
| 落地接口 | 元零件不绑定特定承载物——它判的是**别的零件与位置是否已咬合**；落地时按被验对象取 `制度隶属`／`资源依赖`／`历史旧账` 至少一项 |
| 压力机制 | 想接入须付出权限／代价／矛盾之一（**权限／代价**）；三者皆无则接口不成立（**判定**） |
| band | **L1**（recover 判定）｜target: 无 ｜ recover: ——（元零件，不取走东西） ｜ 判定工具，本身不拿东西 |
| phase | **设**——验收纪律；不作叙事相位 |
| rule | REQ: 出现候选接口 ｜ EFF: 用三问验收；三者皆无则不成立 ｜ Δ: 无 ｜ ELSE: 无 |
| 行程激活差异 | **按接口四型分流**：位置型→逃亡者读到「这地方谁能进、从哪绕」；差事型→执法者读到「这活派给谁、算不算公差」；身份型→学习者读到「这个位要什么资格」；交易型→投机者读到「这里能换什么、汇率谁定」。四型被卡住的点不同，这正是"可替换主角"的前提 |
| 不可申诉之物 | 三者皆无即不成立——不接受「氛围很好」「很有压迫感」作为接口成立的依据 |
| 施压时序 | **立刻**｜是（本零件即通电检验器） | |
| 适配基线 | **元零件无需适配**——它判的是别的零件与位置是否已咬合，本身不随题材改写；只须保留三问判据 |
| 接口四型 | **位置**（一个可去的场所）／**差事**（一件可接的活）／**身份**（一个可承的位）／**交易**（一次可做的交换）——判据不变：接入即被卡。**只找地点会漏掉后三型**（M-01 教训：卷四真正可接入的是「能写人」这个动作，池子只是条件） |
| 调用记录 | **M-01**／蜀山卷四 幻波池（376–380）／元零件判定通过／**实战发现接口需分四型（位置／差事／身份／交易）**；**M-02**／卷五「借力」是动作型接口（四型验证）；**M-05**／站区级拼装（`18`）：**六站各验一次接口四型**（甲／乙／丙／戊／丑／代理处），每次位置／差事／身份／交易四格全填；累计 6×4＝24 个接口位无一空缺。实战结论：**四型不是四个地点，是四扇不同的门**——甲的「交易」是重复次数、乙的「差事」是查存根、戊的「身份」是第九次不可代选；只找地点会漏掉后三型（M-01 教训的站区级复验） |

## 接口族咬合示范

```
两层宪章争正统 ──制度隶属──→ 名分阶梯 ──信息──→ 划名机制
   （按哪套）                  （你算几级）        （划掉你）
        ↓                          ↓                  ↓
                篡改痕迹符号系统 ←── 焚卷旧账 ──→ 通电接口验收
                （谁动过文本）      （另一种结局）     （接入即被卡）
```

> **与模板 §1.5 的对接**：先锁课题 → 用 `WB-IFACE-0018` 判定候选零件是否真是接口 → 再按课题挑 2-3 件咬合 → 只为下一站拼装。**不是先把零件库用完。**

## `WB-HIST-0024` 名与事不同寿（事比名活得久）

| 字段 | 填写 |
|---|---|
| 零件名 | 名与事不同寿 |
| 卡面版本 | **v2.3**——本卡按 v2.3 字段口径填写（24 项：五组 21 项＋F 组 2 项＋卡面版本） |
| 抽象层 | **L2** |
| 来源登记 | `SRC-001`（蜀山 03 §R2 补笔律「只许写已发生却无人记下的事」＋`10A` 卷六结局场 §1.3「他写的不是名字，是事」；**卷六章纲，尚未开写**）｜提炼至 L2 |
| 借用方式 | 切断点：借「记录分名／事两层、两层寿命不同」的结构，自研两层各自的载体 |
| 借用范围 | 借「名可以被划被忘，事划不掉——后来的人会重新遇到同一件事」；**未借**原作的册制、补笔条款、具体人物 |
| 双标签 | `历史 × 揭示`／`信息 × 催化` |
| 一句话定义 | 记录分两层：外层的「名」可被划掉、被忘掉，内层的「事」一旦发生就再也收不回去 |
| 内核层 | **基础层**（记录的层次属性不因剧情改） |
| 参数可换度 | **中**——须换「名」与「事」各自的载体 |
| 可咬合零件 | `WB-INST-0001` 记录即存在（`制度隶属`）、`WB-INFO-0017` 划名机制（`资源依赖`）、`WB-HIST-0013` 焚卷旧账（`历史旧账`） |
| 装配角色 | **参与**——装配体的常规成员，自身施压 |
| 互斥零件 | 无 |
| 落地接口 | `资源依赖`→ 承载「事」的载体（册／碑／口传／物证）；`制度隶属`→ 有权决定写名还是写事的机构 |
| 压力机制 | 若想让人留下，则须放弃「留下名字」——**被记住与被署名，两者不可兼得**（**代价／矛盾**）；而事会一直在，谁做的却永远说不清（**揭示**） |
| band | **L3**（recover 判定）｜target: 名 ｜ recover: 不可逆（名划掉就没了） ｜ 拿走署名与名分，不可补（事已发生，名已划掉） |
| phase | **翻**——揭示「事比名久」这件事本身就是翻转；不宜作「设」 |
| rule | REQ: 主角试图留名 且事已成立 ｜ EFF: 名被划掉，可事情的痕迹还在（碑／记录／习俗） ｜ Δ: 名 −1；事 +1（不可量化，标记为存续） ｜ ELSE: 若 名 已为 0 → 仍可靠「事」被间接记住，Δ 无（但读者知道） |
| 行程激活差异 | 求名者读到「白做了」；后来者读到「这事有用，不管谁做的」；记录者读到「写事比写名稳」；当权者读到「抹掉名字容易，抹掉事难」 |
| 不可申诉之物 | 事一旦发生就收不回去——名可以被划一千次，事一次也划不掉 |
| 施压时序 | **立刻**｜是——主角第一次想「留个名」，就发现能留下的只有事 |
| 适配基线 | 须重写：名与事各自的载体、谁能划名、事靠什么留存；**「事比名活得久」这条内核不得改**。⚠️ **必要条件（M-03 测试补）：「事」必须有独立于「名」的载体**（碑／检修记录／物证／重复发生的习俗）——只靠口传时，事也会随人死而失传，本件降档为 🟡 |
| 调用记录 | **M-02**／蜀山卷六结局场（726–750：他写「事」不写名，最后被人忘掉名字却记得有这么个人）／与 `WB-INST-0001`、`WB-INFO-0017` 咬合 |

> **为什么这是历史族而不是信息族**：它的压力来自**时间尺度差**——名短、事长。
> 信息族（`0007` 描述即约束、`0019` 篡改痕迹）处理的是"此刻文本可不可信"，本件处理的是"百年之后还剩什么"。
>
> **与 `WB-HIST-0013` 焚卷旧账的区别**：`0013` 是**历史被销毁**（有人烧了它，留下空架与残留）；
> `0024` 是**历史被分层**（烧得掉名，烧不掉事）。前者是"有人不让你知道"，后者是"知道了也没用，因为署名没了"。
>
> **本件的由来**：卷六结局的硬约束是「不团圆、不虚无、不洗白」——他不能当掌门、不能被平反、不能被追封，
> 但「多一勺」这个动作要留下。**这三条约束要同时成立，只能靠「名与事不同寿」这一个结构**：
> 名归零（不团圆），事留存（不虚无）。用 `WB-HIST-0013` 或 `WB-INST-0001` 都撑不住这个结局。

## `WB-HIST-0026` 债由上定（债务由制度单方核定，偿债即续债）

| 字段 | 填写 |
|---|---|
| 零件名 | 债由上定 |
| 卡面版本 | **v2.3**——本卡按 v2.3 字段口径填写（24 项：五组 21 项＋F 组 2 项＋卡面版本） |
| 抽象层 | **L2** |
| 来源登记 | `SRC-026`（廓者「戴罪立功」：罪小而具体、债额由系统核定、偿债工具最终被同一套逻辑处置）＋`SRC-022`（点子库 模块 11「台账必结算」）＋`SRC-001`（蜀山 押名链的"力要还"）｜**三源同构**，提炼至 L2 |
| 借用方式 | **主题综合**（三源取最大公约数，不借任何一源的完整设定） |
| 借用范围 | 借「债额由制度单方核定、当事人无申辩权；偿还过程本身产生新账；偿债工具最终被同一套制度处置」；**未借**廓者编号体系、四神、具体罪由，点子库法条，蜀山人物与章号 |
| 双标签 | `历史 × 施压`／`制度 × 阻碍` |
| 一句话定义 | 一个人欠的债由制度单方核定、他无权申辩；他靠替制度干活还债，而干活本身不断产生新债 |
| 内核层 | **基础层**（债务核定权归谁，是世界法则，不因剧情改） |
| 参数可换度 | **高**——只换罪由与债额核定者；「偿债即续债」不动 |
| 可咬合零件 | `WB-INST-0001` 记录即存在（`制度隶属`）、`WB-INST-0002` 不可逆代价（`资源依赖`）、`WB-ECON-0022` 押名担保（`制度隶属`） |
| 装配角色 | **参与**——装配体的常规成员，自身施压 |
| 互斥零件 | 无 |
| 落地接口 | `制度隶属`→ 有权核定债务的机构；`资源依赖`→ 可被折算成工时／劳役的偿债方式 |
| 压力机制 | 若想恢复自由身，则须先还清一笔**不由你核定**的债（**权限**）；而偿债过程本身产生新账，越还越多（**代价**）；想证明自己无辜，与制度里根本没有"无辜"这个类目（**矛盾**） |
| band | **L3**（recover 判定）｜target: 时／位 ｜ recover: 不可逆（偿债即续债，除有人代偿） ｜ 拿走自由与时间，且偿债即续债 |
| phase | **设 → 压**——先立「债由上定」；后每期劳役都是加压 |
| rule | REQ: 被判有罪（罪由可小而具体） ｜ EFF: 债额单方核定，须以劳役偿还 ｜ Δ: 时 −3；位 −1 ｜ ELSE: 若 势 ≥ 3 → 有人代偿，Δ 势 −3 |
| 行程激活差异 | 欠债者读到「还完就自由了」；债权人读到「他还能再干十年」；旁观者读到「他本来没犯那么大的事」；接任者读到「上一个也是这么还的」 |
| 不可申诉之物 | 债额单方核定——不存在第三方仲裁，也没有"债已还清"的凭证可以自己保存 |
| 施压时序 | **立刻**｜是——主角一接入就被告知「你欠多少」，而数字是他第一次听到 |
| 适配基线 | 须重写：罪由（须小而具体，不许是"灭世"级）、债额由谁核定、偿债方式、新账如何产生；**「债由上定、偿债即续债」两条内核不得改** |
| 调用记录 | —／**M-04**／《创造主们的战争》立项级调用（`15`）：卷三／债额由制度单方核定；phase 改按「翻」用 |

> **为什么它不是 `WB-ECON-0022` 押名担保**：`0022` 是**拿别人的名字**去抵押（横向转移，债主拿走第三方的名）；
> 本件是**拿自己的劳力**去偿还一笔别人定的债（纵向隶属，债主拿走你的时间与身份）。前者怕"连累别人"，后者怕"永远还不完"。
>
> **为什么它不是 `WB-INST-0003` 职格互斥**：`0003` 是"要管理就不能被承认"（**结构性悖论**，无人作恶）；
> 本件是"债额由人核定"（**分配性不公**，有人定价）。前者让人无话可说，后者让人有话无处说。
>
> **本件的由来（跨项目验证）**：这一结构在三个独立项目里被分别发明——
> 廓者的"戴罪立功"（他是矫正工具，也在被矫正）、点子库的"台账必结算"（账不会错，只会累）、
> 蜀山的"力要还"（借来的力最终要以名字偿还）。
> **三源互不相干，却都长成了"债不由己、越还越多"** ——这是本库判定它够 L2 的依据。
