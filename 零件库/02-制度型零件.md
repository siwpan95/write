# 02 · 制度族零件卡（主干）

> 制度族是全仓最有复用价值的共享资产：**记录即存在 + 不可逆代价 + 职格互斥**三者咬合后能自动生成剧情压力。
> 这三件在六个独立项目里被反复独立发明（蜀山／点子库／奇门遁甲／华夏克苏鲁／廓者／十三叩），是"零件库＋接口规则"方法论最好的示范组合。
> 字段定义见 `00`；来源逐条见 `99`。**卡内描述均为 L1/L2 抽象，不含原书专名与数值。**

---

## `WB-INST-0001` 记录即存在

| 字段 | 填写 |
|---|---|
| 零件名 | 记录即存在 |
| 抽象层 | **L2** |
| 来源登记 | `SRC-001`（蜀山 03 §2 R1）＋`SRC-012`（华夏克苏鲁 铁律表 FL-04）＋`SRC-018`（奇门遁甲旧案A §1）＋`SRC-022`（点子库十二模块）｜L0 原文留档，提炼至 L2 |
| 借用方式 | **主题综合**（四源同构，取最大公约数，不借任何一源的完整设定） |
| 借用范围 | 借「存在与否取决于第三方可查验记录」的结构命题；**未借**任一部作品的册名、机构名、人物、具体卷数、数值 |
| 双标签 | `制度 × 施压` |
| 一句话定义 | 人／物／事是否被任何权威记录载明，决定其是否"算数"；未被记录者在社会意义上不存在 |
| 内核层 | **基础层**（这是世界如何定义存在的法则，不因单卷剧情改） |
| 参数可换度 | **中**——须换记录载体（册→数据库→堂单）与垄断者；内核不动 |
| 可咬合零件 | `WB-INST-0002` 不可逆代价（`制度隶属`）、`WB-INST-0003` 职格互斥（`制度隶属`）、`WB-INFO-0017` 划名机制（`资源依赖`）、`WB-ECON-0012` 名分兑换率（`制度隶属`） |
| 落地接口 | `制度隶属`→ 记录资格的垄断机构；`资源依赖`→ 记录即生存资料凭证；`历史旧账`→ 前代异端版本 |
| 压力机制 | 进入者若想被承认／办事／领资源，须先被写入权威记录（**权限**）；从记录中除名即丧失全部社会资格（**代价**）；记录者要秩序、被记录者要存在，两者不可兼得（**矛盾**） |
| band | **L4**（recover 判定）｜target: 位／存在 ｜ recover: 不可逆 ｜ 除名＝社会意义上的存在消失，不可补。对「另有他册可依」者降为 **L2** |
| phase | **设 → 翻**——先立「什么算数」的规则；后可在「册子骗人」处翻转（虚字线） |
| rule | REQ: 位 ≤ 1 且试图办事 ｜ EFF: 办事被拒，旁人转头就忘他姓什么 ｜ Δ: 位 −1；名 −1 ｜ ELSE: 若 名 ≥ 3 → 三人以上口传可临时作保，但保人须当众报出自己的名；口传一出，保人一并列入待核，Δ 时 −1；名（保人）−1 |
| 行程激活差异 | **四条线**：补录线（加法）→ 从无到有、要付出代价；划名线（减法）→ 从有到无、不可挽回；焚卷线（归零）→ 连"曾经存在过"的痕迹一并抹除；**改写线（改性质）→ 名还在、人还在，但"他被写成什么"变了**（M-01 补：原三线只覆盖「有没有／有多少」，漏了「是什么」） |
| 不可申诉之物 | 除名后不可自助恢复——恢复必须经由同一套记录制度，而该制度正拒绝你。**改写线另有不可申诉**：改后的版本覆盖改前的，见证者只能靠「旧行并存」来追 |
| 施压时序 | **立刻**｜**是**——主角一接入世界，第一道关卡就是"你不在册" |
| 适配基线 | 跨题材须重写：①记录载体（册／数据库／堂单／户籍）；②记录资格垄断者；③三种激活线各自的具体代价 |
| 调用记录 | **M-01**／蜀山卷四（376–500）／与 `WB-INST-0002`、`WB-MECH-0020` 咬合／**实战发现激活线缺「改写」第四条**，已补；**M-02**／卷五押名线的前提（他只有半个名，押不动）／**M-04**／《创造主们的战争》立项级调用（`15`）：卷一（元零件）／记录即存在升为 `03` 公理 2 |

**接口三问自检**：① 与职格互斥、名分兑换、划名机制咬合 ✅ ② 施压"你连死都没被写下" ✅ ③ 三条激活线后果完全不同 ✅

## `WB-INST-0002` 不可逆代价

| 字段 | 填写 |
|---|---|
| 零件名 | 不可逆代价 |
| 抽象层 | **L2** |
| 来源登记 | `SRC-002`（蜀山 03 §2 R3 + 机制台账 M-05）＋`SRC-014`（奇门遁甲 字债五档）＋`SRC-013`（华夏克苏鲁 FL-02）｜提炼至 L2 |
| 借用方式 | **主题综合** |
| 借用范围 | 借「代价可观测、不可撤销、语义不解释、逐档递进不可跳档、由制度而非人审判」五条骨架；**未借**原书的档名、数值、具体付出物 |
| 双标签 | `制度 × 施压`／`技术·规则 × 交易` |
| 一句话定义 | 任何改写世界记录的动作都必须当场付出不可逆代价；代价可计量、可累加，且不存在求情或代付的捷径 |
| 内核层 | **基础层**（代价律是世界法则） |
| 参数可换度 | **高**——只换代价物与计量单位；「不可撤」不动 |
| 可咬合零件 | `WB-INST-0001` 记录即存在（`制度隶属`）、`WB-MECH-0004` 代价记账法（`资源依赖`）、`WB-INST-0003` 职格互斥（`制度隶属`） |
| 落地接口 | `制度隶属`→ 记账／审计机构；`资源依赖`→ 计量单位（能折算成什么） |
| 压力机制 | 进入者若想改写一条记录，须先交出一项真实所有物（**代价**）；无计量单位则操作不成立（**权限**）；想保留自我与想改变世界相冲突（**矛盾**） |
| band | **L3**（recover 判定）｜target: 财／身 ｜ recover: 不可逆 ｜ 交出的是「真实所有物」，不可撤。若代价物只是钱则降为 **L2** |
| phase | **设 → 压**——先立「改必付账」的规则，后每次调用都在加压 |
| rule | REQ: 试图改写记录 ｜ EFF: 账当场结算，数字写在账上 ｜ Δ: 财 −2（或 身 −1，按代价物） ｜ ELSE: 若 位 ≥ 3 → 可用配额抵扣，Δ 位 −1 |
| 行程激活差异 | 谨慎者读到「每次只敢改最小一格」；赌徒读到「把最重要的东西押上换一次大改」；旁观者读到「代价数字本身就是身份等级」 |
| 不可申诉之物 | 代价一旦付出不可撤销；**审判者是制度不是人**（消除了"求情"这条捷径） |
| 施压时序 | **立刻**｜是——主角第一次动用能力就必须付账，且账目当场可见 |
| 适配基线 | 须重写：代价物（钱／记忆／关系／寿）、计量单位、结算时机；**「代价不可撤、且由制度而非人收」不得改** |
| 调用记录 | **M-01**／蜀山卷四／与 `WB-INST-0001`、`WB-MECH-0020` 咬合／**实战发现「计量物」措辞窄，装不下「能力型代价」**／**M-04**／《创造主们的战争》立项级调用（`15`）：卷二／校勘权的代价机制 |

**接口三问自检**：① 与记录即存在、代价记账法咬合 ✅ ② 施压"变强必失去" ✅ ③ 三种读者/探针行为不同 ✅

## `WB-INST-0003` 职格互斥

| 字段 | 填写 |
|---|---|
| 零件名 | 职格互斥（制度性悲剧发生器） |
| 抽象层 | **L2** |
| 来源登记 | `SRC-003`（蜀山 03 §3.5 T-05）＋`SRC-015`（奇门遁甲 临时工不在编制）＋`SRC-013`（华夏克苏鲁 FL-05 境界越高人间性越少）｜提炼至 L2 |
| 借用方式 | **主题综合** |
| 借用范围 | 借「追求目标必经之路本身禁止达成目标」的悖论；**未借**原书职务名、阶位名、具体排斥条款 |
| 双标签 | `制度 × 阻碍` |
| 一句话定义 | 一个岗位的职责与获得完整资格互斥：要管理这套制度，就不能同时被这套制度承认 |
| 内核层 | **基础层** |
| 参数可换度 | **高**——只换岗位名与互斥条款；悖论结构不动 |
| 可咬合零件 | `WB-INST-0001` 记录即存在（`制度隶属`）、`WB-INST-0002` 不可逆代价（`制度隶属`）、`WB-INFO-0016` 名分阶梯（`制度隶属`） |
| 落地接口 | `制度隶属`→ 位置与资格可分离的世界（有职无格）；`资源依赖`→ 资格决定生存资料 |
| 压力机制 | 进入者若想获得完整资格，须先脱离当前岗位（**权限**）；脱离即失去该岗位的权力与其附带资源（**代价**）；越努力越远离所求（**矛盾**） |
| band | **L3**（recover 判定）｜target: 位 ｜ recover: 不可完全补（只能换一条路） ｜ 拿走「完整资格」，终身不可补，只能换一条路 |
| phase | **设 → 翻**——先立「有职无格」的规则；后在他发现自己永远进不去时翻转 |
| rule | REQ: 想获得完整资格 且身在岗上 ｜ EFF: 被告知「离岗才能入册，离岗就没有资格」 ｜ Δ: 位 −1；信 −1 ｜ ELSE: 若 名 ≥ 4 → 有人代他作保，改为 Δ 名 −2 |
| 行程激活差异 | 认命者读到「这就是规矩，守着吧」；反抗者读到「必须换一条路」；旁观者读到「这是个笑话」——三种探针都立刻获得处境判断 |
| 不可申诉之物 | 互斥是制度设计，不是某人恶意；**没有可恨的反派，只有正确的规矩** |
| 施压时序 | **立刻**｜是——主角一接入制度就被卡在"有职无格"的位置上 |
| 适配基线 | 须重写：岗位与资格如何分离（有职无格）、谁定这条互斥；**「追求目标必经之路本身禁止达成」不得改** |

**接口三问自检**：① 与记录即存在、不可逆代价咬合后自动生成悲剧 ✅ ② 施压"你走的路不许你到达" ✅ ③ 三种探针反应不同 ✅

## 三件咬合后的涌现效果（示范「接口规则」如何工作）

```
WB-INST-0001 记录即存在  ──制度隶属──→  WB-INST-0003 职格互斥
        │                                        │
        └──资源依赖──→  WB-INST-0002 不可逆代价 ←┘
                              │
                              ↓
        自动生成：想被承认 → 必须改记录 → 改记录要付代价 →
        而能改记录的岗位恰好禁止你被承认 → 闭环困境
```

**这就是"零件库＋接口规则"的核心价值**：三件单独看都是熟悉的设定，咬合后**不用作者安排反派，世界自己就会逼角色做选择**。

**可插手的第四件**（选配，改变走向）：
- 加 `WB-INFO-0017` 划名机制 → 走向"减法线"（被抹除）
- 加 `WB-MECH-0004` 代价记账法 → 走向"可数线"（代价递增可预测）
- 加 `WB-HIST-0013` 焚卷旧账 → 走向"归零线"（连历史一并销毁）

> **复用示范**：仙侠（名册）、都市怪谈（条例）、民俗克系（堂单箓牒）、赛博（数据库身份）均可拼装同一组三件，只需按各零件的 `适配基线` 重写载体与代价。

## `WB-INST-0025` 改一次生一漏（规则的不完备性）

| 字段 | 填写 |
|---|---|
| 零件名 | 改一次生一漏 |
| 抽象层 | **L2** |
| 来源登记 | `SRC-001`（蜀山 `03D` 卷三 291–295 改规矩已落地正文；`03F` 卷五 ⑦「结卷规矩」待写；`03` §2 R5）｜提炼至 L2 |
| 借用方式 | 切断点：借「成文规则必有未写到的空子、修改只换空子不消空子」的结构，自研规则内容 |
| 借用范围 | 借「规矩一经写下即产生空子；改规矩会把空子换到新地方；而写规矩的人自己也会被新空子伤到」；**未借**原作具体规矩条文、人物、章号 |
| 双标签 | `制度 × 施压`／`信息 × 揭示` |
| 一句话定义 | 任何成文规矩在被写下时就产生了它没写到的空子；改规矩不消灭空子，只把空子换到新地方 |
| 内核层 | **基础层**（规则的不完备性是法则，不是某条规矩的缺陷） |
| 参数可换度 | **高**——只换规矩内容与改法；「改一次生一漏」不动 |
| 可咬合零件 | `WB-INST-0001` 记录即存在（`制度隶属`）、`WB-IFACE-0015` 两层宪章争正统（`历史旧账`）、`WB-INFO-0017` 划名机制（`资源依赖`） |
| 落地接口 | `制度隶属`→ 有权改规矩的机构；`资源依赖`→ 可被反复修订的成文本子 |
| 压力机制 | 若想堵住一个空子，则须改动规矩——而每次修改都产生新的空子（**代价／矛盾**）；不改则空子被最会读条文的人吃掉（**施压**） |
| band | **L2**（recover 判定）｜target: 名／位 ｜ recover: 条件（再改一次，但生新漏） ｜ 拿走秩序与信任，可补但要再改一次（而再改又生新漏） |
| phase | **压 → 翻**——空子出现是「压」；改完更乱是「翻」 |
| rule | REQ: 出现规矩没写到的空子 ｜ EFF: 改规矩，旧空子堵上 ｜ Δ: 名 −1（显得无能）；位 +1（权力确认） ｜ ELSE: 若 名 ≤ 1 → 改不动，Δ 时 −1 |
| 行程激活差异 | 立法者读到「怎么改都有漏」；投机者读到「新漏在哪」；受害者读到「规矩是他写的，他也是被自己写的规矩害的」；执法者读到「照本办，本子本身就是漏的」 |
| 不可申诉之物 | 规矩一旦成文，它的空子就同时对所有人可见——包括最想钻的那个人 |
| 施压时序 | **立刻**｜是——主角第一次定规矩就埋下空子，下一次冲突直接由那个空子引爆 |
| 适配基线 | 须重写：规矩的载体、谁有权改、空子的具体形态；**「改一次生一漏」这条内核不得改**（改成"改好就好了"即失效） |
| 调用记录 | **M-02 附带**／蜀山卷三 291–295（他改规矩「以报名字为序」，下一章就有人伪报名字）／与 `WB-INST-0001` 咬合／**M-04**／《创造主们的战争》立项级调用（`15`）：卷四／结卷规则的漏洞 |

> **为什么它不是 `WB-INST-0002` 不可逆代价**：`0002` 收的是"改记录要付账"（改一次付一次，付完就完）；
> 本件收的是"改规矩会造出新漏洞"（**付完账，问题还在，只是换了个形状**）。前者是费用，后者是结构。
>
> **为什么它不是 `WB-IFACE-0015` 两层宪章**：`0015` 是**两套**规则源互争（冲突来自"用哪套"）；
> 本件是**一套**规则自身的空子（冲突来自"这套没写到的地方"）。前者需要一个对手，后者不需要。
>
> **本件的由来**：卷三 291–295 已经写过一次完整的「改规矩 → 更乱 → 想写死」四拍，
> 但当时没有语言概括它。补入本库后，卷五 ⑦「结卷规矩」可以直接复用这条结构——
> **结卷律落地时若要"改结卷规矩"，必然再产生新空子。** 这是由真实课题拉动补件的第二例。
