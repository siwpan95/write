# 02 · 制度族零件卡（主干）

> 制度族是全仓最有复用价值的共享资产：**记录即存在 + 不可逆代价 + 职格互斥**三者咬合后能自动生成剧情压力。
> 这三件在六个独立项目里被反复独立发明（蜀山／点子库／奇门遁甲／华夏克苏鲁／廓者／十三叩），是"零件库＋接口规则"方法论最好的示范组合。
> 字段定义见 `00`；来源逐条见 `99`。**卡内描述均为 L1/L2 抽象，不含原书专名与数值。**

---

## `WB-INST-0001` 记录即存在

| 字段 | 填写 |
|---|---|
| 零件名 | 记录即存在 |
| 抽象层 | **L2** |
| 来源登记 | `SRC-001`（蜀山 03 §2 R1）＋`SRC-012`（华夏克苏鲁 铁律表 FL-04）＋`SRC-018`（奇门遁甲旧案A §1）＋`SRC-022`（点子库十二模块）｜L0 原文留档，提炼至 L2 |
| 借用方式 | **主题综合**（四源同构，取最大公约数，不借任何一源的完整设定） |
| 借用范围 | 借「存在与否取决于第三方可查验记录」的结构命题；**未借**任一部作品的册名、机构名、人物、具体卷数、数值 |
| 双标签 | `制度 × 施压` |
| 一句话定义 | 人／物／事是否被任何权威记录载明，决定其是否"算数"；未被记录者在社会意义上不存在 |
| 层归属 | **基础层**（这是世界如何定义存在的法则，不因单卷剧情改） |
| 可咬合零件 | `WB-INST-0002` 不可逆代价、`WB-INST-0003` 职格互斥、`WB-INFO-0016` 划名机制、`WB-ECON-0010` 名分兑换率 |
| 咬合条件 | `制度隶属`→ 记录资格的垄断机构；`资源依赖`→ 记录即生存资料凭证；`历史旧账`→ 前代异端版本 |
| 压力机制 | 进入者若想被承认／办事／领资源，须先被写入权威记录（**权限**）；从记录中除名即丧失全部社会资格（**代价**）；记录者要秩序、被记录者要存在，两者不可兼得（**矛盾**） |
| 行程激活差异 | 补录线（加法）→ 从无到有、要付出代价；划名线（减法）→ 从有到无、不可挽回；焚卷线（归零）→ 连"曾经存在过"的痕迹一并抹除 |
| 不可申诉之物 | 除名后不可自助恢复——恢复必须经由同一套记录制度，而该制度正拒绝你 |
| 通电状态 | **是**——主角一接入世界，第一道关卡就是"你不在册" |
| 适配基线 | 跨题材须重写：①记录载体（册／数据库／堂单／户籍）；②记录资格垄断者；③三种激活线各自的具体代价 |

**接口三问自检**：① 与职格互斥、名分兑换、划名机制咬合 ✅ ② 施压"你连死都没被写下" ✅ ③ 三条激活线后果完全不同 ✅

## `WB-INST-0002` 不可逆代价

| 字段 | 填写 |
|---|---|
| 零件名 | 不可逆代价 |
| 抽象层 | **L2** |
| 来源登记 | `SRC-002`（蜀山 03 §2 R3 + 机制台账 M-05）＋`SRC-014`（奇门遁甲 字债五档）＋`SRC-013`（华夏克苏鲁 FL-02）｜提炼至 L2 |
| 借用方式 | **主题综合** |
| 借用范围 | 借「代价可观测、不可撤销、语义不解释、逐档递进不可跳档、由制度而非人审判」五条骨架；**未借**原书的档名、数值、具体付出物 |
| 双标签 | `制度 × 施压`／`技术·规则 × 交易` |
| 一句话定义 | 任何改写世界记录的动作都必须当场付出不可逆代价；代价可计量、可累加，且不存在求情或代付的捷径 |
| 层归属 | **基础层**（代价律是世界法则） |
| 可咬合零件 | `WB-INST-0001` 记录即存在、`WB-MECH-0004` 代价记账法、`WB-INST-0003` 职格互斥 |
| 咬合条件 | `制度隶属`→ 记账／审计机构；`资源依赖`→ 计量单位（能折算成什么） |
| 压力机制 | 进入者若想改写一条记录，须先交出一项真实所有物（**代价**）；无计量单位则操作不成立（**权限**）；想保留自我与想改变世界相冲突（**矛盾**） |
| 行程激活差异 | 谨慎者读到「每次只敢改最小一格」；赌徒读到「把最重要的东西押上换一次大改」；旁观者读到「代价数字本身就是身份等级」 |
| 不可申诉之物 | 代价一旦付出不可撤销；**审判者是制度不是人**（消除了"求情"这条捷径） |
| 通电状态 | 是——主角第一次动用能力就必须付账，且账目当场可见 |

**接口三问自检**：① 与记录即存在、代价记账法咬合 ✅ ② 施压"变强必失去" ✅ ③ 三种读者/探针行为不同 ✅

## `WB-INST-0003` 职格互斥

| 字段 | 填写 |
|---|---|
| 零件名 | 职格互斥（制度性悲剧发生器） |
| 抽象层 | **L2** |
| 来源登记 | `SRC-003`（蜀山 03 §3.5 T-05）＋`SRC-015`（奇门遁甲 临时工不在编制）＋`SRC-013`（华夏克苏鲁 FL-05 境界越高人间性越少）｜提炼至 L2 |
| 借用方式 | **主题综合** |
| 借用范围 | 借「追求目标必经之路本身禁止达成目标」的悖论；**未借**原书职务名、阶位名、具体排斥条款 |
| 双标签 | `制度 × 阻碍` |
| 一句话定义 | 一个岗位的职责与获得完整资格互斥：要管理这套制度，就不能同时被这套制度承认 |
| 层归属 | **基础层** |
| 可咬合零件 | `WB-INST-0001` 记录即存在、`WB-INST-0002` 不可逆代价、`WB-INFO-0016` 名分阶梯 |
| 咬合条件 | `制度隶属`→ 位置与资格可分离的世界（有职无格）；`资源依赖`→ 资格决定生存资料 |
| 压力机制 | 进入者若想获得完整资格，须先脱离当前岗位（**权限**）；脱离即失去该岗位的权力与其附带资源（**代价**）；越努力越远离所求（**矛盾**） |
| 行程激活差异 | 认命者读到「这就是规矩，守着吧」；反抗者读到「必须换一条路」；旁观者读到「这是个笑话」——三种探针都立刻获得处境判断 |
| 不可申诉之物 | 互斥是制度设计，不是某人恶意；**没有可恨的反派，只有正确的规矩** |
| 通电状态 | 是——主角一接入制度就被卡在"有职无格"的位置上 |

**接口三问自检**：① 与记录即存在、不可逆代价咬合后自动生成悲剧 ✅ ② 施压"你走的路不许你到达" ✅ ③ 三种探针反应不同 ✅

## 三件咬合后的涌现效果（示范「接口规则」如何工作）

```
WB-INST-0001 记录即存在  ──制度隶属──→  WB-INST-0003 职格互斥
        │                                        │
        └──资源依赖──→  WB-INST-0002 不可逆代价 ←┘
                              │
                              ↓
        自动生成：想被承认 → 必须改记录 → 改记录要付代价 →
        而能改记录的岗位恰好禁止你被承认 → 闭环困境
```

**这就是"零件库＋接口规则"的核心价值**：三件单独看都是熟悉的设定，咬合后**不用作者安排反派，世界自己就会逼角色做选择**。

**可插手的第四件**（选配，改变走向）：
- 加 `WB-INFO-0016` 划名机制 → 走向"减法线"（被抹除）
- 加 `WB-MECH-0004` 代价记账法 → 走向"可数线"（代价递增可预测）
- 加 `WB-HIST-0013` 焚卷旧账 → 走向"归零线"（连历史一并销毁）

> **复用示范**：仙侠（名册）、都市怪谈（条例）、民俗克系（堂单箓牒）、赛博（数据库身份）均可拼装同一组三件，只需按各零件的 `适配基线` 重写载体与代价。
