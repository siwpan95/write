# 16 · 喜剧节奏与无厘头手法模板（通用可复用 · 中性版）

> 用途：为**任何题材**的叙事项目提供"让读者获得乐趣"的喜剧工具层。网文不是严肃文学，也不是教材——可以寓教于乐，但**乐趣优先**；教益必须藏在情节因果里，禁止借人物之口说教。
> **中性化声明**：本模板只给原理、技巧、结构、应用场景与实操练习，不含任何项目专属设定；项目基调（如冷面爽文/正剧）由项目级文风卡与热梗规范决定，本模板与之冲突时以项目文件为准。
> 配合文件：`11-合规与一致性检查模板.md` §3.5（热梗注入检查）、`05-文风卡与章节规范模板.md`（基调词与禁用词）。
> 变更记录见文末。

## 一、原理（为什么好笑）

1. **预期违背**：笑点来自"读者用普通逻辑建立预测→被打破"。打破后的新逻辑必须**比原预测更妙、且事后讲得通**（B 比 A 合理），否则是闹剧不是喜剧。
2. **两种打破量级**：反套路破的是"剧情预期"（他会输？他赢了，但赢的方式出乎意料）；无厘头破的是"场景逻辑"（天塌下来的灾难，归因成一个再小不过的日常动作）。前者管结构，后者管段落——两层可叠加，不可混用。
3. **步伐纪律**：一次只破一条预期；破完立刻回到正常逻辑走两步再破下一次。连续荒诞=读者疲劳。
4. **冷热分工**：主角高光与严肃暗线保持"冷"；笑点由配角、反派嘴硬、场景细节承担（冷热对比=张力最大化）。"谑而不虐"：只嘲行为，不嘲人的尊严。

## 二、技巧工具箱

| 技巧 | 操作 | 一句话示例 |
|---|---|---|
| 不相干联结 | 巨大后果 ← 一个极小的日常归因 | "公司塌了。""哦，谁打了个电话？" |
| 降格处理 | 天大的事用最平淡的语气说 | 报灾像报天气预报 |
| 一本正经的荒诞 | 荒诞事件被角色完全严肃地对待 | 对着灾难现场直播点评"这回是真的寄了" |
| 数字具象 | 把抽象威胁换算成具体小数字 | "十四年，总有些账经不起看" |
| 反向关怀 | 紧张场景里有人惦记完全无关的小事 | "吃饭呢，你输出这么密，菜都要凉了" |
| 冷面误接 | A 玩梗，B 一本正经接歪，C（读者）补完笑点 | 玩梗-接梗-观众三角 |
| callback 回扣 | 跨章回提前梗一次，形成记忆锚 | 单梗全书回扣 ≤2 次 |

**与相声/脱口秀的关系（一脉相承）**：铺垫=铺平垫稳；破预期=三翻四抖（前三翻用普通逻辑喂饱预测，第四抖才破）；接梗角色=捧哏（接得住、托得住、立得住）；分寸=谑而不虐。检索梗库可用梗百科/萌娘百科/游戏圈黑话（登记义务见 `14`）。

## 三、结构：无厘头单元四拍

| 拍 | 要求 | 操作要点 |
|---|---|---|
| ① 开头定调 | 第一段用一句**平静的陈述**建立场景和语气，让读者进入判断模式 | 越平淡越好；陈述里埋一个将在④回环的物件/动作 |
| ② 中段铺垫 | 接连设置 1-3 个期待点，每个点用**普通逻辑**推进，使读者建立预测 | 每个期待点都要"喂饱"：逻辑自洽、情绪到位；预测叠得越高，破得越响 |
| ③ 爆点交付 | 在预测最满处用**荒诞反转或不相干联结**打破预测；**步伐不要过猛** | 一次只破一条；破完的余波用正常逻辑收两拍 |
| ④ 回环收尾 | 用一个**呼应开头的元素**或一个**意外的归纳**闭合，既给笑点呼吸，又留下余韵 | 呼应=开头的物件/动作再出现一次；归纳=一句超出场景但符合人物逻辑的总结 |

**与三翻四抖的换算**：四拍的②（铺垫 1-3 个期待点）≈三翻；③（爆点）≈第四抖。四拍比传统段子多出①④两拍，是为了让笑点嵌进叙事（有呼吸、有余韵），而非独立段子。

## 四、应用场景与禁用场景

| 适用 | 禁用 |
|---|---|
| 打脸/胜利的 aftermath（荒诞侧写） | 殉职、葬礼、师门旧案揭晓 |
| 日常家庭戏、群像闲笔 | 生死告白、诀别 |
| 反派嘴硬与降格处理 | 决战第一回合、反派出场首秀 |
| 番外/售后/婚后日常 | 主角高光时刻的叙述层 |
| 章末钩子的"冷幽默变体"（慎用，钩子功能优先） | 教育读者、借角色说教的段落 |

## 五、实操练习（写前热身，5 分钟）

"三改一留"法：取本章任一严肃场景——

- **一改**：把灾难的宣告句改成平静陈述句（练①）；
- **二改**：给灾难找一个不相干的小归因（练③）；
- **三改**：结尾补一个呼应开头的物件动作（练④）；
- **一留**：主角反应保持冷面（人物腔调不动，笑点由配角承担）。

**合格判据**：①删掉无厘头段，情节因果无损（润滑剂判定）；②破预期后的逻辑经得起"事后复盘"（B 更合理）；③全章喜剧单元 ≤1 个（密度纪律，项目可按文风放宽至 ≤2）；④朗读一遍，笑点前没有"预告笑"（"让人捧腹的是/搞笑的是"=硬禁）。

## 六、自检清单

- [x] 每个喜剧单元四拍齐全（定调/铺垫/爆点/回环）
- [x] 爆点步伐不过猛（单单元单破预期；破后有两拍正常逻辑）
- [x] B 比 A 更妙且事后讲得通
- [x] 场景在"适用"白名单内，未踩"禁用"红线
- [x] 冷热分工成立（主角冷面；笑点由配角/场景承担）
- [x] 谑而不虐（只嘲行为不嘲尊严；无预告笑词）
- [x] 密度合规（单元数 ≤项目文风卡限额）
- [x] 可删性：删掉不影响情节因果
- [x] 寓教于乐：教益藏在因果里，无说教段
- [x] 热梗部分已过 `11` §3.5 六项抽检
