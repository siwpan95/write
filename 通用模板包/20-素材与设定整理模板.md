# 20 · 素材与设定整理模板（v3.15 新增）

> **本份只给形式**：六张空白表 + 填写规则 + 自检 + 一个校验脚本。不含任何题材内容，字段随项目自定。
> **一句话用途**：把「一堆散素材」变成「能查、能比对、能裁决、能交接」的表。
> **不替代**：`03` §13 的变更登记（管结果）、`04` 的人物卡（管正名）、`14` 的来源登记（管包外依赖）。本份只管**素材层怎么摆**。

---

## 〇、什么时候用 · 三步 · 与既有文件的分工

**触发条件**（任一成立即用）：

1. 同一事物有**两种以上写法**（原名/译名、旧名/新名、官方称/俗称、角色甲怎么叫它/角色乙怎么叫它），且已经开始在正文里混用；
2. 素材来自**多个来源**（原作者、百科、攻略、译本、AI 生成、自己旧稿），需要知道每一条出自哪、可信到什么程度；
3. 设定量大到**记不住在哪**——要能按类查到「这条写在第几章、用哪个口径」。

**三步**：建表（表 0 + 表 5）→ 并列填（表 1）→ 裁决（表 2 / 表 3），缺陷一律进表 4。

| 文件 | 管什么 | 本份给什么 / 不给什么 |
|---|---|---|
| **本份 `20`** | 素材层：多来源并列、空缺、缺陷、裁决过程 | 给表骨架；**不给**任何定名结论 |
| `03` §13 | 设定**变更结果**登记 + 影响章节 | 本份只把裁决后的口径交给它，不另建变更台账 |
| `04` | 人物正名、称呼、关系 | 表 3 的别名白名单是它的上游，不重复定义人物属性 |
| `06` §四 | 线头/悬念/支线计数 | 与本份无关，**不得**把素材行数当产能 |
| `14` | 包外来源与依赖登记 | 表 5 只记「来源是谁、可信到哪」，路径登记仍归 `14` |
| `19` §〇 | 行业事实 A/B/C 分级 | **本份不用 A/B/C 三字母**，见 §七 档位，两套不得混用 |

## 一、七个形式要件（要抄的就是这七条）

| # | 要件 | 形式（照这个写） | 为什么必须 | 省了会怎样 |
|---|---|---|---|---|
| F-1 | **归属行** | 表上方一行：`> 归属：M-00 台账 › M-02 地名` | 一张表要知道自己属于哪一类、上级索引是谁 | 表多了找不到，重复建表 |
| F-2 | **来源注记行** | `> 来源：A＝原表（2026-01-01 取）｜B＝译本｜C＝自撰` | 每个代号一次交代清楚，表内只写代号 | 三个月后不知道 A 是什么，整表作废 |
| F-3 | **键在首列** | 键＝不译、不改、不合并的稳定标识（原名/编号/拼音） | 行身份唯一，才能跨表对齐 | 键一改，裁决与正文对不上 |
| F-4 | **来源并列** | 每个来源一列；**一格只放一个写法**；素材层禁止「选优」 | 先把分歧摆明，裁决才有依据 | 边填边选，分歧被悄悄抹掉 |
| F-5 | **基线相对标记** | 表头下声明 `基线＝A`；**只把与 A 不同的单元加粗**（纯文本用 `★` 前缀） | 只标异常，不标正常；未加粗本身就是信息 | 全表加粗＝没有标记；逐格打勾＝徒增字符 |
| F-6 | **空缺留空** | 空＝该来源未收录；`—`＝该来源不适用；`?`＝存疑待核 | 三种「没有」含义不同，混写就查不出真缺口 | 「无/未知/待定」混用，缺口永远数不清 |
| F-7 | **按类拆表** | 一类一文件（人物/地名/器物/称谓…），不做巨表 | 更新频率、体量、可信度各不相同 | 巨表改一处要重读全表，且无法分工 |

> **F-5 的代价**：基线只能有一个。换基线＝全表加粗重算，故基线写在表头下，改动记进表 4（类型＝「基线变更」）。

## 三、表 1 · 并列主表（核心表，其余表都挂在它的键上）

> 归属：M-00 台账 › ＿＿＿＿
> 来源：A＝＿＿（＿＿ 取）｜B＝＿＿｜C＝＿＿｜D＝＿＿
> 基线＝A（与 A 不同者**加粗**；纯文本环境用 `★` 前缀）

| 键 | 来源 A | 来源 B | 来源 C | 来源 D | 备注 |
|---|---|---|---|---|---|
| M-02-001 | ＿＿＿＿ | ＿＿＿＿ | ＿＿＿＿ | ＿＿＿＿ | ＿＿＿＿ |
| M-02-002 | ＿＿＿＿ | **＿＿＿＿** | ＿＿＿＿ | ＿＿＿＿ | 与 A 分歧，待裁决 |
| M-02-003 | ＿＿＿＿ | — | ＿＿＿＿ | ? | `—`＝B 不适用；`?`＝D 存疑 |

**填法四条**（只四条，不多）：

1. **一行一个实体**。同一实体有多个写法，写在**同一行的不同列**，不拆行。
2. **同键多行只在一种情况下允许**：同名但是**两个不同实体**（重名歧义）。此时在「备注」写区分依据（出处/类别/首次出现），并进表 4 登记，不许放着不管。
3. **一格一个写法**。不要写「甲／乙」并列在格内——那是两列的事。
4. **原样抄**。素材层的错字、乱码、缺字一律先照抄，修不修由表 4 决定；边抄边改＝毁掉可回溯性。

**列数配方**（列数由「来源数」决定，不硬套 5 列）：

| 场景 | 列数 | 列序 |
|---|---|---|
| 一份原始资料 + 我的改写 | 3 | 键 ｜ 原文 ｜ 我的写法 |
| 旧稿 vs 新稿 | 3 | 键 ｜ 旧稿 ｜ 新稿 |
| 三来源对照（原作／译本／官方） | 4 | 键 ｜ A ｜ B ｜ C |
| 多来源译名或称谓并列 | 5～6 | 键 ｜ A ｜ B ｜ C ｜ D ｜ 备注 |
| 称谓矩阵（谁怎么叫谁） | 5+ | 键（人物）｜自称｜同伴称｜敌方称｜旁白称 |

> 同一文件内列数必须一致；**不同文件之间不要求一致**——这正是 F-7 拆表的理由。

## 六、表 4 · 空缺与缺陷登记（这张表决定素材能不能用）

| 编号 | 表／键 | 类型 | 现状 | 处置 | 登记日 |
|---|---|---|---|---|---|
| Q-01 | M-02-003 | 存疑 | D 列标 `?`，待核 | 待补（核完去掉 `?` 并写来源） | ＿＿＿＿ |
| Q-02 | M-02-005 | 冲突（重名） | 同键两行，译法不同 | 拆为 005a／005b，备注写区分依据 | ＿＿＿＿ |
| Q-03 | M-03-011 | 损坏（乱码） | 3 字不可读 | 保留原样 + 按上下文推定，推定值写进备注 | ＿＿＿＿ |
| Q-04 | M-02-002 | 未裁决 | 两来源分歧 | 进表 2，卷末前裁完 | ＿＿＿＿ |

**类型只用这七个**：未收录 ｜ 未译 ｜ 不适用 ｜ 存疑 ｜ 冲突（重名/异义）｜ 损坏（乱码/截断）｜ 未裁决
**处置只用这四种**：待补 ｜ 已补（写来源）｜ 不改（写理由）｜ 已覆盖（写用哪段正文盖过去）

> 乱码不许静默修：**保留原样 + 另记推定值**。静默改字＝把「当时看到什么」永久抹掉，日后无法判断是素材错还是抄错。

## 八、五道工序

| 序 | 工序 | 做什么 | 产出 | 验收（不过不进下一步） |
|---|---|---|---|---|
| 1 | 立表 | 定类、定键、定来源列 | 表 0 + 表 5 | 每份表都有归属行、来源注记行、基线声明 |
| 2 | 灌入 | 原样抄，不改字、不选优、不合并 | 表 1 | 允许空、允许乱码；**不许**出现「甲／乙」同格 |
| 3 | 体检 | 跑 `tools/tab_lint.py` | 表 4 初稿 + 覆盖率 | 列数/重复键/加粗配对 0 error |
| 4 | 裁决 | 每键选一个口径，写一句话依据 | 表 2 + 表 3 | 未裁决项全部进表 4，无悬挂 |
| 5 | 交付 | 口径写进 `03` §13 / `04`；正文只用裁决口径 | 可引用的定名表 | 正文里搜不到白名单外的写法 |

> 工序 2 **故意不设质量门**：素材层的第一价值是「没被加工过」。加工留到工序 4。

## 九、可复制空表（直接抄走）

**① 五列并列（Markdown）**

```
| 键 | 来源 A | 来源 B | 来源 C | 来源 D | 备注 |
|---|---|---|---|---|---|
|  |  |  |  |  |  |
```

**② 三列（原文 / 我的写法）**

```
| 键 | 原文 | 我的写法 |
|---|---|---|
|  |  |  |
```

**③ CSV（Excel 直接打开，首行是列名）**

```
键,来源A,来源B,来源C,备注
,,
```

> CSV 用**逗号分隔、UTF-8 编码**；格内含逗号时整体加双引号。不要用制表符（`00` §九 R-1 禁 TAB）。

## 十一、N/A 通道

**整份 N/A 的判据**（三条同时成立）：① 单来源、无第二写法；② 专名少于 20 个且未出现漂移；③ 短篇或单卷完结。

标法：`- [N/A] 本份不适用：单来源、专名 12 个、未漂移`。
即便整份 N/A，**表 4 与表 5 仍各留一行**（缺陷与来源各记一次），否则下次接手的人没有任何线索。

## 附录 · 本份形式的来源

七要件提炼自一批「同一实体 × 五来源并列」的术语对照表（17 份 / 18,915 行，其中空缺 3,534 处、差异标记 21,487 处、重名键 671 处）。原表已具备 F-1／F-3／F-4／F-5／F-7；F-2 只在 5/17 份里写了来源注记；F-6 只有「留空」一档，且**没有裁决层**——本份补的正是 F-2 的强制化、F-6 的三分类与裁决层。来源登记见 `14` D-16。

> 数字为 2026-11-18 本机实测，仅作「这套形式在真实数据上长出什么样」的参照，不是任何项目的目标值。
