# 03 · 世界观圣经模板（通用可复用）

> **单一事实源。所有写作与一致性校验都从这里取数。改了正文要同步回来。**
> 配套文件：01 立项定位 · 02 大纲/分卷 · 04 人物卡 · 05 章节模板 · 06 连载状态表 · 07 伏笔账本

---

## 使用说明（动笔前只读这 5 条）

1. **本文件是空白骨架**：表格里的 `＿＿＿＿` 是待填位，正文里不需要出现的字段也要填——作者知道得越多，笔下越省力（见 §4 冰山原则）。
2. **填不了就是还没想清楚**。尤其是 §2 规则表与 §8 的"代价/反制"两栏，空白 = 后期一定崩。
3. **先有实感，再补体系**：从具体场景（一段饭钱、一件旧物）里长出规则，别让设定先于故事生长。
4. **每个字段下斜体小字是"填写说明"**，填完可删；`> 【本书范例】` 是已完结项目《废土旅法师 / 烬地废土》的实填参照，可整行替换。
5. **改设定必须先登记**（§13），禁止在正文里不动声色地硬改。一致性脚本／人工核查以本文件 R 规则为准。

## 1. 基础设定卡

> 一页看完这本书讲什么。任何时候都能凭这张卡回到起点。

| 字段 | 内容 |

| 一句话故事 | ＿＿＿＿（谁 + 想要什么 + 挡路的是谁） |
| **时代背景** | ＿＿＿＿（年代/技术水平/与现实的差异） |
| **核心冲突（一句话）** | ＿＿＿＿ vs ＿＿＿＿ vs ＿＿＿＿ |
| 精神内核 | ＿＿＿＿（这本书到底在说什么） |
| 目标读者 | ＿＿＿＿ |
| **目标字数** | ＿＿＿＿ 万字 ｜ 卷数 ＿＿＿＿ ｜ 单卷 ＿＿＿＿ 万字 ｜ 单卷 ＿＿＿＿ 章 |
| 对标作品 | ＿＿＿＿ |

**填写说明**
- **类型标签**：最多 3 个，第 1 个决定读者搜索时在哪一类里找到你。
- **时代背景**：写"距今多少年 + 技术处于什么水平"，不要写"架空中古"。
- **核心冲突**：写三方。两方会塌成单线打怪，四方以上读者记不住。
- **精神内核**：检验标准是——把它删掉，故事是否仍然成立？成立则说明内核还没找到。
- **目标字数**：决定节奏密度，100 万字的敌人出现时机和 30 万字完全不同。

> 【本书范例】类型：穿越·废土·系统流·力量成长 ｜ 时代：平行地球，科技文明浩劫后约 100 年 ｜ 核心冲突：底层穿越者凭面板崛起 vs 废土势力垄断与阴谋 vs 终局清算倒计时 ｜ 目标 100 万字 / 5 卷 / 单卷 40-50 章。

## 3. 世界四层建构表

> **外层决定内层，因果是世界观的黏合剂**。自上而下问：地理决定了资源，资源决定了制度，制度决定了人心，人心决定了故事。填完请反向检查一遍：每一层的结果，能否追溯回上一层的因？

### 3.1 自然环境层

| 提问 | 回答 |
|---|---|
| 地形/气候：这块地方长什么样，天气对人有多凶？ | ＿＿＿＿ |
| 资源：能撑起文明的生存资源是什么？最缺什么？ | ＿＿＿＿ |
| 物种：本地食物链顶端是谁？人排在第几？ | ＿＿＿＿ |
| 灾难：周期性要命的东西是什么？多久来一次？ | ＿＿＿＿ |
| **→ 它决定了哪种生存方式** | ＿＿＿＿ |

### 3.2 社会结构层

| 提问 | 回答 |
|---|---|
| 政治：谁说了算？权力凭什么被承认（血统/武力/技术/资本）？ | ＿＿＿＿ |
| 经济：钱从哪来，劳动怎么换饭（见 §10）？ | ＿＿＿＿ |
| 军事：暴力垄断在谁手里？个体武力的天花板？ | ＿＿＿＿ |
| 法律：一条命值多少钱？犯事怎么罚？ | ＿＿＿＿ |
| 阶层：上升通道存在吗？谁被卡死在原地？ | ＿＿＿＿ |
| **→ 它决定了哪类冲突必然发生** | ＿＿＿＿ |

### 3.3 文化表层

| 提问 | 回答 |
|---|---|
| 信仰：人们信什么？为什么这种苦难下恰恰信这个？ | ＿＿＿＿ |
| 语言/称谓：有什么只在本地流通的行话、黑话、骂人话？ | ＿＿＿＿ |
| 日常：普通人一天怎么过（见 §11）？ | ＿＿＿＿ |
| 审美：他们觉得什么算体面/算耻辱？ | ＿＿＿＿ |
| **禁忌：什么绝对不能做（见下表 + §7）？** | ＿＿＿＿ |
| **→ 它决定了什么样的行为会被视为"越界"** | ＿＿＿＿ |

### 3.4 个人经验层

| 提问 | 回答 |
|---|---|
| 主角在这个世界里**身体上**最先感到的是什么（气味/疼痛/匮乏）？ | ＿＿＿＿ |
| 他最怕的具体是什么？这个恐惧是哪一层规则造成的？ | ＿＿＿＿ |
| 配角里有没有人**认同**这套秩序？他的理由是什么？ | ＿＿＿＿ |
| 一个"好人"在这个世界里要付出什么代价才做得到？ | ＿＿＿＿ |
| **→ 它决定了角色弧光的起跳点** | ＿＿＿＿ |

### 3.5 禁忌登记（文化层的果实，必填）

| 编号 | 禁忌内容 | 来源（哪个历史事件/规则） | 破禁后果 | **是否卡住主角的目标** |
|---|---|---|---|---|
| T-01 | ＿＿＿＿ | ＿＿＿＿ | ＿＿＿＿ | 是 / 否 |
| T-02 | ＿＿＿＿ | ＿＿＿＿ | ＿＿＿＿ | 是 / 否 |
| T-03 | ＿＿＿＿ | ＿＿＿＿ | ＿＿＿＿ | 是 / 否 |

**填写说明**
- 禁忌 = 张力。破禁 = 剧情。**至少要有一条禁忌直接卡死主角的核心目标**（够不到、绕不开、碰了就失去最重要的人）——否则这本书没有戏。
- 禁忌必须有来源。凭空规定的禁忌读者不买账；从历史事件里长出来的禁忌才站得住。
- 四层填完做一次**因果回溯**：§3.4 的每个心理事实，能否一路倒推回 §3.1？推不回去的，是孤立的装饰，删。

> 【本书范例】自然环境：生态战争后大气/水源/土壤全毁，辐射尘常驻 → 决定了"菌落农业 + 昆虫蛋白"的生存方式。
> 【本书范例】社会结构：李氏公司垄断配给券与医疗 → 决定了"离开公司即等于慢性自杀"这一底层冲突；禁忌 T-01：不许追问大撤离那晚的事——主角想查的真相正好压在这条禁忌上。

## 4. 设定三层深度表（冰山原则）

> **设定总量 ≈ 写进正文的 5-10 倍**。沉在水下的部分不是浪费——它是作者不慌的底气，也是读者"这世界好像是真的"的来源。
> **进入正文的唯一通道**：冲突、代价、选择。禁止用说明段解释设定。

| 深度 | 定义 | 判定标准 | 本书条目 | 是否已进正文 |
|---|---|---|---|---|
| **核心设定** | 不懂就读不懂剧情的那部分 | 删掉它，某段情节无法成立 | ＿＿＿＿ | 是 / 否 |
| 核心设定 | | | ＿＿＿＿ | 是 / 否 |
| 核心设定 | | | ＿＿＿＿ | 是 / 否 |
| **背景设定** | 作者必须清楚，读者只需模糊感知 | 影响决策与人物动机，不必解释原理 | ＿＿＿＿ | 部分 / 否 |
| 背景设定 | | | ＿＿＿＿ | 部分 / 否 |
| 背景设定 | | | ＿＿＿＿ | 部分 / 否 |
| **风味设定** | 让世界有质地的一两个词 | 删掉不影响任何情节 | ＿＿＿＿ | 偶尔提及 |
| 风味设定 | | | ＿＿＿＿ | 偶尔提及 |

**填写说明**
- **分配建议**：核心 : 背景 : 风味 ≈ 1 : 3 : 6。核心设定超过 5 条，说明你还没把它们合并；风味设定少于 3 条，正文会显得干。
- **每章新揭示≤2 条**。写手侧控制：见第 05 章模板的信息量管理。
- 每条都要回答"它**服务**哪段剧情或哪个主题"。答不上来的，移出圣经，丢进素材箱（自嗨设定也是好素材，只是不该占着事实源）。
- **Sanderson 三法则转译**：① 规则要能解释，解释不了就只配当氛围，别给数值；② 限制比能力更重要（先写 §8 代价列，再写能力列）；③ 先把已有设定用深，再新增设定。

> 【本书范例】核心：异族判定与火花转化规则（不懂就读不懂升级逻辑）｜背景：虚境四大守护者与百年契约（操控全书终局时钟，正文只透片段）｜风味：养殖员给巨型变异蟑螂起的外号"广东双马尾"（一条不解释，质感就来了）。

## 7. 势力 / 组织表

> **缺什么就抢什么，冲突由此而来**。每填完一家，先写"它缺的"再写"它要的"——顺序反了，你就会写出一堆无敌的纸片组织。

## 8. 力量体系表

> **体系的第一性问题不是"能变多强"，而是"变强要付什么、谁克你"。** 没有代价的能力三章就崩，没有反制的能力必然走向数值碾压与读者疲劳。

> 【本书范例】原力·隔空取物｜卸力/取物/短距控制物体｜代价：透支体力与血糖，用猛了当场昏睡｜反制：密闭金属容器、多点同时施压分散注意力｜代价档位：可逆消耗（第二章即可恢复）。
