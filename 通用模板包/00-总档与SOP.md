# 00 · 创作室通用模板包 · 总档与作业流程

> **这是什么**：一套从《烬地·废土旅法师》第一卷（楔子 + 40 章，约 17 万字）的完整生产实践中**逆向沉淀**出来的通用模板，
> 再用联网调研补齐了行业通行的结构/节奏/设定方法。去除了本书独有内容，可复用于任何新书或后续卷。
> **怎么用**：按工序顺序，逐个文件"填空 + 过自检"，上一道不过关不进下一道。

## 二、四条使用路径

### 路径 A：新开书（完整流程）

```
1. 填 01-立项定位      → 过"一句话故事三条验收门"，不过关退回重写；平台/品类/IP 决策先跑 12
2. 出 09-立项书         → 立项结论三行 + 文件索引 + 决策清单（01 通过当天成册）
3. 填 02 的 L1/L2/L3    → 一句话故事 / 三幕骨架 / 分卷表
4. 出 10-节拍表         → 第一卷 15 拍 + 黄金三章施工指令（动笔前）
5. 填 03-世界观圣经     → 先只填"核心设定"层，别一口气写完百科（世界中心型先跑 13 §2）
6. 填 04-人物卡         → 主角完整版 + 核心配角精简版 + 反派梯队
7. 填 05-文风卡         → 定六维指纹 + 写 500 字试写验收
8. 填 02 的 L4 章纲     → 只写一句话梗概，不写对话
9. 进 06-连载护航       → 日更 + 最小台账 / 伏笔账 / 时间线同步
10. 每卷末              → 跑 06 卷末复盘 + 11 合规体检
```

**开书包最小交付集**：一句话故事 + L2 三幕 + L3 第一卷表 + 圣经核心设定 + 主角人物卡 + 文风卡 + 前三章。

### 路径 B：写崩了求诊

先定位崩在哪一层，再只回退到那一层，不要全盘推翻。

| 症状 | 崩在哪层 | 回退到 |
|---|---|---|
| 节奏拖沓、读者说"不知道在写啥"、主线不推进 | 情节层 | `02` L3 分卷 / L4 章纲 |
| 设定前后矛盾、战力崩坏、能力无代价 | 世界层 | `03` 规则表 + 能力-代价-反制表 |
| 配角工具人、主角没成长、反派纯坏 | 人物层 | `04` 欲望-恐惧三角 + 反派梯队 |
| 文风飘、前后不像一个人写的、AI 味重 | 文风层 | `05` 文风卡 + 去 AI 味二遍流程 |
| 写不动、卡文、断更 | 执行层 | `06` 卡文急救三板斧（先判别结构型/产能型） |
| 伏笔满天飞收不回来 | 管理层 | `06` 伏笔账本 + 每卷末复盘表 |
| 被质疑 IP / 品类 / 分类（如"诸天流属流派非原创分类"） | 品类/IP 层 | `12` 先联网核实再定性（铁律：不凭印象下判断） |

### 路径 C：连载中期护航

日常只碰两个文件：`05`（写的时候）+ `06`（写前写后各 5 分钟最小维护）。
每 5 章查一次时间线，每 10 章跑一次 `06` 的一致性校验清单，每卷末做一次复盘并跑一次 `11` 合规体检。

### 路径 D：世界先行型开书（玄幻/无限流/诸天/废土/规则怪谈）

> 当"世界本身是卖点"时，先建压力系统，再放测试变量。全流程见 `13`；不适用者跳过，仍走路径 A。

```
1. 01/09 立项                → 一句话故事与核心命题过关
2. 02 只出 L1/L2            → 先定三幕骨架，不急着分卷
3. 13 §2 区域包             → 只建"第一章往外推"的一块 + 第一站；每图一条结构性矛盾
4. 03 填核心设定            → 规则/地点/势力/力量回填编号，别一口气写完百科
5. 13 §3 世界观人物         → 每图 1-2 个，先建 3 个就够
6. 04 主角卡                → 初始信念必须由世界压力反向定义（13 §4）
7. 02 L3 + 13 §5 换图卡     → 卷＝卷级图；五件套齐了再排 15 拍
8. 10 卷级节拍              → 15 拍＝进入→碰壁→学规则→用规则→付代价→离图
9. 05 文风卡                → 六维指纹 + 500 字试写
10. 02 L4 章纲 + 06 日更    → 每卷末跑 13 §6/§7 复盘
```

**世界先行最小交付集**：区域包 ×2 + 世界观人物 ×3 + 换图卡 ×1 + 信念试炼 ×1 + 主角卡（含错误信念）+ 第一章。

> **v3.5 命名说明（2026-11-10 追加）**：本节标题「四条使用路径」沿用历史命名，追加 E/F 后实为**六条**；为不改动既有正文，标题保留原样，以本注记为准。

### 路径 E：只有世界的素材（v3.5 追加）

> 适用于「一份架空国家条目／宪法草案／百科式设定文档」——**零叙事层**：无主角、无情节、无正文、无平台。
> 依据 Tserena 两轮实填验证，见 `../../Tserena/设定与参考/模板实填验证-Tserena-20261109.md` §六（优先级 1）。

```
1. 03 世界观圣经   → 条文／规则拆成可判定项；价值宣言类登记进「不可判定条款登记表」（待逐份补）
2. 13 世界先行     → 区域包／换图卡／因果链／信念试炼。**无主角时依然成立**，只依赖制度密度
3. 11 合规一致性   → 一致性 + 去 AI 味；「制度张力」单列第三档（待逐份补）
4. 12 品类 IP 前置 → 逐词核实专名、版权定性、原创设定的现实映射核查（待逐份补）
5. 04 人物卡（可选）→ 若要留「未来主角位」，只建空卡，不编生平
```

**跳过**：`01 / 02 / 05 / 06 / 08 / 09 / 10`——叙事层未出现，整批标 `N/A`，**判「不适用」而非「未过」**（见 §四 N/A 通道）。
**最小交付集**：`bible/world-bible.md` + `bible/世界地图与换图表.md` + 一致性检查 + IP 前置 + **外部事实核对表**。
**证据底座纪律**：凡涉真实世界对照（地理／历史／语言／版权），先建外部事实核对表；**未收录的事实，任何文档不得引用**。

### 路径 F：从设定集过渡到叙事层（v3.5 追加）

> **触发判据**（任一成立即视为叙事层出现）：① 确立主角及其欲望；② 写出卷纲／行程；③ 落地第一章正文。
> 此时**回头追补立项**，不要从路径 E 直接续跑，也不要重做已建的世界层。

```
1. 追补 01 → 09      → 一句话故事从**卷纲反推**（不是从百科压缩）；09 把归档素材标「基准」、正文标「草稿」
2. 回填 02 L1~L4     → 世界层已建，L2/L3 只排已定卷；L4 章纲按已写正文回填实测
3. 10 节拍表         → 启用**回填模式**：以正文为准做复核与修订指令，明确「不改正文、只出指令」
4. 04 人物卡         → 主角补齐欲望／恐惧三角；镜像角色从已建势力里挑
5. 05 文风卡         → 对已有正文跑真实文本统计；先判是否需 §1.6.2 题材校正，再定基准稿
6. 06 / 08           → 启用**轻量模式**：06 只开 §一~§七 一致性骨架；08 只跑章节自检与质量闭环；运营节整体标 N/A
7. 每卷末            → 照常跑 11 / 13 复盘
```

**覆盖率随阶段变化（实测，勿一次性判死模板）**：`4/14`（纯设定集）→ `8/14`（01/02/09/10 激活）→ `11/14`（05/06/08 激活）；`00`/`07` 为索引不参与判定。
⇒ **「模板不适用」是阶段属性，不是项目属性。** v1 曾判这 7 份「必然空转」，本轮全部实填且自检无一项因「无叙事层」失败。
**实证与全部 46 条反馈**：`../../Tserena/设定与参考/模板反哺报告-20261110.md`。

## 三、建议的目录结构（照抄即可）

```
【书名】/
├── （通用模板包/ 已上提至仓根 `通用模板包/`，三书共享，不在每书内复制）
│   └── 00-总档与SOP.md … 13-世界先行与地图叙事模板.md（空骨架，永久不变）
├── bible/                 ← 本书实例（单一事实源）
│   ├── world-bible.md         由 03 生成
│   ├── 世界地图与换图表.md      由 13 生成（只存区域压力/换图路线/因果链/信念试炼；规则与数值仍以 world-bible 为准）
│   ├── 长弧规划.md             由 02 生成
│   ├── timeline.md             由 06 生成
│   ├── plot-board.md           由 06 生成
│   └── characters/*.md         由 04 生成
├── 第XX章_标题.md        ← 正文，每章一个文件（只含标题行 + 纯正文）
└── 小说.txt               ← 正文合集（定期导出）
```

> **关键原则一：模板不动，实例动**。模板包永远保持空白骨架，本书的实际内容写进 `bible/` 与各章文件。
>
> **关键原则二：单一定义处**。同一概念若在两份模板里都出现，只在一处定义，其余文件**单向引用、不复制数值**——
> 复制一次就多一个漂移点，改一处忘一处是必然。本包已按此收口的一例：
> 「章型」的参数与判定规则唯一定义处＝`05` §2.2.1，`06` 台账只记结果——日更最小台账 4 列（章型不进台账），卷末汇总视图记章型 1 列，
> 不复制区间、不记实测数值（实测只有两个消费点：`05` §1.1 每 3 章回填、`06` §十二 W3 每 5 章抽查）。
> 以后往包里加任何跨文件字段，先问一句"它的唯一定义处是哪一份"。
>
> **结构映射可视化**：[`可视化_结构映射/`](可视化_结构映射/index.html) —— Graphviz 绘制的 `index.html` / `graph.svg` / `graph.dot`，展示模板包 00-13 如何派生到本书实例（规划集 / bible·SSOT / 落地正文 / 素材），含「正文为准·回填设定」纪律与指令⑦ git mv 归位标注。

> **关键原则三（v3.5 追加）：空白骨架不得填入实书数值／专名／纪律**。模板是「待填容器」，不是「填好的样例」。
> 凡发源书的实测值、专名表、写作纪律、范例数值，一律移入「附录·样本参考」并在正文留空（`＿＿`）。
> 实填者极易把样本当通用标准——`05` §1.1「实测值」列、`05` §1.2.2 世界词表、`08` §五八条纪律、`02` §1.1 范例值均属此类。
> 判定口诀：**模板里出现任何一部具体作品的数字或名字，就是实例倒灌。**
> 依据与治理建议：`../../Tserena/设定与参考/模板反哺报告-20261110.md` §3.1 A6（本轮治理层级最高的一条）。

### 验收门的不适用（N/A）通道（v3.5 追加）

| 项 | 规则 |
|---|---|
| 判定条件 | 该验收门的**前置品类假设不成立**（如「有平台／日更」「有金手指」「有叙事层」「有多卷卷纲」），而非「没填完」 |
| 勾选记号 | 统一用 `- [N/A]`，并写明「因 X 假设不成立」；**不得留空、不得记 0 分** |
| 分母重算 | 自检合计按 `适用项` 计分母：`合格数 / 适用项数`；`N/A` 项既不进分子也不进分母，另列一行「N/A × N」 |
| 验收效力 | 「无未过项 + 所有 N/A 项均有理由」即视为该门通过；**N/A 不构成退回重写的理由** |
| 反向约束 | 不得为凑「适用」而虚构前置条件（如为过「平台字数」编一个目标平台）；宁可标 N/A |
| 覆盖范围 | `00` 与各模板自检清单一致适用；`03` 9 项「无叙事层必然不过」、`11` 制度张力、`08`/`10` 编码与硬指标冲突均按本通道处置 |

> 实证：Tserena P2 四份实填合计 **8 项 N/A / 0 项因无叙事层空转**；`10` 快评表增设 N/A 与品类化替换后由 `13/18` 改判 `15/20`。详见 `../../Tserena/设定与参考/模板反哺报告-20261110.md` §四实证 2。
