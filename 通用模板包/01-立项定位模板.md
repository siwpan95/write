# 01 · 立项定位模板（定调层）

> 全创作室的地基。**这一层不过关，不许往下走**——大纲、设定、人物、文风全部建立在它上面。
> 使用方法：逐项填写，填完过文末自检清单；标 ⚑ 的是"不过关即退回"项。

## 0. 一句话故事（L1）⚑

> 填不出来就别开书。要求：能口头讲给别人听，对方听完能复述，且能听出"这书爽在哪"。

**公式 A（要素式）**

```
一个【什么样的主角】，在【什么背景/世界】下，面对【什么核心冲突】，
凭借【什么金手指／筹码／可依赖之物】，最终【什么结局或抉择】。
```

- 主角：
- 背景：
- 核心冲突：
- 金手指 / 筹码 / 可依赖之物：
- 结局 / 抉择：

**公式 B（因果式，推荐先用它打草稿）**

```
主角想要 ______，因为 ______，但 ______，于是 ______，最终 ______。
```

**公式 C（卖点式，用于对平台/编辑自我介绍）**

```
______ 流 + ______ 世界观 + ______ 情感锚点，主打 ______ 爽点。
```

> 于是靠旅法师面板刷异族攒火花，最终点燃火花成为鹏洛克，并面临"去多元宇宙还是回头救废土"的抉择。

### 0.1 一句话的「广告词」约束与赌注问句（v3.8 · 雪花第 1 步）

> 这一句话不是内部备忘，是**永久性的 10 秒推销工具**：给编辑、读者、平台介绍作品时用的就是它，且十有八九会成为正式简介的**第一句**。定稿后即成为全书不可删常量（对齐 `02` §1.3「删章检验的基准线」，`02` 为该检验的定义处）。

| 约束 | 要求 |
|---|---|
| 长度 | 中文 ≤30 字（越短越好；原文为英文 ≤15 词，中文本土化后放宽） |
| 不提专名 | 全句无人名／地名／体系名——写「一个身有残疾的杂技演员」而不是角色姓名；判据见 `02` §1.3，**此处不重复定义** |
| 大背景 × 小背景 | 句里必须同时看得见「**世界级设定**」与「**这一个人会失去什么**」，二者焊在一句里，不能只写世界观 |
| 赌注问句 | 落笔前先答两问：**谁在这个故事里会失去最多？他想要什么？** 答不出＝这句话还没想明白 |

*填写说明：把「赌注问句」的两个答案分别对到公式 A 的［核心冲突］与［主角］；若答案是「大家都差不多」「世界会毁灭」，说明赌注还没落到具体的人身上，退回重写。*

**永久性检验**：这句话在 L2/L3/L4 排完后仍要成立（`02` §七「收尾」已含此条）；若要改它，按 `02` §2.6「回溯修订通道」登记，不得静默替换。

### 一句话故事验收门（三条全中要过）⚑

- [ ] **可复述**：讲给一个人听，他能不看书复述出"谁 + 要什么 + 挡着什么"。
- [ ] **有爽点引擎／期待锚点**：句中能看出读者为什么追（升级 / 打脸 / 揭秘 / 守护 / 逆袭，至少一个）。**慢氛围品类**命中「揭秘／守护」时判据改为「期待锚点」——允许状态句首句与环境留白，但三章内须让读者说得出主角要什么、挡着什么（依 `00` §九 R-6，来源 S34/S35）。
- [ ] **有终极抉择**：结局处存在一个"两难"，不是单纯的"变强了"。

## 6. 立项自检清单（全部打勾才算定调完成）

- [ ] ⚑ 一句话故事三条验收门全过
- [ ] 一句话 ≤30 字、不提专名，且能同时看见世界级设定与「这一个人会失去什么」（§0.1）
- [ ] 「谁会失去最多／他想要什么」两问已答，答案能落回公式 A 的具体空位（§0.1）
- [ ] 卖点矩阵至少 3 条，每条能落到具体情节
- [ ] 核心命题是一个"两难问题"，不是一句口号
- [ ] 至少 1 个情感锚点角色（读者会因为他在乎这本书）
- [ ] 对标作品 ≥2 部，且写明差异
- [ ] 字数目标与平台匹配，更新计划是"做得到的量"（**非连载项目整项 `- [N/A]`**）
- [ ] 红线条款已写下，且具体到可判定（能一眼看出有没有违反）
- [ ] 能说出"第一卷结束时主角变成了什么样"（卷级目标已有雏形）

---

> **N/A 通道（v3.6，依 `00` §四与 §九 R-3）**：自检清单统一增设 `- [N/A]` 档。判定条件＝该项**前置品类假设不成立**（无平台／无日更／无金手指／无叙事层／无多卷卷纲／无力量体系），而非「没填完」；勾选时须写明理由，**不得留空、不得记 0 分**。分母按「适用项」重算：`合格数 / 适用项数`，`N/A` 项既不进分子也不进分母，另列一行「N/A × N」。「无未过项 + 所有 N/A 项均有理由」即视为该门通过。

## 附：定调常见坑

| 坑 | 症状 | 修法 |
|---|---|---|
| 只有设定没有故事 | 一句话故事里塞满世界观名词 | 删掉所有专有名词重写，用"谁要什么、谁挡着" |
| 只有爽点没有内核 | 写到 30 万字后主角没方向 | 补"核心命题"，让它变成主角的中期抉择 |
| 金手指与世界观两张皮 | 金手指放在任何世界都能用 | 给金手指加一条"只有这个世界才成立"的限制 |
| 卖点全是"很新颖" | 说不出具体新颖在哪 | 换成"同类型书里他们做 X，本书做 Y" |
| 没有反派动机 | 反派纯坏 | 给每个反派写一句"他为什么觉得自己是对的" |
