# 章节创作模板（统一规范 v2.0）

> 用途：本书所有章节文件的统一格式与写作规范。新章创作前先定钩子与目标，再动笔；完成后按章末钩子标准与去 AI 味指标自检。  
> 依据：`方法/调研-网文俱乐部手册方法论.md`、`方法/调研-长篇不崩与去AI味.md`、`方法/调研-平台误报规避与去AI味.md`，以及本书第一卷完整生产实践。  
> **v2.0 主要变更**：① 章字数下限从 2000 提到 3000；② 新增 §五之二「六项量化阈值」与 §五之三「情绪直说三分法」；③ 新增 §六「平台误报规避」；④ §八 改为"逐章交付自检"（原"前九章诊断"已完成，移入附录）。

## 一、文件与命名规范

| 项    | 规范                                                  | 示例              |
| ---- | --------------------------------------------------- | --------------- |
| 文件名  | `第XX章_标题.md`（章节号两位数字、短横线、2~6 字标题）                  | `第10章_白日工厂.md` |
| 标题行  | 文件正文首行标题统一为 `第X章　标题`（**全角空格 U+3000**，章序号用中文数字）      | `第十章　白日工厂`      |
| 卷目录  | 正文按卷分目录：`第一卷\`（楔子 + 第 01-40 章）、`第二卷\`（第 41-90 章）……  | ——              |
| 编码   | UTF-8，**无 BOM**                                     | ——              |
| 存档   | **正文文件只放正文**。元信息（时间线/出场/钩子/提要）统一登记在 `方法/目录与章节台账.md` | ——              |
| 场景分隔 | 换场用独占一行的 `===`（三个半角等号），语义唯一：换场/时间跳跃                 | ——              |

> ⚠️ **禁止**：正文里出现 `【字数】`、`【时间线】`、`【本章钩子】` 等元信息字段；正文里出现作者说明、求收藏、请假留言（平台会判"与小说情节无关的内容"）。

## 二、章节标准结构

```
第X章　标题
                       ← 空一行
（正文第一段，直接接上一章钩子）

（正文……）

===

（换场后的正文）

===

（再换场后的正文）
```

**四拍结构**（每章必查）：

| 拍         | 位置           | 要求                        |
| --------- | ------------ | ------------------------- |
| **接钩**    | 开头 0~200 字   | 直接回应上一章章末钩子，不另起炉灶         |
| **推进**    | 中段           | 本章目标明确：**一个主行动 + 一个信息增量** |
| **冲突/回报** | 中后段          | 小冲突或小回报；每 5~6 章一个中型以上回报   |
| **留钩**    | 结尾 150~300 字 | 见 §四                      |

**质量闭环**（平台判"水文"的口径，每章必须完整）：

> 明确目标或异常 → 人物作出选择和行动 → 现场发生变化 → 获得**结果／代价／信息／关系变化／新问题**。

低压章可以弱回报，但**不能没有功能**。

## 三、字数

| 项 | 标准 |
| -------- | --------------------------------------------------- |
| **目标区间（章型级）** | **见 `05` §2.2.1 章型参数表**（动作戏 2500-3500 / 对白戏 2500-3000 / 独白戏 2000-2800 / 过渡章 1500-2200 / 混合型 3500-4200）；平台级总览见 `05` §2.3 |
| **高潮章上限** | 4200 汉字（大场面命中 §2.2.1 第 0 步豁免情形的章可放宽至 4200） |
| **硬下限** | **2500**（低于此值即为"半章感"，推荐算法与读者"值不值"判断双重吃亏） |
| 计数口径 | 汉字数＝`[\u4e00-\u9fff]` 匹配数。**不是**文件字节数，**不是**含标点的字符数 |
| 平台参照 | 起点男频常规 2500-3500（见 `05` §2.3）；本作定位男频付费向，取区间中值附近 |

> **注水四条判据**（任一命中即删该段）：**不推动剧情 / 不塑造人物 / 不营造氛围 / 只为凑字数**。  
> 中场拖沓三修法：**删除法 / 压缩法（5 章压成 2 章）/ 加冲突**。

## 四、章末钩子（核心）

**底层原理（蔡格尼克效应）**：读者对"未完成任务"记忆更深；章末绝不能"讲完闭环"，要在"最想知道下文"处截断。

### 断点位置

- **好断点**：悬念刚出现 / 冲突将爆发 / 谜底将揭晓 / 转折前一刻
- **禁断**：爽点刚爆发 / 正高潮中 / 对话说一半  
  → **例外**：本书可用"伏笔截断（对话说一半）"技法，但**每卷不超过 3 次**，且必须后文有回收。

### 五种技法（轮换使用，**不可连续两章重复同一技法**）

1. **叙事诡计**（信息差）：读者知道而角色不知道
2. **反常悬置**：抛出反常现象不给解释（**必须有后文回收**）
3. **伏笔截断**：回收伏笔的关键句处戛然而止
4. **身份反转**：章末揭示某角色真实身份
5. **危机倒计时**：明确剩余时间，压到极限

### 四种驱动力（轮换组合）

| 驱动   | 读者状态  | 有效跨度    |
| ---- | ----- | ------- |
| 悬念钩子 | 想知道答案 | 短 1-3 章 |
| 危机钩子 | 担心出事  | 中 3-5 章 |
| 反转钩子 | 原来如此  | 即时      |
| 情感钩子 | 在乎角色  | 跨卷长效    |

### 红线

- **爽点预告 > 求知**：强钩子不是"门外站着一个人"，而是"门外站着的正是当年送他进监狱的人"——让读者相信**下一章有大戏**，而不只是好奇。
- **不收在**：总结 / 抒情 / 主题升华 / 作者旁白。
- **不出现**"下一章会……"的预告腔。
- **不用虚狠话凑数**。

### 黄金三章职责（新书/新卷首章通用）

| 章    | 章末钩子职责                  | 本作落实               |
| ---- | ----------------------- | ------------------ |
| 第一章末 | 认知缺口——留下无法不追问的问题，不展开世界观 | "我到底，在哪？"          |
| 第二章末 | 危机升级——局面更糟，不重复第一章套路     | 门外有什么东西正靠近         |
| 第三章末 | 长线钩子——小闭环后引出更大主线谜团      | 黑市帐篷回闪："那个帐篷早晚要掀开" |

> **数据参照**（网文俱乐部）：90% 读者在前三章决定去留；前三章流失约 50% 读者（100 人进 → 第 2 章剩 60-70 → 第 3 章剩 40-50）。

## 五、每章信息量与伏笔管理

- **新设定 ≤ 2 条/章**；新人物首登场给 **1 个记忆点**（外貌 / 口癖 / 动作，不堆三项）。
- 每章至少更新一处**伏笔账本**（埋设 / 推进 / 回收），对照 `bible/plot-board.md`。
- **同时活跃的悬念线控制在 3~4 条**；小悬念 1~3 章内回收，大悬念跨卷。
- 每章结尾把"下一步必须做什么"交代清楚（即使主角选择不做，也要让读者知道他该做什么）。
- **设定不许"倾泻"**：设定靠情节、动作与对话带出。单段超过 200 字的"说明书"式文字，必须拆分或改写。

## 五之二、六项量化阈值（引用副本 · 唯一定义处＝`05` §1.6）

> **本模板不重复维护数值**：以下六项阈值的**唯一定义与登记处是 `05-文风卡与章节规范模板.md` §1.6**，章型级对话占比另见 `05` §2.2.1。开新书改文风卡即自动同步，本处只列消费点，不抄数值。
>
> 消费点速查：句长错落度（变异系数 ≥0.70）/ 对话占比（章均 25%-33%，章型级见 §2.2.1）/ 逐字复读滑窗（≥12 字同章跨章 0 处）/ 回报密度（中型以上每 5~6 章 1 次）/ 希望锚点率（每 3 章 ≥1 物件或动作）/ 情绪直说 B 类（每 3000 字 1~3 次，见 §五之三）。
>
> ⚠ 原"成对高危章"清单（第 10↔11、17↔79 等）为《烬地·废土旅法师》本书实例专属，新书包不继承；换书后由一致性脚本按自身章节重算。

### 感官配额

| 感官     | 配额                                                  |
| ------ | --------------------------------------------------- |
| **听觉** | **每章 ≥2 处**（虚空/黑暗场景中唯一可用通道，优先级最高）                   |
| 视觉     | 不设上限（基础通道）                                          |
| **嗅觉** | **≤1 处/千字，且必须有功能归属**（判食物／判辐射／判血腥／判身份）。**禁止为氛围而写气味** |
| 触觉     | 每章 ≥1 处（与"代价物证"绑定最佳）                                |
| 味觉     | 每章 ≥1 处（与"吃"的场景绑定——本作食物是核心意象）                       |
| 体感     | 不设上限（代替情绪命名的主力）                                     |

## 五之三、情绪直说三分法（引用副本 · 唯一定义处＝`05` §1.2.6）

> 完整定义、类别判定与执行结论（A 类演、B 类直说、C 类删）**唯一定义处＝`05` §1.2.6**，本处不重复维护。
> 速记：B 类（关系性/时间性情绪，如认命/释然/羞耻）**允许且必须直说**，每 3000 字 1~3 次；C 类（程度副词+抽象情绪名词）一律删除；A 类走演出路线。对白里可以有情绪词。

## 六、平台误报规避（v2.0 新增）

> 完整清单（44 条）见 `方法/调研-平台误报规避与去AI味.md` §十。此处只列写章时必须落地的硬条。

### 6.1 敏感情节的意象化写法

| 原写法（高风险）        | 改写法                                 | 理由           |
| --------------- | ----------------------------------- | ------------ |
| 直接描写内脏、断肢       | 写**声音与气味**："一声闷响""铁锈味在嘴里泛开""他没敢低头看" | 保留冲击力，规避血腥词表 |
| 连续暴力动词（砍、剁、剖、插） | 写**受力与后果**："骨节错开""他半个身子砸在门框上弹了一下"   | 动作结果替代动作本身   |
| 尸体、死尸、血肉        | **遗骸 / 那具东西 / 壳 / 空壳**              | 冷感更强，且不触词    |
| 药物、注射、麻醉        | **中和剂 / 针剂 / 一管东西**                 | 弱化药物标签       |
| 爆炸、炸毁           | **塌 / 掀开 / 亮了一下 / 那片区域空了**          | 结果化          |
| 自伤、同归于尽         | **抵命 / 没打算回来**                      | 语义等价         |
| 恐怖分子、邪教         | **教派 / 那伙人 / 灰袍**                   | 弱化标签         |

> **注意**：本作是废土题材，必要的残酷**必须保留**——删掉残酷等于删掉题材。改写的是**用词路径**，不是**残酷程度**。

### 6.2 去 AI 味高发句式（引用副本 · 唯一定义处＝`05` §3 / §1.2 系列）

> 完整句式清单、改写五步、反向边界（哪些"看着像 AI 味"其实不用动）**唯一定义处＝`05-文风卡与章节规范模板.md` §3（去 AI 味五步）与 §1.2 系列（禁用词/禁用句式）**，本处不重复抄表。
> 写章时最常被命中的高频项（速记）：`不是……而是……` 每章 ≤1 处；`仿佛/宛如/似乎` 每千字 ≤2；`他知道/他明白` 排比删；破折号 ≤3 处（弱信号，见 `05` §1.1）；冒号提示语 0 处；弱化副词 ≤3 个/千字。其余以 `05` 为准。

### 6.3 反向边界（不误杀 · 唯一定义处＝`05` §3）

> 以下看着像 AI 味、但实测与人类写作无差别，**不要动**：句长/段长不够参差、句内同构排比、被动句、比喻本身、问句与设问、名词化长句、正文里的"首先……其次"。单字虚词（就/很/了）AI 确实偏少，方向是**补**不是删。完整清单见 `05` §3。

### 6.4 合规自爆项（写章时零容忍）

- 正文里**不得**有求过审、求收藏、请假说明、作者吐槽、小剧场
- **不得**用拼音/首字母/谐音错字替代敏感词（平台明文禁止）
- **不得**有 QQ 群号、微信号、公众号、"加我进群"、二维码
- **不得**出现万智牌/DND 官方专有名词（英文原名、官方位面名、官方人物名）
- 涉及未成年角色（**魏小雨未满 18 岁**）：**不得有任何恋爱/身体擦边描写**

### 6.5 排版

- **段落 ≤3 行**（手机阅读为主，每段约 50~150 字）
- **对话单独成段**；连续对话交替分段；对话与动作、心理描写分开
- 标点全角：引号 `“”`；省略号 `……`；破折号 `——`。数字可按习惯半角（"4%"、"3-C"）
- 面板文本用 `【】`（本作体例，须全书一致）

## 七、写作纪律（本作特有）

1. **他算账**：主角做决定时心里有数字（配给券、工时、火花百分比、还差几天）。
2. **他不解释**：对家人承认"我变了"，但不解释穿越与面板（第 29 章为定例）。**全书五卷从未向任何人解释过**。
3. **失忆不写独白**：黑色法力的代价必须写成**能力退化／行为变形／习惯丢失**，让读者和主角同一秒发现。
4. **每次变强都标价**：任何收益都要配一个具体的代价物证。
5. **不换地图靠换层次**：同一地点用"白班／夜班／地上／地下"制造空间变化。
6. **反派不空转**：每个反派必须有实质出场，不能只活在对话里。
7. **配角不工具化**：每个角色出场都要推进一件事。

## 八、逐章交付自检清单（v2.0）

> 本清单引用的所有文风阈值（字数/对话占比/破折号/感官/情绪等），**唯一定义处均为 `05`**；改文风卡即自动同步，本处不重复写数值，只列勾选项。

**内容与一致性**

- [ ] 章末钩子类型与上章不重复；断点位置合格，不是禁断
- [ ] 四拍完整（接钩 → 推进 → 冲突/回报 → 留钩）
- [ ] 本章新设定 ≤2 条；主角下一步该做什么已交代
- [ ] 本章至少 1 个回报（小回报亦可）
- [ ] 出场人物/伤情/随身物品与 `bible/` 记录一致
- [ ] 时间线与 `方法/目录与章节台账.md` 一致（未新增天数、未跨天错乱）
- [ ] 未让已死/不在场角色出场
- [ ] 角色未说出他不该知道的事（对照 `小说创作完整框架.md` §5.4）
- [ ] 面板文本与数值与 `bible/world-bible.md` §2f 一致
- [ ] 未提前泄露后文真相

**文字质量**

- [ ] 汉字数见 `05` §2.3 / §2.2.1（本书常规 2500-3500，高潮 ≤4200）
- [ ] 至少 3 处动作分解、1 处路人侧写（≤3 处）、1 处代价/收益物证
- [ ] 感官配额达标（听觉 ≥2、触觉 ≥1、味觉 ≥1、嗅觉 ≤1/千字且有功能）
- [ ] B 类情绪直说 1~3 次，且未放在动作戏中间
- [ ] `不是……而是……` ≤1 处
- [ ] `仿佛/宛如/似乎` ≤2 处/千字
- [ ] 破折号 ≤3 处（弱信号，用法约束见 `05` §1.1）；冒号提示语 0 处
- [ ] 弱化副词 ≤3 个/千字
- [ ] 无"这就是……""他终于明白……"类总结抒情收尾
- [ ] 段落长短交错，存在单句成段
- [ ] 同章"废土"≤5 次、"辐射"≤6 次、"沉默"≤2 次、"灰/熵/虚空/位面"各 ≤6 次
- [ ] 与成对高危章无 ≥12 字逐字重复

**格式与合规**

- [ ] 首行 `第X章　标题`（全角空格）；无元信息头
- [ ] `===` 仅用于换场
- [ ] UTF-8 无 BOM；段落 ≤3 行
- [ ] 标点全角；无半角混排
- [ ] 无联系方式/引流/作者留言
- [ ] 无万智牌/DND 专有名词
- [ ] 暴力与身体伤害只写结果与代价，不写器官与创口

| 8 | "这一次，他的眼神比之前更专注了"    | 情绪收尾        | ✅已修复：改收在反常悬置（石棉板后传来更沉的异响）         |

**共性结论**：弱钩的修法统一为"把下一章开头的动作/声音/画面前移半拍到本章末"，并同步做跨章衔接。
