## 三、字数口径与质量闭环（05 没有的部分）

- 目标区间 / 高潮上限 / 平台参照：见 `05` §2.3 / §2.2.1。
- 计数口径：汉字数＝`[\u4e00-\u9fff]` 匹配数，**不是**文件字节数、**不是**含标点字符数。
- **平台连载档的字数下限按 `05` §2.3 对应平台行取**（v3.9 订正）：起点／晋江类 3000 字章项目，2500 字为最低可发线，低于即"半章感"；番茄／飞卢类短章项目按该平台「常规区间」下限取（番茄最低发布线 1000 字），**不得一律套 2500**。
- ✅ **非平台／短章通道（v3.6 新增）**：无目标平台、按阶段制推进、慢氛围短章项目**不设硬下限**，以本节的**质量闭环**为唯一判据；§六第 5 项「字数落章型区间」标 `- [N/A]`，`05` §2.3 平台列同步标 N/A。**不得为凑「适用」虚构一个目标平台**（`00` §四 反向约束）。
- **质量闭环**（平台判"水文"的口径，每章必须完整）：明确目标或异常 → 人物作出选择和行动 → 现场发生变化 → 获得**结果／代价／信息／关系变化／新问题**。低压章可以弱回报，但**不能没有功能**。
- **注水四条判据**（任一命中即删该段）：不推动剧情 / 不塑造人物 / 不营造氛围 / 只为凑字数。
- 中场拖沓三修法：删除法 / 压缩法（5 章压成 2 章）/ 加冲突。

## 四、平台误报规避（05 没有的硬条）

> 去 AI 味句式、反向边界、改写五步见 `05` §1.2 / §3，本节不重复。

### 4.1 敏感情节的意象化写法（改写对照表 · **v3.6 标可选**）

> **08-6（v3.6）**：本节 4.1 为**平台发布设计**，无平台项目标 `- [N/A]`（可保留作修辞参考）；**4.2「合规自爆项」为通用底线，任何项目均须执行**（正文不得有作者留言／引流／联系方式／他人 IP 专名）。

| 原写法（高风险） | 改写法 | 理由 |
| --------------- | ----------------------------------- | ------------ |
| 直接描写内脏、断肢 | 写**声音与气味**："一声闷响""铁锈味在嘴里泛开""他没敢低头看" | 保留冲击力，规避血腥词表 |
| 连续暴力动词（砍、剁、剖、插） | 写**受力与后果**："骨节错开""他半个身子砸在门框上弹了一下" | 动作结果替代动作本身 |
| 尸体、死尸、血肉 | **遗骸 / 那具东西 / 壳 / 空壳** | 冷感更强，且不触词 |
| 药物、注射、麻醉 | **中和剂 / 针剂 / 一管东西** | 弱化药物标签 |
| 爆炸、炸毁 | **塌 / 掀开 / 亮了一下 / 那片区域空了** | 结果化 |
| 自伤、同归于尽 | **抵命 / 没打算回来** | 语义等价 |
| 恐怖分子、邪教 | **教派 / 那伙人 / 灰袍** | 弱化标签 |

> 原则：残酷程度不删（删掉残酷等于删掉题材），改的是**用词路径**。

### 4.2 合规自爆项（写章时零容忍）

- 正文里不得有求过审、求收藏、请假说明、作者吐槽、小剧场
- 不得用拼音 / 首字母 / 谐音错字替代敏感词（平台明文禁止）
- 不得有 QQ 群号、微信号、公众号、"加我进群"、二维码
- 不得出现万智牌 / DND 官方专有名词（英文原名、官方位面名、官方人物名）——本书按 `12` 品类 IP 前置先核实
- 涉及未成年角色不得有任何恋爱 / 身体擦边描写（换成**本书自己的**未成年角色登记）
- **AI 参与生成的内容按《人工智能生成合成内容标识办法》（2025-09-01 施行）与平台规则处理**：发布时主动声明／使用平台标识功能；**不得删除、篡改、伪造、隐匿标识**。平台侧同时把「AI 粗制滥造」列入低质治理（番茄 2026 年已将其列为严禁行为并批量拒签），因此「去 AI 味」不只是文风问题，也是**账号安全**问题（详见 `11` §1.4）

| # | 纪律槽位 | 本书填法 | 生效范围 |
| --- | --- | --- | --- |

| 7 | 引用／档案／面板文本的统一体例（无则标 N/A） | ＿＿＿ | 全书 |

> **08-4 非升级型项目纪律示例（v3.6 新增，只演示"怎么填"，不是标准答案）**：
> ① 主角遇事先找**能作证的东西**，不找能打赢的人；② 规则由**窗口／文书／办事员的动作**给出，不由旁白解释；③ 每次「办成一步」都留一张**回执或存根**作为代价物证；④ 同一地点用「队首／队尾／窗口内／窗口外」制造层次变化；⑤ 无反派时，**对抗力量＝制度本身**，本条标 N/A 但须在世界圣经登记；⑥ 配角每次出场至少改变一件文书的状态。
> 注：以上示例来自 Tserena 而非发源书，仅用于说明「无升级体系时纪律仍可写」；新书须按自身设定重写。

## 附录 · 样本参考（v3.6 自正文迁出）

> 依据 `00` §三 **关键原则三**：空白骨架不得填入任何实书数值／专名／纪律。以下为原 §五八条写作纪律，全部来自发源书《烬地·废土旅法师》，**只作参考、不是通用标准**；正文已改为空白纪律骨架 + 非升级型示例。

### 原 §五 写作纪律（发源书实例）

1. **他算账**：主角做决定时心里有数字（配给券、工时、火花百分比、还差几天）。
2. **他不解释**：对家人承认"我变了"，但不解释穿越与面板。**全书从未向任何人解释过**。
3. **失忆不写独白**：能力的代价写成**能力退化／行为变形／习惯丢失**，让读者和主角同一秒发现。
4. **每次变强都标价**：任何收益都配一个具体的代价物证。
5. **不换地图靠换层次**：同一地点用"白班／夜班／地上／地下"制造空间变化。
6. **反派不空转**：每个反派必须有实质出场，不能只活在对话里。
7. **配角不工具化**：每个角色出场都要推进一件事。
8. 面板文本用 `【】`（体例，须全书一致）。
