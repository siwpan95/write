# 10 · 节拍表与黄金三章施工模板（节拍/施工层 · v3.6）

> 把 `02-大纲四层模板` 的 L3/L4 落成**可执行的章节节拍 + 可落笔的施工指令**。
> 两件套：① 节拍表（全书 → 卷 → 单元案三级）；② 黄金三章施工方案（逐段指令，正文不代写）。
> 用法：先出节拍表锁结构，再出黄金三章施工指令；`06-连载护航模板` 负责日常。
> **v3.6 适用范围声明**：本模板默认「动笔前出施工指令 + 快节奏爽文开局 + 一卷一图 + 有单元案」。v3.6 起支持 **回填模式**（正文已落地，只出复核/修订指令）、**慢氛围品类**（R-6）、**卷／换图链多图**、**换图案口径**（非单元剧）与 **`- [N/A]` 三态评分**。详见 §〇、§1.2、§1.3、§二、§三。

## 〇、何时用

- 大纲 L3 分卷表通过后，动笔前出第一卷节拍表；
- 每卷开写前，出该卷节拍表 + 黄金三章施工指令；
- 落地正文与规划冲突时，以正文为准回填节拍表（不回改正文）。
- **回填模式（10-5 / P4-8 / v3.6）**：正文已落地后，本模板改为「**以正文为准做复核与修订指令**」——**不改正文，只出指令**。触发判据＝存在成稿章；此时节拍表按成稿回填，施工指令以「段级复核 + 待改项」形式登记并交后续阶段执行；「不动好笔」清单优先级最高，未经裁定不删成稿。

## 二、黄金三章施工方案（逐段指令，正文不代写）

> 粒度承诺：每条指令写清"改哪一段、删多少字、加什么句"，作者拿去就能改。示例片段仅示写法，≤全文 20%。

### 0. 执行口径

- **章节命名**（拆章文件制）：`第XX章_标题.md`，文件内只含标题行 + 纯正文；**编码以仓库规范为准（`UTF-8-SIG + LF`，见 `00` §九 R-1），模板不硬编码编码**（10-6 / A3）。单文件草稿制见 `08` §一。
- **冲突裁决原则**：正文为准、回填设定；所有改动逐条列入"设定回填清单"。
- **全局红线**：好笔不动；禁用"突然/竟然/没想到"硬转折；章末禁伪钩子；单次设定信息 ≤ 两句。

> **10-7 / P4-16 N/A 档与分母重算**：第三态记 `- [N/A]` 并写明「因 X 假设不成立」；**不得留空、不得记 0 分**。合计按 `实得分 / (适用项数 × 2)` 归一到 20 分，或并列「实得分 / 适用项满分」双口径；N/A 项不进分子也不进分母，另列「N/A × N」。实证：Tserena 四章按原表 `13/18`（强制记 0 则 `13/20`），改判据 + N/A 档后 **`15/20`**（`模板反哺报告-20261110.md` §四实证 2）。
