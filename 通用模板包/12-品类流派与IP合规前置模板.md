# 12 · 品类流派与 IP 合规前置模板（品类/IP 前置层）

> **本模板是两次真实纠偏的反面教材沉淀**：曾把"诸天无限-诸天"误判为"原创分类"→ 误判 IP 下架级风险；曾把"母亲灯下抬头"误判为"生死矛盾 P0 硬伤"。
> 根因都是**没联网核实品类常识 + 没逐字细读原文**。本模板把"先核实再下判断"固化成必跑前置。
> 何时用：定平台/分类时；正文用到他人 IP 元素（战锤/漫威/影视/游戏世界）时；被质疑 IP/品类时。

---

## 〇、三条铁律（前置，不过不往下走）

1. **品类常识先联网核实，禁止闭门造车式风险评估**——"原创分类/流派/同人惯例"必须查，不靠记忆拍脑袋。
2. **原文细节必须逐字细读再定性**——别把伏笔误判成硬伤；定性前先列全部相关行号互证。
3. **报告只给风险与选项，不代改正文**；法律灰色与行业惯例之差，明确标注"连载无需处理 / IP 开发时需换皮"。

| 一级分类性质 | 是"流派"（如诸天无限）还是"原创分类"？ | |

### 1.2 流派区分速查（易混点）

| 流派 | 核心机制 | 与大杂烩的关系 | 代表 |
|---|---|---|---|
| 无限流 | 主神/系统强制任务 + 奖惩 + 团战 PVP + 兑换强化 | 穿影视/游戏世界是常规 | 《无限恐怖》 |

## 二、IP / 同人合规核查

### 2.1 三问法（决定"连载要不要处理"）

1. **在架先例**：该 IP 的同人/缝合文在目标平台是否大量在架、正常连载？→ 搜"IP名 + 平台"取 ≥3 个在架实例。
2. **是否流派惯例**：本书所用该 IP 元素，是否属于所在流派的常规玩法（如诸天流穿战锤）？
3. **法律 vs 行业惯例差**：未授权同人商用仍属法律灰色；但**连载层面**行业惯例普遍放行，**仅在 IP 开发/出版时需换皮原创化**。

### 2.2 逐词核实表（用到的每个疑似专名填一行）

| 专名 | 是否历史公共符号（如双头鹰=拜占庭） | 是否 GW/厂商核心专名 | 连载风险 | 备注 |
|---|---|---|---|---|

### 2.3 换皮预案（仅在 IP 开发/出版时启用，连载阶段不碰）

- 每个核心专名备 2 个原创替换候选，保留"结构/权力关系"不变（见 `11` 模板 1.3）。
- 唯一可保留真实历史锚点的词：本身是公共符号、且作者已自写真实历史出处的（如双头鹰）。

## 三、原文细读纪律（防"伏笔误判硬伤"）

### 3.1 三遍读法规程

1. 定位：把所有相关行号列出（如"母亲灯下抬头"出现在第 21/23/26/398/399 行）。
2. 互证：逐行对照，判断是否自洽 / 是否构成伏笔闭环。
3. 定性：请作者拍板前，**不擅自给改文方案**；若判为伏笔，在报告里写明"正文已证·不回改"。

### 3.2 伏笔 vs 硬伤 判定表

| 信号 | 偏向伏笔 | 偏向硬伤 |
|---|---|---|
| 后文有明确点破/回收 | ✅ | |
| 多处互文互证、非孤立 | ✅ | |
| 仅两处表面冲突、无其他支撑 | | ⚠ 待查 |
| 作者亲笔定性（如"不像真的"） | ✅ 闭环 | |

## 四、联网核实 SOP（禁止脑补）

- **搜索词模板**：`平台名 + 分类名 + 在架/同人/缝合`；`IP名 + 平台 + 同人现状`；`流派名 + 定义 + 与无限流区别`。
- **源要求**：≥3 个独立源（平台站内搜索 + 行业文章 + 社区讨论），记录 URL 与日期。
- **输出**：把核实结论写进立项书/合规报告，附来源，避免"记忆型误判"复发。
