> 一套从长篇连载实践中逆向沉淀、再经联网调研补齐的**空白骨架模板包**：从"一个想法"做到"日更不崩"。
> 版本：**v3.12（2026-11-13）**｜适用：网文长篇连载、系列短篇、设定集型项目（含零叙事层）

## 一、三分钟上手

1. 解压后先读 **`00-总档与SOP.md`**（总索引 + 六条使用路径 + 验收门）。
2. 按路径选入口：
   - **新开书** → §二 路径 A（01 → 09 → 02 → 10 → 03/04 → 05 → 06）
   - **写崩了求诊** → §二 路径 B（先定位崩在哪层，只回退那一层）
   - **连载中期** → §二 路径 C（日常只碰 05 + 06）
   - **世界中心型**（玄幻 / 无限流 / 诸天 / 废土 / 规则怪谈）→ §二 路径 D
   - **只有世界观素材、没有故事** → §二 路径 E；叙事层出现后 → 路径 F
3. 每道工序填完过文末**自检清单**；不适用项标 `- [N/A]` 并写理由（那是"不适用"，不是"没填完"）。
4. 打包 / 分发前跑一次自检：`python3 tools/check_package.py`。

## 三、这份包为什么"解压就能用"

模板最怕两件事：**链接点开是空的**，和**照着填才发现规则自相矛盾**。v3.9 针对这两点做了治理：

| 风险 | 做法 |
|---|---|
| 正文引用原仓路径，分发后全部失效 | 包外引用全部登记进 `14`（D-01~D-11），正文就地标「（包外，见 `14` D-xx）」；每份文件都给出**包内替代**（各份文末「附录 · 样本参考」）；v3.11 起 `15` 直接就地提供 40 页逐字样例，出处逐条登记在 `14` §七 |
| 同一参数两处不一致（章型 / 字数 / 对话占比 / 破折号） | 逐条收口到「单一定义处」：章型＝`05` §2.2.1；一句话故事＝`01` §0；文风阈值＝`05` §1.1 / §1.6；编码＝`00` §九 R-1 |
| 平台规则 / 法条过期 | `14` §五 登记 8 条联网核实结论（含来源与访问日期）；平台类事实标注「每卷末复核」 |
| 压缩包本身乱码 / 损坏 | 全部 `.md` 统一 **UTF-8-SIG（带 BOM）+ LF**；随包提供 SHA256 清单与自检脚本 |
| 改一处忘一处（同一参数多处漂移） | `14` §三.1「参数 → 唯一定义处」表；历史 bug 写成 `tools/regression_checks.txt` 的**防回归断言**，复发即 ERROR |
| 平台规则过期后仍在用 | `14` §四「复核日程 + 复核记录」，挂到 `06` §11.3 卷末交接第 5 项（每卷末 10 分钟） |

## 四、编码与校验

| 项 | 规格 |
|---|---|
| 文本编码 | UTF-8 **with BOM**（`UTF-8-SIG`）——Windows 记事本 / Word 直接打开不乱码 |
| 换行 | LF（Unix），已统一，无 CRLF 混入 |
| 校验命令 | `python3 tools/check_package.py`（在包根目录执行；也可传路径） |
| 完整性 | `MANIFEST.sha256`：`sha256sum -c MANIFEST.sha256`（Windows 可用 `certutil -hashfile <file> SHA256` 逐项比对） |
| 自检覆盖 | 21 份文档；1,096 处文件引用、632 处节引用、485 处路径、266 张表 / 1,760 行表格、30 条防回归断言 |

> 若解压后中文文件名乱码：用 7-Zip / Bandizip 打开并选 **UTF-8** 编码，或直接用 macOS / Linux 的 `unzip`。本包 zip 已置 UTF-8 文件名标志位。

## 五、边界（别拿它做它不做的事）

- `00`~`14` 是**空白骨架**，不含实例书正文；`15` 是**逐字摘录的填法样例附录**（两册各 20 页），只用来看「填好的样子」，**不是可照抄的标准答案**；`07` 与各份附录给的是更短的字段级示范。
- 模板里出现的具体数字一律是**参考区间**，实填要用自己 500 字试稿 / 实测数据覆盖（`00` §九 R-2）。
- 报告只给风险与选项、**不代改正文**（`11` / `12` 铁律）。
- 本包不构成法律意见；IP 与合规判断须按 `12` 逐词核实并留痕。
