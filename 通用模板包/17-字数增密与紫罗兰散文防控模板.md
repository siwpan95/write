# 17 · 字数增密与紫罗兰散文防控模板（通用可复用 · 中性版）

> 用途：为任何叙事项目提供**合法的扩写增密方法**——专治两类病灶：①真人作者的"堆砌辞藻"（紫罗兰散文，purple prose）；②AI 生成文本的"极简化"（干净但没有生活、字数干瘪）。核心洞察：**真人容易陷入的堆砌困境，逐条逆用后恰是 AI 极简化的救命稻草**——增密不增修饰，增的是承重的字。
> 依据：紫罗兰散文病理清单（F-14 类调研）逐条逆用。
> 中性化声明：本模板不含项目专属设定；项目字数目标、词汇域由项目文风卡决定。
> 配合文件：`05-文风卡与章节规范模板.md`（指标区间）、`16-喜剧节奏与无厘头手法模板.md`（喜剧增密位）、`11` §3.5（热梗密度）。

## 一、病理：紫罗兰散文的七条成因（先认清要避免什么）

| # | 病理 | 典型症状 |
|---|---|---|
| 病1 | 不信任场景会自己说话 | 作者怕素写无聊，用"金色午后阳光像蜂蜜淌在大理石台面上"补偿 |
| 病2 | 修辞密度≠深度 | 形容词/副词堆到"句子呻吟" |
| 病3 | 比喻过量 | 每段一个新比喻，比喻之间互相打架 |
| 病4 | 词库滥用 | 生僻华丽词替换正常用词 |
| 病5 | 描写抢戏 | 读者记住的是句子不是故事 |
| 病6 | 把 show 做成形容词倾倒 | "她很伤心地流着悲伤的眼泪" |
| 病7 | 描写游离基调 | 冷面爽文里突然来一段抒情散文 |

## 二、逆用：七条合法增密指令（每条=一个"承重扩写位"）

> **总原则**：增的字数必须承重——删掉它，会损失**因果、情绪、世界感**三者之一。三者皆不损的字，叫修饰，一律不加。

| # | 反面清单 | 逆用后的增密指令 | 承重判据 |
|---|---|---|---|
| 密1 | 病1 场景怕平淡就化妆 | **给场景加"事件"而非形容词**：让环境卷入情节（茶在杯里晃，因为楼下有车灯扫过；果盘摆得越贵，越显出昨天的耳光响） | 删掉后场景因果是否受损？受损=合法 |
| 密2 | 病2 修辞堆叠 | **用信息密度替代修辞密度**：每段至少加一行信息增量（行话/价码/身份/规则），不增加一个形容词 | 新增句里名词>形容词 |
| 密3 | 病3 比喻过量 | **比喻限量但允许"第二跳"**：同一处，一个比喻+它的落地或反转（"像一条被踩了尾巴的蛇，抖个不停"——比喻+动作后果），总量仍守文风卡上限 | 比喻后半句必须做事 |
| 密4 | 病4 词库滥用 | **分层复现**：同一事物在三个词汇层各出现一次（叙述层叫冷饭/行话层叫"洗地对象"/主角内心层叫"等待点"）——复现合法，生僻替换非法 | 复现出现在不同层 |
| 密5 | 病5 描写抢戏 | **让描写持枪上岗**：每个描写段带一个可判定后果（埋伏笔/付代价/递钩子），不带后果的描写段 ≤1/章 | 描写段末尾有"钩" |
| 密6 | 病6 形容词倾倒 | **show 的合法姿势=过程分解**：一个动词拆三拍（侧身，抬手，拧腕，压肘）；陈述句展开为"动作+生理反应+时间流"（九针计时写法） | 展开的部分有实时信息 |
| 密7 | 病7 游离基调 | **潜台词回合**：对话扩写不加新信息，只加攻防回合（追问-闪避-再追问）；主角独白扩=内心账本（军令体自检，贴人设腔） | 每个回合改变攻防位置 |

## 三、五个现成扩写位（拿来即用，全部承重）

| 扩写位 | 位置 | 内容 | 字数产出 |
|---|---|---|---|
| 位1 呼吸拍 | 高强度段之间 | 冷面反差句、单字成段、环境一瞥（带后果） | 30-80/处 |
| 位2 生活纹理 | 章首/转场 | 配角日常（家庭群、保洁闲谈、行话报价）=生活气息+世界观 | 100-250/处 |
| 位3 潜台词回合 | 关键对话 | 攻防加一两个回合，信息不变位置变 | 150-300/处 |
| 位4 过程分解 | 动作/专业场面 | 时间流+生理反应+专业细节（可观测代价） | 150-300/处 |
| 位5 心理账本 | 章末/决策前 | 主角军令体自检（真气/暴露层级/底线清单） | 80-150/处 |

**配额纪律**：单章启用扩写位 ≤3 个；每章增密后必须重跑文风指标（均句长/逗号密度/破折号红线）——增密不许把指标挤出参考区间。

## 四、实操练习（5 分钟）

取一个 300 字的干瘪场景，按顺序做：

1. **找承重点**：这章的因果/情绪/世界感各是什么？
2. **选两个扩写位**（位2+位3 或 位4+位5）；
3. **写完跑紫罗兰检验**：逐句自问"删掉这句，丢的是承重物还是修饰？"——丢修饰的句子删除；
4. **跑指标**：均句长不超标、形容词增量 ≤3、比喻总量不破限。

**合格判据**：①字数达标且删章检验仍过（无水章）；②新增句信息密度合格（名词>形容词）；③指标不出区间；④朗读一遍无"腻感"（腻=修饰泄漏）。

## 五、自检清单

- [x] 每处扩写可归入七个增密指令之一（标号）
- [x] 承重检验通过（删之损因果/情绪/世界感之一）
- [x] 扩写位配额 ≤3/章
- [x] 紫罗兰四害零泄漏（形容词堆叠/比喻打架/生僻词/游离基调）
- [x] 文风指标复测不出区间
- [x] 删章检验仍过（无水章）
- [x] 喜剧/热梗位未因扩写超密度

**合计：7/7 全过方可入正文；不合格段落回 §四 重练。**
