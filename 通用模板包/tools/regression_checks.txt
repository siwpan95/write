# 创作室通用模板包 · 防回归断言（v3.11）
# 格式：MUST|<文件名前缀>|<必须出现的字符串>
#       NOT|<任何模板文件中都不得出现的字符串>
# 由 tools/check_package.py 的 C8 执行；改历史 bug 时在此加一条，防止复发。
#
# 【排除规则 · 故意跳过，勿改】NOT 断言与 C7 编号类检查不扫以下文件前缀
# （与 check_package.py 的 EXCLUDE_PREFIXES 保持一致，两处必须同步）：
#   00-     版本记录要引用旧值作对照（写「已作废」就必须把旧值抄进来）
#   14-     登记表要引用错值作说明（登记「鹏洛克 → 鹏洛客」必须写出错值）
#   15-     逐字摘录的实例原文含历史译名与实书编号，改字即成「伪样例」
#   审计    审计报告举证修复前后差异，必然同时含旧值与新值
#   README  清单与说明会引用历史版本号与旧值
# ⇒ 不跳过会天天误报。后续加断言时先确认目标文件是否属于排除列表；
#   新增「逐字摘录类」文件也要同步加入 EXCLUDE_PREFIXES，并在此补一行理由。
