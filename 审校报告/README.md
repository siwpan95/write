# 审校报告 · 运行产物目录

> **本目录内容不入版本库**（除本文件）—— 每次 `npm run check` 都会产出一份带时间戳的
> Markdown + JSON，逐次累积会到 MB 级，且**可随时重跑复现**。
> 忽略规则见仓根 `.gitignore`。

## 怎么用

```bash
cd E:/projects/repos/write
npm run check        # 跑全部检查器 → 在本目录产出报告
```

产出两类：

| 文件 | 内容 |
|---|---|
| `工具链自检报告-<时间戳>.md` / `.json` | **汇总报告**：3 个检查器的结论 + 逐条发现（人读 / 机读） |
| `doc-review/doc-review-<时间戳>.md` / `.json` | 审校引擎的**分项明细**（按项目分目录） |

## 归档约定

- **最新一份**：`工具链自检报告-*.md`（取时间戳最新者）—— 需要留档时手动复制到别处。
- **历史**：本地保留若干次即可；跨机追溯请用 git 历史里的
  [`审计报告-深度审计与架构重构-20261113.md`](../审计报告-深度审计与架构重构-20261113.md)（人工归档的结论）。
- **可复现性**：同一输入同一结果（时间戳只进文件名，不进判定），故历史报告无追溯价值。

## 铁律

审校引擎**只出风险与位置，不代改正文**。所有检查器只写本目录，不改被审文件
（与本仓 `通用模板包/11-合规与一致性检查模板.md` 的铁律同源）。
