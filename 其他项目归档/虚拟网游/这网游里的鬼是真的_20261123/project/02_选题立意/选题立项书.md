## 1. 频道与分类判定（终局锁定，不可后改）

- **频道**：男频
- **一级分类**：虚拟网游
- **二级细分**：虚拟网游 × 民俗怪谈（「头盔里藏着脏东西」融合流，番茄快节奏改造版）
- **目标平台**：番茄（主战场，免费阅读节奏）；起点同分类为参照系
- **判定依据**：
  1. 引赛道报告§一：番茄游戏大类「稳定大盘但纯度下降」，纯虚拟网游不占流量 C 位，头部位置被融合流占据 → 纯重生数值流（拥挤度 72）正面突围难度大，必须走融合配方。
  2. 引赛道报告§四：网游×怪谈/民俗拥挤度 **38/100，六方向中最低**，属新蓝海；起点《浊世游戏》首订约 3200、独占追读/留存双榜第 1，路径已被验证；怪谈品类全站搜索量同比暴涨 300%，吃到大盘红利。
  3. 引赛道报告§五：方向一为首推。**裁决：采纳方向①为主干，做两处番茄化修正**（详见 §3 差异化）——修正一：浊世游戏为起点付费节奏，移植到番茄必须把「章节悬念钩」与番茄验证的「3 章一爽点、10 章一全服曝光」节拍器并轨；修正二：不做「头盔进真实异界」（离开现实），改做「游戏本身就是阴间前台」（诡异能顺着注视出游戏找他），保住番茄读者最认的「现实反哺线」。

## 3. 选题差异化（对标赛道报告）

**对标头部作品**：
- 借《浊世游戏》（卡③）：「游戏为壳、诡异为芯」的设定反转公式＋「行当晋升链」职业体系骨架。
- 借《普攻永久加生命》（卡①）：番茄节拍器（3 章一变强节点、10 章一全服曝光、旁观者震惊吐槽做放大器）＋现实反哺线。
- 避《我就卡个BUG》（卡②）与全部重生数值流跟作：不做漏洞型/数值型金手指，不做重生先知开局（红海核心配方，正面避开拥挤度 72 区间）。

**差异化点 1（设定错位——双层互灌）**：浊世游戏是「人走进真世界」，单层穿越；本书是「游戏和现实两层都有鬼、且互相渗透」——游戏里杀诡掉香火强化现实肉身，游戏里结下的「注视度」让诡异能顺着视线在现实中找上门。双轨张力：想变强就必须看，看了就必须被盯。

**差异化点 2（金手指错位——感知型＋经济型双刃，带民俗规矩约束）**：赛道头部金手指全是数值型（普攻+生命/BUFF 永久/卡 BUG 晋升），本书做「看穿真容＋香火结算」双机制互锁；且内嵌民俗硬规矩「**杀不如度**」——脏东西不能无脑屠，需按民俗规矩了结因果（请牌位、对香火、讨封还愿），乱杀背业障、业障反噬属性。金手指自带策略门槛，天然防无敌流写崩。

**差异化点 3（爽点结构错位——怪谈钩子嵌入番茄节拍器）**：纯怪谈文只卖氛围不卖成长，是起点付费逻辑；本书保留番茄验证过的「数值可视化＋全服公告」副引擎（香火账本可视化、注视度倒计时、编外阴差行当晋升链），让恐怖氛围与变强爽感咬合，同时适配番茄免费阅读的追读习惯。

## 4. 金手指设定（一句话版，供 Phase 3 展开）

- **机制**：双刃「阴阳眼·香火账」——①别人看怪物是贴图，主角看见民俗诡异「真容」，可看破弱点、真名与规则破绽；②了结「脏东西」掉的不是装备，是**香火**，香火可淬炼现实肉身、兑换游戏内隐藏天赋、解锁「编外阴差」行当晋升链。
- **成长线**：香火累积 → 现实肉身超凡（游戏反哺现实）→ 编外阴差晋升链（行当名→晋升链→禁忌规则三层结构，移植卡③配方）→ 后期揭开运营方真身（阴司驻阳间办事处，全服玩家皆为「临时工」）的幕后真相线。
- **代价/限制（必须有，防无敌流写崩）**：
  1. **主代价「注视度」**：每直视一次真容，该诡异对他的注视度＋1；注视度累积跨地图、跨登录持续生效，到阈值会被更强的脏东西顺着视线在**现实**中找上门——变强与暴露同源，构成持续决策张力。
  2. **硬约束「杀不如度」**：了结诡异必须按民俗规矩走流程（超度＞击杀），乱杀累积业障、业障直接反噬角色属性；逼主角用脑而非用刀。
