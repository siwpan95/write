## 1. 主角 · 陈九（三段式弧光）

### 第一弧 · 卷一「为香火打工的独行客」

| 项目 | 内容 |
|---|---|
| 心态起点 | 看见＝钱。阴阳眼是计件工具，藏着掖着偷偷赚（怕被工作室夺走、怕被鬼记住）；产量考核压身，越穷越急 |
| 触发事件① | **原罪事件（卷一中段）**：为赶香火产量跳过民俗流程乱杀 → 业障反噬（属性暴跌、现实肉身淬炼逆行），并连累替他顶班的老关受伤 |
| 触发事件② | **真相预演（卷一末）**：阿豪遗物线索拼合——前任头盔主人不是失踪，是被注视度「喂掉」的；他的注视度曲线正在复制阿豪 |
| 触发事件③ | 新手村村长福伯拱手：「阴差大人，阳间的活，接不接？」（吸量三件套简介原句落地，编外入门） |
| 可感知变化节点 | 《避煞簿》页脚出现他自己的批注 + 备忘录「离职本金」旁新增一行「业障：不许再欠」——读者可见的行为规则变更 |
| 心态终点 | 学会按规矩做事：香火照赚，但流程不省；仍独行、仍嘴快，注释视度照涨 |

### 第二弧 · 卷二「并肩者与清算科照面」

| 项目 | 内容 |
|---|---|
| 心态起点 | 不敢有队友：注视度会把鬼引向身边人；金手指一旦暴露，工作室、净尘科技、鬼市都会来抢 |
| 触发事件① | 注视度反噬首次在现实伤到队友身边人（周天霸的司机/白露的室友接二连三「撞邪」）——他意识到藏不住也扛不住 |
| 触发事件② | 阿豪遗档现世：游戏内死亡记录与现实「查无此人」对撞——「玩家＝临时工」初露端倪 |
| 触发事件③ | 清算科「约谈」：一间只有一张桌子的办公室，桌上是阿豪的空白档案——**他反手调出阿豪遗档**（主动出击，主体性自查通过） |
| 触发事件④ | 老关为分担他的业障重伤（全书最大刀点）；注视频发后江小满楼道持枪守夜（情感线唯一名场面） |
| 可感知变化节点 | 他第一次开口求助（对队伍说出「帮我盯注视度」）＋主动建队编外小队、主动申报晋升 |
| 心态终点 | 从赚钱独狼变「行当人」：吃阴间饭就得守阴间规矩、护同行的人；阿豪案从「别人的事」变成「我的事」 |

### 第三弧 · 卷三「编制与人间：看破之后」

| 项目 | 内容 |
|---|---|
| 心态起点 | 真相大白：运营方＝阴司驻阳间办事处，全服玩家＝临时工；阿豪因知晓真相被销籍；自己一睁眼就在重点关注名单上 |
| 触发事件① | 阴司开价：转正式编制——力量、归属、不再被注视度反噬；代价是渐渐不属于人间（爷爷临终呓语「别接上面的活」的真意） |
| 触发事件② | 双线撞车：贺连城「净化演习」拿玩家做 bait 献祭 ＋ 清算科启动「全服销籍清洗」 |
| 触发事件③ | 秦二两的业秤当众称出「临时工条款」：香火归阴司、风险归玩家、知情权为零——流程合法，字字吃人 |
| **抉择（第三条路）** | 拒绝正式编制，以编外身份谈判：知情权入册、销籍需三审、福伯接印改制；《避煞簿》规矩公开给全服玩家——民智即护身 |
| 可感知变化节点 | 他当众把「离职本金」备忘录改成《避煞簿·公开版》第一页的落款——全书账本思维的外化终结，规矩取代报价 |
| 心态终点 | 「看破不说破」新解：不是替阴司闭嘴，是替看不见的人开口。回答「我是谁」：不是临时工，不是阴差，是陈九——阳间人 |

## 5. 逐卷维护纪律（给 Phase 5/6 的对接要求）

1. **回填机制**：每卷正文收笔后，大纲主笔须在本表追加「实际达成」一列；偏差超过 ±1 个节点即触发人设复核。
2. **变化节点硬指标**：主角每卷至少 1 个**读者肉眼可见**的行为变化（《避煞簿》批注 / 开口求助 / 备忘录改落款）；配角每人每卷至少 1 个台词或行为层面的可感变化。
3. **情感线红线**：江小满线节点全书 ≤8 个、每卷 ≤3 个；任何单章情感戏 ≤ 该章篇幅 1/3（男频辅助线纪律，超线即打回）。
4. **反派强度对表**：主角每卷战力（香火账）提升必须与两反派升级路线同步（卷一小鬼与封号摩擦 → 卷二据点约谈与垄断战 → 卷三双线终局），禁止主角越级碾压或反派降智。
5. **代价纪律**：注视度上涨必须与「看得多、嘴快」缺陷挂钩（不是随机掉血）；业障反噬必须与「急、乱杀」挂钩——代价永远打在缺陷上，爽点与代价同源（立项书 §4 双刃口径）。
