## 1. 主角档案（陈九 · 一人一卡）

### 1.1 基础信息

- **姓名**：陈九（游戏 ID：**「九块九包邮」**——打金仔自嘲式 ID，前期被全服当笑话，后期「九爷」二字在鬼市比人名好使）
- **年龄 / 身份开局**：25 岁。打金工作室夜班底层小弟（引《吸量三件套》§4 第 1 条：打金工作室夜班＋二手头盔开局）。干最累的夜班、拿最少的分成，工作室欠薪两个月。装备是全组轮换下来的**二手头盔**——海绵里卡着一根不属于任何同事的头发（开局钩子①，也是他的内在需求来源）。
- **外在目标（想要什么）**：在《镇渊》里靠「看得见」的本事赚到钱——先补回欠薪、交房租，再攒一笔「离职本金」脱离工作室单干。**手机备忘录「离职本金」页是人物第一记忆点**，每章结算更新数字（番茄数值可视化节拍器的人物化载体）。
- **内在需求（真正缺什么）**：查清**二手头盔前任主人阿豪的下落**（立项书开局钩子「前任使用者的存在暗示」的暗线化）——并顺着阿豪的下落，摸到「这游戏到底是什么」的真相（运营方真身线）。表层要钱，深层要的是「我看见的这些东西，到底该对谁说、说了会怎样」。他的孤胆源于爷爷遗训「看破不说破」——但阿豪的下落逼他重新想：不说破，是不是也是一种帮凶。
- **核心缺陷（必须写，无缺陷即扁平）**：
  1. **穷且急，急则乱杀**：产量考核压身（工作室按「产出」扣钱），他一开始把阴阳眼当计件工具用——为赶香火产量跳过民俗流程直接杀，业障反噬（立项书 §4 硬约束）让他摔过跟头。这是卷一原罪事件的根。
  2. **看破就说破不住嘴**：他嘴快、心直，忍不住要纠正别人「那不是狼」。与爷爷遗训「看破不说破」对着干——这条缺陷让注视度涨得比谁都快，也是后期弧光要修的东西（修的方向不是「闭嘴」，见卷三）。
  3. **对「被盯着」的钝感**：底层小弟当久了，习惯了被苛待，对「注视度上涨」的初期信号（镜子慢半拍、身后脚步声）第一反应是「错觉，别耽误干活」——宁可自我消解也不肯停手止损，孤狼病。
- **底色 / 原则（绝不会做的事）**：
  1. 不赚死人钱——不接「拿活人喂鬼换报酬」的单（与反派 A 立场对撞的根）。
  2. 爷爷的规矩不破：白事活计「先敬三分，再讲价钱」；不过手来路不明的香火。
  3. 不当「正式工」卖掉人间籍（卷三抉择的预埋底线）。
- **说话风格（供写手对齐声纹）**：
  - 报价式短句：「这单，三炷香一张符的功夫，收六百。」「超度八百，绝根一万——但我只做八百的。」（后半句是他底色的日常化表达）
  - 看见真容时不叫、不跑，先小声给自己报数：「注视度第三档了，再看一眼就得跑。」
  - 心虚 / 违反爷爷规矩时摸左耳垂（爷爷打他养成的条件反射）。
  - 对江小满（兄妹式情感线）说话突然变规规矩矩，敬语冒出来又咽回去。
  - 专属标志：爷爷手抄的**半本《避煞簿》**（塑封膜包着，边角磨白）＋二手头盔上那根用胶带封存的头发。两件都是「规矩的味道」，供写手做物件锚点。

### 1.2 金手指与人物关系（如何放大优势、如何卡住缺陷）

- **金手指**：**阴阳眼·香火账**双刃（严格按立项书 §4，不得增删）：
  - ①**阴阳眼（感知型）**：别人看怪物是贴图，他看见民俗诡异「真容」，可看破弱点、真名与规则破绽。
  - ②**香火账（经济型）**：了结「脏东西」掉的不是装备，是香火——香火可淬炼现实肉身（游戏反哺现实）、兑换游戏内隐藏天赋、解锁「编外阴差」行当晋升链（行当名→晋升链→禁忌规则三层结构〔Phase 3 对齐点〕）。
- **放大优势**：别人躲鬼，他杀诡得香火——「核心爽点」成立；编外阴差身份让他在游戏里「有编制地接活」，村长拱手那句「阴差大人，阳间的活，接不接？」是身份线起点（引吸量三件套简介原文）。
- **卡住缺陷（双代价，缺一不可）**：
  1. **主代价「注视度」**：每直视一次真容，该诡异对他的注视度＋1；跨地图、跨登录持续生效，到阈值会被更强的脏东西**顺着视线在现实中找上门**（立项书 §4 原文口径）。——恰好卡住缺陷③：他钝感、嘴快、看得多，注视度涨得全服最快。变强与暴露同源。
  2. **硬约束「杀不如度」**：超度＞击杀；乱杀累积业障、业障反噬角色属性。——恰好卡住缺陷①：他越急越想杀，杀越快摔得越狠。逼他用脑而非用刀。
- **金手指来历**：家传——爷爷陈守拙是上一代编外阴差（白事知客先生），阴阳眼隔代睁在他身上；阿豪的二手头盔只是「扣动扳机的扳机」〔Phase 3 对齐点：来历取「家传」口径，需世界观确认；若世界观定为「醒于头盔沾染」则同步修订本卡〕。

### 1.3 主体性自查（铁律）

- 卷一：主动隐瞒阴阳眼私下打香火（自选）、原罪乱杀（自选）、主动接村长「阳间的活」（自选）。

### 3.2 配角个人卡（核心五人落卡；马千军并入反派档 §6；阿豪并入现实侧 §5）

**福伯**（新手村村长，NPC，年龄不明）
- 身份：新手村村长，编外阴差线的引路人。简介原句出处（「阴差大人，阳间的活，接不接？」）。
- 目标：给阴司凑够「阳间的活」的完成率（外）；给编外们留一条不像阿豪那样消失的路（内，卷三揭晓）。
- 缺陷：太会算账，凡事先算利弊，关键时刻反而误事；对阴司有几十年的人身依附惯性。
- 底线：不骗上门的香火钱。
- 语言习惯：开口先拱手；报价精确到「文」；提到阴司永远称「上面」。
- 功能示范：每次主角晋升都由他宣读行当名与禁忌（晋升链仪式感的固定供应商）；同时他是「阴司在场感」的日常化装置——让读者始终记得「这游戏背后有东家」〔Phase 3 对齐点：编外阴差行当名序列需世界观成文〕。

**老关**（关海山，42 岁，现实职业：寿衣店老板）
- 身份：进游戏做「白事活计」的老玩家，民俗规矩活字典；寿衣店接触丧家多，对「脏东西」的规矩门儿清。
- 目标：给儿子攒婚房首付（外）；确认「干了半辈子白事，到底有没有另一头」（内，卷三得到答案）。
- 缺陷：规矩大于天——规矩冲突时宁可硬扛损失也不变通；看轻自己（总说自己「就是卖寿衣的」）。
- 底线：白事活计不还价，先敬三分再讲价钱；绝不碰「绝根」的活。
- 语言习惯：句句带「先敬三分」；劝人必掏桃木尺敲三下桌子。
- 功能示范：主角每一次「想乱杀」都被他一尺子敲回流程——「杀不如度」硬约束的人格化扳手（立项书 §4 机制的执行面）。卷二为分担主角业障重伤，是全书最大刀点。

**白露**（21 岁，女大学生，统计学专业）
- 身份：规则怪谈解谜手，ID「白鹭不吃鱼」。
- 目标：把《镇渊》全部隐藏规则做成一本「完备册」（外）；证明「规则背后一定有个说真话的人」（内——通往运营方真相线）。
- 缺陷：过度依赖数据与规则，规则失效时会宕机式恐慌；为验证规则敢拿自己做实验（注视度风险计量器）。
- 底线：不拿别人的命验证规则。
- 语言习惯：报数据像报天气：「注视度第二档 60%，建议撤退」；口癖「这条不在攻略里」。
- 功能示范：全队注视度监控员（主代价的可视化承担者，番茄数值节拍器的人物化）；规则解谜钩子的固定引擎（立项书 §3 差异化点 3 的「规则解谜爽点」落点）。

**周天霸**（22 岁，富二代，ID「一刀九百九」）
- 身份：氪金狂魔，掉落全服最黑但敢莽全服第一。
- 目标：卷一是「打出一次全服公告」；卷三变为「替编外联盟撑场面」。
- 缺陷：莽，且莽得毫无计划；嘴比脑子快，经常把队伍带进鬼坑——然后靠陈九捞出来。
- 底线：可以坑队友，但绝不卖队友（后期唯一守住的东西）。
- 语言习惯：全服最大声量：「这游戏针对我！」；吐槽一针见血，是恐怖氛围的减压阀（吸量三件套 §4 第 6 条）。
- 命运走向：卷一嘲讽打金仔「九块九」→ 被捞过一次命后改口「九爷」→ 卷二莽功进步、敢断后 → 卷三家底砸进「编外联盟」，第一个公开站队。

**秦二两**（鬼市中间人，NPC）
- 身份：游戏内鬼市情报贩子，收香火卖消息，一杆秤走天下。
- 目标：不明（他只回答「秤知道」）。
- 缺陷：绝对中立到冷酷——只认香火不认人，主角没钱时他见死不救（多次制造危机）。
- 底线：秤上不掺假，阴司来了也照称。
- 语言习惯：只露一杆秤不露脸；报价永远「公道价，阴阳同秤」。
- 功能示范：香火经济体系的展示柜（立项书 §4 香火三通道的经济面）；情报线的灰色接口；卷三揭晓他的秤是阴司「业秤」——主角用秤称出阴司合同里的「临时工条款」，是第三条路谈判的关键道具〔Phase 3 对齐点：业秤与鬼市体系〕。

## 4. 情感线（男频辅助线，占比 ≤15%，红线：不得挤占爽点主线）

- **对象**：江小满（27 岁，市局刑警，专责组），兄妹式，非恋爱直给。
- **设定依据**：立项书 §3 差异化点 1「现实反哺线」——注视度让诡异能顺着视线在现实中找上门，现实侧必须有执法视角承接（「头盔失踪案」：多名玩家现实失踪/死亡与《镇渊》死亡记录精确吻合〔Phase 3 对齐点〕）。
- **关系演进节奏**：
  - 卷一「相识·冲突开局」：她按失踪案名单找上工作室，陈九是她眼中的头号嫌疑人（阿豪的二手头盔在他头上）——不是邂逅，是审讯开局。
  - 卷二「并肩」：双线查案咬合（她查现实尸体，他查游戏鬼源）；「兄妹式」落地——她叫他「小陈」，他叫她「满姐」；名场面只排一场：注视度反噬的厉鬼找上陈九出租屋那夜，她持枪守在楼道口守到天亮，谁也没提。
  - 卷三「留白」：真相公开后她递来一张表格：「下辈子别打金了，来考编，我给你划重点。」收在留白，不表白不拥吻。
- **节点数控制**：全书情感线节点 ≤8 个，每卷 ≤3 个；任何单章情感戏 ≤ 该章篇幅 1/3。超线即打回。

## 5. 现实侧人物落卡（供双线交织）

### 5.1 爷爷 · 陈守拙（已故，全书精神坐标）

- 身份：白事知客先生，**上一代编外阴差**〔Phase 3 对齐点：上一代编外的历史与阴司关系〕。陈九从小跟着他长大，「先敬三分」「看破不说破」全是家训。
- 落卡方式：不出场写出场感——遗物《避煞簿》半本手抄，随三卷补页：卷一页脚多出陈九自己的批注（规矩传承的具象化）；卷二夹着一张阿豪寄给爷爷的旧明信片（两人早有交集——头盔不是偶然落到陈九头上）；卷三补上最后一页：爷爷当年没写完的那句——「看破不说破，说的是：说破之前，先想好替谁说。」
- 功能：主角底色与金手指来历；「杀不如度」的家传根源；卷三第三条路的思想源头。
- 死因暗线：病逝，但临终反复呓语「别接上面的活」——他退出编外的原因，卷三揭晓（他不肯签「临时工条款」，主动挂印，代价是被阴司记档）。

### 5.2 阿豪（真名何振豪，前任头盔主人，25 岁上下，卷三「出场」）

- 身份：工作室前任夜班小弟，半年前「失踪」——现实查无此人，游戏内却有死亡记录〔Phase 3 对齐点：销籍规则〕。
- 三卷递进：卷一遗物（海绵里的头发＋掉出的工牌）→ 卷二遗档（游戏深处他的角色档案：死亡时间与现实失踪日吻合，但现实户籍里这个人「从未存在过」）→ 卷三《注视度笔记》（他用被注视的最后清醒写下的代价记录与真相推论：「玩家是临时工，别让它们记住你的名字，别签转正」）。
- 功能：开局钩子源头；注视度代价的预演者（他的下场就是主角的「如果」）；真相线钥匙（第一个摸到「临时工条款」的人）；主角卷三抉择的直接情感动因——「我不想再用别人的头盔看见这些」。

## 6. 反派设计（两个派系一个机制，独立卡）

### 反派 A · 贺连城（主反派，明线人格反派）

- **身份**：「净尘科技」总裁——《镇渊》运营方在人间的高级代理〔Phase 3 对齐点：人间代理授权制度〕。对外头衔：游戏安全与「净化服务」事业部负责人。
- **作恶逻辑（他要什么、为什么合理——反派不是傻子）**：
  - 他**早于主角知道鬼是真的**，也见过注视度失控的真实惨案。他的立场自洽：「官方（阴司）把脏活全甩给编外，风险全是玩家担的——总得有人把『安全』变成一门能兜底的生意。」
  - 手段：把驱邪公开化、产业化——成立「净化服务」，招募玩家做「净化员」，捕获鬼物→封装→卖给恐惧的富豪与黑市；同时**向阴司竞标「临时工总包」**，想垄断编外阴差的活计与香火结算权——把主角这样的散户编外，变成他的外包劳工。
  - 与主角对撞的合理性：两套都自洽的逻辑——他主张「恐惧必须有价、安全必须垄断」；主角底线「不赚死人钱」。对撞不在善恶标签，在**阴间饭该谁来做主**。
- **与主角冲突升级路线**：
  1. 小摩擦（卷一末）：发现「九块九包邮」香火产出异常，先封号威胁、后高价收编——用规则和市场打人。
  2. 资源战（卷二）：垄断法事道具与「净化服务」渠道；从现实侧施压（收买马千军、悬赏陈九的阴阳眼情报、盯梢江小满的专责组）。
  3. 生死局（卷三）：「全服净化演习」实为**拿玩家做 bait 喂他封装的老鬼**，同时向阴司递交「临时工总包」标书——用上千玩家的注视度喂出「安全库存」，换他做阴间包工头。
- **败亡节点规划**：卷三终局，双重败亡：①被自己封装的鬼反噬（他从未真正净化过任何东西）；②被阴司清算——他想当包工头，但**阴司从不容编外做大**，一句「优化」把他从代理名单上划掉。死前对主角：「你以为谈下来规矩，上面就会守？」——留刺收尾。

### 反派 B · 阴司「清算科」（暗线反派，制度型灰色）

- **身份**：运营方真身（阴司驻阳间办事处）内部的执行部门，非人格化制度反派。主理「临时工」事务：编册、监察、**销籍**。
- **作恶逻辑（他要什么、为什么合理）**：
  - 信条：「**阳间不知阴间，鬼才守规矩。**」知晓全貌的临时工会动摇「看破不说破」的千年秩序——阿豪就是因摸到「临时工条款」被销籍的（户籍里从未存在过）。
  - 为什么合理：他们抹掉的只是「知道太多的人」，换来的是整个香火体系不崩盘——**用制度做残忍的事，且每一页流程都有依据**。这是制度型反派的强度：没有一个坏人，只有一部吃人的流程。
  - 对主角的三重钩：①阿豪销籍案在它手里；②爷爷当年挂印被记档，陈九一睁眼就在「重点关注名单」上；③主角查得越深，「销籍」越近。
- **升级路线**：
  1. 卷一：观察（福伯每月上报编外动态；秦二两的秤在称所有人的业障）。
  2. 卷二：警告 → 「约谈」主角（卷二中期名场面：一间只有一张桌子的办公室，桌上是阿豪的空白档案）→ 主角反手调出阿豪遗档（主动出击，主体性自查通过）。
  3. 卷三：「全服销籍清洗」启动，与贺连城的「净化演习」同线撞车——主角双线作战。
- **败亡 / 去向规划**：不消灭、而改制——主角以编外身份借「业秤」称出临时工条款的不公，与清算科谈判：知情权入册、销籍需三审、福伯接印改制。制度型反派以**制度性和解**收尾，与明线反派的结构性死亡形成对照。

### 机制型对手 · 记名厉鬼「百目」（不占反派人格位）

- 注视度的具象化载体：陈九注视度最高的那只老鬼，跨地图跨登录记着他，注视度累积满百笔时循视线入现实。
- 与阿豪之死直接相关（阿豪的注视度就是被它记满的）——主角打它，既是自救，也是替阿豪收尾。
- 终局：陈九按「杀不如度」全流程（请牌位、对香火、讨封还愿〔Phase 3 对齐点：流程细则〕）了结因果，注视度体系随金手指代价一并收束。
- 设计纪律：它无逻辑无人格，**不得写成反派**——防止写手把金手指代价写成反派（代价与反派分卡管理）。
