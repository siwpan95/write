本项目从「虚拟网游类热门小说扫榜选题」起步，完整跑通九阶段写作链路，并额外产出配套工具链、全过程报告与提案。核心结果：

二、九阶段执行记录

Phase 1 扫榜与市场分析（market-scout 洪观势）

- **方法**：联网检索 6 轮（番茄游戏体育榜、起点游戏分类月票/畅销/追读/潜力榜、头部作品数据页、流派百科与行业趋势稿），交叉验证。

- **核心结论**：稳中分化——传统纯虚拟网游是「稳定大盘但纯度下降」，网游×求生/游戏降临/第四天灾/民俗怪谈融合流处于风口上升期。

- **头部参照**：《普攻永久加生命，阁下如何应对？》（番茄，在读峰值约 186 万·估、459.6 万字完结）、《我就卡个BUG，怎么就无敌了？》（番茄，约 42.4 万在读）、《浊世游戏》（起点，首订约 3200、独占追读/留存双榜第 1）。

- **拥挤度判定**：传统重生数值流 72/100（红海）；游戏降临 55；第四天灾 48；网游×民俗怪谈 38（新蓝海，首推）。

- **交付**：《赛道分析报告.md》（16.6KB）、《爆款拆解卡.md》（9.5KB，3 张拆解卡 + 横向对比表）。

- **纪律遵守**：只拆结构与配方，无原作文字复制；量级存疑处标注「估」。

Phase 2 选题立意与命中率预判（topic-strategist 蓝海深）

- **频道/分类锁定**：男频 / 一级虚拟网游 / 二级「虚拟网游×民俗怪谈」（番茄快节奏改造版）。采纳赛道报告方向①，做两处番茄化修正：与「3 章一爽点、10 章一全服曝光」节拍器并轨；不做「头盔进真实异界」而做「游戏与现实双层互灌」。

- **一句话故事**：打金小弟在藏真鬼的网游里开了阴阳眼，杀诡得香火淬炼肉身，但看得越多，被鬼记得越牢。

- **金手指**：「阴阳眼·香火账」双刃——看真容/弱点/真名/规则破绽 + 了结脏东西掉香火（淬炼现实肉身/换隐藏天赋/编外阴差晋升链）；双代价「注视度」+「杀不如度」业障。

- **命中率**：题材热度 4.5 / 开局钩子 4.5 / 金手指新鲜度 4.5 / 爽点密度 4.0（最薄弱维，已配三重兜底）/ 差异化 4.5 → **加权 4.40，立项通过**。敏感性复核：最薄弱维跌至 3.0 仍有 4.20，容错充足。

- **交付**：《选题立项书.md》（7.8KB）、《吸量三件套.md》（6.1KB）、《命中率评分.md》（5.1KB）。书名《这网游里的鬼是真的》经联网查重无完全重名。

Phase 3 世界观与设定（worldbuilder 蒙开天）

- **游戏世界**：《镇渊》全息网游，民俗题材外壳下副本脏东西全是真的；运营方真身=阴司驻阳间办事处，全服玩家皆为「临时工」。

- **力量体系**：明轨玩家 1-60 级（学徒→宗师）＋白事行五艺；暗轨香火修行三通道（肉身淬炼五阶开窍→壮骨→避煞→金身→阳身／天赋黑榜／编外阴差晋升链六级）。

- **鬼物分级**：五更五阶（一更游魂→二更怨煞→三更凶煞→四更厉鬼→五更沉渊），「规矩即命门」。

- **金手指世界观细则**：阴阳眼四层穿透；香火账三栏可视化（余额/兑换单/注视度台账）；注视度十笔一档（10/30/60/100，满百顺视线入现实猎杀）；业障量化（+1 点/只乱杀、每点全属性 -5%、10 点掉落全停、1:1 折抵）；保密红线五类暴露源排序 + 四档预案。

- **交付**：《世界观设定集.md》（28.0KB）、《一致性台账_设定卷.md》（16.4KB，49 条锁定 + 6 条待裁决 + 事故记录区）。

Phase 4 人物塑造（character-designer 章立人）

- **主角**：陈九，25 岁打金工作室夜班底层小弟，游戏 ID「九块九包邮」；外在目标攒「离职本金」单干，内在需求查清头盔前任阿豪下落；核心缺陷三件套（穷且急则乱杀/看破就说破不住嘴/对被盯着钝感），金手指双刃恰好卡住缺陷。

- **三段弧光**：卷一「为香火打工的独行客」→卷二「并肩者与清算科照面」→卷三「编制与人间：看破之后」，各配可感知变化节点。

四、质量控制与事故复盘

4.1 总编纪律执行情况

- **落盘验证**：每一份成员交付均经主理人 `ls -la` + 编码头核验（UTF-8 无 BOM），口头声称一律不采信。

- **脚本执法**：大纲闸门 `pipeline_check.py outline`、正文闸门 `pipeline_check.py all`、AI 味闸门 `pipeline_check.py deai`，均以真实脚本输出与退出码为准（实际输出见各阶段文件）。

- **口径 grep**：跨阶段用 `grep -c` 实测关键词，确保权威口径（陈九/阴阳眼/香火账/照夜盔/百目）命中、污染口径（许愿/火纹铜钱/长明灯）归零。

4.2 消息污染事故与纠偏（重要）

**事故经过**：Phase 2 回传环节出现一条与成员真实产出不符的「完成消息」（书名《我在惊悚游戏里修仙》/金手指火纹铜钱/主角许愿），据此发出的退回指令与并行任务 prompt 被污染，导致 Phase 3/4 首版产出错误口径。

**发现与纠偏**：

1. 主理人核验落盘文件与回传不符 → 退回重做；

2. 蓝海深（topic-strategist）拒绝盲目执行、附实测字节数请示裁决 → 总编裁定「落盘文件为唯一权威」，污染消息作废；

3. Phase 3/4 分别覆盖重写为 v2.0/v2.1 与 V2，经分组 grep 实测污染词归零、权威词满额后过闸；

4. 跨成员直连（违反中转铁律）两次记录在案；「照夜」撞名经裁决改为「百目」。

**沉淀教训**：

- 成员回传必须「落盘文件 + 实测字节数」双证；

- 总编派发下游 prompt 的锚定信息必须从落盘文件读取，而非从回传消息摘抄；

- 裁决必须基于分组 grep + 结构标题双重证据，且不得对正在被写入的文件做终验；

- 长任务成员必须先消费消息队列再动笔；跨成员一切对齐经总编中转。

4.3 已知限制

- 榜单数据量级来自公开检索快照，属实时波动数据，标注「估」者为多源推算；结论有效期建议 ≤ 7 天。

- 本书民俗鬼神元素以架空网游世界观为壳，不宣扬迷信、不涉政、不涉未成年人受害描写，符合平台合规要求。
