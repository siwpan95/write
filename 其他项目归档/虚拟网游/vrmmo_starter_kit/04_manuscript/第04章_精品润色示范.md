# 第4章 限时活动：灰鸦镇保卫战

江砚用了十一分钟，弄明白“冗余度”是什么。

他把三个名字拖到【回收程序】的说明栏上，一条一条比对。

周启山｜冗余度 4.1%

王阿婆｜冗余度 3.8%

小满｜冗余度 3.7%

三个人有一个共同点：他们今天没有被任何一个玩家交互过。

江砚又拖了另外几个名字上去。

酒馆老板娘｜冗余度 0.4%

镇口守卫｜冗余度 0.9%

布告栏管理员｜冗余度 1.2%

这三个人今天被玩家围过、问过、摸过。

江砚靠回墙上，闭了一下眼。

他明白了。

所谓“冗余”，不是“没用”。

是“没被看见”。

一个 NPC，如果今天没有一个玩家跟他说过话，他的冗余度就往上涨。涨到某个值，他就会被判定为“资源浪费”，凌晨零点，清理掉。

江砚睁开眼。

他做运营七年，第一次遇到一个系统，把“用户关注度”直接写成了“生存权”。

*

他看了一眼时间。

23:47:51。

还剩四小时十二分钟。

他打开【任务配置】。

**当前可创建任务数：1 / 1**

这个额度，他今天晚上已经用掉了。

白天的“新手引导”任务已经完成，但他刚才试过，那个任务位没有释放——系统提示：**任务冷却中，剩余 03:58:12**。

也就是说，他现在什么都做不了。

江砚盯着那行“冷却中”看了很久。

然后他退回主界面，点进【数据看板】，找到一个他从来没点过的按钮。

**事件日历**

点开。

**今日事件：** 无

**明日事件：** 灰鸦镇 · 怪物潮（Lv.1 · 预计 00:10）

江砚的指尖停住了。

明天零点十分，会有一波怪物攻城。

而清理程序在零点整执行。

也就是说，系统给了这个镇子一场“灾难”，却不给它活到那场灾难的机会。

江砚笑了一下。

这个排期，他太熟了。

做运营的时候，最怕的就是这种排期——活动方案还没批下来，投放位已经卖出去了；预算还没到账，供应商已经来催款。

所有的失败都不是因为难，是因为“来不及”。

*

他抬头，看向广场。

三百多个人还在那儿。

有人靠着墙睡着了，有人在小声打牌，有人坐在地上给自己的孩子发语音——当然发不出去。

沈迟坐在布告栏下面，膝上摊着那张流程表，正在用铅笔划掉一行一行。

江砚走过去，在他旁边蹲下。

“沈会长。”

“嗯。”

“你们公会，有多少人能打？”

沈迟抬眼看他。

“能打的不少。”他说，“但今天晚上不打。今天是告别。”

“如果我说，今天晚上打一场，能让它多活三十天呢？”

沈迟捏着铅笔的手停了。

周围几个人转过头来。

“你说什么？”

江砚看着他，一字一句地说：

“这个镇子，今晚零点会死人。不是掉线，是死。彻底没有。”

安静。

沈迟把铅笔放下了。

“你说清楚。”

*

江砚没有全说。

他说了七成。

他说这个世界出了故障，说零点会有一次“清理”，说被清理的对象会消失，说唯一能阻止的办法是“让这些人被更多人看见”。

他没说自己是谁，没说后台，没说“三十天后整个服务器都会关”。

沈迟听完，沉默了很久。

“所以，”他慢慢地说，“你的意思是，我们今晚要是走了，这些人就没了。”

“是。”

“我们要是留下来陪他们——”

“他们能多活一天。”

沈迟看着他。

“一天？”

“至少一天。”江砚说，“剩下的我想办法。”

沈迟低下头，看着膝上那张流程表。

上面写着：23:50 集合；23:55 后山献花；00:00 世界频道齐刷“有人吗”；00:05 合影；00:10 下线。

他拿起铅笔，把最后三行划掉了。

然后他在空白处写了四个字。

**灰鸦镇保卫战。**

*

三百个人，被分成了三队。

沈迟的动作很快。他把公会里能打的挑出来，按等级排；把不能打的编成后勤，负责搬东西；又挑了二十个嗓门大的，让他们挨家挨户去敲门。

“敲门干什么？”小小鱼问。

“让镇子里的人出来。”沈迟说，“让每一个玩家，跟每一个 NPC 说一句话。”

小小鱼愣了一下，然后眼睛亮了。

“我懂了！”他说，“只要说过话，就不算冗余！”

江砚站在旁边，看了沈迟一眼。

这个人用三分钟，把他花了十一分钟才想明白的机制，自己推出来了。

*

二十三点五十二分。

灰鸦镇第一次这么热闹。

三百多个人散开，一条街一条街地敲。

“大爷！大爷您出来一下！”

“老板娘！这酒多少钱！我买！”

“小朋友你叫什么名字啊？你几岁啦？”

有人蹲在门槛上，跟一个只会重复“今日宜出行”的摆摊的先生聊了十分钟。

有人把布庄的王阿婆扶到门口，让她坐在板凳上晒太阳——虽然天上没有太阳。

有人在酒馆里点了一桌菜，一口没吃，就为了让那个叫小满的杂役一趟一趟地端。

小满端了十七趟。

第十八趟的时候，她小声说了一句：

“客人，你今天……吃得好少。”

那个玩家把脸埋进手里，肩膀抖了很久。

*

二十三点五十八分。

江砚打开后台。

**冗余度刷新**

周启山｜4.1% → 0.3%

王阿婆｜3.8% → 0.2%

小满｜3.7% → 0.1%

他盯着那三个数字，喉咙紧了一下。

**世界活跃度：31.4%**

**世界等级经验：314 / 1000**

*

二十三点五十九分。

镇口的雾，忽然变浓了。

不是夜雾。是那种从地里渗出来的、带着腥味的白。

江砚的后台跳出一行红字：

**［事件提前触发］灰鸦镇 · 怪物潮**

**原因：世界活跃度超过 30%，触发动态难度**

**怪物数量：200**

**等级：1–3**

江砚骂了一声。

他把难度调高的机制忘得一干二净——活跃度越高，怪越多。这是他亲手参与设计的“动态平衡”。

他当年在需求文档里写的是：“让玩家永远处在有挑战但不绝望的区间。”

现在这个“挑战”，是两百只怪。

*

“来了！”镇口守卫喊了一声。

那声喊是活的。不是台词库里的。

沈迟转身，把幡往地上一插。

“所有人——列队！”

三百多个人，在广场上排成了三排。

没有人跑。

江砚看着这个场面，忽然想起三年前《天穹》最后一次大版本更新，宣传语是“三百万勇士，共守九垓”。

那时候他觉得很土。

现在他觉得，这句宣传语没有说谎。

*

第一只怪从雾里冲出来，撞在镇口的第一道栅栏上。

木栅栏断成两截。

“打！”

小小鱼第一个冲上去，一棍子敲在怪头上。

-8。

怪反手一爪，把他掀翻在地。

血条直接见底。

“我死了我死了我要死了——”

他的身体在半空中散成一片光点。

三秒后，光点重新聚合，他又站在了原地。

小小鱼呆了两秒。

然后他抬起头，冲着整个镇子喊：

“我不会死！我死不了！”

“我操，我是第四天灾！”

*

那一声喊，把三百个人点燃了。

“第四天灾！”

“死不了！”

“上！上！”

前排的人被撞飞，倒下，复活，再冲。后排的人踩着前排的尸体重整队形。

江砚站在广场中央，看着这一幕。

他打开后台，手指飞快地动了三下。

**［临时调整］怪物刷新间隔：15 秒 → 25 秒**

**［临时调整］玩家复活时间：10 秒 → 3 秒**

**［提示］本次调整将消耗资源池 400 点**

他按了确认。

资源池从 800 掉到 400。

*

“小小鱼！”江砚喊。

“到！”

“去铁匠铺！让老周修装备！”

“什么？”

“你们的武器会坏！没有铁匠，你们打不完这波！”

小小鱼愣了一下，然后明白了。

他掉头就往铁匠铺跑，一边跑一边喊：

“护住铁匠！护住铁匠铺！”

“所有人听着——谁都不能让怪进铁匠铺！”

*

铁匠铺的门开着。

老周站在炉子前面，手里那柄小锤还举着，脸上全是烟灰。

而在门口，站着一个女孩。

新手上路。

她手里举着一根树枝——就是白天在村口捡的那一根，早就断了半截。

她站在门槛上，两腿发抖，脚下有三只怪正在逼过来。

“让开！”小小鱼喊。

“我让不了。”她说，“我后面有人。”

“你打不过的！你一级！”

“我知道。”

她把树枝举起来。

“我知道我打不过。可我哥说，今天晚上，谁来都别走。”

*

第一只怪扑上来的时候，她挥了一下树枝。

-1。

她的血条被一口气清空。

光点散开，又聚合。

三秒后，她重新站在门槛上。

树枝还在手里。

-1。

又倒下。

又站起来。

江砚在后台看着那行数据跳：**新手上路｜死亡次数：9｜流失风险：0.2%**

流失风险 0.2%。

他做了三年运营，从来没见过这么低的数字。

*



他看见小小鱼冲进来，看见后面追着三只怪，看见街上到处都是光点。

他的嘴唇动了动。

“客官，修东——”

“周师傅！”小小鱼一把抓住他的胳膊，“别修了！打！你打啊！”

老周的手在抖。

他这辈子只会三句话。

他张着嘴，念不出来。

*

江砚在后台，看见了老周的状态。

**周启山｜状态：恐惧｜情绪值：102%｜溢出**

下面有一行灰色的小字，是他从来没见过的：

**［建议］该对象已产生自主意识。是否保留？**

江砚的手指停在“是”上面。

他按了下去。

*

铁匠铺里，老周的锤子掉在了地上。

他慢慢弯下腰，把锤子捡起来。

然后他转过身，走到墙角，掀开一块布。

布下面是一排剑。

十二把，长短不一，每一把都擦得很亮。

“这些……”老周的声音很哑，“这些是我这七年打的。”

小小鱼看着他。

“没人来买。”老周说，“我打了七年，没人来买。我以为，我这辈子就打这些了。”

他把最前面那一把抽出来，剑身很薄，刃口泛着月光一样的白。

“你拿着。”他说。

小小鱼伸手去接。

“多少钱？”

老周看着他。

那句话，不在他的三条台词里。

“不收钱。”

*

小小鱼冲出去的时候，剑在手里亮着。

他喊得整条街都听见了：

“铁匠给我们打剑了——不收钱——”

“这游戏有人！这游戏里的人是真的——”

那一夜，灰鸦镇的三百个人，用十二把剑和无数次复活，顶住了两百只怪。

江砚后来在后台的数据里看到，那四个小时里，玩家死亡次数是 47,312 次。

在线人数，从 312，涨到 1,104。

没有人下线。

江砚站在广场边，看着满地还没散尽的光点。

他下意识地调出后台，新建了一个空白文档，敲下标题：

**《灰鸦镇保卫战 · 活动复盘》**

写完这五个字，他停住了。

上一次写这个标题，是三个月前的国庆活动。那次的数据是：参与人数 2,140，付费率 3.1%，流水 47,000。

他在复盘会上一页一页地翻 PPT，台下坐着孙总和梁铎。

而这一次的数据是：参与人数 1,104，付费率 0，死亡 47,312 次。

他想了想，在“流水”那一栏，填了一个“无”。

然后在备注里补了一行字。

**留存：值得。**

*

零点十分，怪物潮结束。

**［结算］灰鸦镇 · 怪物潮 已击退**

**存活对象：1,847 → 1,847（无损失）**

**世界等级经验：1,000 / 1,000**

**世界等级：0 → 1**

**［解锁］掉落配置 Lv.1**

江砚站在铁匠铺门口，看着那行“世界等级：1”。

他笑了。

然后他听见身后有锤子的声音。

当。当。当。

老周在打完那十二把剑之后，又开始打铁了。

只是这一次，他每敲一下，就会停一下，抬头看一眼门口。

像在等人来。

而门外的雾，还没有散。

## 附：本章润色示范说明

> 这一章是全书的质量基准。下面把三处“初稿 → 精修”的原始对照摊开，说明改动逻辑。你可以直接拿这套规则去改自己的稿子。

### 一、三处对照改稿

**对照 1 · 把“解释”改成“动作”**

- 初稿：江砚明白了冗余度的含义，所谓的冗余度其实就是指这个 NPC 有没有被玩家关注，如果没有被关注就会被清理，于是他意识到必须让所有人都去跟 NPC 说话。
- 精修：

> 他明白了。
> 所谓“冗余”，不是“没用”。
> 是“没被看见”。

改动逻辑：初稿是“作者在给读者讲机制”，一句话 78 字，全是转述。精修把结论拆成三行独立短句，每一行都比上一行少两个字——节奏自然收紧，读者自己得出“没被看见=会死”的结论。**读者自己推出来的结论，比你告诉他的结论，记得牢十倍。**

**对照 2 · 把“形容词”改成“可数的东西”**

- 初稿：小满非常感动，玩家们也很感动，大家都哭了，气氛非常感人。
- 精修：

> 小满端了十七趟。
> 第十八趟的时候，她小声说了一句：
> “客人，你今天……吃得好少。”

改动逻辑：“非常感人”是无效信息。改成一个具体的数字（十七趟）和一句不该由 NPC 说出口的台词。**情绪不靠形容词承载，靠“不该发生的事发生了”承载。** 一个 NPC 说出“你今天吃得好少”，比十句“她很感动”都重。

**对照 3 · 把“平铺”改成“先扔结果”**

- 初稿：江砚看了看时间，发现只剩下四个小时了，他心里很着急，因为他必须在天亮之前想出一个办法来拯救这个镇子。
- 精修：

> 他看了一眼时间。
> 23:47:51。
> 还剩四小时十二分钟。

改动逻辑：开段不铺垫情绪，直接甩数字。精确到秒的时间戳会制造压迫感——**“还剩四小时”是信息，“23:47:51”是恐慌。**

### 二、润色方法论（五条，可复用）

| 规则 | 操作 | 反例 → 正例 |
|---|---|---|
| **1. 删掉“他明白了”式的总结句** | 结论前面凡是出现“这意味着”“也就是说”“他意识到”，砍掉，让事实自己说话 | “他意识到这意味着世界要完了” → “世界寿命：30 天” |
| **2. 一段不超过三句** | 手机屏幕一屏大约 12 行，超过就划走了 | 长段拆成 3–5 个短段，每段一个信息 |
| **3. 数字比形容狠** | 能用数字的地方不用形容词 | “很多玩家” → “312 个人”；“打了很久” → “47,312 次” |
| **4. 每 800 字必须有一次情绪起伏** | 一个疑问、一次打脸、一句狠话、一个反转都算 | 中段如果连续两屏都在解释设定，一定删 |
| **5. 章末必须是“问号”不是“句号”** | 结尾留一个未完成的动作或未兑现的信息 | “他决定明天再去” → “而那个世界里，老周还在打铁。当。当。当。” |
