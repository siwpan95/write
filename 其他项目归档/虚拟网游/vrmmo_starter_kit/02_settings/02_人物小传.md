# 人物小传

> 判断一个人物立住了没有，标准只有一个：**能不能用一个动作记住他。**
> 每个角色下面都有一个"记忆点动作"，写作时反复用，读者就忘不掉。

---

## 一、主角

### 江砚

| | |
|---|---|
| **身份** | 星穹互娱《天穹》项目组 · 活动与补偿专员（外包）· 工号 A-0731 |
| **年龄** | 28 |
| **记忆点动作** | 说话前先把对方的话在心里"翻译"一遍，然后说出更难听但更真的版本 |
| **外貌** | 中等身材，穿什么都像工装；下巴常年三天没刮干净；手指关节有一道旧伤（高中打篮球留的） |
| **口头禅** | "我算一下。"——他遇到任何事的第一反应都是算账 |

**性格三层**

- 表层：嘴毒、冷静、什么都不在乎。会用"我算一下"把情绪挡在外面。
- 中层：给所有人兜底。谁出事他都第一个到，到的时候还带一句损人的话。
- 内核：**怕自己没用。** 他被优化的那天，最难受的不是没钱，是"从此没有人需要我处理问题"。

**动机演化**

| 阶段 | 动机 | 对应章节 |
|---|---|---|
| 卷一前段 | 活下去 / 搞清楚这是哪 | 1–5 |
| 卷一后段 | 保住这 1,844 个人 | 6–29 |
| 卷二 | 搞清楚七年前发生了什么 | 30+ |
| 卷三 | 让它变成一个不需要管理员也能活的世界 | 结局 |

**秘密**：他其实不爱玩游戏。三年里他一次副本都没打过。他每天上线只是为了看工单。这件事他从没跟人说过，因为说出来会被玩家骂死。

**弧光**：从一个"靠发补偿来赎罪"的人，变成一个"敢在发补偿之前先把问题解决"的人。

**关键台词**

> "数据不会骗人，但数据也不会告诉你，那个连着掉线七次还在登录的人，是不是在等你回一句'在修了'。"

## 二、核心配角

### 苏柚（ID：柚子的柚）

| | |
|---|---|
| **身份** | 星穹互娱客服组组长 / 游戏内天赋【读评】 |
| **年龄** | 26 |
| **记忆点动作** | 跟人说话时眼睛会往对方头顶瞟——她在读对方的"评价" |
| **外貌** | 短发，笑起来有梨涡，穿拖鞋上班（客服组特权） |

**天赋【读评】**：能看见每个人头顶浮着的一行字，内容是那个人"没说出口的评价"。

不是读心。是她能看见**别人对她的判断**。

这个能力设定有两个好处：
1. 她是全书唯一的"信息优势者"，能提供主角看不到的信息
2. 她承受着巨大的心理代价——她永远知道别人怎么看她

**与江砚的关系**：三年同事，没见过面（外包和正式员工不在一个工区）。她是唯一记得他每封补偿邮件落款的人。

**为什么她会认出他**：她头顶看到江砚的第一行字是——"这个人发的补偿邮件，落款一直是'在修了，抱歉'"。

**关键台词**

> "你知道我最烦你什么吗？你每次都说'在修了'。你根本修不了，你就是个发补偿的。可你从来没说过'修不了'。"

### 周启山（老周）

| | |
|---|---|
| **身份** | 灰鸦镇铁匠 / NPC / 1,844 人之一 |
| **年龄** | 设定 58 |
| **记忆点动作** | 每敲一下锤子，停一下，抬头看一眼门口 |
| **台词库** | 只有三条：①"客官，修东西么？" ②"铁打的，坏不了。" ③"……" |

**核心悲剧**：七年前女儿阿箬被系统删除。全镇没有人记得她，只有他记得——因为他是她的"关联对象"，删除时被保留了一段残存数据。

他每天偷偷改一个字：把台词里的"客官"改成"阿箬"。系统每次都会校正回来。他就再改。

**第一次说出台词外的话**：第 23 章，"谢谢你，策划。"

**关键台词**（第 4 章，把剑递给玩家时）

> "这些是我这七年打的。没人来买。我以为，我这辈子就打这些了。"
> "不收钱。"

### 梁铎

| | |
|---|---|
| **身份** | 《天穹》主策划 / 停服签字人 / 后成为第二个权限者 |
| **年龄** | 35 |
| **记忆点动作** | 说话时手指在桌面上画圈——他在算成本 |
| **外貌** | 头发三年少了一半，衬衫永远扎进裤子里 |

**他不是反派，他是"正确的人"。**

他的逻辑是自洽的：一个日活三千的项目，一年烧八百万，砍掉它是负责，不是残忍。他甚至为这场停服做了最体面的方案——提前三个月公告、分批发补偿、典藏周边。

**他错了的地方**：他把"正确"当成了"唯一"。

**他最狠的一句话**（第 1 章）：

> "《天穹》为什么会死？因为它太好了。它太好了，所以没人舍得改它。一个不肯变成另一个东西的游戏，只能死。"

**他的弧光**：从"算成本的人"变成"愿意为算不清的东西付一次账的人"。

### 沈迟（ID：念旧·会长）

| | |
|---|---|
| **身份** | "念旧"公会会长 / 带 300 人来送葬的人 |
| **年龄** | 31 |
| **记忆点动作** | 手里永远有一张纸，上面写满流程，他会一行一行划掉 |
| **外貌** | 洗得发白的衬衫，肩上挎一面幡 |

**他是"组织者"型角色**：全书所有群戏，都需要一个人把散沙捏成拳头。这个人就是沈迟。

**他的能力**：用三分钟推出江砚花了十一分钟才想明白的机制。他是主角的"镜像"——同样的脑子，不同的位置。

**他的秘密**：他妹妹沈小鱼（新手上路）三年前查出病，医生说不能长时间用脑。他带她玩游戏，是为了让她有事可做。

**关键台词**

> "我们不是来救它的。我们是来送它的。"
> "但如果你说它还能活，那我们就不送了。"

### 小小鱼

| | |
|---|---|
| **身份** | 17 岁高中生 / 主播（八万粉）/ 全场气氛组 |
| **记忆点动作** | 说话必带"家人们"，哪怕对面只有一个人 |
| **作用** | ① 负责把设定"喊"出来（读者通过他理解规则）② 负责把热度传出去（第 17 章的关键） |

**他为什么重要**：他是全书唯一一个"外部通道"。他手里的手机，是这个世界连接现实的唯一脐带。

**成长线**：从"蹭流量的主播"变成"记录者"。

### 刀锋所向（刀哥）

| | |
|---|---|
| **身份** | 38 岁货车司机 / 七年老玩家 |
| **记忆点动作** | 上线后不干别的，直接去后山那棵树下站着 |
| **秘密** | 这个账号原本是他女儿的。女儿九岁那年病故。他每天上线，是替她"签到" |

**写法提醒**：这个设定极易写成煽情。规则是——**绝不写他哭。** 他只做一件事：站在树下。所有情绪由别人替他表达。

**关键台词**（只有一句）

> "策划，这游戏能不能别关。"

### 新手上路（沈小鱼）

| | |
|---|---|
| **身份** | 22 岁 / 沈迟的妹妹 / 开服当天才下载游戏 |
| **记忆点动作** | 打不死的东西，她就一直打。每次打出 -1 |

### 陆压（陆爷）

| | |
|---|---|
| **身份** | 氪金 47 万的"大佬" / 其实是被人骗过的中年人 |
| **记忆点动作** | 说话时习惯性地"报价"——把一切换算成钱 |
| **作用** | ① 前期的主要对立面（用钱挑战规则）② 后期"付费玩家"群体的代言人 |

**他不是坏人**：他充值 47 万，是因为这是他唯一能"赢"的地方。现实里他输得一塌糊涂。

## 四、人物写作检查表

每写一个新角色，问四个问题：

1. **他的记忆点动作是什么？**（说不出 → 删掉这个角色）
2. **他要什么？**（具体到一个可以达成的目标）
3. **他怕什么？**（怕的东西决定他在危机时的行为）
4. **他和主角的关系是"帮忙"还是"添乱"？**（全是帮忙 = 工具人 = 读者记不住）

> 本书的标准配比：每 5 个角色里，至少 2 个会在关键时刻给主角添乱。
