# 世界观设定集 ·《我给第四天灾发任务》

> 设定不是背景板，是**冲突的制造机**。每一条设定都要能回答一个问题：它逼着主角做什么选择？

---

## 一、一句话世界观

> 《天穹》不是一款死了的游戏，是一个被装进服务器的世界。停服不是关机，是处决。

---

## 二、三层结构

```
┌─────────────────────────────────────────────┐
│  第三层 · 后台层（只有江砚能看见）              │
│  运营中台 v1.0｜数据看板｜任务配置｜资源池       │
│  规则：只能施加"影响"，不能施加"力量"            │
├─────────────────────────────────────────────┤
│  第二层 · 世界层（"九垓"）                     │
│  九块浮空大陆｜灰鸦镇（第 1 块·下垓的边角）      │
│  1,844 个原住民｜有情绪值，会溢出，会觉醒        │
├─────────────────────────────────────────────┤
│  第一层 · 现实层（2027 年，星穹互娱）           │
│  停服公告｜裁员｜论坛｜直播｜热搜                │
│  规则：现实的热度反向喂养虚拟世界的寿命          │
└─────────────────────────────────────────────┘
```

**三层之间唯一的通道是"注意力"。**

玩家看得越多、聊得越多、充得越多，第二层就越结实。第三层只能通过第二层起作用。第一层的热度可以通过第二层折算成经验值。

这个设计让"运营"这个职业从"打杂"变成了"造物"。

## 三、世界层：九垓

### 3.1 地理

九块浮空大陆，按"上、中、下"三垓排列，每垓三块。

| 垓 | 名称 | 状态（第一卷） | 说明 |
|---|---|---|---|
| 下垓 | 灰鸦境 / 沉钟境 / 盐海境 | 灰鸦境已开放，其余锁定 | 新手区，Lv.1–20 |
| 中垓 | 三块未命名 | 全锁 | 需世界等级 4 解锁 |
| 上垓 | 三块未命名 | 全锁，且地图上有一道裂缝 | 卷末伏笔 |

**关键地理设定：大陆的接缝处有裂缝，裂缝会渗"黑"。**

裂缝是七年前那场"封存"留下的伤口。第一卷只让读者看到裂缝在扩大，不给解释。

### 3.2 灰鸦镇（第一舞台）

一个只有 1,844 人的边陲小镇。三条街，一个广场，十七间铺子。

| 地点 | 功能 | 关键人物 |
|---|---|---|
| 铁匠铺 | 修装备 / 打武器 | 周启山（老周） |
| 布庄 | 卖布 / 裁缝 | 王阿婆 |
| 酒馆"半盏" | 恢复 / 情报 | 老板娘柳氏、杂役小满 |
| 布告栏 | 系统公告 / 玩家聚集 | — |
| 后山 | 那棵树 | 无（但树下埋着名字） |
| 镇口 | 登录点 / 刷怪区 | 守卫老陈 |

**为什么选"灰鸦镇"而不是主城：**
主城太大，读者记不住；新手村太小，装不下 300 个玩家的群戏。灰鸦镇刚好——大到能容纳一场保卫战，小到每个 NPC 都有名字。

### 3.3 原住民（NPC）的三条铁律

1. **他们不是数据，是被"设定"住的人。** 每个人有 3 条固定台词，但行为不受限（会擦汗、会犹豫、会害怕）。
2. **情绪值超过 100% 会"溢出"。** 溢出 = 开始说出台词库以外的话 = 觉醒的开始。
3. **觉醒的代价是被判定为"冗余"。** 系统认为，一个不按设定说话的对象，是"错误"。

> **这条设定是全书的情感引擎**：越像人的 NPC，越容易被清理。

### 3.4 七年前的"封存"

| 时间 | 事件 | 读者知道多少 |
|---|---|---|
| 七年前 | 《天穹》立项，服务器上线 | 全部知道（公开信息） |
| 七年前 · 上线第 11 天 | 一次"版本回档"，官方说法是数据异常 | 只有传闻 |
| 七年前 | 灰鸦镇铁匠的女儿"阿箬"被删除 | 第一卷中段揭示 |
| 三年前 | 江砚入职，接手"活动与补偿" | 全部知道 |
| 现在 | 停服 | 全部知道 |

**核心悬念（全书主线）：七年前那次回档，到底回掉了什么？**

答案分三层揭示：
- 第一卷：这个世界的规则被人改过（玩家死亡不掉级）
- 第二卷：改规则的人是"第 0 版"的幸存者
- 第三卷：那个幸存者就是"回收程序"本身

## 四、第三层：运营中台

### 4.1 它是什么

一块贴在视野右上方的淡蓝色半透明界面。长得跟江砚上班时用的后台一模一样——这是最狠的一处设定：**他获得的不是魔法，是工位。**

### 4.2 它能做什么（以及不能做什么）

| 能 | 不能 |
|---|---|
| 看所有人的数据（七维） | 攻击、治疗、移动任何对象 |
| 发布任务（消耗资源池） | 凭空创造物品 |
| 微调爆率（上限 ±30%） | 直接修改数值上限 |
| 发送补偿邮件（预支资源） | 给玩家发真实货币 |
| 封禁客户端连接（24h 上限） | 永久封号 |
| 发布全服公告（Lv.3 解锁，且必须"真实"） | 说谎——公告一旦发出，世界会强制使其成真 |

**最后一条是全书的规则核心：**

> **公告 = 契约。**
> 江砚宣布"本游戏不会停服"的那一刻，世界就会想办法让它不停服。但如果他做不到，反噬会加倍。

这让"发公告"从运营动作变成了赌命。

### 4.3 权限等级 ↔ 世界等级

**权限等级永远等于世界等级。** 这是唯一的限制，也是唯一的成长线。

| 世界等级 | 解锁 | 叙事意义 |
|---|---|---|
| Lv.1 | 任务配置（1 个位） | 只能求人 |
| Lv.2 | 掉落配置 | 能许诺 |
| Lv.3 | 全服公告 | 能立誓 |
| Lv.4 | 新地图（沉钟境） | 能扩张 |
| Lv.5 | 封禁名单 | 能立威 |
| Lv.6 | 地图编辑 | 能改造世界 |
| Lv.7 | 副本导演 | 能设计命运 |
| Lv.8 | 版本公告（影响现实） | 能改写规则 |
| Lv.9 | 现实接口 | 能与外面通话 |
| Lv.10 | 续期申请 | 能谈判 |

## 五、回收程序

### 5.1 它是什么

一段自动执行的清理进程。每天 00:00 运行一次，删除"冗余对象"。

### 5.2 它的判定逻辑

```
冗余度 = 该对象今日未被任何玩家交互的时长 × 权重
清理阈值：冗余度 > 3.5%
单次清理上限：本世界冗余总量的 5%
```

**翻译成人话：今天没人跟你说话，你今晚就会消失。**

### 5.3 它的三重身份（分卷揭示）

| 卷 | 读者以为它是 | 实际是 |
|---|---|---|
| 第一卷 | 一个冷血的系统进程 | 一个在执行命令的"人" |
| 第二卷 | 七年前封存的守门人 | 被封存者之一 |
| 第三卷 | 反派 | 唯一的幸存者，也是唯一的证人 |

**它说的第一句人话（第 19 章）：**

> "我不想删。但我在被删。"

## 六、术语表（读者友好版）

写游戏文最大的坑是术语堆砌。本书的规则：**每个术语第一次出现，必须紧跟一句人话解释，且解释由"玩家反应"给出，不由作者旁白给出。**

| 术语 | 人话 |
|---|---|
| 冗余度 | 今天没人搭理你，你就要被删 |
| 资源池 | 他的钱包，只有 3800 |
| 世界等级 | 世界的血条，靠玩家涨 |
| 情绪值溢出 | NPC 开始不像 NPC 了 |
| 回收程序 | 每天零点来收人的那个东西 |
| 黄叹号 | 头顶上那个"我有任务"的标记 |
| 冷却中 | 技能/任务位的冷却，本质是"你现在没牌可打" |

## 七、合规清单（写作时逐条对照）

> 依据：番茄平台审核规范 + 起点内容规范 + 网络文学出版管理相关要求。
> 原则：**架空要架得彻底。改词救不了改设定。**

### 7.1 已规避（本书做法）

| 风险点 | 本书处理 |
|---|---|
| 真实企业名 | 编造"星穹互娱"，不出现任何真实大厂名 |
| 真实城市 | 全书不出现现实城市名，只用"公司""家里""楼下便利店" |
| 真实机构 | 不出现任何现实监管/执法机构 |
| 真实人物 | 全部虚构，配角名不与现实名人重名或谐音 |
| 封建迷信 | 世界观是"游戏世界"，无鬼神体系、无轮回转世设定 |
| 暴力尺度 | 战斗写"光点散开/复活"，不写血腥细节；死亡=数据消散 |
| 赌博 | 无抽奖、押注情节 |
| 色情 | 无任何性描写；男女主关系为同事/搭档 |
| 系统任务违法化 | 所有任务均为"打怪/护送/修缮/采集"，无犯罪类任务 |
| 自杀自伤 | 全书不出现（刀哥女儿是病故，且以侧写处理，不正面描写） |

### 7.2 需要持续注意

1. **"封号"情节**：不得写成"报复社会"或"侵犯真实用户权益"，要写成游戏内规则执行。
2. **"裁员"情节**：可写，但不得渲染劳资对立、不得出现真实维权流程细节，落点要在"主角的自我重建"上。
3. **"直播/热搜"情节**：平台名一律虚构（"某短视频平台""某论坛"）。
4. **玩家自杀/极端行为**：绝不写。如果剧情需要，用"退游"替代。

### 7.3 每章发布前自检

```bash
python3 05_tools/prose_lint.py --input 04_manuscript/第XX章_xxx.md
```

P0 命中 → 改设定；P1 命中 → 改词；P2 命中 → 看语境决定。
