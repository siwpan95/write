# 分卷大纲

> 总纲：**一个人用"运营"的方式，把一个正在死的世界，养活。**
> 全书 150 万字 / 三卷 / 约 460 章。
> 第一卷已出 30 章节拍表（见 `_auto_beat_sheet.md`），本文件提供四幕结构与关键节点。

---

## 第一卷《停服日》

| 项 | 内容 |
|---|---|
| 章数 | 30 章（约 10.5 万字） |
| 时间跨度 | 30 天（严格倒计时） |
| 核心问题 | 这个镇子能不能活过第一天？ |
| 卷目标 | 世界等级 0 → 10，保住 1,844 个原住民 |
| 卷末状态 | 按下"续期申请"，管理员权限清零 |

### 四幕结构

#### 第一幕｜活下去（第 1–10 章）

**从"1 个管理员 + 3 个玩家"到"灰鸦镇守住第一夜"。**

| 章 | 关键事件 | 幕内功能 |
|---|---|---|
| 1 | 被裁 → 停电 → 掉进灰鸦镇，后台出现 | 事故 + 金手指 |
| 2 | 三个玩家降临，用唯一任务额度支走他们 | 第一次掌控 |
| 3 | 全服公告"世界寿命 30 天" + 清理名单 | 目标确立 |
| 4 | 灰鸦镇保卫战，300 人守夜，世界等级 1 | **第一个大高潮** |
| 5 | 老周的女儿阿箬，7 年前的删除记录 | 情感 + 悬念 |
| 6 | 刀哥的账号，树下的站桩 | 情感 |
| 7 | 苏柚登场，【读评】天赋 | 信息优势建立 |
| 8 | 0 点，第一个 NPC 被格式化 | **代价（虐点）** |
| 9 | 发补偿礼包，300 人愿意留下 | 社交反转 |
| 10 | 梁铎的第一道 GM 指令，冻结地图 | 对抗升级 |

**第一幕结尾的"钩子"**：冻结区里站着一个"本版本已删除"的 NPC。

| 14 | 造神：把爆率调到极限，让零氪玩家爆出传说 | 爽点 |
| 15 | 回收程序"学习"，清理频率从每日改为每小时 | **危机升级** |

**第二幕结尾的"钩子"**：怪潮不是系统刷的——是裂缝里爬出来的。系统也是受害者。

## 第二卷《回档》

| 项 | 内容 |
|---|---|
| 章数 | 约 180 章 / 60 万字 |
| 时间跨度 | 一年 |
| 核心问题 | 七年前那次回档，到底回掉了什么？ |
| 核心矛盾 | 世界续期了，但每续一次，就要删掉一部分记忆 |

**主线设计**

1. **续期的代价**：续期不是永久的。每 30 天要续一次，每次续期需要"献祭"——删掉世界 1% 的记忆。
2. **主角的新身份**：他从管理员变成了一个 NPC，但保留了"能看见数据"的半残权限。**从"下命令的人"变成"只能旁观的人"**——这是全书最狠的落差。
3. **梁铎接棒**：梁铎成为新的管理员，他选择的路线是"效率优先"——为了续期，可以牺牲记忆。两人价值观正式分裂。
4. **开新地图**：沉钟境、盐海境，世界观扩张，等级 21–60。
5. **回收程序的来历**：它原来是"第 0 版"的最后一个 NPC，被留下来当守门人。它的"清理"其实是"保存"——把要消失的对象存进一个离线档案。

**卷末**：江砚发现，被"删除"的 NPC 没有死，他们在第 0 版的存档里活着。而他要去那儿。

## 第三卷《续期》

| 项 | 内容 |
|---|---|
| 章数 | 约 200 章 / 70 万字 |
| 核心问题 | 一个世界，能不能不靠管理员活着？ |
| 终局 | 江砚拆掉了后台，把权限分给所有原住民和玩家 |

**主线设计**

1. **现实与虚拟的边界崩塌**：世界等级 9 解锁"现实接口"，游戏里的东西开始影响现实（先是一句公告出现在热搜，后来是一个 NPC 出现在地铁站）。
2. **最终反派不是人，是"商业模式"**：星穹互娱决定把这个"会自己生长的世界"做成新的产品，要重新上线、要收费、要删档内测。
3. **江砚的终局选择**：不是打赢，是**让这个世界不再需要他**——把后台拆成千万份，分给每一个愿意留下的人。
4. **结局**：灰鸦镇的布告栏上，出现一行新的字，不是系统发的，是玩家自己写的：

> **本服永不停服。**
> ——全体玩家
