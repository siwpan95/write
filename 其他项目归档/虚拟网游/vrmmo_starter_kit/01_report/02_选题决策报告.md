## 二、三个候选方案对比

| | 方案 A | 方案 B | 方案 C |
|---|---|---|---|
| **书名** | 我给第四天灾发任务 | 满级号回新手村 | 我的职业是副本BOSS |
| **一句话** | 被优化的策划掉进自己的游戏，靠后台给玩家发任务 | 全服第一重生开服第一天，双号碾压 | 转生成新手副本 BOSS，每天被刷几百次 |
| **核心爽点** | 调度（我说了算） | 数值（我最强） | 反差（我才是关底） |
| **金手指限制** | 强（不能打架） | 弱（先知+满级理解） | 中（离不开副本） |
| **加权分** | **4.65** | 3.35 | 3.88 |
| **命中率** | **58.7%** | 45.9% | 53.1% |
| **结论** | ✅ 立项 | 🟡 保底 | ❌ 并入 A |

**方案 C 为什么并入 A：** C 最有价值的机制是"BOSS 也能给玩家发任务"。这个机制被完整保留进了 A，只是把身份从"BOSS"换成了"管理员"——自由度更高，不会被困在副本里。

**方案 B 为什么保留为保底：** 它最大的优点是执行成本低。如果 A 的三章写完自己读着不顺（判断标准：读到某一段想快进），可以立刻切 B，损失不超过一周。

## 三、定题卡

### 基本信息

| 项 | 内容 |
|---|---|
| 书名 | **《我给第四天灾发任务》** |
| 备用书名 | 《这个策划在游戏里搞运营》／《网游：停服前夜，我拿到了后台》／《全服玩家都在给我打工》 |
| 类型 | 虚拟网游 / 游戏异界 / 第四天灾 / 经营流 |
| 主平台 | 起点中文网（游戏分类） |
| 副平台 | 番茄小说（游戏体育 / 玄幻脑洞） |
| 目标字数 | 150 万字（第一卷 30 章 / 约 10 万字） |
| 日更 | 4,500 字（两更） |
| 单章目标 | 3,200–3,600 字 |

### 一句话卖点

> 一个刚被优化的游戏策划，在停服前夜掉进了自己维护的老网游，手握全服后台权限——玩家以为在开荒新游戏，其实每一步都在给他的 KPI 打工。

### 目标读者

- **核心层（60%）**：22–35 岁男性，玩过 MMO、懂"策划/运营"这个梗、对"打工人被优化"有生理性共鸣。
- **次核心（30%）**：第四天灾类型读者，冲着"NPC 视角 + 玩家当韭菜"来的。
- **外围（10%）**：游戏行业从业者与云玩家，冲着"行业黑话"的乐子来的。

### 对标作品与差异化

| 对标 | 借它什么 | 和它不一样在哪 |
|---|---|---|
| 《超神机械师》 | 第四天灾的"NPC 看玩家"视角 | 那本是"玩家穿越成 NPC"，这本是"运营人员掉进后台"——**权力来源不同** |
| 《这游戏也太真实了》 | 召唤玩家建设世界 | 那本主角是"游戏设计师"，但侧重建设；这本侧重**运营**（发任务、调爆率、办活动、写公告） |
| 《万朝之劫》 | 起点游戏分类的头部写法 | 它是历史游戏 + 万订品质；这本用**轻喜剧 + 强机制**打差异化 |
| 《全息：女号大佬》 | 番茄的"怪钩子"策略 | 它靠性别反转；这本靠**职业视角反转**（策划 vs 玩家） |

**差异化一句话：没有第二本让"策划"当主角，并且把"运营动作"做成战斗系统。**

## 五、开篇钩子的设计说明

黄金三章要交付三样东西：**一个事故、一次掌控、一个目标**。

| | 交付什么 | 具体做法 |
|---|---|---|
| 第 1 章 | 事故 + 金手指（不完整） | 被裁 → 写停服公告 → 停电 → 掉进灰鸦镇 → 后台出现但功能 90% 上锁 |
| 第 2 章 | 掌控感（一次小胜） | 三个玩家围住铁匠，主角用唯一的任务额度把他们支走 |
| 第 3 章 | 明确目标 + 长期期待 | 全服公告显示"世界寿命 30 天"，同时亮出"今日清理名单"，第一个名字是刚被救的铁匠 |

**为什么把"救铁匠"放在第三章结尾而不是第一章：**
因为读者需要一个"已经产生感情的对象"才在乎倒计时。第一章的铁匠只是背景板；第二章他给出了那张修理券，救了玩家一次；到第三章，他才值得被救。

情感是需要先投资的。

## 六、被否掉的其他方向（留档）

| 方向 | 为什么否掉 |
|---|---|
| 纯电竞文（LOL / CS 同人） | 吃 IP 红利，但番茄、起点都在收紧同人版权；且需要极强的赛事知识 |
| 全息网游 + 重生 + 双天赋掠夺 | 番茄主流，但同质化到读者能背出第一章标题（《网游：万倍掠夺》已有 218 万字占位） |
| 网游经验穿越修真 | 《武神坛指挥穿修真界》已经吃过这一波，且需要极强的"降维解释"能力 |
| 领主建设类 | 属于"游戏异界"分支，但爽点偏慢热，不适合新人首书 |
