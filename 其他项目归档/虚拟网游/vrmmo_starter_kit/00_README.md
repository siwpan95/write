# 《我给第四天灾发任务》开书工程包

> 一份从**扫榜选题**到**正文成稿 + 过审**的完整交付物，含全套可复跑的工具脚本。
> 选题：虚拟网游 / 游戏异界 / 第四天灾 · 起点主平台 + 番茄副平台

---

## 这套东西是什么

不是"一份大纲"，是**一条产线**。

```
扫榜取数 → 赛道分析 → 选题打分 → 设定 → 大纲 → 正文 → 体检过审 → 打包
   CSV      脚本        脚本      文档    脚本     正文      脚本
```

每一个环节都有对应的文件，且每一个自动环节都可以用命令行重跑一遍。

## 三分钟上手

```bash
cd 05_tools

# 1) 看看赛道长什么样
python3 rank_scan.py --input data/rank_samples.csv

# 2) 看看三个方案谁该立项
python3 hit_score.py --input data/candidates.json --sensitivity

# 3) 检查大纲有没有硬伤
python3 outline_build.py --config data/book_config.json --check

# 4) 体检一章正文
python3 prose_lint.py --input ../04_manuscript/第01章_停服前夜.md

# 5) 打包
python3 build_package.py
```

零第三方依赖，Python 3.9+ 即可。

## 核心结论（如果只看一段）

**「虚拟网游」这个类型壳还活着，但壳里的生物换了一茬。**

- 起点游戏分类 45 本样本里，`游戏异界` 占 48.9%，`虚拟网游` 只剩 15.6% 且高度依赖情怀本（《全职高手》完本五年仍在榜）。
- 纯"上线—打怪—升级—PK"已经不能支撑一本新书。
- 2026 年的增量在三个方向：第四天灾、游戏入侵现实、**外部职业能力降维进游戏**。
- 前两个已经很挤，第三个还基本是空地。

所以本书选的是第三个：

> **一个被优化的游戏策划，掉进自己维护的老网游，靠"运营后台"给玩家发任务。**
> 玩家以为在开荒新游戏，其实每一步都在给他的 KPI 打工。

命中率预判：**58.7%**（六维加权 4.65 / 5.0），三个候选方案里唯一进 S 档。

## 三个必须记住的写作纪律

1. **前 300 字必须有事故。** 第一章第一句是"被叫进会议室，手里端着泡面"——会议室是事故现场，泡面是小人物。
2. **金手指必须"不完整"。** 后台 9 个功能 7 个上锁，锁的钥匙是"世界等级"，而世界等级只能靠玩家涨。读者立刻知道该期待什么，也立刻知道主角现在很弱。
3. **每章必须有一个"运营动作"。** 这是本书的差异化肌肉。肌肉一松，就退化成普通系统文了。

## 关于这套工具的一点说明

**它们不是"AI 替你写作"的工具，是"防止你写崩"的工具。**

- `hit_score` 不告诉你哪本会火，它只逼你说出"这 6 个维度分别几分、为什么"。
- `outline_build` 不会替你编情节，它只在你填不出"这一章的钩子是什么"时提醒你那章是水。
- `prose_lint` 不懂文学，它只保证这章不会因为排版、节奏、踩词被读者划走。

**剩下的，只能靠你自己读一遍。**
