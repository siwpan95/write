# 第一章 世界总纲

## 1.1 三层宇宙结构 【A】

| 层级 | 名称 | 说明 |
|---|---|---|
| 顶层 | **宇宙 / 位面** | 无数平行世界并存；南、北、东、西"四极守者"分疆管辖，各自掌辖一片星域 |
| 中层 | **世界（大陆/星球）** | 一个位面内可含多个世界（如"美漫世界"、"艾什顿大陆"、电影位面） |
| 底层 | **小位面 / 异空间** | 可被开辟、封闭、作为囚笼或引爆（关横把合体魔神推进"旧小位面"引爆，十秒后位面化为宇宙尘埃） |

- **空间缝隙**：位面之间的裂缝。承影剑可斩开，但代价极大（见 2.2）。九头蛇曾用"空间设备"扭曲出虫洞，掉出一具僵尸和一本《控尸秘法》【A】。
- **空间虫洞**：宇宙外域侵略者开凿的通道，千年前被华夏仙神界自爆封堵，换来千余年和平；卷末最大虫洞被卿凰震碎【A】。
- **位面压制**：不同世界对力量有压制规则。高谭市曾压制冰、火、磁三系异能；电影位面内不能动用超能力；仓颉的具现文珠**不受任何位面与法则压制**【A】——这是全书唯一"万能"的力量。

## 1.2 分卷独立法则（同人创作第一硬规则）【B】

作者在卷首明确写死：

> "本书的每个分卷都是独立故事，全新人物、全新设定、全新世界！……除了主角姓名和部分能力，以及主线之外，本卷内容与其余分卷并无具体关联。"

这意味着写作时必须遵守：

1. **人物不跨卷**：第一卷的托尼、琴·葛蕾、弗瑞、唐门、杀道会，在第二卷/第三卷**不会出现**（除非写"跨界同人"并自行解释）。
2. **世界不跨卷**：每卷一张新地图、一套新力量名词。
3. **只有三样东西跨卷**：主角关横、找卿凰残魂的主线、"吞鬼兽刺青＋承影剑空间穿越＋具现文珠"三件套。

## 1.3 主线：卿凰残魂

### 定型事实【A】
- 卿凰 = 关横前世的恋人；转世为 X 战警的**琴·葛蕾**（书内多称"琴儿"）。
- 卷末卿凰觉醒，体内本是"凰之魂（善）＋凤之魂（恶，名'黑凤'）"同体；黑凤放出上千分身逃逸，卿凰以同术堵截并强启凤凰之力，把千余邪神卷入平行世界隧道，自身魂魄**分裂成千百道碎片，散入无数位面**。
- 北守者断言："**绝对不可能复活**"；残魂已分身千道，回到过去也只能看到"没有魂魄的虚影"。

### 复活条件（三条同时满足才算"设定内的可能"）【A】
1. **完好无损的肉身**——关横造了玄晶冰棺 + 悬空"眠凰之堡" + 四座文珠山峰守护；
2. **完好的魂魄**——必须逐位面收集残魂（一缕残魂连在关横心脏上，作"引路明灯"，收得越多感应越强）；
3. **代价**——"一命换一命"（具现文珠"生死"组合的理论推演，仓颉从未实践）。

### 写作可用规则
- 残魂**不是碎片化的记忆**，而是"魂体碎片"：每找到一片，可表现为——一缕气息、一个梦、一件旧物共鸣、一段前世幻境、一次短暂附身。
- 残魂会**依附于该位面的某个人/物/地点**，这是同人"每个副本一段故事"的天然接口。
- 关横对残魂的感应是"越近越强、越多越准"，允许写"误判""假冒残魂""残魂被他人拘禁"等冲突。

## 1.4 时间与"穿越"规则 【A】

- 承影剑斩开空间缝隙可穿越，**耗力巨大，一次只够带一个人**，且会造成剑身龟裂、剑魂陷入沉睡。
- 存在"时间之井"一类设施（娲族旧物，可指定年代）【C：第三卷开头残片，仅供参考】。
- 电影位面可由"能穿梭现实与电影世界的人"开启（书中小地府界的放映员瑟利德）。
- 时间流速可不同：昆仑秘境修炼一年 = 外界 24 小时。

# 第二章 力量体系

## 2.1 力量总分类（一张图看懂）

```
                     ┌─ 术：道术（符/咒/阵）——驱魔道门传承，主角根基
   个体力量 ──────────┼─ 气：御气术、铁拳气劲——昆仑"铁拳"传承
                     ├─ 魂：御鬼封魂（吞鬼兽刺青、灵契、同化、吞噬）
                     ├─ 异能：寒气 / 磁力 / 火焰 / 神速（借来）
                     └─ 仙：仓颉仙骨 → 仙神力 → 具现文珠（最高阶）
   外部力量 ──────── 神兵（承影剑）、神赐（奥丁祝福）、鬼契（海拉）、科技（战铠/血清/纳米）
```

**关键认知**：本书的力量不是"修炼等级制"，而是**"收集制"**——主角靠打副本捡能力，每样能力都有明确的"来源、容器、代价、可否跨卷"四要素。这套"来源可追溯"的结构，正是同人写作最该保留的质感。

## 2.2 承影剑（全书第一神器）

### 出身（原文级设定）【A】
- 数千年前，天外陨石坠落华夏，天子命炼化取精，铸**圣剑三口**献西王母贺寿：**上品"含光"、下品"宵练"、中品"承影"**。
- 西王母评："含光、宵练各走极端，不入仙神大能法眼；唯承影，位列中品，承上启下，有影而无实形，鲜有撄其锋芒者，正是为应华夏仙神千年劫而生的**卫道神兵**。"
- 西王母合**华夏仙神界所有大能**之力重铸，置于昆仑火山锤炼数百载而成。
- 剑魂初具灵性时，在西王母寿宴上察觉一位大能被**宇宙外域的邪魔控制**，自行脱鞘将其斩杀；众仙神斥其"妨主不详、嗜杀成性"，要求销毁；西王母不忍，将其**抛弃在昆仑山巅**，一弃数千年。
- 剑魂自述名"**承影**"，少年形貌，性格毒舌、爱看电视剧（关横把剑鞘扔沙发上开着电视，它整晚看肥皂剧学来的现代词汇）。

### 结构：三十三道太乙玄纹 【B】
每一道玄纹对应**一种可吸收的能量**。原文可确认的成长节点：

| 玄纹/印记 | 来源 | 效果 |
|---|---|---|
| 龙心烈焰纹 | 昆仑石窟斩僵尸龙 | 火焰之力、胸口黑龙纹显形 |
| 寒冰纹 | 约顿海姆冰霜王墓（冰风暴戒指崩碎） | "寒冰斩"，自身掌寒气 |
| 磁力线细纹 | 吸收磁力恶魂斯潘达姆 | 后期化光入左眼 → 磁力异能觉醒 |
| 星辰纹（最长、环绕剑锋） | 空间乱流中绞吸星辰齑粉与黑洞力量 | 获得"斩开空间缝隙"能力 |
| 第四道太乙玄纹 | 祝融本命神源、斗杀火旋龟、火风暴戒指粉碎 | 火焰进阶，可生"究极火焰" |
| "一"字细纹 | 参悟仓颉"悟"字文珠 | 与具现文珠共鸣，剑可承载文珠之力 |
| 四极星标 | 卷末四极守者所立誓约相关 | 可斩四极星域任何空间缝隙（耗力巨大，必致剑魂休眠） |

### 核心能力与限制
| 能力 | 说明 | 限制/代价 |
|---|---|---|
| **吸能** | 吸尽一切能量：龙心烈焰、等离子球、寒冰之匣寒气、仙宫神火、艾德曼合金熔液、哨兵机器人铁水 | 能量种类决定玄纹属性，非即时可用，需"消化" |
| **吸魂** | 可抽出鬼魂魂体、吸收恶魂（并回传记忆） | 次数多了会让吞鬼兽刺青变淡（后被凝魂香墨强化） |
| **斩空间** | 斩裂空间缝隙穿越 | 一次只能带一人；耗力巨大；剑身龟裂；剑魂沉睡 |
| **共生** | 三体融魂后，人魂与剑魂互为备份：一方虚弱另一方续力，剑魂可寄宿于主角魂魄深处温养 | 剑魂沉睡期间无法对话、无法借力 |

### 三体融魂（0270–0272，全书最关键的一次质变）【A】
1. 关横为救剑魂，主动让剑身晶石吸取自己的魂魄；
2. 剑魂反过来把自己的剑魂输回关横体内，"你输给晶石多少，我就输给你多少"；
3. 晶石新生成的魂魄也掺入，三者搅成一体，**以人魂、剑魂为主，晶石为次**；
4. 结果："人魂、剑魂既是两个分开个体，也能唇齿相依，一方虚弱，另一方可以立刻续力补救；你可以彻底掌控我的力量、运用我提供的异能；我也可以在神能耗尽时进入你的魂魄深处温养恢复。"
5. **写作要点**：这不是"融合成一个"，而是"双人共生"——剑魂保有独立人格，可以吐槽、可以闹脾气、可以罢工。这是本书最好的人物关系之一，同人里千万别写成"系统"或"外挂语音"。

## 2.3 具现文珠（仓颉传承，全书最高阶能力）

### 规则（原文逐条）【A】
| 项 | 内容 |
|---|---|
| 本质 | 将**关键字**嵌入珠内，使其"具体现实化"；不需要神力、仙力、邪力，只需要知识 |
| 组合 | 多颗文珠组合，**威力呈几何倍数增长**：一颗"风"=一阵大风；"风"+"龙"+"卷"=龙卷风 |
| 前提 | 施术者脑中必须有**海量知识**；知识越少，越造不出强字珠 |
| 代价 | 造珠时**强行抽离**脑中相关知识，被抽走的部分**永久消失，像"租金"一样不退** |
| 过载 | 知识大量流失 → 失忆（最轻）→ 彻底变成白痴（最重） |
| 生死 | "生"+"死"组合理论上可复活，但代价推测为**一命换一命**，仓颉从未尝试 |
| 位面 | **不受任何空间位面与真理法则压制**，任何地方都能用 |
| 继承代价 | 继承文珠后，**无法再自行生成"凝魂香墨"**；作为补偿，满地香墨化入吞鬼兽刺青，刺青更清晰、鬼兽睁眼可**延长魂体禁锢时间** |

### 已知字珠清单【A】
| 字 | 用途 |
|---|---|
| 悟 | 仓颉最后一颗文珠，已生灵智、只差一步化形；为传承重化文珠，部分力量融入剑身，字符封于关横**右瞳** |
| 止 | 定住合体机械魔神的行动 |
| 愈 | 治好唐绝的重伤（瞎眼不能复原） |
| 连 | 把卿凰一缕残魂连在关横心脏脉络上，持续输送生机 |
| 绝、对、防、御 | 关横把脑中知识凝成的四颗"绝对防御"文珠（用于守护眠凰之堡） |

### 写作规范（避免崩设定）
1. 文珠**不能当万能许愿机**：任何一次使用都要"付学费"——写一次失忆、写一次忘掉某个重要的人名或招式，才有质感。
2. **越是抽象、强大的字越贵**（"杀""死""复活"这类字珠几乎不可承受）。
3. 组合字要"可解释"：三个字必须构成一个现实事物（龙卷风、防火墙、铁壁），不能生造概念。
4. 关横在卷末把大量知识凝成四颗珠，等于**自己删掉了半个脑子**——这是写"他变笨了/记不住琴儿的脸"的合法依据。

## 2.4 吞鬼兽刺青（跨卷保留的核心能力）【B】

- 来源：华夏之行无意中获得（原为普通人用寻常材料攒刺的鬼兽图案，用多了会变淡消失）。
- 强化：融合"谛听"残魂后威力大增；后经凝魂香墨加固。
- **三颗破邪之眼**，三种功能：
  1. **震慑**——压制、定住鬼魂；
  2. **吞噬**——收鬼魂入刺青空间（可容纳火种、残魂、兽魂等非人魂体）；
  3. **暂时借取鬼魂能力**——同化某鬼魂，短时间获得其能力（书内极限：同化隐身变种人艾德比，得隐身 12 分钟，而艾德比本人只能 5 分钟）。
- 空间属性：可作"储物魂空间"，存过汽车人火种（爵士、天火）、各类魂体。
- 写作限制：借能力有**时限**与**魂体强度限制**；被同化的鬼魂会"疲惫""消散"，不是免费电池。

## 2.5 御鬼封魂：魂体的五种处置手段 【A】

| 手段 | 做法 | 效果 | 代价 |
|---|---|---|---|
| **镇** | 符纸贴额（灭尸法衍生） | 短暂定住僵尸/鬼魂 | 只是应急，控不住强者 |
| **契** | 结"主仆灵契"或"平等契约"（御鬼术） | 鬼魂听命，如"龙仆"阳宾 | 需对方自愿或被打服 |
| **同** | 鬼魂同化术（刺青） | 短时获得该鬼魂能力 | 时限、消耗刺青 |
| **吞** | 吞鬼兽吞噬 / 承影剑吸魂 | 收魂、得记忆、剑纹进化 | 刺青变淡、剑需消化 |
| **炼/点** | 三魂点灵法＋凝魂香墨（仓颉系） | 给将散之魂"凝固成形"，甚至点化成灵 | 香墨稀少；继承文珠后不能再产 |

**补充**：凝魂香墨还能"喂"给鬼魂使其壮大（书内喂给残魂杰伊·加里克、喂给火豕舒小猪）。

## 2.6 三尸秘法（驱魔道门核心传承，僵尸体系）【A】

| 秘法 | 层级 | 内容 | 状态 |
|---|---|---|---|
| **灭尸之法** | 基础 | 消灭僵尸（符、火、法阵） | 关横原本所学 |
| **控尸之法** | 进阶 | 以**自身精血为墨**，在僵尸周身画法阵；三个法阵可勉强控制数小时，**上百个法阵**才能彻底控制、根除忤逆情绪 | 从九头蛇保险柜夺得秘录，学会 |
| **融炼之法** | 顶级 | 把最高级的**尸皇**融炼成"本命化身"，短时间拥有尸皇之力 | 失传数百上千年，全书未现 |

**符纸控尸的历史定位**：控尸之法失传后，道门想出的应急办法，只能勉强限制行动自由，"方法已落下成"。

### 僵尸等级链【A】
尸兵 → 尸统领 → 超级僵尸（克隆体）→ **尸皇**（理论上最高，融炼之法的对象）

### 已知僵尸/尸傀
| 名称 | 本体 | 能力 | 限制 |
|---|---|---|---|
| 僵大宝 | M 国队长克隆体 | 超级士兵血清＋格斗术；注射蜘蛛侠血液后长出倒钩，可爬墙 | 爬墙仅 20 分钟；牙与指甲被拔，失去吸血/尸毒 |
| 僵二妮 | 幻影猫（凯蒂）克隆体 | 分子拟态穿墙 | **短期只能发动一次**，之后沉睡 24 小时 |
| 皇三泰 | 皇蜻蜓王者（非人） | 坐骑、力大、后期化形成少年 | 进化失败会危及生命，需巨虫体液续命 |
| 水鬼恰森 | 四百年前溺死商人 | 水性、情报 | 需香墨/香火维持 |

**共同规则**：僵尸需定时注射血液维持生机；拔掉的獠牙与指甲**不可再生**；克隆体能力弱于本体。
