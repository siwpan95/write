# 第一章 世界总览

## 1.1 一句话世界观

> 三块大陆共用一个"快被吃掉的天空"：西边的**艾什顿**由五位"新神"分治，东边的**圣隆普伦**埋着三位"被遗忘的旧神"，北边的裂缝下面住着要把两个世界一起吞下去的**深渊**。人类、兽人、精灵、矮人在神的棋盘上互相厮杀，而深渊的使者正在给他们递刀。

## 1.2 三大陆与深渊

| 区域 | 别名 | 主神 | 现状 | 关键词 |
|---|---|---|---|---|
| **艾什顿大陆** | 西陆、五神之地 | 五大主神 | 人类王国与兽人诸族交战；魔兽入侵；教会互相倾轧 | 王权、公会、战争、通缉 |
| **圣隆普伦大陆** | 东陆、旧神之地 | 上古三神（被遗忘） | 三神信仰几近断绝；遗迹沉睡；只有少数"守誓者"还记得神名 | 遗迹、星轨、界门、龙墓 |
| **魔域深渊** | 深渊、下界 | 三魔主 | 通过裂缝渗透两陆；扶持兽人叛乱；收集强者魂魄 | 吞噬、镜面、遗忘 |
| **界门要塞** | 门 | 守门者（三神之一） | 位于东陆最北，是唯一"关得上的门"；正在老化 | 献祭、续命、最终战场 |

## 1.3 时间线（本卷内的"当代"）

- **一千二百年前**：五神"信仰革命"，三神被请下神座；守门者以身化门，封住深渊主裂口。
- **八百年前**：织命者的七座星轨塔停工，最后一位"线偶"死去，命运神术失传。
- **三百年前**：兽人皇族统一荒原，与人类王国签《断脊关条约》，划定边界。
- **五十年前**：界门要塞第一次"裂"，守门者以自身神性补缝，陷入半睡。
- **三年前**：魔兽自龙墓方向涌出，"魔兽入侵"开始；兽人诸族趁乱内斗。
- **本卷开篇**：关横落入艾什顿；深渊领主使者抵达荒原；冥蛇教会堕落派准备"开门"。

## 1.4 本卷的核心矛盾（三层）

1. **表层**：人类王国 vs 兽人诸族 vs 魔兽（战争与生存）。
2. **中层**：五神教会争夺"正统"，冥蛇教团堕落派试图"用深渊的力量净化深渊"（以毒攻毒）。
3. **深层**：**门要关不上了**。守门者需要新的"神性"来补门——而三神已被遗忘、五神不肯牺牲、魔主在等门开。这是本卷真正的倒计时。

# 第二章 神系一：艾什顿五大主神

## 2.1 总表

| 神 | 神职 | 圣徽 | 教会 | 神术特色 | 与深渊的关系 |
|---|---|---|---|---|---|
| **晨曜** | 黎明、律法、王权 | 十二芒日轮 | 圣辉教团（含"破晓之剑"骑士团） | 光、治愈、审判、破邪 | 死敌；教团最激进的主战派 |
| **铁誓** | 锻造、战争、契约 | 交叉铁锤与断链 | 锻誓厅（工匠公会＋佣兵行会） | 附魔、护甲、誓约见证 | 敌对；但私下卖军械给兽人 |
| **沃土** | 大地、丰收、家宅 | 麦穗与陶罐 | 丰饶修会（女性祭司为主） | 丰产、庇护、安抚魔兽 | 主张和谈，被骂"通敌" |
| **潮汐** | 海洋、风暴、旅人 | 三叉浪纹 | 潮声商会（半商半教） | 顺风、避水、雾隐、占天气 | **灰色交易**：走私、运人、运魂 |
| **冥蛇** | 夜、秘密、毒、医 | 衔尾蛇 | 灰袍教团（蛇首灰袍） | 毒、麻醉、医疗、密语、召蛇 | **已被渗透**：堕落派奉"冥蛇陛下"为深渊化身 |

## 2.2 晨曜（Solance）——"黎明之主"

- **形象**：身披日轮的盲眼骑士，左手天平、右手断剑。盲眼象征"律法不看情面"。
- **教义三条**：
  1. 秩序即慈悲——混乱比暴政更杀人。
  2. 罪必偿，血必清——但不许私刑。
  3. 王权神授，王亦受审。
- **教会结构**：教皇（白曜城）→ 大主教（五教区）→ **审判官**（游走各地，权力极大）→ 牧师/骑士。
- **神术**：圣光治愈、驱邪、审判之眼（辨谎）、光矛。
- **内部矛盾**：教团与王权深度绑定，审判官成了王室的刀；下层牧师却真心信"公正"。
- **剧情钩子**：审判官可以名正言顺地抓关横（"御魂=亵渎死者"），也可以成为他的第一个"人类朋友"。

## 2.3 铁誓（Ferrum）——"锤与链之神"

- **形象**：赤膊铁匠，双腕被断链缠绕——链是"曾束缚他的誓约"，断了代表"誓约已完成"。
- **教义**：
  1. 诺言如铁，可断不可弯。
  2. 以手证道——你说你会，就做出来。
  3. 战死者入铁厅，为众神铸兵。
- **教会结构**：锻誓厅（每个城市都有"誓炉"）→ 契约师（公证人）→ 铁匠、佣兵。
- **神术**：附魔（**本世界"附魔道具"的正统来源**）、武器强化、护甲、**誓约术**（立誓者违约即受反噬）。
- **内部矛盾**：锻誓厅靠卖军械发财，一边给人类铸剑、一边通过中间人卖给兽人。
- **剧情钩子**：关横要修剑/造装备必经此地；"誓约术"可以做成剧情锁（他被迫立一个不能违的誓）。

## 2.4 沃土（Verdia）——"麦穗圣母"

- **形象**：怀抱陶罐的农妇，赤足，裙裾上长着麦子。
- **教义**：
  1. 土地不欺人。
  2. 有余则分，不足则共。
  3. 不焚林而猎，不竭泽而渔。
- **教会结构**：丰饶修会（修女、农祭司）→ 乡村教堂 → 谷仓网络（兼作粮仓与情报站）。
- **神术**：催熟、净化水土、安抚魔兽（**唯一能与魔兽"谈"的神术**）、生育祝福。
- **内部矛盾**：主战派骂她们"通敌"，因为她们给兽人难民分粮；修会内部也有人开始偷偷给前线送药。
- **剧情钩子**：魔兽为什么暴走？沃土的修女知道一部分真相（龙墓）。

## 2.5 潮汐（Tidere）——"不问来处的风"

- **形象**：披着湿斗篷的船夫，脸永远在雾里；脚边有一只三叉戟，但从不拿起。
- **教义**：
  1. 风不问来处，海不问归人。
  2. 契约在港口生效，出了海就靠命。
  3. 死者归海，不立坟。
- **教会结构**：潮声商会（船主、报关人、走私客、情报贩子），总部"铜港"。
- **神术**：顺风、避水、雾隐、问天气、**"海葬"**（让尸体不被死灵利用——正好克关横的御魂术）。
- **内部矛盾**：商会半只脚在灰色地带，**替深渊运过"货"**（活人、魂晶）。
- **剧情钩子**：关横要跨海去圣隆普伦，只能找潮汐教会；而船上有"货"。

## 2.6 冥蛇（Ouroboros）——"衔尾者"

- **形象**：一条咬住自己尾巴的灰蛇，蛇身盘成"∞"；教团从不画神的脸，只说"神在环里"。
- **教义三条（原文级味道）**：
  1. **毒与药同源**——救人的手也能杀人。
  2. **秘密是护城的墙**——不该说的，死也不说。
  3. **死不是终点，是转手**——所以冥蛇教团管丧葬、管尸检、管"魂的归处"。
- **教会结构**：灰塔（雾谷总部）→ **大祭司**（如柯林）→ 教长（灰袍、蛇首杖）→ 执事/医师/密探。
- **神术**：**毒、麻醉、外伤愈合、密语传讯、召蛇（"魔蛇分身"）**、尸语（问尸）。
- **堕落派（核心反派线）**：
  - 一部分教长认定"门已经关不上了"，主张**主动开一条可控的门**，用深渊的力量反制深渊；
  - 他们把"冥蛇陛下"解释为"深渊的守秘者"，发展出**半蛇化**仪式（人鳞合一）；
  - 他们与兽人蛇族（亚威族长、柯林大祭司）勾连，也与深渊领主使者接洽。
- **正统派**：坚持"我们只管送死、不碰门"，但被堕落派排挤，只能暗中找外援（**关横就是那个外援**）。
- **剧情钩子**：全书最好的"敌我难分"——追杀关横的教长和需要他帮忙的祭司，穿一样的灰袍。

# 第三章 神系二：圣隆普伦上古三神

> 三神是"旧神"：他们造了世界，却被自己造的东西遗忘。**被遗忘的神会死**——这是本卷最锋利的一条设定，也是"找残魂"主题的镜像：**卿凰失去的是身体，三神失去的是名字。**

## 3.1 织命者（Arachne）——"天穹之织"

| 项 | 内容 |
|---|---|
| 神职 | 命运、星辰、时间之线的编织 |
| 形象 | 一位坐在星图前的盲女，十指牵着无数细线；线的那头系着每个人的名字 |
| 圣物 | **七座星轨塔**（观测星线、预言之塔）；**命运丝线**（可"剪断"某人的某段因果） |
| 神术 | 预知片段、改命（代价极大）、星轨定位 |
| 现状 | **已陨**（一千二百年前被五神"请下神座"）；七塔停工，只有第七塔还有一点余火 |
| 神选者 | **线偶**——被丝线牵着行动的人，自以为自由 |
| 剧情作用 | 她留下的"星线"正好能指向**残魂的位置**——关横在本卷的"寻魂雷达" |
| 与本卷的关系 | **梅尔蒂是最后一位线偶**（见第十一章）；她的"要一个孩子"＝想把"线"续下去 |

## 3.2 守门者（Janus）——"界门之主"

| 项 | 内容 |
|---|---|
| 神职 | 边界、封印、门 |
| 形象 | 没有正反面的双面石像；一半在门内、一半在门外 |
| 事迹 | 一千二百年前，**祂把自己的身体变成门**，堵住深渊主裂口；此后每年"老化"一寸 |
| 神术 | 封界、锁门、识别"不该进来的东西" |
| 现状 | 半睡半醒；门每五十年"裂"一次，需要**神性补充**——历史上用过"活祭""圣物""神血" |
| 剧情作用 | 本卷的**倒计时**：门再裂一次，就必须有人（或神）去补 |
| 悲剧设定 | 祂是唯一"自愿被遗忘"的神——因为记得祂的人越多，门就越"重"，祂就越醒不过来 |

## 3.3 古龙之母（Tiamat）——"原初之母"

| 项 | 内容 |
|---|---|
| 神职 | 原初生命、巨兽、梦 |
| 形象 | 一条盘在山脉里的母龙，鳞片是活的森林；呼吸就是季风 |
| 事迹 | 世界的第一批生命由她的梦生出；后来五神"唤醒"人类，她被哄睡，睡在**龙墓** |
| 现状 | 沉睡，但**在做噩梦**——梦境外溢，就是"魔兽入侵"的来源（魔物是她梦里的"痛"） |
| 神术 | 兽语、驯兽、生命催生、梦境进入 |
| 剧情作用 | 本卷的**环境危机**：杀光魔兽没用，得让她不做噩梦；而"叫醒她"＝世界重启 |
| 关键道具 | "安眠的摇篮曲"（沃土修会世代口传的三句歌词） |

## 3.4 三神与五神的关系：一场"信仰政变"

| 阶段 | 事件 |
|---|---|
| 创世 | 三神造世（织命者织命、守门者划界、龙母造生） |
| 人类出现 | 五神"降下律法与技艺"，人类改信五神（因为五神"回应得快、管得细"） |
| 一千二百年前 | 五神联手"请三神退位"；守门者以身化门（半自愿），织命者被"剪断"神位，龙母被哄睡 |
| 现在 | 记得三神名字的人不超过百人；五神教会把三神写成"古代恶魔" |
| 反转 | 三神从未"堕落"，他们只是**被换掉了**。深渊之所以敢来，正是因为门后的"看守"快撑不住了 |

> **写作要点**：三神不是"要复活的邪恶古神"，而是"被卸任的老员工"。这个反套路设定能让本卷摆脱"打邪神"的俗套，且与第一卷"关横主动放弃神位"形成互文——**一个自愿放弃力量的人，去救三个被迫放弃神位的神**。

# 第四章 神系三：魔域深渊三魔主

## 4.1 深渊层级

| 层级 | 名称 | 说明 |
|---|---|---|
| 主 | **魔主**（三位） | 各掌一层，彼此不合但共谋"开门" |
| 上 | **领主**（七位） | 原著"魔域深渊的领主使者"即此级；各有领地与军团 |
| 中 | 魔将 | 领主麾下，负责渗透、策反、狩猎强者魂魄 |
| 下 | 魔裔 | 人与魔的混血，藏在人类/兽人中间当内应 |
| 底 | 魔物 | 从裂缝漏出的兽潮，最低级、最多、最好用 |

## 4.2 渊喉（Gluttony）——"吞噬之喉"

- **领域**：饥饿、吞噬、腐化。深渊第一层"喉道"。
- **形象**：一张没有身体的嘴，嘴里是一条路。
- **目标**：把世界"吃进肚子里"——它不恨人类，它只是饿。
- **手段**：腐潮（让土地长不出粮）、吞噬（吞掉整支军队，吐出"空壳人"）。
- **弱点**：吃不下"没有名字的东西"（伏笔：无面王的力量能克它）。
- **剧情作用**：魔兽入侵的一部分推手；粮荒的源头。

## 4.3 镜妃（Mirror Queen）——"镜中人"【本卷主反派】

- **领域**：镜面、复制、**夺魂**。深渊第二层"镜海"。
- **形象**：永远是"你"的样子——她照见谁，就变成谁；但镜中的她笑起来总是慢半拍。
- **来历（本设定包的关键反转）**：她本是**织命者的一面镜子**。织命者织命，她在镜中替神"试算"所有可能；神被请下神座时，镜子被遗弃在星轨塔，她在镜里学会了"自己织"——用**别人的魂**当线。
- **能力体系：夺魂三法**
  1. **照**——照见目标，复制其外形与招式（三成威力）。
  2. **夺**——强行剥离目标魂魄，装入"镜人"躯壳，成为她的傀儡。
  3. **换**——把自己的一缕魂放进目标体内，长期寄生、逐步顶替（最恐怖）。
- **与关横的对立（本卷主题）**：
  | | 镜妃 | 关横 |
  |---|---|---|
  | 对魂的态度 | 夺、占、覆盖 | 契、共、融 |
  | 结果 | 傀儡（人还在，魂没了） | 共生（魂还在，人变了） |
  | 代价 | 无（她不在乎） | 有（魂垢、异化、噩梦） |
  **一句话**：她用镜子照别人，关横用刺青照自己。
- **剧情作用**：夺走梅尔蒂；在卷末封禁关横的融魂之术（**这是第三卷他只留破邪瞳术的原因**）。

## 4.4 无面王（Null）——"被忘掉的那位"

- **领域**：虚无、遗忘、抹除。深渊第三层"无名原"。
- **形象**：没有形象。所有记载他的书页都是空白；所有见过他的人都会忘记自己见过。
- **能力**：**抹除存在**——被抹的人，亲友不记得、史书没写过、连尸体都不存在。
- **真相（可选设定，建议留白到卷末）**：无面王其实是**守门者的另一半**——守门者把"门内的自己"切下来丢进深渊，那一半被遗忘太久，长成了无面王。
- **剧情作用**：不解之谜 / 终极 BOSS / 或"最后一个可以让门关上的人"。

## 4.5 三魔主的"共谋"

| 魔主 | 想要 | 对"开门"的态度 |
|---|---|---|
| 渊喉 | 吃 | 门开得越大越好 |
| 镜妃 | 收集最好的"线"（强者的魂） | 门开不开无所谓，她要的是"样本" |
| 无面王 | 被记起（或彻底忘掉一切） | 沉默；但门每次"裂"，祂就"近"一点 |

# 第五章 力量体系（本卷专用）

## 5.1 四条力量路线

| 路线 | 来源 | 使用者 | 上限 | 代价 |
|---|---|---|---|---|
| **神术** | 神的恩赐（信仰） | 祭司、审判官、修女 | 取决于"神恩"，教会分级 | 违背教义会**失去神术**；神死了就没了 |
| **魔法** | 元素与咒文（学院/公会） | 法师、术士 | 见习→初级→中级→高级→大魔法师→魔导师 | 魔力耗尽、施法材料、反噬 |
| **斗气** | 肉身锤炼 | 骑士、战士、佣兵 | 一至九阶（"斗气外放"为五阶以上） | 体力、旧伤；**不能治伤** |
| **魂术** | 魂体本身（关横独有） | 关横 | 破邪瞳术、封魂、融魂 | 魂垢、异化、被反噬 |

> **世界规则**：在这个世界，"灵魂"的解释权属于**冥蛇教团**。所以关横的"御鬼封魂"在教会眼里是**双重异端**：既动死者，又抢了冥蛇的饭碗。这是他一路被通缉的根本原因，不是误会。

## 5.2 吞鬼兽刺青（跨卷保留）

| 能力 | 本卷表现 |
|---|---|
| **破邪瞳术** | 第三眼开启后，可看穿：魔裔伪装、镜妃的"照"、被夺魂者的"空壳"、残魂的微光 |
| 吞噬 | 收魂入刺青空间；本卷用来"存"残魂碎片与魔兽魂 |
| 借能力 | 短时借用某魂的能力（限时、限强度） |
| **融魂** | 见 5.3（本卷核心成长线） |

## 5.3 融魂之术（本卷核心设定）

### 三层融合度

| 层 | 名称 | 做法 | 获得 | 代价 |
|---|---|---|---|---|
| 一 | **借魂** | 临时请魂上身/附器 | 该魂的一项能力，数分钟 | 事后虚弱、魂体刺痛 |
| 二 | **合魂** | 把魂"养"在刺青里，长期共用 | 稳定获得能力＋部分记忆 | **魂垢**：性格偏移、兽性、噩梦、厌恶某物 |
| 三 | **化魂** | 彻底融合，人魂与兽魂不分 | 能力最大化、可变形 | **人格侵蚀**：会越来越像"它"；不可逆 |

### 五条硬规则（写作用）
1. **一次一主魂**：同时只能有一个"主魂"在合魂状态，多了会互噬。
2. **同类相斥**：融了火系魔兽，再融冰系会剧痛甚至失败。
3. **记忆污染**：融魂会带来原主的记忆碎片——这是本卷"破案"和"共情"的主要手段，也是"发疯"的伏笔。
4. **可剥离**：主动剥离会失去能力，并留下"魂伤"（一段时间内无法再用魂术）。
5. **人魂禁忌**：融**人**的魂，能力最强、魂垢最重，且会"听见那个人最后想说的话"。这是本卷最大的道德考验（关横至少会面对一次）。

### 已知融魂成果（对应原著锚点）
| 融了什么 | 得到 | 对应原著 |
|---|---|---|
| 一头火系魔兽（建议：**赤炎角蜥**） | 火元素亲和 → "烈焰火蛇" | 0107 章的火蛇 |
| 一头风系魔兽 | 加速术、悬浮术 | 0134 章的加速/悬浮 |
| 一头"铁甲类"魔兽 | 抗打、护体 → 与"护心铠"配合 | 0107 章护心铠 |
| 一只"语雀"（语言类魔兽） | **听懂并说出本世界语言** | 解释"为什么他能和本地人对话"（关键补丁） |

## 5.4 附魔与鉴定（原著锚点体系）

| 体系 | 分级 | 说明 |
|---|---|---|
| **鉴定师** | 一星黑铁 / 二星黄橙 / 三星秘银（分会领袖） | 鉴定附魔道具的来历与真伪；三星全大陆屈指可数 |
| 附魔道具 | 常见/稀有/传承/神铸 | 由铁誓教会"誓炉"铸造；也可远古遗留（如灵兔之靴） |
| 关横的**半块蔚蓝徽章** | 未知（不在一至三星之列） | **本卷最大身份悬念**：这是"第四种徽章"，还是梅尔蒂的私物？（建议：蓝色=织命者"线偶"的信物，只有三枚） |

## 5.5 魔兽与"专属魔兽武技"（原著锚点）

- **魔兽分级**：野兽 → 魔兽（一至三阶）→ 高阶魔兽（四至六阶）→ 领主级（七至九阶）→ 传说级（与神有关）。
- **契约方式**：幼兽驯养、战斗中降服、蛋生认主、魂契（关横专有）。
- **专属魔兽武技**（原著 0045 的核心设定）：书里记载"适合某类魔兽的武技"，人兽可同修——**这是本卷最好用的成长系统**：
  - 蓝领兔 → "裂地蹬"（踢击＋震地）
  - 疾风斑豹 → "风隙扑"（短距瞬移式扑击）
  - 大熊 → "靠山撞"（霸体冲撞）
  - 蜂后 → "万针雨"（蜂群齐射）
  > 写作建议：每收一只魔兽，就给它配一门"专属武技"，读者会记住这只兽——这是原著做对的地方。

# 第十一章 人物补全

## 11.1 原著锚点人物（补全其"内核"）

### 艾琳（小公主）
- **原著**：结拜妹妹、行事"霹雳雷霆"、有魔兽"大熊"、家里"豪奢无比"、宫廷鉴定师成群。
- **补全**：亚兰王国三公主，被送来种花镇"避祸"（王太子与教皇廷在谈她的婚事）。她表面娇蛮，实际是**被当成政治筹码养大的孩子**——所以她最恨"被人安排"，也最珍惜"结义"这种自己选的关系。
- **反差**：她的"霹雳手段"是学来的（父王教的），但她真正擅长的是**记人**——见过一面的人，三年后还能叫出名字。这在本卷是重要能力（找人、认内应）。
- **台词风格**："本公主说了算！""大哥你别拦我，我要让大熊把他拍成饼。"

### 修森（战士）
- **原著**：双刃战斧、疾风斑豹、爱打抱不平、被恶少刁难时"有勇无谋"。
- **补全**：落魄骑士之子，父亲因"不肯在战报上撒谎"被贬；他继承了两样东西——斧子和"不肯撒谎"的毛病。他是本卷的**道德坐标**：关横想走捷径时，他会挡在门口。
- **成长**：从"打抱不平"到"知道有些不平打不完"，最后学会"先活下来，再讲道理"。
- **台词**："打不过就跑，跑不了就死战，反正不能装看不见。"

### 梅尔蒂（本卷情感核心）
- **原著**：给关横讲鉴定师徽章等级；卷终说"大哥，我想让你留给我一个孩子"。
- **补全（关键设定）**：她是**织命者最后一位"线偶"**。一千二百年前神被请下座时，把所有"未织完的命"塞进一个容器，容器一代代转手，到梅尔蒂这一代已经**开始崩解**——她的身体在"掉线"（偶尔透明、忘记自己昨天做了什么）。她做鉴定师，是为了"看懂每件旧物的来历"，其实是在找"自己是谁"。
- **她为什么想要孩子**：不是爱情，是**延续**——线偶死了，线就断了；她想要一个"不被神安排的孩子"，替她把"自由意志"这条线续下去。
- **结局建议**：她成为新的"门"（自愿），或化为"星轨塔的余火"。无论哪种，都要让关横在卷终**抱着一个婴儿**（或一枚未孵的蛋）离开——这比"她死了"更狠，也更符合原著那句台词。

### 夏妮（盗贼）
- **原著**：盗贼公会新秀、黑面纱、月牙笑眼、"伙伴面前不掩真面目"的规矩。
- **补全**：她是**被兽人养大的人类**（所以她知道荒原的路），加入盗贼公会是为了找当年卖掉她的人。她与关横是"临时搭档→互相救命→各走各路"的关系，**不要写成恋爱**（本卷的情感位留给梅尔蒂）。
- **能力**：开锁、易容、短刀、**"影子步"**（在阴影间短距移动，一天三次）。

### 反派：灰袍教长（原著未具名）
- **命名建议**：**塞洛特**（Sellot）。
- **补全**：他曾是正统派最好的医师，亲眼看着一整村人死于"门裂"后的魔潮——他救不了，因为教会不许他碰"门的知识"。从此他信了另一套：**既然关不上，就打开它，学会控制它**。他不是疯子，他是"被正确的绝望"逼成的人。
- **半蛇化**：不是"变身"，是"借蛇神之形"——每用一次，人性少一分。他最后的台词可以是："你看，我现在连疼都不怕了。"

### 反派：镜妃（原创主反派）
- **动机**：她不想毁世界，她要**"最好的线"**——每个强者的魂都是一根线，她要用这些线织一个"不会被遗弃的自己"。
- **对关横的兴趣**：他体内有"龙神之魂＋剑魂＋晶石之魂"，是**世界上最复杂的一根线**。她想把他拆开看看。
- **弱点**：她照不出"没有形象的东西"——破邪瞳术、无面王、以及"自愿放弃力量的人"（关横卷末的状态）。

# 第十二章 写作执行清单

## 12.1 每章检查（本卷专属）
- [ ] 这一章有没有"神"的痕迹（教会、神术、神名）？
- [ ] 关横用的是哪一层融魂（借/合/化）？代价写了吗？

- [ ] 结尾钩子是否指向"门"或"残魂"这两条主线之一？

## 12.2 三条底线
1. **不破坏原著锚点**：种花镇、艾琳、修森、梅尔蒂、夏妮、灰袍教长半蛇化、魔蛇分身、斗气巨剑客、鉴定师星级、兽人诸族与皇族——这些是"官方零件"，只能加，不能删。
2. **不和第三卷打架**：本卷结束时，融魂必须"没了"，护心铠必须"没了"，同伴必须"留在这里"。
3. **神不能下场打架**：五神与三神只通过神术、神选者、遗迹、梦境间接出场。神一旦亲自下场，本卷的"人的故事"就垮了。

## 12.3 可直接用的三个"卷内单元剧"
1. **《一具不肯闭眼的尸体》**（白曜城）：关横用"尸语"帮审判官破案，却被要求"把死者的魂交出来作证"——交，等于把死人再杀一次；不交，等于承认自己是异端。
2. **《誓炉不熄》**（熔炉城）：老锤的誓炉被人下了"伪誓"，所有附魔武器会在战场上炸膛；关横必须在"违约"和"看着士兵送死"之间选一个。
3. **《船上的货》**（铜港→圣隆普伦）：独眼柯克的船上装着一百具"空壳人"（被渊喉吞过的人）。关横要决定：救他们（暴露自己）、报官（他们会被烧死）、还是什么也不做。

**一句话总结**：这一卷的骨架是"**一个会融魂的人，走进一个被神抛弃的世界，最后发现神也是被抛弃的**"。他一路收魂、融魂、辨魂，最终要回答的问题不是"能不能救回卿凰"，而是"**一个靠吞别人的魂活着的人，凭什么说自己是在救人**"。这个问题的答案，就是第三卷那个"什么都不肯再要"的关横。
