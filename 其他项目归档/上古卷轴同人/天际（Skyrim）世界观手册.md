# 天际（Skyrim）世界观手册

**——仅据 17 份素材词表反向构建**

> 素材：地点、无标地点、人物、任务、书籍、阵营、种族、法术、卷轴、箭、武器、护甲、灵魂石、食物和药水、物品和杂物、钥匙、植物和炼金。
> 性质：全部为**英中名词对照表**（含 ANK / 汤镬 / 大學漢化 / 官方繁中四套译名），**不含任何设定描述文本**。

***

## 0. 方法与边界

### 0.1 这份手册怎么来的

素材里没有一句话解释"世界是什么"。它只有名字。但命名本身就是证据：

* 一个地方叫「精灵之牙·阿尼蒙柯洛里」，说明曾有精灵在此建造**机械制造区**；
* 一件器物叫「黑色灵魂石」，说明灵魂可被**分色分级**储存；
* 一本书叫《锻莫法律探源》，说明消失的民族留下了**可被研究的法**；
* 一个派系叫「梭默」，一处任务叫「处死图留斯将军」，说明**政治暴力正在进行中**。

所以本手册的构建逻辑是：**名词 → 推论 → 规则 → 规则之间互锁 → 世界能运转**。

凡属推论的段落，一律标【推断】；凡直接源自词条的，标（素材：…）。

### 0.1.1 证据规模（去表头后的可用词条数）

| **词表** | **词条** | **词表**    | **词条** |
| ------ | ------ | --------- | ------ |
| 武器     | 3077   | 护甲        | 3126   |
| 人物     | 1974   | 法术        | 1492   |
| 地点     | 1191   | 物品和杂物     | 1152   |
| 任务     | 979    | 书籍        | 937    |
| 食物和药水  | 395    | 钥匙        | 369    |
| 植物和炼金  | 160    | 卷轴        | 92     |
| 种族     | 65     | 箭         | 47     |
| 灵魂石    | 10     | 阵营 / 无标地点 | 全表录入   |

> 结论：这是一个**密度极高、解释力为零**的素材库——名字足够多，因果一条没有。世界观构建的全部工作，就是把"名词的密度"转成"规则的密度"。

### 0.2 三条硬边界

1. **不引素材外的专名。** 本手册出现的每一个地名、人名、组织名、书名、物名，都能在词表中检索到。凡需一个素材没有的概念（如"世界名""纪元编号"），用素材已有词根组合，并标【推断】。
2. **完整 ≠ 无限细节。** 只写"能推出故事"的部分：规则、地理骨架、历史断点、社会运转、冲突源。细节留给扩展接口（见 §11.4）。
3. **自洽优先于丰富。** 每一章末尾有"本章锁死的边界"，声明哪些说法被规则排除，防止后续扩展互相打架。

### 0.3 世界的名字

素材有「泰姆瑞尔大陆」「天际」，有植物「奈恩根」，有「奈恩之魂」，有书《泰姆瑞尔的众神与信仰概述》。

故本手册称：**世界＝奈恩，大陆＝泰姆瑞尔，本卷舞台＝天际（Skyrim）**，天际北方的岛屿属地以「鸦石镇」「斯卡尔村」代称（素材无岛名）。

天有三重：**凡人界（奈恩地表与地下）、神界（圣灵与时间所在）、湮灭（迪德拉的领域）**。三者之间可通行，但通行有代价（素材：湮灭之门、湮灭之契、阿波科法、阿祖拉之星内部、松加德）。

## 1. 核心规则（世界的第一性原理）

一切社会现象必须能被下面六条规则解释；反之，任何与它们冲突的设定都应删掉。

### R1｜法力是可计量的资源，不是天赋灵光

* 证据链：`法力精华`（作为"种族/存在"被单列）、`充沛法力药水`／`极致法力药水`（等级化）、`法力药水配方`、`变换神药`／`毁灭奇药`（药效分级）、`法术书：火球术`、`卷轴`（一次性封存）、`法杖附魔器`。
* 规则：法力（Magicka）可蓄、可耗尽、可用药水与休息回补；法术必须**先有"书"才能施**（法术书是知识的物理形态）；卷轴是把一次施法**预封**在纸上；法杖是外置法力容器，需充能。
* 推论：**法师是专业阶层，不是野生的**。谁能持有法术书、谁就能垄断施法——这直接产生学院、宫廷法师、法术商人（素材：`冬堡学院`、`魔法商人法仁加`、宫廷法师）。

### R2｜灵魂是可以被捕获、分级、交易的物品

* 证据链：`微型／小型／普通／大型／特大灵魂石`（五级）、`黑色灵魂石`（专收人魂）、`阿祖拉之星`／`黑暗之星`（可复用容器）、`摄魂陷阱`、`窃魂箭`、`灵魂荚`、`灵魂石裂片`、`附魔药水`、`附魔师入门指南`。
* 规则：生物死亡的一瞬，灵魂可被封入灵魂石；石有容量等级，**装不下就浪费**；**人魂只能用黑色灵魂石收**，而黑色灵魂石在多数领地属于禁忌物【推断：由「黑色」与「人魂」的对立、以及黑暗之星的存在推出】。附魔＝以灵魂为燃料，把一段法术"焊"进器物。
* 推论：附魔业是一门**消耗死者的产业**；灵魂石是硬通货；"人魂附魔"天然构成道德红线与黑市（素材：`斯库玛贩子`、`销赃`）。

### R3｜语言即力量：龙吼不是法术

* 证据链：`龙吼`、`气旋龙吼`、`凯娜之静`、`意志屈服`（免疫项）、`力量之语`、`灰胡子`、`古代龙裔`、`龙裔之力`、`龙族`。
* 规则：龙吼（Thu'um）用**龙的语言**说出事物的"本来面目"，因此改造现实；它不耗法力，耗**气息**与**理解**（每个词需经"力量之语"训练才能承受）；对已掌握同一词者或特定存在（对"意志屈服"免疫者）无效。
* 推论：**龙吼是政治资源**。掌握它的人（灰胡子、龙裔、龙祭司）天然具备合法性或威胁性；也因此被制度化隔离——灰胡子居「高吼峰」，不下山。

### R4｜神会回应，但从不免费

* 证据链：九圣灵祭坛（`阿卡托什祭坛`／`阿尔凯祭坛`／`蒂贝拉神殿`／`玛拉祭坛`／`斯坦德尔祭坛`／`凯娜瑞丝神殿`／`尤里安诺斯祭坛`／`泽尼萨尔祭坛`／`塔洛斯祭坛`）、迪德拉祭坛（`波耶西亚祭坛`／`梅法拉祭坛`／`海尔辛`／`娜米拉戒指`／`莫拉格·巴尔之锤`／`瓦尔迷纳的睡眠药水`／`魄伊特祭坛`／`梅鲁涅斯·大衮祭坛`／`诺克图娜尔祭坛`）、`九圣灵骑士团`、`斯坦德尔的警戒者`。
* 规则：祭坛赐福**可重复但需离开再回**（一次性、有限、不叠加）【推断：由祭坛作为固定地点而非常驻效果推出】；迪德拉给出神器必索取代价，代价通常写在试炼里（素材：`波耶西亚的试炼`、`海尔辛的诅咒戒指`、`莫拉的诅咒`）。
* 推论：**宗教生活是"跑腿式"的**——去祭坛、领赐福、办差事、还愿。这解释了任务表里大量"把X带到Y"的结构：那是朝圣经济的日常形态。

### R5｜死亡不彻底

* 证据链：`尸鬼`（守墓）、`骷髅`、`幽灵`、`幽魂`、`召唤幽灵魔狼`、`复活僵尸`／`恐怖僵尸`／`亡魂奴仆`、`吸血鬼领主`、`狼人`、`松加德`、`英雄大殿`、`夜母之棺`。
* 规则：死亡有三种结局：**被记住**（进松加德，仅限战死者）、**被留住**（尸鬼、亡灵、缚魂）、**被转化**（吸血鬼、狼人）。三者都不是"复活"，而是"未完成"。
* 推论：**墓葬是基础设施**。古诺德坟墓遍布全境（`荒瀑古坟`、`安息坟`、`白脊古坟`、`覆炉古坟`、`伊斯格拉谟之墓`），既是圣地、也是矿藏、也是灾难源；由此产生守墓人、盗墓者、驱邪业（`亡灵毁灭卷轴`、`银制剑`、`圣水`）。

### R6｜材料有阶梯，器物有上限

* 证据链：矿脉表（`铁矿脉`／`钢锭`／`刚玉矿`／`银矿`／`金矿`／`孔雀石矿`／`月长石矿`／`黑檀矿`／`水银矿`／`星陨石矿`／`心石矿床`／`黏土矿床`）、成品表（`铁制`→`钢制`→`精灵`→`矮人`→`玻璃`→`黑檀`→`龙骨`→`魔冰`）、`龙骨`／`龙鳞`、`神光水晶熔炉`。
* 规则：武器护甲的强度由**材料 + 工艺 + 附魔**三者共同决定，缺一不可；稀有材料（龙骨、魔冰、黑檀、星陨石）受产地垄断。**魔冰（Stalhrim）只能以特定工艺处理**（素材：`新的魔冰资源`、`魔冰箭`）。
* 推论：**地质即地缘**。谁有矿，谁就有兵；马卡斯城（银矿）、晨星（铁矿与港口）、鸦石镇（黑檀）因此富而难治。

### 1.1 六条规则的互锁（因果表）

| **规则**   | **直接产生的社会事实**         | **素材锚点**        |
| -------- | --------------------- | --------------- |
| R1 法力可蓄  | 学院、宫廷法师、法术商人、法术书走私    | 冬堡学院 / 魔法商人法仁加  |
| R2 灵魂可封  | 附魔业、灵魂石贸易、人魂黑市、道德禁忌   | 黑色灵魂石 / 阿祖拉之星   |
| R3 语言即力  | 灰胡子的隐修与政治中立、龙裔的合法性    | 高吼峰 / 力量之语      |
| R4 神会回应  | 朝圣路线、祭坛经济、神殿祭司阶层、神器争夺 | 九圣灵祭坛 / 波耶西亚的试炼 |
| R5 死亡不彻底 | 守墓人、盗墓者、驱邪业、银与圣火产业    | 尸鬼 / 银制剑 / 圣水   |
| R6 材料阶梯  | 矿业城镇、锻造行会、稀有材料战争      | 黑檀矿 / 龙骨 / 魔冰   |

**自洽检验**：给定 R1–R6，能否推出"为什么这个世界的英雄大多是雇佣兵而非骑士团"？能——因为合法暴力被领主与军团垄断（`卫兵`、`帝国军团`），而民间需求（驱邪、护送、寻物、清巢）只能靠**可雇用的个体**承接（素材：`佣兵`、`赏金猎人`、`冒险家`、`可雇用的狗／死亡猎犬`）。这就是任务表 979 条的经济学解释。

## 2. 地理

### 2.1 三级地形模型

| **层**  | **内容**                   | **素材锚点**                                                |
| ------ | ------------------------ | ------------------------------------------------------- |
| **地表** | 九领、道路、农场、矿场、锯木厂、港口、哨塔、废墟 | 白漫领 / 东陲领 / 海芬加领 / 希雅陲领 / 苍原领 / 边塞领 / 裂痕领 / 佛克瑞斯领 / 冬堡领 |
| **地下** | 古诺德坟墓、锻莫地下城、冰川洞穴、伐莫巢穴、矿坑 | 荒瀑古坟 / 阿肯塔兹 / 布塔丹兹 / 楚安德-泽尔 / 精灵之牙 / 黑境                 |
| **界外** | 神的领域与死者的领域               | 松加德 / 阿波科法 / 湮灭之门 / 阿祖拉之星内部                             |

**关键设定**：地表是政治的，地下是历史的，界外是哲学的。三者通过"洞"连通——每一个洞口都是剧情入口。

### 2.2 九领：地理即宪法

天际分为九领，每领一城，领主（Jarl）治领，领内另设军营、监狱、哨塔、马厩：

`白漫城`（白漫领，居中，平原与苔原）、`风舵城`（东陲领，东北，港口与灰区）、`独孤城`（海芬加领，西北，王庭与灯塔）、`马卡斯城`（边塞领，西南，山中银矿）、`裂谷城`（裂痕领，东南，商道与湿地）、`佛克瑞斯`（佛克瑞斯领，南，森林与墓道）、`晨星`（苍原领，北，铁矿与码头）、`冬堡`（冬堡领，东北极寒，学院）、第九领为`希雅陲领`（沼泽，城名素材未给，以领名称之）。

* **权力随地形分布**：白漫居中控四路（东至风舵、西至马卡斯、北至冬堡、南至裂谷），所以它是内战必争之地（素材：`白漫城帝国营地`／`白漫城风暴斗篷营地`并存）。
* **财富随矿脉分布**：马卡斯（银）、晨星（铁）、鸦石镇（黑檀）、各处`矿坑`与`矿场`构成原料网。
* **信仰随孤立度分布**：冬堡孤悬海崖，学院得以自治（素材：`冬堡学院`、`首席法师居住区`）；高吼峰更高，灰胡子因此能"不下山"（素材：`高吼峰`、`灰胡子长袍`）。

### 2.3 城内的空间语法

一个天际城镇的标准配置（由词条反推，可用于快速搭建任意城镇）：

1. **权力核**：领主长屋／城堡（`龙临堡`、`蓝宫`、`佛克瑞斯领主的长屋`）＋`总管`办公室＋`监狱`＋`军营`；
2. **信仰核**：`神殿`（`蒂贝拉神殿`、`玛拉神殿`、`塔洛斯神殿`）＋`祭坛`＋`公墓`；
3. **经济核**：`杂货店`（`贝莱托尔杂货店`、`灰松木杂货店`）＋`铁匠铺`（`战争少女`、`滚烫铁锤`）＋炼金铺（`阿尔凯迪雅之釜`、`艾尔格瑞姆的药水店`）＋`旅店`（`沉睡巨人旅店`、`眨眼恶鼠`、`冻炉旅店`、`银血旅店`）＋`马厩`；
4. **边缘区**：贫民区／`亚龙人聚居区`／`虎人商人`帐（在城门之外）；
5. **地下**：`地下墓穴`＋地下水道＋（若为古聚落）`锻莫遗迹`。

> 写作接口：一个城镇只需要写出上述五格中的三格，读者就会自动补全其余。这是"完整不等于无限细节"的操作方式。

### 2.4 移动方式与季节封锁

`马`、`马车`、`渡船`、`船`（`赤红波浪`、`北岸平台`）、步行。山口（`布莱特辛山隘`、`寒石关`、`红路山隘`、`寒骨山隘`）是咽喉；冬季雪线上升，`霜`与`暴风雪`封锁北境【推断：由地名「寒石关」「雪幔圣所」与大量冰系法术、抗性药水推出】。

**本章锁死的边界**：不得出现蒸汽动力、火器、印刷机；远距离即时传送只能通过法术（`传送门`）或神的领域，且成本极高。地图尺度按"骑马数日可达邻领"计。

## 3. 历史

### 3.1 四段纪年（据素材书名重建）

素材提供了完整的历史书目骨架：《帝国简史》一至四卷、《第三纪元大事记》、《巨龙战争》、《红山之战》、《大坍陷》、《第一议会之战》、《第一要塞起义》、《阿卡拉什的最后剑鞘》、《巴兰兹雅传》、《奥拉夫与龙》、《奥杜因确实存在》、《奥杜因与阿卡托什的双重性》、《湮灭危机》、《天际约法》、《塔洛斯之谬》、《天际的再统一》、《天际的解放》。

据此排出四段：

**第一段｜龙的时代（黎明纪元）**&#x9F99;以"语言"统治，龙祭司为中介，人类为劳役。龙祭司以石棺与咒文求不死（素材：`龙祭司`、`阿季达`、`秘拉克神殿`、`斯库达芬神殿`、`奥杜因之墙`）。终结者是三勇士以龙吼放逐奥杜因——**这一点被后世当成神话，直到它回来**（素材：`奥杜因确实存在`）。

**第二段｜人的时代（第一、二纪元）**&#x4EBA;类起义（`伊斯格拉谟之墓`、`众王之殿`、`英格尔冢`），精灵退入地下（`精灵之牙`、`雪精灵`→`伐莫`），锻莫因不明原因整体消失（`锻莫历史文化文集`、`锻莫法律探源`、`阿肯塔兹`、`神光水晶熔炉`），兽人立国又被击碎（`奥辛纽姆与兽人`、`第一要塞起义`），红山爆发摧毁晨风（`红山之战`、`大坍陷`），第一议会之战确立人类帝国（`第一议会之战`、`阿卡拉什的最后剑鞘`）。

**第三段｜帝国时代（第三纪元）**&#x5E1D;国一统泰姆瑞尔（`帝国简史`、`帝国军团`、`帝国政府`），法度、道路、贸易公司成型（`东帝国贸易公司`、`帝国令状`、`天际约法`）。终结于`湮灭危机`：湮灭之门开启，帝国权威崩解。

**第四段｜当下（第四纪元）**&#x6E6E;灭危机后帝国收缩；夏暮的高精灵以宗教条款反制人类（`塔洛斯之谬`、`天际约法`）：**禁止塔洛斯崇拜**——而塔洛斯正是诺德人最珍视的"人成神"（`塔洛斯祭坛`、`塔洛斯护符`、`欧格蒙的塔洛斯护符`）。

于是：**内战**（`帝国军团` vs `风暴斗篷`，`处决图留斯将军`、`暗杀独孤城领主`）＋**龙的回归**（`打败奥杜因`、`龙裔`）＋**吸血鬼的阴影**（`吸血鬼领主`、`哈孔的骨灰`）＋**旧神的苏醒**（`秘拉克`）。

这四条线同时发生，就是本世界的"当下"。

### 3.2 历史的三种写法（世界观层面的设定）

素材里同一件事有三种载体，构成三种"史观"：

| **载体** | **谁写**   | **可信度**     | **素材**                            |
| ------ | -------- | ----------- | --------------------------------- |
| 官方史    | 帝国、领主的书记 | 服务于当下合法性    | 《帝国简史》《帝国报告：关于萨瑟尔城》               |
| 私人史    | 日记、书信、便条 | 真实但片面       | `阿尔瓦的日记`、`阿荣迪尔的日记`、`加卢斯的加密日记（密文）` |
| 神谕史    | 上古卷轴、经书  | 片段、不可解、要付代价 | `上古卷轴（龙／太阳／血）`、`黑暗经书`、`上古卷轴的作用`   |

**这本身是设定**：世界的历史是不可完全知的（见 §12.2 认识论）。

### 3.3 时间的伤痕

素材有 `在时间伤痕附近朗读上古卷轴`、`时间伤痕`。设定为：龙破裂之处，时间不再连续；在此读书可"看"到别的时刻。**用途**：允许"预言""悔棋""见到已死者"三类情节，但每次使用都会留下痕迹（更响的龙、更多的亡灵）。

**本章锁死的边界**：不得出现"平行宇宙任意穿梭"；改史只在局部、且以"记忆/见证"为限，不能改写既成的大势（否则 §9 的冲突全部失效）。

## 4. 种族

素材的「种族」表把所有有名字的存在都列为"种族"：既有可交往的文明族，也有魔物、亡灵、机械。这说明本世界&#x7684;**"种族"不是生物学分类，而是"是否被当作人对待"的政治分类**。

### 4.1 人类四族

| **族**    | **体貌／地理**   | **社会与信仰**                               | **与他族关系**                  | **素材锚点**                     |
| -------- | ----------- | --------------------------------------- | -------------------------- | ---------------------------- |
| **诺德人**  | 高大、耐寒，散居九领  | 尚武、重誓言与待客之道；信九圣灵但更信"人可成神"（塔洛斯）与"战死入松加德" | 排外：对精灵、亚龙人、虎人有成见；与帝国既依附又怨恨 | `松加德`、`塔洛斯护符`、`天际的诺德人`、`风舵城` |
| **帝国人**  | 中等体格，来自赛瑞迪尔 | 重法度、军政、商贸；以"帝国"为文明本身                    | 自视为秩序供给者，被诺德人视为占领者         | `帝国军团`、`帝国令状`、`帝国简史`         |
| **布莱顿人** | 半精灵血统，高岩一带  | 天生法力亲和，多出法师与炼金师                         | 被精灵视为"杂种"，被人类视为"半个精灵"      | `布莱顿人`、`法术书`群、`变换系训练师`       |
| **红卫人**  | 深肤色，落锤省     | 剑术与武术传统，重视家族荣誉                          | 曾与帝国结盟又破裂，散居为佣兵            | `落锤省服装`、`红卫人`、`佣兵`           |

### 4.2 精灵诸族：一条退化链

素材里精灵的分布不是并列的，而是**一条向下滑落的历史线**，这是本世界最重要的"历史可视化"：

* **高精灵（夏暮）**：魔法与血统至上论者，以宗教条款驯服人类（梭默）。证据：`梭默`、`塔洛斯之谬`、`夏暮暗影`。
* **木精灵（瓦伦伍德）**：森林狩猎者，善弓与草药。证据：`木精灵`、`精灵箭`、`荒野精灵`。
* **暗精灵（丹莫，晨风）**：灰烬之地与祖先崇拜，火山灾难后的流亡者，聚居于风舵城的`灰民区`。证据：`天际的丹莫人`、`丹莫人的祖先`、`灰烬薯`、`灰民区的灾祸`。
* **伐莫（雪精灵的残骸）**：曾建「精灵之牙」巨殿，战败后退入地下，被剥夺视觉与文明，成为盲眼猎食者。证据：`伐莫`、`伐莫箭`、`伐莫耳`、`精灵之牙`、`雪精灵`。
* **锻莫（矮人）**：工匠与法理的民族，造机械、造地下城、造神光水晶熔炉，然后**整体消失**。证据：`锻莫历史文化文集`、`锻莫法律探源`、`矮人机械球`、`矮人百夫长`、`阿肯塔兹`、`布塔丹兹`。

> **设定价值**：精灵史就是"一个民族如何失去自己的建筑、语言、眼睛"。当代高精灵的傲慢与伐莫的盲眼，是同一枚硬币的两面——这让"梭默"的意识形态带上历史讽刺。

### 4.3 兽族与兽人

兽人（Orsimer）信**玛拉凯斯**，以部落与"血亲"制组织，重锻造；被人类与精灵共同歧视，却在每一场战争里被双方雇佣（素材：`兽人血亲`、`部落兽人`、`拉加施布尔兽人`、`玛拉凯斯`、`奥辛纽姆与兽人`）。

**社会学意义**：兽人是本世界的"被排除者共同体"——他们证明文明不是包容的，而是划界的（§5.5）。

### 4.4 兽类智慧种族

* **虎人（凯季特）**：以商队形式流动，被城市拒于门外，只能在城墙外设帐（`虎人商人`、`虎人商人`、`虎人毛皮商的自白`）。其形态与月相相关【推断：由《天际的猫科动物》与虎人多形态词条推出】。
* **亚龙人（阿尔贡）**：来自黑沼泽，抗病、善水；在天际多从事码头与低阶劳作，聚居成区（`亚龙人聚居区`、`黑沼泽间谍`、`亚龙人麦芽酒`）。
* **巨人**：牧长毛象的独居者，语言不通，被视作"路障"而非"民族"（`巨人`、`长毛象`、`巨人的脚趾`）。

### 4.5 非人：龙、魔族、亡灵、机械

* **龙**：不是兽，是"词的持有者"。会说话、会统治、会复活（`龙族`、`龙祭司`、`古代龙裔`、`巨龙图志`）。
* **魔族**：湮灭的居民，可被召唤（`魔人`、`黄金圣徒`、`黑暗诱惑者`、`火焰元素`、`寒霜元素`、`风暴元素`）。有阶层、有交易习惯（`召唤魔人商人`、`召唤魔人管家`）。
* **亡灵**：`尸鬼`、`骷髅`、`幽灵`、`幽魂`、`吸血鬼`——见 R5。
* **机械**：`矮人蜘蛛`、`矮人机械球`、`矮人百夫长`、`锻炉警备长`。它们仍在运转，说明**锻莫的消失不是技术失败，而是别的原因**【推断】。

## 5. 社会

### 5.1 权力：五层结构

```
领主（Jarl）──总管（Steward）──侍卫（Housecarl）──卫兵（Guard）──市民
   │
   ├─ 宫廷法师（Court Wizard）
   ├─ 祭司（Priest）
   └─ 军营／指挥官（Commander）
```

* 领主由**血统与被承认**共同确定，因此内战一开，每个领都要"选边"（素材：`白漫城帝国营地`／`白漫城风暴斗篷营地`、`天际之子政府`、`流亡政府`、`当权政府`）。
* **武卫（Thane）** 是荣誉爵位，用以收买地方支持（`白漫城武卫`、`边塞领武卫`、`苍原领武卫`）。
* 总管掌钱粮与文书，是真正的行政者（`不情愿的管家`、`总管已经被威胁`）。

### 5.2 法：赏金、监狱、处决

* 违法有**价码**：`赏金`、`赏金猎人`、赏金收集者。捕快不追凶，只记债。
* 惩罚是**空间性的**：`监狱`（各城皆有）、矿场劳役、`处决`（`处决图留斯将军`）。
* 存在**管辖裂缝**：城墙内归领主，荒野归有力者；公会因此寄生在裂缝里（`盗贼公会`、`黑暗兄弟会`、`销赃`）。

### 5.3 经济：四条链

1. **矿石链**：矿脉→矿工→锭→铁匠→武器护甲→卫兵／佣兵／出口。锚点：`铁矿脉`、`钢锭`、`战争少女`、`厄伦德·灰鬃`（名匠）。
2. **农业链**：农场→粮→面包／汤／奶酪→城镇。锚点：`战狂农场`、`寒犁农场`、`雪蹄农场`、`卷心菜土豆汤`、`艾达奶酪`。
3. **酿造链**：蜂蜜／葡萄／小麦→蜜酒与葡萄酒→旅店→税收。锚点：`蜜之酿酒庄`、`黑棘蜜酒庄`、`诺德蜜酒`、`阿尔托酒`。
4. **秘术链**：草药→药水；灵魂石→附魔；法术书→施法。锚点：《植物和炼金》词表全表、`附魔师入门指南`、`灵魂石`全表。

> **经济即地理**：四条链的节点位置，自动决定道路、城镇、关卡布局。写新地区时只需摆四个节点，故事自己会长出来。

### 5.4 教育：训练师制度（本世界最独特的社会机制）

素材里出现了成体系的"训练师"：`炼金术训练师`、`变换系训练师`、`召唤系训练师`、`毁灭系训练师`、`幻术系训练师`、`复原系训练师`、`附魔训练师`、`锻造训练师`、`重甲训练师`、`轻甲训练师`、`单手武器训练师`、`双手武器训练师`、`箭术训练师`、`格挡训练师`、`潜行训练师`、`开锁训练师`、`扒窃训练师`、`口才训练师`。

推论（很硬的一条设定）：**技艺不靠天赋，靠付费拜师**。知识是可购买、可转让、可垄断的商品；"训练师"是社会的隐形骨架——每座城里都有几个掌握着别人吃饭本事的人。这也解释了为什么主角能"什么都会"：世界允许用钱换能力。

### 5.5 阶层与被排除者

* 上层：领主家族、富商（`银血`、`黑棘`）、名匠、首席法师。
* 中层：店主、农夫、矿主、船长、祭司、训练师。
* 下层：矿工、码头工、猎人、乞丐（`乞丐`、`乞丐王子`）、孤儿（`孤儿岩`、`孤儿之泪`）。
* **被排除者**：虎人商人（城外）、亚龙人（聚居区）、兽人（部落）、弃誓者（边塞原住民，被官方称作叛贼）、难民（`感染的难民`、`难民的栖息地`）、成瘾者（`上瘾者`、`斯库玛贩子`）。

**这里的设定锋芒**：歧视不是道德缺陷，而是**资源分配的产物**——谁被允许进城，取决于谁缴税、谁有行会、谁有领主背书。

### 5.6 军事

* **帝国军团**：常备军、重甲、编制（`将军`、`队长`、`士兵`）、攻城器械（`弩炮`、`弩炮箭弹`）。
* **风暴斗篷**：民兵＋老兵＋地方动员，轻装、机动、以信仰动员。
* **非国家武装**：`强盗`（`破桨强盗`）、`弃誓者`、`银血佣兵`、`黑棘佣兵`、`吸血鬼奴仆`、龙祭司的亡灵军。
* **战争形态**：攻城（`攻城战时，工作人员和家人会躲起来`）、堡垒攻防（`要塞`、`棱堡`、`哨塔`）、伏击（`伏兵`）。

**本章锁死的边界**：不存在常备骑士团式的圣战军；宗教武力只能是散兵（`斯坦德尔的警戒者`、`海尔辛的猎人`）。军队规模受粮道限制，战争是"据点争夺"而非"会战决胜"。

## 6. 文化

### 6.1 神系：两层信仰，互不否认

**九圣灵（可公开、可建神殿、可领赐福）**：阿卡托什（时间与王权）、阿尔凯（生死）、蒂贝拉（美与秩序）、尤里安诺斯（智慧与逻辑）、凯娜瑞丝（天与风）、玛拉（爱与人伦）、斯坦德尔（正义与守夜）、泽尼萨尔（劳作与商业）、塔洛斯（人成神）。

**迪德拉王子（可私下、可设祭坛、必须付代价）**：阿祖拉、波耶西亚、梅法拉、莫拉格·巴尔、海尔辛、桑吉恩、魄伊特、谢尔格拉、瓦尔迷纳、娜米拉、赫麦尤斯·莫拉、梅鲁涅斯·大衮、玛拉凯斯、诺克图娜尔。

三条决定全部宗教剧情的设定：

1. **圣灵是"维持秩序的一方"，迪德拉是"推动变化的一方"**——不是善恶二分，而是"要不要维持现状"。
2. **圣灵赐福免费但有限；迪德拉给神器但收灵魂或记忆。**（R4）
3. **每位王子都有"必然的破口"**：波耶西亚要背叛、海尔辛要猎杀、莫拉要知识、娜米拉要腐坏、瓦尔迷纳要噩梦、谢尔格拉要荒诞、莫拉格·巴尔要支配。**写好一位王子，只需写清"他要你做什么"。**

### 6.2 生死礼俗

* **婚礼**：玛拉神殿，祭司主持（`玛拉神殿`、`玛拉的使者`、`和玛拉莫谈谈准备婚礼的事情`）。
* **葬礼**：阿尔凯的祭司主祭，墓室被视为"第二住所"（`阿尔凯祭坛`、`阿尔凯的女祭司`、`地下墓穴`、`公墓`）。
* **战死者**：不入土，入松加德（`松加德的英雄`、`英雄大殿`、`众王之殿`）。
* **禁忌**：以黑色灵魂石收人魂；亵渎墓室；娜米拉的食人仪式。

### 6.3 节庆与公共生活

* **火烧奥拉夫节**（`参加火烧奥拉夫节`）：以焚烧肖像纪念屠龙者王，兼具政治宣示功能——**节庆即立场**。
* **市集与旅店**：旅店是信息交换所、雇佣中介、谣言市场（`沉睡巨人旅店服务`、`亡者之饮`、`眨眼恶鼠`）。
* **竞技**：`风舵城斗兽场`——暴力作为娱乐与秩序出口。
* **吟游**：`吟游诗人学院`、`天际歌集`、`奥拉夫王之诗`、`把芬恩的鲁特琴交给因格`。歌是"穷人读得起的史书"。

### 6.4 书与文字

* 法术书＝施法许可（`法术书：*` 全表）
* 卷轴＝一次性法术（`卷轴` 全表）
* 经书＝禁忌知识（`黑暗经书`、`上古卷轴`）
* 日记与信＝真相的碎片（`阿尔瓦的日记`、`加卢斯的加密日记（密文）`）

**识字率设定**：城镇手艺人可读账单与祷文，农民多不识字；**口头传播是主要信息渠道**，谣言比公文跑得快——这为任务设计提供了天然机制。

### 6.5 饮食与日常消费

主食：`面包`、`土豆`、`卷心菜`、`胡萝卜`、`韭葱`、`艾达奶酪`、`山羊奶酪`；肉：`鹿肉`、`牛肉`、`野猪肉`、`鲑鱼`、`海象肉`、`鸡胸肉`；饮：`诺德蜜酒`、`麦芽酒`、`葡萄酒`、`苏贾玛酒饮`、`马兹酒`；奢侈：`仙饮`、`圣水`。

**药物双轨**：`治疗药水`／`法力药水`（合法医疗）与 `斯库玛`／`红水斯库玛`（成瘾毒品）。

### 6.6 礼节与称谓

* 以"领名＋身份"称呼（`白漫城卫兵`、`东陲领武卫`）。
* 见面以"神佑"致意（`阿尔凯赐福`、`塔洛斯赐福`、`玛拉向你展露微笑`）——**祝福语即政治表态**：在梭默面前说"塔洛斯赐福"就是挑衅。
* 待客之道是硬规矩：拒绝款待等于宣战【推断：由诺德族群设定推出】。

**本章锁死的边界**：无中央教廷；九圣灵信仰是"地方神殿＋祭坛"的松散网络，宗教无法统一发令——这正是"禁塔洛斯"必须靠外部强权（梭默）执行的原因。

## 7. 能力体系

### 7.1 三条互不排斥的轨道

| **轨道** | **内容**               | **资源**     | **学习方式**   | **社会位置**    |
| ------ | -------------------- | ---------- | ---------- | ----------- |
| **法术** | 变换、召唤、毁灭、幻术、恢复       | 法力         | 法术书＋训练师＋学院 | 学院、宫廷法师、祭司  |
| **战技** | 单手、双手、弓术、格挡、重甲、轻甲、锻造 | 体力         | 训练师＋实战     | 军团、佣兵、铁匠    |
| **隐秘** | 潜行、开锁、扒窃、口才、炼金、附魔    | 无（靠技巧与消耗品） | 训练师＋行会     | 盗贼公会、商人、炼金师 |

**关键：三轨可以叠加。** 素材的装备表与法术表从不互斥——这意味着世界允许"施法的战士""附魔的盗贼"。这是"英雄可塑"的结构基础。

### 7.2 五学派（法术轨的骨架）

* **变换（Alteration）**：改物质属性——`木甲术`／`石甲术`／`铁甲术`／`檀甲术`／`黑檀之身`／`龙肤术`（护甲阶梯与材料阶梯同构，见 R6）、`念动术`、`水下呼吸`、`点石为金`。
* **召唤（Conjuration）**：从湮灭取物——`召唤火焰元素`／`寒霜元素`／`风暴元素`、`召唤魔人领主`、`召唤幽灵魔狼`、`召唤暗黑骷髅`、`亡魂奴仆`、`束缚剑／弓／匕首`。
* **毁灭（Destruction）**：以元素伤害——`火球术`／`火舌术`／`火焰风暴`、`冰锥术`／`冰风暴`、`闪电箭`／`闪电链`／`雷暴术`、`火焰符文`／`寒霜符文`／`闪电符文`。
* **幻术（Illusion）**：改心灵——`安抚术`／`恐惧术`／`狂乱术`／`心魔术`、`隐身术`／`静行术`／`魔光术`、`和睦术`。
* **恢复（Restoration）**：修生命、驱亡灵、设结界——`治愈术`／`快速治愈术`／`特级治愈术`、`驱赶亡灵`／`亡灵毁灭术`、`次级结界术`→`坚固结界术`→`强力结界术`、`斯坦德尔的光环`。

**观察**：恢复系同时是**医疗**与**反亡灵**——所以祭司与法医是同一职业，宗教在生死事务上不可替代。

### 7.3 等级制：五阶

素材反复出现"新手／学徒／老手／专家／大师"（`召唤系新手`、`召唤系学徒`、`召唤系专家`、`召唤系大师`、`大师级幻术课本`）。设定为：

| **阶** | **能力边界**                     | **门槛**  |
| ----- | ---------------------------- | ------- |
| 新手    | 单发、近距、低效                     | 会读书     |
| 学徒    | 可连发，可维持短时效果                  | 系统训练    |
| 老手    | 范围效果、召唤中级存在                  | 实战与资源   |
| 专家    | 召唤上级存在、改写局部环境                | 稀有材料／名师 |
| 大师    | 一次性改变战局（`火焰风暴`、`群体麻痹`、`龙肤术`） | 传承与代价   |

**这条阶梯的社会意义**：大师稀少且可识别，因此**大师本身就是战略资源**——一个领有没有大师级法师，等于有没有炮兵。

### 7.4 三条"外挂"：附魔、炼金、龙吼

* **附魔**：把法术焊进器物，燃料是灵魂（R2）。器物有"充能耗尽"的问题，故需持续狩猎（`摄魂陷阱`、`窃魂箭`）。
* **炼金**：把植物、脏器、矿物组合成效果（《植物和炼金》词表全表：`奈恩根`、`丧钟花`、`荆棘之心`、`火盐`、`霜盐`、`魔族之心`、`巨人的脚趾`）。**炼金是穷人的法术**——不需法力、不需许可，只需知识与材料。
* **龙吼**：语言改造现实（R3）。已知词例极少：`气旋龙吼`、`凯娜之静`、`意志屈服`、`龙裔之力`。**稀少即力量**：素材中可数的几个吼声，构成政治与神话的全部筹码。

### 7.5 代价总表（写作时用于"不能让主角一路平推"）

| **能力** | **代价**              | **素材依据**         |
| ------ | ------------------- | ---------------- |

### 7.6 反制体系（让世界"能被打败"）

* **银**克亡灵与狼人（`银制剑`、`银制巨剑`、`银制弩箭`）
* **火**克吸血鬼与霜噬生物（`火焰箭`、`火盐`）
* **圣光／斯坦德尔**克亡灵与不死（`斯坦德尔的光环`、`亡灵毁灭卷轴`、`圣水`）
* **麻痹／静行／隐身**克人形敌人（`麻痹术`、`群体麻痹`、`静行术`、`隐身术`）
* **抗性药水**克元素（`火焰抗性药水`、`寒霜抗性药水`、`闪电抗性药水`、`魔法抗性药水`）
* **结界**克法术（`结界术`三级）

**本章锁死的边界**：没有"无消耗的无限施法"；没有"复活死人且永久"（`亡魂奴仆`有时限，`松加德`不可逆）；没有"跨学派万能术"。

## 8. 日常

世界观只有落到"一天怎么过"才可信。以下全部由素材的词条密度反推。

### 8.1 一年十二个月（素材实证）

`晨星月`（1）→`日晓月`（2）→`初种月`（3）→`雨手月`（4）→`次种月`（5）→`年中月`（6）→`日高月`（7）→`末种月`（8）→`炉火月`（9）→`霜落月`（10）→`日暮月`（11）→`夜星月`（12）。

农事历：初种月播种，日高月麦熟，末种月收割入仓，炉火月修屋备冬，霜落月起封路，夜星月是"最冷的月份，也是节庆与围炉的月份"【推断：由月名与食物储备逻辑推出】。

### 8.2 一天

清晨劈柴、喂鸡、开店铺板；午间市集最热闹，卫兵换岗；黄昏旅店起火，吟游开唱；夜里城门关闭、宵禁与盗贼同时活动。

**夜间的社会分工**：`盗贼公会`、`黑暗兄弟会`、`吸血鬼`、`狼人`共享同一段时间——所以"夜里出门"本身就是剧情宣告。

### 8.3 一户人家（三种典型）

* **农家**：种卷心菜／土豆／小麦，养鸡取蛋，女儿纺苔原棉，冬天靠奶酪与腌肉。孩子十岁起干活。
* **矿工家**：男人下矿（`矿工服`、`矿工日记`），女人在冶炼场分拣；矽肺与塌方是常态，`矿工营房`是集体宿舍。
* **手艺人家**：铁匠／炼金／裁缝，铺面即住宅，学徒住阁楼，`训练师`身份带来额外收入与威望。

### 8.4 一份差事（任务表的经济学）

素材 979 条任务里，绝大多数是六种动作：**取回、送达、护送、清除、交付、说服**。

这不是设计偷懒，而是世界规则决定的：治安由领主垄断，民间需求只能外包；而`赏金猎人`、`佣兵`、`冒险家`就是承接外包的阶层。

写作时可用公式：**委托人（有麻烦）＋障碍（地理／势力）＋物件（可携带）＝ 一条任务**。

### 8.5 旅途

`马`与`马车`走官道；`渡船`过河；山口是必经点也是伏击点；夜宿`旅店`或`营地`；遇`狼`、`剑齿虎`、`熊`、`强盗`、`弃誓者`是常态风险。

**距离感**：邻领之间"骑马两三日"，跨省"旬日"，跨陆"月计"——这使"消息滞后"成为可信的情节装置。

## 9. 冲突

冲突不是"有坏人"，而是**两套都合理的规则相撞**。本世界有八组结构性矛盾，全部可从素材锚定：

### 9.1 主权之争：帝国 vs 风暴斗篷

帝国＝秩序、贸易、法度、外部承认；风暴斗篷＝本土、信仰、自治、排外。

两方都有理：帝国能挡住梭默，风暴斗篷能守住塔洛斯。**素材锚点**：`帝国军团`、`风暴斗篷`、`天际的再统一`、`天际的解放`、`处决图留斯将军`、`暗杀独孤城领主`。

**叙事价值**：无论选哪边，都要背叛另一半同胞。

### 9.2 信仰之争：梭默 vs 塔洛斯信徒

高精灵以条约禁绝"人成神"，因为塔洛斯的存在否定了精灵的血统优越。

**素材锚点**：`塔洛斯之谬`、`天际约法`、`塔洛斯祭坛`、`欧格蒙的塔洛斯护符`。

**叙事价值**：一句祝福语就能送命；信仰转入地下，祭坛设在野外（`塔洛斯祭坛`多处位于荒野）。

### 9.3 历史债：精灵 vs 人类

伐莫的盲眼、锻莫的消失、红山的灰烬，都是"人类胜利"的副产品。

**素材锚点**：`精灵之牙`、`红山之战`、`大坍陷`、`锻莫历史文化文集`。

**叙事价值**：当代政治的每一方都能从历史里挖出证据，且都挖得对。

### 9.4 家族之争：血亲 vs 血亲

白漫的`战狂`与`灰鬃`、裂谷的`黑棘`、马卡斯的`银血`——地方权力由家族网络而非官职决定。

**素材锚点**：`战狂农场`、`灰鬃氏族的家`、`黑棘庄园`、`银血旅店`、`银血佣兵`。

**叙事价值**：领主换人不会改变统治，家族换人才会。

### 9.5 法内 vs 法外：行会 vs 领主

`盗贼公会`（以`销赃`洗白）、`黑暗兄弟会`（以`契约`杀人）、`弃誓者`（以原住民权利为名的暴力）。

**素材锚点**：`盗贼公会总部`、`黑暗兄弟会圣所`、`夜母之棺`、`弃誓者`、`赏金`。

**叙事价值**：公会不是"恶"，是"法覆盖不到的地方长出来的秩序"。

### 9.6 生者 vs 未死者

`尸鬼`守墓、`吸血鬼`牧民、`龙祭司`唤醒亡灵军。

**素材锚点**：`尸鬼`、`吸血鬼领主`、`龙祭司`、`亡灵毁灭卷轴`、`斯坦德尔的警戒者`。

**叙事价值**：墓葬既是资源（陪葬品、龙骨）又是威胁，**挖与不挖都是选择**。

### 9.7 阶级与族群：谁被允许进城

矿工 vs 矿主；虎人商人 vs 城门；亚龙人码头工 vs 诺德排外；难民 vs 税基。

**素材锚点**：`虎人商人`、`亚龙人聚居区`、`感染的难民`、`矿工营房`、`乞丐`。

### 9.8 药物与成瘾：斯库玛经济

`斯库玛`／`红水斯库玛`／`斯库玛贩子`／`上瘾者`：一条从黑沼泽到街角的供应链，腐蚀劳动力与治安，且**没有一方能真正禁绝**（因为禁绝会催生更高价的黑市）。

**冲突设计的通用公式**：**任选两组叠加**（如 9.2＋9.4＝一个家族为保产业而暗中举报塔洛斯信徒），就能得到一条不需要反派的任务线。

## 10. 叙事

### 10.1 五个母题（全部可从素材书名读出）

1. **契约与代价**——迪德拉神器、《湮灭之契》、`莫拉格·巴尔之锤`。你要的东西，都有价。
2. **身份可换**——`狼人`、`吸血鬼`、`刺客`、`武卫`、`首席法师`。你做什么，你就是什么。
3. **记忆与遗忘**——`上古卷轴`、`黑暗经书`、`时间伤痕`。真相存在，但读到它要付代价。
4. **末日后重建**——`湮灭危机`、`大坍陷`、`天际的解放`。世界已经坏过一次，现在在勉强运转。
5. **外来者**——`龙裔`、`冒险家`、`虎人商人`。所有故事都从"一个不属于这里的人走进来"开始。

### 10.2 三条主角弧（对应三条能力轨道）

* **天命弧（龙吼）**：从"会喊"到"承担"。冲突在于：预言选了你，但没说你会做对。
* **技艺弧（公会）**：从"学徒"到"大师"。冲突在于：技艺要求你忠于手艺，组织要求你忠于它。
* **权力弧（领主／内战）**：从"办事"到"决定"。冲突在于：每一个决定都要牺牲一部分人。

### 10.3 物件网络（本世界最独特的叙事技术）

素材的任务表暴露了世界的连接方式：**世界不是由地理连接的，而是由物件连接的**。

`把剑交给普罗万图斯`、`把霜盐交给阿尔凯迪雅`、`把龙心外壳带给托夫迪尔`、`把一个充满的特大灵魂石带给瑟吉尔斯`——每件物品都是一条关系链，物品流动即社会流动。

**写作接口**：想让两个陌生角色发生关系，给他们之间放一件东西。

### 10.4 多视角的合法性

因为世界同时存在官方史、私人日记、神谕三种载体（§3.2），**同一个事件可以有三种都成立的说法**。这是本世界允许"罗生门式叙事"的结构性许可，而不是作者偷懒。

**本章锁死的边界**：不允许"预言全对"；不允许"主角无代价获胜"；不允许"单一反派解释一切"（本世界的恶都是结构性的）。

### 11.2 五个最容易写崩的地方与封堵

1. **"为什么不用法术解决一切？"**→ 封堵：法力有限、法术书垄断、法师人数少、抗性与结界普遍、施法有社会管制（学院／宫廷法师制度）。素材里法师仅 55 人条目，远少于卫兵与农夫，**人口比例本身就是答案**。
2. **"为什么国王不派军队清剿强盗？"**→ 封堵：军队被内战钉在边境；粮道有限；荒野无边。强盗住在`要塞`与`洞穴`里，攻城成本高于收益。
3. **"为什么主角能进所有古墓？"**→ 封堵：`钥匙`表证明门是锁的（369 条钥匙，覆盖每户人家、每座堡垒、每处圣所）；进墓要么有钥匙、要么有开锁技艺、要么有法术——三条路都要成本。
4. **"为什么亡灵不灭绝世界？"**→ 封堵：亡灵被困在墓中（需活人唤醒）；`斯坦德尔的警戒者`、银制武器、`圣水`、`亡灵毁灭卷轴`构成常备反制产业。
5. **"为什么精灵不直接灭掉人类？"**→ 封堵：梭默的胜利是**外交与宗教的**，不是军事的；正面战争成本过高，且人类有龙吼与龙裔这一不可预测变量。

### 11.3 规则推导链（一页看懂"世界为什么能转"）

```
法力可蓄 → 法师阶层 → 学院垄断 → 法术书成为商品 → 知识有价
灵魂可封 → 附魔业 → 灵魂石成通货 → 人魂禁忌 → 黑市与道德红线
语言即力 → 龙吼稀缺 → 灰胡子隐修 → 龙裔成为政治变量
神会回应 → 祭坛经济 → 朝圣即任务 → 神殿成为地方权力之一
死亡不彻底 → 墓葬基础设施 → 盗墓与驱邪产业 → 银与圣火经济
材料有阶梯 → 矿脉即地缘 → 矿业城镇 → 内战争夺矿产
```

### 11.4 扩展接口（不加规则也能长出新内容）

* **新地区**：套用 §2.3 的五格城镇语法 ＋ §5.3 的四条产业链。
* **新组织**：给它一门"只有它会的手艺"（附魔／开锁／屠龙／贩毒），它自动获得社会位置。
* **新神**：只需写清"他要你做什么"＋"代价是什么"（§6.1）。
* **新怪物**：只需回答"它靠什么活着"＋"什么能杀它"（§7.6）。
* **新历史事件**：必须留下三样东西——一处废墟、一本书、一句俗语。
* **新法术**：必须归入五学派之一，并给出等价物（法力消耗／卷轴／药水）。

## 12. 哲学世界观

> 这一章不是装饰。它是前面所有规则的"为什么"：如果抽掉它，世界仍然能跑，但跑起来没有重量。

### 12.1 本体论：世界是什么？

**答案：世界是一句被说出的话。**

推导链是硬的：R3 规定"语言可以改造现实"（龙吼）；那么最简约的本体论就是——**存在的底层是"词"，不是"物质"**。

* 神是"能说出世界的人"（《创世神与外来神》）；
* 龙是"记得原句的人"（`龙族`、`奥杜因之墙`）；
* 人是"被说出之后，学会自己说话的存在"——所以人能施法、能龙吼、能成神（塔洛斯）。
* 亡灵是"话没说完的存在"（R5）；灵魂石是"把一句话存进石头"（R2）。

**三层存在**：

| **层**   | **性质**      | **时间性**    | **素材**          |
| ------- | ----------- | ---------- | --------------- |
| 奈恩（凡人界） | 会朽坏、会遗忘     | 线性、会留下"伤痕" | `泰姆瑞尔大陆`、`时间伤痕` |
| 神界（圣灵）  | 维持"已经说出的部分" | 循环、恒常      | 九圣灵祭坛           |
| 湮灭（迪德拉） | 不断重说、改写     | 无时间、可任意    | `湮灭之门`、`阿波科法`   |

**哲学后果**：善与恶不是两种实体，而是"维持"与"改写"两种力量的张力。这解释了为什么本世界的"神"从不单纯善良——**秩序之神也可能残酷，变化之神也可能慈悲**。

### 12.2 认识论：如何认识世界？

**答案：认识必须付代价，且永远是片面的。**

* **书写不可靠**：书是抄本（多版本译名本身就是证据——同一词条有四套译法）；信可伪造（`法恩达尔伪造的斯万来信`）；日记可加密（`加卢斯的加密日记（密文）`）。
* **官方史服务当下**：《帝国简史》与《天际的解放》讲的是同一场战争的两个版本。
* **神谕只给片段**：`上古卷轴` 能"看"，但不能"懂"；读一次要付出视力、记忆或时间（`在时间伤痕附近朗读上古卷轴`）。
* **所以真正的知识来自亲历**：走过去、打进去、喝下去、被咬一口。这就是任务表的认识论——**世界只对到场的人显形**。

**推论**：本世界的"学者"不是书斋里的人，而是探险者。`乌拉格·格洛-舒布`（书库看守）与`冒险家`是同一知识体系的两端。

### 12.3 价值论／伦理观：什么是好？

**答案：有五种"好"，它们互相冲突，且没有裁判。**

| **价值** | **内涵**    | **承载者**     | **代价**  |
| ------ | --------- | ----------- | ------- |
| **荣誉** | 言出必行、战死不退 | 诺德、战友团、风暴斗篷 | 排外、嗜血   |
| **契约** | 立约必守、程序正当 | 帝国、锻莫遗法、迪德拉 | 冷漠、可被利用 |
| **技艺** | 把手上的事做到极致 | 锻莫、铁匠、盗贼、法师 | 不问用途    |
| **慈悲** | 救人、护弱、不弃  | 玛拉、斯坦德尔、警戒者 | 软弱、被背叛  |
| **自由** | 不受支配、自行其是 | 风暴斗篷、盗贼、虎人  | 无序、强者为王 |

**三条共同底线**（唯一真正跨文化的禁忌）：

1. **不可背誓**（对活人、对死者、对神）；
2. **不可亵渎死者**（墓室是"第二住所"）；
3. **不可用人魂附魔**（黑色灵魂石＝把一个人的"未说完的话"永远锁进石头）。

**伦理困境的写法**：把两种"好"放在一个人身上（例：一个守契约的帝国军官，同时是一个护弱的父亲，而命令要求他处决塔洛斯信徒）。**本世界不提供正确答案，只提供代价清单。**

### 12.4 自然观：人与自然是什么关系？

**答案：自然有主，人只是借用。**

* 风属于`凯娜瑞丝`，树里有`树精`，山中走`巨人`，海里游`气母`（`气母胶质`、`采集气母`）。
* 资源是**有限且会枯竭**的：矿脉会挖空（废弃的矿坑）、鱼群会迁徙、收成看天（`霜落月`后的饥荒）。
* 天气是政治：`暴风雪`封路，`寒霜`杀人，`冰怨灵`出没于河面。
* 因此本世界的"进步"不是征服自然，而是**与自然缔约**：向神献祭、向精灵致意、向巨人让路。

**哲学后果**：环境破坏不是道德问题，而是**违约问题**——砍光森林会招来树精，挖空山腹会唤醒亡灵（因为墓在山里）。

### 12.5 历史观：历史往哪里去？

**答案：历史是循环的，但每次循环都更低一层。**

* **循环**：龙的时代 → 人的时代 → 龙的回归（`奥杜因`）→ 新的英雄（`龙裔`）。素材把"奥杜因与阿卡托什"并列为"双重性"，即**毁灭与秩序是同一个神的两面**。
* **下降**：精灵建巨殿（`精灵之牙`）→ 退化为盲眼猎食者（`伐莫`）；锻莫造机械文明 → 整体消失；帝国一统 → 收缩至一省。**每一次辉煌之后都是坍陷**（`大坍陷`）。
* **个体位置**：个体能改变"这一轮"的结局，不能改变"有下一轮"这件事。所以英雄的意义不是终结历史，而是**让这一轮值得被记住**。
* **被记住即不朽**：`松加德`只收战死者——**历史只记得为某件事死过的人**，这是本世界最冷的一句社会评论。

### 12.6 人生观：一个人该怎么活？

**答案：既然必死，就做一件值得被唱的事。**

四条可选的活法（对应四条角色路线）：

1. **求名**（诺德式）：战死、入松加德、被写进`天际歌集`。
2. **求技**（工匠／法师式）：把手艺推到大师，留下作品（一件`龙骨`甲、一本`法术书`）。
3. **求义**（祭司／警戒者式）：守一条底线，哪怕无人承认。
4. **求自由**（盗贼／浪人式）：不受任何人支配，代价是永远没有家。

**共同前提**：本世界不承诺救赎，也不承诺公平；它只承诺**因果**——你做的每件事都会留下痕迹（`时间伤痕`、`赏金`、名声、神的记号）。

所以人生观可以压缩成一句话：**"你做什么，你就是什么；你欠什么，你就会遇见什么。"**

## 附录 C：十条可直接用的任务线

**生成公式**（§9 结尾）：任务线 = 冲突A × 冲突B + 委托人 + 可携带物件 + 地理障碍。

每条的写法统一为：**钩子 → 三幕 → 抉择（至少三条路） → 代价 → 素材锚点**。

代价一栏是硬要求：**没有代价的任务线只是跑腿**。

### C1《霜盐与圣像》｜9.2 信仰 × 9.7 阶级

* **钩子**：`白漫城`「`阿尔凯迪雅之釜`」的店主`阿尔凯迪雅`要三份`霜盐`，但要求"送到城外，别送到店里"。
* **三幕**：① 取盐——霜盐只在北境矿口与炼金商手里，价高且需凭`帝国令状`登记；② 送货——收货点是一座野外的`塔洛斯祭坛`，坛下藏着三个被通缉的信徒，正给一个伤者用`治愈伤口卷轴`；③ 搜城——`梭默`线人开始逐户查祝福语，`白漫城卫兵`被迫配合。
* **抉择**：交出盐并隐瞒（得信徒信任，被梭默记名）｜举报（领赏金，祭坛被拆）｜把伤者转进`白漫城地下墓穴`（需`钥匙`或开锁，且墓里有`尸鬼`）。
* **代价**：无论哪条路，白漫的塔洛斯祭坛**永久失效**——世界从此少一个赐福点。这是"选择改变地图"的最小单位。

### C2《水权》｜9.4 家族 × 9.1 内战

* **钩子**：`战狂农场`与`灰鬃氏族`争一条灌渠，两家都递来一张地契，请"外人"作证。
* **物件**：两张地契 + 一封军团军需官的信（其中一家在给`帝国军团`供粮）。
* **三幕**：① 比对地契——其中一张是伪造的（可从笔迹与印章查出）；② 查供粮——军需信暴露谁在"用粮食换保护"；③ 械斗前夜——两家各聚了十几个人，卫兵装作没看见。
* **抉择**：当众揭穿伪契（两家都毁，你成公敌）｜私下换水（两家都欠你，但穷人先断水）｜把军需信交给`风暴斗篷`（内战升级，白漫守军被抽走）。
* **代价**：白漫城墙的守军因此变薄——下一次龙袭或攻城，镇子要为这场水权付账。

### C3《灵魂石的重量》｜R2 伦理 × 9.5 行会

* **钩子**：`紫杉镇`的少年让亡母"还能说话"——他把母亲封进一枚`护符`，用的是`黑色灵魂石`。石料来自`盗贼公会`的销赃渠道。
* **三幕**：① 神迹——镇民开始来朝拜这枚护符，少年的父亲收钱；② 追查——`斯坦德尔的警戒者`顺着黑石流向进镇；③ 变调——护符里的声音开始说些"不属于母亲"的话（附魔里的东西学会了说话）。
* **抉择**：毁石（少年崩溃，镇民失去支柱）｜替少年顶罪（被警戒者通缉，全镇记你的恩）｜请`冬堡学院`的`瑟吉尔斯·图利亚努斯`转移灵魂（要一件魔法器物作酬）。
* **代价**：触碰**底线三（人魂附魔）**。任何解法都会在"名声"上留一道洗不掉的痕——警戒者会一直记得你的名字。

### C4《钥匙的主人》｜9.5 法外 × 9.7 阶级

* **钩子**：`裂谷城`一栋空宅三年换了三任主人，`钥匙`还在老管家手里。有人出钱请你去"取回屋里的一本册子"。
* **三幕**：① 开锁——门有三道（大门、内门、夹墙暗格），每道都要不同手段；② 账本——里面是`东帝国贸易公司`的走私记录，连着`玛雯·黑棘`的名字；③ 三方竞价——帝国税吏、黑棘、`盗贼公会`的`戴尔文`同时开价。
* **抉择**：交帝国（黑棘报复，码头停工）｜交黑棘（帝国封港，全城涨价）｜卖给公会（钱最多，但你成了"可收买的人"）。
* **代价**：宅子原来那家人再也拿不回钥匙——你只是在换一个锁匠。

### C5《采气母的人》｜9.7 族群 × 9.3 历史债

* **钩子**：`鸦石镇`外，矿工与采集`气母`的灰烬之地部民争同一片浅滩；部民的孩子开始咳血。

**艾迪斯**：（把一袋钱丢在岩石上）帝国出价。外加一张军团通行令，你以后过任何关卡不用排队。

**风暴斗篷信使**：（笑）通行令。（也丢下一个布袋）我们出价少。但我们给的东西，帝国给不了——（指了指龙鳞）这个，会挂在风舵城的殿上。所有人都会知道是谁带回的。

**梭默代理人**：（一直没有动）我不出价。（终于开口）我提醒两位一件事：这块鳞上还带着"词"。（看着你）你们谁把它做成甲，谁就会在穿上它的第一天，被龙听见。

**艾迪斯**：（皱眉）什么意思。

**梭默代理人**：意思是，它不是战利品。（把手指按在鳞上，很快收回）它是地址。

（风把布袋吹得哗哗响。三个人都看着你。）

**分支**

* **卖给帝国**：军团多一副龙骨甲；风暴斗篷把这事编成歌，唱你是"卖国的人"。
* **卖给风暴斗篷**：风舵城多一件象征物，能招一个连；帝国在你的通行记录上标了一个记号。
* **当着三方烧掉**：谁也没得到，三方都记住你；龙鳞烧起来是蓝的，味道像铁。

**收尾**：隘口的风把灰吹向下坡。**一副甲只能穿在一个人身上——所以它真正决定的，是谁会被认出来。**

### 第一章《霜盐之前》｜紫杉镇

**一句话**：你只是替人送了一趟盐，结果送进了一场葬礼。

**场景**：深夜，少年家的门槛。屋里点一盏灯，父亲在数钱，一枚一枚，数得很慢。护符在少年手里发烫。

**对手戏**：少年 vs `伊士冉`——一个要留住母亲的声音，一个要烧掉"没说完的话"。

戏眼：`伊士冉`："她叫你吃饭的时候，用的是谁的声音？"少年答不上来，护符替他答了——用了一个不属于母亲的低音。

**代价结算**：无论你选哪条，**紫杉镇不再有"神迹"**。少年要么失去母亲第二次，要么失去镇子的信任。你则失去"随时可以走"的资格——镇上人开始记得你的脸。

**递交**：护符碎裂后，底座里嵌着一小片**黑色灵魂石碎片**，边缘有一道切口——不是矿石的裂，是刀刻的记号。

***

### 第二章《夹墙里的名字》｜裂谷城

**一句话**：账本不值钱，值钱的是"谁的名字不在上面"。

**场景**：雨夜，空宅二楼。三道锁都开了，夹墙里一本册子，纸上还带着潮气。

**对手戏**：`威克斯` vs `玛雯·黑棘`——一个要卖给出价最高的人，一个要买下"没人知道"这件事。

戏眼：`玛雯`："你开锁的声音很好听。可惜你听见了不该听的。"`威克斯`在你耳边补一句："她不是在威胁你。她是在报价。"

**代价结算**：账本只有一份，三方都要。你交出去的那一刻，**失去另外两方**——从此在裂谷城，你每走一条巷子都要先看后面。

**递交**：账本第三页有一行反复出现的货号：**"蜜酒三桶，白漫，收货人印达林"**。旁边用另一种笔迹写着"石料另计"。

***

### 第三章《地窖里的甜味》｜白漫城·蜜之酿酒庄

**一句话**：毒不写在酒里，写在"谁赔得起"上。

**场景**：午后，地窖。橡木桶排列成行，其中一桶的龙头下垫着一块布，布上有结晶。楼上有女人在哭。

**对手戏**：酒庄主人 vs `印达林`——一个想活，一个只想找个人顶罪。

戏眼：主人跪下说"我的女儿在楼上，她今天早上还在数酒桶"；`印达林`说"码头工每天都有人掉下去"。

**代价结算**：你指认谁，谁就消失——酒庄倒闭三十人失业，或黑棘撤手但毒继续流。**你第一次为一个陌生人的饭碗签字。**

**递交**：你从桶底刮下一枚**刻号酒桶箍**，号数与账本上的货号对得上——但它不是白漫的编号，是**鸦石镇矿场**的编号。

***

### 第四章《浅滩上的空囊》｜鸦石镇

**一句话**：矿主的账上，水也是货。

**场景**：清晨，灰烬浅滩。木杆上挂着空网，水是灰绿色。`蜜洛儿·艾恩斯`卷着裤脚站在水里，手里一个空囊。

**对手戏**：`蜜洛儿` vs 矿主（`东帝国贸易公司`）——一个要水干净，一个要账干净。

戏眼：矿主："这条河从我祖父那辈就流。你告诉我，是哪一天开始有毒的？"`蜜洛儿`答不出——她只有孩子的咳嗽声。

**代价结算**：公开水质则矿场停工、全镇断粮；私了则部民迁走、孩子继续咳。**这一章你必须选择"让谁先饿"。**

**递交**：矿主签字的**提货单**上，收货方不是任何商号，而是一栏空白，只盖了一枚印：**梭默的纹章**。

***

### 第五章《隘口三方》｜龙桥镇

**一句话**：他们要的不是龙鳞，是龙鳞上的"词"。

**场景**：正午，通往`寒石关`的隘口。风大，龙鳞摊在岩石上，边缘还带着没刮净的肉。

**对手戏**：`艾迪斯队长`（帝国） vs 风暴斗篷信使 vs 梭默代理人——三方出价，两方谈钱，一方谈"地址"。

戏眼：代理人把手指按在鳞上又很快收回："它不是战利品。它是地址。"`艾迪斯`："什么意思。"代理人不答——他不需要你懂，他只需要你怕。

**代价结算**：卖谁，谁记你；烧掉，三方都记你。**从这一章起，你在天际没有安全城。**

**递交**：龙鳞烧尽后，灰里剩下一小段没烧完的**卷边**，上面有墨迹——是一份**军需信**的副本，落款处写着两个家族的名字。

***

### 第六章《渠口》｜白漫城·农场渠

**一句话**：内战的粮，是从这笔账里出的。

**场景**：正午，`战狂农场`与`灰鬃氏族`之间的渠口。两家各站一侧，手里都有农具，也都有刀。总管`普罗万图斯·阿文奇`坐在石头上看戏。

**对手戏**：`阿尔伏希德·战狂` vs `索拉德·灰鬃` vs 总管——两个被挑动的人，和一个挑动他们的人。

戏眼：总管拍掉袍子上的土说"你们两家争的不是水，是有人想让你们争"；说完就走，把火留给别人收。

**代价结算**：水权一解决，白漫的守军就被抽走一半——**你换来的和平，是从城墙上拆下来的。**

**递交**：军需信被公开后，白漫城门开始"限流"：**没有通行铜牌的人，一律在北门外等三天**。你在北门领到了自己的第一块。

***

### 第七章《城门与铜牌》｜晨星

**一句话**：第一条先例，是你写的。

**场景**：清晨，霜。`虎人商人`的帐支在护城河外三步，药瓶摆在一块毛毡上，标价是城里的两倍——也是唯一有的。

**对手戏**：矿工的妻子 vs 城门卫兵 vs 虎人商人——三个人都在这条规矩里，谁都不是定规矩的人。

戏眼：妻子说"我男人给你们修过城墙"；卫兵顿了一下，很快说"修墙的名单上没有他"。

**代价结算**：你走私进城、或让伤者出城、或当众质问领主——三条路都会写下同一条先例：**"谁有资格被救"。**

**递交**：你在药瓶底下发现一张纸条（虎人商人的"赊账本"），上面有一行字：**"风舵，第七夜，有人敲门，别开。"**

***

### 第八章《借声的人》｜风舵城

**一句话**：他在说话，但说话的不是他。

**场景**：傍晚，落雪。一个死了七日的人坐在自家门槛上，姿势端正，像在等人递一碗汤。雪落在他肩上，不化。

**对手戏**：`伊士冉` vs 邻居老妇 vs "他"——一个要烧，一个要认，一个在求死。

戏眼：他抓住你的袖子，用回自己的声音说："别让我再说话了。我每说一句，它就多学一句。"

**代价结算**：烧掉则村民暴动、你被赶出城；交出去则他成为标本；带去`高吼峰`则十天路程、每夜一次"借声"。**你付的是一村人的信仰。**

**递交**：火化（或离开）之后，`伊士冉`给你一片**封石拓片**——"他"最后说出的那句话，是一段墓门上的刻文，来自佛克瑞斯。

***

### 第九章《第三道门》｜佛克瑞斯

**一句话**：你们家拜了三十年，拜的是一座门。

**场景**：夜里，古坟第三道门前。火把，风从门缝里出来，长子跪着，凿子迟迟不落。

**对手戏**：族长 vs 长子 vs `伊士冉`——一个要封，一个要开，一个说里面根本不是你们的祖先。

戏眼：族长很轻地问"那我们拜了三十年，拜的是谁"；`伊士冉`答"拜的是一座门。门后面有东西在等有人叫它"。

**代价结算**：炸塌墓道，族史与线索一起埋掉；让长子独入，他抱出一件不属于他家的东西；上报警戒者，门被封上但封条写的是别人的名字。**你带走拓片，等于带走一笔两百年的债。**

**递交**：拓片与祭坛石上的刻痕完全一致——**那份"约"的签约地，是白漫城外的那座`塔洛斯祭坛`。**

***

### 第十章《名单上的第七笔》｜白漫城·祭坛

**一句话**：账合上了，你的名字出现了。

**场景**：黄昏，风起。岩壁下的祭坛，供着旧靴子与断剑。`阿尔凯迪雅`把三份霜盐推过石头。坡下上来一个穿灰袍的人，手里一块石板。

**对手戏**：`阿尔凯迪雅` vs 梭默线人 vs 你——一个只要你走，一个只要你一句话，你只能选一个。

戏眼：线人把石板转向你："这上面有三个名字，和三个空位。你只要说一句'这里没有人'，我就走。"你低头看见第四个空位——**刻痕是新的。**

**代价结算（终局三选）**

* **交名单**：祭坛被拆，白漫的塔洛斯信仰转入地下；秩序恢复，你得到一块"可自由通行"的铜牌，和一辈子的安静。
* **烧名单**：名单上的人四散，祭坛保住；你成为名单上的第七笔，此后每座城都有人认得你，没人承认。
* **划掉名字**：用那片黑色灵魂石碎片，把第四个空位刮平。石板空了，你也空了一块——**你成了记账的人**，从此听得见别人的"没说完的话"。

**收尾**：风把盐吹散。石头是凉的。**这个世界的老神不会因为你的选择而发怒，他们只是不再回应——而账，永远有人接着记。**

### J3 三处交叉点（全网的焊点）

| **交叉点**          | **谁与谁在此相遇** | **一旦断开，会怎样**           |
| ---------------- | ----------- | ---------------------- |
| **矿场提货单**（第 4 章） | 钱 × 名       | 梭默失去矿场现金流，第五、六章的出价能力消失 |
| **军需信**（第 6 章）   | 内战 × 钱      | 两大家族没有把柄，白漫不会限流，第七章不成立 |
| **名单石板**（第 10 章） | 名 × 债       | 前面九章的死者"白死"，故事降级为跑腿    |

### J4 网的形状（一句话）

```
        钱 ──────────────┐
                          ├──── 你（第10章：第四个空位）
        名 ──────────────┤
                          │
        债 ──────────────┘
              （焊点：提货单 / 军需信 / 名单）
```

* 三条线在**物件**上平行，在**人物**上交叉，在**第十章**收成一个点。
* 这个点不是"反派的老巢"，是**一张纸**——名单石板。
* 所以这张网真正的网心是：**记账这件事本身**。

### J5 用它写新剧情的三个动作

1. **选一颗齿**：从 J1 里挑一个物件（如"酒桶箍"），它就是本章的核心证物。
2. **找守门人**：在 J2 里查这个物件的守门人，他的"最怕什么"就是你的杠杆。
3. **看断哪根线**：如果你想写"世界变坏"，就断开 J3 的一个焊点；想写"世界勉强好转"，就修好一个焊点。

> 三个动作做完，一章的骨架就有了——**不需要新设定，只需要重新排列已有的齿。**
