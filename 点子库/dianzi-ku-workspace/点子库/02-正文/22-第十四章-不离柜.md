# 第十四章 · 不离柜

**卷二《河中》E09 后段 · 卡 09-4 至 09-8**

---

### 一、三张手续

三方是踩着上午九点的整点一起来的——不是约好的，是**各自算准了别人会来**。

物理院带的是**备案告知书**。卫蒹亲自来的，她把告知书摊在证物室的登记台上，指节压着第二款："依据法则样本管理要求，凡具法则残留之物，**须于发现后七日内向常数所备案入库**。这东西在你柜子里过了八天——我来，不是索取，是**补程序**。"

（她措辞得滴水不漏。可她自己知道真正的理由在另一行：加密相册"还"里，贴片初现那晚的两份编号，与西郊旧账的时间戳，**格式是同一套**。）

教会带的是**一个字**。净衡立在门口，黑袍上十二处金线补丁在日光灯下一明一灭，他不开口要，也不开口焚——只把一本火漆通牒放在台面上，翻开的那页写着：**"异端法器，依例当焚。"** 四字而已，字字如钉。

社科塔带的最厚：**数据调阅申请单**，一式三联，骑缝章齐全，附《读数采样必要性说明》十七页。慈笙没来——她派了助理，临行嘱咐的话是："单子拿稳，**他们的规矩我比他们熟**。"

文敛听完三面，转身从柜上取过她的第三栏登记簿，翻开，推到台面中央。然后她说了那句后来被三方各自引用、各自解释、各自写进内部通报的话：

**"登记未完，物不离柜。"**

"备案告知书，"她指物理院，"**无案名**——你的是告知，不是调取。调取须案名、原因、时限、会同检视、双方签章。"

"火漆通牒，"她指教会，"**无调取单**——焚毁是处置，处置在登记完成之后。你们的经文管判，不管柜。"

"数据调阅单，"她指那份十七页，翻到最后一页，指尖点在一个空白格上，"**原因栏，空的。** 你们的章很齐——可章齐不等于把话说了。"

十七页的说明里没有一个字回答"为什么"。助理张口要辩，文敛已经把簿子合上了，合得不轻不重，像给一段话画句号：

"手续补齐，我一格一格会同你们检视。手续不齐——"她抬眼，"**秤不撒谎。缺的那栏，你们自己回去补。**"

满室静了三秒。净衡一直没坐，此刻闭目，两字：

**"……悖。"**

（他不是在说她。他是在说这间屋子——一间用**程序**挡住了焚令与备案的屋子。老箴站在最远的角落，第五十八条翻开着，全程没替任何人说话——可他站的位置，恰好是"程序"这两个字的**位置**。）

老箴在三方出门前，只对文敛点了一下头。

**程序这一次，站在登记这边。**（卡03 兑现——与 E05 的"程序站进"同源，但这一次没有人破例：**是制度自己挡住了焚令**。）

### 二、制度的狂欢

没有人想到，文敛那三条驳回，每一条都会变成复制的**新授权**。

午前十一点，物理院补齐了案名——"补正即调取"条被激活，系统向物证推送了一次"**调取预登记**"；预登记要求"重要证物同步备份至调取副本"。

**午后一点，柜 12 里沁出的那份，圆了。三份。一式三份。**

午后两点，教会放弃了调取、改申请"封存待焚"——封存申请又激活了"**封存件独立造册**"条：封存件须另册登记、另格存放。

**三点，册子有了，格子里多出一份。四份。**

午后三点四十，RFID 复核（文敛晨间亲手加的那道）第二次运行——读卡器逐格扫描，屏幕上那行绿色提示像一株见水就长的藤：

```
【编号 WZ-2026-1111-0712 · 在库 × 4
位置：柜 7 · 柜 12 · 封存格 B · 调取预登记副本位
状态：均正常。】
```

"均正常。"小吴念出声，声音已经不太稳："队长……它每次都是**照规矩多的**。"

文敛没有回答。她站在 RFID 屏前，看那行绿字，忽然把整件事看穿了——穿得她脊背发凉：

**这东西不是在钻制度的空子。它是在执行制度。**

制度说重要证物要拍照——它的影像出现在四个机位；制度说要双人核对——两份互为副本就是最忠实的核对；制度说一式三份、备份保存、封存另册、调取预登记……**她每加严一条，它就合规一次；她越尽职，它越完整。**

"它在找齐自己。"她低声说——用了个自己都莫名其妙的词。**完整度。** 像一个只带着半张图的人，听说这面墙上贴着另外半张，就顺着钉子，一格一格地爬过来。

傍晚五点，第六份在取材车下层被发现（依据是"易损物证须复制影像保存"条——它的影像被拍下来的第七分钟，影像变成了实体）。

黄昏六点，第七份。

**第三栏，第一次写不下了。**

文敛没有撕页，没有换本（卡07 禁令：❌撕毁登记）。她拿来尺，在第三栏右侧**现画了一道竖线，凭空开出第四栏**——

```
第四栏（临时启用）：同物多地之持续计数。
计数规则：每有新份现，记位置，记时间，记依据之条。
```

第一行她写下：`第七份 · 柜 19 · 依据：影像保存条。` 写完，她在栏末补了一句全簿唯一一句带温度的字：

**"我在给它的合规记功。"**

### 三、读（卡 09-6）

算守是傍晚带柯无衍进来的。放行条件是文敛亲口给的："**观察不取证。不碰柜，不动封，只许看。** 看完，把他看见的写进你们渡口的簿子——将来某天，两边的簿子要对得上。"

（卡07 逻辑自洽的极致：她不让权能者碰证物，却主动要求**交叉登记**——秤不撒谎的下一层：**两本秤互校，比一把秤更不撒谎。**）

柯无衍在柜 7 前站定。

徒读——双读规程第一款：**凡器读尺内，人手读尺外。** RFID 是器，登记簿是器，封条是器；而这张贴片的"残响"，恰好是尺外的东西。他把手套摘了，指尖隔着封袋的薄膜按上去。

画面来了——与阿钉在铁棚里看见的**同一帧**，分毫不差：

灯色发青的教室。一块黑板。黑板上一行没写完的字：**"这句话没有被……"** 以及一个背影——肩很平，粉笔在指间，整个人的姿态是**正在写、还没写完**的姿势。

同一帧。铁棚里看见过，证物室里复现——**同源残响，衍生物所见皆同**。这不是巧合，这是**同一份底片**在两处显影：它从教室里拓出来，拓在阿钉的体验券上，拓在稽查队的三百只手环上，如今拓在自己每一个合规的副本里——

**它不是在复制自己。它是在把自己拼回去。**

那一瞬，改法的冲动贴着他的脊椎爬了上来——**参数。复制条件。** 他只需伸手，把"依据之条"与"副本生成"之间的那个因果参数轻轻改掉一格，七份就会塌回一份，满室的绿字就会闭嘴——这是改法的第一次实战诱惑，比 E08 裁决室那次更具体、更近、**更容易**——

他把手背到了身后。

（卡01 OOC 核验：❌未喊；❌未改。按住了。）

"它在找齐自己。"他对算守说——与一个小时前文敛说的**一字不差**，隔着两间屋子、两本簿子、两种完全不同的信仰。

算守的掌心贴着封柜，读了三秒，收回手，说了今晚唯一的判断：

"找齐之后呢？"

"不知道。"柯无衍看着那个黑板前的背影，"**拼图拼齐的那一刻，拼图是活的还是画的——没人知道。**"

### 四、线外（卡 09-7）

稽查队围墙外，阿钉在马路对面蹲到了天黑。

他不是来认领的——认领就要登记，登记就要露脸，露脸就要回答"你为什么会有这东西"（卡08 弱点：**怕登记**压过了舍不得，这是他这一生第一次把舍不得排到第二位）。

他只是想看一眼**它过得好不好**。

荒唐。他自己都觉得荒唐。可当那辆载着证物箱的推车从侧门过——他看见了：推车经过的瞬间，侧门玻璃上**呵着一行雾气字**，字迹瘦而直，与当初在他柜台玻璃上写警告的是同一只手：

```
【回收进度：+3
勿念。各得其所。】
```

雾气散得很快。阿钉站在原地，看那行字像看一封拆开又自动折好的信——**"勿念"**。它叫他勿念。一件它自己贴上来的"寄存物"，办完事了，反过来叫他勿念。

马路对面，稽查队大门的阴影里，站着一个人。

不高，不矮，纸页摩擦似的呼吸声——**寄存人**。他就那么站着，看过了三方争物、看过了七份计数、看过了推车与雾气字，一动没动，像在清点自家失而复得的仓库。

阿钉的直觉在这一刻精确得可怕：**那个人不是来看证物的。他是来看"制度怎么把它养大"的。**

夜风卷过巷口。寄存人终于动了——他朝钉记杂货的方向（朝阿钉的方向）欠了欠身，动作轻得像翻过一页纸，然后转身，没入人潮。

他怀里抱着**第八份**。（依据是哪一条？——没有人会去登记了。**没被登记的合规，是这个世界留给他自己的唯一一格。**）

### 五、台账（卡 09-8）

当夜 23:00，四本簿子同时落笔，各记一角：

- **文敛（第四栏）**：`第八份：未在库。去向不明。依据：无。`——她写下"依据：无"三个字时，笔尖顿了顿：**这是她全簿第一行"无依据"的记录，也是第一次，"无"比"有"更让她害怕。**
- **算守（渡口簿）**：`残响贴片：读取结论——它在找齐自己。同源残响所见同帧（钉记/证物室互证）。`
- **卫蒹（加密相册"还"）**：贴片四机位影像与西郊旧账时间戳的**格式同源性**截图，存档。
- **阿钉**：没有簿子。他在铁棚的柜台上，用指甲在木头上刻了一个很轻的"**7**"——他数过的份数，也是他守过的天数。

**世界状态台账**：

| 参数 | 变动 |
|---|---|
| 新实体 | **同源复制律**：制度完备度 ∝ 复制份数——**它不是在犯罪，它在合规** |
| 新异常区 | 证物室 = 首个"制度性异常区"（凡人体制内部自生的法则裂缝） |
| S14 | 回收进度 +3；**寄存人首度正面现身**（线外，未登记） |
| 悬案⑨ | 推进半格：教室帧互证=黑板教室真实存在；"背影是谁"仍不可判定 |
