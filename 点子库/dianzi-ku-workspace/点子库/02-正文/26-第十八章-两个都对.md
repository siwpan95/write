# 第十八章 · 两个都对

**卷二《河中》E11 后段 · 卡 11-4 至 11-7**

---

### 一、腕（卡 11-4）

第四遍的时候，两套输出**同时抵达了那只腕**。

徒读的画面里：裁页者侧身，袖口深色，腕上**有一道疤**——旧的，斜的，与主角自己腕上那道隔着玻璃门的月光一模一样的位置——他甚至来不及细想这像意味着什么；

而同一瞬，静电压痕器吐出的图像上：长弧、顿角、回锋的尽头，腕部的静电潜影**光滑完整**——显影粉在那个位置堆不出任何凹槽：

**腕上无疤。**

"停一下。"简伯把两侧图像并排摆在无影台上，戴上老花镜，又摘下来，再戴上，"……机器的图像在这儿，你的说法在这儿。"

"我看见的有疤。"

"我抄出来的没有。"老人的声音平得反常，"静电不骗人——压痕处与平整处的电荷分布差异骗不了粉。**可你徒读的那双手，也从没骗过人。**"

两份记录。同一页压痕。同一次读取。**互斥，且各自完整。**

简伯沉默了足足一分钟，然后做了个柯无衍没想到的动作——他取过登记簿，**两栏并记**：

```
裁页夜压痕读取 · 第四遍
左栏（机读·静电压痕）：腕部无疤。图像编号 R-0801。
右栏（人读·徒读贴片）：腕部有疤，斜向，旧痕。笔录人：柯无衍。
事实：同帧两版并存。无法判定何者为原。
依据：双读规程第一条——人读尺外，机读尺内。
```

他写完，在最底下添了一句不是格式的话：

**"八年来我第一次抄出东西——抄出来的第一个字，是'不确定'。"**

（卡 11-4 兑现：**悬置从哲学升级为制度**——多版本原则第一次有了两份带编号的物证级记录。台账按规矩双收、不裁决。）

### 二、回旋镖（卡 11-5）

第五遍输出的时候，出事了。

机器吐纸的节奏一直很稳——一张，一张，一张——第五张却**多打了三行**。简伯抽出来时以为是故障，眯眼念出声，念到一半手就停了：

```
读取日期：今日。
读取者手部压痕：左，无名指第二关节微凸；铅笔茧位于右手中指。
备注：与样本建档一致。
```

**今日的日期。主角的手。**

压痕里躺着的不再是八年前的裁页夜——是**今天**：他写"真，而不可证"三行样本时按在信笺上的力道、他贴着床沿读取时无名指压出的浅窝，全部被机器连同裁页夜的凹槽**一起显影在了同一页上**。

*你读过的每一寸压痕里，都躺着一个读它的你。*——贴片刻字不是警告，是**说明书**。

简伯的脸色在那一刻变了——不是怕，是一种更深的东西。他快步走到档案柜最深处，抽出一册发黄的旧读痕簿，翻到某一页：1998 年，他师父的名字，一次常规校验的记录——页脚有一行当年被他当成笔误的、极淡的批注：

**"读时似有人立于床侧。未见。"**

他师父也留痕了？还是他师父**看见了别的读者的痕**？老人的手停在那行字上，最终没有往下翻——（卡 11-5 兑现 + 留白：**简伯的师父是否也在某页里，不答**。）

### 三、停（卡 11-6）

"明天不读了。"

当晚收工，简伯把静电发生器断了电，说得很平静。

柯无衍预料到他会停——真正的问题是停在哪：是停在腕上，还是**继续往里读**？缺页压痕的更深处是标尺的核心：门楣的字、第0版的悬案、立约的原件方向……岸派做梦都想读的东西就在那张床底下压着。

"再读下去，读的是标尺的命。"简伯把手套收进抽屉，落了锁，"**机器成功了就够了。** 一张床空了八年，我今天要的不是把它填满——是知道它**还能出东西**。"

（卡 11-6 兑现：**岸派教条的正面形态**——破例已经用在"邀约"上，用完了。卡 06 的缺陷与信念在此处达成平衡：他好奇得要死，但他守的不是好奇心，是"床不能死"。）

主角没有争。他收拾贴片时，那张第五遍的多余输出纸飘到灯下——他顺手一瞥，看见纸的空白处，浮着一行不是打印、不是手写、**像是纸自己哈出来的**小字：

**"两个都对。读的人在看读的人。"**

字迹瘦而直。（留言者三选一：寄存人？器灵？还是——纸页里那位"上一个读者"？**不判定。**台账本集的规矩就是不判定。）

他把这页纸单独折好，收进贴身的口袋——没有交给简伯的登记簿。这是他第一次对渡口之外的人**留下一页不登记的纸**。

（他不知道这个动作将来会救他一次，也不知道它将来会要他一次。）

### 四、课表一角（卡 11-7）

收工前的最后一步是归档。简伯把五遍图像按编号排进底片袋，排到第四袋时忽然"嗯"了一声：

裁页夜图像的**右下角**，静电潜影里多出一小片网格——横七竖八，格子里有极淡的、被压过的字迹残影。他用侧光把那一角折出放大：

**是一张课表的边角。**

班级栏被裁掉了，只剩"周三·第三节"与一个模糊的板书计划格——**裁页的现场，墙上贴着课表。**

与 E09 铁棚里阿钉看见的那帧教室、与主角徒读到的黑板"这句话没有被……"，在压痕的最底层**闭环**了：裁页夜与教室，从来就是**同一个房间的不同两张纸**。

简伯把课表一角的图像拍进档案，写下本集最后一行登记：

```
新线索：裁页现场=教学场所。与残响印教室帧（WZ-0712 链）互证。
悬案⑨：推进一格。背影身份：仍不可判定。
```
