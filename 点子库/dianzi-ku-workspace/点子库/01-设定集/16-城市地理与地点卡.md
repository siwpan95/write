# 补遗 · 城市地理与地点卡

> **查漏点**：原设定集的事件有零星落点（破产法庭地下室、废弃心理医院），但没有一张城市地图——渡口"选址规律"给了原则没给清单，冲突区/落点/相变街区的空间关系从未落位。本章给出城市整体布局 + 八渡口清单 + 12 张可直接用于跑团与编剧的地点卡。

---

## 检索依据

- 都市异能创作指南：**建立都市异能地图**（地点是设定的容器——每个关键地点至少绑定一条法则读数与一个未决悬案）。
- TTRPG 随机表传统：地点卡采用"表层用途 / 里层真相 / 法则读数 / 可触发场景"的最小字段（对齐 12 章场景三问）。

---

## 一、城市总览：衡城

> 城名取"衡量"之衡——这座城的宿命就是**被标尺量与量标尺**。

```
        北 · 新城中心（三方总部三角区）
   ┌─────────────────────────────────────┐
   │  物理院主院          社科塔临界监测局  │
   │       ＼            ／              │
   │        ＼  旧城中轴 ／               │
   │  法院档案区 ── 破产法庭(渡口) ── 教区 │
   │        ／            Ｒ              │
   │       ／   城南(τ*沉降三街区)  ＼     │
   │  期货交易所渡口      市立医院渡口      │
   │                          ↓           │
   │  西郊·法则冲突区(E04)    东南·落点    │
   │  （守恒反噬疤）     （废弃心理医院,E07）│
   └─────────────────────────────────────┘
        东北 · 城东读数禁区（5年前τ*暴走区）
```

**空间三定律**（编剧室用）：

1. **渡口必在"现实规则正在变形"处**——全城八渡口分布即变形点分布；
2. **冲突区与落点永远在扩张方向上对角**（一个物理撕口、一个元边界薄膜——E04/E07 的伏线在地图上早已对称）；
3. **城南是 τ* 的病灶，城东是 τ* 的坟场**——社会侧事件只在这两个方向出。

## 三、地点卡（12 张，跑团/编剧两用）

**卡面格式**：表层 / 里层 / 法则读数 / 可触发场景（对应场景三问的"局面"）

**1. 破产法庭地下室**
- 表层：卷宗库，无窗，恒湿
- 里层：八渡口之一；卷宗库的档案柜摆成**不可判定域的形状**（无意识的，还是刻意的？）
- 读数：信息层稳定，法律层"裂缝密度"全城第二
- 场景：第十三条卷宗（E01 教学场）；标尺室的旧校验仪藏于此

**2. 第 73 号卷宗**
- 表层：一份重组协议
- 里层：自指悬空实体；裂缝的"首次回望"现场
- 读数：法律层 0 → 突变为不可测
- 场景：主角觉醒；"上报基础成功率 0"的教学检定

**3. 标尺室（档案库核心区）**
- 表层：摆渡人档案库的校验间
- 里层：标尺 v17 悬挂墙上；**哥德尔条目位置有一块颜色更浅的矩形**（缺页 8 年）
- 读数：数学层高密度——在这里一切"封闭体系"都会轻微发抖
- 场景：E03 补页（规则内必败）；Ω刻度之争的物理现场

**4. 城南三街区**
- 表层：老居民区，烟火气浓
- 里层：τ* 读数 0.681 且持续下沉（E02）
- 读数：社会层"温度"全城最高
- 场景：临界感知检定 DC20；大失败=被裹挟进人群；小破窗批量制造现场

**5. 西郊法则冲突区**
- 表层：已封控的工业园区，围挡写"燃气管道检修"
- 里层：两套能量账本在同一空间互殴（E04 守恒反噬疤）
- 读数：物理层读数互相矛盾——同一处测出两个值
- 场景：回收行动（物理检定 −5）；对抗检定；串账涌现（背上能量债）

**6. 废弃心理医院（落点）**
- 表层：已拆除大半的旧院，仅剩门诊楼
- 里层：**膜最薄处**；第零纪悖论战争的疤（14 章）
- 读数：心理层法则**对自身无效**——所有感知检定对自我 −10
- 场景：E07 落点勘探；"自己最后一次对自己无效"的档案记录

**7. 社科塔临界监测局**
- 表层：统计局办公楼
- 里层：全城 τ* 读数网络的中枢；**E02 警报的第一接收人选择了沉默**
- 读数：社会层被仪器化的最高形态
- 场景：读数调阅（需授权或入侵）；激进派泄密预案的讨论地

**8. 物理院反噬管理处**
- 表层：能源审计部门
- 里层：守恒账本的追偿台；账本上有一笔**"不许查"的账**（E04 悬案）
- 读数：能量守恒法则的"账房"——此处挪用能量必被即刻记账
- 场景：账本调阅对抗检定；卫蒹求援戏

**9. 教区·律正司**
- 表层：教堂附属法律援助中心
- 里层：立约原件存放处（第 13 条载体）；授阶账簿
- 读数：法律层被"合法化"加持，法律法则者在此 +5
- 场景：老箴的主场；授阶锁死条款的谈判

**10. 期货交易所渡口包厢**
- 表层：VIP 结算室
- 里层：仲裁席巡回庭；机会成本合约的签署台
- 读数：经济层流动全城最快
- 场景：仲裁戏；双标尺并行后的"两套报价"乱象（E06 余波）

**11. 城东读数禁区（废弃地铁换乘站）**
- 表层：封死的隧道
- 里层：5 年前 τ* 暴走遗址；群体行为自持 72 小时的"化石"——**墙上还留着当时人群画满的符号**
- 读数：社会层低于 τ* 的死区，读数器在此只会归零
- 场景：禁区探险；第八渡口失守真相；舟派"半渡"传闻的起点

**12. 老城钟楼**
- 表层：文物修缮处，摆着停摆的老钟
- 里层：彼岸级守渡人的静修地；**钟停的那年=柯无言上岸那年**（暗线卡）
- 读数：惯性法则——此地一切变化都比外面慢半拍
- 场景：向彼岸级请教"上岸"的代价；获知立约第 13 条线索

## 四、地图使用规则

1. **编剧室**：每集设定变动卡必须落到本图某点；地图上没点可落的卡=空转卡，重破。
2. **跑团**：跨区移动即触发 17 章 d100 异常遭遇表（每跨一区掷一次）。
3. **世界状态**：六参数（12 章）中"冲突区数量、τ* 读数、膜厚度"三项在图上有固定读点——**地图就是台账的封面**。
