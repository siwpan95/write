## 三个值得先看的新增设计

1. **觉醒率谱层定律**（13 章）：觉醒率随谱层左移指数下降——社会 1/100、数学 1/10⁶。一次回答三件事：为何权能者没淹没凡人、为何学者先觉醒、为何右移档数补偿（总表）是公平的。
2. **守秘均衡**（15 章）：守秘不是传统是纳什均衡——泄密第一受益者是社会侧权能者，第一受害者是 τ* 本身。"要不要揭盖子"由此成为真两难。
3. **第零纪悖论战争**（14 章）：前代文明不是被毁灭而是被**悬置**（仍存在，存在与否不可判定）——落点是它的疤，E08 同桌裁决是它三条残规的执行。
