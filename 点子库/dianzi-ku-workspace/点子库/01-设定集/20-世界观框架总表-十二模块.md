## 模块 1 · 核心前提与基调（元层）

| 项 | 定义 |
|---|---|
| **一句话前提** | 从物理规则到社会法则，每一条法则都能带来独一无二的超能力——掌握程度决定强弱，边界决定上限，边界之外是让出边界的创造主 |
| **这个世界最独特的一条规则** | **真与可证分离**：任何足够强的体系都有真而不可证的命题；权能者能改写规则，改写不了"规则必须自洽" |
| 类型 | 高概念都市奇幻 / 硬设定（换主角换剧情依然成立的设定驱动型） |
| 主题 | 真与可证、知情的代价、量与不可量 |
| 情绪基调 | 冷峻底色 + 绮丽肌理（青灰白上点烈色）；宿命感（预叙谶语） |
| 尺度 | **单城（衡城）为舞台，法则为星球级**；城外世界=故意留白（模块 11） |
| 真实度/荒诞度 | 99% 现实质感 + 1% 裂缝（法庭程序、破产法条、CR 算法全部可查证） |
| **故事为什么必须发生在这里** | 衡城=八渡口之城、规则变形最密之城；破产法庭=专门受理"规则失效"的渡口——自指条款只会在**处理失效规则的地方**被发现 |

## 模块 2 · 宇宙与物理规则（自然层）

- **保留的现实规律**：全部已知物理（牛顿/热力学/相对论/量子）——检索见前七章 03/07；现实常数即边界

## 模块 8 · 社会组织与日常生活（社会层）★本轮重点补全

**关键问题：普通人一天怎么过？不同阶层差异在哪？**

### 凡人的一天（烟火白描技法条目——名词驱动、删标签、留可拍照的细节）

- **晨**：菜场冰块融化的水渍混着腥气漫过脚边；铝饭盒里隔夜菜的油味；校验日前后"这礼拜单位体检排队特别长"（权能者暗中校准，凡人只见排队）
- **午**：法院食堂的冬瓜汤寡得能照见人影；老陈的红蓝铅笔削到第三截；新闻里"某废弃厂区燃气管道爆燃"，看一眼，骂一句，转给家族群
- **暮**：瓦檐里的路灯先亮后暗一秒（读数波动的肉眼可见形式）；周婶挪观音像；戏腔从卷宗库飘出来
- **夜**：冰箱嗡嗡像偷懒的小马达；楼上有床板吱呀半声；陈永年在剪报本上写"编号七"
- **阶层差异**：凡人上层（庭长、稽查队家属）隐约"知道有事"但用程序消化；凡人下层（城南）直接用口诀消化（"窗破三夜，人走一巷"）——**上层信程序，下层信口诀，中层信标签**，三层各有一套自洽的消化系统

### 权能者的一天

- 登记者：手环晨检→按阶位出勤（窥=观察岗、引=处置岗）→ 校准日排长队
- 漏登者：阿钉的折叠床、冰柜后的纸缝、体验券流水
- 高阶：算守的巡渡（读数夜巡）、老箴的法援中心坐班、卫蒹的外勤

### 器物与质感清单（器物拟人工法）

卷宗库的樟脑味、标尺室的檀香与无灯穹顶、火漆三种温度（象牙白/鸦青/素白）、卡其风衣领口、计量环的素光、粉色童鞋的卡通猫、绿萝、烤红薯、《锁麟囊》戏腔、"搪瓷缸沿的磕痕"级别的法庭旧物

### 设定渗透原则（渐进式渗透法）

制度不讲解——**依附具体事件披露**：登记制度通过"手环晨检"呈现，标尺经济通过"授权费对账"呈现，守秘均衡通过"燃气爆炸标签"呈现。**设定如盐溶于水。**
