## 工作区三条规程

1. **以正文为准**：正文写过的 > 设定集写过的；冲突时改设定集并在补遗章"六栏结算"登记（19/21/22 章格式）
2. **六栏结算制**：每卷正文完稿后按【人物→支线→台账→实体→风格→方法】回填一章补遗（编号接续：23、24……）
3. **白名单铁律**：一切依现实，仅七项微调（22 章）；新实体入典先过"现实原型是什么"一问
