# 完整设定集 · 总纲

> **一句话**：宇宙由法则构成，掌握法则者获得权能；权能的上限由边界决定，边界之外是创造主——而创造主为了被认识，自愿让出了边界。
>
> 本册是全体系（01–18 章 + 法则总表）的一册贯通版：六条主线、两张总表、一张导航。新读者从此册入门，老读者以此册对表。

---

## 第一章 · 底层架构

### 1.1 两条公理

1. **法则即接口**：法则不是知识，是世界的接口；掌握一条法则即获得该法则的权能（01 章）
2. **独一无二原则**：一条法则只产生一种权能原型，表现形态由掌握者的认知透镜决定

### 1.2 法则连续谱

```
数学/逻辑 → 物理 → 化学 → 生物 → 心理 → 经济 → 法律 → 政治 → 文化 → 道德
```

- 越靠左：越客观，耗能量与精度，**觉醒率越低**（数学层 ~1/10⁶），全域生效
- 越靠右：越主观，耗共识与网络，**觉醒率越高**（社会层 ~1/100），离群即归零
- 中间五层（数学/信息/生命/心理/经济）有完整图鉴（08 章），构成物理与社会之间的过渡带

### 1.3 五阶掌握模型

| 阶位 | 核心机制 | 进阶门槛 |
|---|---|---|
| 窥法 | 感知法则流向 | —— |
| 引法 | 小范围引动 | 知识门槛（可练） |
| 织法 | 构建自维持结构 | 结构门槛（需样本场） |
| 改法 | 改写法则参数 | 相变门槛（需世界触发） |
| 合法 | 成为法则化身 | 抉择门槛（不可逆） |

**一人一法则**：终身一条锚点法则；第二条仅限六对同构共鸣，否则即半身人（09 章）。

### 1.4 物理侧 vs 社会侧

| 维度 | 物理侧 | 社会侧 |
|---|---|---|
| 权能源 | 自然律 | 集体共识 |
| 控制基础价 | 20 点/级 | 40 点/级 × 网络密度系数 |
| 失效条件 | 奇点/法则冲突区 | 孤立环境/反共识 |
| 代价 | 能量、身体 → 法则化 | 信誉、意志 → 共识化 |
| 精度/尺度 | 精确目标、线性叠加 | 统计分布、相变放大 |

## 第二章 · 现实基础（03 章精华）

- **社会算子**（2026）：融合(+)、差异(−)、自创生(↺)、纠缠(⊗)——社会过程与物理力/数学运算的基本同构，可测量、可证伪
- **社会气体模型**：立场即粒子，宏观量服从状态方程——改一个量必波及其他量，社会改写永远有附带效应
- **τ* = 0.68**（Dror & Duru，124 系统六洲实证，PRL 审稿中；1,225 组织/217 国复现）：高于阈值自组织且韧性，低于阈值级联失败且**与财务健全无关**；同一常数独立出现于宪法绝对多数、网络渗流、演化稳定性
- **一阶相变双稳态**（Batista-Bouchaud-Challet 2014）：信任崩塌不可回滚——τ* 之下推不回去
- **兰道尔极限**：擦除 1 比特 ≥ kTln2——社会改写耗 FP 不耗 HP，随社会温度递增
- **尺度悖论**：个体层面越强，集体层面越被统计淹没——社会侧买的不是精确性是规模

## 第三章 · 边界理论（04 章精华）

**边界三形态**：物理侧（光速/普朗克/热二/兰道尔）、社会侧（τ*/渗透阈值/幂律指数）、元边界（边界必须存在）。

- **边界如何划分现实与超凡**：现实 = 系统远离临界点，个体影响被平均淹没；超凡 = 在边界处施加影响、利用临界放大
- **代价**：跨越边界者也被边界同化——合法阶段的本质
- **膜的意象**：权能者是膜上的振动——能感知张力、制造涟漪、拉伸形状，**永远无法撕破膜本身**；撕破膜，权能随之消失
- **反转**：边界不是超凡的障碍，是超凡的来源（临界点响应性最大）

## 第四章 · 边界之外（05 章精华）

- **定义**：不需要法则、不受边界约束、可自我限制以进入体系的存在
- **三原型**：卡巴拉 Ein Sof/Tzimtzum（收缩让出空间）、诺斯替迪缪尔哥斯（高级合法者的镜像）、洪荒圣人"削己入凡"
- **GURPS 实现**：Omnilock [150]（只受作者权威影响）+ Aseity [100]（不可购买——创造主是叙事公理非角色）+ 化身逆构筑（1d6 小时新化身）
- **层级**：创造主（边界外）→ 合法者（边界本身）→ 织/改（边界之上）→ 窥/引（边界之内）
- **铁律**：作者不能击败笔下人物，只能选择不再写他
- **第零纪**：悖论战争前代文明被悬置（仍存在但不可判定）——落点是疤；三条残规约束至今，E08 同桌裁决即其执行

## 第五章 · GURPS 点数化（02 章精华）

- 一条法则 = 一个 Power（来源 + 焦点）；法则天赋 5 点/级；力量来源修饰符 −50%
- 五阶 = 阶梯式优势组：察觉（5/级）→ Control（常见 20/级、抽象 40/级）→ +区域（+50%/级）+持续 → +**Cosmic +50%**（PU4 核实；神级 +150%）→ 替代形态 + 支配
- **法则冲突**：对抗检定；跨级 +2~+5；主场加值；社会侧按网络密度 ±3~±5；反制 = 中立化/静态
- **代价闭环**：高阶劣势（依赖、不可逆承诺 −15、道德修正 −10%~−20%）返还点数抵消高阶成本——**点数平衡与叙事平衡是同一张表**

## 第六章 · 量级标尺（07 章精华）

- **CR 0–30**（含 1/8、1/4、1/2）：CR X = 四名 X 级角色的中等难度；防御 CR（HP+AC）与进攻 CR（DPR+命中）取平均（DMG 273–281 核实）
- **神力等级 0–21+**：准神 → 半神(1–5) → 弱等(6–10) → 中等(11–15) → 强大(16–20) → **神上神(21+，艾欧 Ao)**——不授予法术、不回应祈祷
- **FP 单位体系**：1 FP = 1 标准成年人 ≈ CR 1/16；1 宅男 = 0.5 鹅 = 0.5 FP；KFP/MFP/GFP/TFP = 10³/10⁶/10⁹/10¹² FP
- **Ω 不可换算**：合法者天花板 10⁶ TFP；Ω 属于边界级——**问"多少 FP 等于一个艾欧"是范畴错误**（作者与人物谁强？问题在人物的世界里无法被提出）
- 标尺的裂缝：正统派视 Ω 为极限值（如光速），异端派视 Ω 为**零刻度线**（标尺得以绘制的前提）——你无法用尺子测量"这把尺子为什么存在"

### 7.3 主角与主题

**柯无衍**，哥德尔不完备法则，破产法庭编外档案员——觉醒于一份"效力取决于自身是否被签署"的第十三条（11 章）。他的职业困境即能力本质：**指得出裂缝，证不实裂缝**。

- 配角：物理院卫蒹、社科塔慈笙、教会老箴、守渡算守、上岸人之兄柯无言
- **主题**：真与可证是两回事——不可证明不等于不存在；世界侧表述为季命题：**一个无法被完整度量的世界，还算不算自洽？**
- 终卷收束：真与可证分离的世界里，**选择本身就是证明**
