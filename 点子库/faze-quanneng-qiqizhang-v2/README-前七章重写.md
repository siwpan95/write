## 一、为什么要重写

原 01–07 章是设定早期的对话直出稿，存在三类问题：

1. **口语化与重复**：章节间大量相互重复的论述（边界、膜的意象反复出现四五次），无导航
2. **事实松散**：GURPS 定价、D&D CR 算法、τ*=0.68 的文献出处均为转述，未核对原始规则书与论文
3. **与后期脱节**：01–07 成稿于 08–18 章（图鉴、互动学、摆渡人、主角、剧情引擎、补遗）之前，**互不引用**——总纲没有导航、五阶没有觉醒机制、叙事没有台账
