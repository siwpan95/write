## 二、联网检索补入的三类信息

### 1. 破产法庭实务（第一章场景真实度）
- **债权表**由管理人编制（《企业破产法》第 57 条），提交**第一次债权人会议核查**（第 58 条）；有异议的十日内评议、裁定书经审判长审核报庭长签发
- 第一次债权人会议标准程序：**书记员宣布纪律 → 审判长通报到会情况 → 管理人作执行职务报告 → 核查债权 → 表决**（云浮/中山/厦门法院审理规程）
- **表决票编号须与债权表编号一致**；决议须有表决权债权人**过半数通过且债权额占无担保总额 1/2 以上**（第 64 条）——正文第一节会议全部按此程序书写
- 场景锚定：正文中的"职工债权清单单独成册""红蓝票分色计票""重整计划草案表决"均来自实务流程

### 2. 自指悖论素材（裂缝的语言）
- **理发师悖论/罗素悖论**（集合能否包含自身）、**说谎者悖论**（"这句话是错的"）、**哥德尔句**（"这句话是不能证明的"）、**贝里悖论**（"第一个不能用少于十个词命名的数"）、**黑格尔**（"人从历史学到的唯一教训是人从历史学不到教训"）
- 关键转译：正文第一章让主角的内心独白以这串悖论为"圣餐"，第二章以哥德尔句的"抬起脸"写觉醒，序章以"尺子量不出尺子"预演缺页

### 3. 华丽文风语料（辞藻技法库）
- **张爱玲式色彩词**：蟹壳青、虾子红、鸡油黄、宝蓝、苍绿、月白——正文化用为"碧玉牌""旧玉""陈年琥珀""鸦青硬卡"
- **张爱玲式博喻/以实写虚**："生命是一袭华美的袍，爬满了虱子"的结构 → "不是大理石，是蛛丝；不是梁柱，是回音"
- **白先勇式工笔**：对信笺、火漆、肩章、手提箱的逐件细描
- **鲁迅式冷艳**：寒冽底子上的烈色 → "血红的章""香樟叶如刚上过桐油的碧玉牌"
- **钱钟书式奇喻**：正文多处（"像一个在暴雨里坚持缝伞的人""像印着国徽的白条"）

## 三、文风设计备忘（供续写保持一致）

1. **每段至少一层博喻**（三连喻起步），喻体优先取"法律文书+旧戏曲+植物+光学"四个料堆
2. **色彩词成簇出现**，冷底色（青/灰/白）上点一记烈色（红章、香火、磷光）
3. **四字格连缀**制造韵律，关键句用短句断奏（"真，而不可证。"）
4. **设定必须肉身化**：不解释规则，让规则长在场景里（表决程序=死亡名单式的编号对应；觉醒=图钉按进软木板）
