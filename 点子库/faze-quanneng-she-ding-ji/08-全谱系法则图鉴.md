| 谱层 | 权能源 | 代价 | 失效域 | 边界常数 |
|---|---|---|---|---|
| 数学/逻辑 | 形式系统的结构性真理 | 认知滑脱、不可自证 | ——（全域生效，故极难掌握） | 不完备性 |

| 信息 | 信息的数学本质 | 记忆噪声侵蚀 | 绝对封闭域 | 兰道尔极限 |
| 生命 | 遗传与选择的算法 | 个体性消解 | 无生命环境 | 稳态即死亡 |

## 第二章 · 中间层法则图鉴（完整五阶条目）

### 2.1 数学/逻辑层

**① 哥德尔不完备法则**

- 窥：发现任何规则体系中"真而不可证"的裂缝——天然的漏洞探测器
- 引：构造自指悖论，困住对手的规则（"本攻击不可防御"）
- 织：划定**不可判定域**——区域内的命题真假永久悬置，法律、契约、物理在此均无法闭合
- 改：让"真但不可证"的命题强制生效——绕过一切程序的实体化
- 合：成为系统外真理；**代价：合法者永远无法证明自己的合法性**，其存在对任何验证手段呈现为不可判定
- 克制关系：**克制一切封闭法域**——防御越自洽，越必有你无法证的裂缝

**② 康托尔对角线法则（无穷层级）**

- 窥：察觉"名单之外还有更高一层"
- 引：对角线逃逸——突破任何名单、封锁、通缉、枚举
- 织：构造不可数领域，让对手的清单永远列不完
- 合：成为不可数本身。代价：**永远有更高一层，无法登顶**——你能逃脱任何列表，但你也在别人的列表里

**③ 停机问题法则（不可判定）**

- 窥：预感"这不会有结果"
- 引：让一个过程永不终止（无限循环牢笼——最温柔的囚禁）
- 改：让判定本身失效
- 合：成为不可判定——**一切关于你的预测永不收敛**，预言术与因果律在你身上空转

### 2.2 信息层

**④ 香农信息熵法则**

- 窥：量化不确定性（测谎的本质是测信息量）
- 引：注入噪声，污染信道——导弹制导、命令传递、谣言辨别同时失效
- 织：建立加密信道或信息茧房，区域内"只有一种声音"
- 改：改写信道容量——让某些真相**物理上传不出去**
- 合：成为信道本身。代价：使用即增熵，自身记忆被噪声逐比特侵蚀（与兰道尔极限直接结算FP）
- 克制关系：**信息噪声克制社会共识**（共识依赖传播）；反被物理克制（物理法则不需要被"传达"即生效）

### 2.3 物理层扩充

**⑤ 能量守恒法则（热一律）**

- 窥：感知能量流动 → 引：抽空动能（"点穴"）→ 织：能量自循环场 → 改：挪用能量，但**必须在别处记账** → 合：成为能量账本，一切能量转移都经过你
- 独特代价：**守恒反噬**——你挪用的每一分能量，必在最坏的时刻、以最坏的形式在别处偿还

**⑥ 光速不变/因果视界法则**

- 窥：感知时间膨胀 → 引：局部钟慢 → 织：因果视界（视界内你的"现在"是别人的未来）→ 改：改写光锥，划定"事件不可能" → 合：成为光锥
- 关键弱点：与外界时间脱钩者**无法参与共识**——社会法则对高阶相对论者天然减效（共识需要同步的时间）

**⑦ 不确定性原理法则**：测不准 → 制导模糊 → 测不准域 → 抬高不确定性下限 → 成为概率云

**⑧ 泡利不相容法则（排他）**：识别"不可叠加" → 禁止两人占同一位置/角色 → 一人一位的排他领域 → 改写"同一性"判据 → 成为唯一性。**明确克制：量子叠加分身者遇之即被锁死**（两个费米子不能处于相同量子态）

**⑨ 熵增法则**：谱层位置为物理层最右端，是**唯一通向时间箭头的物理法则**（五阶链沿用总表）。

### 2.4 生命层（全新）

**⑩ 中心法则（DNA→RNA→蛋白质）**

- 窥：读取遗传信息 → 引：表达调控（开关某个性状）→ 织：可遗传的结构改写 → 改：改变信息流方向（逆转录常态化、获得性遗传）→ 合：成为遗传信息流本身——你的存在即所有生命的模板
- 代价：成为"模板"后失去个体性，**所有你的复制品都不是你**

**⑪ 自然选择法则**

- 窥：看见适应度梯度 → 引：施加选择压（定向淘汰某类人）→ 织：塑造选择环境（造一个只利于某种人的世界）→ 改：改写"适应"的定义 → 合：成为选择压本身，凡与你相遇者皆被你筛选
- 代价：**你自己也必须永远被选择**——合法者不能停止适应，否则即消亡
- 跨层共鸣：与社会层**马太效应同构**，两者是同一法则在生命层与社会层的投影

**⑫ 内稳态法则**：读取平衡偏离 → 调节回稳 → 稳态域（区域内伤口自愈、情绪自动纠偏）→ 改写平衡点（让毒药成为新的稳态）→ 成为稳态本身，吸收一切扰动
- **边界：绝对稳态即死亡**——生命本质是远离平衡的耗散结构，合法者将因此"稳定"成一座雕像

**⑬ 进化稳定策略（ESS）法则**（生命↔社会过渡层）

- 窥：看出哪套行为是稳定解 → 引：植入策略扰动 → 织：锁定策略均衡（鹰鸽博弈定型，群体行为不可逆转）→ 改：改写均衡解 → 合：成为均衡——**任何偏离者自动被淘汰**
- 代价：你必须永远玩这个策略，不能变通
- 现实基础：1973年梅纳德·史密斯给出精确数学形态 E(S,S) > E(T,S)，合法者的策略就是那个无法被入侵的 S

**⑭ 最优觅食法则**（生命↔经济过渡）：感知收益递减 → 边际扰动 → 斑块调度 → 改写性价比 → 成为效率本身

### 2.5 心理/经济过渡层

**⑮ 损失厌恶法则（前景理论）**：看见谁在害怕失去 → 放大损失感 → 恐惧场 → 改写价值曲线（让等价物不等价）→ 成为"失去"本身
- 代价：**对自身无效**——你比任何人都更难评估自己的损失

**⑯ 认知失调法则**：察觉信念与行为的裂缝 → 制造不适以扭转态度 → 群体自我说服网络 → 改写"一致性需求" → 成为必须自洽的引力：所有人面对你，要么改口，要么崩溃

**⑰ 供需法则**：看价格信号 → 边际扰动 → 构建市场 → 改写弹性 → 成为市场

**⑱ 格雷欣法则（劣币驱逐良币）**：察觉劣币化 → 推动劣币流通 → 良币退出网络 → 改写"价值"判据 → 成为贬值本身
- **与信任法则构成天然对冲**：良币即信任锚，劣币化即共识瓦解

## 第四章 · 势力与叙事钩子（本章新增）

谱系补全后，原三方势力之外自然分化出第四方：**中间五层的"摆渡人"**——掌握生命/心理/经济过渡法则的游离者，物理院视他们为不够硬的科学家，社科塔视他们为不够正的社会工程师，法则教会则认为**过渡层才是边界膜最薄的地方**，因为心理法则"对自身无效"、生命法则"必须永远被选择"——这些代价最像人的代价。

教会内部的异端派由此提出新假说：**创造主"削己入凡"时，落点不在物理侧也不在社会侧，而在心理层**——因为只有在那里，全能者才会第一次体验到"对自己的无效"。
