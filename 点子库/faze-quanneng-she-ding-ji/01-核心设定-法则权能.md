# 核心设定 · 法则权能体系

> 法则不是知识，而是世界的接口；掌握一条法则，即获得该法则的权能。

---

这个设定很适合做一套“法则权能”体系。核心可以定为：

法则不是知识，而是世界的接口。掌握一条法则，就等于获得该法则的“权能”；掌握越深，权能越强，但代价也越接近被法则同化。

1. 底层结构：物理到社会是一条连续谱
可以排成：

数学/逻辑 → 物理 → 化学 → 生物 → 心理 → 经济 → 法律 → 政治 → 文化 → 道德

越靠左，越客观、越依赖能量与精度；越靠右，越主观、越依赖共识与集体意识。
所以物理系强者能徒手造重力井，但可能被“契约”锁死；社会系强者能言出法随，但离开人群就近乎凡人。

2. 掌握程度：五阶
同一条法则，不同人掌握程度不同，能力表现为同一原型，但范围、精度、持续、可逆性、代价不同。

窥法：感知法则流向。如感知重力异常、谎言、权力结构。

引法：小范围引动。如拉动物体、促成交易、短暂获得信任。

织法：构建稳定结构。如局部重力场、债务网络、信任共同体。

改法：局部改写法则参数。如改变重力方向、重写背叛代价。

合法：成为法则化身。如自身即引力奇点、自身即共识。但会逐渐失去人性与自由。

3. 示例能力
物理侧：

万有引力：测重 → 拉拽 → 重力场 → 改方向 → 黑洞/轨道编织。

熵增定律：感知混乱 → 加速冷却/热寂 → 局部秩序 → 逆熵 → 时间箭头局部倒转。

量子叠加：概率直觉 → 量子隧穿 → 叠加分身 → 选择观测结果 → 多世界并行。

牛顿第三定律：感知反噬 → 反弹伤害 → 转移作用力 → 设定反作用对象 → 强制因果反噬。

社会侧：

信任法则：辨谎 → 建立信任 → 信任网络 → 重写背叛成本 → 成为信仰共同体。

权力法则：看权力结构 → 威慑 → 联盟 → 重写合法性 → 言出法随。

交换法则：看价值流向 → 促成交易 → 债务网络 → 重写等价关系 → 资源再分配。

契约法则：感知违约 → 口头约束 → 自动执行 → 条款重写 → 因果契约。

破窗效应：感知失序 → 引发连锁 → 修复或制造混乱 → 定义文明边界 → 秩序化身。

4. 代价与平衡
物理法则耗能、耗身体，高阶者会“法则化”：引力使自身坍缩，熵增使自身衰老。

社会法则耗信誉、关系、意义，高阶者会“共识化”：失去自我，只剩角色。

越根本的法则越难掌握，但改写后影响越大。

社会法则在孤立环境失效，物理法则在奇点/法则冲突区失效。

5. 叙事潜力
可以形成三方：物理院、社科塔、法则教会。
物理院想用法则稳定宇宙，社科塔想用法则重塑文明，教会认为“合法者”已不是人。
主角可以掌握“信任”或“熵增”这种看似弱、实则能颠覆系统的法则。
