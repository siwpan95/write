# 完整设定集 · 总纲

> 底层架构 → 现实基础 → 边界理论 → 边界之外 → GURPS 点数化 → 叙事整合（全体系一册贯通）。

---

## 序章：一句话概括
宇宙由法则构成，掌握法则者获得权能，但权能的上限由边界决定，边界之外是创造主——而创造主为了被认识，自愿让出了边界。

## 第一章 · 底层架构

### 1.1 法则连续谱
从物理到社会，法则构成一条连续谱：

数学/逻辑 → 物理 → 化学 → 生物 → 心理 → 经济 → 法律 → 政治 → 文化 → 道德

越靠左：越客观，越依赖能量与精度，越不受共识影响。

越靠右：越主观，越依赖共识与集体意识，越受网络结构影响。

两侧并非截然分开：社会物理学已证明社会现象与自然现象存在系统共性，社会算子框架在数学运算与物理基本力之间建立了同构关系。

### 1.2 法则即力量
在 GURPS Powers 框架下，一条法则就是一个 Power：

来源：宇宙本身的结构性真理（物理侧 = 自然律；社会侧 = 集体共识）

焦点：该法则支配的具体现象域（引力、熵、信任、权力……）

获取机制：法则天赋（5点/级）+ 法则亲和，解锁该法则下的优势集合

### 1.3 五阶掌握模型
| 阶位 | 核心机制 | 能力表现 | GURPS 实现 |
|---|---|---|---|
| 窥法 | 感知法则流向 | 感知重力异常、谎言、权力结构 | 察觉/共情优势 + 天赋1-2级 |
| 引法 | 小范围引动 | 拉动物体、促成交易、短暂获得信任 | 控制1-3级 + 低阶先天攻击 |
| 织法 | 构建稳定结构 | 局部重力场、债务网络、信任共同体 | 控制4-7级 + 区域效应 + 扩展持续 |
| 改法 | 改写法则参数 | 改变重力方向、重写背叛代价 | 控制8-15级 + 宇宙修正值(+50%) |
| 合法 | 成为法则化身 | 自身即引力奇点、自身即共识 | 替代形态 + 支配(法则同化) |
### 1.4 物理侧与社会侧的结构性差异
| 维度 | 物理侧 | 社会侧 |
|---|---|---|
| 控制基础价 | 20点/级（常见） | 40点/级（抽象） |
| 范围限制 | 物理距离 | 共识范围/网络密度 |
| 失效条件 | 法则冲突区/奇点 | 孤立环境/反共识 |
| 代价类型 | 能量、身体、HP | 信誉、关系、意志、FP |
| 高阶修正 | 宇宙+50% | 宇宙+50% + 道德修正值(-10%~-20%) |
| 精度特征 | 可指定精确目标 | 只能影响统计分布 |
| 尺度跃迁 | 线性叠加 | 相变临界放大 |

## 第二章 · 现实基础

### 2.1 社会物理学的实证支撑
社会算子理论：融合(+)、差异(−)、自创生(↺)、纠缠(⊗)四种核心算子，在社会与心理过程和物理基本力之间建立基本同构关系，提供可测量参数与严格证伪标准。

社会气体模型：个体立场建模为抽象空间中的粒子，推导出配分函数与宏观可观测量（压强、体积、温度），社会系统存在理想气体状态方程形式的宏观统计描述。引入化学势可处理开放社会系统与跨群体传播。

信任阈值普适常数：对1972-2024年间六大洲124个系统的分析发现，集体系统在 τ* = 0.68 ± 0.01 处存在普适相变。低于该阈值指数衰减，高于该阈值自组织并展现幂律标度。该常数在经济危机和文化多样性中保持不变，与宪法绝对多数、网络渗流、演化稳定性中的常数一致。

社会爆炸临界性：社交媒体社会运动的爆发遵循与物理临界现象相同的数学结构，幂律指数在不同时间窗口和标签数量下保持一致。

复杂传染的临界质量：社会法则的传播存在渗透阈值，低于阈值无法扩散，高于阈值呈幂律爆发。

### 2.2 尺度的悖论
集体行为的可预测性来自个体特异性的消失。法则权能者在个体层面越强大，在集体层面越被统计规律淹没。社会侧控制购买的不是精确性，而是规模——这是其基础价高于物理侧的深层原因。

### 2.3 兰道尔极限与社会代价
擦除一比特信息至少消耗 nTln2 的能量。社会法则改写的信息代价可据此估算，“改法”级别的社会法则使用消耗 FP（疲劳点） 而非HP，消耗量随“社会温度”升高而增加。

## 第三章 · 边界理论

### 3.1 边界的三种形态
物理侧边界：光速、普朗克尺度、热力学第二定律、兰道尔极限、临界指数。

社会侧边界：信任阈值 τ*=0.68、渗透阈值、幂律指数、网络密度临界点、社会气体状态方程。

元边界：任何法则必然有适用域和失效条件。取消边界等于取消法则，等于取消权能。

### 3.2 边界如何划分现实与超凡
现实：系统远离临界点，处于稳定相。个体影响被统计平均淹没，法则权能微弱或不可见。

超凡：权能者识别边界、在边界处施加影响、利用临界放大效应。系统在临界点附近具有最大响应性，微小输入产生巨大输出。

关键：一旦权能者跨越边界，他自己也被系统同化。“合法”阶段的代价即源于此。

### 3.3 边界即法则的“膜”
现实与超凡之间隔着一层法则的膜。权能者不是膜外的神，而是膜上的振动——能感知张力、制造涟漪、短暂拉伸形状，但永远无法撕破膜本身。因为膜就是法则，撕破它，权能也随之消失。

## 第四章 · 边界之外的存在

### 4.1 定义
创造主/圣人/创世神明：不需要法则、不受边界约束、但可以选择自我限制以“进入”法则体系的存在。

### 4.2 现实原型
卡巴拉的 Ein Sof 与 Tzimtzum：

Ein Sof = 绝对无限、无属性、不可知的神性本质，不能直接创造。

Tzimtzum = Ein Sof 收缩自身，腾出“空无的空间”，让创造得以发生。

边界 = Tzimtzum 留下的膜。

核心：创造主不是法则的拥有者，而是法则的前提。合法者是法则的内容，创造主是法则的容器。

诺斯替主义的真神与迪缪尔哥斯：

迪缪尔哥斯 = “合法”阶段的法则权能者。他确实创造了一个世界，但误以为这就是全部。

真神 = 创造主。不参与物质世界的法则运作，存在方式是启示而非权能。

洪荒流的圣人：

本质与道相合，超脱时空因果束缚。真身无法承载于任何故事、世界、时空或混沌之中。

“圣需削己入凡”：圣人若要介入，必须主动降维，将概念投射为法则可承载的形态。

### 4.3 GURPS 机制实现
Omnilock（全锁） [150点]：

Unkillable 3 + Insubstantiality + Immunity to All 的复合优势。

只能被其他 Omnilock 存在或“作者权威”影响。

不受任何法则权能影响，甚至不在“可被感知”范畴内——除非自愿。

Aseity（自存性） [100点]：

元优势，不属于任何力量来源。

不依赖任何外部条件存在，不需要法则环境、共识、信仰、能量。

无法被“购买”——创造主不是用点数构建的角色，而是叙事的公理。

“削己入凡”的机制：

创造主若要介入，必须临时购买“合法者”优势，并自愿限制自己在扮演期间无法使用 Omnilock 和 Aseity。

化身可被击败，但创造主不受影响，可在 1d6 小时内创造另一个化身。

真身无法被“故事”承载——任何法则体系内的故事都需要冲突、代价、成长，而 Aseity 的存在没有这些。

### 4.4 层级关系
| 层级 | 与边界的关系 | 存在方式 | 力量来源 |
|---|---|---|---|
| 创造主/圣人 | 边界之外 | 自存，不受任何法则影响 | 无来源——他是来源的来源 |
| 合法者 | 边界本身 | 法则化身，成为边界的一部分 | 与法则合一，被法则定义 |
| 织法/改法者 | 边界之上 | 操作法则参数，利用临界放大 | 法则天赋 + 控制优势 |
| 引法/窥法者 | 边界之内 | 感知和局部引动法则 | 法则天赋 + 感知/控制 |
关键区分：创造主不是“最强的合法者”。合法者被法则定义，创造主是定义法则之所以可能的前提。创造主不能直接“击败”合法者，正如作者不能直接“击败”自己笔下的人物。他能做的是选择不再写这个人物——表现为法则体系的突然“失效”，而非一场战斗。

### 5.3 关键增强与限制
增强修正值：

区域效应：2码半径/级，+50%/级

扩展持续时间：秒→分钟，+20%~+60%

持久：+40%

宇宙：+50%（绕过常规防御，无视常规抵抗）

限制修正值：

触发条件（TRUST_LEVEL ≥ 0.68）：-20%~-30%

道德修正值（信任法则不能说谎）：-10%~-20%

需要准备时间：-10%~-30%

代价（FP/HP）：-5%~-20%

### 5.4 法则冲突规则
同级冲突：对抗检定（法则天赋 + 相关技能 vs. 对方法则天赋 + 相关技能）

跨级冲突：高阶法则+2至+5加值

同法则冲突：高阶者有天然优势，低阶者若在“主场”可获得环境加值

网络密度加值：社会侧权能者在高度互联社群中+3至+5，孤立环境中-3至-5

反法则手段：中立化（法则）、静态（法则）

### 5.5 代价与劣势
物理侧高阶劣势：

依赖（法则环境）

脆弱（反法则攻击）

## 第六章 · 叙事整合

### 6.1 三方势力
物理院：想用法则稳定宇宙，相信边界可以被完全理解。

社科塔：想用法则重塑文明，相信边界可以被推得更远。

法则教会：认为“合法者”已不是人，边界之外的存在才是真正的神。

### 6.2 主角弧线
从感知者到化身者的过程，本质上是角色与法则之间距离不断缩短的过程——也是人性不断被法则逻辑侵蚀的过程。

物理侧：身体不再是身体的异化。
社会侧：自我不再是自我的消解。

### 6.3 终极悖论
法则权能者的一切力量来自在边界上的行走。边界之外的存在恰恰没有“行走”这个概念。合法者用一生追求“成为法则本身”，而创造主从一开始就不需要法则。合法者的终极目标——与法则合一——在创造主看来是一种自我囚禁。

但反过来，创造主若要被感知、被理解、被爱，必须“削己入凡”，进入法则体系，成为边界上的一个存在。一旦进入，他就受限于法则——他不能再“撤回法则”而不撤回自己。

边界不是创造的偶然副产品，而是神性选择自我限制以换取关系的必然结果。

“圣需削己入凡”不是圣人的弱点，而是圣人的选择。这个选择，正是所有法则、所有边界、所有权能之所以存在的第一因。

### 6.4 社会侧权能者的独特命运
当信任法则的“合法”者将群体信任推过 0.68 的临界点，群体进入自组织状态的那一刻，他不再是操纵者，而是被操纵的系统的一个节点。他的个人意志被集体优化的统计力学所吸收。社会气体模型的“化学势”描述的就是这个过程：权能者从一个独立的“粒子”变成了系统“相”的一部分。

在物理世界中，法则权能者是能够改变规则的神；在社会世界中，法则权能者是能够改变统计分布的工程师——但最终，他们自己也被这些分布所描述。
