# 法则权能体系 · 完整设定集

### 剧情推进方法论（12 号文件速记）

- **世界中心制三铁律**：每集由一张"设定变动卡"驱动（世界先动，角色后动）；角色是设定的探针；**台账比角色重要**——一集结尾世界状态台账没动，这集判废。
- **世界状态台账六参数**：标尺版本号、τ* 城区读数、膜厚度、法则冲突区数量、三方均势、Ω刻度状态。
- **双工具循环**：跑团掷骰产生**意外**（涌现叙事）→ 编剧室把意外固化为**结构**（破集）→ 世界状态读数结算入账。
- **第一季《标尺失准之年》**：E01 第十三条 → E03 缺页（窥法→引法）→ E04 守恒反噬（中点）→ E06 标准战争（引法→织法）→ E08 回望·Ω裁决（织法→改法）。

### 体系七大支柱（速记）

1. **连续谱**：数学/逻辑 → 物理 → 化学 → 生物 → 心理 → 经济 → 法律 → 政治 → 文化 → 道德。越左越客观、耗能量；越右越主观、耗共识。
2. **五阶模型**：窥法（感知）→ 引法（引动）→ 织法（编织）→ 改法（改写）→ 合法（化身，失去人性/自由）。
3. **独一无二原则**：一条法则只产生一种权能原型，表现形态由掌握者的认知透镜决定。
4. **边界理论**：光速、普朗克尺度、τ*=0.68、兰道尔极限……边界可逼近、可局部跨越、不可取消；膜即法则，撕破膜权能随之消失。
5. **边界之外**：创造主（Ein Sof/Tzimtzum、迪缪尔哥斯、圣人"削己入凡"）；D&D对应神上神力（艾欧），Ω不可度量。
6. **量级标尺**：1 FP = 1 标准成年人 ≈ CR 1/16；1 宅男 = 0.5 鹅；上至 10⁶ TFP，边界级 Ω 不可换算。
7. **代价闭环**：物理侧耗能/法则化，社会侧耗信誉/共识化；同构共享、悖论自毁——强力必有等价支取。
