## 1.2 词汇层

### 1.2.1 禁用词（AI 腔 / 书面腔红线）

沿用 `通用模板包/05` §1.2.1 全表（35 词两级红线）**不复制**，本卡只追加本书特有禁用：

| 禁用 | 原因 |
|---|---|
| 忽然、猛然、骤然 | 本书的异常必须表现为「故障」而不是「惊吓」 |
| 诡异、可怕、毛骨悚然 | 恐怖由制度与流程承担，不由形容词承担 |
| 强大的力量、恐怖的力量、毁灭 | 空泛的强度词，本书强度只用**系统健康度**与**庇护项**衡量 |
| 仿佛命运、似曾相识、莫名的 | 模糊化叙事，本书要求可判定 |

### 1.2.2 必用词 / 世界特色词（世界指纹）

| 词 | 用法 |
|---|---|
| **矫正** | 核心动词：**剥离神力庇佑并重塑为守法社畜**；禁止写成「消灭/净化/超度」 |
| **廓者** | 身份名；工牌正面唯一身份标识 |
| **大 / 清** | 廓者信条的两面：「大＝扩张覆盖、让系统运行；清＝清除」 |
| **庇护** | 被剥离的东西（勇气/智慧/欢乐/生命）统一称「庇护」，**它会转移进廓者身体** |
| **残余聚合体** | 处置对象的登记类别名（工单用语） |
| **社畜化潜力** | 工单备注栏用语；也是本书的核心讽刺 |
| **非固定资产维护窗口** | 体制的窗口名（归档地） |
| **按 / 计数** | 廓者的自我维持动作（数按键、数时间、数心跳） |

### 1.2.3 四层词汇域（四层不许串味，含年代层）

| 层 | 词汇 | 禁用混入 |
|---|---|---|
| **故障层**（系统／技术） | 报错、无法连接、丢失、重启、线程、索引、校验、兜底、回滚 | 不许混入情绪词与神学词 |
| **体制层**（工单／规范） | 派发、处置、归档、备注、窗口、试行、编号、对象、信仰 | 不许混入系统的技术黑话（体制不懂技术，只懂流程） |
| **故障生物层**（被处置者） | 庇护、聚合、黏稠、关节、呢喃、残余 | 不许混入体制用语（它们不理解流程） |

| **年代层**（千禧年） | 座机、寻呼机、呼台、手机短消息、七位码、代收水费、纸质通知、大背投、ADSL、VCD、凤凰自行车、开窗公交车 | 不许混入年代错位物（微信、智能机、扫码、网约车、共享单车、液晶大屏、流媒体）——清单见 `03` §〇 |

> **判定规则**：一句台词若同时含两层词汇 ⇒ 重写。工单短信里出现「无法连接」＝**体制层被故障层污染**（这是一个可机检的硬伤）。
> **年代层是硬约束**：千禧年平行世界里出现「扫码」＝年代穿帮（可机检）。

### 1.2.4 禁用句式

- 「我不知道该说什么，但……」类**情绪直白转折**（本书情绪只能通过动作与物件显影）。
- 「仿佛整个世界都……」类**宏观抒情**。
- 「他/她仿佛明白了什么」—— 第一人称书禁止写别人「明白」。
- 「一切都是命中注定」—— 与「无精密界定的真理」相斥（这是**世界观内在矛盾**，写出来即穿帮）。

### 1.2.5 招牌句式（本书特色 · 限量使用）

| 句式 | 用途 | 频次 |
|---|---|---|
| 「你知道吗？你当然不知道。」 | 传说体的自问自答 | **每卷 ≤3 次**（第 01 章已用满，后面不得复读） |
| 「X。Y。Z。」单字/短词列举 | 剥离庇护时的清单式呈现 | 每次矫正 ≤1 段 |
| 「请于今日十七时前至……执行矫正。」 | 工单口吻 | 每次任务 ≤1 段 |
| 「有事儿呼我。」／呼台班长的转述 | 千禧年派单质感（寻呼台时代） | 每卷 ≤2 次；**只作时代底噪**，不替代短信工单（手机短信此时刚具备） |
| 「一切没有精密界定的真理都会变成谎言，所有经过合理设定的谎言都能变成真理。」 | 工牌背面的信条 | **全书 ≤3 次**（是题眼，不是口头禅） |

### 1.2.6 情绪直说三分法

情绪**允许直说**，但必须落在「可归属」上：写「我有点喘不上气，心里发空」（第 01 章原文）＝**归属到身体**；写「我很害怕」＝**禁止**。
规则：**情绪词后面必须跟一个身体动作或物件**。

### 1.2.7 第二叙述层的定位：**润滑剂**，不是方法论分析（作者定，2026-11-13）

- 原稿里的「写作方法实践」是**作者的自我体检**，属分析文，**不进正文**（已转记 `01` §四 与 `03` §六）。
- 正文里的第二层是**旁白层的冷评**：一句话，一处，替读者把不适感**压实**或**挪开**，像润滑剂而不是教学。
- **禁止**：解释主题、总结机制、教育读者、预告下一章（「这意味着……」类一律不写）。
- **允许**：自嘲、把荒诞说破半句、把读者逗一下。
- 频次：**每章 ≤1 处**；一卷 ≤8 处（与 `10` §段3 第 5 步一致）。

## 1.3 段落与排版规范（**按作者原稿实测反推，2026-11-13 订正**）

- 段首**全角缩进两格**（`　　`）—— 与仓内其他正文一致（三章均如此）。
- **段间不空行**：缩进段连续排列（第 01 章 83 段 / 0 空行；第 02、03 章同）✔
- **不使用独立省略号段**（`　　……` 单独成段）：**作者原稿零使用**（第 01 章 0 处）。
  本仓第 02/03 章初稿曾以它作分节符（14/21 处），已全部移除 ⇒ 那不是本书的排版法。
- 单句成段是本书特征（88%~96%），**不合并**；但同一节奏连续 3 段短句时，第 3 段起加一个具体物件作锚。
- **系统提示用【】**（如「【未检测到可用的麦克风设备。】」「【廓者】」「【廓者行为规范（试行）】」）。
- **工单短信用引号整段引出**，不加解释性引导语。

## 1.4 感官配比（听觉友好）

每章感官配额：**日常物件 ≥2、声音 ≥1、触觉/身体 ≥1、超自然感官 ≤1**（且那一次要写成**故障表征**，不写怪物形貌）。

## 1.5 描写禁令（五禁）

1. **禁血腥肢解**（平台红线 ＋ 与「社畜化」的讽刺内核相悖）。
2. **禁怪物图鉴式描写**（不列外形特征清单；用**行为与后果**代替）。
3. **禁直接写神名威压**（四神只以**工单备注栏**与**信徒的话术**出现，不登场）。
4. **禁解释世界观**（世界观只能从工单、投诉、物业通知、路人闲话里漏出来）。
5. **禁让叙述者替读者总结**（不写「我意识到这是某种阴谋」）。

## 1.6 误报规避量化阈值

- 短句占比 <40% 才报；逗号/百字 >6 才报；感叹号按**叙述段/传说段分算**（叙述段 >3 才报）。
- 「不知道」「仿佛」等词：按**每千字**计，单章 ≥5 才报。
