## 2. 第一阶段：辖区包（本书＝故障域）

### 2.2 辖区卡 · 阳光苑（首个辖区）

| 格 | 内容 |
|---|---|
| **辖区名** | 阳光苑三号楼（二单元） |
| **坐标层** | 单元门口贴着物业的通知，纸边卷了；本月水费代收，落款是物业的名字和一个电话 |
| **物理层** | 四楼消防通道拐角；楼下的路灯；单车经过，后座绑着一捆东西；巷子里的纸箱被风追着跑 |
| **居民层** | 物业（代收水电、贴通知、只留电话）；住户（抱怨、投诉、不知情）；骑车送货的人（只出现，不说话） |
| **信仰层** | 四神（暴君／奸相／慈父／纵欲王子）——只出现在**工单的信仰栏**与信徒的话术里 |
| **信条层** | 「廓者，一曰大，二曰清。」＋「一切没有精密界定的真理都会变成谎言，所有经过合理设定的谎言都能变成真理。」 |
| **日常质感层** | 物业通知、水费代收、路灯、纸箱、台灯、楼道脚步声、电梯（停错楼层） |
| **危险层** | 残余聚合体（低威胁、社畜化潜力高）；更大的黑暗藏在**分类**环节 —— 误把人当故障、或把故障当人 |
| **硬通货／硬凭据** | **庇护**（勇气／智慧／欢乐／生命）＝唯一硬通货；工单＝硬凭据（可执行的处置凭证）；**钱不是通货**（体制内不出现交易） |
| **历史与神话** | **反复被引用的旧文／旧账**：①《廓者行为规范（试行）》十四条（只背得下第七条）；②工牌背面两句话（来历不明）；③格式化手册（旧版本残页，人人可抄） |
| **不可申诉之物** | 见 §2.5 |
