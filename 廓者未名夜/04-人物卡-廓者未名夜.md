### A2 基础档案

- **年龄/性别/外貌**：未在原稿明确；工牌照片「比现在年轻，眼睛比现在亮一点，嘴角比现在紧一点」⇒ 现比照片更老、更松。**待正文落定**。
- **籍贯/现居**：城市不明；住所为「堆满杂物的电脑桌」＋ 台灯（现址待定）。
- **自述起点**：「这个故事开始于某个无聊的下午」；「我按的是 Alt」（连按 72 下）—— **都市传说是 Tab 81 下成为「取经人」，他按错/按的是另一个键**。
- **身体状态**：开篇起，胸口出现贯穿性异变（随每次矫正加剧）。
- **随身物**：工牌（正面照片＋编号；背面「廓者，一曰大，二曰清」＋「一切没有精密界定的真理都会变成谎言，所有经过合理设定的谎言都能变成真理」）；手机（收工单短信）。

### A3 性格图谱七件套

| 维 | 表现 |
|---|---|
| 外在 | 懒散、自嘲、话多；对流程不耐烦却从不违规 |
| 内在 | 怕被发现自己已经不记得的东西；用「数数」维持秩序（数按键、数时间、数心跳） |
| 缺点 | 把自己也算进「可以清理的东西」 |

| 恐惧 | 有一天连自己工牌背面那两句话都记不住 |
| 信念 | 「廓者，一曰大，二曰清」——他相信清除是慈悲 |
| 秘密 | 他的编号在系统里有旧记录（**戴罪立功**的「罪」指向何处，待揭） |

### A4 欲望–恐惧–错误信念三角

- **欲望**：洗清自己的罪。
- **恐惧**：记忆继续模糊，直到无法自证「我是我」。
- **错误信念**：**「矫正是慈悲，是比杀戮更彻底的清除」** —— 他这样相信，是因为他还没意识到被清除者的痛苦会**转移到他身上**（庇护涌入胸口）。
- **打碎这信念的力量**：被矫正的存在**带着记忆与怨**存活下来 —— 而那些记忆与怨，会在他体内沉积。
- **必须落地的开关**（原稿方法论诊断）：每一次矫正必须同时推进「清除」与「共情」两层；**社畜化停在讽刺层，信念弧光即失效**。

### A7 行为特征

- 遇事先**数**（数按键、数时间、数心跳）—— 维持自我秩序的最后手段。
- 报工单时**照抄格式**（对象／信仰／备注），但对「备注」栏最有兴趣（「社畜化潜力高」＝他在挑对象）。
- 讲都市传说时会**先声明是自编的**（「这个由我亲手编纂的都市传说」）。
- 对读者说话（「诸位看官请瞧仔细」）—— **叙述者的在场感是他的保护壳**。

### B2 猎魔人（范式群像）

- **来源**：自小受邪恶魔法教育的流浪小孩；肉体在渎神仪式中变异。
- **代价**：**失去情感、无法生育**。
- **处境**：逐年稀少；用肮脏手段赚钱；被社会既需要又憎恶。
- **在本项目里的位置**：廓者的**镜像与替代品** —— 若廓者可被替代，第一个被想起的就是猎魔人。

### B3 残余聚合体「丁上」（第 02 章首个工单对象）

- 登记：对象＝残余聚合体；**信仰＝永久灼热之心**；备注＝低威胁、**社畜化潜力高**。
- 外观：看上去五十多岁，穿秋衣和棉拖鞋，坐在楼梯上，手里牵着绳子，绳子另一头拴着一辆蓝色儿童滑板车（轮子上沾着干了的泥）。
- 处置结果：勇气、智慧、欢乐、生命被剥离，**涌入廓者胸口**。

### B4 廓者体制（机构，非人格）

- 形态：只发**短信**（发件人是看不出归属地的号码）；工单固定四栏（时间／地点／对象／信仰／备注）。
- 窗口：**社区综合服务·非固定资产维护窗口**（物业办公室隔壁）—— 交付归档地。
- 规范：《廓者行为规范（试行）》**十四条**，每条都很短；**第七条**＝任务完成后须在二十四小时内至指定地点（待揭其余各条，尤其第十四条）。
