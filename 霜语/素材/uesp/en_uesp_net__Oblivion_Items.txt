==Object ID==
All of the listed items include the item's Object ID (or Form ID), which can be used on the PC version to obtain the item using the PC [[Oblivion:Console|Console]] command <code>additem</code>. To add an item to your inventory:
# Open the console with the ` key (the key to the left of the 1 key). The legend of the key varies from country to country. For example, the North European keyboard has a § sign there.
# Type: <code>player.additem <ObjectID> <Quantity></code> (ex. <code>player.additem 0004788D 1</code>)
# Hit <Enter> (or <Return>)
# Close the console by pressing the ` key (or equivalent) again.
It is not necessary to type the zeroes (0) before the natural numbers or letters when adding an item to your inventory.

* The Object ID for [[Oblivion:Gold|gold]] is <code>0000000F</code>, so to give yourself 10000 gold the command is <code>player.additem F 10000</code>
* For items from [[Oblivion:Downloads|official downloads]], the provided Object IDs all start with "xx". The "xx" needs to be replaced by the number assigned to that download on your computer, which depends upon the number of downloads you are loading and their load order. See [[Oblivion Mod:Formid|In Game Formid]] for details.
* For items from [[Oblivion:Downloads|official downloads]], it is not necessary to enter the first '0' in front of the number which denotes the load order (the 'xx').
