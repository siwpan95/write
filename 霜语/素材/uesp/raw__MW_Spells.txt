==Spellcasting Formulas==
===Success Chance===
Chance of success in percent is <code>(Spell's skill * 2 + Willpower / 5 + Luck / 10 - Spell cost - [[Morrowind:Sound|Sound]] magnitude) * (0.75 + 0.5 * Current Fatigue/Maximum Fatigue)</code>

'''Example:'''
You are a lvl 1 Breton and you have 20 Destruction, 60 Willpower, 50 Luck and have 150 Maximum Fatigue, you are not affected by Sound and you are at maximum fatigue. The spell you want to cast is "Fire Bite": <code>(20 * 2 + 60 / 5 + 50 / 10 - 6 - 0) * (0.75 + 0.5 * 150/150) = 63.75% chance that you will succeed</code>

===Spell Damage===
Spell Damage is <code>Damage * (1 - ( Resistance - Weakness )/100)</code>.

===Spell Cost===
The Spell Cost (the amount of magicka a spell takes to cast) for built in spells (spells that aren't created by the player) can be either auto-calculated or set manually. Spells which are set to auto calculate use the formula <code>( ( ( Min Magnitude + Max Magnitude ) * Duration * ( Base Cost / 40 ) ) + ( Area * Base Cost / 40 ) )  * ( 1.5 if On Target )</code>, rounded to the nearest whole number (n+1/2 rounds up to n+1); this formula is calculated per spell effect and summed together for multi-effect spells. 

Custom spells use the similar formula <code>( ( 2 * Average Magnitude * ( Duration + 1 ) * ( Base Cost / 40 ) ) + ( Area * Base Cost / 40 ) )  * ( 1.5 if On Target )</code>, rounded ''down'' to a minimum of 1. Notably, the additional +1 to the duration and area terms mean that spells with a one second duration effectively have their cost doubled compared to built in auto-calculated spells. 

'''Examples:'''
* '''[[MW:Ondusi's Open Door|Ondusi's Open Door]]:'''
** Built in spell: <code>( ( 50 + 50 ) * 1 * ( 6 / 40 ) ) + ( 0 * 6 / 40 )</code> = 15
** Custom spell:  <code>( ( 50 + 50 ) * ( 1 + 1 ) * ( 6 / 40 ) ) + ( 0 * 6 / 40 )</code> = 30
* '''[[MW:Levitate (spell)|Levitate]]:'''
** Built in spell: <code>( ( 10 + 10 ) * 30 * ( 3 / 40 ) ) + ( 0 * 6 / 40 )</code> = 45
** Custom spell: <code>( ( 10 + 10 ) * ( 30 + 1 ) * ( 3 / 40 ) ) + ( 0 * 6 / 40 )</code> = 46 (rounded down from 46.5)
* '''[[MW:Fire Storm|Fire Storm]]:'''
** Built in spell: <code>( ( ( 1 + 10 ) * 10 * ( 5 / 40 ) ) + ( 10 * 5 / 40 ) )  * ( 1.5 )</code> = 23 (rounded up from 22.5)
** Custom spell: <code>( ( ( 1 + 10 ) * ( 10 + 1 ) * ( 5 / 40 ) ) + ( 10 * 5 / 40 ) ) * ( 1.5 )</code> = 24 (rounded down from 24.5625‬)

===Notes===
* If Resistance - Weakness is equal to 100 or more, the effect is resisted.
* Resistance/Weakness to Magicka does not affect elemental damage.
* "Self" spells have an Area value of 1.
* "Target" spells multiply the above spell cost by 1.5.
* The lowest value possible on a slider is 1 (one), despite it displaying zero.
* Spells without magnitudes (such as Invisibility) behave as though they have magnitudes of 1.

==Deleting Spells==
If you are on PC, hold shift and click on the spell name. On Xbox, select the spell and press the White button. If the deleted spell was bought from a spell merchant, that merchant will have it available for sale again after deletion.
===Notes===
*If you want to be able to use an effect for spellmaking/enchanting, keep at least one spell with that effect.
