## 四、四层建构

### 4.1 自然环境层
- 高纬、寒带针叶林与岩原；风隘是风口，夜里声音会被风撕碎
- 雪有三种：干粉（留不下脚印）、湿雪（粘靴）、冰壳（踩碎会响，会暴露位置）
- 火是硬通货：能生火的地方就是安全区，不能生火的地方只能"熬"

### 4.2 社会结构层
- 领主（Balgruuf）要保城、 Legion 要保帝国、 Stormcloak 要保独立、龙要保蛋
- 四方的目标互不兼容但没有一方是傻子——压迫感来自结构，不来自降智
- 白漫城门在卷三关闭：城内防内战、城外防龙，主角夹在中间

### 4.3 文化表层
- 诺德人不轻易道谢；"我在"是比"谢谢"更重的回应
- 守墓人不进屋，烧纸是在替死人记路
- 名字是可以自己取的：主角姓"霜门"是自取（日志原文："姓不重要了，霜门是我自己取的"）

### 4.4 个人经验层
- 主角的记忆有洞：海尔根那夜她做了什么，她自己说不全
- 她对"有人陪着"的感知来自一个声音，不是一个人
- 卷六揭示：她记得他，而他正在忘记她——这是全书最后一层疼

## 五、力量体系四件套

### 5.1 等级（6 大阶 × 3 小段）

| 阶 | 名 | 能力边界 | 每段标志 |
|---|---|---|---|
| 1 | **听** | 只接收声音，无回应 | 听见 / 分辨 / 确认不是幻觉 |
| 2 | **应** | 能回话，能提问 | 试探 / 问事 / 讨价 |
| 3 | **唤** | 能让字变成吼（需他人在场） | 单字 / 双字 / 成句 |
| 4 | **镇** | 能让龙停一下 | 对视 / 对喊 / 对峙 |
| 5 | **称** | 龙用她的名字叫她 | 被认出 / 被当成同类 / 被当成威胁 |
| 6 | **默** | 不再需要说话也能被听见 | 主动沉默 / 不靠水晶 / 自己成为那边 |

> 每 8–15 章一次可见跃迁；跃迁必须伴随一次可见代价。

### 5.2 资源（产出—消耗成环）

| 资源 | 产出 | 消耗 | 稀缺曲线 |
|---|---|---|---|
| 体温（warmth） | 火、兽皮、室内、走动 | 暴露、夜行、流血 | 卷一极紧 → 卷三稍缓 → 卷四再次归零 |
| 体力（stamina/hp） | 口粮、休息 | 战斗、跋涉、失血 | 始终紧，到卷六不再归零 |
| 灵魂（soul） | 未知（"那边"的来源） | 每次通话 | 单调递减，不可补充——这是定时炸弹 |
| 龙语残响 | 吞龙魂、读壁、被龙注视 | 发吼、镇龙 | 卷二出现，卷四峰值，卷六归零 |

### 5.3 瓶颈（每三阶一次，有剧情承载）

- **第 3 阶瓶颈**：她发现"那边"每次说话都在忘记什么，于是停止提问 → 但停止提问等于放弃线索
- **第 4 阶瓶颈**：龙不再听她喊，因为喊的人和听的人不是同一个 → 她必须让"那边"替她喊一次
- **第 5 阶瓶颈**：龙叫出她的名字，她必须回答"我不是你的蛋" → 承认自己是什么，也承认自己不是什么

### 5.4 代价（不可取消、不可豁免）

| 行为 | 代价 | 追讨窗口 |
|---|---|---|
| 通话 | "那边"失去一段记忆 | 每 10–20 章一次，卷六总爆发 |
| 发吼 | 肋下灼烧复发一天 | 3–5 章 |
| 吞龙魂 | 身体里多一个不属于她的声音 | 卷二末至卷五逐步显形 |
| 救人 | 被救者记住她，成为追兵的线索 | 5–15 章 |

## 六、金手指设计卡（B3）

| 要素 | 内容 |
|---|---|
| **唯一性** | 帝国末年遗存的灵魂链接水晶，仅此一枚；断线即永久 |
| **成长性** | 从"只能听"到"能反问"到"能沉默"到"自己成为那边"（6 阶） |
| **限制①** | 单向传声，无图像、无触碰、无法验证身份 |
| **限制②** | 每次有效通话消耗 `soul`，耗尽断线；主角**不能选择不付**——她不知道在付什么 |
| **限制③** | 水晶发热代表"有人在"，变冷代表"没人了"；她无法主动加热 |
| **代价** | "那边"在遗忘自己。主角越活，那边越空 |
| **首秀** | 第 01 章后段（困境已建立后） |
| **限制被触发次数** | 卷一 3 次（问话扣 soul、断线恐惧、"那边"忘了自己的名字）；卷四 1 次（主动沉默）；卷六 1 次（代价反转） |
| **反制** | 第 05 阶后，"那边"可以选择**不回答**——这是全书唯一一次主动权反转 |
