# bible · 状态机体感化对照

> 游戏日志里的 `hp / warmth / soul / trust / stamina / clock / clues / flags` 是引擎数值。
> 小说**不写数值**，一律转成可观察的身体感受或行为证据。本表是全书唯一的转换口径。

---

## 一、核心状态转换表

| 游戏字段 | 范围 | 禁止写法 | 本书写法（按程度递进） |
|---|---|---|---|
| `warmth` 体温 | 0–100 | 体温值 | 100：手能弯、能站久 / 60：手指迟钝、说话带白气 / 30：斗篷里面是硬的、膝盖裂响 / 10：站不起来、记不清话 / 0：想睡，且醒不过来 |
| `hp` 生命 | 0–20 | 生命值 | 20：能走能打 / 12：肋下抽、笑会疼 / 6：视野变窄、耳朵嗡 / 0：倒下（不写数字） |
| `soul` 灵魂 | 0–10 | soul-1 | 满：水晶很烫、光稳 / 半：暗一分、需要握久一点才热 / 0：**凉的，怎么握都不热** |
| `trust` 信任 | 0–100 | 信任度 | 升：不再问为什么、直接照做、把秘密说给它听 / 降：反问、停顿、把手从水晶上拿开 |
| `stamina` 体力 | 0–10 | 体力条 | 满：能走坡 / 低：每一步都要先拔腿 / 0：腿抖、撑不住 |
| `clock` 时钟 | 0–20 | 时间戳 | 用天光、影子、火堆剩灰、"第二天早上" |
| `rations` 口粮 | 0–3 | 数量提示 | 不写"还剩两份"，写"她数了三次，还是那么多" |
| `gold` 金币 | 0–32 | 金币数 | 用"她把硬币数出来，摊子上的手没动" |
| `clues.soulLink` | bool | 状态提示 | 用手掌贴上水晶、它矮了一寸（日志原意象） |
| `flags.knewTruth` | bool | flag | 用一个角色的沉默或一句"原来你也知道"表达 |

---

## 二、可观察证据写法（三条纪律）

1. **不写内心形容词**：不写"她很冷""他有点慌"，写"她把两只手塞进腋下""那头连着说了两个'我在'"。
2. **状态变化要有物证**：水晶明暗、斗篷软硬、雪上的脚印、火堆的灰，都是证据。
3. **读者能推算程度**：通过递进的物象，读者自己知道"现在很危险"，不需要作者报数。
