## 三、法律边界（提示，非意见）

> **2026-11-18 更新：按"用事实验证、不再要求书面确认"的处置，已联网核验同人投稿规则，关闭原 P1 待办。**
> 核验结论分三层，**A 级事实支持"同人可投稿"，但商用授权边界仍是客观灰色地带，如实披露、不承诺结果**。

### 3.0 联网事实核验（检索日 2026-11-18）

| 事实 | 证据 | 等级 | 对本书的意义 |
|---|---|---|---|
| 起点官方明确定义"同人指利用原作人物、情节、设定进行二次创作的作品，**写动漫/影视/游戏等对话体同人也可以参加征文**" | 起点官方活动页 `https://acts.qidian.com/2019/856358253/index1.html` | **A** | 游戏同人（本书属此类）在起点被官方明确承认并纳入活动 |
| 官方在创作/投稿流程中设"衍生同人""明星同人"分类 | 同上活动页"话萌小说 APP 用户……选择'衍生同人'或'明星同人'分类发布即可" | **A** | 同人有官方分类入口，非禁区 |
| 起点官方举办同人征文并设"衍生同人"类别，且有阅文自有版权 IP 的同人征文（如《遮天》女性角色同人征文） | `https://write.qq.com/actarticle/detail/artidx/639` | **A** | 平台主动组织同人创作，投稿路径成立 |
| 原创声明不适用于同人：官方《起点用户原创声明》明确"不包括改编、翻译……他人已有作品而产生的新作品" | `https://acts.qidian.com/2017/59433009/index.html` | **A** | **投稿时不得勾选"原创"**，须如实按同人发布——这是本书必须遵守的操作 |
| 起点活动规则禁止"使用、联动任何未授权作品的人物、情节、形象、名称、设定、世界观" | `https://m.qidian.com/chapter/1035241703/777111446`（2023 暑期活动投稿指南） | **A（该活动规则）** | 提示二创边界：本书已显著标注非官方，且改写 6 处 lore 硬伤避免照搬 |

| 同人小说建议直发（自带题材流量），内投通过率相对低 | 2026-05 新人攻略 `http://mp.weixin.qq.com/s?__biz=MzkxOTc0MjE5MA==&mid=2247483704&idx=1&sn=3067b2e4eb34b1e1f2230030d659c086` | **D** | 采用直发策略，不内投 |

**核验结论**：
1. ✅ **可投稿**——"同人可发布、游戏同人可参与、有官方衍生同人分类"是 A 级官方事实，无需再向起点书面确认。
2. ⚠️ **操作红线**——投稿时**不得勾选"原创声明"**（A 级官方声明排除改编作品），须按同人如实发布。
3. ⚠️ **客观边界**——商用签约后的授权范围、国外 IP 的长期连载容忍度无公开 A 级条文；D 级经验称属可写灰区、不扣 10%。此为实现事实披露，**不是待办、不构成法律意见、不承诺签约或收益结果**。
4. ✅ **本书已做的合规动作**：显著非官方声明、6 处 lore 硬伤改写、二设与考据锚点分表登记、不照搬原作具体事件台词。

| 项 | 说明 | 来源 |
|---|---|---|
| 同人性质 | 使用他人作品角色与设定二次创作，通常涉及原作改编权 | 《著作权法》相关条款，须由持证律师核实 |
| 商用风险 | 起点签约分成/全勤属商业使用；国外 IP 长期连载的授权边界无公开 A 级条文，属客观灰区 | 见 §3.0 核验结论第 3 条 |
| 免责标注 | "非官方同人、与原作方无关联"可降低混淆，但不必然免除侵权责任 | 通用法律科普口径，非法律意见 |
| 稿酬 | 国外游戏 IP 同人，D 级经验称不扣 10%（仅限阅文自有版权 IP 才扣） | 见 §3.0，非官方合同文本 |

**执行要求**：
1. 每本书籍页与正文首章顶部保留免责声明（已在 `00-作品总览.md` 与正文落盘）。
2. **投稿时按同人如实发布，不勾选"原创声明"**（A 级官方要求，见 §3.0）。
3. 采用直发策略，不内投（D 级经验）。
4. 本包不代做授权谈判；商用授权边界为已披露的客观事实，非待办。
