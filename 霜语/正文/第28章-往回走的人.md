# 第28章 · 往回走的人

往南走和往北走不是一条路。

她去的时候走的是北边的雪线，回来的时候选了南边——石片地图上的另一条路。法仁加把路画得很清楚：从河尽头往东，绕过风隘，过灰烬渡口，回白漫。

她一个人走。

不，不是一个人。她现在能听见很多人——不是声音，是那种在身体里叠着的、很轻的存在。她走路的时候能感觉到多了一双脚，迈步的时候能感觉到多了一双手在摆。

她起初不习惯。她走在雪地里，觉得自己的身体里住了太多人，挤得慌。

后来她习惯了。

「你们挤一挤。」她说。

答她的声音从胸口来，很多个，叠在一起："好。"

她笑了。她现在经常笑——不是因为高兴，是因为她发现，一个人走了一路以后，身边有人说话，是这种感觉。

第四天，她回到了灰烬镇。

镇子还是老样子。一条街，两边各十几间屋子，街尽头是那座石桥。桥下的河冻着，黑水在冰底下走。

她径直走到河湾。

那块石头还在——她刻过名字的那块，半埋在雪里，朝着南边。她走过去，蹲下来，把雪拨开。

名字还在。那个她刻了很久、刻完又盖上的名字。

她看着那个名字，忽然发现她想起来了——那个人叫什么，从哪来，为什么叫她那个名字。

一切都在她脑子里，清清楚楚：

他是从帝国那边来的，一个普通的兵，在海尔根行刑队里站过。那天火烧起来的时候，他看见一个女人从人群里往外爬，就跟着跑了。他追了她一路，追到河湾，看见她跳下去。他也跳下去了。

他把她捞上来，把蛋拿走，自己沉下去——不，他没沉下去。他往上浮的时候，被水底的东西抓住了。他挣了很久，最后把蛋往上一抛，抛到岸上，自己被拖下去了。

他喊了一声她的名字。

她没听见。她在岸上昏着。

他一直以为她没听见。

海尔薇蹲在石头前，把手放在名字上。

「我听见了。」她说。

风从河面吹过来，很冷。她把那块石头从怀里拿出来——现在上面刻着三行字："我在，你也在，他也在。"

她把石头放在那块刻着名字的石头旁边。

两块石头靠在一起。

「你沉下去以后，一直在叫我。」她说，「你叫了很多年。我后来听见了——在石头里，在水里，在一个词里。我一直答，但我不知道答的是你。」

「现在我知道了。」

她坐在雪地里，靠着那块石头，坐了很久。

她没有哭。她只是坐在那儿，把那块石头握在手里，听那些叠在一起的声音——"我在，你也在，他也在"。

后来她站起来，拍掉身上的雪，走到桥上。

桥栏杆上刻着很多名字。她上次来的时候看不清，这次看清了——最靠边的一个，就是他。不是那个刻在河湾石头上的名字，是另一个，更短的，是他自己刻的。

他在桥上刻了自己的名字，然后跳下河去捞她。

海尔薇把手放在那个名字上。

「我记得你了。」她说。

她转身往镇子里走。走到街口的时候，一个补网的男人抬头看了她一眼——不是索恩，是灰烬镇那个补得很快的老人。他看见她怀里抱着石头，笑了笑。

「回来了？」他说。

「回来了。」

「北边怎么样。」

「有一条龙，带着一条小龙飞走了。」海尔薇说，「往北。」

老人点点头，像听见了什么早知道的事。

「他们都会回来的。」他说。

「谁。」

「龙。」他说，「走的人。名字。都回来。这儿是灰烬镇——烧过的地方，什么都留得下。」

海尔薇站在街口，看着他补网。他的手很快，一根线穿过去，再穿回来，网眼一个接一个。

「你补网补得很快。」她说。

「慢了就补不完了。」

「索恩补得很慢。」

老人抬起头。

「你认识索恩？」

「在渡口见过。」

「他是我弟弟。」老人说，「他补得慢，是因为他不想补完。补完了，就没理由坐在那儿等了。」

「等什么。」

「等人从北边回来。」他说，「他等了很多年。后来他不耐烦了，就去了渡口。渡口人来人往，总有人从北边来。」

海尔薇的手指动了一下。

「他还在渡口吗。」

「不知道。」老人说，「很久没回去了。」

海尔薇想起灰烬渡口的索恩——那个补网补得很慢的男人，那个说"想被找到的人会留下痕迹"的男人，那个卖给她补眠药、又提醒她药会吃掉记忆的男人。

她一直以为他只是个商人。

「他等的是谁。」她问。

「一个从海尔根出来的女人。」老人说，「他说她会经过渡口，往南走。他说他要告诉她一件事。」

「什么事。」

「不知道。」老人说，「他没说。他只说，等她来，就告诉她'别信那个声音'。」

海尔薇站在街口，风把她的斗篷吹得猎猎响。

「别信那个声音。」

她重复了一遍这句话。

「他说这话的时候，我还小。」老人说，「我笑他，说哪有什么声音。他说你以后会懂。后来我懂了——我见过很多人从这个镇子经过，每个人都在跟自己说话。有些人跟死人说话，有些人跟石头说话，有些人跟自己身体里的什么东西说话。」

他看着海尔薇。

「你也在跟谁说话。」

海尔薇没有回答。

老人低下头，继续补网。

「他让我转告你一句。」他说，「如果你来了，就告诉你——'别信那个声音，要信那个答你的声音。'」

海尔薇站在街口，很久没有动。

「答我的声音？」她轻声问。

「他说，问你的声音可能是假的，但答你的声音是真的。」老人说，「因为问的人想让你去，答的人只想你在。」

海尔薇把手按在胸口。

石头是温的。那些叠在一起的声音在她身体里，很轻，很稳。

「我知道了。」她说。

她转身往南走，走出镇子，走上那条来时的路。

风从北边吹过来，带着河水的味道。她走了很久，忽然停下来，回头看了一眼灰烬镇——那条街，那座桥，那些低矮的屋子，在灰天里缩成一小团。

「索恩。」她说。

答她的声音从胸口来："我在。"

「你弟弟说，你在渡口等我。」

"我在。"声音又说了一遍——这一次，答的人不是索恩，是那些叠在一起的声音，是那个位置，是所有人在答。

海尔薇笑了。

「那我去看他。」她说。

她改变方向，往渡口走。

她走了一天一夜。到渡口的时候，天快黑了。渡口还是老样子——几艘破船，一个歪掉的码头，几个等着过河的人。

索恩在。

他还是在那儿补网，补得极慢，一根线穿过去，要停很久才穿回来。他抬头看见海尔薇，愣了一下，然后笑了。

「你回来了。」他说。

「你等我很久了？」

「很久。」他说，「从你第一次买了我的斗篷那天起。」

「你那时候就想告诉我？」

「不是。」索恩说，「那时候我还不确定。你第二次来，问我守墓人的事，我才确定。」

「确定什么。」

「确定你在跟一个声音走路。」索恩说，「因为你问'如果我找的人不想被找到呢'——那不是问守墓人的话，那是问你自己的话。你在问：那个声音是不是不想被我找到。」

海尔薇站在他面前，没有说话。

「我哥哥让我告诉你一句话。」索恩说，「他说的原话是：'别信问你的声音，要信答你的声音。'」

「我弟弟跟他一样，也这么说。」

「他们都说对了。」海尔薇说。

「什么对了。」

「问我的人，是那个声音。」海尔薇说，「他问我'有人吗'，我答了'我在'——从此我就一直被他问，一直答，一直走。我以为我在跟着他走，其实我在被他问着走。」

「那答你的呢。」

「答我的，是我自己。」海尔薇说，「还有那些人——阿尔卡、法仁加、托尔、那个第一个叫我在的人。我说'我在'，他们答'你也在'。他们从来不问我往哪走，他们只答我在。」

索恩看着她，看了很久。

「那你现在往哪走。」

「往南。」海尔薇说，「回白漫。然后一直走，走到没有路为止。」

「不找了？」

「找。」海尔薇说，「但不找那个声音了。我找那些答我的人。」

索恩低下头，把线穿过去，打了个结。

「你比我想的走得远。」他说。

「我走了很久。」

「你身上有那个词了。」他说，「不是石头里的——是你自己的。」

海尔薇把手按在胸口。石头是温的，那些声音在，很稳。

「是。」她说。

她转身往南走。走出几步，她回头看了一眼——索恩还在补网，补得极慢，像这辈子都不打算补完。

「你不补完了？」她喊。

「补完就没理由坐着了。」他说。

「坐着等谁？」

「等从北边回来的人。」他说，「现在等着了。」

海尔薇笑了。她转过身，往南走。

风从背后吹过来，推着她。她走了很久，拿出石头看了一眼——

上面的字又变了：

"我在，你也在，他也在，她也也在。"

字挤在一起，快要写不下了。

海尔薇看着那些字，忽然笑了。

「挤一挤。」她说。

答她的声音从胸口来，很多个，叠在一起："好。"

她继续往南走。
