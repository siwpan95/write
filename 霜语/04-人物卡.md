# 04 · 人物卡 —《上古卷轴：龙临堡的第九种死法》

---

## A. 主角卡 · 海尔薇·霜门

### A1 速查
低起点（幸存者、右手曾残、无补给）+ 唯一专长（听得见"那边"）+ 明确困境（不知道那头是谁，也不知道自己在被拿走什么）

### A2 基础档案
| 项 | 值 |
|---|---|
| 姓名 | 海尔薇·霜门（姓为自取，日志原文："姓不重要了，霜门是我自己取的"） |
| 年龄 | 20 出头 |
| 出身 | 不明；海尔根行刑队的旁观者/囚徒，卷一不交代 |
| 此刻状态 | 从海尔根火中逃出第三日；右手功能刚恢复；肋下有灼痕 |

### A4 欲望—恐惧—错误信念三角
| 项 | 内容 |
|---|---|
| 欲望（ conscious ） | 活到白漫，找到阿尔卡，弄明白身上的火 |
| 恐惧 | 死的时候没有人在；"那边"不说话了 |
| **错误信念** | **"只要我照着那头说的做，就能活下去"**——这个信念在卷二被打破，卷六被反转 |

### A3 性格图谱七件套
- 嘴上硬、心软；砍价、怀疑、反问都快，但别人一求助就留下
- 不说"谢谢"，说"我在"
- 叙述习惯：短句，观察先于判断；对异常的第一反应是"记住"，不是"评价"
- 情绪从不直说，落到手上：攥紧、发抖、指节发白、把石头握出红印
- 有黑色幽默：狼把她吓倒，她起来第一句是"我不想数"
- 不轻易信人，但一旦把某人划进"我的人"，会一直记着
- 对自己人不设防——这是她的致命漏洞，被"那边"用了八次

### A5 能力与持有
- 能力：龙语读写（本能）、6 阶金手指（见 `03` §六）、极强的方向感与警觉
- 持有：龙语水晶、石片（龙石拓本）、短刀、深褐斗篷、补眠药（未喝）

### A8 成长轨迹（6 卷）
| 卷 | 状态 | 转折 |
|---|---|---|
| 一 | 被声音牵着走 | 发现声音也会怕、也会错 |
| 二 | 开始反问 | 吞龙魂，第一次自己发吼 |
| 三 | 主动沉默一次 | 用"不说话"夺回主动权 |
| 四 | 学会谈判 | 主题句"不是杀，是谈判" |
| 五 | 知道代价 | 发现"那边"在遗忘自己 |
| 六 | 自己成为"那边" | 说出"你也是"，完成身份互换 |

### A9 四维弧光
| 维 | 起 | 终 |
|---|---|---|
| 认知 | 有人替我安排就好 | 我要自己选，包括选不听 |
| 能力 | 只能听 | 能沉默、能发吼、能被龙叫出名字 |
| 关系 | 需要有人陪 | 能陪别人走最后一段 |
| 道德 | 活下去就行 | 有些代价不能让别人替我付 |

### A10 镜像角色
**阿尔卡**：同样从龙焰里活下来的人，选择了"留下来守墓"；海尔薇选择"走出去"。两人是同一种伤的两种活法。

### A11 当前状态（卷一末）
`hp` 恢复中 / `warmth` 低 / `soul` 一路由消耗 / `trust` 高但已生疑 / 已进白漫城门

## B. 「那边」· 听者（配角卡 · 精简版）

| 项 | 内容 |
|---|---|
| 身份 | **全书最大悬念，不命名、不揭示、不给视角** |
| 已知线索 | ① 声音类专业判断（狼、绿烟、地形）过准，不像普通人；② 阿尔卡见水晶时说"灵魂链接，帝国末年的东西"；③ 海尔薇问名字時他反复回避；④ 每说一句就忘一点；⑤ 卷六结尾出现"你也是"的对称回应 |
| 声音标记 | 短句、祈使句多、爱说"我在"；回避问题时说"我尽量"；从不主动说"谢谢"，卷一末破例一次 |
| 动机（表层） | 让海尔薇活着走到白漫 |
| 动机（深层，卷六揭） | 他在补偿自己曾经做过的一个决定——那八次他没说话 |
| 功能定位 | **陪伴位，非攻略位**；不得写成后宫对象 |
| 硬限制 | 无图像、无触碰、不能出手、不能替她做决定（卷三破一次，付出代价） |

> ⚠️ 写作纪律：任何章节不得给"那边"内心视角、不得写出他的名字、不得让他直接解决战斗。违反即破悬念。

## C. 配角

### 索恩（灰烬渡口补网人）· 二设原创
- 功能：交易、信息、镜像试探者
- 声音：先报数后说话；句子短；从不免费帮忙，但收费永远低于市价
- 关键动作：一眼认出海尔薇"是从北边来的"，并暗示"他也应该在海尔根"
- 与海尔薇关系：互相试探，彼此都没说真话；卷五可作为白漫内战线的中间人回归
- 反制：他只对"活着回来的人"有兴趣——海尔薇一旦失败，他会立刻消失

### 法仁加（龙临堡法师）· 借官方名，行为二设
- 功能：带路、给出"响应"这个词、把石片交给海尔薇
- 声音：陈述句，专业术语多，但越往下走越短
- 内核：他挖了很久，什么都没挖到，所以看见海尔薇时像看见答案
- 风险：不得把他写成全知者；他只会给出"他亲眼见过的"

### 阿尔卡（白漫守墓人）· 二设原创
- 功能：终局接引人；海尔薇口中"我在这座城里的一个人"
- 声音：极少说话，说就一句；烧纸时不抬头
- 关键台词（游戏日志原句）："灵魂链接。帝国末年的东西。还在用？"
- 与主角关系：哥哥/旧识（书中不明说，靠"一个人"与"她哥哥"的口误暗示）
- 出场：卷三末，卷四正式；不在卷一–二出现

### 格丽塔（卖药老太婆）· 二设原创
- 功能：西门落脚点；给主角"睡一晚又不被盘问"的安全区
