## 三、本书专属技法（从日志提炼）

### 3.1 "那边"的台词呈现
- 用「」直呈，**不加"他说"、不加提示语、不加引号外的解释**
- 读者通过位置辨认：海尔薇的发言带动作或"她说"，那头的发言是独立成段的裸「」
- 例：
  > 「听得见。」海尔薇说，「一直听着。」
  >
  > 「……谢谢。」

### 3.2 状态体感化（**不写数值**）
| 状态 | 禁止写法 | 本书写法 |
|---|---|---|
| warmth 下降 | "体温降至 20" | "手指终于能弯过来" / "斗篷里面还是硬的" |
| hp 下降 | "生命值剩下 3" | "她笑的时候肋下抽了一下" |
| soul 消耗 | "soul -1" | "水晶暗了一分" / "她想不起那个答案了" |
| trust 上升 | "信任 +5" | "她没有再问为什么，直接走了" |
| clock 推进 | "时钟 14→15" | "天快亮的时候" / "第二天早上" |

### 3.3 重复的节奏器
日志靠重复句式制造窒息感。本书保留三句作为节奏锚：
- **"我在。"** —— 全书的呼吸，每章至少 1 次，卷六反用
- **"我尽量。"** —— 那头的回避，出现 5–8 次，最后一次必须反转
- **"你先走。"** —— 隐瞒的信号，出现 2–3 次

### 3.4 情绪两写法
不写"她很生气"，写：
1. 手部动作：攥紧、指节发白、把石头握出红印
2. 具体物件：斗篷上的灰、鞋面的裂口、冻硬的刀鞘

### 3.5 冷幽默（替代笑点）
日志里海尔薇在极冷场景下仍会自嘲（"我不想数"）。本书用她的黑色幽默填"轻松段"功能位，不写段子、不写网络梗。

## 四、禁用词（两级红线）

**逐词上限（每章，硬上限）**
| 词 | 上限 | 理由 |
|---|---|---|
| 仿佛 / 宛如 / 好似 | 0 | 比喻腔，破坏冷硬 |
| 不禁 / 不由得 | 0 | 书面腔 |
| 深吸一口气 | 1 | AI 高频 |
| 眼神复杂 | 0 | 情绪直说 |
| 意味深长 | 0 | 同上 |
| 空气仿佛凝固 | 0 | 套句 |
| 他知道，这一切都 | 0 | 全知腔 |
| 要知道 | 0 | 说教 |
| 一丝 / 一抹（+抽象名词） | 各 1 | 泛滥 |

**总量兜底**：单章命中以上总数 ≤2；每万字 ≤5。

**破折号**：每章 ≤3 处；禁止连续两段都用。
**形容词**：一段内不超过 2 个；优先用名词和动词。

## 七、去 AI 味五步（改稿用）

1. **删解释**：凡是"因为……所以……"能删就删，让动作自己说明
2. **换感官**：把"他很冷"换成"他把两只手塞进腋下"
3. **加具体**：把"一个地方"换成"离城门二十步"
4. **减形容词**：一段两个封顶
5. **破对称**：禁止"A像B，C像D"的排比惯性
