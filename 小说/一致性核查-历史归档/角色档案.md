# 角色档案（一致性核查 · 标准化）

> **用途**：给每个主要角色建标准卡，覆盖「姓名 / 年龄 / 性格 / 动机 / 能力 / 弱点 / 背景 / 关键道具」八项。
> 后续写正文时，所有行为都拿这张卡对照「像不像他会做的事」。
> **单一事实源**：`bible/characters/*.md`（记"人"）+ `bible/world-bible.md` §2f（记主角"数值"）。本档案是从各卡 distill 出的统一口径，冲突以 bible 为准。
> **覆盖角色**：魏成河 / 魏小雨 / 魏青山 / 老周 / 阿芸 / 疤脸刘 / 瘦猴 / 赵珩 / 铁手 / 白褂 / 低语者（共 11 人）。

| 项 | 内容 |

| 动机 | 短期：治小雨的眼、躲李氏悬赏、学会控制法力；长期：兑现对实验体"你那个位面，我替你去看一眼"；隐性：证明"上去"不等于"走掉" |
| 能力 | 旅法师面板（火花已点燃）、乙太感知 Lv.2、蓝系解析/反击法术、黑色代偿（烧记忆换力）、位面行走、弱点解析、异族感知；数值见 §2f |
| 弱点 | 软肋＝魏小雨与前世的孤独（无人收尸）；黑色法力代价＝每用一次失去一段记忆/情感且不可复原；身体左臂 35 格灰线读条（位面污染） |
| 背景 | 现代地球社畜穿越为废土底层少年；前世写过一个万智牌同人外挂【鹏洛克速成指南】的"个人面板"模块，没测就死了——面板是他前世的产物 |
| 关键道具 | 旅法师面板（绑灵魂）、乙太节流阀（为小雨刻于眼底，非自身）、后颈灰痕（虚空指路、对白褂"认亲"发烫）、虎口旧疤（D4 烧后看得见说不出来历） |

**一致性校验要点（写他之前必读）**：
- 他做决定时心里有数字（配给券、工时、火花%、还差几天），写"他算完的结论"而非"他犹豫了很久"。
- 对家人承认"我变了"但不解释穿越与面板（第 29 章定例）。
- 他的温柔是动作（留灯、把糊推过去、挑出碗里那块），不写"他很爱妹妹"。
- 他的狠是平静的（第 37 章划掉"击杀"、第 88 章虹膜写"已死"）。
- 失忆**不许写独白**，必须写成能力退化 / 行为变形 / 习惯丢失。
- 网络梗仅限内心层与对家人脱口而出的半句，禁止叙述层与配角对话层。
