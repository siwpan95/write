# 世界观设定标尺（一致性核查）

> **用途**：把故事世界的物理规则、社会规则、特殊设定固化成"可判定形式"，作为判断情节是否自洽的**标尺**。
> 写正文 / 改设定前，先用本标尺逐条对一遍；任何新设定若违反下列规则，须先回 `world-bible.md` 登记并说明，不可私自加。
> **单一事实源**：`bible/world-bible.md` §2（R1–R15）、§2c（经济）、§2b（道具）、§2f（面板）、§3.5（位面命名）、§7（变异谱系）。本表是其"可判定"提炼。

---

## 一、物理规则（确定性校验 C4 的来源）

> 每条都写成「条件 → 结果」的可判定形式，便于机器比对。

| 规则 | 可判定形式（条件 → 结果） | 出处 |
|---|---|---|
| **R1 异族判定** | 辐射诱变生物发生"本质变异" → 面板判为"异族"；仅体型增大 → 不判 | §2 |
| **R2 火花来源** | 击杀异族 → 面板吸收异质性凝物转火花；普通生物击杀 → 火花=0 | §2 |
| **R3 面板绑定** | 面板绑宿主灵魂；宿主死 → 面板随灵魂转移新宿主 | §2 |
| **R4 原力觉醒** | 原力觉醒者在生死边缘 → 有概率觉醒（约十万分之一） | §2 |
| **R5 功能解锁** | 火花达特定阈值 → 逐步解锁功能（明细见 §2f 总表：20%异族感知→25%加点→30%灵敏→40%精神→45%突破→50%共鸣→54%弱点解析→58%残影→100%点燃） | §2 |
| **R6 辐射质变** | 辐射超临界 → 质变（异族化，一级及以上）；低于临界 → 仅体型增大（零级） | §2 |
| **R7 虚空耐受** | 鹏洛克在黑暗虚空停留超当前耐受上限 → 被熵力撕裂（第二卷7分，每卷+2，递增表见 §3.5） | §2 |
| **R8 点燃后** | 火花点燃后不再增长；力量增长改走"汲取多位面法力" | §2 |
| **R9 黑色代价** | 黑色法力以记忆/情感碎片为燃料，一次消耗一段，不可复原 | §2 |
| **R10 非鹏洛克禁入** | 非鹏洛克进入黑暗虚空 → 被瞬间撕裂（不可带人穿越） | §2 |
| **R11 污染加深** | 虚空耐受上限与黑色代偿档位仅能通过位面污染加深（F12）提升；越能扛越不像人 | §2 |
| **R12 界→墟** | 位面界内活体密度归零 → 改称"墟"；墟中任何击杀火花=0 | §2 |
| **R13 组合税** | 五色法力组合（两色叠加）额外消耗"结构税"；组合越复杂，灰线增长越快（第三卷引入） | §2 |
| **R14 外域规则** | 外域中五色法力均等，任一色法术不增益；本土力量（原力/义体/基因）不受影响（第四卷启用） | §2 |
| **R15 点火归位** | 白塔五色种火可由"被记住的名字"点燃，一个名字一分，不设上限（第五卷启用） | §2 |

**标尺用法**：若正文出现"带普通人穿越虚空"→ 违 R10；"击杀普通变异兽掉火花"→ 违 R2/R6；"火花超过100%还在涨"→ 违 R8；"外域里蓝法术特别强"→ 违 R14。

## 三、特殊设定（力量 / 位面 / 道具）

### 3.1 力量体系三轨

| 轨 | 核心 | 可判定边界 |
|---|---|---|
| 旅法师面板（主角） | 火花→100%→点燃→鹏洛克；点燃后走法力池+五色法术 | 成长阶段：火种期(0-100%)→点燃→新晋鹏洛克→成熟鹏洛克 |
| 原力（大哥，本土） | 基因+生死边缘觉醒；外域反而唯一可用 | 挡不住位面级攻击（第75章） |
| 四大飞升（本土） | 基因/合成/灵能/义体；李氏垄断基因飞升 | 灵能失败者变疯子；义体人性流失 |

### 3.2 五色法力（点燃后）

白(秩序/守护)·蓝(知识/理性·主角主色)·黑(野心/代价)·红(自由/爆发)·绿(自然/成长)。主角双主色＝蓝+黑。

### 3.3 位面命名（§3.5 单一定义处）

| 层 | 正式名 | 后缀 | 判据 |
|---|---|---|---|
| 主位面 | **锈界**（废土所在） | 界 | 自持物质循环+可诞生火花载体 |
| 过渡层 | **乙太海** | 海 | 乙太感知Lv.2可见的"缝" |
| 位面间隙 | **黑暗虚空** | 虚空 | 非鹏洛克进入→一次呼吸内撕裂 |
| 已死位面 | **光桥墟**（实验体故乡） | 墟 | 活体密度=0 |
| 外层位面 | 五色境/野/渊 | 境/野/渊 | 无原生循环，单色维持 |
| 交汇枢纽 | **外域** | 域 | 五色均等，任一色不增益 |

**命名三铁律**：① 专名2-3字+1字后缀，全长≤4字，禁用人名/地名/英文音译；② 后缀先定（界/海/虚空/域/境/野/渊/墟）不可跨层混用；③ 禁仙侠词（霄/宸/太虚/九幽）、禁"死亡/毁灭/末日"直白字、禁叠形容词。
**标尺用法**：正文出现未在 §3.5 登记的位面名 → 违"位面名只取自 §3.5"。新增位面必须先在此登记。
