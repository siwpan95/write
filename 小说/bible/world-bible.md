## 1. 基础设定

- 类型：穿越 / 废土 / 系统流 / 科幻 / 力量成长
- 时代背景：平行世界地球，科技文明浩劫后约100年，废土时代
- 核心冲突：底层穿越者凭借旅法师面板崛起 vs 废土势力垄断与阴谋 vs 终局清算倒计时

## 2. 世界规则（确定性校验 C4 的来源，须写「可判定形式」）

- 规则 R1：辐射诱变生物 在 发生"本质变异"时 被面板判定为"异族"，普通变异（仅体型增大）不判为异族。
- 规则 R2：击杀异族 后 面板吸收其"异质性"凝聚物转化为火花，普通生物击杀 产出 火花为零。
- 规则 R3：面板绑定 宿主灵魂，宿主死亡时 面板 随灵魂转移至新宿主。
- 规则 R4：原力觉醒者 在 生死边缘时 有概率 觉醒原力，觉醒率约十万分之一。
- 规则 R5：面板功能 在 火花进度达到特定阈值时 逐步解锁。**完整阈值表见 §2f「面板功能解锁总表」**（20% 异族感知 → 25% 属性加点 → 30% 灵敏 → 40% 精神 → 45% 属性突破 → 50% 火花共鸣 → 54% 弱点解析 → 58% 位面残影 → 100% 点燃）。点燃后火花不再增长，故 100% 之后的成长改走「法力池 + 五色法术」路径（R8）。
- 规则 R6：变异生物 在 辐射剂量超过临界值时 发生 质变（异族化），低于临界值 仅 体型增大。**可判定形式**：辐射剂量以"变异等级谱系"（§7）间接判定——零级＝仅个体略大、无质变；一级及以上＝体型/甲壳/行为出现质变。**面板只对"一级及以上"产出火花**，零级产出恒为 0（第 6 章验证）。
- 规则 R7：鹏洛克 在 黑暗虚空 中 停留超过当前耐受上限 时 被熵力撕裂（第二卷 7 分钟，每卷 +2，递增表见 §3.5）。
- 规则 R8：火花 在 点燃后 不再增长；力量增长改为 汲取多位面法力。
- 规则 R9：黑色法力 以 记忆/情感碎片 为燃料，一次消耗一段，不可复原。
- 规则 R10：非鹏洛克 进入 黑暗虚空 时 被瞬间撕裂（因此不可带人穿越）。
- 规则 R11：黑暗虚空耐受上限 与 黑色代偿档位 仅能通过 位面污染加深（F12）提升；越能扛，越不像人。
- 规则 R12：位面 在 界内活体密度归零 时 由"界"改称"墟"；在墟中 任何击杀 产出 火花为零。
- 规则 R13：五色法术的**组合**（两色叠加，如蓝+白）额外消耗一份"结构税"——组合越复杂，位面污染（灰线）增长越快。**这条是"变强即污染"的机制化**。（第三卷引入）
- 规则 R14：**外域规则**——五色法力在 外域 均等，任一色法术 不增益；**本土力量（原力/义体/基因）不受影响**。外域因此是主角的弱区、本土路线的主场。（第四卷启用）
- 规则 R15：**点火归位规则**——白塔五色种火 可由"被记住的名字"点燃；一个名字一分，不设上限。这是"人是燃料"（F13：记忆/情感碎片当燃料）的**反面**：同样是人，一个被烧掉当燃料，一个被叫出来当火。（第五卷启用）
- 规则 R16：**递梦机制**——乙太侧存在 可向 天赋接收者（接收器过载型乙太感知，如魏小雨）定向递送梦境；递送节奏为"一夜多一段"（与实验体经共鸣通道传梦的"一夜灌完"相区分——砸是往死里灌，讲是怕你不懂）；同一梦内容夜夜复现、可复述可记数；梦受者听觉优先，声源（翻纸声、水声）为主要信息通道。（第三卷98章启用；L9 的机制基础）

## §2g 第三卷·承境位面细则（109/111章落地）

### 械理境·"不用手搭的架"（109章）
- 形制：一节一节咬合，**上一节是下一节的榫、下一节是上一节的卯**；节节坐在下头的槽口里，靠自重与斜纹咬住，**不用钉、不用绑、不用手扶**。
- 关键工艺三条：①榫头过松时不可硬推，改**从上方松手让它自落**（自重＋卯眼斜纹自己带进去）；②手僵时改**绳＋楔**（绳吃住那一下，绳不需要手）；③活扣三圈——**力气越大越紧，摔一下反而更牢**。
- 血手印：主角每上一节按一道，共74道，按到后面的是压出来的印子（看着重、擦不掉）。
- 失败处理原则：**退出来的东西不接回原位**——退到第5节就从第5节重来。
- **代价物证**：74根料磨了3处榫头（补那半分），右手虎口裂一道、指节背面两道蹭破；七十四下抖，架没动。
- 悟点（**主题落点**）：他搭通了，却**没有懊恼**——词到嗓子眼没出来。"他从前不是这样的"。**变冷从这一笔起**。

- **"半寸"的真相**：格退半寸即停＝底下有坎，**不是人在拽，是格自己让出来的**（热的东西留缝，留缝是为了让它自己走完那半寸，走完不受力不裂）。那半寸是留给来的人的。

- **形制**：残响图书馆的大账翻到某一页，页上是一栏一栏的**方格**，密到看不见尽头；每一格蒙一层东西（像窗纱，又像灰），灰上有一道一道**竖痕**，每道一样长、从格顶贯到格底。
- **记法**：残响用指头划格。**第7格起格里有字**（字是**压**出来的，从格底往上凸，边上一圈极细毛边）；第8、第9格也有字；**划到第19格停住，只敲两下，格里的灰不收**。
  - 第7格那个字的结构：**左边一竖，右边三横，中间那一横比上面那一横长出一截**（他记下了形状，不认得）。
  - 主角当场拆穿两条：一是落笔节奏（前18格一样重、一样快，第19格只敲两下），二是范围（"你在我腰上数到四十七，往下那十四格你没数"）。残响未否认，账自己翻回前一页。
- **两条数并存**：页脚压出一行**十一组数目**（＝"用了几回"），第十一组底下跟着**第12个空格**（还没被收过）。空格下另有一栏，纸被压薄过一层、停手没压穿（＝有人在他之前也数到这里，没压穿）。
- **那一条空出来的凉**：指头压在第12个空格上，摸到一层极薄的凉，与格谱底面那层同源、同样**止于一处**，凉不往指节上走。
- **残响的动作应答**（它不说话，全部用动作）：
  - 手往胸口按一下再往外推 ＝"你问的不是用了几回，你问的是谁在用"
  - 双臂抬到齐肩往两边一分 ＝"我在废土上"
  - 整页的灰往下走一寸又退回来，走的那一寸里十一组数目全亮一下 ＝"十一组是它自己划的，第十九个是别人写上去的"
  - **它能答的都答完了；"后来呢"不答**——账上没写完的那一栏它不碰。
- **结论（F9 半个答案）**：面板不是外挂，是一件**留在废土上的东西**，谁先捡上谁往里写。他胸口这个占**第19格**；前18个是它自己划的，第19格落笔的是另一个人，那个人也捡上过、也数过、也在废土上。
  - **推论**：面板＝账上的第19格；左臂灰线＝"走到哪儿了"那一栏（61格）。**两笔记在同一本账上**——一笔记"用了几回"，一笔记"走到哪儿了"。
- **同章落地（F7 回退）**：半张乙太频谱贴上手套内衬后**不在了**；缝里长出比该有的长度多出一截的空缝，贴得比别处平。他记得自己贴过，不记得贴了多久、也不记得贴的时候是什么样。
- **同章落地（小雨判据）**："壳不能闷着。闷着的那只手，是没有在干活的那只手。"——据此决定当天装不装铁手的滤量壳（当日两只手都在干活 → 不装）。

### 二、南街地下的三样东西（116章）

- **白地段**：三路口往里三尺一片发白的地皮（白得平）。踩上去**不留鞋印**——主角连踩三下都留在原来的白上，一层压一层，土不动。往土里按半寸，指头底下顶上来一层**网**：细到摸不出单个格，只摸得出有密度；往上抬它就跟，抬到与土面齐平停住。
  - 老周判语：**"白的地方它已经数过了。"** 主角按住那片土时顶手的那层，是"它在底下接着"。**它在接人。**
- **窖井**（南街尽头，早年封了）：石板被挪开一尺斜靠井台、砖头滚在两尺外，砖面沾泥。**石头是温的，但不是太阳晒的那种温**——太阳的温在面上，井台的温在底下。
  - 用**左手的骨头**贴石板（不是听）：左手贴到一层一层的东西，**格与格之间有一道极细的缝，缝里的气比缝外的气凉**；换右手贴过去是一整块，什么都没有。
  - 井里不是黑的。井壁中段有一层绕壁转的光，一圈两三分钟。数到第二圈光断一次，井底有响声往上顶——**声音是从上头来的**，是井壁底下有什么东西在往上顶、顶到壁、壁把声音弹回来。
- **老周自井底上来**（子时上来，带一身土，扫进簸箕倒在坑里，对媳妇说"去看水"）。他交的口径：
  - 它要的就是**有人上来看看**；"它知道有人上来了。**它分不出来是谁。**"
  - 它从底下走了**十八年**；上来过**三回，三回都是撞**，撞完下去，下去一次安静两年（第三年不安静，第五年撞第三回）。**今年是第四年。**
  - **上一次是往上传**（三年前撞穿隔离层，公司用能量武器压回去）；**这一次是往下顶**。
  - 底下有一个**没有图纸的池**，自打打通就有；池壁是照着什么东西浇的，浇时用了**三批料**——头一批不对，第二批换配方，第三批才把缝堵住。
  - 下去过的只有两个人：**十八年前下去的那个没上来**（穿的罩衫是新的）；**三年前下去的那个上来了，是魏青山**（"他那左肩现在还抬不过头"）。
  - **它撞的方向不是出口，是声音**："三年前它是往上传的。它顶的方向不对。它不是朝着出口顶的，它是朝着声音顶的。"——三年前主角在新棚户区那头砸铁桶引怪，**那口井就在那声落地的正下方**。
  - 今天停手的缘由：**它数到了不该数的**——井台底下那一块，三年前它撞了一夜、压回去、压不住的那一口；它今天往下顶就是想去够那块，顶了一夜没够着。**"天亮它眼睛不好使。"**
- **破土而出的那几根东西**：断墙前移一寸，墙根那块被蹭了**十八年**的铁板从底下翻起来，掉在土上的东西比头发粗、比铁丝软，**蜷成一个个小圈，每个圈心都空**。
  - 老周判语：**"这个不是根。根是往下扎的。这个是横着长的。它横着长是为了找东西。"** 他用钎子尖碰了一个圈，圈心带上來一层土。**"它不咬人。它只是数。"**
- **那口井台边掉下来的砖**：砖上一个孔，**不是虫蛀的**——孔从一面进去从对面出来，边上被磨得发亮，直径不到一分。**它从底下顶，顶的是这块砖。** 主角收进口袋（117章用它比对灰线，见下）。

### 三、王（117章首现身，E2）

- **形制**：
  | 项 | 形制 |
  | - | - |
  | 高度 | 比人高半个头还多；肩宽到两个他并排都不够 |
  | 胳膊 | 两条，垂在身体两边；前端没有指头，是一整片斜着的壳面，末端搭到膝盖下头；走路不摆 |
  | 头 | 一个圆的壳顶。**没有脸**——没有眼、没有嘴，只有一层壳 |
  | 缝 | 壳上有一道**竖的缝**，从上头下来，到壳顶的一半就没了。开＝有东西出来；开合次数是它的计数 |
  | 壳纹 | 横纹从脖子底下排到腰，腰以下换成密的竖纹。**横纹是被压出来的，不是长出来的**（主角数到二十一道，压得横竖一样深，压在什么上他不知道）|
  | 脚 | 陷在土里到脚踝。**抬脚之前不落脚**，抬起来以后往前送出去，落下去时脚底先碰到土，土往两边让开 |
- **它现身的方式**：土**不是裂开**，是那一片自己往两边挪，挪到能让出一个人的宽度，停住。土不落回去，就停在那儿。
- **感知方式**：**它看不见东西。它看的是壳面上的变化。**
  - 他举右掌朝上 → 壳顶偏一分；他放右掌 → 壳顶回正。
  - 他举左掌（掌心里什么都没有）→ 它照样偏。
  - 他把左掌往它那边**送出去一尺** → 缝**合上**（合得很慢，合到底后不再开）→ 它朝他**低壳顶半尺**。
  - 他把右掌举到肩高往前推，推到一半停住 → 缝**开得很久、不合** → 从缝里出来一根丝。
  - 它走路的跟进速度＝**他退它退、他进它进**，"它不高，也不矮"。
- **它数的是什么**：**它数的不是他，是他左臂上那些格。** 它隔着衣服数出来了，**从腰往上数到四十七格就停**。它数完没有再动。
- **清点方式（本章记忆点：它不攻击，它清点）**：
  1. 抬起右胳膊，抬到肩高就停，把斜壳面朝下往脚前地上**按**下去；按下去的同时它**跪下**（跪着比站着高，壳顶与他坐着时齐平）。
  2. 地上留下一个**方的印**：比掌心大，边上齐整，四角没有一处是圆的。
  3. **隔一掌按一个**；第一到第七的间距与第八到第九的间距一样。
  4. 按的时候壳顶的缝**开合次数不是一定的**：第三个开一次、第四个开两次、第五个开三次。
  5. 它把按地那只胳膊举起来、朝他**推一下**——推的方向不是指他，是往他脚边那一片土指；它指的是他刚才挪过来**坐过的那一块地**。那一块土上什么都没有。
     → **它在他坐过的那一块上，隔一掌按一个。它在数那一块地上有没有东西。**
  6. 按完第9个抬起胳膊，不再按；把两条胳膊收回身前，**低头把壳顶在地面上磕一下**，转身朝井。
- **第十个印**：不在那一排的前头也不在后头，**在斜下方三四步外**。那个位置上什么都没有。它指着那个印，把壳顶转回来，缝开一次合上。
  → **它数完了这一片，数出十个。它要数第十一个，那个地方现在还没有东西。**
- **它放出来的那根丝**：伸到一尺高在半空停住 → 垂到地上 → **落地不往两边散，立着** → 立三息后**自己往他这边走**（不是它走，是丝走）→ 前头挪到他鞋尖前一尺 → **分成两根** → 从土里往上抬，抬到一寸高停住。
  - 两根丝中间夹着抬出来的那样东西：**一块骨头，灰白的，比指骨粗，长不到一寸，一头是断的**。丝把它抬到一寸高停五息，然后一松，骨头落回土里。**那样东西本来就在土里**，不是从土里长出来的。
- **嗅觉两条**（本作"甜腥"第二次落地，与第111章枯索野的甜腥分家）：
  1. 它上来时身上带**土腥味，浓，浓到发甜**，他说完一句话以后就淡了，快得像有人把窗关上。**这是明面上的土腥**。
  2. 随后他的鼻子"换了一样"：**这辈子闻过的所有东西合起来又拆开的样子**——铁锈、湿土、油、剩汤、灰，加一段他从来没闻过、也不记得谁闻过的气味（甜的，往上走的）。进来了半息就退干净。
  → 他的判语：**"它在底下。底下有人待过。"**
- **网认人**：他把手按在第十个印的土上，网迎上来，**方眼贴上掌心，一个眼贴一块**；贴上来以后**不缠**，数了他一遍就往后退。
  - 退完，他两只手掌心的纹路里嵌着**方**——左手七个、右手七个，**一共十四个**，位置一头一头对着。攥拳时方的边缘嵌进肉里，有点疼。
- **它与灰线的对位（本章最重的一笔）**：他把那块带孔的砖贴到左臂上比对——
  - 四十七格满，第七节往上摸不着，从腰往上到六十一，六十一上面什么都没有。
  - **孔只有一分，不够数一格。**
  - 结论：**"它不是数格子的。它是数格子的东西的。"** 它蹭了十八年的那块砖上，有它蹭过的十八年。
  → 也就是说：**它数的是 F12 本身**。
- **本章收束句**：他这一路上被数了三回——配给站窗口那个不看人的手、残响账页的第十九个格子、它。**三回都不问名字，三回数完就走。**
- **当前动向（截至第117章黄昏）**：它不等天黑，朝井口走了两步，把壳顶往下低到那个盖着石板的缺口上，站着不动。井台上只剩石板和那块砖，砖面上的泥已经没有了。

### 四、四本账（第 207 章 · 全书唯一一次四方对账）

> **"白土区的账，不是李氏一本，是李氏、黑石、清道夫、教派，四本合一本。"**

矮桌是铁手用废甲板拼的，桌面有旧铆钉的坑，坑里积着灰。

| 一方 | 人物 | 守的那一笔 | 交付物 |
|---|---|---|---|
| **李氏残余** | 赵珩（+ 两个李氏旧部） | 清算令那笔 | 压着白土区清算令的账（朱划一格） |
| **黑石帮** | 抱臂者 | 地界那笔 | 白土区边界地界草图 |
| **清道夫公会** | 老周 | 母舰的道那笔 | 道图（肩上搭着条走远的灰） |
| **教派残余** | 低语者 | 念名那笔 | 那枚旧印（印面是同款花） |

- **加上主角、大哥、铁手、小雨 → 八个角，少一个不立**。小雨把八笔对应写满一页。
- 主角定调：**"对的不是谁欠谁，是白土区这四百一十七个人，怎么站着活。"**

  - 黑石帮抱臂者："地是白土区的，人是白土区的，这铁片护的也是白土区的。"
- **机制意义**：这是外传"任务式结构"的**原型**——四方各守一笔，缺一笔则账不成立。

### 五、四路不通（第 226 章 · 终局结构）

主角一整天在试"把它们弄通"，**结论是不通**：

| 路 | 载体 | 走向 |
|---|---|---|
| 原力 | 大哥按着塔底 | **走地** |
| 灰线 | 主角按住那道缝 | **走缝** |
| 手掌 | 417 人贴在塔四周 | **走铁皮** |
| 菌丝 | 王胸口那一小截丝 | **走壁** |

- **它们不通。** 这是全书对"合力"的最终回答：四条路各自成立，合起来仍不通。
- 主角同章的雾爬到第五格停住；第七格的响变轻。

### 六、四样留种（第 189 章 · **"名/耳/地/读"，由小雨一句记下**）

小雨原话（189 章，**这四字的连缀出自她本子**）：

> **"名我背，地它种，两样都留着，谁也不丢。"**

| 样 | 谁留 | 载体 | 落点 | 章 |
|---|---|---|---|---|
| **名** | 小雨 | 417 个名字背下 + 本子 | 188 背下 → 227 念名 → 230 领进门 | 188/227/230 |
| **耳** | 铁手 | 铁丝环（细铁丝盘三圈，环心嵌一小片铁） | 187 教 → 189 编完 417 只 | 187–189 |
| **地** | 王级异族 | 菌丝（白丝按进土里，土色深一层） | 189 白土区外废墟留种 | 189 |

- **铁手的环**：上环不疼，"凉一下，凉过那一下，你就能听见远处敲空管子的响"；**环不碰味，只碰响**——"你的味还在身子里，响只是替你听见，不替你忘"。
- **铁手的纪律**：**"你分出去的，我接着往下分……不用他蹲在跟前"**——**外传里铁手必须继续这样传手艺，不许他变成随叫随到的匠人**。

### 九、老周第三行（230 章 · **外传终点锚**）

1. 他先写"**不知道**"；主角说「我不知道往哪儿走」，他在两个字后头添一笔变成「**不知道往**」。
2. 又翻回前一页写下「**反面，洼地，能种**」。
3. 他自己的话：「**我不知道能不能到，我把我知道的写上去了**」。
4. 他对主角说：「**我按了十七年地，我这一辈子没人替我记过事，今天你替我记了一件**」。
5. 小雨记进本子：「**老周，第三行，不知道往。东三里，坡的反面，洼地，能种**」。

> **外传终点锚定句：「东三里，坡的反面，洼地，能种。」**
> **主角全书最后一句成形的话：「我记不住来处。可我知道往哪儿走。」**

### 十一、第五卷硬红线清单（写外传前必读）

1. 魏成河**不出场**（外传主角是陆平）。
2. **不新增能力**——外传里任何"新招"必须写成"有人教他"，不是"他忽然会了"。

5. **主角不恢复记忆、不找回本名**（陆平到最后一章也没想起自己叫什么）。
