# 人物：李氏残余（赵珩线）

> **外传任务结构的关键机制来源**｜"四本账"里的第三本

| 字段 | 内容 |
|---|---|
| 一句话内核 | **一群把白土区扫空的账房，如今自己替白土区记着一笔。** |
| 身份 | 李氏外派中层赵珩 + 两名李氏旧部；清算令后李氏在白土区的残余 |
| 守的那一笔 | 四本账之一——**清算令**（交付物：压着白土区清算令的账，朱划一格） |
| 当前状态 | 在世·编外"死人"；赵珩练走路，手背留方印 |

## 一、这是什么

第五卷第 207 章建立的一个**结构性机制**——全书唯一一次四方坐下来对账：

> **白土区的账，不是李氏一本，是李氏、黑石、清道夫、教派，四本合一本。**

矮桌是铁手用废甲板拼的，桌面有旧铆钉的坑，坑里积着灰。四路人、四种步子第一次落在同一张矮桌边。**八笔对完，四路人各守一笔**：

| 一方 | 人物 | 守的那一笔 | 交付物 |
| -- | -- | --- | --- |
| **李氏残余** | 赵珩（+ 两个李氏旧部） | 清算令那笔 | 那本压着白土区清算令的账（朱划一格） |
| **黑石帮** | 抱臂者 | 地界那笔 | 白土区边界地界草图 |
| **清道夫公会** | 老周 | 母舰的道那笔 | 道图（肩上搭着条走远的灰） |
| **教派残余** | 低语者（袖口同款纹的旧印） | 念名那笔 | 那枚旧印（印面是同款花） |

> 对的不是谁欠谁，是**白土区整片怎么站着活**。

## 二、李氏残余这一路的写法

### 群像特征
- **灰里泛青的衣裳**——不是制服，是李氏外派中层/旧部共有的那种洗旧的青
- **掌纹里嵌着洗不掉的墨**（赵珩）
- **手背上有很淡的方印**（方里一横）——李氏按过的那本把白土区扫空的账的戳
- 不带兵器，只带账

### 赵珩其人（第五卷终局）
- **签字习惯**：签十七年的名，落笔前都摸一下第一个指头——「一千多个名字都从这儿起的笔。摸一下，才敢落。」
- 练走路（洁癖式的自我规训）
- **手背上的方印保留**：主角说「**你们按过一本把白土区扫空的账，这个印该留着，本来就不该洗掉**」
- 结局判词：「**空是因为没人再按**」

## 三、机制意义（外传核心）

这四本是**"谁在给白土区记着什么"**的四条平行账：

- 李氏记的是**欠**（清算令：谁欠谁）
- 老周记的是**谁在这儿**（第二本账）
- 黑石帮记的是**地界**（线在哪儿）
- 教派记的是**名字**（念完就从"在数"里出来）

主角做的事是**把四本合成本**——而这正是外传"任务式"结构的现成骨架：
**每一项任务 = 找到账本的主人 = 让四本账对上**。

## 四、写作纪律

1. **李氏不是纯反派**。他们按的是"上头让按的"，方印是职务不是罪——但主角仍说"该留着，本来就不该洗掉"。**罪在制度，不在个人**。
2. **他们不点火**。白色种火那格是"收据"，收据亮不代表火在烧。**账和火必须分开写**。
3. **四色不是四栏，是四道竖的**（第 225 章硬设定）。四条里只有三条，**第四条的位置上铁是平的——平的那一条正好是第九格**。外传若画四本账，须与这道竖的结构对齐。
4. **外传用法**：这张矮桌是外传"第一幕"的天然场景。任何外传的开场任务，都可以从"再请一张桌、添第五本账"开始。
