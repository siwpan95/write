# 关键物件：第五卷新增（终局物证层）

> 正史五卷写完后新增的物件档案。**这些是外传的"任务道具"来源**——每件都带一个未兑现的动作。

## 一、四百一十七片薄铁（钥匙）

| 项 | 内容 |
| -- | ---- |
| 来源 | 主角把母舰点二口的**读取权**分成 417 份（205 章）。三道刻痕＝**高程一道斜、倾角一道更缓、周期一道最短横在中间**（207 章铁手在矮桌上当面说清） |
| 制作 | 铁手凿。**每一组三道，深浅不一**；最深的一组在正当中，是陆平划的——"那个记不起自己名字的人，划得最用力"（190 章） |
| 交接 | 主角一片一片递，最后一片给陆平。陆平问「你这个铁，上头的三道，是什么」，问完没再问，把铁片塞进怀里拍了拍压实——**和小雨收本子的动作一个样** |
| 功能 | 「这不是燃，是读，母舰点二口的读，你记着，就没人能偷偷开」 |
| 闭环 | 227 章点火的引子：格是空的，边是框，框在，格不在 |

## 二、小錾子（铁手 → 主角 → 刻"收"）

| 项 | 内容 |
| -- | ---- |
| 原主 | 铁手那把不抖的手的工具 |
| 交接 | 铁手 217 章坐担架来坡上捏铁边时，头一片上有**五道刻痕**（"第一个数是我说了算"） |
| 用处 | 220 章主角**在门正中那个方凹边上刻"收"字**——门开一寸，第九格那一格装了 417 片铁 |
| 意义 | **刻"收"的是主角，全书第一次由他落笔下账**（此前都是别人记账他看） |

## 三、李氏账板（冷库门口横铁框上）

| 项 | 内容 |
| -- | ---- |
| 形态 | 两块铁板焊的，水渗进斜缝 |
| 字迹 | 字被压平了，刮出来**十一道一横**（第十一道是两横）＝十七年的账，一年一列。**李氏只存了十一次，后六年在扫，第四栏没人碰** |
| 印 | 斜缝渗水露出一个方的浅印，印边上有**三个小凸起**（三道刻痕的起头） |
| 判词 | 「**格空着，名不空**」；「白塔顶上那一格是空的，底下那一格是满的。这不是一回事」 |
| 去向 | 搁在冷库门口的横铁框上，没扔——**留着当证据** |

## 四、门框八十二格（锚点）

| 项 | 内容 |
| -- | ---- |
| 是什么 | 主角第一天到废土时，他家那个门框上他自己刻下的**八十二格刻度** |
| 关键回环 | 第 229 章：**他认不出那面墙**（墙是甲板碎块垒的、火塘是九块石头围的、坡顶九根小木棍各压一块石头）——但**他认得门框上的刻度**。他一路都是靠它走的 |
| 原点 | 第一天他站在自家门口认不出那是自家的门，靠门框上那八十二格认路。第五卷同一件事再来一遍，他认出来了 |
| 一句话 | 「**他记不住来处。可他知道往哪儿走。**」 |

## 五、老周的第二本账

| 项 | 内容 |
| -- | ---- |
| 第一本 | 谁欠谁（清道夫工会的旧账，九栏土墙） |
| 第二本 | **谁在这儿**（巴掌大、甲板封皮上有九个圈的本子） |
| 第三行 | 一直空着。终局终于填上：先写「不知道」，主角说「我不知道往哪儿走」→ 老周在两个字后头添一笔变成「**不知道往**」→ 又翻回前一页写下「**反面，洼地，能种**」 |
| 判词 | 「我不知道能不能到，我把我知道的写上去了」；「我按了十七年地，我这一辈子没人替我记过事，**今天你替我记了一件**」 |

## 六、门缝那一寸（第七格）

| 项 | 内容 |
| -- | ---- |
| 位置 | 白塔第九格，门开一寸 |
| 塞进去的东西 | 主角从冷库顶板背面**揭下的一层薄到能透光的东西**，塞进去半寸（226 章） |
| 后来 | 小雨念名字时，**白覆住那半寸薄片，变成厚的、有弹性的一层**（227 章） |
| 终局 | **白色那一格是空的**——"格是空的，边是框，框在，格不在"；白是**长出来**的不是流出来的；从缝里出来分两股往上往下走、走到两头停住、边缘往回卷成一个圈，圈住整个口 |
| 闭合处 | 厚出一个方的印（方里一横分成三段），与李氏账板那个印、门正中刻"收"字那个方凹**同形**——这一格的印就是母舰点二口那一格 |
| 名 | 「**它有名字了**」——小雨在霜上写：「我记了四百一十七个名，里头没有一个是它。今天它自己有一个了」 |

## 七、母舰的邀请函（已兑现）

| 项 | 内容 |
| -- | ---- |
| 文本 | 「**你上来，我们就停手**」 |
| 纸张 | 发硬的纤维，折痕深，被反复展开又折回；**母舰通用刻印体，机械的，一笔一划都齐**（与花押主人袖口那朵"花手"不是一种手） |
| 代价 | 窗口开一次少一次，**开它的代价是两百个名**——归人从 417 里挑了两百"能走的、肩上有劲的" |
| 结果 | 订单作废（215 章）。母舰自己关引擎升走（223 章） |
