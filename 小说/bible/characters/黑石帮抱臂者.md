# 人物：黑石帮抱臂者

> **外传主角候选 E**｜"地"的具象化，全书唯一一个只守不攻的人

| 字段     | 内容                                                                     |
| ------ | ---------------------------------------------------------------------- |
| 一句话内核  | **一个"我什么都不会，只会守地"的人，守了这么多年，头一回知道守的是什么。**                          |
| 基础档案   | 男 / 中年 / 黑石帮 ｜ 外貌记忆点：**抱臂**（全书他唯一的招牌动作）；脚步重，鞋底碾过碎铁屑发出细响；手背起泡（袖子沾白后烂出一圈毛边） |
| 定位     | 黑石帮（第二卷起白土区边界实际控制者）→ **四本账之一**                                 |
| 欲求     | 守地界那几道线                                                              |
| 恐惧     | 守的东西是空的                                                              |
| 功能定位   | **"地"这一路的答案** —— 与王的"留种"、花押主人的"拿走"构成第三极                        |
| 首登场记忆点 | 第 207 章（四本账那张矮桌）：从西头进来，抱臂，脚步重；"我们黑石，向来不问名，只问地，这地若是白土区的，我们守" |

## 关键行为

| 章 | 行为 |
| -- | --- |
| 207 | **四本账第一次摊在同一张矮桌上** —— 铁手拼的矮桌（桌面有旧铆钉的坑，坑里积着灰）。八笔对完，四路人各守一笔：赵珩守清算令 / 黑石帮守地界 / 老周盯母舰的道 / 教派念名 |
| 207 | 从怀里摸出**白土区边界地界草图**铺在桌角：「这是白土区边界，我们守的线，画在这上」 |
| 207 | 定场句：「**我什么都不会，只会守地。可我守了这么多年地，头一回知道守的是什么——不是地界那几道线，是线后头那四百一十七个揣着铁片的人。**」 |
| 220-221 | 白塔之战：以袖子盖灯，袖子沾上白**袖口就烂了，烂出一圈毛边**，手背起了三个泡；缩手 |
| 223 | 没去点二口那道缝（缝已合），**从坑壁爬出去**，站在坑边看了一眼，回头看了一眼，然后走了 |

## 弧光

- **起点**：问地不问人的边界看守
- **中段**：他手里有了第一样不是地的东西——**一张地界草图**（草图是他的语言）
- **终点**：袖子烂了，他退到坑外回头看一眼就走了。**他没有抢、没有救、也没有死**——他只是守完了

## 写作纪律

1. **他不问名**。全书他没问过任何人叫什么。这是他与其他三路的根本区别。
2. **抱臂是他的姿势，也是他的态度** —— 抱臂＝不介入、不表态、等。
3. **他的痛只写手**：三个泡、一圈毛边。不写他疼不疼。
4. **禁止**：不给他英雄时刻。他不打母舰、不点白塔、不救任何人。**他只是守着**。
5. **外传用法**：他是"守土"这条线的天然入口——**外传若写"白土区之外的地面"，他就是引路人**。
