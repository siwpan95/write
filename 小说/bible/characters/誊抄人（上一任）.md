# 人物：誊抄人（＝上一任）

> **外传主角候选 D**｜F9/F10 的交汇点，全书最关键的"已死之人"

| 字段     | 内容                                                                        |
| ------ | --------------------------------------------------------------------------- |
| 一句话内核  | **一个从废土走出去的第一个人，也是第一个把名单誊抄过的人——他路断在半道，留下一笔"等"。**              |
| 基础档案   | 男 / 年龄不明 / 誊抄人 = 上一任 ｜ 外貌记忆点：不详（**从未正面描写**）；留痕只有一样东西——**捺尾**，同模同手，一笔一下收笔力道极重 |

## 弧光

- **起点**：一个在名单上逐个念名字的人（也念过自己的）
- **中段**：他划掉了不该划的，也犹豫过（划到一半停住）
- **终点**：**他没有走完**。他把该留的留了（"等"和"存"两个字），把该说的说了（低语＝没走完的路），然后停在半道
- **关键对照**：主角和他正对——**主角分了五样出去，路有人一起走；上一任一个人断在半道**。这是全书对"孤独"最冷的一笔

## 写作纪律

1. **永远不给他正脸**。全书到完结都没正面描写过他。全传继续保持——**他是物证不是角色**。
2. **他的字迹是他唯一的身体**：所有"他在场"的证据都通过刻痕/捺尾/笔法呈现。
3. **低语就是他的脚步**。E4 那些"它们在点名""别让它们读完你的名字"，真身是他在走那半道路。**不是异族，不是教派**（这是硬红线，任何外传不得改写）。
4. **"带不走就别带"**（第 209 章，主角对小雨说上一任划名单的事）——这是主角替他立的一句话。外传若写他，须承认这句。
5. **外传用法**：**他是最难写、也最有价值的外传主角**——因为"一个没走完的人"正是外传的主题本身。
