# 人物：花押主人（"花"）

> **外传主角候选 C**｜E5/F17 的具象化，全书最终对手，**叫不上来自己的名字**

| 字段     | 内容                                                                          |
| ------ | --------------------------------------------------------------------------- |
| 一句话内核  | **一个收了一辈子别人不要的东西、却从来不知道那叫"不要"的人。**                            |
| 基础档案   | 男 / 年龄不明 / 母舰花房那层的主人 ｜ 外貌记忆点：**袖口一朵四出浅瓣的花戳**；眼角的纹是年岁刻的，不是乙太；说话前必用棉球一根一根擦手 |
| 别称     | "花"（代号，第 127 章起只留痕不见人）                                              |
| 欲求     | 履约。订单不是武器，是**一次航行的燃料**；燃料不是记忆，是名字                              |
| 恐惧     | 怕自己有名字。**念名卡在第三百个——「那个名在我这儿是空的」**                                  |
| 与主角的关系 | 第四章末对手 → 母舰邀请函 → 白塔对决。他不是被打败的，是**把柱子自己拔起来的**                |
| 功能定位   | **"取"这一路的终点** —— 全书所有"拿走"的意志的化身；与王的"留"正对偶                     |
| 首登场记忆点 | 第 127 章：只留痕不见人，代号"花"                                        |

## 弧光

- **起点**：签发栏里的一枚戳（没人见过签名，只有花押）
- **中段**：等了十七年算出那三个数（高程、倾角、周期），把订单走成一次航行
- **终点**：**他自己来拔那一柱**——他既不认输也不逃跑，他把账永远留在那儿，让"留着"这件事继续需要有人来看
- **核**：他和主角是同一件事的两头。主角把东西分出去（417 片铁、417 个名、五样留种），他一样一样往回收。**他收的都是别人不要的**——可他从来没问过"不要"是谁说的

## 写作纪律

1. **不写他愤怒**。他的常态是恒定含笑、把杀伐说成园艺（与白褂同一套教养，不同派）。
2. **"擦手"是他的节拍**。第 222 章「他今天不擦了」= 他自己知道这是最后一次——**这个细节不能删**。
3. **他叫不上自己的名字是硬设定**，不许在后续给他补上名字。外传若写他，必须保留这个空。
4. **他不是恶人**。他只是"要"得太久了，"要"到忘了要的是什么。原文：「它比花押主人明白，花押主人要拿走，它要留下。」
5. **十七年这个数是死的**。他等了一十七年算出那三个数，误差是"零日零一天"。任何外传不得改动这个数。
