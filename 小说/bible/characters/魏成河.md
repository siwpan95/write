## E. 弧光（五维 · 全书完结版）

- **起点**：废土底层虚弱少年 + 996 社畜的窝囊感（全属性 4）
- **认知弧**：活下去 → 变强 → 走出去 → 第 37 章顿悟：点燃＝终将离别 → 第二卷"两件事可以同时要，但要付账" → 第三卷"知道燃料是人还按不按效率最优" → 第四卷"救四百个人还是救那个还愿意救人的自己" → **第五卷：一个连来处都忘了的人，凭什么替一个被遗弃的世界做选择？**（答：凭什么不知道，但知道往哪儿走）
- **能力弧**：全 4 → 火花积累 → 乙太重塑（体质 18/精神 24）→ 鹏洛克·新晋 → 蓝·一阶 → 白·一阶 → 黑·一阶 → **第五卷能力冻结：一格没涨**。**他的成长曲线在第五卷变成水平线——但他分出去的东西最多。**
- **关系弧**：小雨（承诺治眼 → 外置记忆 → 417 名的活载体 → 领他进门）；大哥（摊牌 → 并肩 → 家规三条 → 左臂废 → 第五卷**站着**，原力"横在那儿"不往下走）
- **代价弧**：**四笔全烧完**——D4 方法论（76 章）→ D2 认识论（85 章）→ D3 价值论（133 章）→ D1 本体论（169 章）。**四笔烧完，记忆一格没回。** 这是他付出的全部代价，也是他"记不住来处"的物理原因。
  - 纪律：失忆不许写在独白里，必须写成能力退化／行为变形／习惯丢失
- **镜像**：实验体＝走在同一条路上、失败坠落的前任；**誊抄人＝走成了但断在半道的前任**；主角＝分了五样出去、有人一起走的那个
- **终点**（第 230 章）：他撸起袖子看着那道新的白，**没有去数它。他等着。等有人替它数。**——**从"我记不住来处"到"我知道往哪儿走"，再到"我不数了，等人替我数"**，这是三步。

## F. 写作纪律（写他之前必读）


1. **他算账**：做决定时心里有数字（配给券、工时、火花百分比、还差几天）。不要写"他犹豫了很久"，写他算完的结论。
2. **他不解释**：对家人承认"我变了"，但不解释穿越与面板（第 29 章为定例）。
3. **他的温柔是动作**：给小雨留灯、把糊推过去、把碗里那块挑出来——不写"他很爱妹妹"。
4. **他的狠是平静的**：威胁人时不放狠话（第 37 章划掉"击杀"两个字、第 88 章在赵珩虹膜里写"已死"）。
5. **面板文本他念得出来**：面板是他前世的产物，他对它的语气是"熟悉 + 荒诞"，不是"惊讶"。
6. **禁止**：英文（技术词除外，见下）、对读者说话、作者旁白式总结。
7. ~~禁止现代网络梗~~ → **2026-10-01 作者拍板撤销**：网络梗是他的母语，禁掉等于删掉最活的一层口语，**反而是 AI 味的来源**。用法见 §G 配额，不再是红线。

## G. 网络梗使用规范（2026-10-01 作者拍板新增）

> **拍板理由**：他是从现代社会穿过去的人，网络梗是他思维的默认语言。要求一个现代人主角在心里和嘴边自动过滤网络语，等于要求他演一个不是自己的人——这种"被过滤过的内心独白"恰恰是 AI 腔最典型的指纹。禁梗不是去 AI 味，是**助长** AI 味。

| 项            | 规则                                                                                                                                                    |
| ------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------- |
| **允许层**      | **主角内心层**（默认位置）、**他脱口而出的半句话**（对小雨/大哥说漏嘴，旁人听不懂是笑点来源）                                                                                                   |
| **禁止层**      | **叙述层**（作者语言）——旁白里出现网络语＝作者跳出来，不是角色说话；**配角对话层**——阿芸/老周/疤脸刘不许说网络梗，他们的语言是白土区土话                                                                           |
| **配额**       | 每 2~3 章 ≥1 处（**防 IP 漂移的下限**；连续多章 0 处即触发复核）；每章 ≤2 处（超了就变段子集锦）                                                                                          |
| **语用三条**     | ① **必须压缩**：一个梗顶一句话，不能解释这个梗；② **必须有功能**：自嘲 / 测距感（"这个世界连 XX 都没有"）/ 给恐惧降级（把不可名状的东西比作已知的小东西）；③ **必须有时差感**：他想起 YouTube/外卖/老板/热搜，随即意识到那地方已经不在了——梗是伤口，不是笑料包袱 |
| **红线**       | ① 情感兑现点（第 52/87/89 章类）**不用**梗打岔；② 章末钩子段**不用**梗收尾（钩子必须具体到物件）；③ 不用时效性短命梗（三个月后没人懂），只用存活 ≥5 年的通用梗；④ 不解释梗的出处——解释了就死                                        |
| **与既有机制的关系** | 网络梗与 F 节第 1 条"他算账"不冲突：算账是会计语境，梗是吐槽语境，两者可以连着写（"这账算下来，性价比堪比办健身卡"）                                                                                       |

> 【用法范例·合规】"他看着那扇门，脑子里冒出的第一句话是：这玩意儿的根本批复不了的工单。"（内心层，给不可名状的恐惧降级，不解释为什么像工单）  
> 【用法范例·违约】"对他而言，这就像是遇到了大 Boss 一般，俗话说得好，明知山有虎偏向虎山行。"（解释梗 + 旁包扎场，删）
