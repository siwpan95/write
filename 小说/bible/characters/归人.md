# 人物：归人（世代飞船侦察舱幸存者）

## A. 基础档案

| 字段 | 内容 |
|---|---|
| 称呼 | 归人（叙事层编目名，正文中魏成河尚不知其身份） |
| 性别 / 年龄 | 男 / 不明 |
| 现状 | 北境冻原坠毁舰体内，侦察舱醒着；第88章情报"四十天前自醒、有活人" |
| 首露面 | 第107章：远观——沿舰脊走到最高舱口，面朝魏成河藏身的石梁站半晌，**朝天指了一下**，收手入舱合门（不对话，只给一个动作） |
| 记忆点 | 那一指——所指非舰体上空，是更高处（F14"点二"＝母舰的暗种） |

## B. 定位（卷纲 §六）

- E3 线的具象化；他不是敌人，也不是朋友，**他是"另一份名单上的人"**。
- 本卷求援 → 第四卷带来"另一条路" → 第五卷成为选择的一半。
- 第130章正式登场对话："你们这儿，还有多少人活着"。

## C. 第五卷终局（补）

- **他带走了两百个人**（第 171 章带走 → 186 章带回来两百）。开启点二口的代价就是这 200 个名，母舰认了，窗口才开，邀请函才到。
- **邀请函原文**：「**你上来，我们就停手**」（母舰通用刻印体，机械的，一笔一划都齐——与花押袖口那朵"花手"不是一种手）
- **他说的话**：「母舰要的是'锈界的人肯上去'，不是这两 217 个，是随便谁上去都行——**可上去的人，下来的难**」；「挑能走的，肩上有劲的」
- **第 223 章：母舰是自己停的** —— 柱上渗光节律「像有人把一根正在滴水的管子从中间捏住了」，凉下去的那一段上有**三下的节律**：**舰上的人自己关掉了引擎**。王在坑底喊「**还敲着呢**」——敲三下这件事白土区的人懂。
- **母舰升走后**：他把两百带回来。第三层名单层挂着的名字、引擎层碾乙太、花房嵌一朵铁花。
- **他的功能收束**：他是"对面也在求生"的具象。他不是敌人也不是朋友，**他是"另一份名单上的人"**——而最终他自己也变成了"替人把两百个名背下来的那个人"。

## D. 写作纪律

1. 第130章之前只允许远观与痕迹，不给正面、不给名字、不给台词。
2. 其行为克制、有军伍式的准确感（走得不快也不停）。
3. 与教派"点名"、冷库"在册"构成三方名单的互文，不点破。
