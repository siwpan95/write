# 人物：陆平（改名"最后一个"）

> **外传主角候选 A**｜第五卷核心人物，贯穿 12 章

| 字段     | 内容                                                                 |
| ------ | ------------------------------------------------------------------ |
| 一句话内核  | **一个连自己名字都没有的人，用一双手把四百一十七片铁片全捡了起来。**                       |
| 基础档案   | 男 / 中年（南味口音的老头是另一人，陆平是那个"记不起名字"的）/白土区·冷库在册者 ｜ 外貌记忆点：虎口上老茧厚厚一层，握铁的手很稳；记不起名字，只记得**冷库的气味**（霉铁混着潮土） |
| 名字来历   | 「陆平」不是他自己记得的，是**小雨抄下来的**——抄的时候问了他三遍，他不记得自己叫什么；又问冷库气味，他说记得。于是名字后头添了那句气味 |
| 欲求     | 别人告诉他他是谁，他就信；他要一个能攥住的东西                              |
| 恐惧     | 「我摸到了。可我一攥就没了。」——怕自己是被丢下的那一个                              |
| 与主角的关系 | 被主角教「数能开什么」「指到哪儿」的人；不是属下，是他**能指路的人**                        |
| 功能定位   | **"最后一个"的具象** —— 白土区第一批「记不起名字的人」；也是"记名"这条线的活证据 |
| 首登场记忆点 | 第 188 章：站在队列尾端，握铁的手很稳，问「你这个铁，上头的三道，是什么」              |

## 弧光

- **起点**：记不起名字的人，被人叫一声就应一声
- **中段**：开始问「这个铁上头是什么」——从「被记的人」变成「想知道自己记着什么的人」
- **终点**：**他不要名字了**。他抖着手把名字交出去，跪在坑底脸贴地半炷香，起来说「够了」。最后一个名字是他自己选的，也是最后一个——因为那一栏本来就没有别人

## 写作纪律

1. **他的"记不住"不是病，是设定**：他认不得门、认不得字、认不得铁，但**他摸得出哪块地不一样**。
2. **他不说漂亮话**：全篇台词加起来不超过二十句，全是问句和短句。
3. **不写他被治愈**：他到最后也没想起自己叫什么。**不许给他找回名字**——那是硬红线。
4. **抖**：他跟主角一样会抖（D3 见圆物手抖），但他抖着照样把活干完。
5. **外传用法**：他是「第一批记不起名字的人」这个命题的最好载体——外传里若写"别人被丢下的那批人"，他就是锚点。
