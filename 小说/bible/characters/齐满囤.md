# 人物：齐满囤（配给站登记员）

## A. 基础档案

| 字段 | 内容 |
|---|---|
| 姓名 | 齐满囤 |
| 一句话内核 | **一个把两本账按在同一只手上的人——他不怕，因为没人读。** |
| 别名/称呼 | 老齐（配给站同事）、窗口那位（居民口中的代称） |
| 性别 / 年龄 | 男 / 五十上下 |
| 外貌关键特征 | 灰褂子外套蓝布袖套；右手中指第一节一块墨茧（握笔磨的，非搬夫的指肚茧）；写账写一笔顿半息、笔尖不离纸 |
| 身份 | 白土区配给站登记员（李氏雇员） |

## B. 功能与秘密（第106章查明）

- **白天**：配给站窗口登记户头、按户按人头记账、发券发中和剂。
- **每旬一夜**：被李氏调往九号冷库秤房值更过册——四百一十七个"在册"名字由他一笔一笔接进北门。
- 名字大大方方留在排班表值更栏与台账落款上，"不怕，是因为没人读"。
- 魏家三口在其户册上；其名初现于第59天（窗口换生人章手）。
- 悬念指向：能把配给站与冷库两本账按在一只手上的调令，来自更高处（E5/花押线）。

## C. 第五卷 / 外传（补）

- **第五卷**：未出场（0 章）。他的那本冷库秤房值更簿上的 417 个名字，已经在 181 章全部被记住、由小雨背下
- **外传适配 ★★★★☆** —— **他是外传最好的"开场引路人"**：
  1. **他隔着一道窗口**（写作纪律第 3 条），天然适合做"第一次接触"的场景
  2. **他握着两本账**（白土区户册 + 冷库在册）——**"能把两本账按在一只手上的，上头还有手"** 这句悬念至今未解
  3. **"不怕，是因为没人读"** —— 这是外传第一副本的完美任务钩子：**有人开始读了**
  4. **他不是反派**（纪律第 2 条）——他是"账的那只手，不是下账的头"。**外传需要这种"手上很脏但不是坏人"的角色**

## D. 写作纪律

1. 只写可观察的细节（章手、顿笔、袖套），不写其内心。
2. 他本人不担任反派——他是"账"的那只手，不是下账的头。
3. 与魏成河的全部互动隔着一道窗口。
