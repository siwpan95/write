# bible —— 设定事实源

《废土旅法师》的**设定单一事实源（Single Source of Truth）**。
正文里任何一句设定冲突，**以本目录为准**；本目录与正文冲突，**以正文为准并立刻修本目录**。

## 二、`world-bible.md` 的卷级附录结构

设定按**卷**分节追加，而不是堆在一处。这是本目录最重要的组织约定：

| 节 | 覆盖 | 关键红线 |
|---|---|---|
| §1–§8 | 基础设定 / 世界规则 / 面板 / 力量体系 / 地理 / 结构 / 经济 / 生态 / 自查清单 | 全书通用 |
| **§2g** | 第二卷·承境位面（109/111 章） | 器理境榫卯工艺 |
| **§2h** | 第三卷·承境后段（112–114 章） | 位面停留 ≤3 章 |
| **§2i** | 第三卷·承境后段（115–117 章） | 王的三条铁律 |
| **§2j** | **第五卷·终局（181–230 章）** | **能力冻结 / 94 格 / 门认不出** |

> 第二、四卷暂无独立附录——它们的设定散在 `world-bible.md` 正文节与各卷卷纲里。
> **若要补，按 §2j 的格式加§2k、§2l，不要就地扩写已有节**（就地扩写会让节膨胀到无法核对）。

### §2j 第五卷附录包含什么

能力冻结表 · F12 终局值 94 格 · F19 门仍认不出 · 四本账 · 四路不通 ·
四样留种（名/耳/地/读） · F20 那道白 · 终局物件闭环 · 老周第三行 ·
F18 交付口径 · **10 条硬红线清单** · 5 条待回收线。

**写外传前必读 §2j §十一（硬红线清单）与 §2j §十二（待回收线）。**

### 卡片格式约定（两代并存，解析器都认）

**新格式**（推荐）：
```markdown
# 人物：名字
> 一句话定位
| 字段 | 填写内容 |
|---|---|
| 一句话内核 | …… |
| 基础档案 | …… |
## 关键行为
## 弧光
## 写作纪律
1. ……
```

**老格式**：`## A. 基础档案` / `## B. 关键行为` / `## C. 关系网` / `## D. 弧光与纪律`

> 解析器（`wasteland-panel/engine/bible_parser.py` 的 `parse_character_cards`）两代都认，
> 纪律数按 `写作纪律` → `弧光与纪律` → `### 外传适配` 三级回退。
> **新卡一律用新格式**，且必须包含 `## 写作纪律` 章节（不要塞进表格单元格里）。

## 六、写作前后的固定动作

**写正文前**
1. 查 `plot-board.md`——这个伏笔的状态是什么？能不能写？
2. 查 `world-bible.md` 对应卷的附录——有没有硬红线？
3. 查 `characters/` 相关角色卡——他的纪律第几条会拦你？
4. 查 `设定与参考/目录与章节台账.md`——上一章的钩子是什么？章型是什么？

**写完正文后**
1. 更新 `timeline.md`（T 编号连续，**按数值排序**）
2. 更新 `目录与章节台账.md`（字数、章型、提要）
3. 有伏笔埋/收 → 更新 `plot-board.md`
4. 角色有新行为 → 更新 `characters/` 对应卡
5. 跑 `杂项/_audit.py` 与 `node server/cli.mjs reparse`

## 八、三条硬约定

1. **正文冲突优先。** 设定文档跟正文打架时，改文档——不反过来。
2. **数值写来源。** 任何数字（94 格、417 名、82 格、四本账）都要能指到章号，
   指不到就说明它是推的，**推的要标注"未落地"**。
3. **红线只增不减。** 已回收的伏笔不得回退成"待回收"；
   F12 是唯一故意不回收的线（停在 **94 格**，不是 82）。
