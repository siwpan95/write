# 04 · 人物卡模板（通用可复用）

> **适用**：长篇连载 / 系列小说 / 群像戏。一份模板管主角、配角、反派三代人。
> **核心纪律**：**中层三件套（欲望 / 恐惧 / 错误信念）没填完的人物，不许进入正文。** 只有表层的人物叫 NPC。
> **填写顺序**：先 A4 三角 → 再 A3 七件套 → 再 A8/A9 弧光 → 最后回填 A2 表层。反着填会写出"好看但没劲"的人。

### 更新规范（务必遵守）

| 规范 | 写法 |
|---|---|
| 状态更新 | 旧状态加删除线 `~~旧内容~~`，后接新状态，不删历史 |
| 转折记录 | 统一格式 `第X章：事件 → 变化`，一行一条，可无限追加 |
| 范例引用 | 本书范例一律用 `> 【本书范例】……` 引用块，填卡时整块删除 |
| 通用性 | 本模板与题材无关；本书范例仅作"填成什么样算合格"的样板 |

## A. 主角人物卡（完整版）

### A1 角色速查

| 字段 | 填写内容 |
|---|---|
| 一句话角色内核 | 一句话写尽这个人的本质（结构建议：把__包装成__的__人）。写作前扫一眼就能复活这个角色 |
| 一句话处境 | 他现在卡在什么两难里（一句话，用于判断本章该让他难受在哪） |
| 一句话弧光 | 从__的人，变成__的人（全书跨度，一句话） |

> 【本书范例】内核：**一个把算计当盔甲、却把软肋当命的过劳死者。**
> 【本书范例】弧光：从"不能再窝囊地死一次"的自保者 → 到"别变成我"的背负者。

---

### A2 基础档案

> 外貌只抓 **1-2 个记忆点**，不写五官清单。记忆点必须能被别人在人群里一眼认出来。

| 字段 | 填写内容 |
|---|---|
| 姓名 | 全名 / 是否有曾用名、假名、绰号 |
| 性别 / 年龄 | 年龄要写明"生理年龄 vs 心理年龄"是否错位 |
| 身份 / 职业 | 社会身份 + 隐性身份（他实际在干什么） |
| 外貌记忆点 1 | 一个身体标记（疤 / 残疾 / 异色 / 随身物） |
| 外貌记忆点 2 | 一个动态特征（习惯姿态 / 眼神 / 声音） |
| 别称一览 | 各关系人对他的叫法（叫法=关系亲疏的温度计） |
| 出身 / 阶层 | 从哪来、现在处于哪一层、想爬到哪一层 |

> 【本书范例】外貌记忆点：**瘦骨嶙峋，双手骨瘦如柴、指节分明；额头一道撞伤血痂。**（两条都来自"前一世死因"，一个特征带两世信息）
> 【本书范例】别称：小雨叫他"二哥"，青山只叫"魏成河"，黑市的人叫"那个养殖员"。

### A3 性格图谱七件套

> 七件套的意义是：**让人物在压力下反应可预测**。写到卡壳时翻这张表，人物自己会动。

| # | 字段 | 填写内容 |
|---|---|---|
| 1 | 核心标签 | 3-5 个词，其中**至少 1 个是缺点**（例：理性 / 算计 / 不死板 / 护短 / 记仇） |
| 2 | 深层欲求 | 他自己可能都没意识到的那个（表层欲望在 A4，这里写更深的、说不出口的） |
| 3 | 核心恐惧 | 欲求的反面。必须具体到"失去__"或"变成__"，不能写"害怕失败" |
| 4 | 伪装（面具） | 他在人前扮演什么样的人（与真实自我的落差=戏剧空间） |
| 5 | 保护策略 | 感到威胁时他会怎么做（攻击 / 撤退 / 开玩笑 / 讲道理 / 沉默） |
| 6 | 失控触发 | 什么情况下面具会崩（一个具体情境或一句话） |
| 7 | 致命弱点 | **性格缺陷优先于能力短板**——过度的某种品质（太讲理、太重承诺、太要面子） |

> 【本书范例】深层欲求：**想证明自己这一世没白来——不是想活，是想"值得"。**
> 【本书范例】核心恐惧：**怕自己为了走得更远，把身后的人忘干净**（怕变成实验体那种人）。
> 【本书范例】致命弱点：**对家人无条件心软**——所有算计在小雨面前失效，多次因此进入险境。

### A4 欲望-恐惧-错误信念三角（角色驱动内核）

> **这一节是全卡的命根。** 填不满，人物就是工具人。
> 检查标准：**欲望与恐惧必须互相打架**——他越想要那个东西，就越可能失去他最怕失去的。不打架，就没有内在戏剧性。

| 顶点 | 填写内容 |
|---|---|
| 欲望（他知道自己想要） | 具体、可验证、能被阻碍的一个目标 |
| 恐惧（他怕失去 / 怕成为） | 具体的人、物、身份或状态 |
| 错误信念 | 他对世界的一句错误判断（"只有__才配__"句式）。**弧光 = 纠正这句话的过程** |
| 矛盾点（打架处） | 一句话写清欲望与恐惧如何互相拆台 |
| 信念来源 | 这个错误信念是哪次经历种下的（对应 A8 过往伤口） |
| 主题对齐 | 本卡错误信念 ↔ 全书主题是否一致（不一致则改其一，回报主理人仲裁） |

> 【本书范例】欲望：点燃火花、走出废土，兑现"你那个位面我替你去看一眼"的承诺。
> 【本书范例】恐惧：每用一次黑系法力就掉一段记忆/情感——怕有一天连小雨都记不清。
> 【本书范例】错误信念：**"只要我够强，就不会再有人被我拖累。"**（真相：越强的代价越吃人，他恰恰在用失去人的方式保护人）
> 【本书范例】打架处：**他靠"变强"来保护小雨，而变强的燃料恰恰是他关于小雨的记忆。**

### A5 能力与持有

| 字段 | 填写内容 |
|---|---|
| 核心能力 | 主能力 + 当前等级 / 阶段（有数值就写数值，与设定圣经联动） |
| 辅助能力 / 技艺 | 清单式，标明被动 / 主动、获取章节 |
| 装备 / 道具 | 常带的东西（1-2 件够，"标志性意象"见 A7） |
| 资源 | 钱 / 权限 / 情报 / 据点 |
| 人脉 | 可调动的人（谁欠他、他欠谁） |
| 能力代价 | **每次使用失去什么**（体力 / 寿命 / 记忆 / 信誉 / 关系）——必填 |
| 能力天花板 | 当前阶段的极限在哪（防止后期无脑升级） |

> 【本书范例】核心能力：火花共鸣 + 弱点解析（蓝主解析 / 黑主代价，双色倾向）。
> 【本书范例】能力代价：**以记忆与情感碎片为燃料**（已损耗：前世办公室窗外的那棵树）。
> 【本书范例】资源：D 级权限（**不得进入 D 级以上区域**）、法力池为空需自行修习。

### A6 人际关系（每人一张关系小卡）

> 每个重要关系人复制一张。**每人至少挂两种关系类型**（冲突 / 依存 / 镜像），只挂一种的关系写不出戏。

**关系人：_______**（关系类型勾选：□爱恨 □利益 □血缘 □师徒 □秘密 □镜像 □同阵营）

| 字段 | 填写内容 |
|---|---|
| 关系定位 | 对我方角色而言，对方是什么（锚点 / 参照系 / 对手 / 债主 / 诱饵） |
| 表面态度 | 他**表现**出来的态度（嘴上说的） |
| 内心真实 | 他**实际**的想法（与表面态度的落差=张力） |
| 张力线 | 那条**没说出口的话** / 未解决的矛盾（一句话） |
| 关键历史 | 1-3 条共同经历，标章节（决定这段关系的底色） |
| 变化轨迹 | `第X章：事件 → 关系变化` 逐条追加 |
| 依存内容 | 他需要对方身上的什么（能力 / 信息 / 情感 / 合法性） |

> 【本书范例 · 魏小雨】定位：情感锚点。表面：依赖、担忧、劝他别出门。内心：**她已经听出二哥的声音不对了，但不敢问。**
> 【本书范例 · 魏小雨】张力线：**"眼前这个二哥不是原来那个二哥"——她知道，她也选择不说。**
> 【本书范例 · 魏青山】定位：实力参照系。张力线：原力路线 vs 火花路线的认知冲突；内心真实是"又恨他不成器又要替他挡"。
> 【本书范例 · 阿芸】定位：知情者 / 共犯。张力线：**她举报了原主，却把活下来的代价（凝晶原液）交给了新主。**

### A7 行为特征

> 目的：**遮住名字也能认出是谁在说话/在动**。三项全填，声音才立得住。

| 字段 | 填写内容 |
|---|---|
| 说话节奏 | 短促 / 绕弯 / 长句铺陈 / 反问式 / 沉默型 |
| 用词层次 | 书面 / 市井 / 术语（他的专业出身会漏出来） |
| 口头禅 | **限一个**，多了变口癖小丑 |
| 拒绝说的词 | 他**绝不会说**的那一类词（粗人不说书面语，学者骂人用典）——见 F 节速查表 |
| 习惯动作 | 一个可被镜头拍到的小动作（紧张时 / 思考时 / 说谎时各一） |
| 标志性意象 | 绑定的**物品 / 颜色 / 气味 / 声音**（四选二即可，反复出现形成记忆锚） |

> 【本书范例】魏成河：节奏短促、先算后说；用词带前世程序员的量化和自嘲；拒绝**喊口号**（不说"我命由我不由天"这类话，他只会说"算一下，值不值"）。
> 【本书范例】标志性意象：**黑色（代价）/ 火花点燃的声音 / 前世那棵已经记不清的树。**

### A8 成长轨迹

| 字段 | 填写内容 |
|---|---|
| 过往伤口 |  formative 创伤事件（1 条就够，写明：发生了什么 / 他因此得出了什么结论） |
| 秘密 | 对谁都不能说的那件事 + 目前谁知道 |
| 底线 | 打死不做的事（1-2 条） |
| 底线被践踏时 | 他的反应（不是爆发就叫反应，写具体动作） |
| 弧线方向 | 起点状态 → 终点状态（一句话） |

**关键转折记录**（逐条追加，格式统一）：

| 章节 | 事件 | 变化 |
|---|---|---|
| 第__章 | ____ | ____ → ____ |
| 第__章 | ____ | ____ → ____ |

> 【本书范例】过往伤口：前世过劳死，额头磕桌角、后脑着地——死得无声无息，没人记得。结论：**"总不能再窝囊地死一次。"**
> 【本书范例】第37章：濒死点燃 → 认知从"活下去"跳到"走出去"，同章顿悟"点燃=终将离别"，反向修正为"别变成我"。

### A9 四维弧光

> **四拍结构**：起点（带着错误信念的正常生活）→ 触发（事件撞上信念裂缝）→ 挣扎（占全书 60%，用"代价"续命，最容易写水）→ 转变（在最大压力下做出"旧我做不到的选择"）。
> 挣扎段写不下去时，问一句：**这一章他付出了什么代价？** 没代价的挣扎都是水。

| 维度 | 起点 | 触发 | 挣扎（本章段重点） | 转变（旧我做不到的选择） |
|---|---|---|---|---|
| **认知弧** | 错误信念牢固 | 什么事件让信念裂了缝 | 旧信念惯性与新认知拉扯 | 新信念落地成行动 |
| **能力弧** | 初始水平 | 获得途径/契机 | 每一级台阶的门槛 | 关键突破（含代价） |
| **关系弧** | 初始关系态 | 关系被事件撬动 | 疏离/靠近的反复 | 关系不可逆改变 |
| **代价弧** | —— | —— | —— | **每次变强失去了什么（必填）** |

**代价弧明细**（每次升级/突破都记一行，这是全书最值钱的一张表）：

| 章节 | 得到什么 | 失去什么 | 他是否知情 |
|---|---|---|---|
| 第__章 | ____ | ____ | 知 / 不知 |
| 第__章 | ____ | ____ | 知 / 不知 |

> 【本书范例】代价弧：每用一次黑系法力，失去一段记忆或情感碎片；已损耗"前世办公室窗外的那棵树"。
> 【本书范例】关系弧：小雨（承诺治眼+拉钩）→ 青山（摊牌→并肩→"两下都挨完了"）→ 阿芸（知情者，守密）。
> 【本书范例】弧光阶段标记：`setup` → `冲突积累` → `转变中` → `已转变` → `收束`

### A10 镜像角色

| 字段 | 填写内容 |
|---|---|
| 镜像对象 | 与本角色互为镜像的人（同一起点的另一种可能） |
| 镜像命题 | "如果主角当年__，就是他"——把这句话补全 |
| 对照方式 | 两人面临相似抉择时的不同选择（各写一句） |
| 对照出现节点 | 哪些章节让镜像并置（对话 / 对照场景 / 反派自白） |

> 【本书范例】镜像对象：**实验体**——走在同一条路上、已经坠落的前任。
> 【本书范例】命题：**"如果主角当年只想着飞升、忘了身后的人，就是他。"**

### A11 当前状态（动态更新区）

> **每章写完后更新此区。** 旧值加删除线，不删历史。这是防穿帮的第一道闸。

| 字段 | 填写内容 |
|---|---|
| 更新至 | 第__章 / 故事内时间（第__天） |
| 所在位置 | 具体地点（与在场性规则联动） |
| 当前目标 | 短期（本章级）/ 长期（本卷级） |
| 情绪基调 | 一个词 + 一句身体感受 |
| 知识边界 | 他**现在**知道什么、还不知道什么（详见 D 表） |
| 身体 / 资源状态 | 伤势、数值、持有物 |
| 本节更新记录 | `~~旧~~ → 新`（第__章） |

> 【本书范例】`~~穿越第一夜 / 火花10% / 全属性4~~` → **在世 / 鹏洛克·新晋（第37章点燃，穿越第18天）/ 法力池空，待修习**。
> 【本书范例】知识边界：知面板与火花机制、废土格局；**不知**原主死因全貌、李氏地下实验全貌、虚境。

## B. 配角人物卡（精简版）

> 一人一卡，长度约为主角卡的一半。**只保留六项**：内核、档案、欲求与恐惧、与主角的关系张力、功能定位、首登场记忆点。
> 配角弧光可压缩为**两拍**：一个反差瞬间即可（懦夫的一次挺身）。

### 角色名：_______

| 字段 | 填写内容 |
|---|---|
| 一句话内核 | 一句话写尽这个人 |
| 基础档案 | 性别/年龄/身份 + **1 个外貌记忆点** + 别称 |
| 欲求 | 他想要什么（一句话） |
| 恐惧 | 他怕失去什么（一句话） |
| 与主角的关系 | 定位 + **张力线**（那句没说出口的话） |
| 功能定位 | 在主线里承担什么功能（提供信息 / 制造阻碍 / 情感锚点 / 主题对照 / 情报源 / 代价提醒者） |
| 首登场记忆点 | 他第一次出场的那个动作或那句话（读者凭什么记住他） |
| 弧光两拍 | 常态 → 反差瞬间（`第__章：____`） |
| 当前状态 | 在世/已故/外出 + 位置 + `~~旧~~ → 新` |

> 【本书范例 · 老周（周德厚）】内核：**一个在工厂干了十二年、靠"不该问的别问"活到今天的班组长。**
> 【本书范例 · 老周】记忆点：满脸辐射灼伤暗红色疤痕；嗓音沙哑如砂纸刮铁皮；领口系褪色红布条。
> 【本书范例 · 老周】张力线：**他知道 B-3 下面有什么，他一个字都不说。**
> 【本书范例 · 老周】首登场记忆点：听到"工厂下面还有什么"时**脚步顿了一下**，随后甩出一句"不该问的别问"。
>
> 【本书范例 · 魏小雨】内核：**一个看不见世界、却把家里每个人的脚步声都记住的盲眼少女。**
> 【本书范例 · 魏小雨】功能定位：情感锚点 + 主角人性的度量衡（她一开口，读者的心就软）。
>
> 【本书范例 · 阿芸】内核：**一个被公司做成线人、却把活下来的代价交给仇人的女人。**

### C2 反派专项三问（每名反派单独填一栏）

| 字段 | 填写内容 |
|---|---|
| 正当性 | 在他自己的价值观里，他为什么是对的（写得出一句让人无法反驳的话） |
| 欣赏时刻 | 他在哪一章、因为什么对主角流露出欣赏/惜才 |
| 惋惜点 | 他败亡时，读者会惋惜什么（他失去的、他本可以成为的） |
| 镜像关系 | 他与主角互为镜像的那一句命题 |
| 升级路径 | 他如何一步步从"可以谈"变成"必须死" |

> 【本书范例 · 初期】疤脸刘：动机=拿没人追查的孤儿试"新货"，在他眼里这叫"生意"；与主角因果=**原主之死**；欣赏时刻待补。
> 【本书范例 · 中期】李氏公司中层：动机=追查异常、掩盖实验，在他眼里这叫"维持秩序"。
> 【本书范例 · 终局】古老鹏洛克：动机待补——**必须与主角"走出废土 vs 背负废土"的终局抉择互为镜像**。

## 【人物自检清单】

> 人物进正文前逐项打勾。**中层三件套任一为空 = 不许进正文。**

### 内核层（否决项）

- [ ] 欲望已填（具体、可验证、能被阻碍）
- [ ] 恐惧已填（具体到"失去__"或"变成__"）
- [ ] 错误信念已填，且**弧光就是纠正它的过程**
- [ ] **欲望与恐惧互相打架**（不打架=没内在戏剧性）
- [ ] 错误信念 ↔ 全书主题对齐（不一致已回报主理人仲裁）

### 立体度

- [ ] 有致命弱点，且是**性格缺陷**而非能力短板
- [ ] 有**一个**外貌/行为记忆点（不超过两个）
- [ ] 有秘密（对谁都不能说的那件事）
- [ ] 有底线，且写过底线被践踏时的具体反应
- [ ] 有伪装（面具），且与真实自我有落差

### 弧光

- [ ] 四拍齐全：起点 / 触发 / 挣扎 / 转变
- [ ] **代价弧已推进**（最近一次成长，他失去了什么）
- [ ] 挣扎段有"代价"续命（不是原地打转）
- [ ] 转折记录格式统一为 `第X章：事件 → 变化`

### 关系

- [ ] 每个重要关系人都标了**连接类型**
- [ ] 主角至少挂 3 种关系类型
- [ ] **至少有一人是主角的镜像**
- [ ] 每条关系都有"没说出口的话"（张力线）

### 反派（若本章涉及）

- [ ] 在他自己的价值观里，他的目标是正当的
- [ ] 他有对主角"欣赏"的时刻
- [ ] 他败亡时读者有一丝惋惜
- [ ] 他与主角互为镜像

### 声音与一致性

- [ ] 说话节奏、口癖、拒绝说的词三项齐全
- [ ] **盖住名字能认出是谁在说话**（F1 测试通过）
- [ ] 群像中三人的句长已错开
- [ ] 写本章前已查 D 表（谁知道 / 不该知道）
- [ ] 角色状态已用 `~~旧~~ → 新` 更新
- [ ] 在场性检查：已故不登场、外出者未提前返回、权限未越级
