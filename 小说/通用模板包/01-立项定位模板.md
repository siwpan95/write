# 01 · 立项定位模板（定调层）

> 全创作室的地基。**这一层不过关，不许往下走**——大纲、设定、人物、文风全部建立在它上面。
> 使用方法：逐项填写，填完过文末自检清单；标 ⚑ 的是"不过关即退回"项。

---

## 0. 一句话故事（L1）⚑

> 填不出来就别开书。要求：能口头讲给别人听，对方听完能复述，且能听出"这书爽在哪"。

**公式 A（要素式）**

```
一个【什么样的主角】，在【什么背景/世界】下，面对【什么核心冲突】，
凭借【什么金手指/筹码】，最终【什么结局或抉择】。
```

- 主角：
- 背景：
- 核心冲突：
- 金手指 / 筹码：
- 结局 / 抉择：

**公式 B（因果式，推荐先用它打草稿）**

```
主角想要 ______，因为 ______，但 ______，于是 ______，最终 ______。
```

**公式 C（卖点式，用于对平台/编辑自我介绍）**

```
______ 流 + ______ 世界观 + ______ 情感锚点，主打 ______ 爽点。
```

> 【本书范例】B式：魏成河想要活得不窝囊，因为前世过劳死无人收尸，但穿成废土全属性4的将死少年，
> 于是靠旅法师面板刷异族攒火花，最终点燃火花成为鹏洛克，并面临"去多元宇宙还是回头救废土"的抉择。

### 一句话故事验收门（三条全中要过）⚑

- [ ] **可复述**：讲给一个人听，他能不看书复述出"谁 + 要什么 + 挡着什么"。
- [ ] **有爽点引擎**：句中能看出读者为什么追（升级 / 打脸 / 揭秘 / 守护 / 逆袭，至少一个）。
- [ ] **有终极抉择**：结局处存在一个"两难"，不是单纯的"变强了"。

## 5. 红线与自律条款

> 提前写下"本书绝不做的事"，中期崩书基本都是踩了自己没写下的红线。

| 类型 | 本书红线 |
|---|---|
| 战力红线（升级节奏上限） | |
| 情感红线（不写什么） | |
| 设定红线（不新增什么体系） | |
| 节奏红线（虐点最多几章、不水几章） | |
| 结局红线（不烂尾、不机械降神） | |

> 【本书范例】战力红线：十章升三级尚可，三章满级必死；虐点不超过 2 章；不新增与主体系并列的第二套能量本源。

## 6. 立项自检清单（全部打勾才算定调完成）

- [ ] ⚑ 一句话故事三条验收门全过
- [ ] 卖点矩阵至少 3 条，每条能落到具体情节
- [ ] 核心命题是一个"两难问题"，不是一句口号
- [ ] 至少 1 个情感锚点角色（读者会因为他在乎这本书）
- [ ] 对标作品 ≥2 部，且写明差异
- [ ] 字数目标与平台匹配，更新计划是"做得到的量"
- [ ] 红线条款已写下，且具体到可判定（能一眼看出有没有违反）
- [ ] 能说出"第一卷结束时主角变成了什么样"（卷级目标已有雏形）

## 附：定调常见坑

| 坑 | 症状 | 修法 |
|---|---|---|
| 只有设定没有故事 | 一句话故事里塞满世界观名词 | 删掉所有专有名词重写，用"谁要什么、谁挡着" |
| 只有爽点没有内核 | 写到 30 万字后主角没方向 | 补"核心命题"，让它变成主角的中期抉择 |
| 金手指与世界观两张皮 | 金手指放在任何世界都能用 | 给金手指加一条"只有这个世界才成立"的限制 |
| 卖点全是"很新颖" | 说不出具体新颖在哪 | 换成"同类型书里他们做 X，本书做 Y" |
| 没有反派动机 | 反派纯坏 | 给每个反派写一句"他为什么觉得自己是对的" |
