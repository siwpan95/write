# 06 · 连载护航模板（通用可复用）

> 用途：百万字长篇连载的**日常操作系统**。写前查、写后更、定期体检、卡文急救，全部落到可勾选项。
> 配合文件：`bible/world-bible.md`（单一事实源）、`bible/plot-board.md`（伏笔/线头）、`bible/timeline.md`（时间线）、`bible/characters/`（人物卡）、`05-文风卡与章节规范模板.md`（怎么写 · 文风红线见 §8.3）、`章节创作模板.md`（单章格式）。
> 使用原则：**写前读状态表，写后更新状态表。** 这一分钟是百万字不崩的唯一保险。
> 通用性说明：所有时间锚写成 `{相对锚}` 占位，如"穿越第N天""历练第N月""入学第N周"。换行投产时只需全局替换占位词。
> 自动化：每 10 章跑一次 `python scripts/consistency_audit.py --bible bible --ms .`（novel-writing-assistant 技能目录下），脚本报告与本模板 C1-C12 编号对齐。

## 一、章节状态表（每章一行 · 全书主干台账）

> 每写完一章立即补一行；本表是 C1-C12 全部校验的取数源。
> 【章型】单选标签（五档枚举，**唯一定义处＝05 §2.2.1**）：`动作戏 / 对白戏 / 独白戏 / 过渡章 / 混合型`。
> 混合型＝**内容跨两类的章**（「独白+动作」「独白+意识对话」或「对白+动作」皆可），**大场面/高潮章专用**，每卷 ≤3 章；**不是兜底桶**——功能四步归不进四类的普通章，按最接近的一步归入四类之一，不许顺手填"混合"。

### 1.1 章型抽样复检表（每 10 章填一次）

> 本表**只记章型，不记实测数值**（对话占比/短句占比等实测值只回填 05 §1.1，不在本表第三处维护）。
> 用途：卷末查"章型分布红线"时的取数源；同时复核"写章纲时定的章型"与"成稿功能"是否一致。

| 章 | 写章纲时定的章型 | 复核后章型（功能判定） | 是否改判 | 备注（含空档兜底/豁免） |
|---|---|---|---|---|
|  |  |  |  |  |
|  |  |  |  |  |
|  |  |  |  |  |
|  |  |  |  |  |

**判定与校验分工**
- **判定（定章型）**：按功能，**先走第 0 步（大场面 + 连续动作推进 + 显著内心/意识段或多人对话交锋 → 混合型）**，不命中再走 1→4 步（见 §1 字段说明）；对话占比不参与判定。
- **大场面但内容单一**：章纲标了大场面，却内心段 <3 处、对话也不构成交锋（就是一场纯动作）→ **按 1→4 步归入四类之一**（绝大多数归动作戏），**只触发字数豁免**（可写至 4200 字，不受所归章型字数上限约束）；**对话占比仍按所归章型考核，不额外放宽**——喊话太多就删，或改判对白戏，否则"大场面"会变成绕过对话红线的后门。
- **混合型不是兜底桶**：普通章走完功能四步仍归不进四类的，按最接近的一步归入四类之一，禁止顺手填"混合"——否则卷末分布红线立刻失真。
- **校验（查达标）**：只用 W3（逐章）与 05 §1.1（每 3 章回填）的实测值对表。
- **空档兜底**：实测对话占比落在 **20%~25%**（过渡章/**混合型**上沿 20% 与对白戏下沿 25% 之间）时，**判过渡章、混合型或判对白戏都不算错**，以功能判定为准；该章**豁免对话占比达标考核**，只计入章型分布。
- **越线二选一**：实测落不进章型区间时，**改文（增删对话）或改章型**，不允许两头都不动。

**轮换红线（写章纲时就排，不写完再查）**：连续动作戏 ≤2 章；过渡章每 5 章 ≤1 章；**混合型每卷 ≤3 章**（超出＝高潮贬值）；混合型对话上限 **≤20%**（独白型常 ≤12%，对白型 12%~20%）。
**字数豁免**：章纲标为大场面的章可写至 **4200 字**，不受所归章型字数建议上限约束；豁免的只有字数，对话占比照常考核（见上一条）。
**越线处置**：回 05 §1.1 找差距最大维度 → 二遍改写（§8.3 五步）→ 仍不合格则出校准意见交风格调教师，不在连载层自行改判章型。

## 五、时间线模板

> 标准行格式：**`T{n}：{相对时间锚}·{时段} — 事件：……（出处：第X章）`**
> 日期不要加空格；跨天写"第17-18天"；同一锚点多条按 T 递增排列。

### 5.1 两种锚的写法与取舍

| 锚类型 | 写法 | 适用 | 优点 | 风险 |
|---|---|---|---|---|
| 相对锚（推荐主线用） | `穿越第N天·夜` / `历练第N月·上旬` | 穿越/重生/觉醒类，主视角连续叙事 | 读者体感清晰，倒计时天然成立 | 视角切换时易算错天数 |
| 绝对锚（推荐多线/跨地图用） | `浩劫历112年·霜月·初七·黄昏` | 群像、跨地域、跨年跨度 | 多线可交叉比对 | 需维护历法表，读者记忆负担重 |
| 混合锚（长篇最稳） | `穿越第N天（=浩劫历112年·霜月初七）·夜` | 百万字长篇 | 两全 | 换算表必须同步维护（见 5.3） |

> 【本书范例】`- T41：穿越第17-18天 — 事件：大哥苏醒，兄弟对话确认"两下都挨完了"；乙太感知诊断小雨眼病；夜赴郊外废墟首次显现位面坐标，夜空东北方一道紫色裂隙（出处：第40章）`；跨天写法：`- T36：穿越第15-16天·深夜至凌晨 — 事件：……（出处：第35章）`。

## 八、日更 SOP

### 8.1 三段式流程

**写前 10 分钟（查）**

1. 读状态快照（§2）：位置/身体/数值/物品/知道什么/不能做什么
2. 读上一章章末钩子：本章开头 200 字内必须接住它
3. 读本章章纲一句话目标（写不出目标＝回大纲层，见 §10）
4. 扫 C7 不该知道 + 在场性表（谁能出场、谁不能）
5. 定本章：时间锚 / 地点 / 出场 / **章型** / 爽点类型 / 钩子类型（先定后写；章型在写章纲时就定，参数区间查 05 §2.2.1）

**写中（只盯一句话目标）**

1. 结构四拍：接钩（0-200字）→ 推进（主行动+信息增量）→ 冲突/回报（爽点）→ 留钩（150-300字）
2. 番茄钟：25 分钟 × N，钟内不回看不改稿；卡住先写 `[TODO 此处补]`，一气到尾
3. 新设定 ≤2 条；新人物给 1 个记忆点；单段 ≤200 字
4. 红线：不收在总结/抒情/升华；不写"下一章会……"

**写后 10 分钟（更 + 自检）**

1. 更新章节状态表（§1）一行
2. 追加 timeline 一条（§5）
3. 更新伏笔账本（§3）与线头表（§4）
4. 面板/物品有变动 → 同步 world-bible（2f / 2b）
5. 角色知识/在场性有变动 → 同步 6.1 / 6.2
6. 钩子自检：类型≠上章；指向"下一章必须做的动作"

### 8.2 日常打勾清单（每天复制一次）

```
□ 写前：状态快照已填（§2）
□ 写前：上章钩子已在本章开头接住
□ 写前：本章一句话目标已写下（写不出→回大纲层）
□ 写前：出场名单已比对在场性表（C3/C6）
□ 写前：章型已定并写入 05 §2.2 头部块（写完倒推无效）
□ 写中：四拍结构完整（接钩/推进/回报/留钩）
□ 写后：新设定 ≤2 条（C9）
□ 写后：章节状态表已补一行（§1）
□ 写后：timeline 已追加 T{n}（§5）
□ 写后：伏笔账本 + 线头表已更新（§3/§4）

□ 写后：章末钩子类型 ≠ 上章（C11）
□ 写后：存稿水位 ≥ 警戒线（§9）

□ 文风：引号全角 “”；无禁用词/禁用句式；二遍已过"去AI味五步"

### 8.3 文风红线速查（与 `05-文风卡与章节规范模板.md` 联动）

> 本表只做**写后 1 分钟快筛**；完整判据、评分表、改写五步见 05 号文件（§1 文风卡 / §1.6.2 评分表 / §3 去 AI 味五步）。
> 硬门槛：05 §1.6.2 评分 **≥85 才发**；70-84 改一轮；<70 重写。脚本 `python style_analyze.py 基准稿.txt 本章.txt` 相似度 **≥0.60**。

| # | 红线项 | 目标值（05 实测） | 超线处理 |
|---|---|---|---|
| 1 | 平均句长 | 14-20 字（17.7） | >22 字拆句 |
| 2 | 短句占比（≤15 字） | ≥50%（58%） | <45% 拆长句 |
| 3 | 单句逗号 | ≤1 个 | 第 2 个即拆句 |
| 4 | 平均段长 | 20-40 字（25.4） | >50 拆段；单段硬顶 200 字 |
| 5 | 单句成段占比 | 35%-55%（46%） | <25% 补短句落点 |
| 6 | 破折号 / 省略号 / 感叹号 | **破折号每章 ≤3 处（v2.0 修订：人类 0.80 / AI 2.38 次/千字，旧"≤10 次/千字"作废）** / ≤3 次/千字 / ≤2 个/章 | 禁连续两段都用破折号 |
| 7 | 对话占比（按章型·**校验值**） | 对白戏 25%-35%；动作/独白章 0%-10%；**混合型 ≤20%**（独白型常 ≤12%，对白型 12%-20%） | 越区间＝二选一：改文（增删对话）或改章型，不允许两头不动；**20%-25% 空档豁免**（过渡章/混合型/对白戏皆可，以功能判定为准）；**大场面章不豁免对话占比** |
| 8 | 比喻 | 只用「像」；喻体限工业建筑/生物/日常器物/身体 | "仿佛/如同/似的"零次；越域重写 |
| 9 | 招牌句式"不是 X。是 Y。" | ≤2 次/千字；高潮段最后 300 字 ≤1 次 | 连用 3 段即成机械排比 |
| 10 | 环境独立成段 | ≤8%（实测 3.2%） | 景物嵌进动作句 |
| 11 | 感官配额 | 每章 听觉 ≥2 + 触觉 ≥1 + 味觉 ≥1；**嗅觉 ≥1 且 ≤1 处/千字、必须有功能归属**（v2.0：82% AI 文写嗅觉，禁为氛围写气味） | 缺则补、超则删 |
| 12 | 世界特色词 | ≥3 个/千字 | 缺即变通用废土文 |
| 13 | 排版 | 引号全角 `“”`，标点全角，章标题全角空格 | ⚠ 现存坑：第29/33/37/40 等章残留半角 `"`，新章禁用，旧章择机批量替换 |
| 14 | 对话标签 | 用"他说"或纯动作 | 禁"他怒吼/他冷笑" |

**二遍改写顺序（不可颠倒）**：删解释 → 换感官 → 加具体 → 减形容词 → 破对称。判据：不解释 / 可验证 / 有尺寸 / 一形一名 / 不齐整。

## 九、存稿与节奏管理

### 9.1 存稿水位警戒线

| 水位 | 章数 | 状态 | 动作 |
|---|---|---|---|
| 红区（危险） | ≤ 2 章 | 随时断更 | 启动 §9.2 应急预案，先补库存再谈质量 |
| 黄区（警戒） | 3-4 章 | 应急缓冲 | 本周加更 1-2 章；暂停开新支线 |
| 绿区（安全） | 5-10 章 | 日常水位 | 正常日更 |
| 蓝区（宽裕） | ≥ 15 章 | 上架/爆更预备 | 可安排爆更、请假、大修 |

硬规则：
- 开书发布前存稿 **≥ 10-20 章**（新人取上限）
- 上架/推荐位前存稿 **≥ 20 章**
- 日常任何时刻 **不低于 5 章**，低于 5 章即视为进入黄区
- 请假/出差/生病：提前按天数 × 日更量备稿，并预留 2 章机动

### 9.2 断更应急预案（按优先级执行）

| 序 | 预案 | 适用 | 说明 |
|---|---|---|---|
| 1 | 发存稿 | 存稿 ≥1 章 | 宁发旧稿不断更；发布后不再修改 |
| 2 | 切支线视角章 | 主线卡住 | 配角平行事件，信息密度低但推进感强，主线零消耗 |
| 3 | 闪回章 | 需回收旧伏笔 | 一箭双雕：既补库存又收伏笔；必须标注 `[闪回·{原锚}]` |
| 4 | 事件余波章 | 大高潮之后 | 各方反应 + 情报汇总，可顺势埋下一卷伏笔 |
| 5 | 短章 | 实在写不动 | 不低于 1500 字，收在强钩子，下章补回长度 |
| 6 | 请假条 | 以上皆不可 | 提前发，说明回归时间；回归首章必爆更 2 章补偿 |

### 9.3 周更字数表（按目标日更量自动换算）

| 模式 | 日更字数 | 周产字数（×7） | 周更章数（3000字/章） | 强度 |
|---|---|---|---|---|
| 兼职保底 | 2000 | 1.4 万 | 4-5 章 | 低 |
| 标准日更 | 4000 | 2.8 万 | 9-10 章 | 中 |
| 职业日更 | 6000 | 4.2 万 | 14 章 | 高 |
| 爆更冲刺 | 10000 | 7 万 | 23 章 | 极高（不超过 2 周） |

节奏红线：
- 固定更新时间 + 固定更新量（读者习惯 > 偶尔爆更）
- 爽点间隔 **≤ 3 章**；连续 3 章无爽点＝节奏告警
- 每 10-20 章必须推进一次主线；支线不得连续 3 章以上占满
- 每章结尾交代"下一步必须做的动作"

> 产能换算参考：100 万字 ÷ 3000 字/章 ≈ 334 章；日更 6000 字约需 5.5 个月（全力）；日更 4000 字约需 8 个月。开书前先对齐这个数量级——多数人高估自己 3 倍。

### 10.1 判别树（先诊断再动笔）

 │       └─ 问：是否连续 3 天以上、且多章都写不动？
 │           └─ 是 →【结构型】卷级问题，暂停日更，回大纲做一次卷级重构
 └─ 附加判定：文字写出来"不像这本书"→ 文风漂移，出风格校准（非卡文，转风格调教师）
```

| 类型 | 症状 | 病根 | 禁忌 |
|---|---|---|---|
| 结构型 | 坐两小时写不出第一句；写完自己都不信 | 本章无目标 / 无障碍 / 无障碍升级 / 无代价 | 禁止硬写——硬写必水，水章比断更伤 |
| 产能型 | 知道要写什么，但句子堵、场景推不动 | 状态低谷 / 场景太重 / 信息塞太多 | 禁止删稿重开——先写完再改 |

### 10.2 A · 结构型卡文三动作（回大纲层）

| 动作 | 怎么做 | 产出 |
|---|---|---|
| A1 补章纲三件套 | 给本章补：目标（主角要什么）+ 障碍（谁/什么拦着，且比上章更强）+ 代价（失败/成功各失去什么） | 一条可写的章纲 |
| A2 换 POV 或换幕 | 本章视角换成配角（收获情报/压力）或把本章改为余波章，把卡点推到下章 | 绕过卡点，主线不空转 |
| A3 回卷纲校验 | 检查本卷中期目标是否还成立；不成立则升到大纲层重排本幕（8-15 章） | 卷级方向的修正决定 |

> 结构型卡文的预防靠大纲详细：章纲细到"目标+障碍+转折+钩子"四要素，卡文率下降一个数量级。

### 10.3 B · 产能型卡文三动作（当场急救）

| 动作 | 怎么做 | 适用 |
|---|---|---|
| B1 跳过卡点 | 在卡住处写 `[TODO 此处补]`，直接跳写后面有把握的场景/结尾，回头补 | 中段某场戏卡住 |
| B2 降维场景 | 把大场面降成小场景：两人对话/一顿饭/一次清点；用对话把信息推进掉，不写动作戏 | 调度太重、人物太多 |
| B3 对话推进 | 只写对白与反应，不写环境描写；先搭骨架，二轮再上色 | 完全写不动的当天 |

**通用预防三招**：① 往前翻 3 章找语感；② 看同类作品 10 分钟激活节奏；③ 大纲写细（章章有四要素）。休息优先于硬扛——睡眠不足写出的稿，次日必改。
