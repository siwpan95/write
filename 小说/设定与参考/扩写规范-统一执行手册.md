# 扩写规范·统一执行手册（v1.0）

> 用途：把《废土旅法师》第一卷、第二卷现有章节扩写到 **正文汉字 ≥ 3000 字/章**，同时**不得改动任何剧情事实**。
> 适用对象：作者本人及一切代笔/协作流程。执行前必读，执行后必自查。
> 配套文件：`bible/world-bible.md`（设定单一事实源）、`bible/plot-board.md`（伏笔账）、`bible/timeline.md`（时间线）、`bible/characters/`（人物卡）、`方法/章节创作模板.md`（章节规范）。

---

## 一、目标与验收标准

| 项 | 标准 |
|---|---|
| 字数 | 每章正文**汉字数 ≥ 3000**（不含标题行、不含 `===` 分隔行、不含标点与空格） |
| 计数口径 | 汉字 = `[\u4e00-\u9fff]` 匹配数。**不是**文件字节数，**不是**含标点的字符数 |
| 上限 | 单章不超过 4500 汉字（防注水；高潮章可至 5000） |
| 交付 | 直接覆盖原 `.md` 文件；覆盖前必须先做备份 |
| 验收 | `pwsh` 逐章统计汉字数，全部 ≥ 3000 方为通过 |

**为什么是 3000**：网文平台主流单章区间为 2000～4000 字，低于 2000 字在推荐算法与读者"值不值"判断上双重吃亏；本作原稿多在 1900～2200 字，属于"半章感"，扩到 3000～3500 是最稳的区间（依据见《章节创作模板.md》§七参考资料）。

---

## 二、文件格式（一字不可变）

```
第X章　标题

正文第一段……
正文第二段……

===

（换场后的正文）

===

（再换场的正文）
```

硬规则：

1. **第一行**是标题，格式 `第X章　标题`（章序号用**中文数字**，标题前是**全角空格 U+3000**）。例：`第五章　金手指登场`、`第四十一章　悬赏`。
2. 标题行下空一行，直接进正文。
3. 场景切换用独占一行的 `===`（三个半角等号）。**不新增** `===` 的语义（它只表示换场/时间跳跃）。
4. **禁止**在章节 `.txt` 里出现元信息头、`【字数】`、`【时间线】`、`【本章钩子】` 等任何非正文内容——这些只存在于 `方法/目录与章节台账.md` 与 `bible/` 文档中。
5. 文件编码 UTF-8，无 BOM。段落之间单空行还是紧邻，**沿用该文件原样**（扩写只增内容，不重排格式）。

## 三、不可动清单（硬约束，违反即返工）

以下内容一个字都不许改：

1. **章末最后一段**（钩子）。若确因扩写需要，只能**增强**，不能更换钩子类型、不能提前泄底、不能改成总结抒情。
2. **所有已成型的关键台词**（人物说出口的话）。可以前后加动作/停顿，**不可以改写措辞**。例：小雨"骗人。"、大哥"你还是我弟弟吗"、老周的原话、面板提示文字。
3. **面板文本**：`【魏成河】`、`体质：4`、`【火花：0（4%）】` 等格式与数值，原样保留。
4. **专有名词**（见 §五术语锁定表）。
5. **剧情事实**：谁在场、谁受伤、谁说了什么、物品在哪、时间过了几天、火花百分比、解锁节点——全部照旧。
6. **伏笔的埋设位置**：`plot-board.md` 记录某伏笔"埋于第 X 章"，该钩子句必须原位置保留。
7. **叙事人称与视角**：第三人称限知，紧跟魏成河。不新增第二个视角人物的独立心理段落。
8. **人物死亡/退场**：已死或不在场的角色不得出场（`world-bible.md` §8 自查项）。

## 四、六大扩写技法（按优先级使用）

> 原则：**扩写＝把原来一句话概括的事，摊开成读者能看见、能听见、能闻到的一段时间。**
> 不是加形容词，是加**动作分解、具体物件、旁人反应、短对话、代价细节**。

### 技法 1｜动作分解：一拍拆成三拍

原文写"他一掌把蟑螂按在墙上"。扩写后：抬手（迟疑半拍）→ 落掌（触感：甲壳的硬、体液的温、腿的刮擦）→ 收手（看掌心、甩一下、在裤子上蹭）。

**要求**：每章至少挑 3 处关键动作做这种分解，优先挑：首次登场、战斗、受伤、拿到关键物品。

### 技法 2｜五感锚点：一场戏至少两种非视觉感官

废土专属感官库（挑用，勿堆砌）：

- 听觉：铁皮屋顶被风掀动的"哐"、探照灯电流的嗡、远处变异兽嚎叫、蛋白棒包装的塑料脆响、水管里的气声
- 嗅觉：煤烟、霉味、铁锈、碱化的土腥、辐射区那种"甜得发腻的烂味"、消毒水
- 触觉：配给券的毛边、硬质纤维纸"滑得不像纸"、油灯余温、蟑螂甲壳的边缘割手
- 味觉：蛋白棒像发霉豆粉、变异玉米糊刮嗓子、水的铁腥味
- 体感：辐射剂量高时后颈发紧、饥饿时手抖、伤口换药时的凉

### 技法 3｜路人侧写：用无名者的一个动作替代旁白

不要写"白土区的人都很苦"。写：一个老头眯眼把悬赏令从头读到尾，咂咂嘴走了；两个半大孩子对着"三万券"咽口水，被大人拎着耳朵拖走。

**要求**：每章至少 1 处路人侧写，**不超过 3 处**（多了抢戏）。

### 技法 4｜对话加壳：台词不变，加停顿、动作、答非所问

原文：

> "以后我夜里不出门了。"他说。
> "骗人。"小雨说。

扩写（台词一字不动，只加壳）：

> "以后我夜里不出门了。"他把碗往桌里推了推，指腹在碗沿上蹭掉一圈水渍。
> 小雨没抬头，手里的衣服在水里翻了个面。
> "骗人。"她说。
> 盆里的水晃了一下，撞在盆沿上，又落回去。

**要点**：加的是**动作节拍**与**沉默**，不是新台词。若要新增台词，只允许**功能性短句**（追问、提醒、报数、称呼），且不与人物卡语气冲突。

### 技法 5｜代价具体化：给"变强/受伤/失去"配一个可验证的物证

- 受伤 → 具体到"左手抬不过肩""换药时纱布粘在痂上，撕下来带一层白的"
- 变强 → 具体到"原本要两只手抬的料箱，现在一只手拎起来，另一只手还能扶门框"
- 失去 → 具体到"他摸到虎口那道疤，想不起它怎么来的"（**写行为，不写独白**）

**要求**：每章至少 1 处代价或收益的**物证**。这是本作的核心质感，也是防"注水"判定的关键——读者能记住的只有具体的东西。

### 技法 6｜环境定时：给场景加"钟表"

用可观察的外部周期把时间钉住，替代"过了一会儿"：

- 厂区探照灯**每十几秒**扫过一次天幕
- 配给站**每天清晨六点**开闸，队伍从巷口排到水塔
- 养殖区**每两小时**喷一次消毒雾
- 虚空中**没有钟**，只能靠心跳与计时面板

## 六、易误报内容改写规则（本次重点）

> 目标：**文学上更狠，审核上更稳。** 平台审核与 AI 检测误报，绝大多数来自"用语抽象化不足"和"句式机器化"，不是来自情节本身。

### 6.1 敏感情节的意象化写法

| 原写法（高风险） | 改写法（推荐） | 理由 |
|---|---|---|
| 直接描写内脏、断肢、脑浆 | 写**声音与气味**："一声闷响""铁锈味在嘴里泛开""他没敢低头看" | 保留冲击力，规避血腥词表 |
| 连续的暴力动词（砍、剁、剖、插） | 写**受力与后果**："骨节错开""他半个身子砸在门框上弹了一下" | 动作结果替代动作本身 |
| 尸体、死尸、血肉 | **遗骸 / 那具东西 / 壳 / 空壳** | 冷感更强，且不触词 |
| 药物、注射、麻醉 | **中和剂 / 针剂 / 一管东西** | 保留功能，弱化药物标签 |
| 爆炸、炸毁 | **塌 / 掀开 / 亮了一下 / 那片区域空了** | 结果化 |
| 自伤、自杀、自杀式 | **抵命 / 同归于尽 / 没打算回来** | 语义等价，规避词表 |
| 恐怖分子、邪教 | **教派 / 那伙人 / 灰袍** | 保留设定，弱化标签 |

**注意**：本作是废土题材，必要的残酷**必须保留**——删掉残酷等于删掉题材。改写的是**用词路径**，不是**残酷程度**。

### 6.2 去 AI 味高发句式（逐条自查，命中即改）

| AI 常用句式 | 问题 | 改写 |
|---|---|---|
| `不是……，而是……` | 最典型的机器对偶结构 | 拆成两句，或只留后半句 |
| `仿佛 / 宛如 / 似乎 / 好像` 连用 | 模糊化副词堆叠 | 每 1000 字不超过 2 次；改用**直陈** |
| `他知道，他明白，他清楚` 排比 | 解释性旁白 | 删掉，用动作表达 |
| `这一刻 / 那一刻` 开头段 | 情绪脚手架 | 直接写动作 |
| 段落长度过于均匀（每段都 3-4 行） | 检测器高度敏感 | 刻意制造**长短交错**：单句成段与 5 行段并存 |
| 抽象总结收尾（"这就是废土"） | 作者旁白 | 收在具体动作或具体物件上 |
| 过度形容词（"深深的""无尽的""浓浓的"） | 稀释信息密度 | 删，换具体度量 |
| 四字格连用（"阴风阵阵，荒芜凄凉"） | 套路化 | 保留 1 个，其余删 |
| 每段开头副词化（"缓缓地""静静地"） | 机器节奏 | 删除该副词，直接给动词 |
| 破折号密集 | 检测特征（人类 0.80 / AI 2.38，每千字） | 每章 **≤ 3 处** |
| 心理描写解释行为（"他之所以这样做，是因为……"） | 说教 | 删因果解释，只留行为 |

**反 AI 味的正向手法（每章至少用 5 条）**：

1. 具体数字：`三万券`、`七小时`、`每十几秒`、`一秒六下`
2. 具体物件名：`硬质纤维纸`、`搪瓷缸掉了漆的边`、`半桶水`
3. 方言/口语颗粒：`话里有话`、`拎着耳朵`、`咂咂嘴`、`腰杆都直了`
4. 不完美的口语语法：倒装、省略主语、半截话
5. 人物各说各的：答非所问、岔开话题
6. 留白：不说破的动机，让读者自己补
7. 感官的**非典型**选择：不写"他看见"，写"他听见""他闻到"

### 6.3 重复与雷同自查

- **自我查重**：每章写完后，检索本章是否与本书其它章节出现**成段雷同**（尤其是"废土环境描写""回忆前世""面板提示"三类，最容易自我复制）。
- **桥段查重**：不照搬热门作品的标志性桥段与原句；可用的是**结构方法**，不是**具体呈现**。
- **内部重复词**：同一章内"废土"不超过 5 次、"辐射"不超过 6 次、"沉默"不超过 2 次、"灰""熵""虚空""位面"各不超过 6 次；超出即换表达或删。
- **成对高危章（扩写时必须逐段比对，防跨章复制）**：第 10↔11 章（白日工厂／夜猎）、第 17↔79 章（旧人／旧人）、第 41↔63 章（悬赏／变了）、第 53↔80 章（虚空／二次穿越）、第 59↔82 章（回响／第二枚）、第 60↔66 章（循环之末／信号）。

### 6.4 情绪直说的三分法（**本节纠正一条常见误解，务必执行**）

> 背景：马良写作引用的研究称「人类命名情绪的频率是 AI 的约 11 倍」，据此建议**多用情绪词**；而国内平台口径恰恰把「他不禁感到一阵心悸」这类**情绪直陈＋弱化副词**列为最强 AI 特征词簇。
> **两者不是真矛盾，是精度问题——"情绪词"被当成了整体。** 必须拆成三类：

| 类别 | 定义 | 本作处置 | 例 |
|---|---|---|---|
| **A 类：动作能演出的情绪** | 有对应身体反应或行为外显的即时生理/心理状态 | **必须走演出路线，禁止直接命名**（维持现有规范） | 害怕／紧张／疼／累／愤怒／惊恐／兴奋 |
| **B 类：动作演不出的情绪** | 无对应外显动作的**关系性、时间性**心理状态 | **允许且必须直说**——强行演出会写成比直说更假的绕圈 | 认命／释然／羞耻／迟疑／心软／发怵／舍不得 |
| **C 类：空泛情绪形容词** | 程度副词＋抽象情绪名词的组合 | **一律删除**（这才是"少用情绪词"真正针对的对象） | 深深的悲伤／无尽的痛苦／浓浓的失落／五味杂陈 |

**执行结论**：

1. **"少用情绪词"应精确表述为"少用 C 类空泛情绪形容词"，而不是"不写情绪动词"。**
2. **下限**：每 3000 字章节，B 类直接命名 **≥1 次**。这是**防 AI 指纹的硬指标**——若连续多章"情绪直接命名＝0"，即触发复核。
3. **上限**：每 3000 字章节 B 类 **≤3 次**。超过即滑向"贴标签"。
4. **落点约束**：B 类直说优先放在三类承重位置——① 章末钩子前最后 150～300 字；② 卷级转折章（第 29／37／76／85／88 章）；③ 情感伏笔兑现点（第 87／89 章）。**不放在动作戏中间**（动作戏一律走 A 类演出）。
5. **禁止情绪词＋弱化副词组合**（"不禁感到一阵心悸""隐隐有些不安"一律改成具体生理反应）。
6. **例外**：**对白里可以有情绪词**——人说话本来就会说"我怕""我急"。这是人物语言，不是旁白。

### 6.5 感官配额（防"AI 更爱写气味"的反向陷阱）

通用数据显示：**82% 的 AI 故事写到嗅觉，人类只有 57%**。本手册 §四技法 2 把嗅觉列为废土专属感官重点，方向与 AI 偏好一致，**必须设配额**：

| 感官 | 配额 | 硬性要求 |
|---|---|---|
| **听觉** | 每章 ≥2 处 | 虚空/黑暗场景中唯一可用通道，优先级最高 |
| 视觉 | 不设上限 | 基础通道 |
| **嗅觉** | **≤1 处/千字，且必须有功能归属** | 功能仅限：判食物是否变质／判辐射与污染／判血腥与死亡／判身份。**禁止为氛围而写气味** |
| 触觉 | 每章 ≥1 处 | 与"代价物证"绑定最佳 |
| 味觉 | 每章 ≥1 处 | 与"吃"的场景绑定（本作食物是核心意象） |
| 体感 | 不设上限 | 代替情绪命名的主力（A 类演出） |

### 6.6 书名/简介/标签侧（作者层）

- 简介与标签不使用：`最强`、`无敌`、`神级`、`吊打`、`震惊` 等夸张词堆叠。
- 不复述敏感设定作为卖点（实验、解剖、人体改造等不写进简介）。
- 标签用平台既有词条：`末世`、`废土`、`穿越`、`系统`、`位面`、`单女主/无女主`（按实际）。
- **不得出现万智牌/DND 官方专有名词**（英文原名、官方位面名、官方人物名）。「鹏洛克」是通用中文译名可用；位面名全部自造，以 `world-bible.md` §3.5 为唯一来源。本作是**设定借鉴**，不是同人——番茄等平台对无授权 IP 同人是上架即封禁。

> 完整的平台合规清单（44 条）见 `调研-平台误报规避与去AI味.md` §十。

## 七、扩写作业流程（每章照做）

1. **备份**：`备份-扩写-<时间戳>\` 下保留原件（整批做一次即可）。
2. **读三份**：本章原文、本章在 `方法/目录与章节台账.md` 中的条目（拿时间线/钩子/提要）、本章出场人物的人物卡。
3. **列 6 个扩写点**：对应 §四六大技法，先写下来再动笔（防随手堆字）。
4. **动笔**：在原文骨架上**插入**，不重写原文已好的句子。
5. **自查**（见 §八）。
6. **计数**：汉字 ≥ 3000 才交。

## 八、交稿前自检清单

**内容与一致性**

- [ ] 章末钩子与原文一致（或更强），未被削弱、未被"讲完"
- [ ] 所有关键台词原样保留
- [ ] 面板文本与数值原样保留
- [ ] 出场人物、在场状态、伤情、随身物品与原文一致
- [ ] 时间线与 `方法/目录与章节台账.md` 记载一致（未新增天数、未跨天）
- [ ] 未新增第 3 个以上新设定（每章新设定 ≤ 2 条）
- [ ] 未让已死/不在场角色出场
- [ ] 未提前泄露后文真相
- [ ] 新增的所有地名/机构名/人名均在 `world-bible.md` 或本手册 §五中存在，否则**不用**

**文字质量**

- [ ] 汉字数 ≥ 3000 且 ≤ 4500
- [ ] 每章至少 3 处动作分解、1 处路人侧写、1 处代价物证、5 条反 AI 味正向手法
- [ ] `不是……而是……` 句式：**≤ 1 处**（行业线 ≤2，本作从严）
- [ ] `仿佛/宛如/似乎` 合计 ≤ 2 处/千字
- [ ] **破折号 ≤ 3 处**（行业实测：人类 0.80 / AI 2.38，每千字）
- [ ] 弱化副词（微微/淡淡/缓缓/轻轻/悄然/默默/隐隐）**≤ 3 个/千字**
- [ ] 冒号提示语（"核心是：""一句话总结："）**0 处**
- [ ] 无"这就是……""他终于明白……"类总结抒情收尾
- [ ] 段落长度明显长短交错，存在单句成段与 5 行段并存
- [ ] 引号全为 `“”`；省略号 `……`；破折号 `——`；无半角标点混排
- [ ] 同章"废土/辐射/沉默"未超 §6.3 上限；新增"灰/熵/虚空/位面"同章各 ≤6 次

**六项量化阈值**（完整依据见 `调研-长篇不崩与去AI味.md` §8.1）

| 阈值项 | 本作目标值 | 计数口径 |
|---|---|---|
| 句长错落度 | **0.68～0.78（≥0.70）** | 变异系数＝句长标准差÷均值；**排除标题行、`===`、面板行** |
| 对话占比 | **25%～33%（章均 28%）**；硬下限 **18%**，硬上限 40% | 引号内字符 ÷ 全文汉字 |
| 逐字复读滑窗 | **≥12 字逐字重复：同章 0 处、跨章 0 处** | 白名单：面板整行、R1-R12 引用、术语表词条 |
| 回报密度 | **中型以上回报每 5～6 章 1 次**（每卷 8～10 次）；小回报每 1～2 章；大回报每卷 3～4 次 | 回报四形态：变强物证／信息反超／规则被利用／立场翻转 |
| 希望锚点率 | **每 3 章 ≥1 个具体物件或动作** | 锚点库：配给券数字、一锅留着的饭、拉钩、"我记得就行"、火花百分比 |
| 情绪直说（B 类） | **每 3000 字 1～3 次**（下限 1、上限 3） | 判定见 §6.5 |

> ⚠️ **回报真空高危区**：第二卷第 63-73 章（共 11 章）经实测为"无中大型回报"区段。扩写该区段时**必须至少植入 2 处中型回报**，且优先用「信息反超」与「规则被利用」两种形态——**不新增剧情事实，只把已有事实的回报感写足**。

**感官配额**（硬指标）

| 感官 | 配额 |
|---|---|
| 听觉 | **每章 ≥2 处**（虚空/黑暗场景中唯一可用通道，优先级最高） |
| 视觉 | 不设上限（基础通道） |
| 嗅觉 | **≤1 处/千字，且必须有功能归属**（判食物／判辐射／判血腥／判身份）。**禁止为氛围而写气味** |
| 触觉 | 每章 ≥1 处（与"代价物证"绑定最佳） |
| 味觉 | 每章 ≥1 处（与"吃"的场景绑定——本作食物是核心意象） |
| 体感 | 不设上限（代替情绪命名的主力） |
| 回溯标记 | **≥0.5 处/千词**；每次燃烧记忆必须带回溯 |
| 叙述认知（他知道/他意识到） | **≤3 处/千字，且必须跟动作** |

**格式**

- [ ] 首行 `第X章　标题`（全角空格）
- [ ] 无元信息头、无 `【字数】` 等字段
- [ ] `===` 仅用于换场，数量与原文一致或按需微增
- [ ] UTF-8、无 BOM
