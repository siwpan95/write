## 一、台账列说明

每章必须填这些列：

| 列 | 说明 | 是否必填 |
|---|---|---|
| 章 | 文件名 | 必填 |
| 字数 | 实际字数（≥3000 下限） | 必填 |
| 时间线 | 故事内时间 | 必填 |
| 地点 | 主要场景 | 必填 |
| 出场 | 出场人物（≤4 主+辅） | 必填 |
| 章型 | 入场／判定／清场／掉落／留种／火边／代价／共享／主干 | 必填 |
| **命题** ★新增 | 本章对应的副本命题（≤20 字，是拷问不是场景） | 副本内章节必填 |
| **拼图编号** ★新增 | 本章揭示哪块拼图（如 F22-①） | 揭示点章节必填，其余填"—" |
| **记账三处** ★新增 | 本章后白土区账／小雨本子／铁手环各多或少什么 | 副本出口章必填，其余填"—" |
| **钩子类型** ★新增 | **结果型**／**代价型**——结果型＝"他能不能成"；代价型＝"他成了，但付了什么" | 必填 |
| 本章钩子 | 一句话钩子内容 | 必填 |
| 提要 | 内容提要（写完后填） | 写完后填 |

## 二、钩子类型硬指标

> 来源：《品类调研方案》§4.8。正史 74 万字已把结局写死了（洼地能种），外传的悬念**不可能**是"结果"，只能是"代价"。

| 指标 | 要求 | 检查方法 |
|---|---|---|
| **代价型钩子占比** | **≥ 80%** | 每写完一章统计钩子类型列 |
| 结果型钩子每部上限 | **≤ 3 处** | 每部收口时统计 |
| 结果型钩子典型句式 | "他能不能……"／"会不会成……" | 写完一章检查钩子句式 |
| 代价型钩子典型句式 | "他成了，但……"／"少了一样……"／"这一趟没人白走" | 同上 |

**红线**：若一部写完发现代价型占比 < 80%，**必须返工**——把结果型钩子改成代价型。改法：把"他能不能成"改成"他成了，少了什么"。

## 五、跨部回声机制

> 记账循环的核心：**每一笔账都跨部回声**。

| 账本 | 第一部记什么 | 第二部回声 | 第三部回声 | 第四部回声 | 第五部盘点 |
|---|---|---|---|---|---|
| 白土区账 | 东三里起步·铁皮道通过 | 老周念到这一行 | 拿土时再添一笔 | 拿水时再添一笔 | 第五本账写满 |
| 小雨本子 | 四个人今天进了铁皮道 | 她不在场，回来念到 | 多记一个人的路 | 多记一件事 | 417 + 1 全数盘点 |
| 铁手环 | −1 只（教废） | −N 只（每副本一只） | −N 只 | −N 只 | 终部剩几只对应付出过几次 |

**写法纪律**：每部开写前先看上一部的账本状态，**账本只能加不能减**——这是记账循环的不可逆性，对应正史"账不会忘"的纪律。
