## 第一部分：创作要素总览（调研结论）

### 一、长篇小说的核心要素体系

根据联网调研（阅文作家专区、网文俱乐部创作指南、知乎专栏、头条创作指南、搜狐长篇构思方法论、英文写作指导等来源），长篇小说创作需掌握的要素可归纳为以下体系：

| 层级 | 要素 | 说明 |
|---|---|---|
| **立项层** | 核心创意 | 一句话能说清的"这本书讲什么" |
| | 题材定位 | 类型标签、对标作品、目标读者 |
| | 精神内核 | 价值观/主题（如"被遗弃者的自我救赎"） |
| | 核心卖点 | 读者为什么要追（爽点引擎） |
| **世界层** | 历史背景 | 重大历史事件、时代划分 |
| | 地理地图 | 地点布局、地域特色、动线设计 |
| | 社会结构 | 势力划分、权力层级、阶级制度 |
| | 世界规则 | 可判定的规则（什么能做/不能做） |
| | 经济体系 | 货币、资源、贸易链 |
| | 生态/风物 | 动植物、气候、日常细节 |
| **体系层** | 力量体系 | 等级划分、进阶路径、核心规则 |
| | 金手指/外挂 | 主角独有优势的机制与限制 |
| | 禁忌与代价 | 什么不能做，做了有什么后果 |
| **人物层** | 主角档案 | 身世、性格、执念、弧光、目标 |
| | 配角群像 | 盟友/对手/导师/感情线各 3-5 人 |
| | 反派梯队 | 初/中/终三段反派，各有动机 |
| | 关系网络 | 爱恨、利益、血缘、师徒的连接图 |
| | 角色弧光 | 认知弧、能力弧、关系弧、代价弧 |
| **情节层** | 全局大纲 | 三幕结构/英雄之旅的全书骨架 |
| | 分卷规划 | 每卷独立小主线 + 服务全书主线 |
| | 章节细纲 | 每章目标 + 钩子 + 信息增量 |
| | 明暗双线 | 明线（升级打怪）+ 暗线（身世/阴谋） |
| | 爽点节奏 | 密度规划、打脸/升级/获得/击败/装逼 |
| **管理层** | 伏笔账本 | 埋设、推进、回收的全程跟踪 |
| | 时间线 | 绝对/相对时点的事件登记 |
| | 角色知识状态 | 谁知道什么、谁不该知道什么 |
| | 在场性管理 | 谁在场、谁不在场、状态是否自洽 |
| | 道具/物品状态 | 关键物品的流转与终态 |
| **执行层** | 章节结构 | 钩子→推进→冲突→留钩四拍 |
| | 章末钩子 | 五种技法轮换、四种驱动力组合 |
| | 信息量控制 | 每章新设定 ≤2 条、新人物 1 个记忆点 |
| | 文风规范 | 排版、标点、段落长度、对话格式 |
| | 一致性校验 | 定期跑脚本扫描矛盾 |

| 清道夫公会 | 魏青山／老周 | 消息来源与后勤 | 同行 + 共守秘密 |
| 辐射教派 | 低语者 | 未正面接触 → 争夺小雨 | 契约 + 争夺 |
| 世代飞船归来者 | 归人 | 求援 → 交易 → 各自离开 → 终局并肩 | 交易 + 对照 |
| 王级异族 | 异族之王 | 威胁 → 短暂同盟 | 同类目标 |
| 虚境 / 外域 | 低语真身／外域本体 | 终局背景 | 契约 + 回声 |

**秘密的持有链（防止信息穿帮）**

| 秘密 | 谁知道 | 谁不知道 |
|---|---|---|
| 主角是穿越者（非原主） | 主角本人 | **全书所有人**（大哥只知道"我弟弟变了"） |
| 面板/火花的存在 | 主角本人 | 所有人 |
| 位面/五色/乙太体系 | 主角、后来的小雨 | 大哥、老周（第二卷末仍不知） |
| 黑色法力的代价 | 主角、大哥（部分）、小雨（部分） | 其他人 |
| B-3下面是什么 | 主角、老周、大哥、李氏 | 白土区居民 |
| 人工火花/火种计划 | 主角、赵珩、白褂、花押主人 | 白土区居民、小雨 |
| D1-D4已烧的内容 | **无人知道全部**（这是全书最孤独的一条设定） | 所有人 |

> **最重要的一条**：主角**从未**向任何人解释过穿越与面板（第29章为定例）。这条纪律贯穿全书五卷——他的孤独不是"没人信他"，是"他从没说过"。

## 第九部分：写作规范执行标准

### 9.1 已有规范

- 章节创作模板（`章节创作模板.md`）：文件命名、章节结构、排版、钩子标准、信息量管理
- 去AI味规范（见 de-ai-novel 技能）：画面优先、主观感受、听觉友好、描写禁令

### 9.2 补充规范

- **新设定每章 ≤2 条**：避免信息过载
- **新人物首登场给 1 个记忆点**：外貌/口癖/动作
- **同时活跃悬念线 ≤3-4 条**
- **小悬念 1-3 章回收，大悬念跨卷**
- **每章结尾交代"下一步必须做的动作"**
- **相邻章末钩子类型不可重复**

### 9.3 一致性自检频率

| 检查项 | 频率 | 方法 |
|---|---|---|
| 人名变体 | 每章写完 | 对照人物卡规范名 |
| 时间线 | 每5章 | 对照timeline.md |
| 面板数值 | 每次变动 | 立即更新world-bible.md |
| 伏笔状态 | 每10章 | 对照plot-board.md |
| 角色知识状态 | 每章写前 | 对照5.4表 |
