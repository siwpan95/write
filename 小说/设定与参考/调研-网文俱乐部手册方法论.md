## 一、大纲与卷纲方法论

### 1.1 三级大纲

| 级 | 名称 | 内容 | 粒度建议 |
|---|---|---|---|
| 一级 | **总纲** | 一句话故事 / 核心矛盾 / 主角成长线 / 结局方向 | 一页纸 |
| 二级 | **卷纲** | 标明**章号 + 字数区间**；每卷有独立主线与完整起承转合 | 细纲 1–2 万字最推荐 |
| 三级 | **章纲** | 标出**每段字数**；每章目标 + 钩子 + 信息增量 | 每卷、每 10–20 章细化一次 |

> 来源：[大纲方法](https://www.wangwenclub.com/handbook/category/%E5%88%9B%E4%BD%9C%E6%8C%87%E5%8D%97) / [长篇架构设计](https://www.wangwenclub.com/handbook/category/%E5%86%99%E4%BD%9C%E6%8A%80%E5%B7%A7)

### 1.2 单卷与全书结构

- **单卷字数**：首卷 30–50 万；中间卷 50–80 万；末卷 20–40 万。
  → **本作调整**：本作走"短卷快节奏"路线（每卷 12–15 万字、40–50 章），单卷体量为手册建议的 1/3。理由：① 章均 3000 字、五卷 230 章共约 70 万字，总量本身就是"中等体量"；② 短卷利于每卷一个完整弧光，符合本作"一卷只回答一个问题"的设计。
- **每卷必备三件**：独立主线 + 完整起承转合 + **卷末高潮**。
- **三幕配比**（手册以 200 万字级为例）：25% / 60% / 15%。
  → **本作调整**：约 20% / 58% / 22%（59 章 / 130 章 / 50 章）。第三幕偏重，因为本作的"回归抉择"需要足够的篇幅收束 19 条伏笔。
- **境界体系**：10–15 级最合理；每级须写清晋级条件、实力表现、寿命、数量分布、社会地位；**越级不超过 2 个大境界**。
  → **本作对照**：本作不用"境界"而用"面板解锁 + 位面层级"，但手册的"每级五要素"仍适用——`bible/world-bible.md` §2f 解锁总表已按此补齐（每个解锁点都写了条件、效果、落点章）。

### 1.3 章节字数

| 场景 | 建议 |
|---|---|
| 标准 | 2000–3000 字 |
| 平时 | 2000–2500 |
| 重要情节 | 3000–4000 |
| 高潮 | 4000–5000 |
| 起点男频 | 3000–4000 |
| 晋江女频 | 3000–5000 |
| 免费平台 | 2000–3000 |

→ **本作定位**：起点男频向 → **章均 3000 字，下限 3000、上限 4500，高潮章 ≤5000**。这正是本次 88 章扩写的目标区间，也是 `方法/扩写规范-统一执行手册.md` §一 的取值依据。

### 1.4 开篇硬指标

- **3 章内出金手指**；**每章 1 个小爽点**；**10 章内有打脸**；**30 万字内换地图**。
- **90% 读者在前三章决定去留**；收藏主要来自前 30 章。
- 第一章第一段必须做到四件事：**抓眼球（冲突/悬念/有趣）+ 信息明确 + 代入感强 + 文字流畅**。
- 前三章留人率实测：第 1 章 100 人进入 → 第 2 章剩 60–70 → 第 3 章剩 40–50。**前三章会流失 50% 读者。**

→ **本作对照**（`bible/第一卷卷纲.md` §二 已按此表逐条落实）：

| 指标 | 手册线 | 本作落实 |
|---|---|---|
| 3 章内出金手指 | ✓ | 第 5 章面板显现（略晚但第 3 章已给"死因疑云"长线钩） |
| 每章 1 小爽点 | ✓ | 第 7 章首杀入账；第 12 章异族感知 |
| 10 章内打脸 | ✓ | 第 9 章四步战略成形 + 第 19 章畸形巷爆发 |
| 30 万字内换地图 | ✓ | 第二卷 53 章进入光桥墟（约 20 万字处） |

### 1.5 断章（章末钩子）

- **好断点**：悬念刚出现 / 冲突将爆发 / 谜底将揭晓 / 转折前一刻。
- **禁断**：爽点刚爆发 / 正高潮中 / 对话说一半。
- 钩子四类：**突发事件 / 悬念 / 危机 / 反转**。

> ⚠️ **手册与本书现行规范的一处差异（须留意）**：手册把"对话说一半"列为**禁断**；而本书 `方法/章节创作模板.md` §四 采用"伏笔截断"技法时，允许在关键句处戛然而止。
> **取舍结论**：以本书规范为准，但**限定使用频率**——"对话说一半"式的截断**每卷不超过 3 次**，且必须是真的截断（后文有回收），不能是偷懒。其余断章一律用手册认可的四类。

## 二、人物与世界观管理

### 2.1 人物卡字段

- **主角 11 字段**：姓名 / 年龄 / 外貌 / 性格 / 背景 / 家庭 / 目标 / 金手指 / 特长 / 弱点 / **价值观**
- **配角 8 字段**：其中**必须含「退场时间」**
- **反派模板**：**三次交锋 + 遗留**

→ **本作对照**：`bible/characters/` 现有卡片已升级为 A–G 结构（基础档案 / 当前状态 / 目标 / 关系网 / 弧光 / 写作纪律 / 关键台词）。**缺口**：手册要求的"退场时间"与反派的"三次交锋"尚未在卡上显式登记。
**补强建议**（已写入各卡）：疤脸刘＝第 17/31/38 章三次交锋 + 遗留（李氏三个月前已知情）；赵珩＝第 67/70/88 章三次交锋 + 遗留（三处坐标 + 编外身份）；白褂＝第 73（远观）/78（正面）/85（大战）章 + 遗留（"你烧了什么，你自己还不知道"）。

### 2.2 配角数量与功能

- 长期配角 3–5 个；阶段性配角每篇 2–3 个。
- 配角核心三作用：**推动剧情 / 衬托主角 / 丰富层次**。
- 衬托手法：**能力对比（不要直陈，要用配角之口）** / 性格对比 / 价值观对比。
  - ❌ "李明很强。"
  - ✅ "连宗门第一天才都败了，这李明到底有多强？"

→ **本作对照**：`方法/小说创作完整框架.md` §5.2 已按"功能审查"（镜像/催化/对照/信息）建表，并设三层红线（核心 12–18 / 总具名 ≤28 / 每卷新增 ≤5）。这条比手册更严，来自 `调研-长篇不崩与去AI味.md` §8.1⑥。

### 2.3 反派设计

- **反派强度 = 主角成长动力**。匹配四阶段：小反派（打脸爽点）→ 中反派（略有挑战）→ 大反派（势均力敌）→ 终极反派（惊险刺激）。
- **立体反派四件**：有自己的信念 / 有合理的动机 / 有复杂的性格 / 有悲剧的过往。
- 平面 vs 立体对比：
  - ❌ "我就是喜欢做坏事，哈哈哈哈！"
  - ✅ "当年你们正道灭我全族，说是为了天下苍生；今日我屠你们满门，也是为了天下苍生。有什么区别吗？"

→ **本作对照**：`小说创作完整框架.md` §5.3 的反派梯队已按"每一层都有可理解的动机"重写。本作反派的统一命题是——**在资源不够的世界里，谁来当燃料**。花押主人的立体化正落在这条上（"他不是要毁灭，他是在给母舰找一条活路"）。

### 2.4 金手指设计

**好金手指五标准**：独特性 / 合理性 / **成长性** / **限制性（不能太无敌，要有代价）** / 趣味性。
**按来源三分类**：外挂型（系统/神器/老爷爷/传承）/ 天赋型（体质/血脉/悟性）/ 重生穿越型（时空优势）。

→ **本作对照**（这是本作金手指的合规自检）：

| 标准 | 本作落实 |
|---|---|
| 独特性 | 旅法师面板＝前世自己写的外挂穿越后生效（区别于签到/抽奖/模拟器） |
| 合理性 | 底层逻辑通用（击杀异族→火花），且与本土"四大飞升"并列而非碾压 |
| 成长性 | 火花 4%→100% 十级解锁；点燃后转"法力池 + 五色法术"（第二引擎） |
| **限制性** | **火花点燃后不再增长**（堵死刷怪）；**黑色法力以记忆为燃料**（不可复原）；**虚空耐受 7→9→11→13 分钟**；**灰线污染不可逆** |
| 趣味性 | "读懂即得"（解析产生法力）、五色组合、代偿转移 |

> **限制性是本作金手指最硬的一块**，也是手册这条标准做得最足的地方。写作时**任何一次变强都必须标价**（见 `方法/扩写规范-统一执行手册.md` §四技法 5"代价具体化"）。

### 2.5 世界观

- 世界四层、冰山原则、设定三层深度；能力—代价—反制三件套。
- → **本作对照**：`bible/world-bible.md` §2 的规则 R1–R15 全部写成**可判定形式**；§2f 面板解锁总表；§3.5 位面体系单一定义处。**已符合手册要求。**

## 三、章节技术与断章钩子

### 3.1 节奏与爽点密度

| 项 | 手册建议 | 本作取值 |
|---|---|---|
| 前期（1–30 万）爽点 | 每章 1 个 | 每章 1 个小回报 |
| 中期（30–100 万）爽点 | 2–3 章 1 个 | 中型回报每 5–6 章 1 次 |
| 小高潮频率 | 10–15 章 1 次 | 每卷 8–10 次中型回报 |
| 中高潮频率 | 30–50 章 1 次 | 每卷 3–4 次大回报 |
| 大高潮频率 | 100–150 章 1 次 | 每卷 1 次卷末高潮 |

> **术语本土化**：本作无女主线、无宅斗式"打脸"，故把"爽点"改称**回报**，四形态为——**变强物证 / 信息反超 / 规则被聪明利用 / 身份或立场翻转**。完整依据见 `调研-长篇不崩与去AI味.md` §8.1④。

### 3.2 中场拖沓三修法（手册原文，可直接用）

1. **删除法**：不推动剧情 / 不塑造人物 / 不营造氛围 / 只为凑字数的段落 → 删。
2. **压缩法**：5 章压成 2 章。
3. **加冲突**。

> **注水四条判据**（手册口径）：**不推动剧情 / 不塑造人物 / 不营造氛围 / 只为凑字数**。
> → **本作直接采用**，并写进 `方法/扩写规范-统一执行手册.md` §八。这是本次 88 章扩写最需要遵守的一条：**扩写不是把 2000 字变成 3000 字，是把"被概括的事"摊开成"读者能看见的一段时间"**——每一个新增段落都必须能回答"它推动了什么／塑造了谁／营造了什么"。

### 3.3 追读率红线（商业指标，作者层参考）

| 追读率 | 判定 |
|---|---|
| 95%+ | 理想 |
| 90–95% | 正常 |
| 85–90% | 警告 |
| <85% | 危险 |

**追读率 = 当前章阅读数 ÷ 上一章阅读数**。**定位问题的方法**：追读率从哪一章开始掉？那一章写了什么？质量下降 / 情节拖沓 / 方向跑偏 / 出现大 BUG？

> → **本作可用性**：若后续上架，**每 10 章记录一次追读率，把掉点章号记进 `方法/目录与章节台账.md`**，与"回报真空区"（第二卷 63–73 章）的检查合并执行。

## 四、文风与描写技巧

### 4.1 各专项要点（手册口径）

| 专项 | 要点 |
|---|---|
| **对话** | 对话要推动剧情或塑造人物；避免"说明文式对话"（人物互相交代设定）；千人一腔是大忌（每个角色要有自己的说法方式） |
| **战斗** | 要有胜负逻辑与代价；避免数值复读；一招一式的过程与结果要配对 |
| **心理** | 避免"复述式心理"（把刚发生的事再想一遍）；心理要产生决策，而不是复述 |
| **环境** | 避免"环境套话"；环境要与人物的处境、情绪或行动发生关系 |
| **多视角** | 视角切换要有明确标记与理由；不可在读者不知情时偷换视角 |

### 4.2 修改润色：三层法（手册口径，与本作扩写作业直接相关）

| 层 | 改什么 | 本作对应 |
|---|---|---|
| **第一层 结构修改（大改）** | 开局是否吸引 / 中段有无拖沓 / 高潮是否足够 / 结尾是否有力 / **伏笔是否回收** / 主线是否清晰 / 人物是否 OOC / 反派动机是否合理 | 对应 `bible/` 各卷卷纲 §十一自检清单 |
| **第二层 情节修改（中改）** | **删除冗余**（四条判据）/ 补充缺失（能力、情感、实力提升的铺垫）/ 调整顺序（高潮分布、爽点密度、悬念解开时机） | 对应本次扩写 |
| **第三层 语言修改（小改）** | 精简（"他慢慢地、缓缓地、一步一步地走过去" → "他缓步走过去"）/ 增强表现力（**把"告诉"改成"展示"**） | 对应 `扩写规范` §四六大技法 |

- **改稿顺序**：**结构 → 情节 → 语言 → 细节**（不可颠倒）。
- **改稿次数**：连载文最多改 **2–3 遍**（手册明确警告过度修改会拖垮更新）。
- **投入配比**：写作 50% + 修改 50%。
- 名家口径："文章不厌百回改""第一稿都是 shit"。

> ⚠️ **与去 AI 味规范的一处张力（必须给出裁决）**：手册第三层要求"把'告诉'改成'展示'"（show-don't-tell）；而 `调研-长篇不崩与去AI味.md` §8.2 指出，**过度执行 show-don't-tell 会在结构层刻出更干净的 AI 指纹**。
> **裁决**：两者不矛盾，是精度问题。执行口径＝**情绪词三分法**（详见 `方法/扩写规范-统一执行手册.md` §6.4）：
> - **A 类**（动作能演出的情绪：害怕/紧张/疼/累/愤怒）→ 走演出，禁止命名。
> - **B 类**（动作演不出的情绪：认命/释然/羞耻/迟疑/心软）→ **允许且必须直说**（每 3000 字 ≥1 次、≤3 次）。
> - **C 类**（空泛情绪形容词：深深的悲伤/无尽的痛苦）→ 一律删除。
> 手册说的"改成展示"，针对的是 C 类；B 类直说不违反手册精神。

### 5.2 注水判据

### 5.3 违约与解约四触发

长期断更 / 抄袭 / 内容违规 / 跳槽。

### 5.4 全勤双门槛

**日更 4000 字 + 不能断更 + 内容合规**；断一天全勤作废。
→ **本作对照**：章均 3000 字，日更 4000 字需 1.33 章/天。**这是本次把章均拉齐到 3000 字的现实理由之一**——原稿 1900–2200 字的章节，读者"值不值"与全勤门槛双重吃亏。

### 5.5 一稿多投

签约后严格独家；同一作品多投 → **封号 + 违约金 + 信誉受损**。不同笔名可写不同的书。

### 5.6 刷数据（手册措辞最重的一条）

> "被平台发现：封号 / 虚假数据误导自己 / 真实成绩不知道 / **法律风险**。**绝对不要刷！**"

### 5.7 合同隐形雷

| 雷 | 说明 |
|---|---|
| 最低月更字数 | 原文示例"每月不少于 10 万字"，未达标可能失去全勤/推荐/被解约 |
| 版权买断 | "尽量不要完全买断" |
| 独家期限 | 新人 3–5 年较合理 |

### 5.8 手册的两处内部不一致（记录备查）

1. **黄金三章字数口径**：《100 问》"第一章 800–1000 字" vs 《开头技巧》"3000 字内、前 1000 字主角出场、后 2000 字金手指"——粒度不同，可并用。
2. **《新人作者常见问题 100 问》实际只有 80 问**：页面自述"由于篇幅限制，本章仅展示前 80 问"。
