## 二、用途分层原则（关键）

参考素材分两层，**不可混用**：

1. **写作技法层**（rl1053081 文集）：提供"怎么写"的方法论——人物命题、冲突设计、伏笔控制精度、魔法设定的"现象化"、金手指生命周期等。**只取方法，不取设定**。
2. **设定考据层**（wenku 万智牌/DND）：提供"世界长什么样"的素材——planeswalker / 位面 / 五色法力等。**只取灵感，不直接抄名词**。

本项目已落地的对应做法：
- 万智牌"鹏洛克"概念 → 改写为本书术语 **鹏洛克**（canonical，扩写规范 §6.6）；官方旧译"鹏洛客"仅保留于 `方法/设定调研与参考资料.md` 的引用，不进正文。
- DND 宇宙观 → 抽象为 §3.5「位面体系与命名」的**自创位面名**（锈界/乙太海/黑暗虚空/光桥墟/五色境野渊/外域），不出现 DND 官方专有名词。

## 三、获取与落地流程（可复现）

```
1. 抓取文集页  →  WebFetch rl1053081  →  得到全部文章标题+顺序（一次拿全，不必逐篇）
2. 按需精读单篇  →  提炼"可迁移的方法点"（如：伏笔三重境界、魔法现象化）
3. 对齐红线  →  对照 world-bible §8「禁用万智牌/DND官方专有名词」+ §3.5 命名三铁律
4. 落地到本书  →  方法点转化为本项目的写作纪律/卷纲设计（如：伏笔账 F/L/E、代价弧四维）
5. 登记  →  若新增设定，必须先在 world-bible §3.5 / §2 登记，再写正文
```

**抓取注意事项**：
- bilibili 文集页为动态加载，WebFetch 能拿到标题与摘要列表（已验证可行）；若单篇正文过长，分篇 WebFetch。
- wenku.baidu.com 部分文档需登录/有防爬，优先取可公开段落；官方术语以"引用"方式标注来源，正文不出现。
- 所有外部灵感须经过"术语改写 + 命名登记"两道闸，才可进正文。
