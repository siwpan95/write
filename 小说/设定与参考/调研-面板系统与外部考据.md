## 一、MTG 官方设定：火花与鹏洛克的合法性背书

### 1.1 已核实的官方事实

| 条目 | 官方表述 | 出处 |
|---|---|---|
| 火花本质 | 所有鹏洛克都拥有一枚 **spark**，是「来自盲界永恒（Blind Eternities）的以太印记，烙在灵魂上」 | [MTG Wiki · Planeswalker (lore)](https://mtg.wiki/index.php?title=Planeswalker_(lore)) |
| 天然概率 | 约 **1/数百万** 有智慧的生物天生带火花；带火花者中只有**极少数**会点燃 | [Wizards 官方《You are a Planeswalker》](https://magic.wizards.com/en/articles/archive/feature/you-are-planeswalker-2008-07-25) |
| 点燃条件 | 点燃多由**极端压力或强烈情绪**引发，常见于**濒死体验**；但濒死也**不保证**点燃 | [MTG Wiki](https://mtg.wiki/index.php?title=Planeswalker_(lore)) |
| 点燃后果 | 点燃后立刻进行**第一次位面行走**，被拉进盲界永恒后**随机出现在某个位面**；不少新晋者第一次行走后就死了（呆滞、迷失、或压力致死） | 同上 |
| 盲界永恒 | 只有鹏洛克能在其中相对安全地穿行，且**时间有限**；无火花的凡人会被未收容的熵与法力**迅速摧毁** | Wizards 官方文 |
| 资格门槛 | 必须**有灵魂**且**能操纵法力、施展法术**才可能成为鹏洛克 | MTG Wiki |
| 点火异名 | 点燃又称 **triggering / flaring / ascension** | MTG Wiki |

### 1.2 对本书的三条实质支撑

1. **R7「虚空耐受」有原型背书**。官方设定明写「只有鹏洛克能生存，且**时间有限**」——本书的「黑暗虚空耐受 7→8→9→11→13 分钟」不是自创酷刑，是把官方设定里的模糊限制**量化成了可写作的分钟数**。这条让耐受表在设定上站得住。

2. **R4「原力觉醒十万分之一」与「1/数百万火花」形成梯度**。本书刻意让原力（本土）远比面板（外来）易得，这是有意的设定选择：让主角的金手指显得**稀有而非廉价**。官方 1/数百万的概率反过来强化了「主角是异常中的异常」。

3. **「第一次位面行走可能致死」是可用的伏笔矿**。官方明写新晋者首次行走后死亡率高。本书第 37 章点燃后并未立刻变强，反而身体虚弱、灰线开始——这与官方设定同构。**若后续要写「点燃的代价」，官方依据就在这里**，不必自己发明。

### 1.3 ⚠️ 版权红线（必须遵守）

官方设定属于 Wizards of the Coast。本书已在 `扩写规范 §五` 立规矩：**正文禁用万智牌/DND 官方专有名词**。本条只作"世界合理性"背书，正文不得出现「Magic」「万智牌」（除主角前世回忆语境）、「planeswalker」原词等。

本书的 canonical 译名是**鹏洛克**（`事实基线 §6`），官方旧译「鹏洛客」仅允许出现在 `方法/设定调研与参考资料.md` 的官方引用段，不得进入正文。

## 二、辐射变异生物学：本书「巨型变异蟑螂」的科学与现实

### 2.1 已核实的科学事实

| 条目 | 结论 | 出处 |
|---|---|---|
| **辐射不会让动物变大** | 变异普遍**降低**适合度与体型。「巨大鲶鱼」实为该鱼本来就大，非辐射所致 | [Mental Floss](https://www.mentalfloss.com/article/586059/chernobyl-animal-facts) |
| 真实辐射效应是**畸形** | 昆虫出现触角残缺、翅皱曲、腹部肿瘤；鸟类出现脸部肿瘤、部分白化 | [Smithsonian](https://www.smithsonianmag.com/arts-culture/chernobyls-bugs-art-and-science-life-after-nuclear-fallout-180951231/)、[DW](https://www.dw.com/en/nuclear-accidents-make-mutant-bugs-and-birds/a-19098683) |
| **无剂量阈值** | 剂量与突变率呈统计线性关系，**不存在"以下剂量无影响"的阈值** | DW（Tim Mousseau） |
| 野外生物比实验室敏感 | 同样剂量下，野外小鼠死亡率是实验室小鼠的 **8-10 倍**（实验室动物少受冷/饿等应激） | 同上 |
| **植物比动物耐辐射** | 植物细胞全能性强，可替换受损细胞；动物细胞高度分化，损伤常致命 | [BBC 中文](https://www.bbc.com/ukchina/simp/vert-fut-49037362)、[PMC 综述](https://pmc.ncbi.nlm.nih.gov/articles/PMC10005729/) |
| 变异会**自然消退** | 辐射源衰减后，种群经世代更替回归正常；隐性有害突变可潜伏多代 | DW |
| 变异率提升倍数 | Chernobyl 地区动植物基因突变率提升约 **20 倍**（2011 *Biological Conservation*） | Mental Floss |

### 2.2 ⚠️ 与本书的冲突点（必须处理）

**冲突**：`world-bible §7` 写「广东双马尾＝巴掌大，金属紫甲壳」，并归因为「经过百年辐射和污染催生的巨型变异种」。**这在现实科学上不成立**——辐射不会让东西变大变大变巨，只会让它畸形、衰弱、不育。

**三种处理方案**（需全哥拍板）：

| 方案 | 做法 | 代价 |
|---|---|---|
| **A. 改设定** | 蟑螂体型不变大，改为「数量畸变/甲壳增厚/繁殖力异常」 | 失去"巨型变异"的视觉冲击，读者爽感降低 |
| **B. 改归因** | 保留体型巨大，但**归因改为人工**（李氏火种计划基因改造/辐射只是筛选压力），并在文中点明「并非辐射催生」 | 需在正文埋一句，但反而强化 F13 火种计划线 |
| **C. 明确架空** | 在 world-bible 声明「本书辐射 mutagen 效应为架空设定，不作现实科学承诺」 | 需写进设定层，且免疫读者质疑 |

**工具已内置**：机扫目前**不自动报这条**（它不是 R1-R15 里的可判定规则），但 GUI 的「参考」页会持续显示本条冲突提醒，等你拍板后决定是否升级为 R16。

### 2.3 可反向利用的科学设定（增强可信度）

- **「体型大但衰弱」**：如果保留巨型设定，可加一条设定——巨型种**不育/易病/寿命短**。这样巨型就不是"进化"，而是「辐射把生长调控打坏了」的必然结果，反而更符合 Mousseau 的"突变降低适合度"。**建议采纳 B+弱化版**。
- **「无阈值」对应「白土区无处安全」**：既然不存在安全剂量阈值，本书「白土区=慢性照射区」就更合理，反而不必设定"避难所"。
- **「植物耐辐射」对应「骨补草」**：变异黑蕨（骨补草）能存活并入药，是因为**植物细胞可替换受损组织**。这给了一个现成的科学注脚。
- **汗腺失能（第 91 章）**：辐射损伤的典型表现之一就是皮肤附件损伤（脱毛、汗腺破坏），与 91 章"灰线爬过处汗腺失能、分界齐整"高度一致——这条**完全站得住**，可以放心写。

## 三、TRPG 机制：给战斗场面一个可算的底

### 3.1 已核实的 D&D 5e 规则

| 机制 | 规则 | 出处 |
|---|---|---|
| 难度分档 | DC 5 极易 / 10 简单 / 15 中等 / 20 困难 / 25 极难 / 30 近乎不可能 | [SRD5 Ability Score](https://broken.dnd-wiki.org/wiki/SRD5:Ability_Score)、[D&D Lounge](https://www.dndlounge.com/?p=4344/) |
| 属性修正 | `(score − 10) / 2` 向下取整 | 同上 |
| 核心公式 | `1d20 + 属性修正 + 熟练加值 ≥ DC` | [RPG Stack 速查](https://www.rpgstack.com/cheat-sheets/dnd5e/roll-resolution) |
| 优势/劣势 | 掷 2d20 取高/取低；**不叠加，互相抵消** | 同上 |
| 豁免 DC | `DC = 8 + 施法者修正 + 熟练加值` | 同上 |
| 被动检定 | `10 + 修正`（不做主动掷骰） | 同上 |
| 熟练加值 | **仅在熟练时加**，不是每次都加 | 同上（常见错误清单） |

### 3.2 群遭遇配平（为什么"7只二级"比想象中危险）

社区总结的经验公式：**n 只同级怪的总危险不是 n 倍，而是约 n^1.5 倍**。合成预算 `(Σ 单体^1.5)^(2/3)`。来源：[EN World · Encounters difficulty discussion](https://www.enworld.org/threads/encounters-what-effect-do-special-situations-have-on-difficulty.258536/)

**代入本书第 32 章**：主角打的是「7 只二级寄生体 + 1 只三级母体」。工具算得**合成难度 66、建议 DC 26（极难）**。这解释了为什么：

- 他必须先靠**跑动**突围、再逐个消耗
- 最后能赢，**靠的是母体旧伤这个弱点**（钢管捅旧伤），不是硬实力碾压

**这正好印证了 §2f「异族弱点解析」的必要性**——机制上，没有弱点解析这一章就是打不过。工具把这个"设计意图"量化出来了。

### 3.3 难度曲线：本书的锯齿结构

游戏设计通行的难度曲线有线性/指数/对数/**锯齿**/阶梯五种。锯齿型的结构是：每章从玩家战力**略低**处起步 → 章中追平 → BOSS 高出 10-20% → 下一章重置。来源：[Game Design · Difficulty Curves](https://gamedesign.gg/articles/difficulty-curves)

**映射到本书五卷**：

| 卷 | 卷名 | 难度形状 | 备注 |
|---|---|---|---|
| 一 | 火种 | 锯齿第一齿 | 面板觉醒、四步战略、点燃 |
| 二 | 位面行走 | 持续高于玩家战力 | 首次虚空、代偿代价 |
| 三 | 五色之光 | 锯齿第二齿 | 五色解锁、结构税、灰线加速 |
| 四 | 黑暗时刻 | **难度峰值**（卷名即如此） | 灰线 82 格、外域全失效 |
| 五 | 终局之火 | 峰值后奖励性回落 | 冻结代价弧、收束 |

**结论**：第四卷作为全书最难的卷，与灰线 82 格、原力唯一可用的设定**是自洽的**——不是作者随手安排，是难度曲线的必然峰值。工具会持续监控这条。

## 四、科幻 UI 面板设计范式（GUI 复刻依据）

### 4.1 已核实的范式

| 条目 | 要点 | 出处 |
|---|---|---|
| **Diegetic UI** | 把数据嵌进世界/角色本体（Dead Space 脊椎血条、Fallout Pip-Boy、Metro 手表），比外挂 HUD 更沉浸 | [StraySpark](https://www.strayspark.studio/blog/game-ui-ux-design-principles)、[MyGameDesign](https://mygamedesign.com/game-ui-ux-design-guide) |
| **按紧急度分层** | Critical（高对比+动画）> Important > Informational > Ambient（弱化到几乎融入环境） | 同上 |
| **形状优于数字** | 径向冷却条比数字读得快；精确数字只在必要时给 | [Made Good Designs](https://madegooddesigns.com/game-ui-design) |
| **稳定锚定** | 元素**不得跳位**；只动"出现/变化"动画，不动静止位置（肌肉记忆） | 同上 |
| **颜色不可独用** | 每个颜色信号必须配第二线索（形状/位置/图标），照顾色盲玩家 | 同上 |
| **数值字形** | 6 不能读成 8——用等宽数字/清晰字形 | 同上 |
| **动效时长** | 输入→视觉反馈 <16ms（60fps 一帧）；菜单转场 200-300ms | StraySpark |
| **200ms 读懂** | HUD 是**余光**读的；形状/位置/对比优先于文字 | Made Good Designs |
| **高对比** | 正文对比度 ≥4.5:1；鲜艳色占屏 **20-30%** 上限 | [Toxigon](https://toxigon.com/sci-fi-game-ui-design-principles) |
| **可脱战隐藏** | 只在相关时出现（Dead Space 探索时 HUD 完全消失） | StraySpark |

### 4.2 本书面板的复刻决策

第 5 章对面板的描写本身就是**diegetic UI 的教科书**——「悬浮在视网膜前方的全息投影」，它在主角**眼睛里**而非贴在屏幕上。所以 GUI 复刻按下列原则：

| 决策 | 依据 |
|---|---|
| **面板视觉 = 角色所见**（第一人称全息），而非后台管理界面 | 第 5 章明写「视网膜前方」；diegetic 原则 |
| **火花用径向圆槽** | 第 5 章原文「圆槽底部积累了五分之一的幽蓝色能量」「边缘有一道极细的白线，绕四分之三圈」——这已经是径向条，形状优先 |
| **灰线用读条** | 「左臂 35 格灰线读条」——离散格数适合分段条（形状可数，比数字快） |
| **数字用等宽字体** | 6 不读成 8 |
| **不跳位** | 属性/槽位固定，只有数值与弧长变化 |
| **灰线格数 >30 时** 视觉降饱和 | Critical 层级用颜色+形状双线索 |
| **五色法力用色块 + 文字双标** | 颜色不可独用原则（蓝/黑主色必须配字） |
| 面板边框**刻意保留毛刺** | 第 5 章原文「边缘没抠干净，放大了能看见一层毛刺」——这是设定内彩蛋，必须复刻 |

### 4.3 「毛刺」的额外价值

第 5 章里主角能认出面板，依据是**边框毛刺**（他自己抠图没抠干净的旧素材）。这意味着：

- 面板是**前世他亲手写的** → 毛刺是他的签名
- 这也解释了为什么「火花的圆槽边缘有一道白线绕四分之三圈」是他熟悉的底框（他画进度条用的底框，没来得及改成弧线）

**GUI 建议**：把毛刺做成 CSS 的细微边框不规则（clip-path 或 SVG 扰动），并允许用户「抹掉毛刺」作为彩蛋开关——抹掉后代表"他不再记得那晚的细节"，可与代价弧联动。

## 六、待全哥拍板的开放项

1. **辐射巨型蟑螂的归因**（§2.2）—— A 改设定 / B 改归因 / C 声明架空。**这是本次调研最重要的产出**，直接影响第 5、7、22 章的设定根基。
2. **属性修正公式口径**：本书属性 4-24 量表与 5e 的 3-18 不同，当前工具用 `floor((属性−4−10)/2)` 映射（4→−1, 18→+4, 24→+7）。是否接受这个映射？
3. **群遭遇配平是否写进正文**：机制已量化第 32 章的难度，但正文要不要显式呈现"发现弱点才可打"的机制感？
4. **毛刺彩蛋是否做成可交互**：抹掉毛刺 = 失去前世记忆细节，可与代价弧联动。
