## 二、正文梳理（分章大纲）

### 第一章：异界醒来
- **场景**：陌生硬板床、土坯屋、油灯、粗布短褂。
- **关键信息**：
  - 魏成河前世为加班社畜，深夜去茶水间倒咖啡途中猝死（额头磕桌角、后脑着地）。
  - 醒来发现身处陌生废土民居，身体瘦弱、双手"属于别人"。
- **悬念落点**：*"我到底，在哪？"*

### 第二章：记忆融合，两世为人
- **关键信息**：
  - 原主记忆涌入融合：此身同名少年已咽气，魏成河灵魂接替。
  - 世界观展开：平行世界曾科技极端发达（摩天楼入平流层、量子计算、基因编辑）→ 资本派系终极战争、禁忌武器摧毁生态 → 精英乘世代飞船弃世而去 → 留下数十亿"黔首"→ 百余年后成废土：辐射、毒水、毒土、变异生命、失控战争机器。
- **人物动机确立**：前世死得窝囊，这一世"总不能再窝囊地死一次"。

### 第三章：三妹魏小雨与死因疑云
- **场景**：魏小雨（三妹，17-18 岁）登场；对话。
- **关键信息**：
  - 魏小雨失明（淡粉色荧光瞳 = 辐射诱变的"荧光性视网膜萎缩症"，废土穷人家常见病）。
  - 原主是被"疤脸刘"等人送回，对方称"不小心摔倒撞到头"——说辞可疑。
  - 原主混迹南街黑市；与疤脸刘、瘦猴、阿芸为伍（魏成河视角判定：一群秃鹫）。
  - 大哥**魏青山**：清道夫公会成员、李氏工厂保卫科中层、意外觉醒原力；曾警告"再踏进黑市就打断你的腿"；**还有三天回家**。
  - 原主最后记忆：黑市深处帐篷，有人提"新来的货""要不要试试"，之后断片。
- **情感锚点**：魏成河答应小雨不再跟那些人出去；前世无人收尸 vs 这一世有人等他回家。
- **行动**：出门探查，"天亮之前回来"。

### 第四章：废土格局与力量路线盘点
- **关键信息**：
  - 白土区 = 旧时代超级都市远郊工业区的废墟聚居地。
  - **势力格局**：李氏生物公司（垄断配给券、医疗、唯一辐射检测仪、武装护卫）｜黑石帮（南边黑市、走私地下交易）｜清道夫公会（辐射区边缘清理，最接近"正经行当"）｜拾荒者团伙、流匪、辐射邪教。
  - **变异兽图鉴（初步）**：巨蝎（甲壳防手枪弹）、三头秃鹫、"掘地者"（卡车级穿山甲，破土吞人）。
  - **力量路线盘点**（主角亲口归纳）：
    1. **原力觉醒**（最优）：十万人中一人；大哥魏青山是意外觉醒的例外；觉醒者能隔空取物、预判攻击、干扰意志，且强化身体、抗辐射、延寿。
    2. **基因飞升**（基因编辑，废土上仅李氏可能掌握，且只拿底层当实验材料）。
    3. **合成进化**（意识上传/机械化，需纳米技术与材料科学）。
    4. **灵能飞升**（高维连接，风险极高，失败者变疯子）。
    5. **义体飞升**（全身机械化，最"接地气"，但义体化越深人性越淡）。
  - 主角尝试感应原力失败（原文："只有风……什么都没有"）。
- **行动**：转向南边黑市——查死因 + 找机会。

### 第五章：金手指登场（核心章）
- **场景**：巷中拍死一只"广东双马尾"巨型变异蟑螂（巴掌大、金属紫甲壳、顽强生命力）。
- **关键信息**：
  - **面板浮现**：
    - 【魏成河】
    - 体质 4｜根骨 4｜灵敏 4｜精神 4｜悟性 4
    - 天赋：铁骨（被动，骨骼密度略高、抗打击小幅提升）
    - 技艺：武器掌握（被动 Lv.1，冷兵器本能肌肉记忆）；跑动（主动 Lv.1/冷却 1 分钟，5 秒内提速 15%）
    - 【火花：0（4%）】——圆槽底部积累约五分之一幽蓝能量
  - **金手指来历**：前世猝死前深夜赶制的最后一个产品——万智牌同人游戏外挂【鹏洛克速成指南】的个人面板模块，随灵魂穿越并**真实生效**。
  - **机制揭示**：击杀被判定为"异族"的生命 → 获得火花；攒满点燃 → 成鹏洛克（穿越多元宇宙、汲能、近乎无限寿命）。
  - **规则转译**：此世界因辐射污染发生"本质变异"的生物，被面板判定为"异族"。
  - 主角推算：若每只 4%，约 25 只攒满。
- **情绪落点**：*"事情……似乎变得有趣起来了。"* 目标明确——刷怪。

### 第六章：验证机制，锁定工厂
- **关键信息**：
  - **修正认知**：连杀十几只普通（小号、暗褐甲）蟑螂，火花纹丝不动 → 只有发生"质变"的特殊个体才带火花，光靠数量堆无效，得讲质量。
  - 决定前往李氏生物工厂：三号蟑螂养殖区养殖员身份（靠大哥关系所得），养殖区基数大，有概率出特殊个体。
  - **工厂外景**：八米高漆黑混凝土墙 + 荆棘铁丝网 + 高压电网 + 自动能量武器，"像监狱"；底层人视其为吃人地（进去多、出来少）。
  - 虹膜验证通过：魏成河，权限等级 D。
- **伏笔**：*"这种级别的安保，里面到底在养什么？"*

### 第七章：养殖区首杀（4%→7%）
- **场景**：3-C 养殖区，石棉板蟑螂"公寓"，热浪腥臭。
- **关键信息**：
  - 工作流：自动逮捕器批量吸捕（配给配额），利用混乱中"异常个体逃窜行为"进行筛选。
  - 逮住一只油亮深黑、大一圈、有策略性闪避动作的个体 → 捏碎 → **火花 +3%（7%）**。
  - 效率参考：处理约两三百只出一只特殊个体。

### 第八章：捕捉之难与身体之弱
- **关键信息**：
  - 特殊个体速度快、会躲，靠眼力 + 手速，屡屡脱手；不能动用杀虫剂（蟑螂=公司资产、废土优质蛋白质来源）。
  - **身体问题**：全属性 4，高强度精细操作十余分钟就虚脱。
  - **基准设定**（作者借主角之口确立）：废土健康成年男性平均约 10～11；主角全 4 不及常人一半。
  - 体弱归因：环境污染（基因先天受损）+ 原主在大哥觉醒成靠山后纵欲酗酒、混黑市掏空身体。
- **需求**：提升属性（面板升级 or 营养补充）。

### 第九章：定下四步战略（7%→10%）
- **关键信息**：
  - 抓到第二只特殊个体（惨白甲壳、关节倒刺）→ **火花 10%**；凌晨 3:47 收工。
  - **主角四步规划**：
    1. 利用养殖员身份在工厂继续筛选积累火花，并留意更高等级"异族"（公司杂交实验产物）。
    2. 改善体质：蛋白棒 + 辐射区变异植物土方补剂。
    3. 火花与属性达标后进黑市：查原主死因 + 找高密度异族集中区。
    4. （留白）面板已彻底改变格局，终极目标 = 点燃火花成鹏洛克。
  - 回家，小雨装睡等他；收尾悬念：*"黑暗深处，有什么东西正在苏醒。"*
- **伏笔收束**：变异兽 / 工厂地下实验体 / 黑市帐篷里等"新来的货"的人 / 主角灵魂。

### 时间线（穿越第一夜）
深夜苏醒 → 记忆融合 → 与小雨对话 → 出门（查死因 + 感应原力失败）→ 拍死变异蟑螂（金手指觉醒）→ 验证普通蟑螂无效 → 入工厂 → 3-C 区刷怪（4%→10%）→ 凌晨 3:47 收工回家。**一夜之间完成金手指三连验证**，节奏紧凑。

## 五、基本框架（搭建稿）

### 5.1 世界观框架

**世界名（暂定）**：无官方命名，主角称"平行世界""废土"；建议定名如 **"烬地"** 或保留废土称呼。

**历史四阶段**：
1. **黄金时代**（百余年前）：科技狂飙（平流层摩天楼、量子网络、基因编辑近神）。
2. **生态战争**：资本与派系争夺最后资源的终极厮杀，禁忌武器永久摧毁生态（大气环流、水源、土壤、辐射尘）。
3. **大撤离**：精英（财阀/科学家/政客）携世代飞船、科技、资源、护卫弃世奔星海。
4. **废土时代**（百余年）：黔首后裔在毒土上种畸形作物、废墟中拼凑工具、与辐射共舞；秩序崩解，势力割据。

**地理层级**（由内向外）：
- **白土区**：旧超级都市远郊工业区废墟上的棚户聚居地（废铁皮/水泥板/集装箱），主角出生点。
- **南街黑市**：白土区最南，黑石帮地盘，地下通道摊位、地下拳场、**"畸形巷"**（兜售辐射区深处的怪异活物）。
- **李氏工厂区**：漆黑高墙 + 电网 + 能量武器的堡垒；表面生物养殖/医药，内藏实验。
- **辐射区（废墟带）**：旧时代城市废墟，失控自动防御系统、战争机器、变异兽盘踞；清道夫的工作区。
- **（远期）星空**：精英世代飞船去向——为后期"鹏洛克穿越位面"留的太空线。

**核心生存逻辑**：干净水、无毒肉、能用的子弹 > 一切；配给券 = 废土货币；辐射剂量 = 寿命计价单位。

### 5.3 力量体系框架（三线并行）

**线 1：本土路线——原力觉醒（星战本土化）**
- 定义：一切生物共同创造的能量场；敏感者十万中无一。
- 能力：隔空取物、预判攻击轨迹、干扰意志、强化肉身、抗辐射、延寿。
- 觉醒条件：基因序列 + 生死边缘（魏青山模式）。
- 用途：大哥是行走的参照系与潜在导师/对照。

**线 2：旧时代遗产路线——四大飞升（群星本土化）**
- 基因飞升：基因编辑强化（李氏垄断，底层只能当材料）。
- 合成进化：意识上传 / 机械化（纳米技术，废土缺失）。
- 灵能飞升：高维联系，高风险高收益（辐射教派或为其残响）。
- 义体飞升：全身机械化（最接地气，但人性流失）。
- 用途：作为主角放弃的备选，同时是**敌我势力**的科技树来源（李氏=基因线，黑市技师=义体线）。

**线 3：主角专属——旅法师面板（万智牌本土化）**
- 五维属性：体质 / 根骨 / 灵敏 / 精神 / 悟性。
- 属性基准（已由正文确立，建议固化）：**4 = 主角现状（虚弱）；10～11 = 废土健康成年均值；15+ = 精锐战士/觉醒者；20+ = 超常存在**。
- 天赋槽：铁骨（被动）等。
- 技艺槽：武器掌握（被动）、跑动（主动/冷却）等——Lv 可成长。
- 核心资源：**火花**（击杀"异族"积累；攒满 → 点燃 → 鹏洛克）。
- 异族判定：经辐射/污染发生"本质变异"、被世界规则认可其"异质性"的个体（普通蟑螂无效，特殊变异体有效）。
- 火花产出规则（建议固化）：普通生物 0｜初级异变体 1～5%｜深度异变/实验体 10～30%｜高位异族更高。

## 六、设定一致性与改进建议

1. **火花效率认知**：第 5 章"25 只攒满"与第 6 章"普通个体无效"矛盾已由剧情自洽修正，但建议补一句主角对"特殊个体比例"的估算（千分之几），与第 7 章"两三百只出一只"呼应。
2. **属性基准锚定**：正文确立"均值 10～11"，建议后续所有 NPC 数值沿用同一标尺，避免后期战力崩坏（如清道夫精锐 13～15，大哥觉醒后 18+）。
3. **原主死亡记录的隐患**：虹膜系统是否标记死亡？工厂是否追查？建议作为伏笔回收（#8）。
4. **击杀→火花的世界观解释**：面板为何能"吸"异族火花？建议中期补设定（面板 = 前世代码在此世界的规则具现；火花 = 异族体内异质性凝聚物），为"击杀强大异族"提供合理性。
5. **五色法力（万智牌）**：官方设定中鹏洛克驱使五色法术力，建议在点燃后逐步引入，作为比"原力"更高维的施法体系，与本土力量线形成落差感。
6. **小雨眼病治疗线**：三线力量体系各有治疗可能（原力治愈/基因修复/鹏洛克法术），是贯穿全文的情感钩子，建议刻意保留。
7. **节奏提醒**：目前 9 章均在"第一夜"，信息密度高但场景重复风险（蟑螂刷怪）已现苗头，建议第 10 章起引入新场景（白天工厂人际、黑市初探）稀释。
