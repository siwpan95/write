### 本卷的玩法迭代（第三次换引擎）

| 卷     | 引擎                | 为什么换                           |
| ----- | ----------------- | ------------------------------ |
| 一     | 刷怪攒火花             | 底层逆袭，数字成长                      |
| 二     | 死寂位面捡垃圾 → 回废土双重碾压 | 火花封顶后必须换产出                     |
| **三** | **五色法术的两两组合解**    | 单一色的"汲取+解析"已在第二卷用尽；**组合**才是新玩法 |

> **组合示例（本卷法术树的骨架）**：
>
> - **蓝 + 白** = 把"解析出的结构"写成"不可违反的约束"（对敌：定身/封锁；对人：契约）
> - **蓝 + 黑** = 解析出代价路径，然后把代价转移出去（**灰蚀转移的技术化**，第二卷 76 章是本能，本卷是法术）
> - **蓝 + 红** = 把结构过载成爆发（拆解 → 引爆，一次性的高伤害）
> - **蓝 + 绿** = 把破损结构重新长回去（**这是治小雨眼睛的技术基础**，本卷只做到"能长回去，但缺频谱图"）
>
> **硬约束**：每学会一组组合，必须**同时**写清它的代价与反制（见 `通用模板包/03` 能力—代价—反制三件套）。组合不是无成本的叠加。

## 九、换地图风险防线（本卷硬性执行）

第三卷是"位面往返最频繁"的一卷（五色位面各一次 + 外域），换地图风险高于第二卷：

1. **人来人往**：每次进入位面都必须有一个"回来的理由"被明写（小雨的梦 / 大哥的伤 / 冷库名单的进度）。位面段落中间插入锈界插曲（章 110/114/118 均回到锈界）。
2. **先去后回**：械理境（108）作为第一次外层位面访问，先建立"外层位面规则不同的预期"，之后枯索野（111）、序律境（136）才有层次。
3. **势力延续**：李氏/花押线贯穿全卷；赵珩在 110 出卖他，保证"废土线没有因为换地图而停摆"。
4. **走剧情不走风景**：五色位面的判词**只在第一次进入时给一句**，之后不再解释。奇观嵌进动作句。
5. **停留长度封顶**：单个外层位面连续停留 **≤3 章**（本卷所有位面段落均在 3 章以内）；外域首现仅 1 章（140）。
6. **规则必须落地**：外域"五色均等"不是设定炫技，而是**为第四卷压制主角做的机制准备**——本卷末必须让读者亲眼看到主角在外域变弱一次。
