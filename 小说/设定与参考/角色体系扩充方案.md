> ② 网文四级人物层级（核心主角 / 核心配角 3-6 人 / 功能配角 / 龙套）
> ③ 反派三层金字塔（认知型 → 势力型 → 终极型）
> 状态：**方案稿，待确认后再落地进 `bible/characters/`**

## 三、补位方案：新增 10 个角色

> 硬规则：每个新角色必须**挂钩一条已有伏笔**，不允许凭空加人。

### 1. 祁藕 — 【恋爱对象 + 催化】

| 字段 | 内容 |
|---|---|
| 一句话内核 | **父亲是李氏那只"手"，女儿是全书唯一愿意提笔的人。** |
| 基础档案 | 女 / 二十二 / 配给站新任记档员 / 一手好字，字写得比印出来的还正 |
| 欲求 | 把父亲留下的那本账抄完，抄成一份能给人看的册子 |
| 恐惧 | 怕自己抄着抄着，就变成了父亲那只手 |
| 与主角张力 | **他靠"数"活着，她靠"记"活着。他不停在忘，她什么都记得——她是他的活备份，也是他的痛处** |
| 挂钩伏笔 | **F10 誊抄名单** + 齐满囤线（父女反向设置） |
| 首登场 | 第三卷末埋名，第四卷正式登场 |
| 弧光 | 替父还债 → 成为他唯一的外部记忆 → 第五卷成为"他还记不记得自己"答案的一半 |

### 2. 陈默 — 【密友 + 见证型】

| 字段 | 内容 |
|---|---|
| 一句话内核 | **一个从不问为什么、只替他记数的人。** |
| 基础档案 | 男 / 四十上下 / 南街挖井人兼背尸人 / 随身一个油布包的小本子 |
| 欲求 | 把白土区每一天死了几个、活了几个记全 |
| 恐惧 | 怕有一天没人认得那些名字 |
| 与主角张力 | 主角唯一不必解释的关系——**他忘掉的数，陈默本子上都有**（与小雨"我给你记"、老周"我给你记着"构成三人记账体系） |
| 挂钩伏笔 | **F10 名单** + 124 章已落"六十二块，我给你记着" |
| 首登场 | 第四卷初 |
| 弧光 | 记数人 → **131 章白土区塌方死于其列** → 本子留下来，主角第一次主动翻别人的记忆 |

### 3. 二两 — 【插科打诨 + 信使型】

| 字段 | 内容 |
|---|---|
| 一句话内核 | **把坏消息编成顺口溜卖的半大小子。** |
| 基础档案 | 男 / 十五六 / 黑市报信的 / 口头禅："这话我说了，钱你不给也行，记着就行" |
| 欲求 | 活到能自己定价那天 |
| 恐惧 | 怕自己卖的消息有一天没人要 |
| 与主角张力 | 油滑 vs 沉重的节奏缓冲；**他是全书唯一敢跟主角贫嘴的人** |
| 挂钩伏笔 | 黑市线 + 可作为任意新线的引入口 |
| 首登场 | 第四卷 |
| 弧光 | 油滑报信 → 第四卷关键时刻用一条消息救人 → 第五卷成为唯一的"活口证人" |

### 4. 石（守默者） — 【"心声"角色 + 与低语者对撞】

| 字段 | 内容 |
|---|---|
| 一句话内核 | **他割了自己的舌头，为了永远不应那一声低语。** |
| 基础档案 | 男 / 五十上下 / 辐射教派"不应派" / 舌已自割，以石板刻字说话 |
| 欲求 | 证明"低语是钓饵，应者被数" |
| 恐惧 | 怕自己死后没人守这条规矩 |
| 与主角张力 | **主角的法术本质是"解析"＝"回应"。石主张不回应——直接对撞主角立身之本** |
| 挂钩伏笔 | **E4 虚境低语** + 全书核心禁忌"别让它们读完你的名字" |
| 首登场 | 第三卷末 / 第四卷正式 |
| 弧光 | 教派分裂代言人 → 第四卷被迫开口（以刻字） → 成为"应还是不应"的活答案 |

### 5. 崔照 — 【中层势力型反派 ★核心补位】

| 字段 | 内容 |
|---|---|
| 一句话内核 | **把账算得最清的人，也是主角烧掉价值论后最可能变成的那个人。** |
| 基础档案 | 男 / 四十许 / 李氏北边炉子总管 / 随身一把算盘，说话先报数 |
| 欲求 | 用最少的料，保住最多的活人 |
| 恐惧 | 停手 → 前面烧掉的那些就全白费了（**"退不了"的理由**） |
| 自洽逻辑 | "四百个人的命换全城人的命，这账是正的" —— **局部正确，与主角 D3 烧后的"效率最优"正面撞车** |
| 与主角关系 | **镜像对手**：不是他针对主角，是主角恰好挡了他的账 |
| 挂钩伏笔 | **F13 人工火花/火种计划**（一旬十三袋的执行人）+ 131 主题转折 |
| 首登场 | 第三卷末现身 → 第四卷多次交锋 |
| 弧光 | 总管 → 第四卷末发现自己也在那份名单上（反转）→ 第五卷成为"算了这笔账的人"的代价样本 |

### 6. 哑笔 — 【陪衬 + 刺痛对照】

| 字段 | 内容 |
|---|---|
| 一句话内核 | **反派身边那个手不抖的人。** |
| 基础档案 | 男 / 年纪不明 / 崔照的记账先生 / 不说话，只写；写出来的字与花押同源 |
| 欲求 | 不明 |
| 恐惧 | 不明 |
| 与主角张力 | **铁手要"一只绝对不抖的手"（F7 条件②），而反派身边就有一个。主角要不要去求他？** |
| 挂钩伏笔 | **F7 小雨眼病条件②** + **L8 花押**（字同源） |
| 首登场 | 第四卷（随崔照） |
| 弧光 | 陪衬 → 第四卷主角真的去求他刻针，**代价是替他抄一份名单** |

### 7. 老阚 — 【观众视点 + 平衡角色】

| 字段 | 内容 |
|---|---|
| 一句话内核 | **走过最远的路，只信脚底板。** |
| 基础档案 | 男 / 六十上下 / 车马铺马倌 / 口头禅："天上掉下来的东西，都得还。" |
| 欲求 | 把车马铺撑到最后一匹马死掉 |
| 恐惧 | 怕自己信了一辈子的"脚底板"是错的 |
| 与主角张力 | **主角带回的每样东西（壳/牌子/布），老阚都能给出更朴素的本地解释——有时他是对的** |
| 挂钩伏笔 | 车马铺线（T99/T101 已登场场景）+ 归人的"飞船视角"形成内外双怀疑 |
| 首登场 | 第四卷（车马铺已有场景，低成本带入） |
| 弧光 | 本地常识代言 → 第四卷被证错一次 → 第五卷成为"锈界还有人活着"的活口之一 |

### 8. 祁柱 — 【对比性角色 + 主题落地】

| 字段 | 内容 |
|---|---|
| 一句话内核 | **同一起点，他走了"另一条路"。** |
| 基础档案 | 男 / 二十六 / 祁藕的哥哥 / 加入李氏押运队 |
| 欲求 | 让妹妹不用再记账 |
| 恐惧 | 怕自己押的东西有一天是妹妹 |
| 与主角张力 | **同一处境的两种选择：主角往里查，他往里走** |
| 挂钩伏笔 | **F10 名单** + F6（组织样本运输） |
| 首登场 | 第四卷 |
| 弧光 | 押运夫 → 升上去 → **第五卷成为那四百人押送的最后一环，发现名单上有妹妹的名字** |

### 9. 阿禾（回声态） — 【主题性角色 ★最强悬念】

| 字段 | 内容 |
|---|---|
| 一句话内核 | **他忘了自己干过什么，于是那个人变成一个他认不出来的陌生人。** |
| 基础档案 | 男 / 年纪停在十五岁 / D3 价值论的物证（铜齿轮）持有者 |
| 设定要点 | **不出现在回忆里（因为已烧），而是以"他不知道是谁的陌生人"反复出现在人群中——读者认得，他不认得** |
| 与主角张力 | D3 的"忘了自己的罪"具象化；每一次擦肩都是一次隐性指控 |
| 挂钩伏笔 | **D3 价值论 / F16 铜齿轮**（133 埋、134 症状） |
| 首登场 | 133 章（回忆）→ 134 章后转为"回声态"反复闪现 |
| 弧光 | 被遗忘的罪 → 第四/五卷被重新揭开（铜齿轮回收） |

### 10. 白土区孩子帮（3-4 个半名小鬼） — 【见证 + 情绪缓冲】

| 字段 | 内容 |
|---|---|
| 一句话内核 | **唯一敢靠近他的人，因为孩子不怕灰线。** |
| 功能 | 见证主角变化 + 情绪缓冲 + 主题落点（呼应归人那句"你们这儿，还有多少人活着"） |
| 与主角张力 | 他们会摸他手臂上的格，数出来，然后大声报数——**他把这当成唯一不怕自己的目光** |
| 挂钩伏笔 | 灰线（F12）+ E3 归人台词 |
| 弧光 | 群像底噪 → **131 章塌方死其中两个**（主题转折的情感重锤） |
