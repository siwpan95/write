## 四、复现顺序

脚本内路径写死为 `/data/workspace/steel_dream`，换环境需改各脚本的 `BASE / ROOT / OUT_* / SRC`。依赖已预装：`python-docx`、`docxlib`（`/data/skills/docx/scripts`）、LibreOffice、Poppler、`reportlab`、`pypdf`、思源宋体／黑体。

```bash
# 单卷（以卷一为例；卷二、卷三由 make_scripts.py 派生同源脚本）
python3 steel_dream/build.py
python3 steel_dream/postprocess.py

# 卷二
python3 steel_dream/vol2/make_scripts.py
python3 steel_dream/vol2/build2.py
python3 steel_dream/vol2/post2.py

# 卷三
python3 steel_dream/vol3/make_scripts.py
python3 steel_dream/vol3/build3.py
python3 steel_dream/vol3/post3.py

# 全帙合订本（读三卷 part*.txt + 番外 extra*.txt，正编不改一字）
python3 steel_dream/build_omnibus.py
python3 steel_dream/post_omnibus.py
```

`post*.py` 负责 PDF 精装后处理：满版深炭底层、暖灰做旧纸色、双名制页眉（双数页书名／单数页辑名）、外侧页码、中文字体嵌入。`clean*.py` 为一次性文本清理（去掉创作过程中混入的英文残留与卷次元标签），已就地写回源文本，无需重跑。

- 三卷命题递进：谁能定规矩 → 规矩怎么变成产权 → 产权怎么变成国家。核心物件依次为**牌、铁丝、发票**；死亡方式依次为**被枪、被冻、被归档**。
