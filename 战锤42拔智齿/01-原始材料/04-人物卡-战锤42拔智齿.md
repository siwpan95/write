## A. 主角人物卡 · 陈冲（阿Bin）

### A1 角色速查

| 字段 | 内容 |
|---|---|
| 一句话角色内核 | 把「不肯被安排的人生」包装成「赖在梦里不肯醒的少年」 |
| 一句话处境 | 卡在「考上了七中、该长成父母期望的样子」与「梦里那把剑比现实更真实」之间 |
| 一句话弧光 | 从「被动做梦的少年」→「主动走进梦的人」 |

### A2 基础档案

| 字段 | 内容 |
|---|---|
| 姓名 | 陈冲；被唤作 **阿Bin**（真名与乳名张力，见 `01` §五） |
| 性别/年龄 | 男；15–16 岁（生理），心理年龄因梦线体验略「老」（错位：梦里像经历过生死） |
| 身份/职业 | 市七中新生；隐性身份＝梦内剑客/「第666号」 |
| 外貌记忆点1 | 醒后虎口一道浅红痕（梦剑残留，第08章） |
| 外貌记忆点2 | 左臂握剑后的酸胀感与虎口发麻（梦战斗的体感签名） |
| 别称一览 | 阿Bin（同伴/自呼）· 陈冲（正式/父称）· 「外乡人」（梦内老者称，第11章） |
| 出身/阶层 | 县城工人家庭（父陈迹＝管道维修工），爬向市重点七中 |

### A3 性格图谱七件套

| # | 字段 | 内容 |
|---|---|---|
| 1 | 核心标签 | 钝感·倔·观察细·坏脾气（缺点）·生命力惊人 |
| 2 | 深层欲求 | 想确认「自己是谁」，而非被安排成谁 |
| 3 | 核心恐惧 | 变成「流水线上的零件」（失去自我） |
| 4 | 伪装 | 表面普通、配合的少年，把梦当「幻想」轻描淡写 |
| 5 | 保护策略 | 沉默观察；用自嘲/玩笑盖过不安 |
| 6 | 失控触发 | 身体出现无法用现实解释的梦痕（如蜘蛛咬痕） |
| 7 | 致命弱点 | 太能忍——把异常吞下去，反而让梦越陷越深 |

### A4 欲望-恐惧-错误信念三角

| 顶点 | 内容 |
|---|---|
| 欲望 | 弄清梦里那把剑、那个山神、第666号到底意味着什么 |
| 恐惧 | 醒来后「什么都没发生」，自己只是个普通少年 |
| 错误信念 | 「梦只是梦，醒了就什么都不是」（句式：只有__才配__） |
| 矛盾点 | 越想弄清梦，越怕梦只是幻觉——欲望与恐惧互相拆台 |
| 信念来源 | 县城「考上好学校就有出路」的单一评价（父母/老师灌输） |
| 主题对齐 | ↔ 全书「不肯被安排」内核一致 |
| 弧钩 | 梦线异常持续渗漏（R2），不断撞击「梦只是梦」这一信念 |

### A5 能力与持有

| 字段 | 内容 |
|---|---|
| 核心能力 | 梦内剑术（近身撩/劈/横扫，左手换剑，第08章）；天赋「不用听完整推导」 |
| 辅助能力 | 游戏计算力（女警五发必中，第03章）；《磐石鼎息真功》体能（第11章，非超能） |
| 装备/道具 | 梦中之剑（恒定信物，R11）；现实侧无特殊 |
| 能力代价 | 每次梦战醒来残留体感（痛/酸/痕）；现实体能消耗 |
| 能力天花板 | 梦内仍会被黑影创伤；目前仅能击碎单一个体，未触梦内深层 |

### A6 人际关系（摘要）

- **陈迹（父）**：血缘·依存。名字来自「隙中驹，石中火，梦中身」（第09章），是阿Bin 现实锚点也是压力源。
- **马化云**：同窗·镜像。同样在和焦虑斗争（第08章），是阿Bin 少数能说梦的人。
- **张有志 / 林盛**：同窗·伙伴。天台四人组成员，目前扁平，卷一后续待深。
- **黑色人影**：梦内·对手。试炼者/守门者，非人格反派。

### A7 行为特征

- 说话少而准，常用自嘲；梦战斗时动作描写多、对白近零（见 `05` 章型表）。
- 痛觉清醒：用咬下臂、数心率等身体动作撑意识（第08章）。

### A8 过往伤口 / 弧光

- 伤口：被「成绩=出路」单一标准框定，天赋被老师当众判为「不踏实」（第02章）。
- 弧光：从「梦是逃避」到「梦是另一种真实」，主动走进石床之后的深层。
