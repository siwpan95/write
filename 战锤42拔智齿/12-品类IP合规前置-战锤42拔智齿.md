## 四、去 GW 化改造清单（**仅在决定商业化时执行**）

1. **换书名**：现名「战锤42：拔智齿」→ 完全脱离 GW 命名体系。
2. **换章名**：第 02／05／11 章的「剑魔」「地狱回声世界」「蜘蛛咬痕」→ 自造意象。
3. **换专名**：正文中的「剑魔」「山神」等直接指涉 → 自造名词。
4. **世界观落地**：梦境线的剑／蜘蛛意象改为原创体系（保留「梦境与现实错位」的机制，替换素材来源）。
5. **联动同步**：廓者未名夜 的四神设定**同步处理**（见 §三）。
6. **加非官方标注**（若仍保留任何指涉）：封面／简介／页首显著位置写明「非官方同人，与 Games Workshop 无关，IP 归其所有」。
7. **复核残留**：改完后全量检索 GW 专名表（§五）必须零命中。

## 六、法域事实（同人创作的边界，中国法）

2026-11-13 联网核（中国新闻出版广电报《中国新闻出版广电报》专家分析转载、
中国知识产权资讯网《二次创作行为的版权边界探研》、法院释法等）：

| 要点 | 结论 |
|---|---|
| 《著作权法》第 10 条 | 著作权人享有**改编权**：允许或禁止他人对原作品改编、再创作 |
| 《著作权法》第 24 条 | 合理使用 13 种情形，含「为**个人学习、研究或者欣赏**使用他人已发表作品」 |
| 同人的两种类型 | **演绎类**（续写/前传/改编，保持人物情节环境基本要素）受演绎权调整；**创意借鉴型**（只借人物关系、创作技法、故事背景等抽象范畴）**不受表达层保护**，通常不侵权 |
| 商业性 vs 非商业性 | 是**重要坐标**：但「任何作品一经发表即有盈利可能性，司法难以认定同人属非商业使用」；**一旦上传平台传播，即与起号、引流、带货等商业目的密不可分**，不再纯粹是私人表达 ⇒ 「个人使用」在实务中难以成立 |
| 判例 | **金庸诉江南**：因**商业性使用**而强化了侵权认定 |
| 市场关系 | 同人读者基本衍变自原作同好者，受众市场与原作**不冲突**，不侵占原作市场 |
| 实务建议 | 对知名 IP 二次创作应谨慎，**优先取得授权**；避免抄袭、避免歪曲原 IP 形象、避免损害原作品市场 |

> **落到本项目**：非商业阶段（内部稿、圈内分享）**无须改动**；
> 决定商业化时，路径是「**取得 GW 授权**」或「**去 GW 化改造**」二选一（§四）。
