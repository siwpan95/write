### 2.3 法则的真实地位（**这一段决定了全书的智力诚实**）

法则**不是**这个世界的物理定律。它们是棋子（人）在反复伤亡中归纳出的运行参数，写在《勘定通则》里，共四十二条。

| 它是什么 | 它不是什么 |
|---|---|
| 归纳 | 定律 |
| 可以被违反（第 37 条） | 违反必死 |
| 有例外、有争议、有地区差异 | 普适 |
| **由人写的** | 由神写的 |

> **这条设定是全书反"设定秀"的保险**：任何角色引用法则，都只是在引用"前人的经验"，
> 而不是在宣读"宇宙真理"。所以**法则可以被辩论、被误用、被推翻**——这给了智斗戏空间。
>
> 同时它埋了结局：如果法则是人写的，那么**写法则的人也能改法则**。
> 第 42 条"结卷须十三册同签"是全书的门锁，而钥匙在"谁有资格代表一册"上——这是卷四的核心争夺。

## 3. 认知分层与九宫格

### 3.1 十级认知（C-1 ~ C-10）

| 段 | 级别 | 你能看见什么 | 你得付什么 |
|---|---|---|---|
| **事故层** | C-1 | 只看见"出事了"（楼塌了、人没了、钱不值了） | 无（也无力反抗） |
| | C-2 | 看见"不同片区的事故类型不同" | 开始被要求"按区办事" |
| | C-3 | 看见"每区有一套自己的规矩" | 开始需要选一套遵守 |
| **法则层** | C-4 | 看见"规矩之间有缝"（同一件事两套说法） | 选边，且选错要赔 |
| | C-5 | 看见"缝是可走的"（能同时办两套手续） | 被两套同时记账 |
| | C-6 | 看见"缝是人留的"（有人故意留缝） | 知道得越多，越不能说自己知道 |
| **棋手层** | C-7 | 看见"有人在下棋"（某一区的事故是被人安排的） | 被安排的人开始注意到你 |
| | C-8 | 看见"棋手不只一个，且互相不能取消" | 你会被某一方"招安"，拒绝即被划 |
| | C-9 | 看见"棋盘本身是被缝的"（世界不是天然的） | 追溯行为触发论外丁 |
| | C-10 | 看见"我也在被写" | 无法再确认自己是否真实（全书终点） |

> **升级不涨战力，只涨"看得见什么"**（`01` 卖点矩阵已锁）。这是本书与"修炼升级流"的根本分界。

### 3.2 九宫格（认知段 × 立场）

| | **末人**（认命） | **摇摆者**（套利） | **记录者**（留证） |
|---|---|---|---|
| **C-1~3 事故层** | **数字**：统计里的一个，死了算"其他" | **碰瓷者**：拿事故换赔偿，靠"闹"活 | **报料人**：拍下第一段视频，卖给任何一册 |
| **C-4~6 法则层** | **依册者**：哪本册子管我，我就按哪本活 | **双册人**：两套手续都办，哪套有利走哪套 | **勘定者**：判两份文本哪份为准（**主角所在格**） |
| **C-7~10 棋手层** | **弃稿**：接受自己被降级，不再争 | **反书写者**：改自己的叙事位，赌一把 | **结卷人**：决定谁被写进结局（**卷四争夺位**） |

**九宫格的用法**（写作纪律）：

1. 每个重要配角必须能填进一格；填不进＝功能不明，退回 `04`。
2. **同一格不超过 3 个主要角色**（否则读者分不清）。
3. 主角从"勘定者"起步，**终局必须离开这一格**——他可以走向"反书写者"（卷四）或"弃稿"（若失败），但不能停在中间。这是弧光的硬指标。
4. **"数字"格不得写成纯悲情**。他们不是背景，是第 42 条"结卷须十三册同签"里"册"的合法性来源——没有他们，册子不成立。

## 4. 三层恐怖平衡

| 层 | 谁在平衡 | 平衡机制 | 为什么会崩 |
|---|---|---|---|
| **顶层** | **13 位创造主**（不出场，只以"结卷"施压） | **相互确保取消**：谁直接删对方主线，谁的分支被降级为弃稿；编辑部联合制裁；幸存者注意力流失使该棋局失去燃料 | 棋子获得局部自主性，乃至**反书写**（一个角色意识到自己被写，并改变叙事位） |
| **中层** | 高权重个体（13 棋风各自的顶点：山神／龙首／石头／山神级残神……） | **不直接吃掉对方的王**：默契而非条约；彼此留一块"不感兴趣的领域" | 某个体的"确保毁灭"能力不需要对等质押物——他本身即充分条件，平衡退化为"容忍" |
| **底层** | 国家残余机构 × 十三册代管处 | **相互质押协议**：核指挥隔离带、育种冻结（本棋盘无 B 型，故为空条款）、工业管制协调 | 上层一动作即让协议"变得无关紧要"；国家退化为后勤平台与合法性来源 |

> **顶层没有降临体**（`00` §二已锁）。任何"某个角色强到能上顶层"的写法，都是把本书降级为神仙打架，直接打回。

### 4.1 平衡的"保证"是什么（本书的世界观题眼）

不是信任，不是条约，不是威慑理性，而是：

> **一次被反复验证的、关于连锁崩溃的集体记忆。**
> 交汇第 2 年那场"双册同时生效"的七十二小时，全城有四千人在两套手续之间被判定为"既合法又违法"，
> 最后按"其他"类处理——他们没有死，只是不再算数。这件事没有任何一册愿意记录，
> **但每一个人都记得**。这就是本棋盘唯一的"宪法"。

## 5. 力量体系（能力 — 代价 — 反制 三件套）

### 5.1 总则

本书**没有统一的力量体系**，只有十三套互不换算的"办事方式"。这是设定，也是叙事策略：
读者永远不知道下一秒该用哪套规矩，正如角色永远不知道。

| 通用约束 | 内容 |
|---|---|
| 上限 | 个体最强可毁一条街；**不可毁城**（毁城只有"结卷"） |
| 代价 | 任何超常行为当场结算（公理 3）；不许"事后反噬" |
| 反制 | 每套法则都有自己的"公章"——毁章即废法，但毁章者会被全城追责 |
| 不可换算 | 甲区的功劳不能在乙区换钱；**唯一的通用物是"重复次数"**（见 §8） |

### 5.2 十三棋风的能力—代价—反制（速查）

| 代号 | 能力（能给什么） | 代价（当场付什么） | 反制（怎么破） |

## 6. 金手指／主角专属体系卡：校勘权

| 项 | 内容 |
|---|---|
| 名称 | **校勘权**（民间叫法："判一下"；官方叫法："第三方勘定"） |
| 来源 | 第 25 条：两版都自称原本时，须交第三方勘定。余名是全市**唯一在册的第三方**——因为他不在任何一册，因而对两册都无利害关系 |

| 不能做什么 | ①**判不了自己的册页**（第 25 条"判不了自己"）②不能判"哪份更好"，只能判"哪份为准"③不能连判（两次勘定之间须隔一次"结算"） |

| 解锁节点 | 卷一只判"文本"（纸）；卷二判"手续"（流程）；卷三判"名分"（人）；卷四判"卷"（结局） |
| 反制 | 任何人只要**拒绝提供第二版**，他就无从判——这是全书最常见的僵局 |
| 与法则的关系 | 他不是"凌驾法则"，他是**法则之间的一把尺**。尺本身没有力量，力量来自"两边都怕量错" |

### 6.1 主角的"不在册"状态（三条硬规矩）

| # | 规矩 | 具体表现 |
|---|---|---|
| 1 | **不被检测** | 十三套法则都不认他：册上没他、等级查不到他、梦里没有他、副本进不去。他能走进缝合线而不被撕 |

### 7.1 编辑部专章（**v1.1 新建 · 框架先行，不砍支柱**）

> 它不是"最终 Boss"，也不是"反派组织"。它是这个世界的**运行条件**。
> 本节的写法纪律：**只写它能做什么、不能做什么、如何被观测；不写它想要什么。**

#### 7.1.1 六问

| # | 问 | 答 |
|---|---|---|
| 1 | **是什么** | 创造主之上的"裁判、编译器、风控"三位一体。它不统治，它**维护可读性**——不可读的棋盘会失去注意力，而注意力是棋局唯一的燃料 |
| 2 | **为什么不出场** | **出场即降级**。一旦它有脸、有声音、有偏好，读者就会把它当"最终 Boss"，全书从"没有人负责"退化为"有个人在害我们"（`01` §附否决方案二） |
| 3 | **如何被观测**（四条，全部是物，不是人） | ①**代理处**：唯一物理投影，进去的人少一样东西；②**结卷表决**：第 42 条的启动与计票；③**降级为支线**：论外丁的后果，表现为"相关记录出现从未存在过的空白"；④**记录被改**：公理 4 的直接后果 |
| 4 | **权限边界** | **能**：改记录（须付程序代价）、降级分支、启动结卷表决、判定弃稿。**不能**：凭空造物、直接杀人（它不"杀"，它"不算数"）、改十三册的条文（改册＝干涉创造主，违反顶层"相互确保取消"） |
| 5 | **与十三册的关系** | 册是它的**接口层**，不是下属：册由创造主留下的旧稿生成，编辑部**只能读、不能改**。这条限制是它最大的挫败，也是卷四的杠杆——它想结卷，但缺一册就结不成 |
| 6 | **内部矛盾**（卷四的真正引擎） | **可读性 vs 多样性**。多样性让棋盘丰富，可读性让棋盘能被读；13 套并存已把可读性逼近下限，所以它要结卷。**它不是恶，它是"读不下去了"** |

#### 7.1.2 它在结构上承担什么（删了会怎样）

| 功能 | 删掉的后果 |
|---|---|
| 第 42 条的执行者（结卷须十三册同签） | 结局失去机制，"反书写"变成空喊 |
| 论外丁的维护者（不得追溯创造主） | 元线的恐惧失去来源，变成一句设定 |
| 卷四的唯一对手 | 主角没有对手，只能打"流程"这个抽象概念，戏会散 |
| "没有人负责"的具象 | 全书退化为"反官僚"的浅层讽刺——这正是 `01` 明确不写的 |

#### 7.1.3 写作禁忌（五条，破一条就变味）

1. **不得有情绪、偏好、幽默**——它不嘲讽，也不怜悯。
2. **不得与角色对话**——它没有台词。所有"它的意思"必须由物（机器、表单、提示音）转述。
3. **不得被"打败"**——只能被"读错"（廓的棋风），或让它"结不成卷"（缺一册）。
4. **不得解释自己的动机**——一旦解释，它就变成了"有苦衷的人"。
5. **不得人性化**：不要把它写成"冷漠的官僚"——那仍然是个人。正确写法是：**它根本不看你。**

> **一句话记住它**：它不是"不让你们活"，它是"读不下去你们了"。

## 15. 判例库（附录 · v1.1 新建）

> **为什么建这个**：主角的权能是「判两版并存哪份为准」。
> 若判例无目录，读者会怀疑「凡有争议他都能判」——**金手指一旦无法验证，就会退化成万能**。
> `分析报告.txt`（框架期）把「判例库」列为 P0-2：只有把已判的案子列成表，
> 才能证明**他判得了什么、判不了什么、代价是什么**。
> 第一次正文（卷一第 1 章）以对白带出「这是第二十三份」——本章把它落成表。

### 15.1 判例登记格式

| 项 | 内容 |
|---|---|
| 编号 | `判-XXX`（三位流水） |
| 争议类型 | 两版并存的**分歧点**（日期／姓名／归属／效力） |
| 判定依据 | 哪一条规则或哪一条通则解决了它 |
| 代价 | 主角付出的具体一项（**必填**——无代价的判例视为无效） |
| 归属 | 哪个区的册／代管处 |
| 状态 | 已判／暂缓／在审／涉判例争议（**不可判**） |

### 15.3 不可判清单（金手指的边界，防「万能裁判」）

> **这一栏比已判表更重要。** 已判表证明他判过什么；不可判清单证明他**判不了什么**。

| 情形 | 为什么不判 | 出处 |
|---|---|---|
| **判自己** | 第三方须无利害关系；判自己即失效 | 第 25 条附注（卷三正文已用） |
| **单方判定**（只有一方主张原本） | 通则明禁单方判定 | 第 25 条（卷一正文已用） |
| **两版均无自证优势** | 反而**正是**该他介入的场合 | 第 25 条附注（卷一正文已用） |
| **涉及本人在册状态的争议** | 同「判自己」 | 卷二第 10 节「查的人查不到自己」 |
| **直系亲属的册页状态** | 第三方资格存续期间不得单方面变更——**他护着亲人，也因此护不住** | 第 25 条附注第三款（卷三正文已用） |

### 15.4 维护纪律

1. **每判一次登记一行**，代价栏必填；
2. **代价是可累加的**：主角每判一次少一样「别人能记住他的东西」，
   顺序是 **学历（记忆层）→ 工龄（时间层）→ 亲属关系（关系层）→ 姓名（识别层）**——
   **四样全落在「位」这一个量上**（见 `零件库/装配体/ASM-CCZ-0001.md` §二驱动量）；
3. **不可判清单只增不减**——新增一条须写明为何他判不了；删一条等于扩大权能，须在 §13 登记；
4. **卷末对账**：本表与 `02` 卷纲、`05` 卷末交付对账三方核对，防判例与正文打架。
