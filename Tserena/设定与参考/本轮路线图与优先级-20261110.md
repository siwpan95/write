# 本轮路线图与优先级 · 创作与反哺双向推进（2026-11-10）

> **性质**：本轮工作的施工台账与验收标准。**每完成一个阶段 → 本地提交 → 推送双远端 → `ls-remote` 核对 IN_SYNC**，逐阶段推进，不攒批。
> **用户指令**：「结合联网搜索继续补充 `设定与参考` 与 `bible`；尽最大程度化利用 `通用模板包` 并发现其不足，实现创作与反哺双向推进；罗列优先级，每完成一个阶段提交推送。」
> **开场口径**：粗粒度 4 阶段（P0 勘察／P1 bible 补完／P2 模板激活＋续写／P3 反哺）。**勘察后细化为 5 阶段**——因 P2 实际包含两类互不相同的工序（叙事层规划 vs 文风执行层），拆开才能各自验收。本文件为细化后的唯一执行依据。

## 四、执行口径与纪律

| 项 | 口径 |
|---|---|
| 推送 | 每阶段末 `git push origin master` + `git push github master`，随后 `git ls-remote origin/github refs/heads/master` 双端核对与本地 HEAD 一致（铁律 3：推后核对 IN_SYNC）。**用户本轮已明确授权逐阶段推送** |
| 提交 | 每阶段一次独立提交，message 标阶段号、交付物、验收结果；不攒批、不 amend |
| 模板包 | **只做追加式修订**（新增路径/通道/版本记录/勘误说明），不改动既有 14 份模板的编号与正文；遵守 `00` §三「关键原则一：模板不动，实例动」——实例一律写进 `Tserena/`，不写进 `通用模板包/` |
| 原始素材 | `其他项目归档/` 零改动，每阶段末 `git status --porcelain` 复核 |
| 编码 | 新建/修改文件统一 **UTF-8-SIG + LF**（本仓《工作区规范》§六）；每阶段末跑表格列数校验与行尾检查 |
| 设定纪律 | 凡来自原素材标「据原文 §X」；凡本轮联网/推理新增标「**推断·待确认**」并注明来源编号；不虚构原素材没有的数字作为硬数值 |
| 地理护栏 | Guardafui Channel 作真实海峡提及；不主张对现实索马里领土或海峡岛屿的主权；Afar 只借构造机制，不把真实地名写入 Tserena 国境 |
| 不代作者拍板 | 涉及「德语符号是否保留」「P2-1 `Meltmeer` 三解」等仍需作者定性的，报告只列选项与依据 |
