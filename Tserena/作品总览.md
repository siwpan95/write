## 一、这是什么

**Tserena 共和国**（Republic of Tserena / 内称 Saldan Tserena）——一个位于非洲之角东南部、临 Guardafui 海峡的虚构国家。

| 项 | 内容 |
|---|---|
| 政体 | 单一制民主宪政社会共和国（两市为 **Chartered City 特许市**，P1-2 已澄清，见 `world-bible` §1.5） |
| 首都 | New Haddar（Haddar-Bei） |
| 官方语言 | Tseren（构造的库什特语族语言）+ 英语；国歌与格言用德语 |
| 面积 / 人口 | ~187,400 km² / ~9.6 M（密度 ≈51.2 人/km²） |
| 格言 | *Freiheit, Gleichheit, Solidarität* |
| 国歌 | *„Lied der Küste"*（海岸之歌，德语四段） |
| 货币 | Tseren shilling（TSR） |
| 宪制 | 1979 原版 / 2024 第47届制宪会议修订 / 2025 修订版生效（P1-1 已澄清，见 `world-bible` §1.5） |
| 行政 | 6 区 + 2 **特许市（Chartered City）** → District → Communal Council → Neighbourhood Assembly |

**核心设定一句话**：宪法把土地、底土、水域、大陆架全部锁进公民信托（**可租、永不可让渡**，§7），同时承诺医疗、教育、住房、劳动四项权利（§5）——**有限的租赁资格，兑现无限的公民承诺**。这个缺口是全部冲突的总闸门。

## 五、外部事实纪律

凡涉及真实世界的对照（德国国歌版权、埃塞俄比亚区划、Guardafui 地理、东非合作社史、地名学、名称占用），**一律以 `设定与参考/外部事实核对表-20261109.md` 为准**。

该表规定：**未收录的外部事实，四份文档不得引用；标「未核实」的，不得在结论中当成事实使用。**

**地理表述护栏（一条，务必遵守）**：Tserena 的虚构国土在地理上覆盖真实索马里邦特兰地区。**不得让 Tserena 在文本中主张对现实索马里领土或海峡岛屿的主权**；Guardafui Channel 作为真实地理名称可用，但首次出现宜注明「真实海峡」。
