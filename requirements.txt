# **核心内核不依赖本文件** —— `tools/` 下参与 `npm run check` 的核心检查器

# 为什么显性报错而非降级为可选插件
# ------------------------------
# 历史教训（廓者未名夜）：项目未注册进审校 ⇒ `npm run check` 对它是
# 「SKIP」而非「通过」—— 日更自动化把「错误 0」当放行线，若检查对象
# 不在扫描视角内，那条线**根本不成立**。依赖缺失同理：静默跳过等于
# 闸门失效而无人知晓。故 dse 检查器在缺依赖时报 ERROR 并给出安装指引。

# 版本必须钉死
