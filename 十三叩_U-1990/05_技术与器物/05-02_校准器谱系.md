# 校准器谱系（A01–A13）

十三类校准器，各对应一个常数。命名不得用人名（00-04）。

| 编号 | 名 | 校准对象 | 关键特征 |
|---|---|---|---|
| A01 | 重摆 | C01 G | 单摆周期。最容易造，最难带走 |
| A02 | 光行差尺 | C02 c | 干涉仪。过涡必碎 |
| A03 | 气阶 | C03 R | 测气压梯度。**唯一会「主动报警」的仪器** |
| A04 | 零盏 | C04 0K | 以绝对零度为锚。全宇宙唯一不撒谎的器物 |
| A05 | 摩尔天秤 | C05 N_A | 称一颗粒子的重量。精度低于 10⁻⁶ 即违法 |
| A06 | 双弦 | C06 k_e | 两根本应同频的弦，测失谐 |
| A07 | 热噪箱 | C07 k | 测同一温度下的噪声底 |
| A08 | 粒箱 | C08 h | 数最小作用量。需连续数 40 天 |
| A09 | 影规 | C09 r_s | 测黑洞视界厚度。军事管制 |
| A10 | 火线尺 | C10 ε | 测恒星产能。只有第十席持有 |
| A11 | 烛秤 | C11 M_Ch | 称标准烛光，天文专用 |
| A12 | 膨胀尺 | C12 H₀ | 测退行速度，分两派互不认账 |
| A13 | 平直规 | C13 Ω | 测空间曲率。全境仅三台 |

## 谱系的两条暗线
1. **A04 是唯一诚实的器物**，因为它校准的是「零」。
2. **A03 会报警**——只有气体常数相关的仪器能察觉 δ 突变。
   所以边境城的预警系统全是气压计。这是这个世界少见的「可靠的土办法」。
