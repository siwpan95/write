## 三、四层拆解（模板口径）

| 层 | 本剧内容 |
|---|---|
| **一句话** | 苏然在网游《神界》捡到一把「未知的短剑」，那是另一边递过来的手。 |
| **核心冲突** | 现实里他被卡住（灰暗、无出口）；游戏里他被**选中**（但选中他的不是自己） |
| **主线（外部）** | 接广告 → 下载 → 建号 → 新手村 → 隐藏洞穴 → 得剑 → 组队 → 抉择 |
| **暗线（内部）** | 「未知」意味着什么；短剑为何锈迹斑斑（不像奖励，像**遗物**）；覆水这个角色名是谁给的 |
| **悬念/钩子** | ① 短剑的来源　② 为什么是「未知」　③ 现实线的涟漪是什么　④ 抉择的两条路各通向哪 |
| **信息差纪律** | 现实线只知其一；每集只放**一层**信息，避免提前说破 |

## 四、集结构模板（后续沿用）

```
第 N 集
├ 第一幕：现实的余波（承接上集末幕钩子的现实侧）
├ 第二幕：虚拟侧推进（行动 ＋ 一次小挫）
├ 第三幕：意外发现（机制第一次显形）
└ 第四幕：抉择的十字路口（把决定交给观众）
```

- **单集体量**：≈2,600 字（含镜头描述与画外音），对白占比低于小说体例。
- **钩子位**：只挂**一集**（末幕），不双钩。
