## 二、一句话故事（唯一定义处，供 `01 §0` / `02 §1.1` 引用）

> **峨眉退回来的那个少年，发现这世上的人都活在册子上，只有他不在册。**

- 字数：33 字（≤50 字，符合公式 A 上限）。
- 三个零件：**谁**＝被峨眉退回的少年（杨成志）；**要什么**＝一个不用别人批准的位置；**挡着什么**＝世界只认册上有名的人，而他连"被退回"都没被记一笔。
- 反讽：他要的是"被写进去"，而唯一能写他的人，是他最恨的那几个女人。

### 五句段落（供 `02 §2.5` 引用）

1. **背景**：康熙二年，凝碧崖开府在即，正邪两道都在等第三次斗剑；峨眉广收有缘人，**有缘没缘，看册上有没有你那一行**。
2. **灾难一**：秦寒萼救下的四个孩子被送到凝碧崖求收录，齐灵云执意不收；四人要撞石自尽，凌浑出面说情，才"暂为收下"——他成了"暂"字底下那个人。
3. **灾难二**：他为抢一株芝仙（想证明自己配留下），误动先天灵符，困阵三日，闯下大祸，被遣返；**从"暂收"变成"退回"**。
4. **灾难三**：凌浑皱眉收他为徒，师母一句"这等心术不该收"；他在青螺峪学会本事，也学会"位置可以抢"；第 330 章他有能力救于建，却先伸手拿了那本册子——**他没有推人，他只是没伸手**，从此回不了头。
5. **结局**：第三次斗剑即"结卷"，他手里那一笔能决定谁被写下——他写所有人，不写自己；但被他害死的人不会因此复活。

## 三、主角内核（锚，供 `04 A1–A11` 展开 · v4）

| 字段 | 裁决 |
|---|---|
| 姓名 | **杨成志**（原著人物，F-36） |
| 身份 | 秦寒萼途中救下的少年，与于建、章南姑、章虎儿同送凝碧崖；"暂收"后因芝仙之祸被遣返；凌浑皱眉收为弟子（F-36~F-38） |
| 年龄 | 十六（原著称"二童"，与于建同辈） |
| 性格定性 | **善于趋利避害，但本性纯真（纯真≠白痴）；贪嗔痴妄只是一时之念，不是底色；纵使他人误解，亦能恪守本心，做自己觉得正确的事；"虽千万人吾往矣"。** |
| **双轨制（v4 核心）** | **性格轨（全书不变）**：守本心、纯真、不辩、不谢、认账、怕也去——只被考验，不被改写。**手段轨（逐卷变狠）**：偷墨→借势→批注→对笔→写人入局→"不救"→写所有人。张力＝手段越强，越容易用手段定义自己；他不是变坏，是**差点被手段吃掉本心** |
| 欲望 Want | 表层：抢一个不用别人批准的位置。深层：**要一个自己认可的答案**——"我算不算数，不是你们说了算" |
| 需要 Need | 先看清自己踩的是谁，再谈"我认为对"；自我立法不等于不用付账 |
| 恐惧 Fear | 表层：被退回。深层：**变成一个只会用手段的人**——不是坏，是空 |
| 错误信念 Lie | **这世上的规矩不值得守，除非它经得起我的追问**（所以他敢破规矩，也敢伤挡路的人） |
| 真相 Truth | 你可以自己造一把尺子，但造尺子之前，先看清尺子底下压着谁；手段可以换，本心不能换 |
| 能力 | **阙文**：能看见"未被写下的空白"；**补笔**：把"已发生却无人记下的事"写出来使其成立 |
| 能力来源 | 他不是佚卷执笔人的后人，而是**佚卷里被写过另一种结局的人**：那一卷写过"杨成志血洗凝碧崖"的版本，卷被焚得半干，他成了**两个版本之间的缝**——所以他看得见"没被写下的部分" |
| 代价 | 每次补笔交出"一种本来可能走的路"（记忆消失、不可逆）＋累积手段反噬计数（R3′） |
| 反制 | **批注**：任何"算数的人"可当众质疑其来历；批注成立则补笔崩解，补笔者遭"反写" |
| 初始信念来源 | 由世界压力反向定义：他不是"想被承认"，是"被退过一次"——世界先否定他，他才认定"规矩得先经得起问"（`13 §4`） |
| 弧光终点 | 三拍：**用别人的尺子量自己 → 自己造一把尺子 → 把尺子交出去**（写所有人、不写自己：他终于不需要被量）。**不黑化**：他做过的狠事不撤销、死了的人不复活；**也不洗白**：他不辩解、不求原谅，只把那一笔写完 |
| 镜像角色 | **于建**（老实人被留下、最后当替死鬼——"不作恶也会被牺牲"）；**晓月禅师**（被除名者的未来态） |
| 被误解的机制 | 他的"趋利避害"在别人眼里是投机，他的"守本心"在别人眼里是执迷；**每一次他做自认为对的事，都会有一个具体的人因此受损**——误解不是误会，是账 |

## 四、五条世界律（锚，供 `03 §2` / `13 §2` 展开为可判定条款）

| 编号 | 律名 | 一句话 | 可判定形式（判定问句） |
|---|---|---|---|
| R1 | 存在律 | 被写下（名册/谱牒/口传）的存在才"算数" | 此人是否在任何一份名册、谱牒、碑记或三人以上的口传中出现？否 → 逐渐淡去（旁人记不住、物件失重、路径走不通） |
| R2 | 补笔律 | 补笔只能写出"已发生但未被记下的事"，不得凭空造 | 补笔内容是否与已写定事实冲突？冲突 → 反噬（写错处从补笔者身上"扣"） |
| R3 | 代价律 | 每次补笔须交出"一种可能"，不可逆 | 本次补笔交出了哪一种"本来可能"？未交代 → 该次补笔无效 |
| R4 | 批注律 | 算数者可当众批注，批注成立则补笔崩解 | 是否有在场者以自身名分作保质疑？有 → 进入"对笔"（比谁的名分更硬） |
| R5 | 结卷律 | 逢大劫世界结卷，未写到的部分永久消失 | 当前是否临近结卷节点（斗剑/开府/大劫）？是 → 所有"未写定"者进入倒计时 |

> **v4 修订 R3′（手段反噬律，替换 v3"深渊律"）**：每 3 次补笔，会有 1 章他"**只看手段**"——判断更快、下手更准、话更少；他会把人看成变量（"这个人值三页"）。危险不是"变坏"，是**忘了为什么写**：那一章里他认不出自己在护什么（忘记老周的名字、把"救人"说成"处理"）。
> **写作纪律**：① 这一章不许写"他黑化了"，只许写"他特别能干"；② 不许写他享受伤害；③ 章末必须有一个"拉回来"的小动作（给老周挑水、抄一遍自己的名字、把笔尖朝向自己）。
> **为什么换掉"深渊律"**：让主角"短暂变成没有底线的自己"，本质上仍是堕落线，读者会预判"他迟早变坏"，且踩合规线。改成"手段吃掉目的"后，**性格没坏，坏的是方法**——这才救得回来，也才配得上"守本心"。

## 八、与原著的关系（改编边界，供 `12 §2` 引用）

**采用（原著资产）**：杨成志的全部原著线（F-36~F-39）＋同批人物（于建、章南姑、章虎儿）＋齐灵云、李英琼、凌浑、崔五姑、许飞娘、晓月禅师＋地理（凝碧崖、青螺峪、紫云宫、幻波池、光明境、铜椰岛）＋法宝（紫郢、青索、南明离火、七修、天遁镜）＋术语（F-21）。

**改造（本项目设定，须标注）**：
① 原著在 F-39 后不再交代杨成志，本书**从这里接续**，第三次斗剑结局为补写，不得称"还原"；
② 新增"阙文/补笔/批注/对笔/结卷/佚卷/掌籍"六词与"蚂蚁"绰号；
③ "魔道干亲"只写"以干亲相称"的手段，不写"干孙"名分（原著无据，F-39 存疑）；
④ **不黑化**（v4 替换"不洗白"）：他做过的狠事不撤销、死了的人不复活；但**他不变坏**——性格轨全书不变，手段轨可以狠。他不辩解、不求原谅，只把那一笔写完。三条不可越的线见 §十四；
⑤ **时间线重排（本项目设定，须在全包统一口径）**：原著次序为第 87 回收录→第 95 回芝仙闯祸被遣返→第 211 回峨眉开府（此时他已在青螺峪，"同门皆有份，唯他一人无望赴会"，F-38）。本书为让"被退回"成为卷一高潮，把"点名无他"前移至暂收期（卷一第 11–15 章），芝仙之祸顺延（第 26–45 章），遣返（第 41–60 章）；第 211 回的开府**不删**，改置卷二后段，写成"他听说峨眉开府，同门都有份，只有他没有"——与 F-38 原意一致，只是位置后移。此为改编取舍，不是原著事实。

**禁用（红线）**：
- 不得使用任何影视/游戏改编的独创设定与造型（`11 §1.1`）；
- 不得大段抄录原著原文（公有领域≠可复制；引用单句须 ≤20 字并标回目）；
- 不得把原著人物写成与原著定性相反（齐灵云仍老成持重、李英琼仍刚烈、凌浑仍"人各有心"）；
- 不得给杨成志"其实没做那些事"的翻案（反英雄不是被冤枉的好人）。

| 项 | 判断 |

| 与文风的关系 | **自洽**：17 字轻小说长名＋电波系文风，是同一个决定的两面（用户：蜀山 IP 受众不行，必须出奇招）。不再视为"错位" |
| 真实风险 | 主站仙侠读者可能把"轻小说长名"读成"搞笑文/后宫文"，与本书的冷底色不符 → **简介首句必须给冷的具体物**（"册子上没有他那一行"），把"登天"解释成"抢位置" |
| 用法 | 封面/榜单/书评用全名；口播、简介首句、章末推荐位用《蜀山之撼天》 |
| 章节标题 | 轻小说化长标题（§十二 V4），与书名同一语感；但每 10 章问句标题 ≤3 个 |

## 十一、视角三禁（D1 配套，供 `05 §1.6` / `08 §五` 执行）

1. **不写他不在场的场景**：所有场景必须有他在场或经他转述（"后来听于建说"）。
2. **不写他人内心**：只写他人的动作、话、可见反应；读者与他同步猜。
3. **不用全知旁白点破元叙事**：不出现"这是一本书""作者""读者""页码"这类词；元叙事只通过三种东西渗出——① 他记得"还没发生的事"；② 他能看见"空着的轮廓"；③ 章首偶尔出现的"名录残页"（副文本，不是叙述者说话）。

## 十二、文风律：电波系轻小说（v3 新增 · 唯一定义处的上位规则，量化指纹在 `05 §1.1`）

> **一句话**：用底层少年的错频感知，去解构一个庄严的仙侠世界。不是搞笑，是"他没按你们的频道说话，可他说的是真的"。

| # | 律 | 可执行要求 | 反例（写了即错） |
|---|---|---|---|
| V1 | **错频解构** | 主角用灶房、账本、蚂蚁、柴火的经验去解释仙侠术语：术语进他耳朵，出来就是另一件事（"阙文？我们灶房管这个叫'漏了一勺'"） | 用现代网络词（"系统""bug""打工人"）解构——时代错了 |
| V2 | **短句高对话** | 均句 12–14 字；对话占比 38%–48%；段落 1–3 句；每章至少一场"你说一句我顶一句"的短打对话 | 长段心理描写；连续 3 段无对话 |
| V3 | **内心插叙** | 自由间接引语：他的念头直接混进叙述，不加引号、不写"他想"；每千字 2–4 处，每处 ≤15 字 | 大段独白；括号吐槽连续出现（每章 ≤3 处） |
| V4 | **长标题** | 章节标题轻小说化、口语、带具体物（"第1章 他们说册子上没有我，可我叫杨成志"）；每 10 章问句标题 ≤3 个 | 四字雅题（"问道凝碧"）；标题剧透本章反转 |
| V5 | **哲学只在刀口上** | 尼采式独白每卷 ≤3 次，每次 ≤120 字，且必须**紧接一个具体动作或代价**；不为抒情而抒情 | 空转的"命运""自由""意义"三连；把设定说明写成哲学论文 |
| V6 | **电波≠中二** | 禁止"命运的齿轮""深邃的眼眸""嘴角勾起一抹弧度"这类伪轻小说腔；形容词密度按 `05 §1.1` 上限 | 靠形容词堆"高级感"；句尾滥用"呢/吧/啊"（每千字 ≤5 个） |

> **与原著的关系**：原著文风是"半文半白＋骈俪写景"（F-31）。本书**只保留它的"物"（洞府、法宝、法度的质感），不保留它的"腔"（对句、骈俪、长句）**。这是用户明确的"不必照搬原版"。

## 十四、手段与性格分离（v4 · 用户核心方法论 · 合规与共情的共同底座）

> **原则一句话**：**主角可以干坏事，但不能是彻头彻尾的坏人。手段可以换，本心不能换。**

### 14.1 双轨怎么跑

| 轨 | 内容 | 变化规律 | 读者感受 | 合规作用 |
|---|---|---|---|---|
| 性格轨 | 守本心、纯真、不辩、不谢、认账、怕也去 | **全书不变**，只被考验 | "这人我能跟" | 价值观正向，平台安全 |
| 手段轨 | 偷墨→借势→批注→对笔→写人入局→"不救"→写所有人 | 逐卷更狠、更准、更冷 | "他越来越能干，也越来越让人怕" | 手段不等于价值观，可写 |

**判定口诀**：写一件狠事之前，先问"这是**手段**还是**性格**？"——手段可以狠，性格不许坏。

### 14.2 三条不可越的线（同时也是合规线）

| 线 | 允许 | 禁止 |
|---|---|---|
| L1 不设局害信任他的人 | 可以"不救"（道德灰区，读者能理解但不能原谅） | 不可设套、献祭、把信任他的人当筹码 |
| L2 不虐杀、不以痛苦取乐 | 杀伐果断、斩草除根可以写 | 不写折磨过程、不写他享受伤害、不写虐杀细节（意象化处理，见 `08 §4.1`） |
| L3 不对无辜路人下手 | 挡路的可以是恶人、是对手、是制度 | 不能是随机弱者、妇孺、路人 |

**第四律（认账）**：每做一件狠事，后面必须有一次"认"——不辩解、不推给环境、不说是别人逼的。这是性格轨的证明，也是读者原谅他的唯一通道。

### 14.3 尼采的正确用法（为什么超人哲学适用于杨成志）

网文常把尼采读成"黑暗流许可证"（超人＝可以为所欲为），这是误读。**超人是价值的创造者，不是价值的破坏者**——他不要别人给的规矩，但他给自己定的规矩更严；他自负其责，不把账推给世界。

| 尼采概念 | 误读（不许写） | 本书用法（可写） |
|---|---|---|
| 价值重估 | 所以什么都可以干 | 他先问"这规矩凭什么"，再决定守不守；守的时候比谁都认真 |
| 自我立法 | 我就是法，谁挡杀谁 | 他自己定的规矩里第一条是"不害信我的人"；他破别人的法，不破自己立的法 |
| 超人 | 鄙视弱者、屠戮无辜 | 他不鄙视弱者（他自己就是蚂蚁）；他恨的是"给蚂蚁定规矩的人" |
| 永恒轮回 | 反正能重来，随便造 | 每次补笔＝让"如果重来"发生一次，也是对自己的审判：你愿意这样再来一次吗 |
| 深渊凝视 | 与恶龙缠斗必成恶龙（所以堕落合理） | 他看见自己身上的鳞，然后选择不用那只手（R3′ 手段反噬） |

**金句（可作文眼）**："他们给我规矩，我不要。我自己定一条——定得比他们的还狠。"

### 14.4 与合规的关系（实证）

- 《蛊真人》2019 年 5 月底在起点下架，公开理由为"内容过于黑暗、三观不正、暴力血腥"，期间多次约谈、修改大纲仍未能保住（B 级：多家媒体一致，官方未公开细则）。
- 结论：**黑暗流不是"能不能写"的问题，是"能不能连载完"的问题**。本书选"手段狠、底色正"，既保留反英雄的张力，又留在可连载区。
- 正能量不写成说教：写成"他认账""他不害信他的人""他最后把尺子交出去"。这三件事比任何口号都正。

### 14.5 自检三问（每卷末跑）

1. 这一卷他做过最狠的一件事，是**手段**还是**性格**？（是性格 → 回改）
2. 这件事之后，他有没有"认"？（没有 → 补一场，不许用旁白代替）
3. 读者会不会觉得"他其实是个好人"？（会 → 说明手段不够狠，张力没了；不会但也不想弃书 → 正确区间）

## 十五、弧光参照与结局落点（v5 · 塔里昂模型 + 回归原著）

> 用户 2026-11-15 拍板：参照《中土世界》塔里昂的**人物弧线结构**（复仇游侠→自我牺牲，悲壮、有史诗感、不团圆），并守住"写同人要把落点回归原著"。
> **只取结构，不取设定**：不引入亡灵契约、共生、阿门洲等任何外部设定；本节只谈"弧光怎么走"与"结局落在哪"。

### 16.1 三段弧（结构对照）

| 段 | 塔里昂（只取结构） | 杨成志 | 卷 |
|---|---|---|---|
| 复仇者 | 私仇驱动，为夺回失去而战 | 被退回、被误解，要向峨眉证明"我算数" | 一~二 |
| 守护者 | 从私仇转向守护他人/世界 | 从"给自己抢位置"转向"替没被写下的人补名" | 三~五 |
| 自我牺牲 | 以自身消解换他人存续 | 写所有人、不写自己；名字从册上消失 | 六 |
| 结局 | 悲壮但有归宿（解放，不是虚无） | 从册上消失，**在人嘴里活着**（解放，不是虚无） | 六末 |

### 16.2 结局四不

| 不 | 具体禁令 |
|---|---|
| 不团圆 | 不写他当上掌门、被平反、娶妻生子、受封有祠 |
| 不虚无 | 不写"他从来没存在过"（取消式结尾）；消失必须留下"人的记忆"这一层 |
| 不洗白 | 死者不复活、恶不撤销、他不辩解 |
| 不篡改原著 | 他的牺牲让原著主线**得以发生**，不是取代原著主线 |

### 16.3 回归原著三原则（同人的落点）

1. **世界归位**：第三次斗剑按原著方向发生（正邪了断、劫数完成）；三英二云、七矮、峨眉道统不受他影响，该飞升的飞升、该承道的承道。
2. **代价私有**：他承担的是"让这件事被写下来"的代价，**不是"改变结局"的权力**。他能补的是"被漏掉的人"，不是"改写胜负"。
3. **余响归人**：结局落在"人记得他"，不落在"册记得他"；最后一笔之后，原著人物继续走他们的路，只在某个极小的日常里提他一句。

### 16.4 史诗感的比例（写法）

不是靠规模，是靠比例：**一只蚂蚁的死，让山没有塌。**
最后一章不写天地异象、不写万剑齐鸣，写一个具体的人做一件具体的小事——灶房给新来的孩子多盛一勺，说"从前有个抄书的"。这一勺回扣全书第一个错频（"这不叫格子，这叫漏了一勺"）。
