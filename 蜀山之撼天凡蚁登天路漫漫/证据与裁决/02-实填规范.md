# 02 · 实填规范（所有分册共用，填表前必读）

> 本文件约束 01–19 全部分册的填法。分册之间只允许"引用编号"，不允许"复制数值"。

## 一、必读顺序

1. `证据与裁决/00-蜀山证据包.md` —— 外部事实（F-xx）。**原著事实只能来自这里**。
2. `证据与裁决/01-核心设定裁决表.md` —— 设定锚点（R1–R5、术语、卷表、主角内核、反派梯队、改编边界）。
3. `01-立项定位.md`、`09-立项书.md` —— 已完成的两份实填件，**照这个颗粒度与语气写**。
4. 对应模板原文（`模板原件/XX-...md`）。

## 二、结构原则：模板不动，实例动

- **保留**：模板的全部一级/二级/三级标题、编号（§1.1、A3、C2…）、⚑ 标记、表格列名、自检项顺序。
- **替换**：所有占位符、空白单元格、示例行 → 本项目的实际内容。
- **删除**：模板末尾的「附录 · 样本参考」（含两份发源书样本的数值/专名/纪律）与「本份模板 · vX 变更记录」——这两节是模板维护史料，实例分发时不需要。若保留，必须在文件头注明"模板维护史料，非本实例内容"。
- **改写**：凡模板正文中出现"（包外，见 14 D-xx）"的引用，改为指向本包内文件；无法指向的，改写为纯文字结论。
- **禁止**：不得保留"填写说明"式的空话占位；不得整段照搬模板说明文字当正文。

## 三、填写原则

1. **锚点只引用**：书名、一句话故事、五律、术语定义、卷题、主角欲望/恐惧/错误信念——一律写"见裁决表 §X"，不重抄。展开与数值化归本分册。
2. **原著事实标号**：写"李英琼持紫郢剑（F-20）"这样带编号；无编号的事实不许写。B 级事实标"（存疑）"。
3. **原创设定标"本项目设定"**：阙文、补笔、批注、对笔、结卷、佚卷、掌籍、白朴，首次出现须标一次。
4. **可判定**：规则写成判定问句（"此人是否在任一名册出现？否 → …"），不写"很强大""有神秘力量"。
5. **代价与反制**：任何能力条目必须同屏给出代价与反制，缺一即不合格。
6. **具体到能施工**：写"第 3 章末：他在名册上找不到自己名字，翻页时纸面把他手指盖住了"，不写"要有悬念"。
7. **N/A 三态**：`- [x] 过` / `- [ ] 未过` / `- [N/A] 因 X 假设不成立`。N/A 必须写理由；分母按适用项重算，另列"N/A × N"。
8. **不虚构前置**：为过某条而编一个平台/日更/金手指，一律禁止（`00 §四` 反向约束）。

## 四、本项目的既定事实（不得改写）

- 书名《蜀山之撼天凡蚁登天路漫漫》，180 万字 / 6 卷 / 章均 2400 字，起点·古典仙侠，日更 4000。
- 主角杨成志，19 岁，凝碧崖掌籍房杂役；能力"阙文/补笔"；代价"交出可能"；反制"批注"。
- 六卷：凝碧崖 → 青螺峪 → 紫云宫 → 幻波池 → 光明境/铜椰岛 → 凝碧崖（结卷）。
- 每卷只回答一个问题（见裁决表 §六），不得另起主题。
- 反派：许飞娘（一级）／晓月禅师（镜像）／掌籍真人白朴（系统）／结卷（非人格化）。
- 文风基调：原著是"半文半白＋骈俪写景＋短于人物"（F-31）；本书**留物不留腔**——洞府法宝的质感留下，对句骈俪不留；文风为电波系轻小说（裁决表 §十二），用底层错频解构仙侠术语。具体阈值归 `05 §1.1`。
- 不设境界链（F-35）；"升级"＝名分等级（不入谱→记名→入谱→有传→有祠→有碑）。

## 五、文风要求（所有分册一致）

- 简体中文；表格优先于长段落；每个判断后面跟依据（编号或"本项目设定"）。
- 不用"赋能/闭环/抓手/颗粒度"这类咨询黑话（除本规范自身）；不用形容词堆砌代替内容。
- 段落短，一句一个判断；不写"综上所述""总而言之"。
- 术语首次出现给一句白话解释。
