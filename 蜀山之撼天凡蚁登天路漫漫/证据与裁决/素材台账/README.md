## 二、为什么建这个（不是模板洁癖）

2026-11-18 卷三准备期的事实：**四份上游文件同时声明卷三 251–375，逐章事件互斥**——
`02E`（卷级关键章摘录）、`02B`（卷级细纲）、`02F`（循环施工表）、`03D`（施工级逐章）。
实测 `02E` 的 15 个 ★ 章与 `03D` **事件一致 0 个**（★251「旧册到了，纸是咸的」vs「十二天水路」）。

而当时的检查项只能查**字数／引号／重复段／哈希**，**完全查不出这类语义层冲突**——全靠人读四份文件逐条比对，比对结果还只存在于对话与提交信息里。

**建表之后**：分歧在表里可比对、裁决在表 2 有行、缺陷在表 4 有编号、遗留项能交接。
