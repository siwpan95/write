## 1. 基础设定卡

| 字段 | 内容 |
|---|---|
| 书名 | **《蜀山之撼天凡蚁登天路漫漫》**（副题"一部关于'没被写下来的部分'的仙侠"，仅宣传语用） |
| 类型标签 | 古典仙侠 · 规则流 · 元叙事（第 1 个决定读者在起点·仙侠·古典仙侠里找到它；**不报"修真"**，原著无境界链，F-35） |
| 一句话故事 | 见裁决表 §二（47 字，不重抄）。三零件：**谁**＝被名册漏掉的杂役杨成志；**要什么**＝让自己的名字算数；**挡着**＝这世界只承认"被写下"的存在，而他连死都没被写下 |
| **时代背景** | 康熙二年（1662），对应原著第 215 回"峨眉开府"前后（F-25，B 级存疑，本项目按"开府＝转折"采用）。技术处于冷兵器＋儒释道文书官僚＋剑仙法宝的混合态；与现实最大的差异只有一条：**存在依赖记录**（R1），而非依赖血统或武力 |
| **核心冲突（一句话）** | 峨眉谱房（把卷定稿，为保万人算数可牺牲一人）**vs** 五台派·魔教（争"谁有资格被写进正史"）**vs** 结卷（R5：时间到就定稿，无人可谈）。杨成志不属于任何一方，他是三方的**笔** |
| 精神内核 | 见 `01 §3`：一个人要被记住，靠的不是名分，是有人肯替他作证。删掉它，全书六卷的每一次补笔都不成立 |
| 目标读者 | 22–35 岁男性为主；读过或听过《蜀山》、玩过仙剑类游戏；因"未完成的名著被补完"与"规则解谜"点开（`19 §三 B`） |
| **目标字数** | 180 万字 ｜ 卷数 6 ｜ 单卷 30 万字 ｜ 单卷约 125 章（章均 2400 字） |
| 对标作品 | 《诛仙》《凡人修仙传》《诡秘之主》——学什么、不学什么见 `01 §4` |

**世界尺度**：横向六图——蜀中群山（凝碧崖，海拔与人情都最"厚"）→ 川边峡谷（青螺峪）→ 南海海底（紫云宫）→ 内陆遗府（幻波池）→ 小南极极昼（光明境）→ 南海孤岛（铜椰岛）；纵向一层——名册所及之处才是"世界"，名册之外是阙文。**所以本书的"世界大小"不按里数算，按册上写了多少算**。
**基调**：冷、紧、少话。原著"半文半白＋骈俪写景＋短于人物"（F-31）取其景、弃其骈——**留物不留腔**：洞府、法宝、法度的质感留下，对句与骈俪不留；用底层错频（灶房/账本/蚂蚁）解构仙侠术语（裁决表 §十二；阈值归 `05`）。

**核心冲突为什么只有三方**：第四方（散仙联盟）没有"定稿权"，只有"被写进劫册"的诉求，它天然依附三方中的任意一方，所以不占一方；两方会塌成打怪，四方读者记不住。

## 2. 世界规则表（可判定形式）

> 五律为裁决表 §四锚点，**只允许 5 条，不新增第六律**（`01 §5` 力量红线）。以下把每律写成"主体＋条件＋结果"，并在 §2 逐条给判定问句、是/否分支后果与反例。

| 编号 | 主体 | 条件 | 结果 | 备注/出处 |
|---|---|---|---|---|
| **R1** | 世界（一切人、物、事） | 此人/物/事是否在任何名册、谱牒、碑记或三人以上的口传中出现过 | **是** → "算数"：旁人看得见、名册分得灵气、路径走得通、物件有分量。**否** → "阙文"：逐渐淡去（旁人记不住名字、影子变淡、物件失重、走的路自己绕回来） | 裁决表 §四 R1；"阙文"本项目原创 |
| **R2** | 能看见阙文并下笔者（当前仅杨成志） | 补笔内容是否与已写定事实冲突（对照名册、碑记、三人以上口传三项） | **不冲突** → 空白成立，该处自此算数。**冲突** → 反噬：写错处从补笔者身上按量扣（错一句话扣一段记忆，错一个人扣一样本领） | 裁决表 §四 R2；"按量扣"为本项目设定展开 |
| **R3** | 补笔者 | 该次补笔是否**当场**交代交出哪一种"本来可能" | **交代** → 补笔生效；该可能永久消失，且从本人记忆中清除。**未交代** → 该次补笔无效，世界退回原状；但砚中墨仍耗一分（墨不退款） | 裁决表 §四 R3 |
| **R4** | 任一"记名"及以上（§8.2）的算数者 | 是否**当众**以其名分作保，指出补笔处与已写定事实相悖 | **无人应** → 补笔维持。**有人应** → 进入"对笔"（比名分硬度，不比人数）。**批注成立** → 补笔当场崩解，补笔者遭"反写"：其名从最近一份记录上被划掉 | 裁决表 §四 R4；批注／对笔／反写本项目原创 |
| **R5** | 世界 | 是否临近结卷节点（开府／斗剑／四九重劫；由谱房预告＋天象两项**同时**可观测） | **是** → 所有"未写定"者进入倒计时：阙文扩大、口传失效加速、名册自行合卷。**否** → 常态 | 裁决表 §四 R5；原料见 F-13 |

### R1 存在律 · 判定卡

- **判定问句**：此人是否在任一名册、谱牒、碑记或三人以上的口传中出现？
- **是 →** 他算数：别人记得住他的名字，饭堂给他打饭，符纸对他有效，名字可被"批注"引用。
- **否 →** 他成阙文：三日内旁人叫不出他名字；七日物件在他手里变轻；半月后他走的路会自己绕回原地；三十日后**连他自己都要靠别人的册子确认自己在哪**。
- **反例（什么情况不算违反）**：
  1. **写错了名也仍算数**。名册上把他的名字写错一个字，他照样算数——R1 只辨"有没有一条记录"，不辨真假；要纠正得走 §13 变更登记或 R4 批注，不能靠主角自己说"那是我"。
  2. **只在两个人之间说过，不算数**。老周私下对杨成志说过十遍"你叫杨成志"——仍不成立，口传须三人以上。这条是卷二"救老周"的技术前提：他必须让第三个人听见。
  3. **临时算数不算破律**：一位"有祠"者当众替阙文者作保，阙文者可在保期内被看见——这是 R4 的效果，不是 R1 失效。
  4. **物件以"用过"代记录**：一把刀被人用过十年、三人记得它砍过什么，即算数；无需刻字。

### R2 补笔律 · 判定卡

- **判定问句**：本次补笔的内容，是否与已写定事实冲突？
- **不冲突 →** 空白成立。写下的句子会自己走进最近的册子里（墨迹在空气里走，落到纸上即生效）。
- **冲突 →** 反噬。扣的次序固定：**先扣记忆，再扣本领，最后扣名字**（扣到名字即变成阙文，无人可救）。
- **反例**：
  1. **凭空造物算违反**。写"崖下有一口井"而崖下从来没有井——无"已发生事实"可依，是造，不是补，反噬。
  2. **补写"某人已死"而此人尚在**——直接冲突，反噬最重（扣一样本领）。
  3. **只想不写不算违反**。他在心里排演十种写法、把故事讲给自己听，都不触律；**只有下笔才结算**。
  4. **抄录不算违反**。他抄名册、抄碑文、抄别人的传，一个字都不改——那是 R1 的记录行为，不是补笔，不付 R3 的代价。

### R3 代价律 · 判定卡

- **判定问句**：本次补笔，交出了哪一种"本来可能"？（须能说出具体内容）
- **交代了 →** 补笔成立。交出的那种人生从此不存在，也从此**不在他记忆里**（读者记得，他不记得——这是全书最大的痛感装置）。
- **没交代 →** 该次补笔判为无效：已写下的字散成墨点，世界退回原状，砚仍耗墨一分。**审判者是制度，不是人**（无人可求情）。
- **反例**：
  1. **随口一句不算交代**。"我什么都不要了"不是"一种可能"；有效的交代必须是他**真实算过的那条路**（例：卷一九章他交出"下山做个货郎，娶邻村女子，五十二岁死在自己床上"）。
  2. **别人代笔，代价仍归执笔者**。若杨成志替老周写，代价从杨成志身上扣，不从老周身上扣。
  3. **不补笔的场合不付代价**：只"看见"阙文（被动）不付费；用笔写字画画给活人看也不付费，只要不落到册上。

### R4 批注律 · 判定卡

- **判定问句**：是否有在场者以自身名分作保，当众质疑本次补笔？
- **无人应 →** 补笔维持，且此后不可再被同一事由质疑（一事一批）。
- **有人应 →** 进入对笔：双方各报"名分等级＋可作证的人数"，名分差 ≥2 级则低者必败；同级则比"谁记的人更多"。**败者不是死，是被从册子上划一笔**——他失去那一笔所记的东西。
- **反例**：
  1. **人多不算硬**。十个人一起喊"他写错了"仍不敌一位"有传"者一人开口——R4 比的是名分硬度，人数只在同级对笔时用。
  2. **私下质问不作数**。须当众、须有第三方在场记录（记在签到簿上即成立，是低成本的取证方式）。
  3. **翻旧账不受理**。批注只能指向"本次补笔"，不能指向三十年前已无人异议的记录；翻旧账要走碑祠（§3.3），代价极高。
  4. **批注错了不罚**：批注失败的算数者不受伤，只丢脸；这条让配角敢冒险替主角挡。

### R5 结卷律 · 判定卡

- **判定问句**：当前是否临近结卷节点？（谱房预告与天象须同时成立）
- **是 →** 倒计时开始：所有阙文的"淡去"速度乘十；名册开始自行合卷（页边自己粘合）；口传失效（同一句话三人说出三个版本）。
- **否 →** 常态（每人一年内最多掉一次"记不清"）。
- **反例**：
  1. **一个人的死不是结卷**。李英琼的师父死、某位散仙兵解，都不触 R5——结卷只认"世界级节点"。
  2. **结卷不辨善恶**，只辨"写没写"。魔教中人只要被写下，照样留在卷上；这条是全书最难接受、也最必须成立的一条。
  3. **推迟结卷不算破律，但要付账**：每推迟一次（本项目设定：需三位"有祠"者联署续期），代价是更多人在续期期间掉出卷外——账记在 §5 H-02 的长期账单里。

## 3. 世界四层建构表

### 3.1 自然环境层

| 提问 | 回答 |
|---|---|
| 地形/气候：这块地方长什么样，天气对人有多凶？ | 主舞台凝碧崖在蜀中群山（F-22），四面绝壁、云海在下、上崖只有一条石阶；蜀中多雨，三月雾季，雾里阙文更难被看见（这既是气候也是规则）。另有海底（紫云宫）、极寒极昼（光明境，小南极）、南海（铜椰岛）——越远的地方，名册越薄，阙文越多 |
| 资源：能撑起文明的生存资源是什么？最缺什么？ | 撑得住的是**灵气**与**符纸墨**；最缺的是**名分**。灵气分布不均且不可私占：它按名册分配（R1），不入谱者站在灵气最浓处也吸不到一分。这条把"地理"直接接到"制度" |
| 物种：本地食物链顶端是谁？人排在第几？ | 顶端是"有祠／有碑"级存在与原著异类（神雕佛奴、猩猩袁星，F-TBD-01/02，见 §11.1 与 §13 CHG-003）；普通修士居中；人类杂役在底层，且是唯一"可以被写掉"的一层 |
| 灾难：周期性要命的东西是什么？多久来一次？ | ① 四九重劫，四百九十年一度（F-13）；② 第三次峨眉斗剑（F-13，全书未写结局，F-08）；③ 每甲子一次的**谱房校册**（本项目设定）：校册当日旧册换新册，未被誊入者当场掉出卷外 |
| **→ 它决定了哪种生存方式** | **寄名**：不入谱者靠"挂在别人的名分下"活着——给有传者当杂役、当抄手、当替名的人。这就是杨成志的处境，也是全书一切底层行为的动机 |

### 3.2 社会结构层

| 提问 | 回答 |
|---|---|
| 政治：谁说了算？权力凭什么被承认？ | 峨眉谱房说了算（掌籍真人白朴）。权力凭"被写进正史"承认——不是血统、不是武力。剑房能杀人，但只有谱房能让人"存在过" |
| 经济：钱从哪来，劳动怎么换饭（见 §10）？ | 四条：灵石（硬通货）、香火（祠庙配额）、功德（谱房记账的差事工分）、名分（可折资源、不可买）。杂役的饭＝抄完一册名册换一日口粮 |
| 军事：暴力垄断在谁手里？个体武力的天花板？ | 剑房垄断（紫郢、青索，F-20）。个体天花板＝"有传"级持剑者；"有祠"以上不亲自出手（一出手就要在册上留战绩，等于把自己写死一处） |
| 法律：一条命值多少钱？犯事怎么罚？ | 命价见 §10。最重的罚不是杀，是**划名**：从名册上划掉一笔，人还活着，但从此不算数——比死更重，因为"死还有人送，被划名没人送" |
| 阶层：上升通道存在吗？谁被卡死在原地？ | 通道＝开府入谱（三年一开）。被卡死的三类：杂役（不入谱）、散仙（无门无派，只能求被写进劫册）、被除名者（晓月禅师，F-18——他活着，却不算数） |
| **→ 它决定了哪类冲突必然发生** | **定稿权之争**：谁写的版本被誊入正卷，谁就是"正统"。所以峨眉与五台派打的不是地盘，是"谁来写我"（裁决表 §七） |

### 3.3 文化表层

| 提问 | 回答 |
|---|---|
| 信仰：人们信什么？为什么这种苦难下恰恰信这个？ | 信"写下来就作数"。因为这是唯一被验证过的因果：进香、立碑、抄册之后，人真的会被记住。碑祠崇拜即此教（长眉碑在凝碧崖顶） |
| 语言/称谓：有什么只在本地流通的行话？ | "算数／不算数"（存在与否）、"在册／在野"、"记名"（最低一档）、"批一句"（当众质疑）、"阙了"（人没了）、"你这阙文"（最脏的骂人话，本项目设定） |
| 日常：普通人一天怎么过（见 §11）？ | 五更起、抄册、校字、送签、烧火、守夜。一天的高光时刻是"签押"——在签到簿上写下自己的名字，那一刻是唯一被确认存在的时候 |

### 3.4 个人经验层（一个杂役眼里的开府）

| 提问 | 回答 |
|---|---|
| 主角**身体上**最先感到的是什么？ | 墨臭与手冷。他在分灵宴上端菜穿过人群，菜在手里凉了，没有人给他让路（`09 §四`）；被人撞到时，他感到的不是疼，是**没有阻力**——像撞到一团布 |

### 3.5 禁忌登记（文化层的果实，必填）

| 编号 | 禁忌内容 | 来源（哪个历史事件/规则） | 破禁后果 | **是否卡住主角的目标** |
