## 一、调研综述（本书只取结论，不重述外部案例）

### 1.1 中文谱系：五个教训 → 本书五条纪律

| 教训（来自程序全自动生成长篇的失败） | 本书落点 |
|---|---|
| 堆字量 ≠ 讲故事 | 程序化产物只进 `03`／`04`／`13` 的条目表，不进 `05`／`08` |
| 形容词泛滥是模板病的指纹 | 命名条目必须带"役别＋册别＋名分阶"三项硬字段，不许带外貌描写 |
| 规模骗局不可复制 | 本书 180 万字是结构量（6 卷 × 30 万），不靠程序化产量凑 |
| 可复现性是唯一护城河 | 每批生成记录：脚本、参数、种子、日期、产出路径 |
| 程序难编情感内核 | 主角弧光、老周线、结卷抉择**禁止**程序化（§二 禁用判据 2） |

### 1.2 西方谱系：本书只用到两代方法

| 方法代 | 本书是否用 | 用途 |
|---|---|---|
| 第 2 代 递归文法／字素组合 | **用** | 命名工厂（§3.1）＋谱牒条目文法（§3.2） |

### 1.3 大模型时代：程序化变成骨架，不是作者

| 流水线步 | 本书采用方式 |
|---|---|
| ① 结构化计划 | 人定：`02` L1–L4 ＋ `10` 节拍；脚本只校验（不生成） |
| ② 逐段生成 | 人写正文；AI 可给 2–3 个候选句（候选不进正文，须人重写） |
| ③ 候选重排 | 机械初筛交 §3.4.2 账本，人终审 |
| ④ 事实修订 | 修订指令由 §3.4 巡检产出，AI 只执行，不自判 |

### 3.4 槽位四 · 机械巡检（本书拆成两个子槽位）

#### 3.4.1 名分状态机巡检

- **状态集合**：`不入谱(0) → 记名(1) → 入谱(2) → 有传(3) → 有祠(4) → 有碑(5)`（`03 §8.2`，六阶，禁增第七阶）。
- **规则**（可写成白纸黑字）：
  1. 每次转移只允许 ±1 阶，且必须挂一个触发事件（补笔／朱圈／批注／除名／授册）。
  2. 补笔引发的转移，必须同章给出"交出的可能"（R3，裁决表 §四）；缺 → 该次转移判无效。
  3. 连续 3 章无状态变化 → 告警（`02 §5.5` 红线：连续 3 章不得无一次名分变化）。
  4. 对笔结果须与名分差一致：差 ≥2 阶则低者必败（`03 §8.2` 对笔判据）；不一致 → 告警。
  5. 状态名必须是六阶原文；出现"代笔候补""半个弟子"这类口语 → 记为别名，不新增阶。
- **输入**：`02 §4.2` 章纲"名分变化"列 ＋ `04 §A11` 当前状态 ＋ `03 §9.2` 即时快照 ＋ `06 §三` 伏笔账。
