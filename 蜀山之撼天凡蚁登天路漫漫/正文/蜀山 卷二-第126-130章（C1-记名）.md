# 第 126 章 记人名

开宗前一年，宗门要造一本名册。

（造名册这件事，比修屋顶、挑水、劈柴都重要，因为名册一出来，这地方就有了“谁是谁”。）

（有了谁是谁，才有谁该吃哪一碗饭，谁该站哪一个位置，位置，才是这地方最要紧的东西。）

（要紧的东西，从来不交给随便的人，所以执事在院子里站了半天，把所有人都看了一遍，最后手指点住了他。）

（点住他，是因为他会写字，会写字的人不多，不多，才金贵，金贵，才轮得到这种活。）

（活是好活，坐在屋里，不用挨风，可它也有另一面——名字写错了，就是一条命错了，命错了，谁也赔不起。）

（执事把一叠白纸放在他面前，纸上没有一个字，白得像雪，雪上什么都没有，什么都没有，才要他写。）

（执事说了一句，说的是，从今天起，你记人，记人，才是这地方的根。）

（他没有问为什么，不问，是因为他知道问了也不会多出一个答案，答案，才是这地方最贵的东西。）

（他坐下来，把纸铺平，把笔蘸饱，蘸饱的笔，写出来的字才压得住纸，压得住，才不散。）

（散了，就等于没有写，没有写，就等于这个人不存在，不存在，才是这世上最冷的。）

（第一个来的是个挑水的，挑水的把手在衣上擦了两下，擦完才报名字，报得很小声，小声，是因为他不习惯被人问名字。）

（不习惯，是因为这地方从来没有人问过他的名字，不问，就只是一个“挑水的”，一个岗位，不是一个人。）

（他把名字写下来，写完抬头看了一眼那人的脸，看完，他发现那人的眼睛里有一点东西，那不是高兴，是被看见的慌。）

（慌，是因为他被看见得太少了，少到一被看见就不知道手往哪里放，手没处放，就只能擦衣裳。）

（他忽然明白，记名字这件事，不只是记，它还是给，给一个人一个“被叫得出来”的东西，东西在，人才在。）

（他把这一层想明白了，就写得更慢，慢，是因为他要把每一笔都写正，正，才配得上刚才那一眼。）

（第二个人是个女的，她报的是一个绰号，绰号是“三娘”，他问了真名，她摇头，摇头，就是不说的意思。）

（不说，他也不追，不追，是因为他知道这地方有的人的名字是不能写的，写了，就要出事，出事，才是祸。）

（他在纸上记下“三娘”两个字，然后在旁边画了一个小圈，小圈是他自己定的记号，意思是“此名待考”。）

（待考，是他给自己的活，活在自己手里，才叫本事，本事，才是他唯一带得走的东西。）

（第三个人报了一个名字，那个名字他听着耳熟，耳熟，是因为他在紫云宫旧册上见过，见过的东西，才会耳熟。）

（他没有声张，声张，就是把这件事摊在太阳底下，太阳底下，什么都活不长，活不长的东西，才最需要藏。）

（他把这个名字写得很正，正得看不出一点异样，异样，才是这地方最容易被记住的，记住了，就要被查。）

（一天下来，他记了四十三个名字，四十三个，才是这地方的一小半，一小半，才要接着记。）

（傍晚他把纸收起来，收得很齐，齐，才不丢，丢了一张，就是丢了一个人，人丢了，才是这地方最不该发生的事。）

（他抱着那叠纸往回走，走的时候，他忽然觉得这叠纸很重，重，不是因为纸厚，是因为上面有四十三条命。）

（命在纸上，纸就在他手里，手里有的，才是真的，真的，才要护住，护住，才是这地方的人。）

（他记名的时候，桌上放了两样东西，一样是纸，一样是一小碟清水，清水是用来润笔的，笔一干就写不出正字。）
（这是他自己想出来的法，从前的人写名册都是干写，干写的字容易涩，涩了就难看，难看的字，是对人的不敬。）
（敬这个东西，他这半年才学会，学会之后他才知道，敬不是给别人，是给自己，你敬人，人才敬你，你才有脸站在这地方。）
（第四十四个人来得很晚，天已经擦黑了，他说他白天在山上砍柴，砍柴的人只有天黑才回来，回来才有空报名字。）
（他把这人的名字写完，写完抬头看，看见那人手上有三道口子，口子很新，新得还在渗血，血在灯下是黑的。）
（他没问那口子是怎么来的，不问，是因为在这地方，伤口是自己不小心弄的，说出去就要被记一笔，记一笔，就不值钱了。）
（他只把纸往那人那边推了推，让他按个手印，手印按上去，印泥里就多了一点红，红才是这地方最真的色。）
（按完手印，那人忽然说了一句，说的是，我这名字，三十年没人叫过了，说完他自己愣了一下，愣完就走了。）
（他坐在那儿，把这句话在心里过了一遍，过完他忽然觉得，这本名册其实不是名册，是三十年的沉默被翻了出来。）
（他把册角对齐，对齐了才收，收的时候他忽然想，如果这本册将来丢了，这四十三个人就又回到沉默里去了。）
（回到沉默，才是最冷的，冷到骨头，骨头才记得住，记得住，才知道自己该干什么。）
（他把册抱在怀里往回走，路上碰见执事，执事问他记了多少，他答四十三，执事说，明天还有二十个。）
（二十个，才是明天的活，活一直在，才不慌，不慌，才是这地方的人。）

（他记名的时候，还有一个规矩，就是每写完一个人的名字，要抬头看一眼他，看一眼，不是礼貌，是核对。）
（核对眼睛和名字对不对得上，对得上，才敢落笔，落笔之后，这个人就算真在这地方了，真，才是这地方最缺的。）
（他一共核了四十三次，核到第三十次的时候，他忽然发现，人的眼睛比名字实，名字可以编，眼睛编不出来。）
（这一层他记住了，记住，是因为往后的年月里，他还要靠这一双眼睛去看很多人，看人，才是他要学的本事。）

（他把册合上之前，又翻到第一页看了看，第一页上第一个名字是那个挑水的，字是他写的，写得很正。）
（正的字会一直在这本册上，一直到他死，或者到这本册被烧掉，被烧掉之前，这个名字就是那个人。）
（他忽然觉得，自己写的每一个字，都是在替一个人多活一阵子，多活一阵子，就是他能给的全部。）

（本章完）

# 第 127 章 三十七条门规

第二天他被派去抄门规。

（门规一共三十七条，三十七条，是这地方三百年的积累，积累得越多，越像一张网，网密了，鱼才跑不掉。）

（网密，才是这地方最厉害的地方，它不逼你，它只让你自己小心，小心，才是这地方的活法。）

（他抄的时候抄得很认真，认真，是因为他知道这些字不是给人看的，是给人照着做的，照着做，才是规矩。）

（抄到第十九条，他停了一下，停，是因为他发现这一条跟第七条对不上，对不上，就是矛盾，矛盾，才是这地方最不该有的东西。）

（第七条说，凡入山者，先录其名，名不入册者，不得食，这一条讲的是“先有名，后有食”。）

（第十九条说，凡初入者，先给三日食，三日后录名，这一条讲的是“先有食，后有名”，两条正好反过来。）

（他把这两条反复看了三遍，三遍，才确认自己没有看错，没有看错，才敢往下想，往下想，才是他这半年的习惯。）

（他想，这两条其实不是矛盾，是先后的问题，第七条是常例，第十九条是新例，新例压旧例，才是这地方的规矩。）

（可新例没有写“新例”两个字，没有写，就说明写的人不想让人看出来，不想让人看出来，才是这地方最会的。）

（他不敢改，改，就要掌籍亲手，他不是掌籍，改了就是越界，越界，就要罚，罚，才是他吃过的苦。）

（他也不敢不记，不记，就等于没看见，没看见，就等着以后出事，出事了，他一样跑不掉，跑不掉，才是最冷的。）

（所以他用了一支很细的笔，在第十九条旁边画了一道很浅的线，线浅到要凑近才看得见，看得见，才是他给的记号。）

（记号不是改，不是改，就不越界，不越界，才安全，安全，才是这地方的第一条路。）

（他画完，把册合上，合上之后他在心里把这件事放好，放好，才不占地方，不占地方，才想得清别的事。）

（傍晚执事来收册，收的时候翻了两页，翻到第十九条，停了一下，停的那一下很短，短到别人看不出来。）

（可他看出来了，看出来，是因为他一直在看执事的手，手停，才是人心里动的时候，动，才说明他看见了。）

（执事没有说话，把册合上，合上之后只说了一句，说的是，你倒是仔细。）

（五个字，说得不轻不重，不轻不重，才是这地方夸人的法子，夸得太重，就是捧，捧，才是害人。）

（他低头应了一声，应得很轻，轻，是因为他知道这不是夸，是记，记下了，往后就要多用他，多用，才是机会。）

（机会来了，就要接，接得稳，才叫本事，本事，才是他的全部。）

（他把那一条批注写完之后，又往回翻了三页，翻的时候他在想，这三十七条里还有没有别的地方对不上。）
（他一条一条比，比得很慢，慢，是因为这种活最耗神，耗神的东西，才最见功夫，功夫，才是他的命。）
（比到第二十六条，他又发现一处，第二十六条说“凡有过者，罚抄百遍”，可第四条说“过轻者，罚三日火”。）
（两处并不算冲突，可它们放在一起，就有一个空子，空子在于“过轻”和“有过”之间的界线没有人写，没有写，就能随便说。）
（他没有再画线，这一次他只是在心里记住，记住，是因为他明白，画太多了，就被人看出来他存了心。）
（存心这两个字，在这地方是最危险的，你有心，就说明你想往上走，想往上走，就会挡别人的路，挡路，就要被人使绊。）
（所以他把后面的都放过去了，放过去不是没看见，是看见了不动，不动，才是这地方最难的功夫。）
（他把册交上去的时候，执事翻到第十九条，看了很久，看完问他，这一条，你觉得该怎么写。）
（他答得很慢，答的是，照旧写，只是加一句“新例自某年始”，加了这一句，两条就不打架了。）
（执事听完，没有说话，过了一会儿才说，你这话，不像抄书的人说的，像掌籍说的。）
（他低头，没有接这句，不接，是因为他知道这句是试，试他有没有想往上爬的心，他一接，就露了。）
（执事看他没接，笑了一下，笑完就把册收了，收的时候说了一句，说的是，你会写，但你不会说。）
（七个字，是判，判得准，准，才是这地方最认的东西，认了，才是根。）

（他从账房出来的时候，天已经暗了，暗下来的天把院子压得很低，低得叫人心里发闷，发闷，是因为他知道自己刚才多做了一步。）
（多做一步这件事，在这地方有两种结局，一种是被人记住，一种是被人生恨，记住和生恨，往往是一起发生的。）
（他站在院子里想了想，想完他决定往后少做，少做不是躲，是把力气留给真的要紧的地方，要紧的地方，才值得动。）
（他把这个分寸记住，分寸这东西，不写在册上，写在人心里，心里有的，才是真的。）

（他回到灶下的时候，老火工正在拨火，火拨得很旺，旺火才烧得开一锅水，水开了，才有明天早上的粥。）
（老火工见他进来，问了一句今天做什么，他答抄门规，老火工笑了一下，笑完说，门规是给守规矩的人看的。）
（这句话他没听懂，追问了一句，老火工说，守规矩的人不用看，不守的人看不懂，看懂的人，早就不守了。）
（他站在那儿想了一会儿，想完，他忽然觉得这地方最深的东西，都在这些不写字的人嘴里，嘴里有的，才是真的。）

（他躺下之前，把今天抄的门规在心里默了一遍，默到第十九条，他停下来想，这一条到底是谁加的。）
（加这一条的人，一定见过新人饿得站不起来，见过，才会改，改，才是这地方还有一点人味的地方。）
（人味这个东西，从来不写在册上，写在册的缝里，缝里有，才说明这地方还能活三百年。）

（他闭上眼的时候，听见外面有狗叫，狗叫得不多，叫两声就停了，停，说明没有生人，生人来了才是这地方的事。）

（狗叫声停了以后，院子里就彻底静了，静得能听见自己的心跳，心跳四下，四下才是平，平，才是他现在的日子。）

（他翻身朝里，草扎了一下，扎，才觉得自己还是活的。）

（本章完）

# 第 128 章 修屋顶

开宗前一年的夏天，西厢的屋顶漏了。

（漏，是因为去年的雪压得太厚，压厚了，瓦就裂，裂了，雨就进来，进来，屋里就没法住人。）

（没法住人，就要修，修屋顶要瓦，瓦要从山下运，运瓦要钱，钱在账房，账房不给，不给，就自己想办法。）

（办法是，先把现有的瓦数清一遍，缺多少补多少，补得刚好，才不浪费，不浪费，才是这地方的算。）

（算这件事，落到了他头上，落到他头上，是因为他会算，会算的人，在这地方比会打的人还少。）

（他上了屋顶，屋顶很陡，陡到要贴着瓦爬，爬的时候不能往下看，往下看，心里就慌，慌，脚下就滑。）

（他先量了屋顶的长和宽，量出来的数记在手心，手心才是他最早的册，册上不落墨，落的是汗。）

（一片瓦能盖多大的地方，他心里有一个数，这个数是他自己量出来的，量了三次，才敢定下来。）

（第三次量的时候，他把一片瓦放在地上，用脚量了三次，三次都一样，他才把那个数记牢。）

（长乘宽，再除以一片瓦的盖面，算出来的数，比实际需要的少一点点，少一点点，才是对的，因为边角要留余。）

（他算出来要三百一十二片，现有的有三百零六片，缺六片，六片，不多，可六片就能让一间屋住不了人。）

（他去账房领瓦，领的时候，管账的人问他要多少，他说六片，管账的人抬头看了他一眼，看完就笑了。）

（笑，是因为从前的人来领瓦，都往多了报，报二十片，领回去用六片，剩下的就自己留着，留着，才是这地方的常态。）

（他不这么干，不这么干，不是因为他多干净，是因为他知道多领的那十四片，将来会记在他头上，记上了，就要还。）

（还，才是这地方最厉害的东西，它不催你，它只是记着，记着，总有一天会来。）

（管账的人给了他六片，给的时候说了一句，说的是，你这个人，不会算错。）

（七个字，听着像夸，其实是判，判的是他这个人往后能不能托事，能托，才叫用。）

（他把六片瓦背上屋顶，一片一片地补，补的时候他很小心，小心，是因为瓦很脆，脆的东西，一用力就碎。）

（碎一片，就要再下山一趟，一趟要一天，一天，就是一天的饭，一天的饭，才是这地方最实在的东西。）

（补完了，他坐在屋脊上，往远处看，远处是雪山，雪山上面是天，天很白，白得像一张没写过字的纸。）

（他忽然想，如果他这辈子能在这张纸上写下一行字，那一行字就够了，够了，才是他要的。）

（他从屋顶下来的时候，老弟子正在院子里看着，看的时候没有说话，等下了地，才说了一句。）

（说的是，你会算，会算的人，将来要吃亏的，他问为什么，老弟子答，因为算得太清，别人就没法糊弄你。）

（别人没法糊弄你，就不喜欢你，不喜欢，就把你放到最边上，边上，才是这地方最冷的地方。）

（他听完，没有说话，没有说话，是因为他知道这话是真的，可他没有别的路，路，是他自己走的。）

（他算瓦的时候用了一个别人不用的法子，别人是数有多少间屋，他是数一年要换多少片瓦。）
（一年换多少片，才是这地方真正的账，账不是今年的，是往后十年的，十年的账，才叫算。）
（他把十年要用的瓦数写在纸上，写在纸上，是为了给账房看，账房看了，才知道这人算得远，算得远，才敢用。）
（算得远这件事，在这地方很少见，少见，才叫本事，本事在手，才有人记，记了，才有下一次。）
（他从屋顶下来之后，把剩下的半片瓦也收了回去，半片也是瓦，瓦在这地方比纸贵，贵的东西，才不能随手丢。）
（管账的人看见他把半片也还回来，愣了一下，愣了一下之后就在账上把这一笔记成“整”，整，才是他给的脸。）
（他明白这一层，因为他在崖上就学会了，给脸这件事，不用花钱，可不花钱的东西，才最贵。）
（那天晚上他躺在草堆上，忽然想到一件事，想到的是，会算的人，其实是在替这地方省钱，省下来的钱，从来不会到算的人手里。）
（不到手里，也不等于白算，因为算得清的人，才有资格被留下来，留下来，才有一切。）
（他把这一层想透了，心里反倒安了，安了，才睡得着，睡着，才是明天。）

（他补完瓦那天下了一场雨，雨下得不大，可下了整整一夜，一夜过去，屋里没有一滴水进来，没有水，才是他这活的答案。）

# 第 129 章 一个错字

# 第 130 章 名字的重量
