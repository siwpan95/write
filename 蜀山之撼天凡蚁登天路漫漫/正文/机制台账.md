# 机制台账 · 跨批交接用

> 用途：每卷定稿后，把本卷**写了"某个身体/器物/条件导致某结果"的机制**登记在此。
> 下一卷开写前，**把本表随规格一起交给执行单元**，并在规格里写明「该机制只能这样表述，不得另立归因」。
> 建立原因：2026-11-18 卷二批次实测——C24 的 244 章把「楊字那一竖为什么少」归因成**墨老旧、胶少、散得快**；而 C23 已定机制为**右手虎口的墨渗进纹路两年**，C25 更用「换左手拿笔、两张纸都断在同一处」→「不是他今天的手坏了」**排除墨这个变量**——三章正面冲突，且同循环内 241 已写对、244 又换说法。**这是语义层冲突，字数／引号／重复段／MANIFEST 全绿。**

## 二、交接检查清单（每卷开写前，主控逐条过）

- [ ] 本表新增的机制，是否已写进本卷施工规格的「跨批机制与设定约束」节？
- [ ] 本卷施工单里，**凡触及既有机制的章**，是否标注了"该机制的唯一归因"？
- [ ] 本卷是否有章**另立归因**？（执行单元发现冲突须报主控，不得自行折中）
- [ ] 代价数字是否**可数、可累加**（门房少半截 → 今天少更多）？
- [ ] 规格里是否写明「**不得改写机制**」的红线？

---

## 三、登记规则

1. 一条机制**只登记一次**，后续卷若有补充表述，追加到「已定稿章」列，**不改归因**。
2. 若发现某章**另立归因**且已定稿：立刻标记「❌ 冲突」并令其修改（走规格 §三-6 的报主控流程）。
3. 若某机制**确实需要细化**（不是改归因，是补细节），在「表现」列追加，并在交接时说明。
4. 本表随每卷施工规格一并交接，**规格里须有本表的引用**。
