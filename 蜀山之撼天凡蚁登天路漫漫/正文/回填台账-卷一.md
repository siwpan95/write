## 四、一致性核查（C13–C16 批次）

| 项 | 结果 | 说明 |
|---|---|---|
| 送≠押 | ✅ | 一前一后是「夹」，不碰手；送的人不出界。遣返是送回，不是押解——与 `03 §8.2` 一致 |
| 「凉了就不算数」 | ✅ | 全批最重的一句：把「恩」转成「条件」，人才收得下。与 C07 老周塞饼、C09「别谢」同一套逻辑，第三次兑现 |
| 半块饼的去向 | ✅ | 大的朝里留在门槛（给于建），小的带走。他给出去的，永远比自己留的多一点——这是他的「认账」 |
| 七日与「张五」 | ✅ | 刻痕是旧的，不是崖上那个张五；同名不同人。这一笔不解释，留给读者。数到一百停，是他「不想点名」 |
| 「我认得字」 | ✅ | 全书题眼之一。驿丞问路，他答字——答非所问，却是他唯一真实的本事。字就是他的路 |
| 「抢」的边界 | ✅ | 那人说的是「抢位置」，不是「抢人命」。本作红线：抢可以，害无辜不行。C15 只给了「抢」的念头，没给「抢」的行动 |
| 掮客的写法 | ✅ | 他不是反派，是生意人；他的话一半真一半钩（真话才钩得住）。墙角七捆行李是他「不记得名字」的物证，一个动作写完他的全部 |
| 青螺峪的门 | ✅ | 没有门，只有三尺雪路；名分写在衣服上，不在册上。与崖上「册」形成对照：一个用册管人，一个用衣服管人 |
| 冷饭 | ✅ | 第一顿就是冷的——不是苦情，是「来晚了」的规矩。他不抱怨，因为「挑是有了以后的毛病」 |
| 数字 | ✅ | 三尺路宽、一百个名字、三块饼、七捆行李、三处磕痕、七块碎砚——全部可复核 |
| S/N | ✅ | 用 S-20（五台派传话人）；N-02 路上、N-25 出崖录（此处无录，正因无录才「野」） |
| 红线 | ✅ | 无虐杀；无「抢」的实际行为；掮客的恶写得克制（七捆行李一笔带过） |
| 文风 | ✅ | 括号行全无引号；对话一律用「他说，……」与独立成行的短句；本批平均句长最短，符合路上章的分量 |
