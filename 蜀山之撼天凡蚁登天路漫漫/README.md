## 三、事实边界（重要）

1. **本包不是原著，也不是原著的替代**。所有原著事实均带 `F-xx` 编号，可在 `证据与裁决/00` 查到来源；B 级事实标"存疑"。
2. **改编合法性**：作者 1961 年逝世，作品自 2012-01-01 起在两岸四地进入公有领域（F-11）。但**影视改编的独创设定不可用**（1983/2001/2015 三部已逐部列出规避项，见 `12 §2.1`）。
3. **第三次斗剑的结局是本项目补写**，不是"还原原著"。原著没写到（F-08）。任何宣传不得暗示"还原"。
4. **联网信息有污染**：调研中命中 4 条 AI 生成的伪考据（虚构统计、虚构刊物、把网文境界链倒灌进民国文本、同名条目被改写），已登记为 X-01~X-04 并给出识别方法。**这 4 条是本包的反面教材，请勿引用其内容。**
5. **AI 参与说明**：本包由人机协作完成（资料检索、结构化填表、交叉校验）。所有判断保留依据与推翻入口（`09` §五 决策清单）。
