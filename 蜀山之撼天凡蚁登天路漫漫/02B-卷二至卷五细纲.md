# 02B · 卷二至卷五细纲（起承转合 × 一无二随）

> **本件修正 `02A` 的一处硬伤**：02A 让杨成志"亲自去"紫云宫、幻波池、光明境当花瓣——但原著写明了那三处是齐霞儿/朱文（紫云宫）、李英琼/易静（幻波池）、七矮/乙休（光明境·铜椰岛）的主场。他去，就违"一有二不随"。
> **修正后的位置**：他不在前线，他在**后方文书房**。原著写"谁打赢了"，本书写"打赢之后，名字怎么记"。

---

> **底座**：本件的每条原著锚点都对应 `02C` 的 S 编号，每处空白对应 N 编号；越界红线见 `02C` §五。
> **章级施工**：四卷的必写章（71 章）、起承转合落点、留白补法，见 `02E-卷二至卷五章纲.md`。

## 一、先把"一无二随"用对

| 项 | 含义 | 本书的执行 |
|---|---|---|
| **一设** | 原著明确写了的：事件、结果、人物定性 | **一个字不改**（芝仙之祸是他自己动的灵符、他被遣返、开府无他份、借阿但含婆之力、逃逸） |
| **一无** | 原著没写、或写得含糊的：他在哪、干了什么、为什么 | **本卷的创作空间**（遣返到收徒之间一百多回，原著一字未写） |
| **二随** | 在空白处补，但要随三样东西 | **随人物**（齐灵云不会突然心软、凌浑仍"人各有心"）、**随制度**（峨眉"有缘"、名册、谱房、散仙渡劫）、**随因果**（斗剑胜负不能改） |
| **一有二不随** | 原著写了的不能动；不把自己的脑补当原著 | 三次拒绝：不去紫云宫、不进幻波池、不参加光明境 |

**判断口诀**：动笔前问一句——**"这件事原著写了吗？"** 写了 → 只能写"背面"（谁在记录、谁被漏掉）；没写 → 才是我的地方。

> **一句话结构**：原著每一件大事，都有一个"文书"环节没写。杨成志就是那个环节。

## 三、他把"补笔"用在了哪里（能力与位置匹配）

| 场景 | 原著写了什么 | 他补什么 | 代价 |
|---|---|---|---|
| 慈云寺阵亡名录 | "破寺，邪派败" | 补"某年某月，某人在寺后挡了一刀" | 交出一段可能 |
| 戴家场战报 | "斩敌若干" | 补"若干"里第一个人的事 | 交出一段可能 |
| 雪山派开宗录 | "凌浑开宗，收徒若干" | 替于建补名（第一次给活人写） | 于建替他背错 |
| 紫云宫旧册 | "破宫，取宝" | 补被撕掉那一页的"事" | 姓氏来历被扣 |
| 幻波池空卷 | "圣姑遗府，空" | 验出焚卷令笔迹 | 忘掉自己恨谁 |
| 开府贺表 | "群仙毕至" | 不能补——贺表不认无名者 | 无（这是他第一次"写不了"） |
| 战功册 | "七矮除蚿" | 补随行杂役的事 | 最后一个信他的人失望 |

**关键**：他的能力**只对"文书"有效**，对"战局"无效。这就从根上保证了"一有二不随"——他永远改不了原著的结果，只能改"记录"。

## 四、卷二 · 青螺峪（**起**）

**卷功能**：他被退回，第一次主动选择"学抢"。这是四卷起承转合的"起"——他进入成人世界。

| 项 | 内容 |

| 一设锚点 | 凌浑开宗、收徒（F-38，第 188/211 回）；崔五姑"这等心术不该收"；凌浑"人各有心，不可勉强"；于建同批同收 |
| 一无（本卷补什么） | 遣返到收徒之间，他在青螺峪**靠什么活**；凌浑**为什么**收一个"心术不正"的人；于建**怎么**替他背了第一次错 |

| 二随·随因果 | 他这一卷不能变强到能打——他只会写字；凌浑不教他剑，只教他"看人" |

## 五、卷三 · 紫云宫（**承**）

**卷功能**：承接"学抢"，他第一次借外力（魔道）把事办成。这是"承"——势力扩张，代价累积。

| 项 | 内容 |
|---|---|

| 一无（本卷补什么） | 紫云宫破后，海底旧册被送回掌籍房，**谁抄**；旧册上被整页撕掉的是谁；他**怎么**第一次接触元命牌 |

| 二随·随因果 | 紫云宫的战果不能变：宝取了、宫破了。他只能在"旧册归档"这一环动手 |

## 六、卷四 · 幻波池（**转**）

|---|---|

| 二随·随因果 | 幻波池的探索结果不能变：他们进去了、拿到了该拿的。他只在"验卷"这一环 |

## 七、卷五 · 光明境·铜椰岛（**合**）

**卷功能**：收束。两边争他，他选"不选"，放弃最后一个信他的人。这是"合"——所有线收拢到结卷。

| 项 | 内容 |
|---|---|
| 一设锚点 | **峨眉开府**（F-38："同门皆有份，唯他一人无望赴会"）；**铜椰岛**（乙休大闹、天痴上人）；**光明境**（七矮除万载寒蚿）；**借阿但含婆之力、被朱文破坏、逃逸**（F-39） |
| 一无（本卷补什么） | 开府那天他在青螺峪**做了什么**；他怎么**搭上**阿但含婆；逃逸之后**去了哪**（原著断线） |
| 二随·随人物 | 七矮、乙休、朱文仍是原著样子；阿但含婆仍是魔道，以"干亲"拉人（F-39，B 级）；朱文仍会破坏他的事 |
| 二随·随制度 | 开府要"贺表"，各派都要署名；结卷前要"预演"报名册 |
| 二随·随因果 | 他借力失败、被朱文破坏、逃逸——这条不能改；开府他无份——这条不能改 |

**起承转合的内在逻辑**：
- 起（卷二）：他要"位置"，学会了抢。
- 承（卷三）：抢到了，发现抢来的位置要拿人垫。
- 转（卷四）：垫了人之后，发现自己本来就是"会垫人的人"。
- 合（卷五）：知道自己是那样的人之后，他选择"不选"——不选边，不借力，不认那个位置。这一步是"自我牺牲"的预演：他已经开始放弃"被承认"。

## 十一、给写手的一句话

写这四卷时，先翻原著找到那件大事，问三个问题：

1. **原著写了什么结果？**（不能改）
2. **这件事有没有"文书"环节？**（名录、战报、贺表、抚恤、归档——都有）
3. **杨成志在这环节里，能补哪一个"没被写下的名字"？**

答完这三问，一章的骨架就有了。
