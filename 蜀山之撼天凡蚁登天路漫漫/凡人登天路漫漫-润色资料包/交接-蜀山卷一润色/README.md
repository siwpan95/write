## 一、三条铁律（违反即返工）

1. **成稿不许出现全角括号「（」「）」**。原稿是一行一括号的草稿，润色必须化成正常段落。
2. **每章正文汉字 ≥ 3000**，口径为全文汉字（含章节标题），不含标点、空格。
3. **每段必须有新信息**：新的物、新的数、新的动作、新的规矩、新的因果。一段删掉后文意不减，就是注水。

字数不再是"看着有三千"，必须跑工具核对：

```bash
python3 tools/count.py draft/ch110.md
```

## 五、原文常见问题（处理方式）

润色不是照抄，原稿这四类问题必须修，并在交付回复里说明：

1. **同一段写两遍**（如第 62 章掰饼、第 63—64 章老周的喘与"走吧"）→ 合成一遍，保留一处最强的。
2. **时序冲突**（如第 64 章末老周已回灶下，第 65 章又站在门里看门关）→ 改前章收尾，让后章成立。
3. **数字对不上**（如"八个字"实为六字、伤亡数与崖上崖下分项）→ 按上下文改成能自洽的数。
4. **残留的作者工作笔记**（如"第53章她会说我担"）→ 删除或化成正文。

改动都要记在交付回复里，不要默默改。

## 六、八条教训（都是踩过的）

1. 不据已交章数推断全书规模或"整卷完成"；只报具体章号。
2. 不沿用原稿括号，那是草稿标记，不是文体。
3. 字数按汉字算，不按"含标点字数"虚报。
4. 不靠短句换行凑密度；短句是刀，刀下面得有东西垫着。
5. 不为凑整数字反复微调；宁可按内容写足，也不要注水。
6. 知识库文件名固定格式，不做整卷合并版。
7. 上传后如出现同名副本，主动提醒作者删旧的那份。
8. 单轮输出有上限：写不完五章就如实交两章并说明，绝不用残稿充数。
