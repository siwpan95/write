我在做网文《凡人登天路漫漫》（蜀山卷一）的逐章润色，已交到第 109 章，卷一全长 125 章。
交接包在 `/sandbox/workspace/交接-蜀山卷一润色/`，先读 `README.md`、`02-写作标准.md`、`03-设定与伏笔.md`、`04-进度与文件清单.md`，再读 `samples/第108章-一页.md` 和 `samples/第109章-记住.md` 两章样板。

规矩只有三条：
1. 成稿不许有全角括号「（」「）」；原稿是一行一括号的草稿，要化成正常段落。
2. 每章正文汉字不少于 3000，用 `tools/count.py` 核。
3. 每段必须有新信息，不够字数从"工序、账目、履历、规矩与例外"四处取，不许注水。

接着写第 110—114 章，然后交付：
```bash
cd /sandbox/workspace/交接-蜀山卷一润色
python3 tools/extract.py 110          # 取素材（111、112…依次）
# 写稿到 /sandbox/workspace/draft/ch110.md … ch114.md
python3 tools/count.py /sandbox/workspace/draft/ch110.md /sandbox/workspace/draft/ch111.md /sandbox/workspace/draft/ch112.md /sandbox/workspace/draft/ch113.md /sandbox/workspace/draft/ch114.md
python3 tools/build.py --start 110 --end 114 --upload
```

交付回复里给我：字数表、这一批补了哪些实内容、改了原稿哪些问题（重复段落/时序冲突/数字对不上）、已交到第几章、还剩哪几章。不要推断整卷进度，不要说"卷一完成"。单轮写不完五章就如实说写了几章。
