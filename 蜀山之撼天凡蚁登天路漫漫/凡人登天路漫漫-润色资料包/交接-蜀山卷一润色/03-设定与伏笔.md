# 设定与伏笔（一致性核对用）

## 一、人物卡

### 主角
**杨成志**（小杨），十七岁。路径：崖上外门"暂收"→ 掌籍房代笔 → 妄动灵符、阵乱三日、伤亡二十六 → 遣返原籍 → 崖下驿舍等七天 → 茶棚学"抢" → 青螺峪山脚站一天 → 杂役 → 记名弟子 → 客录上自写一行"杨成志，记事，自记"。
手上有墨、掌侧一道碎砚割的痂；笔是黄杨木杆、没漆、握处一道凹。

### 崖上
- **白朴**：掌籍，三十年盖同一个印，手稳如器。只在"字缝里让一步"（"架上是公物，桌上不是"）；不收谢（"不受，就不欠"）。鼻尖常沾墨，没人敢说。说过"你还回来""此人可用"。
- **齐灵云**：大师姊，代掌教。全程只在小窗后说了两个字："我担。"——不是替他担，是替自己那句没开口的话担。
- **老周**：灶下火工，无名字（杂籍只记"火工，一名"）。二十岁被遣下山，走回崖门，要了一碗热水，留下烧火四十年。给饼说六个字："凉了，就不算数。"
- **于建**：救过主角，替他按过保。病三月，没来送。
- **章南姑**：孩子病，没来送，托人带话"等娃好了给小杨做双鞋"。
- **霍师兄**：记名弟子三十年，不进内门不出山门，劈柴为生。讲旧事的人。
- **老陈**：灶下，一只眼白，火三十年不熄，压灰拍三下。给他起名"小杨"。
- **张有**（挑水，右肩低）、**吴三**（劈柴，左眼白翳，有黄狗一条）、**哑巴**（灶下，手势多）、**陈婆**（扫院）、**小六**（跑腿）。
- **孙执事**：管账房、柴、米、人进出。十二年没说过一个"好"字。

### 青螺峪
- **凌浑**：开派祖师（"凌真人"）。赤脚、旧青袍破处不补、一根树枝串半个馒头（一天只吃半个，省下给山门外的一个人）。坐三块石头（中间那块坐了三十年，另两块空着）。当年是四个人里吃半个馒头留下的那个。只教字，不教剑："剑是杀人的，字是记人的。"
- **崔五姑**：客，深青褙子带云纹，脚上黑布鞋自己纳的。住三年不入门。提醒过他"你站直"，也质疑过凌浑"你不管"。
- **陆三**：五台派，高筒靴、靴底横竖纹中一方孔。看锁、看水、看灶。说过"我认得你的字""下次带人"。
- **李**：倒泔水的，内八字，每天出后墙一次，在墙根土上划记号（圈里一道横）；后墙外坡下石头上刻着同样的记号。

## 二、术语与形制（不可改）

| 项 | 设定 |
|---|---|
| 册分三等 | 仙籍（记名、记事、记功）／道籍（记名、记职）／杂籍（记数，不记名） |
| 三个印 | 戒律房：方，一寸二分，角是圆的；谱房：方，八分；掌籍房：长，二寸四分（盖下去像一条横线，把人划掉） |
| 划掉 ≠ 撕掉 | 划掉是挪到《出崖录》，人还在册上，只是不在这一页 |
| 罚册 | 三寸厚，蓝皮，内有黑页（整页涂黑，不许看）；记"怎么没的" |
| 罚目 | 三本，九百页，三十六万字；格式五栏：年、月、事、罚、人 |
| 入册录 | 记"入"；架上本二十四行，土墙夹层本二十六行（差两行：陈小满、周阿六） |
| 二十六 | 阵乱伤亡之数（崖上七 + 崖下十九），全书三次出现同一数字 |
| 七块碎砚 | 砚碎成七块，对应崖上死的七个人；最小的一块给了驿舍老头压碗 |

## 三、时间线（已写到 109 章）

出崖（第60章）→ 驿舍七天（61—68）→ 茶棚（69—75）→ 青螺峪（76—80）→ 抄开宗录（81—85）→ 见凌浑、压笔、记名（86—90）→ 站山门（91—94）→ 火与赶走（95—99）→ 自写一行（100）→ 回崖送册（101—105）→ 看自己那一页、抄罚目、私记（106—109）。

季节：出崖在正月前后，青螺峪一路雪，火在冬，"开春之前"收束；回崖时四月的风还在（101章）。

## 四、正在生效的伏笔（110 章以后要用）

1. **册房少四本**：罚册、旧罚册（最下层灰布下的窄印）、两本旧册。
2. **一团涂墨**：七人同遣那一页，涂的是"下落"一栏；墨边是硬的，是笔涂的。
3. **陈某**：十七岁，三年前上崖，无"殁"记，无"调"记；年纪与驿舍老头所说（十三岁）差四岁。
4. **七人同遣**：冯、吴、罗、杨、周、许、陈；六人事由无。
5. **后山采石**：一人换四斗粮。
6. **内应**：李的记号（圈横）；后墙外的石头；"下次带人"。
7. **白朴的承诺**："你还回来"；"此人可用"条子已在主角怀里，掌门下山，一个月后回。
8. **齐灵云的"我担"**：尚未回收。
9. **老周的六个字**：尚未回收（主角后来理解了"热"的另一半）。
10. **空着的一格**：他答应过"写不出，就先空着"——将来要填。
11. **字迹即名字**：陆三认得他的字；他已在客录上署名"值日杨"。

## 五、禁令（不许碰）

- 不改册的三等、三印形制、二十六、七块碎砚这些硬设定。
- 不给体系加超自然解释：全书的力量都落在"规矩、账、字、人心"上。
- 不让主角开挂：他的能力只有三样——抄得快、记得牢、看得懂规矩。
- 不写现代词（"系统""数据""情绪价值"等一律不许）。
- 不改老周"没有名字"、白朴"不收谢"、凌浑"半个馒头"这些已经成立的核心意象。

## 六、人物称呼速查

- 崖上叫职名：掌籍、执事、师兄、师姊；不叫名字。
- 青螺峪叫"师父""师兄"；凌浑称"真人"（敬称，不直呼其名）。
- 杂役无名字，叫"火工""挑水的""倒泔水的"；主角被叫"小杨"。
- 册上写法：名字 + 岁 + 籍 + 入 + 殁/遣。遣返不写"罪"，写"妄动灵符，阵乱三日，伤亡二十六；遣，原籍"。
