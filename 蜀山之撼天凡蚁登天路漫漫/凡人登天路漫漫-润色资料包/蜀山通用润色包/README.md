# 蜀山通用润色包

一套用于**长篇冷叙事小说逐章润色**的工作包。原为《凡人登天路漫漫》（蜀山卷一至卷二）定制，现改造为通用版：换书只改 `config.json`，代码不动。

核心是三条铁律、一套五步流程、一组可跑的检查工具，以及一份把"感觉"拆成"动作"的技法库。

```
三条铁律
  1. 零全角括号，恢复自然段落
  2. 每章正文汉字 ≥ 3000（全文汉字，含标题），不许靠标点凑
  3. 密度优先：每一段必须有新信息（新物、新数、新动作、新规矩、新因果）
```

---

## 一、这个包解决什么问题

原稿常见的四种病，这个包各有对应的解法：

| 病 | 症状 | 解法 | 用到的工具/文档 |
|---|---|---|---|
| 括号病 | 一行一括号，靠括号和标点充字数，实际汉字不足 | 括号三落地（并入前句／独立成段／化为动作） | `docs/01` 第三节；`count.py` |
| 稀 | 字数够了，但一段没有新东西 | 四来源扩写（工序、账目、履历、规矩与例外） | `docs/01` 第四节 |
| 油 | 形容词多、抒情多、判断多 | 冰山六律 + 静物载情 + 减法 | `docs/02` |
| 乱 | 数字前后不一、时序打架、伏笔失收 | 一致性基准表 + 伏笔登记表 | `templates/` |

## 二、五步流程（每一批都走一遍）

**第 0 步 · 定位**
```bash
python3 tools/extract.py 126          # 抽一章素材（去括号、并段）
python3 tools/extract.py --scan       # 看全目录：章号、标题、所在文件与行号
```

**第 1 步 · 拆**
读完素材，先在纸上（或脑子里）回答四个问题。答不出就别动笔：
1. 这一章**发生了什么事**？（一句，不许用形容词）
2. 这件事的**工序**是什么？（谁、用什么、几步、多少钱、多少天）
3. 这一章的**账**是什么？（人数、页数、字数、米数、工钱、时辰）
4. 这一章**立了什么规矩**，规矩的**例外**是什么？

**第 2 步 · 写**
按 `docs/01` 的扩写路径写。目标 3000—3300 汉字，写到 3000 就停，不要为凑数加句子。
一章一个文件：`draft/ch126.md`，首行 `第126章 标题`。

**第 3 步 · 检**
```bash
python3 tools/count.py draft/ch126.md     # 硬指标：字数、括号、引号、半角标点
python3 tools/kit.py   draft/ch126.md     # 体检：密度、重复、注水、节奏
```
`count.py` 不过不许交；`kit.py` 出的建议逐条看，能改的改。

**第 4 步 · 出件**
```bash
python3 tools/build.py --start 126 --end 127 --upload
```
生成 `<书名>-第126至127章-润色稿.md/.txt/.docx`，docx 自动上传知识库（`config.json` 的 `kb_id`）。

**第 5 步 · 报**
按 `templates/批次交付说明模板.md` 写交付说明：字数表、本章补了什么实内容、原文缺陷如何处理、进度到哪一章。

## 四、命令速查

```bash
# 素材
python3 tools/extract.py 126 --raw          # 保留原稿括号形态，看它坏在哪
python3 tools/extract.py 126 --limit 2000   # 只看前 2000 字

# 校验
python3 tools/count.py draft/                       # 整目录
python3 tools/count.py draft/ch126.md --min 3200    # 临时提高下限
python3 tools/count.py draft/ch126.md --json        # 给脚本用

# 体检
python3 tools/kit.py draft/ch126.md --top 12

# 出件
python3 tools/build.py --start 126 --end 128 --upload
python3 tools/build.py --start 130 --end 130 --upload --single

# 自检
bash tools/selftest.sh
```

## 五、换一本书怎么用

1. 改 `config.json`：`book`（书名）、`kb_id`（知识库）、`src_dir`（原稿目录）、`min_han`。
2. 原稿放进 `src_dir`，章标题用 `# 第 N 章 标题` 或 `第N章 标题`。
3. 草稿放 `draft_dir`，命名 `ch<章号>.md`。
4. 跑 `bash tools/selftest.sh`，四项全绿再开工。
5. 把 `templates/新对话启动提示词.md` 里的占位符填掉，作为下一次对话的第一句。

## 六、四条不能破的线

1. **不靠标点凑字数**。字数只认汉字；`count.py` 的 `--min` 不是目标，是底线。
2. **不替作者抒情**。该有情绪的地方找物件，写人物对物件的动作。
3. **不改作者的判断**。只补可查的事实（工序、账目、履历、规矩），不动人物的对错。
4. **不回炉既成事实**。作者明确说过不回改的批次，不重做；发现错误记进 `samples/` 与本包教训清单，往后不犯。

## 七、这套东西的来源

- 工程经验：蜀山卷一 1—125 章、卷二 126—135 章的逐章润色（31 + 6 个交付批次）。
- 方法论调研：小说修订三轮法（结构／人物／语言）、海明威冰山六律、契诃夫细节载情、以景结情、GB/T 15834—2011 标点国标。详见 `docs/04`，来源链接一并列出。

方法与来源分开写，是为了将来能反驳自己：有出处的部分是调研，没出处的部分是本包的经验，别混。
