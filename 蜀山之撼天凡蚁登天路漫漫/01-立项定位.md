## 0. 一句话故事（L1）⚑

**公式 A（要素式）**

- 主角：一个被峨眉"暂收"又"退回"的少年（原著杨成志，十六岁）
- 背景：凝碧崖开府在即，正邪都在等第三次斗剑；这世界只认册上有名的人
- 核心冲突：他要抢一个不用别人批准的位置，可抢来的位置要拿信他的人垫
- 金手指 / 筹码 / 可依赖之物：**阙文**（看见未被写下的空白）＋**补笔**（把已发生却无人记下的事写出来）；代价是交出"一种可能"，且每用一次更像"佚卷里那一版的他"
- 结局 / 抉择：第三次斗剑即"结卷"，他写所有人、不写自己；但他害过的人不复活

**公式 B（因果式）**

> 杨成志想要一个不用别人批准的位置，因为他被"退回"过一次、册上从没有他那一格，但这世界的名分只认册子，于是他学会抢，最终发现：抢来的位置，垫的都是信他的人。

**公式 C（卖点式）**

> 反英雄成长 + "文本即世界"的仙侠世界观 + 被退回者的不甘，主打"以名分赌命、以人垫脚"的智斗爽点。

### 0.1 广告词（≤30 字）与赌注问句

> **这世上的人都活在册子上。只有他，不在册。**（21 字，无专名）

| 约束 | 本件核对 |
|---|---|
| 长度 | 21 字 ≤ 30 ✅ |
| 不提专名 | 无人名、地名、体系名 ✅ |
| 大背景 × 小背景 | "人都活在册子上"（世界级规则）× "只有他不在册"（这一个人连被退回都没被记） ✅ |
| 赌注问句·谁失去最多 | 杨成志：他已经没什么可失去，所以他会去抢——真正会被失去的是**信他的人** |
| 赌注问句·他想要什么 | 册上有一行自己的名字，且不是别人"暂"给的 |

**永久性检验**：六卷皆围绕"抢位置—拿人垫—写别人"，该句到卷六仍成立。

### 一句话故事验收门（三条全中要过）⚑

- [x] **可复述**：讲给一个人听，他能复述"一个被退回来的少年，要一个不用别人批准的位置，可这名分只认册子"。
- [x] **有爽点引擎／期待锚点**：**逆袭**（无名者抢位置）＋**揭秘**（册子为什么只认写下的）。反英雄线本身是钩子：读者想知道他会坏到哪一步。
- [x] **有终极抉择**：写所有人（自己消失、恶不撤销）vs 不写（活着，但所有人困在未完成）——两难。

## 3. 精神内核

- **一句话主题**：一个人可以自己定什么算数——但定了，就得认那笔账。
- **核心命题**（两难）：当所有规矩都经不起你一句"凭什么"，你是重定规矩，还是掀桌子？
- **情感底色**：`被退回的屈辱 vs 自己给自己作证的孤独`
- **价值观表达**（书封句）：**"位置可以换人，人做过的事换不掉。"**
- **性格落点**（v3）：趋利避害是活法，纯真是底线，守本心是选择——"虽千万人吾往矣"不是不怕，是怕也去。
- **尼采的正确用法**（v4）：超人是**价值的创造者**，不是破坏者——他不要别人给的规矩，但自己定的规矩更严（第一条：不害信我的人）。金句：**"他们给我规矩，我不要。我自己定一条——定得比他们的还狠。"**
- **结局弧**（v5 · 裁决表 §十五）：**复仇者 → 守护者 → 自我牺牲**（参照塔里昂的弧光结构，不取设定）。悲壮、有史诗感、不团圆；从册上消失，但在人嘴里活着——是解放，不是虚无。
- **双轨制**（v4 · 裁决表 §十四）：性格轨全书不变（守本心、纯真、不辩、不谢、认账）；手段轨逐卷变狠（偷墨→借势→批注→对笔→写人入局→"不救"→写所有人）。**手段可以狠，性格不许坏。**

## 4. 对标与差异化

| 对标作品 | 学它什么 | 不学它什么 | 本书如何差异化 |
|---|---|---|---|
| 《诛仙》 | 古典仙侠的身世悬念与情感浓度；单元—主线交替 | 不学中后期主线松散 | 把"身世悬念"换成"文本身世"：他不是谁的儿子，他是"被写过两遍的人" |
| 《凡人修仙传》 | 资源—风险—收益闭环；主角"算得清"的行为逻辑 | 不学境界阶梯（本书无，F-35） | 用"名分"替代境界作硬通货；主角不是稳健，是**敢拿人垫** |
| 《诡秘之主》 | 规则可推演、组织有官僚层、能力必带代价与污染 | 不学西式克苏鲁外壳与翻译腔 | 把"序列/教会"换成"谱牒/谱房"，把"扮演法"换成"补笔—批注—对笔" |

> **反英雄方法论**（非对标作品，写作参照）：每一步都要有理由，但每一步都更坏；不给"其实他是好人"的翻案，也不给"他终于被原谅"的结算。参照美剧《绝命毒师》的堕落曲线——观众理解他，但不必喜欢他。

## 5. 红线与自律条款

| 类型 | 本书红线 |
|---|---|
| 力量／规则红线（最高约束） | ① 五律 R1–R5 不得违背（裁决表 §四）；② 每次补笔必须当章交代代价，未交代即破律；③ **不黑化**：芝仙之祸是他自己动的灵符（F-37），狠事不撤销、死者不复活，但他**不变坏**（性格轨不变）；④ 不新增第六律、不设境界链 |
| 手段红线（v4 · 合规线） | **L1 不设局害信任他的人**（可以"不救"，不可献祭）；**L2 不虐杀、不以痛苦取乐**（杀伐果断可写，折磨过程不写）；**L3 不对无辜路人下手**（挡路的必须是恶人/对手/制度）；**第四律：每件狠事后面必须有一次"认"**（不辩解、不推给环境） |
| 情感红线（不写什么） | 不写"爱情救赎恶人"；不写被他害的人临终原谅他；不用失忆当虐点（"不被记住"是规则后果，不是失忆梗） |
| 设定红线（不新增什么体系） | 不新增第三套写定工具；原著人物定性不改（齐灵云老成持重、李英琼刚烈、凌浑"人各有心"）；不借用影视改编独创设定 |
| 节奏红线（虐点最多几章、不水几章） | 虐点连续 ≤2 章；"批注/对笔"辩论戏每卷 ≤2 场；连续 3 章不得无一次"名分变化" |
| 结局红线（不烂尾、不机械降神） | 不由长眉、东海三仙、白眉和尚出手解决；结卷必须由他自己那一笔完成；不写"梦一场/其实都是书"；不给他一个"被原谅"的结算；**落点回归原著**：斗剑按原著方向了断，他的牺牲让主线得以发生，不取代主线（裁决表 §十五） |
