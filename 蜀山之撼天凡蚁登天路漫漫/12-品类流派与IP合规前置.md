### 1.1.1 各平台结构差异（只写结构类型，不写死会变的分类名）

> 平台分类**名字**会变，**切分维度**不会。本表只记"按几个维度切"。确认度：`✅` 已核实／`◐` 结构判断成立但未逐项核验分类名；**投稿前一律以站内当前导航为准**。

| 平台 | 切分维度 | 两级怎么填 | 易错点 | 确认度 |
|---|---|---|---|---|
| **起点** | **频道 → 分类 → 标签**（三级） | 一级填频道"仙侠"，二级填"古典仙侠"，三级挂 5 个标签 | 把二级分类当一级入口申报；用旧记忆报已拆分的入口 | ✅（本书实投平台，2026-11-15 核） |

### 1.2.1 风险档（v3 新增，v5 补第二档）：读者心理层与题材可连载性

> §2.2 逐词表只覆盖**权利层**风险；本节登记两类**表外风险**：**档一＝读者预期错位（判 `留存`）**，**档二＝黑暗流合规（判 `硬伤`）**。两档共用 §2.2 三档口径（`硬伤`／`留存`／`无需处理`），但判级理由不同：档一影响"读不读下去"，档二影响"**能不能连载完**"。

**档一：轻小说读者预期 vs 仙侠冷底色（判 `留存`）**

| 项 | 内容 |
|---|---|
| **风险** | 书名是轻小说式长名（裁决表 §一 D6）＋风格标签挂"轻小说／电波系"，会把按**"废柴逆袭／沙雕日常"**预期进场的读者吸进来；而本书前 500 字是跪在崖前、册上念到最后没有他、没人看得见他——预期落差直接体现在首章跳出率与"以为是搞笑文"的差评上 |
| **不是缺陷** | 错位可转为反讽（裁决表 §十"不是缺陷"行）：他确实登了天，代价是把自己写成另一个人。轻小说读者能留下，靠的是**反讽**，不是"好笑" |
| **处置（主动作，唯一）** | **简介首句给一个冷的具体物**：不写"且看少年如何撼动九天"，写"他跪在崖前，膝下那块破席磨穿了；名册念到最后，也没有他。"先立冷底色，再让标签负责拉人 |
| **二级处置** | ① 前 500 字不许抖机灵（`16 §1.4` 红线 6、`13 §1.3` 风险 4 同一对策）；② 首章章题可长、可口语，但不许用问句堆笑点（裁决表 §十二 V4）；③ 详情页首屏不出现"逆袭""撼天"式承诺（§1.1 跨类策略⑤） |
| **验收** | 三章完读读者的留言中，出现"以为是搞笑文／以为是升级流"的比例 → 若超过 1/3，**改简介首句，不改文风**（文风是已拍板项，裁决表 §十二；简介是成本最低的可调项） |
| **档位与复核** | `留存`（可用但登记观察）；每卷末随 §1.1 平台复核一起复跑（`14` §四 复核记录） |

**档二：黑暗流合规风险（判 `硬伤`，不是 `留存`；v5 新增）**

| 项 | 内容 |
|---|---|
| **风险** | 本书是反英雄成长（裁决表 §一 类型行）：主角卷二拿老实人换机会、卷三把人写进死局、卷五放弃唯一还信他的人。若手段轨越界滑向"彻头彻尾的坏人"，读者的第一反应不是"这书真敢写"，而是"这作者在教人做坏事"——一旦进入这个读法，问题就从**阅读体验**变成**价值导向判定** |
| **为什么判 `硬伤` 而不是 `留存`** | `留存` 是"可用但观察"（读者喜不喜欢）；本项是"**能不能连载完**"（平台判不判）。两者的处置成本差一个量级：留存风险靠改简介、调节奏即可，硬伤风险意味着整卷回改甚至全书失去连载资格 |

| **正确的问法** | 不是"能不能写坏事"（能，反英雄的全部张力在这里），而是"**读者会不会认同坏人**"。所以本书管控的对象不是"坏事的数量"，而是"坏事之后的立场" |
| **处置（唯一主动作）** | **性格轨正向 ＋ 三条线 L1–L3 ＋ 第四律认账**（定义见裁决表 §十四；本件只引用）：① 性格轨全书不变——守本心、认账、不害信任他的人；② 手段轨可狠但不越三条线：L1 不设局害信任他的人（可以"不救"）、L2 不虐杀不以痛苦取乐（暴力按 `08 §4.1` 意象化）、L3 不对无辜路人下手；③ 每件狠事后必须有一次"认"，且**不许用旁白代替** |
| **复核（挂到哪）** | **每卷末跑 `11 §1.5` 三问**（最狠那件事是手段还是性格／有没有认／读者会不会觉得他其实是好人）；结论回写 `11 §2.1` 与 `06 §十一`。三问任一不过 → 回改该卷最狠那件事的**写法与后果**，不改人设（人设是锚，见裁决表 §三） |
| **档位与复核** | `硬伤`（须处置，不可"观察后放行"）；复核节拍＝每卷末，随 `11` 卷级体检一起跑 |

## 三、原文细读纪律（防"伏笔误判硬伤"）

### 3.1 三遍读法规程

本书的"原文"分两层，规程同一套三步：

1. **定位**：把该事实的**全部出处编号**列出（原著事实列 F 编号；正文列章次与段号）。例：判断"紫郢归谁"，须列 F-20（法宝谱系）＋X-03（污染源，反证）。
2. **互证**：≥2 个独立来源一致 → A 级；单一来源或来源间有异说 → B 级并标"存疑"；学界／读者推论 → C 级，不得写成原著事实。
3. **定性**：分级后**才**允许写进分册；判为污染（D）的，只作反面案例，不得作为任何分册的依据。
