# 篇幅白名单（合法超限）

> 用途：登记**经重复检测确认"无无效重复、内容饱满"**的超限章，`校验/验收_任意批次.py` 对这些章放宽上限。
> 生效方式：脚本启动时读本文件的表格（第一列章号、第二列实测字数），据此判定。
> **收录条件（三条同时成立）**：① 超过 3000 字；② 章内**完全重复段 0 组**（≥8 实质字的括号段）；③ 章内**近似重复段 0 对**（相似度 >0.82、间隔 <26 段）。

---

## 一、判定口径（2026-11-19 主控实测）

| 项 | 方法 |
|---|---|
| 完全重复 | 同章内 ≥8 实质字的括号段，去标点后完全相同的组数 |
| 近似重复 | 同章内间隔 <26 段的段对，用 `difflib.SequenceMatcher` 算相似度，>0.82 计一对 |
| 结论 | 两项均为 0 → **无无效重复**，超限是内容饱满，不压字数 |

> **为什么不硬压**：主控 2026-11-19 指令——"超限不要强压字数，如果确实存在无效重复，再进行治理"。
> 硬压会把有信息量的段落删掉，或逼出更啰嗦的改写；而**门禁的目的是防注水，不是防写长**。

## 三、移出白名单的条件

任一条成立即移出、并须把该章压回 2200–3000：

1. 后续修订引入了新的重复段（复跑检测，完全重复或近似重复 >0）；
2. 该章被重写（重写后按新稿重新检测，不复用旧结论）；
3. 卷二整体做体例治理时，按治理后的实测重算。

> **不许**因为"懒得查"而把某章塞进本表。**本表的每一行都必须有上面那两项检测的 0 结果。**
