## 四、本轮修订清单（3 处）

### 4-1 校验脚本误报规则（硬伤，已修）

**位置**：`校验/check_package.py` 第 99–104 行

**原规则**（全文字符串匹配）：
```python
if "第 178 章" in t or "第178章" in t:
    add("E", f"{rel} 残留失效章号 178（应为 726）")
```

**问题**：这条规则生成于 2026-11-15（校验报告时间戳），**早于卷二正文落稿（11-17）**。当时"第 178 章"是 v1→v2 迁移期针对单文件的临时规则，却被写成全仓匹配。结果把卷二**合法的第 178 章**（对应原著第 211 回）误判为失效章号，报 2 个 error。

**全量核验后确认**：本包正文章号体系为 **1–225 连续无缺号**（225 章）+ 卷六结局场 726/750，227 个章号全部落在合法域。第 178 章在 1–225 域内**完全合法**。

**已改为按章号域精确校验**：
```python
VALID_RANGES = [(1, 225), (726, 750)]
chap_re = re.compile(r"^# 第 (\d+) 章")
# 仅校验章节标题行，越界才报错；文档中的章节引用（如"第 178 章"）合法
```

**复跑结果**：
```
[i] 15-填法样例集：模板维护资料，按规范不分发（已登记）
[i] 17-字数增密与紫罗兰散文防控.md 含 1 处 ＿＿（引文占位，白名单）
[i] 扫描 Markdown：69 份；合计 2832 KB
[i] error = 0；warn = 1
[i] 结论：PASS：可分发
```

> **教训**：这类"迁移期临时规则固化成全仓断言"的坑，通用模板包的 `check_package.py` 里也有同款设计（防回归断言 36 条）。建议对**所有**形如"某字符串出现即报错"的规则，逐条问一句"它在规则制定时，那批文件存在吗？"——不存在就是误报源。

### 4-2 MANIFEST 整体失效（硬伤，已重建）

**位置**：`校验/MANIFEST.sha256`

**现象**：README §四 教人跑 `sha256sum -c 校验/MANIFEST.sha256` 自验，实测结果：

```
sha256sum: WARNING: 15 listed files could not be read
sha256sum: WARNING: 2 computed checksums did NOT match
sha256sum: WARNING: 1 line is improperly formatted
```

**逐条归因**（实测比对，非推测）：

| 问题 | 数量 | 根因 |
|---|---|---|
| 路径失效 | 15 条 | MANIFEST 记的是 `正文/卷一-第001-005章（C01-崖前）.md`，实际文件是 `正文/蜀山 卷一-第001-005章（C01-崖前）.md`——**正文加"蜀山 "前缀后，MANIFEST 从未同步** |
| 哈希过期 | 2 条 | `正文/进度表.md`（正文后来落稿）、`证据与裁决/00-蜀山证据包.md`（本轮修订前） |
| 未收录 | 28 个 | 全部是加前缀的正文 + `参考.txt` + 本轮新增报告 |

**结论**：MANIFEST 是在**正文加前缀之前**生成的，此后从未重建，等于**形同虚设**——README 教的这条自验命令一直在骗人。原先那句"1 line is improperly formatted"只是路径解析失败的表象。

**已重建**：按原收录口径（排除 `校验/` 整个目录——其中的 `校验报告.txt` 与本报告均为脚本/校验产物，每次变动，不应被哈希锁定；排除 `*.bak-*` 备份）重新生成 **70 条**（含 `参考.txt`——它此前未被收录，本轮补入）。

**复验结果**：
```

（全部 OK，FAILED 计数 = 0）

$ python3 校验/check_package.py
[i] 扫描 Markdown：69 份；合计 2836 KB
[i] error = 0；warn = 1
[i] 结论：PASS：可分发
```
原"improperly formatted"警告随之消失——格式统一后 sha256sum 不再误解析中文路径。

> 旧文件已备份为 `校验/MANIFEST.sha256.bak-20261118`，保留可追溯。

### 4-3 校验脚本追加「MANIFEST 覆盖率」自检项（防复发）

**起因**：MANIFEST 整体失效了两个月（11-15 生成 → 11-18 才被发现），而 `check_package.py` 里**没有任何一项检查 MANIFEST**——README §四 教的验证命令一直在骗人，脚本却报 PASS。

**已加（第 135 行起，编号 7）**：遍历 MANIFEST 与实际文件，三向比对——
- 实际有、MANIFEST 无 → E「MANIFEST 未收录：xxx」
- MANIFEST 有、实际无 → E「MANIFEST 条目无对应文件：xxx」
- 路径存在但哈希不符 → E「MANIFEST 哈希不符：xxx」
- MANIFEST 缺失 → E「缺少 校验/MANIFEST.sha256」

**自检自举**：加完后首次运行即抓出「MANIFEST 未收录：参考.txt」，据此补入，重建后复跑 PASS。**新检查项立刻证明自己能抓到真问题**，不是摆设。
