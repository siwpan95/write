## 一、先说环境测试结果（实测，不是推测）

我用 AutoCAD 自带的命令行内核试着直接跑转换，**两个入口都失败了**：

| 尝试 | 命令 | 结果 |
|---|---|---|
| Core Console | `accoreconsole.exe /i xxx.dxf /s save.scr` | 版本号能打印（`U.61.0.0`），随后卡在 `CoreHeartBeat` —— **许可校验心跳** |
| 主程序批处理 | `acad.exe /i xxx.dxf /b save.scr` | `Exception in SSOServerProcess::Start: 拒绝访问。` + `Failed to lock inter-process mutex` |

**结论**：AutoCAD 的许可服务在我当前沙箱里无法启动（权限被拒），**我驱动不了它**。
这不是 DXF 的问题，所以我换了做法——把该准备的东西都准备好，你那边一键执行。

## 三、三种用法（推荐第一种）

### ① 直接打开（最简单）

双击任意 `.dxf` 文件 → AutoCAD 自动关联打开 → `Ctrl+S` 另存为 `.dwg`。

5 个文件，手工也就两分钟。

### ② 一键批量转 DWG

同目录下已放好 **`批量转DWG.scr`**：

1. 打开 AutoCAD（任意空白图纸）
2. 命令行输入 `SCRIPT` 回车
3. 选择 `批量转DWG.scr`
4. 它会自动依次打开 5 个 DXF 并另存为 **2018 格式 DWG**，输出到 `dwg\` 子目录

> 脚本用 GBK 编码保存，中文路径不会乱码。

### ③ 只要看图

直接打开 `场景平面图.html`，浏览器里看 SVG 版本，不用开 CAD。

## 四、图层结构（在 AutoCAD 里可按层开关）

## 五、要改图怎么办

所有图都由 **`_gen_scenes.py`** 生成。改设定后重跑一次即可全部重出：

```bash
cd "C:/Users/13122/WorkBuddy/2026-09-20-07-08-27/output/综网废柴逆命/场景图"
/Python314/python.exe _gen_scenes.py
```

脚本里几个可调参数：

| 参数 | 作用 |
|---|---|
| `self.k` | 几何尺度系数（按图幅自动算） |
| `self.kt` | 文字尺度系数（带 0.52~2.2 上下限，防小图字过小） |
| `self.m` | 图框边距（随图幅 1600~5000） |
| `LAYERS` | 图层表（名字 + ACI 颜色号） |

脚本零第三方依赖（纯标准库），DXF 是手写的 R12 ASCII——**不需要装任何 CAD 库**。
