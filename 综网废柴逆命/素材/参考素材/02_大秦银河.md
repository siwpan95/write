## 七、方术炼丹与基因改造

> 道教炼丹术，分**外丹、内丹**。大秦银河因之：**外丹为基因改造之药，内丹为基因改造之炼。**
> 基因改造归墨家火星监管，然**其术根于方士炼丹**。

### 7.1 外丹：丹药三品

| 品级 | 炼制 | 服者 |
|---|---|---|
| **金丹**（九转） | 以星炬主源余热为炉，以皇帝长生药稀释液为引，以仙渊三仙山灵药为料 | 皇帝（半化星炬）、徐福（半金属化）、公族柱国 |
| **银丹**（七转） | 星郡星炬灯塔余热为炉，少府工坊为器，灵能兵器残片为料 | 军功甲士、十二金人金甲 |
| **铜丹**（三转） | 郡县工坊为炉，方士禁术为引，草药金石为料 | 郡兵、边军 |

**炼丹九转**：选料 → 研磨 → 入炉 → 化气 → 凝液 → 结丹 → 注灵 → 淬炼 → 成丹。

**服药之礼**：斋戒七日 → 沐浴更衣 → 入骊山金宫侧殿 → 以皇帝玺印额、星炬密钥启目 → 服丹 → 星炬光淬体、反亚空间符文镇灵 → **七日不出、七日不食、七日不眠**。
**服丹不成者**：化为灵能灰烬 / 堕为亚空间异端 / 疯或死 → **坑于骊山刑场，十二金人监刑**。

### 7.2 内丹：三关九转

| 三关 | 内容 |
|---|---|
| 炼精化气 | 以身为炉，以星炬光为火，以灵能为药——基因**初**改 |
| 炼气化神 | 以气为药，以灵能为炉——基因**中**改，灵能抗性中增 |
| **炼神还虚** | 以神为药，以星炬主源为炉——基因**全**改；**只公族柱国、十二金人金甲可得** |

**内丹九转**：调息 → 辟谷 → 胎息 → 导引 → 存思 → **内视（内视基因）** → 注灵 → 淬炼 → 还虚
