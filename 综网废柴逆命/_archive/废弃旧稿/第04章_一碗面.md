# 第04章 一碗面

> **本章概要**：陆沉用剩余的进入次数，在净场里做了两组对照实验——一次「无伤的失败」拿 1 点，一次「受伤的失败」拿 3 点，由此反推出逆命值的结算规律与上限公式。他同时得出一个让他平静得可怕的结论：要凑够 10 点，他需要一场「队友伤亡」级别的失败，而他不打算让任何人替他承担。走出副本楼，他当众用概率算死了正在炫耀首通成绩的裴战，把「废柴」这个帽子第一次反过来扣在了天才头上。
> **本章爽点**：双重爽感叠加——**智性爽**（用两次实验反推出金手指的底层公式，并同时推出上限与代价系数）+ **口头打脸**（用概率把天才的三分钟首通拆成「运气 + 面板兜底」，全场安静）。
> **情绪曲线**：冷静（实验设计）→ 上浮（公式推演成功）→ 微沉（发现自己需要「队友伤亡」级失败）→ 陡起（当众算死裴战）→ 钩子（老周拦住他，问出那行小字）

---

第二天早上七点，练习副本的两次进入权限刷新。

陆沉站在那栋灰色矮楼门口，等到闸门升起，走了进去，没有看一眼旁边。

他今天要做的事很简单：**做对照实验。**

昨晚躺在床上，他把昨天那一场从头到尾过了一遍，发现自己漏了一步。

昨天第十八次重置之后，面板上确实浮出来了东西——那两行小字，他记住了。可字后面跟着的数字，他没看。

当时他站在那片灰里，脑子里只有一句话：“该账号不适用常规评估。”

他把后面那一行漏掉了。

所以他今天必须补上——**那个东西，到底给多少。**

**第一组：无伤的失败。**

他走进净场，没有等灰犬出来。他蹲下身，从灰地板的边缘抠起一块碎石，握在手里，掂了掂，然后朝雾里扔了出去。

石头飞出去，落在灰白的地面上，滚了两下，停了。

面板弹出来。

```
【投掷检定 · 目标值 6（容易难度）】
掷骰：2d6 = 7
修正：−5
结果：2
判定：失败
```

“……”

陆沉记下：**容易难度，目标值 6，结果 2，低于目标值 4 点。**

失败，但不是大失败。

面板没有任何额外的东西浮出来。

他等了三秒，确认了什么都没有。

**结论：普通失败不计入结算。**

他需要的是**大失败**。

这时候灰犬从雾里走出来了。

陆沉没有转身跑。他往后退了半步，捡起第二块石头，抬手，对准那条没有眼睛的狗，用尽力气砸过去。

```
【力量检定（投掷攻击）· 目标值 10】
掷骰：2d6 = 9
修正：−5
结果：4
判定：大失败
```

石头从他手里飞出去的时候，他的手腕偏了，脱手，石头砸在自己脚尖前面不到半米的地方，弹起来打在小腿上。

灰犬被这动静吸引，转过头，但没有冲过来。

**它没打他。**

陆沉低头看着自己的小腿。

皮都没破。

视野底部，那行小字浮出来了。

```
【逆命值 +1】
```

再下面一行，是一个带斜杠的数字。

```
【逆命值：4 / 10】
```

陆沉看着那个 4。

昨天到今天，他只触发过一次结算——就是昨天第十八次重置那一下。

**四减一，等于三。**

**昨天那一次，值三点。**

**一点。**

**无伤的大失败，值一点。**

他站在灰色的空地上，慢慢直起身。

心跳很稳。

**第二组：受伤的失败。**

这一组，昨天已经无意间做过一次了。

按刚才那块面板上的 4 反推，昨天那一下是三点。

他现在要确认的是——**今天再来一次，是不是还是三点。**

他要把这件事从“偶然”变成“规律”。

他把手里剩下的一小块石头扔掉，敞开双手，往雾里走了三步，站在灰犬正面。

灰犬没有立刻动。

它站着，那两片没有眼睛的皮肤对着他，像在读他。

陆沉没有动。

三点二秒之后，灰犬动了。

左前腿落地。

它撞上来。

胸口一沉，脚离地，身体在空中翻过去，后背砸在灰色的硬地面上。这一次他清楚地感觉到右边锁骨下面有什么东西断了——那是游戏世界给他的伤害反馈，痛感是真的，只是不会被带走。

生命值归零。

重置。

他站在入口，摸了一下锁骨。完好。

面板亮起。

```
【逆命值 +3】
【逆命值：7 / 10】
```

“……”

陆沉把两个数字并排放进脑子里。

**无伤，+1。**

**受伤，+3。**

昨天那一次，同样是受伤，同样是三点。

**这个结算，是稳定的。**

他没有再做第四组测试。不是为了省次数，而是因为他已经看到了那个模式。

**结算的多少，跟“他输得有多惨”成正比。**

不是随机的。

不是运气。

是**代价系数**。

把这两组数据都拿到之后，他把视线落回面板最底下。

那行数字的格式和前面都不一样，是带斜杠的。

```
【逆命值：7 / 10】
```

陆沉盯着那个「10」看了很久。

他还不知道逆命值能拿来做什么。

但他知道这个「10」是什么意思。

**上限。**

他昨天职业等级 1 级。今天还是 1 级。上限是 10。

如果上限跟等级挂钩——而综网里的一切上限几乎都跟等级挂钩——那么公式就是：

**上限 ＝ 10 × 职业等级。**

他站在净场的入口，周围是一片完全没有边界的灰。

他很安静地，把接下来要做的事排了一个序。

第一，他需要**10 点**。

第二，他现在的拿法是：无伤 1 点，受伤 3 点。

第三，他手上是 7 点——昨天一次重伤 3 点，今天无伤 1 点、重伤 3 点。按这个价目，他还差一次重伤，就能凑够 10 点。

第四——

他停在这里。

第四件事，是他在心里推出来的**最大水平的那次结算**。

昨天那两行字里有一句：“该账号不适用常规评估。”

既然系统给他的结算是按“代价”来的，那么代价最大的一档是什么？

**不是自己受伤。**

**是队友伤亡。**

综网副本的类型里有战斗、有追猎、有守卫——有太多太多种可能，让人死在别人面前。

**如果身边有人死了，他大概能拿到 10 点。一次就够了。**

陆沉看着那片灰，很轻地吐出一口气。

他把这个选项在心里放了一下，然后放到了最后一个位置。

不是不想。

是**不用**。

他不知道自己为什么这么笃定。

也许是因为父亲留下那句话的方式——先算概率，再赌性命。父亲的意思是：**概率算完了，性命还是得自己赌。**

他赌自己。

不赌别人。

他抬起手，在面板上一按。

```
【已退出练习副本·净场】
【本次结算：探索度 0 / 击杀数 0 / 任务进度 0】
【获得经验值：0】
```

零。

一无所获。

他走出那栋灰色的矮楼。

外面的阳光有点刺，他抬手挡了一下眼睛。

然后他听见有人在笑。

---

楼门口的花坛边站着七八个人，围着一个中心。

中心那个人，陆沉认识。

裴战。

就是他昨天在前面上过评定台的那位——属性总和 62，甲等。

他今天换了件深色的新外套，头发往后梳了一点，正被一圈人围着说话，声音不大，但那种不大，是**故意让周围所有人都能听见的不大**。

“……三分钟。”他说，“净场那只怪是 F 级的，官方标的最弱单位。我进去三分钟，一个人清掉的。”

“三分钟？那么快？”

“快吗？”裴战笑了笑，“还行吧，主要是我力量 14，修正是加二。打它不太费劲。”

“那也太猛了。我听说有人进去被追着打了半个多小时才出来。”

“那是属性不够，”裴战说，“面板不够的人，你进去就是给那只怪练手的。”

围着的几个人都笑了。

陆沉从他们旁边走过去。

他没有停。

但裴战看见他了。

“欸。”

裴战叫住他。

“你就是那个 417 吧？昨天六维全一那个。”

那圈人全部转过头来。

陆沉停下来，回头看他。

“有事？”

“没事，”裴战笑了一下，抱着胳膊，“就是有点好奇，你昨天不是也进副本了吗？净场，我看见你往那边走的。”

“去了。”

“清掉了吗？”

“没有。”

“那被追了几次？”

“十八次。”

有人笑出来了。

裴战也笑，笑完摇了摇头，一副很宽容的样子：“我说句实话你别介意——你这种面板，进去就是浪费配额。你一天两次机会，攒着不好吗?你现在连最弱的怪都打不过，你拿什么在九十天里到五级？”

陆沉看着他。

他的表情一直很平。

然后他开口了。

“你敏捷多少。”

“啊？”裴战愣了一下，“十二啊，怎么了。”

“十二，修正值是加一。”陆沉说，“净场那只灰犬，先攻速度是固定的，十二。你掷先攻要和它比，得掷出十一以上才能抢在它前面动。两枚六面骰掷出十一以上的概率，是三十六分之三。”

花坛边那圈人安静了一点。

“你今天抢到了先手。”陆沉说，“祝贺你。”

裴战脸上的笑还没掉，但眼神已经滞了一下。

“这跟你有什么关系——”

“没什么关系。”陆沉说，“我只是提醒你一句，下一次你有十二分之十一的概率抢不到。”

风从花坛那边吹过来。

裴战把胳膊放下来了。

“你一个六维全一的，跑过来跟我讲概率？”

“对。”陆沉说，“正因为我是六维全一的，我才必须把概率算准。**你的运气可以浪费，我的不能。**”

他顿了一下，又补了一句。

“还有。”

“还有什么？”

“你说你三分钟清掉了它。”陆沉说，“你的力量 14，修正是加二。要打中那只灰犬，你得掷出八以上，概率是三十六分之十五。三分钟里你能出手大概四十次，命中十七次左右。”

“十七次。”

“你花十七次，打死了一只综网官方标注的 F 级单位。”

他顿了顿。

“这不叫猛。”

“这叫**面板替你兜底**。”

花坛边，一点声音都没有了。

裴战的脸从白到红，又从红到白。

他往前走了一步，张了张嘴，还没想出话。

陆沉已经转过身了。

“祝你下一个副本好运。”他背对着他们说，“真的。运气也是数值的一部分。”

他走远了。

身后过了很久，才重新响起一点说话声，但那些声音，已经不像刚才那么响亮了。

---

晚上，陆沉回家熬了一锅粥。

粥在锅里咕嘟，他把咸菜切好，摆在一个小碟里。陆谣坐在桌前写作业，写一会儿抬头看他一眼。

“哥。”

“嗯。”

“今天公告榜更新了。”

“嗯。”

“上面……有你的名字。”

陆沉把粥盛出来，放到她面前。

她拿起勺子，吃了一口。

然后又放下。

“哥。”

“嗯。”

“你能不能别老是一个人。”

他没说话。

“我说真的。”她把勺子搁在碗沿上，“你什么都自己扛。你不说，我也看得出来。”

窗外的路灯亮着。粥在碗里冒着热气。

他低头看着那碗粥，看了很久。

“先吃。”

吃完饭，他洗完碗，把妹妹的作业检查了一遍，然后拿上外套出门。

第三区评定署门前有一面很长的公告墙。

墙上有三块屏。

第一块是甲等名录；第二块是本区副本积分榜；第三块是——

**清退序列公示**。

今晚那块屏上，最上面一行，是他。

```
【清退序列 · 待复核对象】
编号 417 · 陆沉 · 第三区
初始属性总和：6（六项均为 1，全服唯一）
评定结论：不可培养，建议清退
复核期：90 天
```

旁边还有一张照片。

照片是昨天拍的。他低着头走出评定大厅，光从他侧后方打过来，看不清脸，只看得见一截很短的后颈。

下面排着一行更小的字：

**“全服唯一六维全一。”**

有人在这行字下面用马克笔加了一句：**“也不容易，全服唯一呢。”**

周围站着几个看热闹的人，笑得很开心。

陆沉站在那里，看着那块屏。

他没有生气。

他在算九十天。九十天，五级。他今天拿到的是 7 点。

“小兄弟。”

身后有人开口。

陆沉回过头。

公告墙下站着一个人。四十多岁的样子，穿一件洗得发白的旧夹克，头发乱，脸上没什么肉。他手里拿着一面铜镜。

镜子不大，巴掌宽，镜面朝下，不反光。

他对陆沉笑了一下，露出上排有点发黄的牙。

“你今天去净场了吧。”

“去了。”

“第几次出来的？”

陆沉没有回答。

那人也不追问。他把铜镜往袖子里一收，两只手插进夹克兜里，往前凑了半步，声音低了下去。

“我不问你里面的事。规矩我懂——**别人拿命换出来的东西，我开口问就是抢**。”

他顿了顿。

“我就问一件事。”

“你说。”

“你出来的时候，”男人的眼睛盯着他，很稳，“面板上——”

“**有没有多出一行字？**”

---

**章末钩子**：陆沉没有说话。

男人看着他，忽然笑出了声，笑完把两只手从兜里抽出来，往后退了一步，做了一个“打住”的手势。

“行了，我懂了。”

“你不用回答我。”

他转身要走，走了两步，又回过头。

“我叫老周。铜镜的周。”

“明天下午，西市场那边有个**废料副本**在招人。三级难度，四级要求，缺两个人。报名费二十积分。”

“哦对，忘了说了，”老周补了一句，“那个副本的死亡率，是**四成**。”

“你要是想清楚了，就来找我。”

他走了。

夜色里,那块公告屏上的光，把陆沉的影子拉得很长。

**“全服唯一六维全一。”**

他抬起手，把外套的拉链往上拉了一格。

然后他往家的方向走了。

**（第03章 · 完）**
