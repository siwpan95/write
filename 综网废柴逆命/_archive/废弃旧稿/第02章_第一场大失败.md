# 第02章 第一场大失败

> **本章概要**：陆沉进入最底层的练习副本「净场」，在十七次被击倒的过程中，把「必败」从一种命运读成了一份数据。他实测出灰犬的攻击节奏、掷骰的落点分布，并推演出一个残酷但干净的结论——他一生的检定都掷不出 15。第十八次，他不再攻击，而是站着不动，把自己送到怪物面前，主动去吃一次最难看的失败。就在那一刻，面板底部浮出一行从未有人见过的小字。
> **本章爽点**：逆势推进的智性爽感——主角不靠愤怒、不靠喊叫、不靠哭诉，靠**实测与统计**把绝境翻译成算式；第十七次到第十八次之间的认知跃迁（「既然我必输，那输本身是不是一种资源？」）是本卷金手指的真正起点。
> **情绪曲线**：平（副本开局，冷静观察）→ 连续下坠（三次、七次、十一次的接连击倒）→ 谷底（第十七次，他意识到数值上毫无胜算）→ 反弹（第十八次主动送死）→ 钩子（面板浮出异常小字）

---

净场是一片没有边界的灰。

脚下的地是硬的，深灰色，看不出材质，踩上去没有一点回声。远处没有墙，也没有天，只有灰白色的雾，一层一层地垒起来，像有人把整个空间用一个空盒子扣住了。

陆沉站在入口处，等着那东西出现。

——这是第一次。

他还不知道，在天亮之前，他会在这同一个入口，站上十八次。

它出现得很安静。

从雾里走出来的，是一条狗。

准确说，是一条**像狗的**东西。一米高，四足着地，身子细长，皮毛是灰的，跟地板一个颜色。它的头很长，嘴部向前突出，牙齿不外露，但能看见牙床的位置在动。

它没有眼睛。

眼睛该在的地方，是两片平滑的、有点发亮的皮肤。

```
【灰犬】
综网官方强度评级：F
说明：全综网标注强度最低的战斗单位。建议用于新手熟悉判定流程。
```

面板给完这行字，就往下滚了一行。

```
【净场·副本特殊规则】
一、本副本内不判定死亡。生命值归零时，玩家重置至入口。
二、重置不消耗进入次数。
三、每次重置，构成一次失败判定结算。
```

陆沉看着第三条看了两秒。

**“失败判定结算”。**

这四个字很轻，但他是今天第二个听到它们的人。第一个是评定官韩度，念的是“不可培养，建议清退”。

灰犬动了。

它没有跑，它是直接出现在他面前三步的位置——不，不对，它是跑过来的，只是太快了，快到他眼睛跟不上。它的鼻端对着他，那两片没有眼睛的皮肤，正对着他的胸口。

陆沉脑子里第一件事不是闪，是**顺序**。

综网战斗遭遇的流程是死的：先攻判定，轮次推进，结局判定。先攻靠敏捷检定掷两枚六面骰。他的敏捷修正是负五。

掷出来的结果，是六。

六减五，等于一。

灰犬的先攻是十二。

它先动。

然后他第一次尝到了“属性 1”是什么味道。

那不是被打。

那是**被无视**。

灰犬撞上来的时候，他甚至没看清动作。一股力从胸口压进来，他的脚离了地，身体在空中翻过去，重重摔在灰地板上。他听见自己的肩膀在落地时发出一声闷响。他感觉到肋骨那一块有温热的东西正在散开。

然后就是灰。

世界重新变成灰色，他站在入口。

```
【你已被击倒。生命值归零。】
【已在入口重置。请准备下一次尝试。】
```

“……”

陆沉低头，摸了一下肋骨。

不疼。

一点伤都没有。

他抬起手，往前推了推——手心里什么也没有，空气是实的，但那道被撞出来的痛，是真的记得的。

投影世界副本的规则他背过。死亡不带来真正的死亡，身体状态恢复至进入副本前的状态。

连痛都是被擦掉的那种痛。

他吐出一口气。

**第二次。**

灰犬从雾里出来。

这次他不等它动。他先动——他往前冲，抬手，出拳。

面板在视野边缘跳出判定：

```
【力量检定 · 目标值 10（普通难度）】
掷骰：2d6 = 8
修正：−5
结果：3
判定：失败
```

失败。

拳头从灰犬的身子一侧擦过去，什么都没打到。

灰犬回过头，像在等他把这一套做完，然后撞了上来。

**第三次。**

他改用腿。他记得自己入学时体测跑得不算慢——当然，那是没有面板的年代。

```
【敏捷检定 · 目标值 10】
掷骰：2d6 = 6
修正：−5
结果：1
判定：大失败
```

大失败。

他的腿抬到一半，脚下踩空，整个人往前栽倒。灰犬甚至不用撞他，他自己把头磕在了地上。

重置。

**第四次。**

**第五次。**

**第六次。**

第七次的时候，他改了做法。

他不打了。

他站在入口，一步不动，看着灰犬从雾里走出来，走过来，绕着他转。

他看它的腿。

看它的头。

看它每次出力的顺序。

第八次,他数了。灰犬从静止到启动，中间有一个极短的停顿——左前腿先落地，然后整个身子压下去，然后才是冲。这个停顿很薄，比眨眼还短，但它存在。

第九次，他又数了一遍。间隔大约是三点二秒。三点二秒，游戏世界里差不多是半轮。

第十次，他确认了：**这个停顿是固定的。**

第十一次。

他站在入口，等灰犬走出雾，等它启动，等它的左前腿落地——然后在那一瞬间，他往侧面扑。

他扑出去了。

灰犬从他刚才站的位置穿过去，擦着他半边肩膀。

“……”

陆沉趴在地上，喘着气。

这是他第一次，没有被一击打飞。

他抬头，看着灰犬停下来，回过头，那两片平滑的皮肤对着他。

**看懂了节奏，还是不够。**

他心里很平静地转过头来算这笔账。

他刚才那次侧扑，是一次敏捷检定。面板没有弹判定的结果。

为什么不弹？

因为闪避不是检定，闪避是**豁免**。

而豁免用的是同一套骰子。

他闭上眼睛，把那一整套规则在脑子里重新过了一遍。

综网的一切判定，都是掷两枚六面骰，加上属性修正值，然后跟一个目标值比。容易是六，普通是十，困难是十五，极难是二十。

他的修正值是负五。

他掷出的最低值，是二减五，等于负三。

他掷出的最高值，是十二减五，等于七。

**他这辈子，在综网里掷不出超过七的成绩。**

普通难度的目标是十。

他需要掷出十五。

而两枚六面骰能掷出的最大值，是十二。

**十五不存在。不是难，是不存在。**

他甚至算出了“大失败”的占比。大失败的判定是总结果低于目标值五点以上——目标值十，就要求掷出的总值不超过五。两枚六面骰一共三十六种组合，落在这一档里的，有三十三种。

**三十六次里，三十三次是大失败。**

这不是运气问题。

这是**系统在数学上，给这个人判了死刑。**

第十二次。

第十三次。

第十四次。

第十五次。

第十六次。

他不再试着打中了。他开始试着**记录**。

他记录灰犬的攻击前摇有多少帧的感觉，记录它从左侧切入比右侧快还是慢，记录他在被撞飞的过程中，身体的哪个部位先着地。

他像一个拿着最后一笔本金的人，在赌桌前做统计。

**他没法赢。**

**但他可以知道，自己是怎么输的。**

第十七次。

他站在入口，看着灰犬从雾里走出来。

这一次他什么都没做。

他不打，不闪，不跑。

他就站在那里，看着那条没有眼睛的狗朝他走过来。

他忽然想起父亲。

陆铮，丙等副本外包工。三年前死在一次探索型副本的塌方里，遗体都没找回来，只送回来一块编号牌。父亲一辈子没跟他说过什么大道理，只在他十二岁那年教过他一句话。

**“先算概率，再赌性命。”**

陆沉那时候不懂。

他以为那是赌徒的话。

现在他懂了。那不是赌徒的话，那是**只有输了足够多次的人，才说得出口的话**。

灰犬启动。

左前腿落地。

陆沉没有动。

他看着那股力量从正面压过来，看着灰色的皮毛填满整个视野。他脑子里最后一个念头，不是“我完了”。

是一个很干净的问题：

**“既然我必输 —— 那‘输’本身，是不是一种资源？”**

轰。

他被撞飞出去。

那一下很沉，沉得他能听见自己骨头里的声音。他的后背砸在灰地板上，视线一下子黑掉一半。

生命值归零。

**第十八次重置。**

灰色的世界里，他站在入口。

身上没有伤，肋骨不疼，肩膀也完好。

他低头看着自己的手。

然后面板亮了。

不是战斗判定，不是重置提示。

是一行他从没见过的字。

浮在视野最底部，字号比任何一条系统提示都小，颜色是淡的，像有人用一根很细的笔，小心翼翼地写上去。

```
【检测到异常：该账号不适用常规评估。】
```

陆沉看着这行字。

他很慢地，把右手握成了拳，又松开。

然后他做了一件今天以前从来没做过的事。

**他笑了一下。**

很轻，很淡，几乎看不出来。

但是笑了。

---

**章末钩子**：那行小字下方，又缓缓浮出第二行。字号一样小，一样像是偷偷写上去的。

```
【逆命者协议：已激活。】
```

陆沉站在净场的入口处，看着“逆命者”这三个字。

他还不知道它是什么意思。

但他知道两件事——

第一，**系统在他的账号上，改写了某个东西。**

第二，今天他来了第十八次。

而第十八次，是他第一次带着“收获”走出这片灰。

**（第02章 · 完）**
