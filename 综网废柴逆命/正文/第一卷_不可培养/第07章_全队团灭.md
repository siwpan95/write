# 第07章 全队团灭

> **本章概要**：铜镜小队进入西市地宫。这个副本有两条规则：照明不足，一切视觉检定取劣势；声音放大十倍，任何巨响触发全区怪物警觉。第三条规则他是在第三层才明白的。**这里不判死，但是会真的痛。**
> **本章爽点**：**绝境算路**。全队被围、石臼被压住的那一刻，他第一次在别人面前算出了一条活路。而那一条活路，需要他自己走进去。

---

早上五点五十，北门。

天还没亮。三个人已经在等着了。

苏青靠着墙，手里拿着一个笔记本。石臼蹲在地上，面前摆着两个铁箱。贺小满在给一支短棍缠布条。

陆沉走过去的时候，陈九斤正从巷子那头跑过来，怀里抱着一个鼓鼓的布袋。

“哥！哥！”他边跑边喊，“我给你带了干粮！还有这个——”

他从袋子里掏出一个巴掌大的东西，塞给陆沉。

是一支微光棒。

“一人一支。我蹭了店里三支。”九斤压低声音，很得意，“不要钱。”

苏青看了一眼表。

“五点五十八。人到齐了。”

她把笔记本合上。

“三件事。”

“第一，这个副本的通关条件不是杀光，是**抵达最底层的结算柜，取回寄存物**。柜子在最下面那一层，路线穿过整个商场。”

“第二，规则两条。照明不足，**一切视觉检定取劣势**。声音放大十倍，**任何巨响触发全区警觉**。”

“第三——”

她顿了一下。

“**副本不判死。**”

石臼抬起头。

“什么意思？”

“意思是你被打倒不会死。生命归零，会被重置回入口。”

“那挺好啊。”九斤说。

“不好。”苏青说，“重置一次，队伍就要从头走一遍。”

“而且——”她看着九斤，“**痛感是真的。**”

九斤的脸白了一下。

入口是跳蚤市场最里面一个摊位下面的铁盖。

苏青掀开它。下面是一道锈掉的铁梯，往下大概四米。

“我先下。”石臼说。

他先下去了，铁梯响了一声。

然后上面所有人同时听到了那声响的**回音**。

不是普通的回音。

**是十倍大的回音。**

苏青的脸沉了下来。

“从现在起，所有人——”她把声音压到几乎听不见，“**不要说话。**”

地下商场比想象中大。

这是一条商业街的地下一层，店铺还在，招牌还挂着。有一块招牌上写着“张记卤味”，字掉了一半，只剩下“张”和“味”。

地上有积水。水很浅，刚过鞋面。

天花板在漏。每隔七八米就有一处，水珠砸在水面上，“嗒”。

**而那一声“嗒”，在这地方听起来像有人敲了一下桌子。**

陆沉走得最慢。

他走在队伍最后面。

他没有开微光棒。

“你怎么不开灯？”贺小满回头，用气声问。

“看得见。”

“……你看得见？”

“不。”陆沉说，“**我不用看的。**”

因为视觉检定在这里取劣势。而他的视觉检定，本来就是负五。

开灯，也只是把负五变成负五加劣势。

**没有意义。**

所以他改成用别的。

用耳朵。用手。用脚下的水。

水的深浅在变。店铺门口的水浅，通道中间的水深。他踩着水的深浅，就知道自己走在什么位置上。

走了大约七十米，苏青停了。

前面是第一个岔路。

左边一条通道更宽，更直，地面是干的。**看起来好走。**

右边一条更窄，一直往里绕，水更深。

“左边。”苏青说。

“右边。”陆沉说。

所有人都回头看他。

“左边那条路，地面是干的。”陆沉说，“**干了九年，却没有灰。**”

“……”

“说明有人一直在走。”

“那更好啊，”九斤小声说，“有人走过说明安全。”

“说明**有别的东西**一直在走。”陆沉说。

苏青看着左边那条通道。

看了三秒。

“改右边。”

右边的通道，他们走了四十分钟，没遇到任何东西。

那四十分钟里，陆沉一句话没说，只是在走。

但他手里一直在动。

**他在数。**

事情发生在第三层。

他们下了一层并没有走完的楼梯。铁栏杆，缺了三段。通道尽头是一排货架，倒了一半，堆在地上。

苏青让他们贴着墙走。

石臼走在最前面。

陆沉走在最后。

然后他闻到了一股味道。

不是霉味。

**是甜的。**

他停住，抬头。

那味道是从他左侧上方来的。

他把微光棒按亮了一秒。

只有一秒。

然后他看清了。货架上方，趴着一排东西。

不是货。

**是活的。**

那一秒之后，他做了一件全队都没想到的事。

**他伸手，把旁边一整排货架推倒了。**

“哐——！！”

十倍。

那声巨响在这条地下街里炸开，回音滚了三层。

**所有人同时被震得蹲了下来。**

“你干什么——”石臼吼了半句，自己就停住了。

因为货架倒下去的那一刻，从上面的阴影里，掉下来了十几只。

那是人形的。

一米多高，通体湿滑，像被泡烂的布。它们没有脸，没有五官。落在地上，慢慢爬起来，朝这边过来。

**水蛭傀儡。**

“往后退！”苏青喊，“退到楼梯口！”

退不掉。

水是从上面下来的。

**它们从天花板上掉。**

第三只砸在石臼后背上。

石臼一把抓住它扯下来摔在地上，一脚踩上去。

踩下去的时候，那东西没有破。

**它软。**

像踩在一摊水里。

“打不死！”石臼吼，“这玩意儿打不死！”

它当然打得死。

陆沉脑子里已经在算了：这种生物在被挤压时会暂时改变密度，需要连续两次、间隔不超过两秒的挤压才能破开。

**石臼每两秒只能踩一次。**

**他知道。**

但他说不出来。

**因为他一喊，就会引来更多。**

第五只、第六只落下来。

石臼已经站不稳了。

他背对着一根支撑柱，一边扯一边吼，退到了第三根柱子边上。

然后那根柱子后面，一整排货架塌了下来。

**砸在他身上。**

“石臼！！”

苏青冲过去了。

陆沉没有冲。

他站在原地看着。

**他在算。**

第一项：那排货架大约有一吨半。石臼体质十几，能扛住，但他被压在地上，四肢动不了。

第二项：水蛭傀儡正在往他那边聚。它们对**受困的、温热的、流血的**目标有反应。

第三项：苏青现在冲过去，能推开货架，但推开需要大概八秒。八秒里，聚过去的水蛭傀儡会有七到九只。

**她推开货架，自己就变成新的目标。**

第四项。

这条路是死路了。

**除非有人把这一群先引走。**

“苏青！”

他的声音不大，但在这地方还是震了一下。

苏青回过头。

陆沉站在那片阴影里，站在所有人身后。

“别推货架！”

“‘不推他就完了！’”

“**听我的。**”

他说了三个字。

然后他转身。

**朝着通道的另一头，走了过去。**

那一头没有路。

那一头是水蛭傀儡最密的地方。

他走得不快。

走的是一条**直线**。

身后传来贺小满的尖叫，苏青在喊什么，石臼在吼。

但陆沉没回头。

他一边走，一边把手里的微光棒举起来。

并且**按到了最亮那一档。**

水蛭傀儡惧强光。

不是因为光能伤它们。

是因为**光让它们看得见猎物在哪。**

七只。

八只。

十只。

它们从货架上面、从天花板、从两侧的店铺里，一起涌向那一点光。

陆沉站在那点光的正中央。

就像前两天，他在净场里，站在那只灰犬正面一样。

敞开双手。

视野底部，那行小字浮了出来。

```
【逆命值 +3】
```

再下面一行。

```
【逆命值：10 / 10】
```

**（第07章 · 完）**
