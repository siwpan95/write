# 第08章 翻命

> **本章概要**：他站在光里，把十几只水蛭傀儡全部引向自己。第一次判定，他掷出了大失败。照理他应该当场被撕开。但那个结果没有发生。**结果是：他改掉了它。** 全队安全撤出，他一个人留在最底层，靠着承伤爬了出来。
> **本章爽点**：**全书第一个大爽点。** 十次的积累在一瞬间兑现。「翻命」这个能力第一次被读者看见：**不是变强，是让已经写好的结果不算。**

---

光在他手里。

微光棒按到最亮那一档，光只够照亮一个半径两米左右的圈。

陆沉站在圈的中央。

他左手张开，把棒举高了一点。

第一只从左边扑过来。

他没动。

第二只从正面上方掉下来。

他没动。

第三只、第四只、第五只。

他都没动。

他不是在等死。

**他在等它们全部进来。**

一只，两只，三只，四只，五只，六只，七只……

他在数。

**因为它们只能从光的外围进来。而光的外围，只有这么大。**

**十四只。**

全部涌进那两米的圈，需要大概一点四秒。

而它们进来之后，会**互相挤压**。

这就是他要的。

**一点四秒。**

圈子满了。

**第一步：面板浮出来了。**

```
【敏捷检定 · 目标值 12】

掷骰：2d6 = 4

修正：−5

结果：−1

判定：大失败
```

**大失败。**

敏捷检定大失败的意思，是他不但没躲开，而且**绊了一下**。

他的脚在水里打了个滑。

身体往前扑。

那一刻，他脑子里浮出来的不是恐惧。

是**账**。

**这一下，值 3 点。**

（受伤的大失败，一直值三点。）

**一点四秒。**

十四只水蛭傀儡全部压上来了。

**第二步：**

面板底部，那行一直亮着的小字，突然变成了另一种颜色。

```
【逆命值：10 / 10】

【可用操作：翻命（消耗 10 点）】

【是否将本次判定结果改写？】
```

陆沉在往前扑的半空中，抬起了右手。

**第三步：**

他按了下去。

**嗒。**

（不是骰子。是别的东西。）

**咔。**

（判定，锁死了。）

然后。

**轰——！！！**

世界停了。

不是慢下来。

**是停了！！**

水蛭傀儡全部悬在半空。它们的身体像一团被按了暂停的湿布，还在往下压，但压不到他。

光也停了。

水面上溅起来的那几滴水珠，停在半空，一颗，一颗，清清楚楚。

**只有他一个人还在动。**

面板上的那行字，变了。

```
【敏捷检定 · 目标值 12】

掷骰：2d6 = 4

修正：−5

结果：−1

判定：大失败

—————————————————

【改写中……】

【改写后判定：成功】

—————————————————
```

**成 功 ！！**

陆沉看着那两个字。

然后他忽然笑了一下。

那是他这两天里第一次笑。

**第四步：**

世界重新动了。

但这一次，动的方式不一样了。

他的脚在水里打的那个滑，**没有滑**。

他的身体往前扑到一半，**稳住了**。

他没有摔倒。

他站直了。

而且，**他站到了那群水蛭傀儡的中间。**

十四只。

全部挤在他身边，最近的离他不到二十厘米。

**但它们没有一只碰到他。**

因为刚才那一点四秒里，它们全部挤进了这个两米的圈子。

而这个圈子的直径是两米。

**十四只一米多高的东西，挤在两米里，是什么状态？**

是**动不了**。

它们贴在一起，湿软的身体互相缠住，堆成一个团。

**它们卡住了。**

陆沉站在那个团的缝隙里。

二十厘米。

不多，不少。

他从团的中间，一步一步往后退。

**一只都没有惊动。**

**八秒。**

他需要为苏青争取八秒。

身后传来货架被推开的声音。

沉重的、铁的摩擦声，一声，两声，三声。

石臼的吼声。

苏青在喊。

凌乱的脚步声。

**第五秒。**

他退出了那个团。

**第六秒。**

他开始往楼梯口跑。

**第八秒。**

“陆沉！这边！”

是九斤在喊。

他没有回头。

**第九秒。**

那团水蛭傀儡散了。

**第十秒。**

它们发现了他。

**第十一秒。**

陆沉被第一只从背后扑倒。

**第十二秒。**

他撞在了一排倒下的货架上。

**第十三秒。**

第一口咬在他左肩上。

他听见自己肩膀发出一声很轻的“咔”。

**第十四秒。**

面板浮出来。

```
【力量检定 · 目标值 10】

掷骰：2d6 = 11

修正：−5

结果：6

判定：失败
```

失败。

不是大失败。

**这一次，他没有任何额外的东西可拿。**

**第十五秒。**

第二只咬在他小腿上。

**第十六秒。**

第三只。

**第十七秒。**

生命值归零。

灰。

他站在入口。

铁梯下面那片积水，还是刚来的时候那个样子。

他低头，看自己的肩膀。

**衣服是完好的。**

他把左肩活动了一圈。

不疼。

但他知道，刚才那一下是**真的疼过**的。

**痛感是真的。只是不会被带走。**

他扶着铁梯站了一会儿。

面板浮出来。

```
【逆命值 +3】

【逆命值：3 / 10】
```

三点。

受伤的大失败，三点。

他算了算：翻命用掉 10 点，中间又拿了一次 3 点，现在剩 3 点。

**所以明天他最多能拿到 7 点。**

**要再用一次翻命，需要等两天。**

他把这个数记在心里。

然后顺着铁梯，重新往上爬。

出来的时候，天已经亮了。

跳蚤市场刚开张，摊主们在摆货。他们五个站在巷子口，身上全是水。

石臼坐在地上，被人架着。他左腿塌了一块，正在被贺小满用布条缠。

“两根。”石臼龇着牙，“两根骨头。”

苏青站在旁边，一句话没说。

陆沉从市场里走出来的时候，所有人的头都转了过来。

水从他外套上往下滴。

一滴，一滴。

**滴在地上。**

“你……”石臼先开口，“你他妈是怎么活下来的。”

陆沉看着他。

“算的。”

石臼张了张嘴，最后没说出话。

苏青往前走了两步。

她站在他面前，比他矮半个头。

她什么都没说。

然后她抬起手，把自己衣领上的那枚队徽摘了下来。

**那枚队徽她戴了四年，从进队第一天到现在没摘过。**

她把队徽按在他手心里。

“收着。”

**（第08章 · 完）**
