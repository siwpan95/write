# 27 · 文风规范：冷热二段式

> **缘起**：作者指出——「其实你可以参考港漫，**如果非要大量使用破折号之类的内容，那就贯彻到底**。」
>
> 这句话点出了比"清理破折号"更根本的问题：**我之前的错不是用了破折号，是"用得没有章法"**。
> 风格化元素要么不做，要么做到极致——半吊子的效果字，比不用还难看。

---

## 一、港漫的表达手法（调研结论）

| 手法 | 具体 | 出处 |
|---|---|---|
| **旁白反客为主** | 旁白几乎把打斗过程全叙述完，读者不看画面都懂：「刀仙抢先出招，刀锋冷，刀势快如急电！拦腰一劈，**中了，可惜只是虚影！**」 | 《新著龙虎门》 |
| **感叹号极致化** | `！！` `！！！` 密集轰炸，动词狂轰 | 全港漫通用 |
| **拟声词独立** | 咕！呱！吔！哇！㗅！嗄！——「磁场怪叫」 | 《海虎》 |
| **强者语** | 「真正的强者，不是没有恐惧，而是面对恐惧依然前进！」「不知所谓」 | 《海虎》《武神》 |
| **力量匹数化** | 兆瓦级 → 亿兆瓦，直白夸张 | 《海虎》 |
| **短促断句** | 简洁有力的分镜式句子 | 全港漫通用 |
| **重复强调** | 同一句连用三次 | 全港漫通用 |

**核心精神**：**不要克制，要炸。** 港漫的美学就是"夸张到自成一个体系"。

---

## 二、但这本书不能全篇港漫化

原因：本书的**人设与基调是冷的**。

陆沉沉着、算概率、不喊口号。全书的主线动作是「改写判定」——**一个绝对理性的动作**。

如果全篇都炸，会与"他在算"这个核心冲突。

**所以本书的方案不是"港漫化"，是"冷热二段式"。**

---

## 三、核心机制：港漫模式 = 改写判定的视觉化

> **这是整个方案的关键，也是它能自洽的原因：**
>
> 陆沉是**改判定的人**。
> 当他改写判定时，**叙述本身的"规则"也被他改了**。
> 平时那个克制、冷静、只写数据的叙述者，在那一刻**失真**了——开始用感叹号、拟声词、破折号、重复。

**在叙事层面上，这是一次元操作**：不是"作者想耍帅"，是"**世界被他改了一下，连讲述世界的方式都变了**"。

| 模式 | 触发条件 | 表达方式 |
|---|---|---|
| **冷静模式**（默认，占 90%） | 日常、叙述、对话、算账、潜行 | 极简。零破折号。短句。数据。白描 |
| **港漫模式**（爆发，占 10%） | **逆命值触发 / 改写判定 / 逆命之刃具现 / 关键击杀** | 拟声词、感叹号、破折号、旁白加速、重复、排版断裂 |

---

## 四、港漫模式的八条具体规则

### 1 · 进入信号

港漫模式**不能随便切换**，必须有明确的进入信号。本书用三种：

- 面板浮出`【可用操作：翻命】`
- 逆命之刃具现
- 骰子掷出**大失败**或**大成功**的那一瞬间

### 2 · 感叹号放开用

```
他算出来了！！

不是猜的。

是算出来的！！！
```

**规则**：港漫模式里感叹号不限量；冷静模式里**全章不超过 3 个**。

### 3 · 拟声词独立成行，加粗

本书的拟声词必须来自**"机械／数据／判定"的语域**，不能用《海虎》那套（吔、呱、口也）——那是别人的语域。

| 场景 | 拟声词 |
|---|---|
| 骰子落定 | **嗒。** |
| 面板亮起 | **嗡。** |
| 判定锁死 | **咔。** |
| 数据崩解 | **嚓——** |
| 翻命生效 | **轰——！！** |
| 刃具现 | **铮！！** |

### 4 · 破折号只用于一件事：**力量延伸**

破折号的合法用法在本书被收窄为一个：

**表示"这个动作还没结束，或者超出了预期"。**

```
他去——！

（动作未完成 / 被截断）

轰——！！

（力量的余波在延伸）
```

**除此之外，全书破折号归零。**

### 5 · 旁白加速（学《龙虎门》）

关键动作可以**由旁白直接叙述完**，不写画面：

```
左！右！上！下！

四只同时扑到。

第一只咬空，第二只撞在他背上，第三只被他拨开，第四只——

不。
```

### 6 · 重复三次

```
不算。
不算。
不算！！
```

### 7 · 数字要炸开

冷静模式里数字是数据（`2d6 = 4`）。

港漫模式里数字是**视觉**：

```
五 减 五 等 于 零

**零！！**
```

### 8 · 退出信号

爆发完必须**立刻回到冷静模式**。用空格或分隔标记。

```
（一轮之后）

……

他站在那儿，喘了两口气。

面板上跳出：

【逆命值：0 / 20】
```

## 五、示范：第 08 章「翻命」段落的两种写法

### 冷静模式写法（现有的，安全但平）

> 他按了下去。
> 世界停了。
> 不是慢下来，是停了。
> 水蛭傀儡全部悬在半空。

### 港漫模式写法（重写版）

```
他按了下去。

———

嗒。

（不是骰子。是别的东西。）

咔。

（判定，锁死了。）

然后——

轰——！！！

世界停了。

不是慢下来，是停了！！

水蛭傀儡全部悬在半空，湿软的身体还在往下压，可它们压不到他。

光也停了。

水面上溅起来的那几滴水珠，停在半空，一颗，一颗，清清楚楚。

只有他一个人还在动！！！

面板上的那行字，变了。

【敏捷检定 · 目标值 12】

掷骰：2d6 = 4

修正：−5

结果：−1

判定：大失败

———————————————

【改写中……】

【改写后判定：成功】

———————————————

成 功！！！

他笑了。

那是他这两天里第一次笑。

———

（世界重新动了。）

然后他站直了。

没有摔倒。

而且，他站到了那群水蛭傀儡的中间。
```

> **对比**：同样一段，港漫模式用 `轰——！！！`、`成 功！！！`、`———————————————` 分隔线、`！！！`，把"改写判定"这件事的**冲击力**做了出来。
> 而这些手法**只在这一次爆发里出现**，回到下一段叙述就全部收掉。

## 六、边界：什么时候不能用

| 禁止场景 | 理由 |
|---|---|
| **日常对话**（粥桌、西市场议价） | 会破坏"冷"的底色，也让爆发贬值 |
| **信息章**（复查被驳、老周讲历史） | 这里要的是压迫感，不是爽感 |
| **All Is Lost**（第 16 章序列营） | 谷底要的是**静**，炸了反而轻浮 |
| **闻人驭的对白** | 他的力量在于"平静地记录你"，任何夸张都是削弱 |

> **一句话**：**港漫模式是他的能力特效，不是全书的语气。**

## 七、这件事的闭环

| 层次 | 内容 |
|---|---|
| **表面** | 解决了"破折号怎么用" |
| **中层** | 建立了"冷热二段式"的风格纪律 |
| **底层** | **风格的切换本身，就是主角能力的元叙事表达** |

> 读者会慢慢形成一个条件反射：
> **只要叙述突然变得不冷静了，就说明——判定被他改了。**

这是这套文风真正的价值。

## 八、附：歌词使用政策（2026-09-20 联网核实）

### 核实结论

**一两句歌词用于情节需要，不构成侵权。**

| 项 | 结论 |
|---|---|
| 《著作权法》第 24 条 | 为**评论、情节需要**适当引用他人作品，属合理使用（注明出处即可） |
| 侵权门槛 | 只有「**大量引用作为小说重要组成部分**」才可能侵犯复制权／发行权 |
| 行业惯例 | 网文圈"文抄公"流派（**以引用歌词、影视台词为核心卖点**）长期大量存在 |
| 风险区 | 整首照搬｜作为核心卖点密集使用｜未注明出处 |

> 此前我按"合规优先"处理，是**过度谨慎**了。

### 但本书的选择仍然保持"化用"

理由**不是法律，是风格**：

> **没有铺垫的歌词，容易出戏。**

本书是冷硬基调。突然出现一首现实歌曲的名字和一整段歌词，会瞬间击碎沉浸感——读者会意识到"这是作者在贴素材"。

### 三条具体规定

| 允许 | 说明 |
|---|---|
| ✅ **化用意象与句式** | 第 19 章已用：「**围猎既然开场，没人幻想能优雅收场。**」（化用李常超《围猎》） |
| ✅ **出现歌名作为时代道具** | 形如"收音机里在放《XX》"——**第二卷起可用**，但要写得像环境噪音，不像引用 |
| ❌ **整段照搬歌词** | 除非有充分铺垫，且只引一句 |

> **一句话**：**歌词可以进这本书，但必须以"世界里本来就有的声音"的身份进来，不能以"作者引用的名句"的身份进来。**

## 九、附：两项执行要求（2026-09-21，据外部点评 `32`）

### 9.1 「判定前三件套」——让读者能参与推理

**问题**：此前写判定，是**他算完了，然后告诉我们结果**——读者在**旁观**推理，不是**同步**推理。

**要求**：判定发生**之前**，必须先给三样东西——

| # | 内容 | 例（第 08 章翻命） |
|---|---|---|
| **1** | **已知条件 3–5 条** | 微光棒只能照亮两米；水蛭傀儡从光的外围进来；它们会互相挤压 |
| **2** | **一处可疑之处** | 「它们只能从光的外围进来。而光的外围，只有这么大。」 |
| **3** | **一个可验证的数** | 十四只 × 一点四秒 |

**然后判定发生**：
- **读者猜对** → 爽感来自**智性确认**
- **读者没想到** → 爽感来自**反转冲击**

两种都是正向体验——**但前提是读者的思考被激活了**。

**硬性要求**：「可疑之处」**不能在下一段立刻解释**，要留到判定发生时。

### 9.2 「可视化推理动作」——为改编预留镜头

**要求**：冷静模式的叙述里，**必须保留能被看见的推理动作**：

| 动作 | 已有实例 |
|---|---|
| 在纸上写 | 05 章写五条规则｜20 章在纸上写四样东西 |
| 用手指划过某处 | 17 章抹开灰看刻痕 |
| 数数 | 08 章数傀儡｜11 章数挂索 |
| 把东西放到特定位置 | 15 章点公告屏 |

**两个理由**：① 文本层面更有画面；② **为短剧改编预留镜头语言**（`31` 报告指出改编是主要变现路径）。

> **纯心理推理在短剧里没法拍。** 但他在纸上写下一行字可以。
