# 21 · 三大框架重构

> **返工说明**：本文件回答一个此前被跳过的问题——**这本书的主线、世界观、情节到底是什么。**
>
> 现有 00–20 号文档做了大量工作，但它们的问题不是"不够多"，而是**顺序错了**。
> 正确的顺序（据番茄金番作家徐二家的猫《开书前六大硬核筹备要点》）是：
>
> ```
> 主线 → 世界观（从势力对抗长出来）→ 体系设定 → 金手指 → 人设 → 卷纲
> ```
>
> **我是从"体系设定"开始的**：先做了 2d6 检定、法则谱系、位面结构、怪物谱系、状态表……把"世界的物理"写得极细，却把"世界的戏剧"留空了。
> 结果就是——世界像一台精密但没插电的机器。

## 一、主线（第一个该定、却一直没定清楚的）

### 简洁版

> **一个全服最废的人，靠输变强，最后改写了判他死刑的那条规则。**

### 详细版

> 综网降临第九年。全人类被一套冷酷的规则重新分等：属性总和决定你能住哪一区、能不能结婚、能不能活过四十岁。
>
> 十八岁的陆沉，六项属性全是 1——综网接入九年来，全世界只有一个人是这个面板。评定署给他的判词是八个字：**不可培养，建议清退**。跟着一起被判的，还有他十四岁的妹妹。
>
> 九十天。他必须在这套规则里活下来。
>
> 而在最底层的练习副本里，他发现了自己真正的异常：**别人靠赢变强，他靠输变强。** 每一次被判定为大失败，都在给他积累一种别人看不见的东西。
>
> 于是他要在这套把他判死的规则里，一级一级往上爬——从弃民爬到发牌的人。爬到足够高的时候，他会看到那件事：综网九年来一共留下过八个"不适用常规评估"的账号，前八个都死了。第八个的编号是 **000416**。
>
> 那是他父亲。

### 四卷分段主线

| 卷 | 卷名 | 一句话 | 主角要什么 |
|---|---|---|---|
| 一 | **不可培养** | 90 天，从"必败废柴"爬到 5 级，把清退令卡住 | 活着 |
| 二 | **第 9 个** | 追查父亲 416 与前面 8 个同样的账号 | 知道真相 |
| 三 | **收割者** | 面对上一个文明的变量，明白"筛选"其实是"喂养" | 拒绝命运 |
| 四 | **改判** | 他改不了规则本身，但他能改一条 | 定规矩 |

## 二、世界观框架（必须从"势力对抗"长出来，不是从"规则"长出来）

### 2.1 先说方法论给的范式

> 「首先要有正派的势力、体系。**再根据正派的体系，完善相对应的反派体系**，地图、科技树等一系列的事情。」
> 举例：朝廷是最大势力 → 但江湖还能存活，需要一个理由 → **皇子夺位，江湖是一把夺权的刀**。

**关键**：世界格局不是"设定出来的"，是**一个阵营的存在理由逼出另一个阵营**。

### 2.2 正派体系：拾荒者

**问题**：原设定里主角没有归属。铜镜小队太小（四个人），撑不起"正派体系"。

**立**：**拾荒者** —— 不是组织，是一种身份。

| 项目 | 内容 |
|---|---|
| 是什么 | 西市场一带低阶玩家自发的互助网络。没有正式名称、没有首领、没有章程 |
| 暗语 | **「铜镜朝下」**（老周那面镜子的放法） |
| 做什么 | 只做两件事：**交换情报**、**把快饿死的人拉一把** |
| 不做什么 | **不反抗综网**。他们认命，但不想看着同类死干净 |
| 代表 | 老周（情报）、陈九斤（中转）、以及几百个连名字都没有的丙等玩家 |
| 与主角的关系 | 主角是他们当中唯一一个"往上爬"的人；初期他们不信他能爬上去，后期他们靠他活着 |

> **一句台词定调**（老周）：
> 「我们不反对这规矩。我们只是在这规矩底下，尽量多留几个人。」

### 2.3 反派体系（据正派反推）

| 阵营 | 是谁 | 要什么 | 为什么和主角冲突 |
|---|---|---|---|
| **评定署** | 韩度 | 让规则正常运行 | **他判了主角死刑，也是三年前签他父亲清退令的人** |
| **清退序列管理司** | 未具名的官僚系统 | 按名单处置 | 执行者，不上场，但一直在推进倒计时 |
| **综网序列 · 异常行为调查科** | 闻人驭 | **清除"异常账号"，保护系统稳定** | 他处理过 41 个，主角是第 42 个 |
| **规则本身（"筛子"）** | 综网 / 地狱之下 | 完成筛选 | 它给了主角金手指，也给了所有人等级 |
| **上一个变量** | 收割者 | ？（卷三揭晓） | 终极 |

### 2.4 核心矛盾（世界级大矛盾——这是之前完全缺失的一环）

> **综网序列认为"异常账号"是病毒，必须清除。**
> **而实际上，异常账号是综网自己留下的筛选机制——它在找一个人。**
>
> **于是：官方在阻止这场筛选，而主角正是筛选的产物。**

这条矛盾的价值：
- **第一卷就能埋**（闻人驭猎杀他，理由充分且"正确"）
- **贯穿全书**（读者会一直好奇：系统为什么帮他？）
- **卷三炸开**（原来不是帮他，是喂养）

### 2.5 世界格局（把上面的阵营放进地图）

```
                    【综网 / 地狱之下】
                    规则制定者，不下场
                            │
            ┌───────────────┴───────────────┐
            │                               │
      【官方序列】                      【制度层】
   综网序列 / 评定署                  清退序列管理司
   闻人驭 · 韩度                      名单与倒计时
            │                               │
            └───────────────┬───────────────┘
                            │  等级体系（筛选的执行）
                            ▼
                    ┌───────────────┐
                    │  甲 / 乙 / 丙  │
                    └───────┬───────┘
                            │
                    【拾荒者】丙等底层的互助网络
                    老周 · 九斤 · 无名者们
                            │
                         主角
                    （本不该存在的第 9 个）
```

## 三、体系设定的换算比例（此前的硬伤）

方法论明确要求：
> 「一定要严格制定好一个前提：**达到什么样的要求才能晋级**，节奏是否合理，每个等级**分别提升了什么待遇**。」
> 举例：一个武者打两个普通士兵，一个武士打十个，一个武师打五十个，宗师可万军从中过。

**我之前只有抽象 FP，没有这个直观刻度。补上：**

| 等级 | 战力比（≈ 能打几个普通人） | 待遇变化 | 首卷参照 |
|---|---|---|---|
| 普通人 | **1** | —— | —— |
| **1 级** | **0.5**（比普通人还弱） | 无。只有一天两次免费练习副本 | **陆沉开局** |
| 2 级 | 3 | 可进 4 人小队，接 3 级副本 | 第 07 章 |
| 3–4 级 | 10 | 丙等精英，可报名费减半 | —— |
| **5 级** | 50 | **可申请户籍复核，解除清退** | 第 19 章 |
| 9–12 级 | 200 | 乙等，可服役 | —— |
| 13–16 级 | 1000 | 甲等，可考序列 | —— |
| 17–20 级 | 5000+ | 权限层，可兑换属性 | —— |
| **逆命者（任何等级）** | **不可比** | 他能改写**判定结果**——这不是战力，是规则层操作 | 全书 |

> **换算比例必须在战斗里让读者"看见"**：
> 第 06 章石臼（总和 51）能扛住三只水蛭傀儡；陆沉（1 级）一只都扛不住——**但陆沉能算出哪只先动**。
> 这个对比一句写清，读者立刻懂了"等级"是什么。

## 四、金手指复核（发现一个真实的风险）

方法论警告：
> 「**切忌不要将金手指设定得太过于强大，至少不要盖过主角的风头。**让主角成为一个可有可无的人……就算没有金手指，主角也不会混得太差，这样读者才会喜欢主角。」

**对照陆沉：没有逆命者，他就是个废人。** ← 这违反原则。

### 修正：给他三种"不依赖金手指的能力"

| 能力 | 来源 | 作用 |
|---|---|---|
| **算概率** | 父亲遗言「先算概率，再赌性命」 | 他能算出任何检定的成功率、任何战术的存活率 |
| **读谱系** | 自学 | 认出怪物的谱系就知道它的弱点和本能——**这是纯知识，不靠面板** |
| **读人** | 长期被轻视养成的 | 他看得出谁在说谎、谁在硬撑、谁快撑不住了 |
| **承受失败** | 性格 | 他不怕输。这是全服最稀缺的品质——别人输一次就崩了 |

**定调**：
> 「就算没有逆命者，他也能靠这三样活下来——**只是慢十倍**。」
> 金手指是**加速器**，不是**唯一依靠**。

这也让"他的成功不依赖运气"这一点站得住。

## 五、人物框架（必须从故事反推，不是独立设计）

方法论：
> 「到了这一步反而简单起来了。**因为一个基本的故事已经在你的脑海中成型了。**」
> 男主复仇 → 性格坚毅果断睿智 → 但复仇需要同伴 → 就设一个男二/女配**补充男主性格缺陷** → 反派要强，否则男主的努力无意义。

### 5.1 主角（由主线反推）

| 步骤 | 推导 |
|---|---|
| 主线需要什么 | 一个**能忍、能算、不服**的人——他要在最底层待足够久，还要爬上去 |
| 因此性格 | **坚毅（能忍十八次）、冷静（靠算不靠喊）、不认命（但也不喊口号）** |
| 性格缺陷 | **他不肯让别人替他承担**。这是他的病——**也是全书要治的东西** |
| **他相信的谎言（Lie）** | **「只要我算得够准，就不需要任何人。」** |
| 家人配置 | 妹妹（**唯一软肋**，也是他不能退的理由）；父亲（**死因是伏笔**） |

> **关于 Lie（2026-09-20 补，据 `29` 的跨媒介调研）**
>
> **Lie 与 need 互为镜像**——need 是"他应该学会什么"，Lie 是"他现在错信什么"。
>
> **本书的 Lie**：**「只要我算得够准，就不需要任何人。」**
>
> 这个谎言的特征：
> - 它**看起来是他的优点**（他确实靠算活到了现在）
> - 它和第 16 章补写的第五条（「允许别人挡在我前面」）**正好相反**
> - 它应该**在第三卷被彻底击碎**——他必须面对"有些东西算不出来"
>
> **三段式处理**：第二卷让它**动摇**（他不得不依靠别人）→ 第三卷让它**碎掉** → 第四卷他带着这个教训去改规则。

### 5.2 同伴（补主角缺陷）

| 角色 | 补的缺陷 | 具体 |
|---|---|---|
| **苏青** | 补"他不肯开口求人" | 她会直接替他做决定，然后让他承担后果 |
| **老周** | 补"他看不见全局" | 他知道很多但不全说，逼主角自己问 |
| **九斤** | 补"他太冷" | 九斤会把数字翻译成人话——**他是读者的情绪替身** |
| **陆谣** | 补"他没有软处" | 她会对他发火，会拒绝被保护 |

### 5.3 反派（要强，且动机合理）

| 反派 | 强在哪 | 动机 |
|---|---|---|
| **韩度** | 他的判断在规则层面**是对的** | 他签过主角父亲的名字，他不想再签第二个 |
| **闻人驭** | 处理过 41 个，从未失手 | 他不只是在执行，**他在害怕**——怕有一天自己出现在名单上 |
| **收割者** | 上一个文明的变量 | （卷三揭晓） |

> **一句定调**：**他们不是坏人，他们是这套规则里最尽职的人。** 主角要赢的不是他们，是规则。

## 六、情节框架（卷纲——方法论说「卷纲的意义大过大纲」）

### 第一卷 ·《不可培养》

| 阶段 | 章 | 剧情链 |
|---|---|---|
| **入局** | 01–04 | 判废 → 净场十八次 → 发现靠输变强 → 决定报名地宫 |
| **立足** | 05–09 | 地宫首次翻命救全队 → 被拾荒者注意到 → 老周给出关键情报 → 复查被拒 |
| **抬头** | 10–12 | 索道取胜但被系统记录 → 救裴战 → 回声市场拿到名单（**第一行是 000416**） |
| **打压** | 13–15 | 闻人驭登场 → 苏青停职 → 妹妹被带走，一无所有 |
| **翻盘** | 16–20 | 回净场读懂刻痕 → 站台改规则 → 围猎反杀 → 听证 → **改判，把闸门卡住** |

**卷末状态**：他不是赢了，是**卡住了闸门**。他的清退程序停在半空，他也从弃民变成了"名册上最危险的人"。

### 第二卷 ·《第 9 个》

| 阶段 | 剧情链 |
|---|---|
| **出狱** | 从序列营出来，身份从"待清退"变成"待观察"；宿配额到手，妹妹搬进来 |
| **追查** | 开始查父亲 416 的档案 → 发现九年来有 **8 个"六维全 1"**，全部死亡 |
| **痕迹** | 8 个人各留下一句话，散落在 8 个不同的副本里。他开始一趟一趟地找 |
| **有人抢先** | 闻人驭也在找这些痕迹——**而且他比主角早三年** |
| **卷末** | 他找到第 8 个的遗物：**他父亲的编号牌**。上面刻着下一句提示 |

### 第三卷 ·《收割者》

| 阶段 | 剧情链 |
|---|---|
| **失衡** | 综网开始衰减，副本失控，真实世界副本比例激增 |
| **现身** | 收割者出现——它是第八个文明的那个变量，已经和"筛子"融为一体 |
| **真相** | 它告诉主角：**这不是筛选，是喂养。** 每个文明的变量最终都成为它的一部分；而它之所以一直"帮"主角，是因为它想吃掉一个比它更强的 |
| **前八个** | 前八个都死在第 8 步——他们选择了拒绝，然后被吃掉 |
| **卷末选择** | 主角做出第三个选择（前两个是"接受"和"拒绝"） |

### 第四卷 ·《改判》

| 阶段 | 剧情链 |
|---|---|
| **联合** | 拾荒者、铜镜小队、部分序列人（包括动摇的闻人驭）站到他这边 |
| **对抗** | 与收割者/筛子的最终对抗 |
| **武器的本质** | 他的武器不是力量——是**改写一条判定**。而这次的判定，是整个地球的"评估结果" |
| **结局** | 他不能删除规则（那是"边界之外"的事），但他能**改一条**——把"清退"改成别的什么 |
| **收尾** | 妹妹问他：改完了吗？他说：改了一条。 |
