## 三、三大发现（对本书设定的实质影响）

### 发现一：「数据化」——它解释了「该账号不适用常规评估」

**实证原文**（《轮回规则书 4.4》）：

> 「数据化是轮回中枢的重要功能之一，它的作用是将轮回者的各项机能核对并**转化成相当于其将会进入的那个位面的数值**……例如即便你之前是可以以一敌百的猛将，在被收入轮回中枢之后，都将会被统一移除生前的技艺，身体机能也会被数据化成基本的模板。**这样做其实并不是限制轮回者自身的力量，而是在保护**——可能会有**数据超标的轮回者与中枢系统产生序列冲突而导致意外死亡**的情况发生。」

这段话解决了本书三个悬而未决的问题：

| 本书的既有设定 | 由「数据化」得到的解释 |
|---|---|
| 原文条款：**「这游戏初期会压制高等级玩家的实力」** | 压制不是为了平衡，是为了**保护**——数据超标者会与中枢发生「序列冲突」而意外死亡 |
| 「该账号不适用常规评估」（F1 伏笔） | 陆沉的问题**不是数据超标，是低标到无法被数据化**。系统的评估程序拿到的是一份**无法映射成任何位面数值**的机能表 → 评估失败 |
| 逆命者为何是「补偿机制」（N5） | 数据化失败意味着他**无法进入常规评估链路**。系统必须给他一条**链外通道**——这就是逆命者 |

> **写作价值**：这是全书金手指最深层、也最冷酷的一层解释——**他不是被偏爱，他是被"另案处理"了。**

### 发现二：「资历值」——它解释了「不可培养」

**实证原文**（《变量之轮 v1.2.0》）：

> 「**资历值**是衡量角色综合能力水平的数值，当角色**消耗经验值时**，消耗的经验值就会变成资历值计算在角色卡面板上面……玩家报名进入一次变量之轮时，主持人往往可以通过角色的**资历值**和玩家自身的数据与装备来**判定其战斗力是否符合这个干涉任务的难度等级**。」

**推论**：资历值由**消耗掉的**经验值转化而来——花了才算数。

**应用到本书**：

| 设定 | 内容 |
|---|---|
| 综网引入「资历」 | 判定战斗力的官方尺度，由消耗的经验值转化 |
| **陆沉的资历** | **永远是 0**。他属性全 1，学不了技能（技能检定基于属性），属性抽选对他是浪费——**他没有地方可以消耗经验值** |
| 后果 | 系统拿资历值评估他，永远得到 0 → 永远判定「不可培养」 |
| 第 19 章的兑现 | 他升到 5 级、总和越过 30 之后，**第一次有地方消耗经验值** → 资历值第一次不是 0 |

> **这补上了世界观最后一块拼图**：第 01 章韩度那句「不可培养，建议清退」，**不是官僚的偏见，是系统的输出**。

### 发现三：「负载值／背包格」——它把「宿＝0」落到了实处

**实证原文**（《回廊 v1.13》）：
> 装备按**负载值**分五档：劣旧（<5）／凡物（5-10，伤害至多 1D6）／精良（10-20）／非凡（20-30）／传说（30-50，伤害至多 8D6+X）。**内置装备需要对应等级的专精评级才能带出。**

**实证原文**（《惊悚乐园 2.0》）：
> 「人物有一个**空间背包，共有 10 格**……人物在自己的个人空间里有一个 **20 格的仓库**。」

**应用到本书**：

| 项目 | 设计 |
|---|---|
| 综网的背包装载 | 由**力量**决定负重上限 |
| **陆沉的负重** | 力量 1 → **负重上限几乎为零**。他捡到好东西也**背不动** |
| 这解释了什么 | 他全卷只有三件随身物（编号牌、纸、户籍卡），不是穷，是**背不动** |
| 与金手指的咬合 | **「逆命之刃」不占负重**——它是「承受过的失败」的具现，属于**超限界物品**（借《惊悚乐园》概念：牵涉因果律） |
| 宿的配额 | 0 格背包 ＋ 0 立方米宿 → 第 19 章后：**0.27 立方千米 ＋ 20 格仓库** |

## 四、值得补强的四点（均据实读推导）

| # | 借鉴源 | 补强内容 | 用于本书 |
|---|---|---|---|
| 1 | 《无限恐怖》**20 扇门**、《回廊》**守门人** | 综网需要一个「引导者」机制：**陆沉的引导者是空白的**（配额 0 的延伸）。别人的引导者给任务提示，他的引导者那一栏是 `【—】` | 第 16 章（他发现这件事） |
| 2 | 《变量之轮》**SAN 值**＋「心智保护机制是**防止损耗量过高、高阶者产生速度不及需求**」 | 综网的「认知影响」条款（原文 9.3 条）背后是**资产保值**，不是善意。血腥场景的免疫是**维护成本控制** | 第 18 章（一句冷描写即可） |
| 3 | 《深空无限》**血统的适应期／进化条件** | 逆命者的等级提升可设「适应期」：升级后 24 小时内不能再升 | 第 19 章 |
| 4 | 《王牌进化》**反刷怪**（多杀同阶怪则掉率 −10%） | 逆命值的**同类失败递减**：同一副本内重复同一种大失败，结算点数逐次减半 | 修正 `07_副本设计卡` 的账本（**这条必须加**，否则「反复送死」可以无限刷） |

> **第 4 条是本次校验发现的一个真实漏洞**：现有设计里，陆沉只要在净场反复挨打就能稳定拿 +3。必须补上递减规则，否则金手指会失去张力。

## 五、横向对照：综网设定在无限流谱系中的位置

| 维度 | 主流无限流共识（24 部中 ≥14 部） | 综网 | 判定 |
|---|---|---|---|
| 入场不可拒绝 | ✅ | ✅ 接入即绑定，隐性确认 | 一致 |
| 中转空间 | ✅ 白色/中立/安全 | ✅ 登陆空间（星界切片） | 一致 |
| 双轨经济（货币＋经验） | ✅ 21/24 | ✅ 积分 ＋ 经验值 | 一致 |
| 兑换物分类 | 科技／魔法／辅助／娱乐（《无限口述》） | 道具／技能／情报／权限 | **差异化**：多了「情报」与「权限」 |
| 死亡分层 | 多数为真死（《曲面世界》例外：可复活） | 三层（教程／投影不死，真实世界死） | **差异化** |
| 破限机制 | 基因锁／血统／潜能（14 部有） | **逆命者** | **核心差异化** |
| 强化地点限制 | ✅「只有回到变量之轮才能强化」（《变量之轮》） | ✅ 回登陆空间才能兑换 | 一致 |
| 个人空间 | ✅（27 立方千米／20 格仓库） | **宿，配额 0** | 一致机制 + **差异化的用法** |
| 选人标准 | 「低谷／赴死前／参透真理时」（《轮回 4.4》） | 全体十八岁人类 | **差异化**（需要补动机，见下） |

**一处需要补的动机**：主流无限流都回答了「为什么选中我」。综网目前是「无筛选」，缺少动机。**建议**：L2「接入日」揭晓——综网接入地球，恰好在人类历史的最低点（这是千层饼第二层的兑现）。

## 六、结论

1. **设定骨架无须改动**：24 部规则书横比之下，综网的核心结构（不可拒绝的入场／中转空间／双轨经济／兑换限制／死亡分层）**全部落在无限流的共识区间内**。
2. **两处差异化是卖点而非缺陷**：破限机制（逆命者）与死亡分层。
3. **三处机制空白已获填补**：「数据化」解释异常，「资历值」解释不可培养，「负载值」解释宿＝0。
4. **发现并修补一个真实漏洞**：逆命值缺少「同类失败递减」规则，需补入（见第四节第 4 条）。
5. **提取通路已全部验证**：CHM／PDF／DOCX／DOC／ZIP 五类格式的取证方法均已跑通并可复用，后续任何规则书都能按同一流程实读。
