# 10 · 装备与道具品级

> **补位说明**：本编号此前空缺。现用于承接 `19_设定完备性自检` 的 **P1-3（装备品级体系）**。

## 一、品级体系：**装备品级与户籍等级严格对应**

> 这是本书最重要的一条经济设计——**你的装备上限，由你的阶层决定。**
> 不是你买不起，是**更高级的装备根本不向你开放**。

| 品级 | 俗称 | 谁在用 | 附加属性 | 技能 | 获取途径 |
|---|---|---|---|---|---|
| **F** | **废件** | 丙等底层 | 无，且属性不稳（每次副本随机浮动） | 无 | 副本残骸里捡的 |
| **D** | **白件** | 丙等标准 | 无 | 无 | 商城 / 掉落（1–7 档） |
| **C** | **蓝件** | 丙等精英 / 乙等 | **1 条** | 无 | 掉落（8–10 档）/ 素材加工 |
| **B** | **金件** | 乙等 | 2–3 条 | **1 个** | 精英掉落 |
| **A** | **序列件** | 甲等 | 3 条以上 | 2–3 个 | **与身份绑定，不可转让** |
| **S** | **唯一件** | 传说 | 不适用 | 不适用 | 全世界只有一件 |

### 关键限制

| 限制 | 内容 |
|---|---|
| **开箱限制** | 拿到的装备若高于本人可用的最高品级，**无法装备**——面板会提示 `【您当前的权限等级不足以激活此物品。】` |
| **不可出售** | 装备**不能卖给商城**，只能**分解成素材**（借自《轮回 3.82》：道具由数据序列构成） |
| **不可转让** | A 级以上与身份绑定。**这是甲等与乙等之间真正的墙** |
| **负重** | 由**力量**决定。陆沉力量 1 → 负重上限 ≈ 0 |

### 分解产出表

| 分解 | 产出 |
|---|---|
| F 废件 | 0（直接丢） |
| D 白件 | 1 素材 |
| C 蓝件 | 3 素材 |
| B 金件 | 10 素材 + 1 枚钥匙残片 |
| A 序列件 | **不可分解**（绑定物） |

> **经济意义**：一个丙等玩家打完副本，最好的变现方式是**把装备拆了卖素材**。
> 而素材价是成品的**三成**——**这套规则就是设计来让底层攒不起钱的。**

## 二、陆沉的装备现状（关键：他一件都没有）

| 项 | 情况 |
|---|---|
| 装备栏 | **空**。不是不穿，是**没有能穿的**——他能拿动的只有一块石头 |
| 随身物 | 父亲的编号牌｜妹妹给的包子纸袋｜写着五条规则的纸 |
| 唯一的"武器" | **逆命之刃**（第 11 章获得） |

### 逆命之刃的特殊性

| 项 | 说明 |
|---|---|
| 性质 | **超限界物品**（借《惊悚乐园》概念：牵涉因果律的物品） |
| 品级 | **无品级**——因为它不是装备，是**他承受过的失败的具现** |
| 重量 | **0**。不占负重 |
| 限制 | 只能在逆命值 ≥ 20 时具现，且用完即散 |
| 为什么重要 | **这是全书唯一一件"阶层规则管不到的东西"**——它不属于 F 到 S 的任何一级 |

> **设计意图**：陆沉全身家当都是"归零"的——宿 0 立方米、负重 0、装备栏空、称号栏空。
> **而他的武器也是"0 重量"。** 这套符号是统一的：**他一无所有，所以他不受约束。**

## 三、素材与加工

| 概念 | 内容 |
|---|---|
| 素材 | 装备分解后的产物；也是副本的主要掉落物 |
| 加工 | 素材 + 工艺等级 → 装备。**工艺等级由户籍等级决定** |
| 成品率 | 丙等工艺：60%；乙等：80%；甲等：95% |
| 代工 | 西市场有代工点，抽成 30%（**九斤认识几个**） |

> **丙等的死循环**：分解拿素材（三成价）→ 加工要抽成（30%）→ 成品率只有 60%。
> **所以丙等玩家的装备永远是"捡来的"，不是"做出来的"。**

## 四、与掉落表的衔接（`15` 号文档）

`15` 的 d10 掉落表用的是"白装/蓝装"俗称，对应关系：

| d10 | 掉落 | 对应品级 |
|---|---|---|
| 1–2 | 白装 + 少量素材 | **D** |
| 3 | 白装 + 贵重品 + 未知材料 | **D** |
| 4–6 | 白装 + 贵重品 + 恢复药剂 + 未知材料 | **D** |
| 7 | 白装（+3/+4）+ 贵重品 + 恢复药剂 | **D（强化）** |
| 8–9 | 蓝装（1 条附加属性） | **C** |
| 10 | 蓝装（2 条附加属性 + 1 个技能） | **C（近 B）** |
| 精英 | 金件 | **B** |
| 小 BOSS | 银色剧情装备 | **B（剧情绑定）** |

> **注意**：**普通玩家一辈子摸不到 A 级**。因为 A 级不靠掉落——**它是发给甲等的身份配给。**

## 五、这条设定解决的问题

| 之前的问题 | 现在 |
|---|---|
| 有掉落表但没品级规则 | ✅ F–S 六级 + 开箱限制 |
| 主角"穷"缺少机制解释 | ✅ 装备不可出售 + 分解只值三成 + 代工抽成 30% + 成品率 60% |
| 阶层差异只体现在属性上 | ✅ **装备上限由阶层决定**——这是看得见摸得着的墙 |
| 逆命之刃的定位模糊 | ✅ 无品级、零重量、不属任何一级——**阶层规则管不到的东西** |
