## 一、综网术语表

### 1.1 机构与体系

| 术语 | 含义 | 备注 |
|---|---|---|
| **综网** | 多元宇宙综合游戏网络，覆盖多个位面与文明 | 运营方为「地狱之下」 |
| **地狱之下** | 综网运营公司（对外名称） | 玩家口中的「那家」 |
| **登陆空间** | 进入游戏的中转空间；入场表现为封闭空间向下急坠 | 全白，无窗 |
| **评定署** | 主世界负责属性评定、户籍、清退序列执行的官方机构 | 各区设点 |
| **清退序列管理司** | 负责清退序列的统一处置 | 名称自带回避感 |
| **副本管理局** | 负责副本推送、准入许可、死亡登记 | 环带 |
| **防卫署** | 负责监控宇宙信号、深空实体 | 沿用《通宵杀敌》原作设定 |
| **平衡稳定署** | 负责应对大规模灾害事件的机构 | 沿用原作设定 |
| **综网序列** | 官方玩家序列组织；下设「异常行为调查科」 | 闻人驭所属 |
| **序列营** | 清退序列待复核人员的临时安置区 | 「只进不出」 |

### 1.2 规则机制

| 术语 | 含义 |
|---|---|
| **面板** | 属性面板。每人独有，可被官方查询 |
| **属性** | 力量／敏捷／体质／智力／魅力／感知，1~20，10 为常人平均 |
| **修正值** | `(属性值 − 10) ÷ 2`，向下取整 |
| **检定** | `2d6 + 修正值` 对比目标值 |
| **目标值（DC）** | 6 容易／10 普通／15 困难／20 极难 |
| **大成功／大失败** | `总值 ≥ DC + 5` / `总值 ≤ DC − 5`，均可能带来超出预期的额外效果 |
| **优势／劣势** | 掷两次取高／取低 |
| **对抗检定** | 双方各掷，高者胜；平局维持现状 |
| **阶层** | 阶层一 1-4 级／阶层二 5-10 级／阶层三 11-16 级／阶层四 17-20 级 |
| **遭遇** | 副本的基本单元，＝一个目标 + 一个障碍 |
| **轮** | 战斗与社交遭遇的时间单位，＝游戏世界内 6 秒 |
| **投影世界副本** | 死亡不带来真正死亡的副本 |
| **真实世界副本** | 死亡不可逆的副本 |

### 1.3 玩家口语（写对话时使用）

| 口语 | 含义 |
|---|---|
| **清退** | 被取消户籍、编入处置名单；玩家圈里等同于「死」，但比死更难听 |
| **开箱** | 副本掉落 |
| **掉队** | 等级长期停滞，**也指三年大重排里被划下去的人** |
| **拾荒** | 只做低阶副本赚小钱 |
| **兜底** | 面板好，做事有容错 |
| **萌新／纯萌新** | 新玩家／连条款都没看的新玩家（后者带贬义） |
| **在册** | 姓名还在综网名册上；反义为「名册之外」 |
| **拾荒者** | 西市场一带低阶玩家自发互助网络的身份。不是组织——没有名称、首领与章程 |
| **铜镜朝下** | 拾荒者的接头暗语。也是那一句立场：**「我们不反对这规矩。我们只是在这规矩底下，尽量多留几个人。」** |
| **异常账号** | 综网序列的官方术语，指"不适用常规评估"的账号。九年来出现过 8 个，全部死亡。**第 9 个是陆沉** |

| **宿** | 综网分配给玩家的**私人空间配额**。默认值为 **0**（新账号无配额）。**陆沉初始为 0 立方米**，第 19 章升至 5 级后更新为 **0.27 立方千米**。空间内是**与净场同一种灰**，无光源却明亮，脚步声会在**对面**被还回来（实为空间随人移动）。**与净场相反：这里的灰会留下痕迹。** |

### 1.4 社会硬规则（世界设定，非口语）

> 这些是第 01 章就已出现、但此前未成文的规则。**写正文时必须遵守。**

| 规则 | 内容 |
|---|---|
| **属性 ↔ 寿命** | 综网把「寿命」折算进了面板：**属性偏低者的医疗配额与寿命上限被压缩**。第三区的常识是——**能不能被允许活到四十岁，看的是评定结果**（第 01 章） |
| **户籍即权限** | 甲等住城心／乙等住环带／丙等住外区；**通行、婚育、教育、副本准入**全部挂钩 |
| **装备上限由户籍决定** | 明细见 `10_装备与道具品级` |
| **属性修正公式** | **修正 = ⌊(属性值 − 10) ÷ 2⌋**（12→+1，14→+2，1→−5） |
| **先攻判定** | 使用**敏捷**检定（详见 `00_设定提取` 的「本书口径」；察觉用于判定是否被突袭） |
| **死亡分层** | 新手教程与投影世界副本不判死；**真实世界副本死亡不可逆** |

### 2.2 综网商城常规道具（写作时可随手调用）

| 道具 | 价格 | 效果 |
|---|---|---|
| **凝血针剂** | 15 积分 | 立即止血，不恢复生命值 |
| **短效增益符** | 60 积分 | 一次检定取优势 |
| **侦察鸦** | 120 积分 | 侦查一片区域，持续 10 分钟 |
| **属性抽选券** | 800 积分 | 一次属性抽选机会（升 1 点） |
| **户品升级申请** | 500 积分 | 丙等 → 乙等（**九斤的目标**） |

> **阶层感设计**：陆沉全家最贵的东西是一张 60 积分的增益符——他从来没买过。而裴战进副本时随手带三张。

### 2.3 生活层物价（第三区 · 丙等）

| 项目 | 价格 |
|---|---|
| 一人一天伙食 | **1** |
| 一份红烧牛排面（泡面） | 0.5 |
| 第三区公寓月租 | 30 |
| 小孩一学期学费 | 15 |
| 一件像样的冬衣 | 8 |
| 妹妹的作业本（一学期） | 2 |

> **核心换算**：陆沉家全部积蓄 **34 积分 ≈ 一个月的伙食费**（第 03 章）。
> 而户籍升级要 500 积分——**靠打副本要攒十个月**。
> **所以"变强"在这个世界里从来不是努力问题，是阶层问题。**

### 2.4 掉落与回收

| 项 | 规则 |
|---|---|
| 装备出售 | **不可出售**，只能分解成素材（明细见 `10_装备与道具品级`） |
| 空间回收 | 普通道具**半价**回收 |
| 副本通关结算 | **30–80 积分**（视完成度） |
| 商城修复重伤 | **3000 积分** ← **母亲当年凑不齐的那个数字** |

### 4.2 高阶怪物（第二卷起·沿用《通宵杀敌》原作设定）

| 名称 | 评级 | 设定要点 |
|---|---|---|
| **菌斗兽** | D | 由血浆中生出：血浆涌出 → 鼓泡 → 灰白丝状物遇空气疯长 → 织成网状 → 成型。约两米高，无五官，菌膜下有暗红脉动。攻击方式为**贴脸吸取生命**。成型后血浆会再次涌出生成新个体 |
| **斯兰达人** | A | 无面部特征、身着灰色僧袍的类人生物，常出没于荒原；撑伞戴帽，步伐平稳；掌握**远古魔法符文**；可随意拉伸四肢、改变大小；头部永远是空白，带来「纯粹的、赤裸的注视」感 |

## 六、面板文案规范（强制）

### 6.1 格式要求

1. 一律用 `【】` 包裹标题行，正文为纯文本；
2. **不加任何情绪化修饰**——系统从不安慰、从不恐吓、从不感叹；
3. 检定块的固定格式（字段顺序不可变）：

```
【XX检定 · 目标值 N（难度名）】
掷骰：2d6 = X
修正：±N
结果：X
判定：成功 / 失败 / 大成功 / 大失败
```

4. 数值一律用阿拉伯数字；
5. 系统提示**从不解释原因**。「原因」永远是主角自己算出来的。

### 6.2 反例（禁止）

| ❌ 错误写法 | 原因 |
|---|---|
| `【警告！你太弱了，快跑吧！】` | 情绪化、拟人化 |
| `【恭喜宿主获得逆天能力】` | 网络小说套话，与综网的冷硬腔调冲突 |
| `【检测到危险，建议立即撤离】` | 系统不给建议（明确写在条款里：「系统不承担告知责任」） |

### 6.3 正例

```
【感知检定 · 目标值 10（普通难度）】
掷骰：2d6 = 7
修正：−5
结果：2
判定：失败
```

```
【逆命值 +3】
【逆命值：7 / 10】
```

```
【该账号不适用常规评估。】
```
