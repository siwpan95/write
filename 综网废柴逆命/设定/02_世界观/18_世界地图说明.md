# 18 · 地图说明（莲花结构图 ＋ 地理志地图）

> 文件：`世界地图.html`（结构维度）、`地理志地图.html`（地理维度）
> 两份都是单文件、零外部依赖（地理志地图仅依赖腾讯地图官方 SDK）。

---

## 一、它是什么

一个把设定库 **00-17 号全部文档**串起来的地图，六个视图对应六个维度：

| 标签页 | 串起了什么 | 主要来源文档 |
|---|---|---|
| **世界地图** | 莲花结构：花芯「狱」＋ 8 张花瓣地图 ＋ 阶层圈层 ＋ 连线（回花芯） | 05、07 |
| **位面结构** | 六大位面分类，及每张花瓣地图的位面归属 | 14 |
| **历史千层饼** | L4→L0 五层历史，含"关联活人"与"回收章" | 05、04 |
| **怪物谱系** | 13 个谱系 ＋ 未归档，含弱点规律与各阶层怪物池 | 12 |
| **人物关系** | 陆沉为中心的 10 个角色，点开含属性面板与台词 | 06 |
| **逆命值账本** | 20 章结余折线图 ＋ 逐章账表（含节拍定位） | 07、08 |

---

## 二、怎么用

1. **切换视图**：点顶栏标签。
2. **查看详情**：点任意节点 / 卡片 / 谱系格，右侧栏显示完整设定。
3. **读地图**：虚线椭圆由内到外＝阶层一 / 二 / 三·四；花瓣到花芯的连线表示「每次离开花瓣都必须回花芯」——这是莲花地图法的核心约束。

---

## 三、设计上的两处取舍

1. **为什么用莲花布局而不是地理图**：本书的地图本来就不是地理概念，而是「综网按位面推送副本」的结构。莲花地图法（宅猪）正好把"中心—花瓣—回中心"的关系画出来了，比画一张大陆图更忠实于设定。
2. **为什么零依赖**：不用任何 CDN，避免离线打不开或版本失效；全部图形用内联 SVG 手绘。

## 五、地理志地图（地理维度，另一份文件）

| 项目 | 内容 |
|---|---|
| 文件 | `地理志地图.html` |
| 底图 | **腾讯地图**（合规白名单内；领土要素符合国家标准） |
| 图层 | 全国 9 个接入区标记 ＋ 第三区 5 层同心圆 ＋ 6 个地点标记 |
| 两个视图 | 全国 · 接入区划（zoom 5）／第三区 · 空间层级（zoom 12） |
| 交互 | 点标记或圆环 → 右侧栏显示详情；右上角切换视图 |

### 与莲花地图的分工

- **莲花结构图**回答「综网怎么组织」——花芯／花瓣／位面推送；
- **地理志地图**回答「它铺在什么地面上」——第三区在哪、城心离它多远、序列营在哪个方向。

### 合规说明（重要）

| 项 | 做法 |
|---|---|
| 地图服务商 | 仅用**腾讯地图**官方 SDK；未引入任何其它服务商 |
| 底图改动 | **零改动**——不修改边界、地名、领土要素 |
| 虚构内容 | 仅以「标记点」与「圆环」形式**叠加**于底图之上 |
| API key | 前端**零密钥**，走 WorkBuddy 运行时代理（`_TMapSecurityConfig`） |
| 打不开时 | 腾讯地图 API **不支持 `file://` 协议**——须通过 WorkBuddy 内置预览（http）打开；用 file 打开时页面会给出明确提示，且设定内容仍可在右侧栏查看 |

### 为什么没有直接用你给的那三个站点

| 站点 | 性质 | 结论 |
|---|---|---|
| **makeamap.cn**（易制地图） | 手工绘图工具（架空世界／真实世界截取），不是地图服务商 | 合规上无障碍，但它需要登录操作，我无法代你作图——**更适合你后续自己拿去做手工微调** |
| **bzdt.ch.mnr.gov.cn**（标准地图服务） | 官方标准地图下载（jpg／eps） | 底图本身最权威，但官方明确写着「对地图内容编辑（包括放大、缩小和裁切）改动的，**公开使用前需要送自然资源主管部门审核**」——不适合做成"魔改版" |
| axhub.im/maps | 未核实其服务性质 | 未纳入 |
