# 15 · 副本随机生成表（d20 工具集）

> **用途**：当「知道大纲、但不知道这一章具体写什么」时，摇六次骰子，把结果填进 `07_首卷副本设计卡` 的四件套里，即可开写。
> 所有条目均与 `12_怪物谱系`、`13_状态表`、`14_位面体系` 兼容。

---

## 使用流程（写一章前做六次掷骰）

| 次序 | 摇什么 | 得到 |
|---|---|---|
| ① | 副本类型表 | 这一章的玩法骨架 |
| ② | 位面属性表 | 这一章的"世界的敌意" |
| ③ | 副本特殊规则表 | **本章的核心机制**（放进副本卡第三行） |
| ④ | 怪物遭遇表 | 派谁上场 |
| ⑤ | NPC 动机表 | 让 NPC 有目的，不当工具人 |
| ⑥ | 失败代价表 | 陆沉这次会失去什么 |

> 若摇出的结果与已有设定冲突，**以已有设定为准，重摇**——表是工具，不是法律。

## 表三 · d20 副本特殊规则（**本章核心机制**）

> 规则永远**优先于通用规则**（条款第 4.3 条）。这是全书「机制反转」爽点的合法来源。

| d20 | 特殊规则 |
|---|---|
| 1 | 本副本内一切视觉类检定取劣势 |
| 2 | 声音放大十倍，任何巨响触发一次全区怪物警觉 |
| 3 | 每经过固定间隔，副本难度提升一档 |
| 4 | 不可使用暴力——任何攻击检定自动大失败 |
| 5 | NPC 只回答**已经被问过的问题** |
| 6 | 每问一个问题，须付出一样带不回来的东西（记忆／名字／习惯） |
| 7 | 本副本不判定死亡，生命归零即重置至入口 |
| 8 | 同一检定重复尝试取劣势（禁止暴力试错） |
| 9 | **本副本内所有检定取劣势**——对陆沉反而有利 |
| 10 | 只结算存活时间，不结算击杀数 |
| 11 | 每有一人死亡，全场所有人下次检定取一次劣势 |
| 12 | 站台上有一台可改写的公告屏，改哪条规则就变哪条，**每次只能改一条** |
| 13 | 被追猎方**无法攻击**追猎者，只能躲避与设陷 |
| 14 | 每 N 分钟必须换乘／换位一次 |
| 15 | 某一种伤害类型完全免疫（按谱系决定） |
| 16 | 一切治疗手段失效 |
| 17 | 地图按固定间隔重排 |
| 18 | **在场有一个 NPC 在说谎，但不知道是哪一个** |
| 19 | 通关条件不是杀光，是找到某件东西并带出来 |
| 20 | 副本内时间流速与外界不同 |

## 表九 · d12 陆沉的"非金手指解法"（防止每章都靠翻命）

| 3 | 靠利用副本的位面属性 |
| 4 | 靠一句把对手算穿的话 |
| 5 | 靠放弃（主动弃掉一个目标，换整体） |

| 7 | 靠别人教他的一件小事 |

## 表十 · d10 钥匙掉落分档（借自《王牌进化 2.4》）

> 副本通关或击杀精英后掉落「钥匙」，**钥匙的骰值决定掉落品质**。写作时掷 d10。

| d10 | 品质 | 掉落内容 |
|---|---|---|
| 1-2 | 下等 | 一件白装 + 少量素材 |
| 3 | 下等＋ | 白装 + 贵重品 + 未知材料 |
| 4-6 | 中等 | 白装 + 贵重品 + 恢复药剂 + 未知材料 |
| 7 | 中等＋ | 白装（+3/+4）+ 贵重品 + 恢复药剂 + 未知材料 |
| 8-9 | 上等 | **蓝装**（含 1 条附加属性）+ 贵重品 + 恢复药剂 |
| 10 | 极品 | **蓝装**（含 2 条附加属性 + 1 个技能）+ E/D 级道具 |

**分级对应**：小怪最高蓝装；精英亮金；小 BOSS 银色剧情装备。

**与本书的咬合**：
- **陆沉几乎永远掷出 1-2**（因为他的检定修正 −5，掉落判定同样受修正影响）——但他并不在乎，因为**他的成长不靠掉落**。
- 反面用法：**裴战的运气好**，所以他的装备一直比陆沉好——这是"面板替你兜底"的最好物证。
- **注意**：装备**不能出售，只能分解成素材**（借自《轮回 3.82》），所以丙等玩家没有变现渠道。

## 附：一次完整的掷骰示例

**任务**：生成第 09 章（复查）之后的一场副本。

| 次序 | 掷出 | 结果 |
|---|---|---|
| ① 类型 | 13 | 综合／混合型 |
| ② 位面属性 | 2 | 声音异常（放大／消音） |
| ③ 特殊规则 | 8 | 同一检定重复尝试取劣势 |
| ④ 怪物 | 7 | 异怪 1 只，弱点需现场观察 |
| ⑤ NPC 动机 | 3 | 想完成一件九年前没做完的事 |
| ⑥ 失败代价 | 12 | 力竭 +1 |
| ⑦ 解法 | 1 | 靠认出怪物谱系，预判本能 |

**生成结果**：一场混合型副本，位面声音异常；规则禁止暴力试错（重复检定取劣势）；对手是一只弱点不明的异怪；有一名 NPC 执着于完成九年前的事（**自动接上 L2 接入日的线**）；陆沉靠认出它的谱系本能取胜。代价是力竭 +1。

> **注**：③ 的「重复尝试取劣势」与陆沉的处境高度契合——普通人靠试错，他连试错的资格都没有。所以他会**靠观察一次成型**，这正是他人设的机制化表达。
