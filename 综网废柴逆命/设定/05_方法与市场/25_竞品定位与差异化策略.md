# 25 · 竞品定位与差异化策略

> **缘起**：作者指出「综网流开山怪就是易伤秋者」，并给出起点在售作品链接。
> 本文件是对**综网流**这一成熟流派的调研，以及本书的定位判断。
> ⚠️ 结论：**"综网"不是一个自造词，是一个有开山作、有稳定读者群的起点流派**——这既带来风险，也是机会。

---

## 一、调研发现：综网流是一个成熟流派

### 1.1 开山怪：易伤秋者（阅文 Lv.5 作家）

| 作品 | 主角 | 状态 | 字数 |
|---|---|---|---|
| **《光头武僧在都市》** | 易秋 | 完结 | 241 万字 |
| **《都市的变形德鲁伊》** | — | 完结 | — |
| **《综网的巫：从艾泽拉斯吃到山海经》** | 易夏 | 完结（1740 章） | 346.75 万字 |
| **《综网：终焉的守望之无尽词缀》** | 守望者 | 完本（861 章） | 162.99 万字 |
| **《综网：从速刷打灰开始的战斗天选》** | 易青锋 | **连载中（591 章）** | 140.82 万字 |

**注意两点**：
1. **主角统一姓「易」**——这是一个系列宇宙（易秋／易夏／易青锋）
2. **书名格式就是「综网：XXX」，起点完全允许冒号**（我此前的"全角冒号不合规"判断**错误**，已撤回）

### 1.2 "综网"的定义（源自开山作）

> 「连入《多元宇宙综合游戏网络》(以下简称《综网》)成功，正在读取版本信息……」
> 「应推荐者要求，《综网》版本设定为：**短生种的逆袭之血脉崛起**。」

**综网 = 多元宇宙综合游戏网络**。它的接入是一种**半自愿的仪式**（论坛帖子里口胡选职业 → 第二天面板真的出现）。

### 1.3 综网流的核心机制（读者的既有预期）

| 机制 | 说明 |
|---|---|
| **版本设定** | 每个玩家／文明绑定一个「版本」，规则差异构成身份标识（如"终焉的守望之无尽词缀"） |
| **职业锁定** | 接入时锁定一个职业（武僧／圣骑士／巫觋／奇械师……） |
| **副本系统** | 每日副本、随机副本天赋群、跨位面猎场 |
| **综网论坛 / 交易板块** | **玩家互动是核心**——论坛发帖、交易、组队 |
| **成长模块** | 词缀、血脉模组、概念建筑、限定版本事件 |
| **货币** | 综网灾币、贡献点 |
| **空间结构** | **主世界（大本营：休整、交易、领地建设）+ 任务世界（资源猎场）** |

### 1.4 综网流 vs 无限流（流派自我界定）

> 「与传统的无限流不同，**综网流更强调玩家之间的互动，以及主世界与任务世界的联系**。主世界是玩家的大本营，用于休整、交易与领地建设，而任务世界则是获取资源的猎场。」

**当代综网流代表作**（说明赛道已拥挤）：
《综网：我的道兵，皆为神明》（道兵养成）｜《综网：泰拉瑞亚的奇械领主》（科技种田）｜《综网：副本仙人的飞升之旅》（副本制造）

### 1.5 流派的调性

从代表作评价可见读者的口味：
- 「**文青作者，明明是杀伐果断的主角，但作者文笔总是给人一种治愈的感觉**」
- 「主角乃一代**钢筋混凝土直男**」
- 大量**美食、吐槽、论坛弹幕**桥段
- 核心爽点是**信息差 + 跨界套利 + 日常幽默**

## 二、风险与机会（对照分析）

### 2.1 本书与综网流的差异——**几乎每一项都是反的**

| 维度 | 综网流（主流） | **本书** |
|---|---|---|
| **接入方式** | 半自愿（论坛口胡） | **强制**——全体满 18 岁人类 |
| **综网的本质** | 游戏平台 | **筛选器**（并且有阴谋） |
| **社会结构** | 现实基本照旧，主角个人变强 | **阶层重构**：等级即户籍、装备上限、寿命 |
| **主角起点** | 选一个强力职业 | **六维全 1，无职业** |
| **成长逻辑** | 打副本变强 | **靠输变强** |
| **玩家互动** | **核心爽点**（论坛/交易/组队） | **几乎没有**（主角是独狼） |
| **基调** | 轻松、治愈、美食、吐槽 | **冷硬、压迫、代价** |
| **主角姓氏** | 易（系列宇宙） | 陆 |

> **一句话**：本书是**用综网流的框架，写了一个反综网流的故事**。

### 2.2 风险

| 风险 | 说明 |
|---|---|
| **认知错位** | 书名「综网：XXX」会让读者按轻松向期待，开篇三章的冷硬可能劝退 |
| **流派审查** | 综网流老读者可能评价"这不算综网文"（因为没有论坛、没有交易套利、没有日常） |
| **冒号书名的借势反噬** | 借用格式有流量，但也有"蹭开山怪"的观感 |

### 2.3 机会

| 机会 | 说明 |
|---|---|
| **现成读者群** | 综网流已有稳定受众，搜索"综网"能进池子 |
| **差异化蓝海** | 综网流作品清一色轻松向；**"冷硬反乌托邦版综网"目前无人占位** |
| **设定深度** | 本书的"阶层社会 + 装备上限由户籍决定 + 靠输变强"在同类中独一份 |
| **与流派本意暗合** | 综网的"版本设定"本质就是**规则不平等**——本书只是把这个不平等等级化了 |

## 三、定位建议（三层）

### 第一层 · 书名：保留《综网：废柴逆命》

**理由**：
1. 起点完全允许冒号（开山怪的书名就是「综网：XXX」）
2. "综网"是**流量关键词**，能进综网流的推荐池
3. "废柴逆命"四字本身直接点明卖点

**但必须做一件事**：在**简介第一句**就完成调性告白，避免读者预期错位。

### 第二层 · 简介：第一句定调

**当前简介开头**：「综网降临第九年，全人类按属性总和重新分等。」

**建议改为**（加一句定调）：

> **这不是一个轻松的游戏故事。**
>
> 综网降临第九年，全人类按属性总和重新分等。
> 十八岁的陆沉，六项属性全是 1……

**理由**：综网流读者看到"综网"会带着轻松预期进来，**第一句把预期掰过来**，能有效过滤错位读者、留住对口读者。

### 第三层 · 标签：加入流派词

| 原建议 | **修正建议** |
|---|---|
| 无限流 / 综网 / 系统流 / 逆袭 / 悬疑 / 热血 | **综网流** / 游戏异界 / 系统流 / 逆袭 / 悬疑 / 热血 |

**理由**：
- 「综网流」是流派正式名称（比"综网"更精准命中该流派读者）
- 易伤秋者的作品标签就是「游戏·游戏异界」——**跟着流派走**，进同一批推荐位

## 四、一处曾误判的设定（**已撤回**）

我此前写道：「综网流有'主世界大本营'的核心爽点，而本书主世界是压迫性的——**缺少物理上的安全空间**，建议强化"宿"的大本营功能。」

> ⚠️ **该建议已撤回**（作者指正）：**物理上的安全空间可有可无，实力本身就是最大的安全。**

**修正为**：不强化"宿"的安全感，而是**强化陆沉的「不可战胜感」**——读者不需要替他担心有没有家，读者需要**相信他不会被人算死**。

具体的战力与爽感设计见 `26_爽感与节奏设计.md`（对标《凡人修仙传》的"同阶无敌／对下碾压／对上偶尔越级"）。

## 五、本轮结论

| 项 | 结论 |
|---|---|
| **P1-6 书名合规** | ❌ **撤回**——起点允许冒号，我的判断基于错误来源（某小平台规范） |
| **书名** | ✅ 保留《综网：废柴逆命》 |
| **简介** | ⚠️ 需加**第一句定调**："这不是一个轻松的游戏故事。" |
| **标签** | ⚠️ 「综网」→ 改为「**综网流**」；补「游戏异界」 |
| **定位** | **综网流框架下的冷硬反乌托邦**——同框架、异调性，目前无人占位 |
| **最大领悟** | "综网"是别人的流派，不是我的自造词。**我必须知道自己站在谁的赛道上。** |
