## 一、人物外貌锚点（P0-1）

> 用途：写到具体场景时需要稳定的视觉锚点。**每人的外貌只需记住 1 个"标志物"**，反复用。

### 主角

**陆沉**（18 岁，一米七八）

| 项 | 内容 |
|---|---|
| 体态 | 偏瘦，肩膀窄，手腕细。**旧外套的拉链坏了，用一枚别针别着** |
| 头发 | 很短，露一截后颈 |
| 眼睛 | 不抬眼看人。看东西时视线偏低——**他在算地面到那个东西的距离** |
| 手 | 指甲剪得极短，指尖有磨出来的茧；右手虎口一道浅疤 |
| **标志物** | **他算数的时候，右手会在裤缝上轻轻敲**（节奏是数拍子） |
| 走路 | 左脚略微内八；习惯贴着墙根走 |
| 变化线 | 等级越高，**手上的灰越洗不掉**（负能量位面留痕）——第 16 章起常驻 |

**一句速写**：一个总在看地面的人。

**陆谣**（14 岁）：个子到哥哥肩膀，马尾，校服袖口短了一截，手腕细得能看到青筋。**笑之前会先看一眼哥哥的反应**。

### 配角

| 角色 | 一句速写 | 标志物 |
|---|---|---|
| **苏青** | 短发，颧骨高，站姿像钉在地上的钉子 | 右手虎口一道旧疤；**队徽从不摘——直到第 07 章摘下来给他** |
| **裴战** | 比陆沉高半个头，肩宽，头发往后梳 | **下巴一直抬着**（第 11 章之后不抬了） |
| **老周** | 四十多，脸瘦，颧骨突，旧夹克洗到发白 | **右手总插在兜里**（另一只手要拿铜镜） |
| **韩度** | 四十多，制服笔挺，铭牌擦得发亮 | **领口第一颗扣子永远扣着** |
| **闻人驭** | 三十出头，无框眼镜，笑容标准 | **说话时看你的眉心，不看眼睛** |
| **陈九斤** | 二十，圆脸，个子矮 | **走路小步快走；手里总攥着记账本** |

## 二、90 天倒计时日历（P0-2）

> 全书硬约束。**第 01 章评定日 = D1**。

| 天 | 章 | 事件 |
|---|---|---|
| **D1** | 01–02 | 成年评定日，判「不可培养」，90 天复核期起算；当晚入场（01 章末）→ **净场十八次重置**（重置不消耗进入次数，属**同一次进入**内） |
| **D2** | 03 | 两次对照实验，反推逆命值公式；当众算穿裴战 |
| D3 | 04 | 决定报名地宫；写下五条规则 |

| D7 | 09 | 评定署复查被拒；净场发现刻痕 |
| **D8** | 10–11 | 索道（时限 90 分钟）；**Midpoint**；第二次翻命救裴战 |
| D9 | 12 | 回声市场（交付记忆换名单） |
| D10 | 13 | 闻人驭正面登场；苏青被带走问话 |
| D11 | 14 | 潜入九号站台，副本崩盘（+30） |
| **D12–D14** | 15 | 序列营谷底（石臼重伤、妹妹被带走） |
| D15 | 16 | 回净场读懂刻痕（复写③韩度） |
| D16 | 17 | 九号站台正式；改公告屏；末班车 |
| D17 | 18 | 围猎场（强制推送） |
| D18 | 19 | 清退听证被推翻；升 5 级；**宿配额更新** |
| **D19** | 20 | 对抗检定 → **改判**，卷终 |

**校验**：
- 首卷用 **19 天**，距 90 天截止还剩 **71 天** → 第二卷有充足空间
- 副本之间留 1 天恢复期（对应力竭规则：长休息降 1 级）
- 两处密集段（D4–D5 地宫连打、D16–D18 站台接围猎）**必须写出力竭**，否则节奏失真

## 三、积分物价表（P0-3）

> 参照：第 03 章"家里只剩 **34 积分**"、第 05 章"报名费 20 积分"。

### 生活层（第三区 · 丙等）

| 项目 | 价格 |
|---|---|
| 一人一天伙食 | **1** |
| 一份红烧牛排面（泡面） | 0.5 |
| 第三区公寓月租 | 30 |
| 小孩一学期学费 | 15 |
| 一件像样的冬衣 | 8 |
| 妹妺的作业本（一学期） | 2 |

> **34 积分 = 陆沉家全部积蓄 ≈ 一个月的伙食费**。这就是他全部的家底。

### 综网层

| 项目 | 价格 |
|---|---|
| 练习副本 | **免费**（丙等以下，一天两次） |
| 废料副本报名费 | **20**（其中 10 是掮客加价，见下） |
| 凝血针剂 | 15 |
| 短效增益符（一次检定取优势） | 60 |
| 侦察鸦 | 120 |
| 户籍等级申请（丙 → 乙） | **500**（九斤的目标） |
| 属性抽选券 | 800 |
| **商城修复一次重伤** | **3000** ← **母亲当年凑不齐的那个数字** |

### 掉落与回收

- 装备**不能出售，只能分解成素材**（借自《轮回 3.82》）
- 空间**半价回收**普通道具
- 副本通关基础结算 ≈ **30–80 积分**（视完成度）

> **经济设计要点**：一个丙等家庭靠打副本，**要 10 个月才能攒够一次户籍升级**。
> 所以"变强"在这个世界里从来不是努力问题，是**阶层问题**。

## 四、中层反派：贾算（P0-4）

> 首卷中段（第 05–10 章）需要一个**具体的人**把压力落到主角身上——副本机制再狠，读者恨不起来。

| 项目 | 内容 |
|---|---|
| **姓名** | 贾算（外号「贾半成」） |
| 年龄 / 面板 | 41 岁｜总和 39（丙等偏下） |
| 身份 | 西市场的**副本报名掮客**；经手全区的组队、报名、结算抽成 |
| **手段** | ① 吃两头回扣；② 伪造队伍资质；③ **把没人要的人塞进死亡率最高的队**，因为死人不退报名费 |
| **与主角的冲突** | 他多收陆沉 **10 积分**（报名费本该 10，收他 20）。理由："你这种面板，本来就该多交点押金。" |
| 动机 | 不是恶，是**他在这个系统里唯一能赚的钱**——他自己当年也是被塞进高危队的人 |
| **打脸点** | 第 07 章之后，陆沉用他记在纸上的五条规则当众拆他的账：**报名 4 人收 80 积分，报给管理局的是 40，差额去哪了** |
| 退场 | 被清查；但临走前说了一句让陆沉记住的话——「你现在能算我了。等你算不动的时候，你就成了我。」 |
| 功能 | ① 给中段一个可恨的具体人；② **展示"积分经济"的社会面孔**；③ 让主角的"算"第一次变成武器而非自保 |
