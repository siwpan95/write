## 二、版本变更

### v1 → v2（11-13 → 11-20）

| 项 | v1（11-13） | v2（11-20） |
|---|---|---|
| 书名 | 无 | 《越看不起我，我越强》 |
| 主角名 | 陆沉（撞名） | **陆拾** |
| 系统触发 | 他人施压＋不折腰 | **见傲气即可收割** |
| 结算方式 | 以弱胜强 / 令其收回轻视 | **压 / 驳 / 破 三路**（压得越低越贵） |
| 惩罚 | 折腰即七日沉寂 | **真认命才罚**，假意折腰算「压」 |
| 进化 | 固定百点一层 | **九节递增：40/100/240/600/1500…** |
| 力量体系 | 只有「灵根」一个概念 | **双轨：修为（打多大力）＋ 承载力（接多大力）** |
| 核心道具 | 无 | **辱名榜**（猎物地图＋进度条＋伏笔工具） |
| 赛道结论 | 系统流最抗风险 | **已失效**；改走「纯修仙＋主攻改编」 |
| 篇幅 | 未量化 | 卷一 30 章 ≈ 6 万字；全书 5 卷 ≈ 30 万字 |

- 新增简介 3 版（B 版定稿）、签约材料包、提交作战计划（A 方案）。

## 三、核心设定速查（写前 30 秒）

| 项 | 值 |
|---|---|
| **结算公式** | `逆鳞值 = 1.5 × MAX(身份差, 修为差) × 公开度 × 回收方式` |
| **系数** | 身份/修为：1/2/3/5；公开：1/2/3/5；回收：驳1/压3/破6 |
| **解封门槛** | 40 / 100 / 240 / 600 / 1500 / 3800 / 9000 / 20000 / 50000（九节） |
| **承载力倍率** | ×2 / ×4 / ×8 / ×16 / ×32 …（每节翻倍） |
| **冷却** | 小人物 2–3 日｜外门 5–10｜真传 10–15｜**圣子·长老 60–90** |
| **冷却例外** | 冷却的是存量，**恨会一直涨**（敌人越恨他，他越肥） |
| **惩罚** | 真认命 → 沉寂七日＋反噬剧痛（卷一第 17 章必须真用一次） |
| **系统金句** | 「脊梁不折，万劫可逆。」（只在大高潮用） |
| **主题句** | 「他不是获得了外挂，他是被掏空了，系统是代偿。」（卷四揭） |

## 五、续写纪律（v2 · 六条）

1. **设定先行**：世界观与规则以 `03` 为 SSOT，写前先读 `03` §3.6（使用纪律七条）。
2. **元规则优先**：`00-决策单` 与 `03` 冲突时，以 `00` 为准。
3. **数值必须写乘数**：每一次结算都要让读者能自己算平；不许发无名之财。
4. **主角不许靠修为赢**：他只能「扛住 → 找破绽 → 让对方当众失手」。
5. **原稿零改动**：`原稿/` 永久保留，不切分、不改字。
6. **每章过气口检查**：`00` §5.2 六条硬指标，一条不过就重写。

> **提交前额外纪律**（`提交作战计划.md` §一）：只做首屏通读／错别字格式／数值链核对三件事；不改书名、不改简介、不改第 4 章以后情节、不重排章节顺序。
