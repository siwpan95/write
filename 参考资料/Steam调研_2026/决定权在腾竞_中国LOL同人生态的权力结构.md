# 决定权在腾竞，不在拳头：中国 LOL 同人生态的真实权力结构

> 本文修正前一版的判断错误。前一版把"官方二创态度"归因于拳头游戏，这对中国市场是错的。**在中国，决定 LOL 同人生态边界的不是拳头，是腾讯——具体承载者是腾竞体育。**

---

## 一、股权链：腾讯在拳头之上，腾竞在两者之间

先把结构画清楚。

**第一层：腾讯持有拳头。**

2011 年腾讯对拳头实现控股，2015 年**全资收购**〔A-92·B〕。也就是说，拳头是腾讯的全资子公司。

**第二层：腾竞是腾讯互娱与拳头的 50:50 合资。**

2019 年 1 月 4 日，腾竞体育文化发展（上海）有限公司注册成立，注册资本 5.3 亿元，由腾讯互动娱乐与拳头游戏各持股 50%〔A-93·A〕。

管理架构：
- 董事长：马晓轶（腾讯集团高级副总裁）
- 董事兼法人：黄凌冬（腾讯游戏副总裁，2026 年任 CEO）
- 首任联席 CEO：金亦波（腾讯互娱《英雄联盟》负责人）、林松（拳头中国区总经理）

**第三层：腾竞的业务范围。**

工商登记与官方表述一致：LPL 赛区英雄联盟核心赛事联盟管理及运营、英雄联盟国际赛事本地推广及商业化代理、电竞创新业务与创新产品、电竞相关游戏产品、**电竞 IP 衍生品**〔A-93·A〕。

注意最后一项——**"电竞 IP 衍生品"写在了营业执照式的业务范围里**。这不是一个模糊的许可，而是一个被明确列出的业务条目。

**第四层：腾竞同时管着瓦。**

2023 年，无畏契约冠军巡回赛 CN 联赛（VCT CN）启动，同样由腾竞运营〔A-93·A〕；招聘信息亦明确其业务含"英雄联盟和无畏契约电竞赛事的联盟管理及运营"〔A-94·B〕。

所以对瓦的国内生态，腾竞也是实际运营方。

**结论**：从股权链看，腾讯 → 拳头 →（合资）腾竞。所谓"拳头的态度"，在中国市场的落地环节上，是由腾竞执行的。

## 二、拳头政策原文：严禁商业用途

拳头的官方文件叫"法务碎碎念"（Legal Jibber Jabber），中文版原文写得相当直白〔A-95·A〕：

> "我們超愛大家的創意，也支持玩家利用我們的智慧財產創作免費的粉絲作品……如果不違反以下規則，我們通常不會阻止粉絲創作。"

授权范围是：**"個人、非專屬、不可再次授權、不可轉讓、可撤銷的限定授權"**。

关键限制在同一句里：

> "嚴禁作為商業用途（下列狀況除外）。"

三种例外：被动广告收入、实况频道的订阅与赞助、遵守 API 条款的商业作品。**没有一种例外覆盖"在文学平台收费连载的同人小说"。**

而且拳头保留了一项兜底权利：

> "我方保留隨時禁止任何人使用我方 IP 的權利，不限或不需理由。"

**这就产生了一个明显的矛盾**：按政策文本，起点上大量收费连载的 LOL 同人小说是不被允许的；但事实上它们大量存在、正常签约、正常上架。

**唯一的解释是：这是一个默许空间，而不是一个授权空间。** 而默许的给出方，不可能是远在美国的拳头，只能是本地生态的实际运营者——腾讯/腾竞。

## 三、默许空间的三个支撑

### 3.1 平台与 IP 方在同一体系内

起点中文网属阅文集团，阅文与腾讯的关系众所周知。这意味着"写 LOL 同人的平台"与"持有 LOL 中国区运营权的一方"处在同一个商业体系内。

跨体系维权成本高、收益低；体系内协调成本低、且同人内容本身对 IP 热度是正贡献。**默许是同体系内的理性选择。**

### 3.2 同人对赛事生态是净正向

LOL 同人小说做的是"用文字再生产赛事情感"。它不消耗 IP 资源，只增加讨论量与情感黏性。

腾竞的业务里明确有"电竞 IP 衍生品"一项——同人内容在功能上就属于衍生品的广义范畴。**官方没有理由驱逐一个免费帮自己维持热度的环节。**

### 3.3 腾讯有"撒钱"的能力与意愿

腾竞成立时提出的三年目标：联盟总收入 10 亿元、观赛时长 40 亿小时、LPL 成为中国最具价值的体育 IP 之一（2021 年宣布基本实现）〔A-93·A〕。合作品牌从最初 7 家增至 15 家。

2026 年 LPL 招商方案显示：**首席合作伙伴报价 6,000 万元，国际赛事中国区联合赞助 1,600 万元**〔A-96·B〕。

这个量级的商业盘子，意味着它有能力把"同人"当作生态的一环来养，而不是当作侵权来打。

## 四、三角洲：一个完全闭环的样板

把三角洲拿出来对照，结构差异立刻显现。

### 4.1 增长曲线

| 时间 | 数据 |

| 2024-09-26 | 国服上线 |
| 2024-11-17 | 全网注册用户突破 **4,000 万** |
| 2025-04 | 国服 DAU 突破 **1,200 万** |
| 2025-07 | DAU **2,000 万** |
| 2025-09 | DAU 突破 **3,000 万** |
| 2026-01 | DAU **4,100 万** |
| 2026-03 | DAU **5,000 万** |
| 2026-10 | DAU **5,800 万** |

〔A-97·A〕

同期数据：首月全网视频播放量超 120 亿；抖音 #三角洲行动 主话题播放量破百亿；Steam 同时在线曾破 21 万；2025 年 Q4 国内收入超 10 亿元〔A-97·A〕。

### 4.2 为什么它能一年堆出 15 部小说

因为它的链条是闭合的：

**天美琳琅天上研发 → 腾讯发行 → 腾讯电竞（猛攻杯、ACL、烽火世界杯）→ 腾讯系直播平台 → 阅文/起点（腾讯系）**

每一环都在同一体系内。这意味着：
- 新版本上线，小说作者第一时间拿到素材
- 赛事开打，直播与二创同步铺开
- 平台给量，因为这是"自家产品"

对照瓦：**瓦的国内运营也归腾竞，但 IP 本身不归腾讯**。叙事供给的节奏由拳头控制（每季一段短片），腾竞只能做赛事与推广，不能决定剧情怎么走。

**这就是结构性差异**：三角洲是"全链自控"，瓦是"运营外包 + IP 在外"。

## 五、结论：三层结构

把中国市场游戏题材网文的上游依赖，拆成三层：

| 层级 | 谁在决定 | 对长篇的影响 |
|---|---|---|
| **IP 叙事供给** | 开发商（拳头 / Respawn / Valve / 天美） | 决定有没有"连续故事"可写 |
| **本地生态运营** | 腾竞 / 腾讯 / 代理商 | 决定同人是否有生存空间 |
| **内容分发平台** | 起点 / 番茄 / 晋江 | 决定能不能签约、给不给量 |

三层的组合决定了长篇的生死：

- **LOL**：三层全在腾讯体系内（IP 虽在拳头，但拳头是腾讯全资子公司），**供给连续 + 默许明确 + 平台给量** → 能出 363 万字长篇
- **三角洲**：三层全自控，**供给新但节奏快 + 默许明确 + 平台给量** → 一年堆 15 部
- **瓦**：IP 在拳头（供给 episodic），运营在腾竞，平台在阅文 → **供给断 + 默许模糊 + 平台观望** → 最长 27.6 万字
- **Apex**：IP 在 EA/Respawn，国内运营方不明，**供给碎 + 无人默许 + 平台无动力** → 最长 69.84 万字

**所以"拳头算老几"这个问法是对的**：在中国市场，拳头的政策只是文本，真正决定边界的是腾竞代表的那套本地生态。
