# 游戏/竞技题材长篇创作指南 · 可填表版

> 本文件把此前全部讨论（赛道选择、竞品分析、上游供给、品类谱系、开局施工、失败设计）收敛成一套可直接填写的表格。
> **使用顺序**：第一部分定赛道 → 第二部分定容器 → 第三部分定开局 → 第四部分定结构 → 第五部分定失败 → 第六部分定人物 → 第七部分定分发 → 第八部分总自检。
> 每张表前的一句"为什么填这个"，是判断依据；表内的"＿＿＿"是待填字段。

# 第一部分 · 立项前的三项判断

## 表 1-1 上游供给体检表

> **为什么填这个**：一款游戏能不能养长篇，取决于上游能不能持续供给"可被追更的连续故事"。供给断裂，作者就会无米下锅。

| 检查项 | 填写 | 判读 |
|---|---|---|
| 目标游戏 | ＿＿＿ | — |
| 官方是否有连续叙事载体（剧集/动画/官方小说/漫画） | 有 / 无 / 仅季度短片 | 仅季度短片 = episodic，慎入 |
| 叙事推进的动力是什么 | 故事往下走 / 新产品上线 / 无主线 | "新产品上线"驱动的，长篇必断 |
| 官方叙事交付频率 | ＿＿＿（月/季/年） | 间隔越长，作者越需自建 |
| 作者自由度（能否脱离官方设定） | 高 / 中 / 低 | 低 = 角色是卖点，改不得 |
| 结论：适合长篇 / 只适合短篇 / 不建议 | ＿＿＿ | 三者只能选一 |

**判读口诀**：供给连续 + 自由度中 = 可写（跟官方节奏）；供给弱 + 自由度高 = 可写（靠人物）；**供给碎片 + 自由度低 = 不可写长篇**。

## 表 2-3 IP 借用边界表

> **为什么填这个**：电竞文可写真实赛事，异界/虚拟网游必须自建。混用会招版权风险。

| 我要借的东西 | 允许 / 需改造 / 禁止 | 处理方式 |
|---|---|---|
| 游戏名称 | 允许（名称难达独创性） | 可用，但注意商标语境 |
| 赛事名（Major、TI） | 允许（描述现实） | 可用 |
| 真实选手名 | **需改造** | 建议改名或只写 ID 特征 |
| 游戏世界观/角色 | **需改造** | 必须"翻译"成自建名词 |
| 剧情主线、角色羁绊 | **禁止** | 绝不能碰 |
| 玩法机制（搜打撤、BP） | 允许（属通用玩法） | 可自由使用 |

**操作口诀**：借类型，不借 IP；借机制，不借剧情；借结构，不借名词。

## 表 3-1 黄金三章设计表

- 首句必须是动作或异常

# 第五部分 · 失败设计（核心）

## 表 5-1 单次失败设计表

> **为什么填这个**：失败的实质不是"让主角难受"，是"让主角获得信息"。填不出第 4—6 行，这场失败就是纯虐。

| 项 | 填写 |
|---|---|
| 1. 失败形式 | 身体死 / 目标死 / 关系死（可叠加） |
| 2. 失败对象（具体失去什么） | ＿＿＿ |
| 3. 失败原因（他的哪个判断错了） | ＿＿＿ |
| 4. **获得的信息**（他知道了什么之前不知道的） | ＿＿＿ |
| 5. **信息如何改变选择**（下一卷做法有何不同） | ＿＿＿ |
| 6. **不可逆的代价**（什么永远回不来） | ＿＿＿ |

## 表 5-3 无效失败对照表

> **为什么填这个**：这四种写法最常见，逐条对照可提前避开。

| 症状 | 表现 | 我的书里有没有 |
|---|---|---|
| 觉醒翻身 | 输了→领悟XX真谛→突然变强（领悟与失败原因无关） | 有 / 无 |

**四者的共同病根**：失败没有改变主角的**认知模型**，只改变了他的**情绪或资源状态**。

## 表 8-2 常见病症对照

> **为什么填这个**：这些是本次讨论中反复出现的失败模式，写之前先避开。

| 病症 | 症状 | 药方 | 出处 |
|---|---|---|---|
| **时事依赖症** | 靠赛事梗、黑料、热点撑起故事，热度一过书就废 | 从"时事"退到"人物"或"自建" | 红海机制 |
| **仿全职症** | 想复刻荣耀的设定，结果被说"抄"或"不如" | 换容器，装同一套东西 | 重走荣耀之路 |
| **硬核门槛症** | 设定完整但读者进不来 | Roguelite 化：保内核，砍摩擦 | 门槛迁移 |
| **纯虐症** | 主角一直输，但什么都没学到 | 补"信息产出" | 失败三层功能 |
| **阶段无敌失速** | 每阶都无敌，读者疲劳 | 每阶用一次有效失败买票 | 阶段无敌 |
| **设定漂移** | 写着写着规则变了 | 建规则台账，每卷末核对 | 品类谱系 |
| **情怀透支** | 靠旧记忆吸引读者，用完就没了 | 情怀是消耗性资产，不能当主线 | 共时演进 |
