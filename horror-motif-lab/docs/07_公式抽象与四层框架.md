# 公式抽象与四层框架

> 版本：v1.0 ｜ 2026-11-21 ｜ 对应任务：把 `T = (R − e₁) × Δ − I − E` 从「恐怖公式」抽象为**可跨类型复用的压力工程框架**
> 前置：`docs/01_八母题R规程库.md`、`docs/08_十六母题库.md`、`write/零件库/`

---

## 0. 一句话

**「恐怖」不在公式里，它是公式的一个取参结果。**

原公式把 I（信息量）和 E（出口）写成扣分项，暗示「越少信息、越少出口＝越好」——那只对恐怖成立。
对正剧、悲剧、讽刺，这个符号是反的。

所以要做的事只有一件：**把「恐怖」从公式的语法里拆出去，降级为一组参数取值。**

拆完之后，得到四层，从单场到整卷都能用。

---

## 1. 四层框架

```
L0  压力生成      P = (R − e₁) × Δ
      ↓           在哪条边界上，撬了多大一处
L1  呈现定调      X = P − I − E                    ← Mode 在这里取值
      ↓           同一份压力，写成恐怖/正剧/悲剧/讽刺
L2  序列编排      V = Σ Pᵢ × phaseᵢ                ← 借零件库 phase
      ↓           先立规、再加压、再翻盘、最后耗尽
L3  多压力装配    S = Π Pᵢ  s.t. 互斥约束            ← 借零件库装配体
                  可共存 / 互斥 / 抵消
```

**这四层是分开的**：L0 决定「这场有没有戏」，L1 决定「这场是什么味道」，L2 决定「几场怎么排」，L3 决定「这些压力能不能同场」。

绝大多数写崩，是因为**跳过 L0 直接做 L1**——没有压力，只调 I 和 E，得到"看不清也没出路"的空转。

## 2. L0 · 压力生成

```
P = (R − e₁) × Δ
```

| 变量 | 含义 | 取值来源 |
| --- | --- | --- |
| **R** | 规程：本来应该怎样 | 十六母题各自的规程库（`docs/08`）+ 零件库的落地接口 |
| **e₁** | 一错：恰好一处没照做 | 每个母题 6–10 条候选池（带 `sym` 载体） |
| **Δ** | 轴：哪条分类边界被撬 | 十六母题 = 十六条轴 |

**三条不变式**（跨类型都成立，这是框架的硬核）：

1. **R 必须可检验**——角色要用日常动作反复确认"一切正常"。没有检验动作，e₁ 无处落脚。
2. **e₁ 唯一**——一处偏移撬一条轴。第二处出现，P 不叠加，而是**降格为奇观**（读者改看热闹）。
3. **Δ 单轴**——同场撬两条轴，两条轴的解法互相抵消（详见 §5）。

**注意：P 没有单位，也不该有。** 它只是一个相对量：同一部作品内部可比，跨作品不可比。
不要试图给 P 打小数——那是伪量化。

### 2.1 不变式 ② 的一次定向证伪尝试（2026-11-21 · **未定论**）

`docs/10` 末尾自陈：三条铁律只有正例，缺反例。为此另起一处实验场：
`write/证伪实验-钢铁之梦/`，拿《钢铁之梦》（西部 × 新黑色，69,632 汉字）的
卷一第2章做基线，定向制造四种 e₁ 漂移（叙述层失效／同轴多 e₁／跨轴多 e₁／给 e₁ 解释），
**预测、评分口径、杀死阈值全部写在动笔之前**（`00_预登记`）。

**结果：实验失效，不变式 ② 原样保留。**

不是「被证伪」，也不是「被证实」——是**测法不管用**，三条硬伤：

1. **权重是循环论证**：口径里 e₁ 计数只占 10/100，等于在写尺子时就把「e₁ 唯一」定价成
   「值 10 分的偏好」，再拿这把尺子去问它是不是铁律。改个权重就能得出相反结论。
2. **机械项里 30 分零区分度**：M4／M5／M6（检验动作／风格越界／篇幅）对五个变体全部满分，
   它们测的是「排版有没有搞坏」，不是漂移。所谓「60% 可复算」实际有效区分只有 20%。
3. **代理指标测错对象**：四项主观项（张力线／隐喻单一／重读价值／可替换性）
   全在问「作者要不要返工」，没有一项在问「读者会不会被击中」。
   结构整洁但不动人的东西能拿满分——而这恰恰是「好看」最反对的东西。

四个变体得分 88／92／80／76，**全部过 75 分的「仍好看」线**。按预登记判定线，
这就该宣布铁律被彻底证伪。**本库不这么宣布**：一个把全部变体都判活的判定线，等于没有判定线。
另外预测的准头也很差——四条预测错三条，且错的方向一致：系统性高估漂移的破坏力。

**但有一条结构性结论站得住，因为它不依赖打分：**

> **漂移的代价，取决于它要不要读者新开一个隐喻。**
>
> - **同轴**（纸上的数自己长大）不需要新模型——读者手上已有「纸＝债＝账」，
>   新异常直接挂在旧模型上，收束句「纸不会掉膘。纸只怕湿。」反而被加强。
> - **跨轴**（土里埋着的死牛群）需要第二个模型，而本章只有一千三百字，装不下两次建模。
>   于是第二个模型只能悬着——**悬着的东西在短篇里是断线，在长篇里才是伏笔。**

由此得到一条**工作假设（H2，未验证，不得当结论用）**：

> **e₁ 的可容漂移量 ∝ 本章字数 ÷ 已建立隐喻数。同轴漂移近乎免费，跨轴漂移要按字付费。**

如果 H2 成立，不变式 ② 的**操作形态写错了**：它不该写成**阈值**（「第二处就降格」），
该写成**斜率**（「每多一处跨轴异常，本场需要额外多少字来建模」）。
「降格」这个词暗示悬崖，而这次实验在单章粒度上看不到悬崖，只看到坡。

**待办**：H2 需要同一处跨轴漂移在同一作品里连续 3／5／10 章，才能看出建模预算在哪一章崩。
盲读包已备在 `证伪实验-钢铁之梦/03_盲读/`（甲／乙／丙，映射见 `02` 表尾）。
在盲读结果出来之前，本库**不改动这条不变式**。

> 一句话记录：**这轮什么都没证明，只证明了「我原来的测法不管用」。**
> 而这个「不管用」本身是有价值的——它说明不变式 ② 现在的写法（阈值）至少有一半是修辞。

## 3. L1 · 呈现定调（Mode）

```
X = P − I − E
```

同一个 P，I 与 E 取不同值，得到完全不同的体裁体验。**这是整个框架最有用的一张表。**

| Mode | I（信息） | E（出口） | 体验 | 典型观感 |
| --- | --- | --- | --- | --- |
| **horror** 恐怖 | 低：永不全景，三次推翻 | 低：不给出口，只给延缓 | 恐惧 | 「别看过去」 |
| **thriller** 惊悚 | 中：给线索，藏动机 | 中：有出路，但很险 | 紧张 | 「跑得掉吗」 |
| **drama** 正剧 | 高：全景，代价可计量 | 中：可和解，但贵 | 共情 | 「他会怎么选」 |
| **tragedy** 悲剧 | 高：看清每一步 | 低：不可逆 | 悲怆 | 「他早就知道了，但还是走了」 |
| **satire** 讽刺 | 高：机制全暴露 | **高：出路明明有，就是没人走** | 荒诞 | 「所有人都知道，所有人都不动」 |
| **epic** 史诗 | 低：只给局部与尺度参照物 | 中：幸存但尺度认知被改写 | 敬畏 | 「我们在它脚边」 |

### 三条关键推论

**推论 1 · 讽刺 = 高压 + 高出口。**
这是本框架最反直觉的一格。原恐怖公式说「出口越多越不恐怖」——对恐怖成立，对讽刺恰恰相反：
**出路明明白白摆在那儿，所有人却都不走**，这才是荒诞。所以讽刺不是"弱化的恐怖"，是**同一个 P 换到 E 高的坐标上**。

> 这也解释了为什么 `M8` 里那句「可和解但被放弃」既可以是恐怖（关系型）也可以是讽刺——差别只在 I：恐怖不告诉你出口在哪儿，讽刺大声告诉你出口在哪儿。

**推论 2 · 悲剧 = 恐怖的高信息版。**
两者 E 都低（不可逆），差别全在 I：恐怖要你**看不清**代价，悲剧要你**看清**代价。
所以「把恐怖改成悲剧」不需要换故事，只需要补信息——把那些刻意藏起来的因果说出来。

**推论 3 · epic 的 I 低，但不是为了藏，是为了**比例**。**
恐怖的 I 低是遮蔽（不给你看），epic 的 I 低是**取景**（只给你门框和台阶，因为全貌无法入画）。
两者操作一样，目的相反：一个要你不懂，一个要你懂"自己有多小"。

### 3.1 POV 结构对 Mode 的硬约束（2026-11-21 增补 · 由真实作品验证）

**视角数不是风格偏好，它会直接改写 I 参数。** 多 POV 意味着读者知道得比每个角色都多，
这等于把 I 拉到高位——而 horror 要求 I 低。

| Mode | 单 POV | 多 POV（3–6 条） | 说明 |
| --- | --- | --- | --- |
| horror | ✅ 原生 | **✗ 参数冲突** | 读者知得比角色多，遮蔽就失效了 |
| thriller | ✅ | ✅ 原生 | 信息差正是它的引擎 |
| drama | ✅ | ✅ 原生 | 每人一条主问题 |
| tragedy | ✅ | ✅ | 多视角看同一不可逆 |
| satire | ✅ | ✅ 效果更强 | 多视角看同一件荒唐事 |
| epic | ✅ | △ | 视角一多，尺度感会被拉平 |

> **一句话**：**想写恐怖，收视角；想写群像，换 Mode。**
> 证据：`docs/10` 例 1（《志异司》六 POV 立项案）——它自己定的硬指标「读者比每个角色都知得多」，
> 与 horror 的 I 低直接互斥，所以它落在探案（thriller）而非恐怖。

### 3.2 跨 Mode 转换的四个条件（同一节增补）

一部作品从中途换 Mode 是常见需求（比如恐怖转悲剧）。成立的条件只有四条：

| 条件 | 判据 |
| --- | --- |
| **同一 e₁** | 转换前后的"不对"必须是同一处，不能换问题 |
| **信息驱动** | 转换由"谜底揭开导致 I 升高"触发，不是"作者想换风格" |
| **不可回退** | 转换后无法退回原信息量 |
| **接口在驱动器上** | 前文积累的未结算项，正好成为后文的抉择筹码 |

> 这不是设计出来的，是**推导出来的**：I 一旦升高就降不回去（读者已经知道了），
> 所以 Mode 转换本质上是「**I 被迫升高之后的落点选择**」，不是风格选择。
> 证据：`docs/10` 例 3（《提交确实未创建》首章 horror → 末章 drama/tragedy）。

## 4. L2 · 序列编排

借零件库 `13-P0字段规格` 的 phase 四相位：

| phase | 做什么 | 在框架里的位置 |
| --- | --- | --- |
| **设** | 立规则（R 被看清） | 开场必用。没有"设"，后面所有"破"都无效 |
| **压** | 同一规则加压（e₁ 反复发生） | 中段主力 |
| **翻** | 规则倒向另一边（发现规则本身有问题） | 转折点 |
| **竭** | 本卷用完（该轴已被榨干，必须换轴） | 卷末 |

**三条排布律**（沿用零件库的 L4D 纪律）：

1. **禁止相邻同轴**：连续两场撬同一条轴，读者免疫。
2. **峰值后强制休止**：连续 2 个高压场（band L3+）之后必须插一个低压场或休止段。
3. **高潮不进系统**：卷末高潮手写锁定，不交给公式自动生成。

**驱动器（Venture）**：一条序列只推进**一个状态量**。
零件库给八量：`财 势 名 位 时 秘 身 信`。选了哪个量，这一卷所有压力都要往它上面结算。

> 这一条是防止"事件罗列"的关键：读者感到的是**受难**还是**递进**，差别就在有没有一个统一的驱动器。

### 4.1 phase 在卷层同样成立（2026-11-21 增补 · 由真实作品验证）

原表只说了"几场怎么排"。实测发现：**四卷长篇的卷结构，就是 phase 的宏观版。**

| 卷 | phase | 做什么 |
| --- | --- | --- |
| 卷一 | **设** | 教读者学规则（此时还不能开打） |
| 卷二 | **压** | 同一规则加压 |
| 卷三 | **翻** | 发现规则本身有问题／出现第二套规则 |
| 卷四 | **竭** | 该轴已榨干，必须抉择或换轴 |

**跨卷不漂的三条机制**（`docs/10` 例 2 实证，《提交确实未创建》120 章 61.9 万字）：

1. **e₁ 只有一个，但可被多次「重新解释」**——同一个事实，每卷换一个**用途**（异常→查证对象→账目→抉择筹码）。
2. **每卷换圈层，不换轴**——L1 新手圈→L4 终局圈，轴始终是 `registry`。换轴等于换书。
3. **留一个物理锚点**——开头出现过的具体物件，结尾还在（该书：多出来的那副筷子，001 → 119）。

> 第 3 条最容易被忽略：读者记不住 120 章的因果链，但记得住那副筷子。
> 物理锚点不是象征，是给读者的**可核对坐标**。

## 5. L3 · 多压力装配

```
S = Π Pᵢ   s.t.  互斥约束
```

三种关系（借零件库 `01-零件总台账` §按互斥检索）：

| 关系 | 含义 | 处理 |
| --- | --- | --- |
| **可共存** | 两条轴撬的是不同维度，互不干扰 | 直接叠 |
| **互斥** | 各自单看成立，同场互相拆台 | 分场，或换一条轴 |
| **抵消** | 两条轴要求相反的呈现方式 | 必须选一条 |

**本项目已确认的互斥（来自零件库 5 对，全部为"接口相容但装配互斥"）**：

| 互斥对 | 条件类型 | 为什么会拆台 |
| --- | --- | --- |
| 不可逆代价 ⊗ 代价不可解 | 前提取消 | 一个要求代价可计量，一个要求永不解释 |
| 代价记账法 ⊗ 代价不可解 | 前提取消 | 可记账的代价必然可归因 |
| 名分兑换率 ⊗ 押名担保 | 载体争用 | 同一份"名"不能既当计价单位又当抵押物 |
| 名分兑换率 ⊗ 名分阶梯 | 效果抵消 | 可折资源后，阶梯失去判级功能 |
| 双印互斥 ⊗ 两层宪章 | 前提取消 | 规则源并列使"切分同一对象"的前提消失 |

**这五对是直接可用的**：写长篇时，凡是这两个零件对应的母题同时出现，一定有一处会塌。

## 6. 跨类型映射：同一个母题，六种 Mode

以 `registry`（在册／不在册）为例——这是零件库里零件最多的一条轴（记录即存在、划名机制、空位必填、认纹不认人）：

| Mode | 同一份压力的写法 |
| --- | --- |
| horror | 不在册的东西会来找你，因为它无处可去 |
| thriller | 你的档案被人改过，而改的人有权限 |
| drama | 一个没有户口的孩子上不了学，母亲跑了三年手续 |
| tragedy | 他到死都没被记进族谱，而族谱是他自己修的 |
| satire | 所有人都知道册子是假的，但没人敢不填 |
| epic | 整个文明的档案在一夜之间被烧掉，没人记得该重建什么 |

**六段写的是同一条轴、同一个 R、同一类 e₁。** 差别只在 I 与 E 的取值。

**这就是"可复用"的意思**：不是"一个公式能套所有故事"，而是**一次结构投资，六种体裁分红**。

## 7. 框架化的三个用法

### 用法 A · 诊断（先查 L0）

作品"不对劲"时，按层往下查：

| 症状 | 病灶层 | 处方 |
| --- | --- | --- |
| 读者说"看不懂" | L1 的 I 太低 | 补信息，不是加解释 |
| 读者说"无所谓" | L0 的 P 太低 | 没有 R 或没有 e₁，先去立规程 |
| 读者说"好乱" | L2 没有驱动器 | 选定一个状态量，其余全部往它结算 |
| 读者说"前面好看后面塌" | L3 互斥 | 查那五对，必有一对同场 |
| 读者说"太假" | L0 的 R 不可检验 | 补检验动作 |

### 用法 B · 改造（换 Mode 不换故事）

一部作品从恐怖改成正剧，**只动 I 与 E 两列**：

1. 把刻意隐藏的因果说出来（I ↑）
2. 把"彻底不可解"改成"可以和解但很贵"（E ↑）
3. P 一个字不用改

**风险**：I 一升，原来靠遮蔽撑着的场面会显得单薄——那些场面本来就没有 P，只有 I 的减法。改完会发现有三四场必须删。**这不是失败的信号，是诊断的成功。**

### 用法 C · 移植（跨项目复用）

把 `write/零件库` 的 29 件当作 **Δ 的可选值**：
- 每件零件 = 一条轴的**工程化实例**（带 band/phase/rule）
- 本库的十六母题 = 这些轴的**分类学**

所以：**零件库回答"这一站用什么装置"，本库回答"这个装置撬的是哪条轴、该配什么 Mode"。**

两者不是替代关系，是**索引关系**。

## 8. 与原公式的关系（不要丢掉原来的东西）

原式 `T = (R − e₁) × Δ − I − E` 在新框架里的位置：

- 它是 **L0 + L1 在 Mode=horror 时的特例**
- 「一错律」「主辅律」「顺序律」「出口律」全部保留，但升格为**跨 Mode 不变式**（见 §2 三条不变式 + §4 三条排布律）
- 五种「温度」（关系型/系统型/身体型/崇高型/狂喜型）保留为 **horror 之内的子档**，与六 Mode 是"总-分"关系：

```
Mode: horror
  ├─ 关系型·温   （I 低，E = 可和解但被放弃）
  ├─ 系统型·冷   （I 低，E = 只给延缓）
  ├─ 身体型·黏   （I 低，E = 代价即结局）
  ├─ 崇高型·史诗 （I 低，E = 幸存但尺度改写）   ← 注意与 Mode=epic 重合，见下
  └─ 狂喜型      （I 感官满/语义零，E = 转化即奖赏）
```

**一处重叠要说明**：恐怖子档「崇高型·史诗」与 Mode「epic」不是同一个东西。
前者是**恐怖的一个子类型**（有威胁、有距离、以敬畏收尾），后者是**独立的呈现模式**（不必然有威胁，可以是纯粹的尺度体验）。
写的时候别混：写恐怖选前者，写《三体》式尺度感选后者。

## 9. 边界

- 四层框架、六 Mode 表、跨类型映射，全部为**创作化引申（C 档）**。
- L2 的 phase 与 L3 的互斥约束**借自** `write/零件库`（`13` 号字段规格与 `01` 号台账），本库只借用其分类，不改其定义；零件库如需修改，以零件库为准。
