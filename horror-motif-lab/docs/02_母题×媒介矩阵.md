# 母题 × 媒介矩阵

> 配套 `01_八母题R规程库.md` 使用。
> 材料 04 只给了「最高效媒介」一列（气味/连续变形的中景镜头/留白…），那是**通道**，不是**媒介**。
> 本文把 8 个母题 × 9 种媒介铺开，解决一个具体问题：**同一个母题，写成短篇、拍成片子、做成游戏，改的是什么参数？**
> 评级与全部判据均为**创作化引申（C 档）**，依据在 §2 的五个控制维度。

**一眼读法**（不必记表）：

- **短篇、电影、游戏** 是八母题里覆盖最广的三档，如果只能选一个载体，先选这三个。
- **长篇** 只对「未知」「怨念」给 ◎——因为它有足够页数去**累积三次信息**，这是短篇做不到的。反过来说：拿长篇写「镜像」，八成会中途改成悬疑。
- **TRPG 和装置** 是两极：TRPG 只擅长「仪式」（因为规则就是仪式），装置只擅长「身体」和「阈限」（因为观众的身体在空间里）。
- **短视频** 意外地适合「阈限」和「镜像」——循环播放本身就是一条 e₁。

## 2. 判据：五个控制维度

为什么有的格子是 ◎、有的是 ✕？不是凭感觉。媒介对恐怖的控制力可以拆成五条，母题对它们的依赖度不同〔C〕。

| 维度 | 含义 | 极端例子 |
| --- | --- | --- |
| **时间控制** | 谁决定"什么时候停" | 电影：导演（100%）／小说：读者（随时可停） |
| **视角控制** | 谁能强制"只能从这里看" | 电影、漫画：完全强制／TRPG：玩家协商 |
| **通道数** | 能同时占用几种感官 | 装置：视觉+听觉+触觉+嗅觉+体感／音频：1 种 |
| **可复查性** | 观众能否回头逐帧核对 | 小说、漫画、游戏：可反复／电影、短视频首刷：不可 |
| **参与度** | 观众是否必须"做动作" | 游戏、TRPG、装置：必须／其余：零 |

### 三条由维度推出的硬结论

**结论一：e₁ 的隐蔽上限，等于媒介的可复查性。**〔C〕
可反复核对的媒介（小说、漫画、游戏），e₁ 经不起糊弄——读者会翻回去看。所以这类媒介适合**精密**的一错（前文没写过的细节不能突然出现）。
一次性媒介（电影首刷、短视频）可以用**剪辑**制造 e₁——观众没有第二次机会去验证"上一秒那个镜头是不是真的存在"。这就是为什么电影能做"回放里多一段"这种效果，小说做同样的效果却必须写出来，一写出来就失去了模糊性。

**结论二：交互媒介是"检验动作"的最佳载体。**〔C〕
规程库第 3 节说，e₁ 生效的前提是"角色刚用某个动作确认过正常"。
- 在小说里，这个动作是**叙述**的（"她数了数碗"）——读者信不信，取决于文笔。
- 在游戏里，这个动作是**玩家亲手做的**（他真的按了三次 R 键去数碗）——玩家自己完成了验证，也自己承受了被推翻。

**这是游戏在恐怖上的结构性优势，任何叙事媒介都替代不了。** 07 号母题（窥视）在游戏里给 ◎，原因就在这里：让"看"变成消耗资源，玩家每看一眼都在付代价。

**结论三：通道数少的媒介，必须换母题。**〔C〕
音频只有一条通道，所以它做「身体异化」（需要视觉的形态变化）只能靠声音的**质感**——湿滑、撕裂、呼吸。评级 △ 不是因为它不能做，而是因为它必须放弃母题最核心的视觉维度。
反过来，音频做「怨念」给 ◎：因为怨念的核心是"声音先到、人后到"，单通道反而**排除了视觉干扰**，跑调童谣在音频里比在任何画面里都可怕。

## 3. 关键格详述（每母题 2–3 个最优媒介）

### 3.1 死亡与腐朽 → 短篇 ◎ / 漫画 ◎

**短篇为什么最优**：腐朽是**过程**，不是状态。短篇的篇幅刚好装下一次完整的过程（七日、一场丧事、一次开棺），超过这个长度，读者对"它还在变"会钝化。**长篇写腐朽，中段必然疲软**，这是结构问题不是笔力问题。

- 手法：把时间切成"日"或"次"（第一日、第二日），每段开头重复同一个检验动作，只在某一段给不同答案
- 载体：现代殡仪馆／冷藏柜温度日志／入殓师的日常——比古宅更冷，因为没有"阴森"这个廉价滤镜
- 失效风险：一旦开始描写气味太久，会变成生理恶心而非恐怖。「只改色温不加血」这条要守住

**漫画为什么最优**：腐朽是**静帧的**——一格画面上同时呈现"完整"和"正在坏"两种信息，只有漫画能在同一格做到（电影必须靠时间，小说必须靠描写）。分格还能让"重复"变得可见：同样构图的三格，第三格只改一处。

- 手法：同一构图重复分格，跨页给"变了"的那一格；对话框留白（无声）
- 载体：遗照／家族相册／殡葬流程说明图
- 失效风险：画得太细会变成解剖图，I 超支。**用留白和构图承担恐怖，不用细节**

### 3.2 身体异化 → 电影 ◎ / 装置 ◎ / 漫画 ◎

**电影为什么最优**：身体型温度要求「近景长镜、不切、不配乐」——这是电影语言的原生能力，其它媒介做不到"不切"。观众被钉在画面上，无法移开视线，**这个"无法移开"本身就是恐怖的一部分**。

- 手法：一个镜头从 80% 变形拍到 100%，中途不剪；全程无配乐，只有环境声与呼吸
- 关键：变形到 80% 时角色仍能说话、仍有礼貌（材料里的"附加律"）
- 失效风险：切镜头就泄气。**任何一次剪辑都是给观众一个喘息，而身体型恐怖的全部力量就在于不给喘息**

**装置为什么也是 ◎**：装置能提供电影给不了的东西——**观众自己的身体也在现场**。当银幕上的人被改写时，观众能感到自己坐着的那把椅子的硬度、空调的风、自己的呼吸。这是唯一能同时改写"作品里的身体"和"观众的身体"的媒介。

**漫画为什么是 ◎**：跨页（见开）是最强的身体恐怖武器——读者必须把书摊开，用两只手，让画面占据整个视野。**这个物理动作本身就无法回避。**

### 3.3 未知不可名状 → 长篇 ◎ / 剧集 ◎

**长篇为什么最优**：材料说"三次信息，每次推翻上一次"——这需要**时间跨度**。短篇做三次推翻会显得赶，长篇做三次才能让读者真的相信前两次。而"永不给全景"在长篇里是一种**耐力**：读者读了三百页还没看到那个东西，这个等待本身就是崇高感。

- 手法：三段式信息结构（设备故障 → 有人潜入 → 自己记错），每段都要有完整的证据链，不能敷衍
- 载体：档案小说／调查报告体／学术伪注（用脚注制造可信度，再用脚注自相矛盾）
- 失效风险：一旦给出"其实是高维存在/量子"的解释，整本书作废。**解释必须是"解释的失败"，不是"新的解释"**

**剧集为什么最优**：周更的间隔就是天然的"信息真空期"——观众在一周里反复猜测，而猜测本身就是恐惧的培养基。剧集还能让"专家"分集崩溃：第三集地质学家崩了，第五集档案员崩了，第七集连观众信任的叙述者也崩了。

- 手法：集末不给答案，给"新的矛盾"；片头曲在某一集悄悄改一个音
- 失效风险：为了留钩而留钩（每集都"其实没死"），三次之后就没人信了。**推翻必须是真的推翻，不是拖延**

### 3.4 幽灵与怨念 → 长篇 ◎ / 短篇 ◎ / 剧集 ◎ / 音频 ◎

**长/短篇都 ◎ 的原因不同**：
- 短篇靠**一次清算**（一场丧事、一笔债、一个晚上），密度高、不散
- 长篇靠**账本的展开**（三代人的债、族谱、地契、旧照片），让"欠了多久"变成可触摸的厚度

**剧集 ◎**：怨念是**关系**，关系需要人物群像，而群像需要集数。中式家族剧的天然结构就是"每一集揭开一层谁欠谁"。

**音频 ◎**（这是最容易被忽略的一格）：怨念的执行顺序是"声音先到、人后到"，而音频**只有声音**，等于把这条顺序律变成了媒介本身。跑调的童谣、纸钱燃烧的脆响、隔着门的一声应答——在画面里，观众会去找"是谁说的"；在音频里，他们只能听，无法确认，**恐惑因此最大化**。

- 手法（音频）：双耳录音做"背后有人"；把童谣跑调的位置每次挪一格
- 失效风险：一旦配音给鬼一个"狰狞音效"，全部作废。**只响不喊**

### 3.5 阈限空间 → 电影 ◎ / 游戏 ◎ / 装置 ◎ / 短视频 ◎

**电影 ◎**：阈限的恐怖来自"空间被完整呈现，却找不到出口"。宽画幅、对称构图、固定机位长镜头，能让一整个走廊同时进入视野——**观众自己扫视画面，自己确认"确实没有门"**。这个"自己确认"比任何台词都有效。

**游戏 ◎**：阈限是八母题里唯一**必须靠走**才能成立的。玩家走了一遍路线，记住步数，然后某一次走完发现门牌变了——这个体验无法被转述，只能被亲历。**步行模拟器是这个母题的原生体裁。**

- 手法：让玩家反复走同一条路（任务要求每天巡查），第三次才给变化
- 失效风险：加了怪物追逐就退化——**阈限的敌人是"没有敌人"**

**装置 ◎**：一条真实的走廊，灯亮着，地毯是潮的，尽头有一扇门，门后是同一条走廊。观众走三遍之后会开始怀疑自己的方向感——**这是唯一能让恐怖发生在观众腿上而不是屏幕上的媒介**。

**短视频 ◎**（意外但成立）：15–90 秒刚好是一条走廊走完的时间。而**循环播放**本身就是一条 e₁——视频结束，自动重播，观众发现"这次走的路和上次不一样"。平台机制被征用成了叙事装置。

### 3.6 镜像与分身 → 电影 ◎ / 短视频 ◎

**电影 ◎**：镜像的核心是**时间错位**（慢半拍），而"半拍"只有影像能精确表达。文学写"他抬手，镜中的他慢了半秒"是在**告诉**读者一个延迟；电影是让观众**看见**那个延迟，而且观众会本能地想再看一次——但电影不给。

- 手法：固定机位对镜，一镜到底；用画外音（有人叫名字）触发"同时回头"
- 失效风险：给了特效（镜面波动、裂纹）就降格为鬼片。**镜面必须一直是完美的**

**短视频 ◎**：因为可以**循环**。观众第一次看，觉得正常；视频自动重播，第二次看，发现镜中人抬手的方向不一样。**循环 = 免费的第二次观看 = 时间错位的最佳放大器。** 这是所有媒介里唯一能"零成本重看且不破坏体验"的形式。

### 3.7 窥视与被窥视 → 电影 ◎ / 游戏 ◎ / 音频 ◎

**电影 ◎**：窥视母题的核心是"画幅"——门缝、取景器、猫眼。电影天然有画框，而画框本身就是窥视的工具。希区柯克之后这条路已经被走透，但**当代变体**（监控画面、行车记录仪、直播）仍有大量空间。

- 手法：全片用"监控画质"拍摄，观众以为自己在看资料；最后一镜，画面里的人抬头看镜头
- 失效风险：变成"变态杀手视角"（有动机就降格）

**游戏 ◎**：如 §2 结论二，游戏能让"看"变成资源。夜视仪耗电、回放占带宽、翻照片要花时间——**玩家每看一眼都在算账**，这直接对应母题的道德-仪式层（"看是免责的"这条被破）。

**音频 ◎**：窥视靠"声源与镜头朝向相反"，而音频里没有镜头，只有声源——所以它能把这条 e₁ 做得更纯：**你听到左边有人说话，但那个位置是墙。**

### 3.8 仪式与禁忌 → 短篇 ◎ / TRPG ◎

**短篇 ◎**：仪式是**清单**，清单需要被完整展示一次，然后只缺一项。短篇的篇幅刚好装下"清单展示 + 执行 + 事后发现"，超过就显得拖。

- 手法：把清单**逐项写出来**（一、二、三…七），让读者跟着数；事后只提一次"她记得自己是从第二个结开始的"
- 失效风险：清单写得太笼统（"进行了一系列仪式"）——读者无法跟着数，一错就没有着落

**TRPG ◎**（本矩阵最强的一格）：因为**规则本身就是仪式**。玩家掷骰、按顺序行动、宣读技能名——这些动作在机制层就是"规程可复述"。当 KP 说"你确定要这么做吗"，玩家就已经在被规程约束了。而跑团最恐怖的时刻，从来不是怪物出现，是**KP 说"好的，你成功了"**——因为玩家会立刻意识到：成功不等于正确。

- 手法：给玩家一份必须照做的清单（进房间前要念的祷词、要摆的蜡烛数）；某次允许他"跳过一步"，并且判定为成功
- 失效风险：把仪式做成解谜（"破解仪式就能赢"）——那就变成推理了

## 4. 媒介原生恐怖机制表

每种媒介都有一件**只有它能做**的事。用不上这一件，就等于用错了媒介〔C〕。

| 媒介 | 原生机制 | 怎么用 |
| --- | --- | --- |
| 长篇 | **耐力** | 让读者读三百页还没见到那个东西，等待本身成为崇高 |
| 短篇 | **密度** | 一个晚上、一场丧事、一次开棺，全程不跳 |
| 剧集 | **间隔** | 周更的信息真空期；片头曲改一个音；集末给新矛盾而非答案 |
| 电影 | **画框** | 门缝、取景器、画幅变化；不给喘息的长镜 |
| 游戏 | **亲手验证** | 让玩家自己做检验动作，再亲手推翻它 |
| TRPG | **规则即仪式** | 判定成功但结果不对；允许玩家跳步并"成功" |
| 装置 | **观众的身体** | 观众必须走、必须弯腰、必须挤过窄道；出口设计成"回到入口" |
| 短视频 | **循环** | 自动重播制造第二次观看；卡点对齐 e₁ 出现的那一帧 |
| 音频 | **声源不可见** | 双耳录音做"背后"；声音的空间位置与现实不符 |
| 漫画 | **静帧共存** | 一格内同时呈现"完整"与"正在坏"；跨页占满视野 |

## 5. 选择决策树

```
你要写的恐怖，核心是"账"还是"界"？
│
├─ 账（谁欠谁、谁该被超度）→ 关系型
│   ├─ 有群像/家族 → 剧集 / 长篇
│   ├─ 只要一个夜晚 → 短篇
│   └─ 要"只听不看" → 音频
│
└─ 界（哪条分类线被撬了）
    ├─ 是"空间卡住了"（内/外）→ 阈限
    │   ├─ 要观众亲历 → 游戏（步行模拟）/ 装置
    │   └─ 要观众旁观 → 电影（宽画幅长镜）/ 短视频（循环）
    ├─ 是"身体不是我的了"（自我/他者）→ 异化
    │   ├─ 要给"过程" → 电影（不切的长镜）/ 漫画（跨页）
    │   └─ 要让观众也疼 → 装置
    ├─ 是"框架失效了"（可知/不可知）→ 未知
    │   ├─ 要累积三次推翻 → 长篇 / 剧集
    │   └─ 只能一次 → 短篇（写"解释的失败"）
    ├─ 是"我数不清自己"（一/多）→ 镜像
    │   ├─ 要精确的"半拍" → 电影
    │   └─ 要免费的第二次观看 → 短视频（循环）
    ├─ 是"看不再免责"（看/被看）→ 窥视
    │   ├─ 要让看有代价 → 游戏（资源化）
    │   └─ 要声源错位 → 音频
    └─ 是"规程有效但对象错了"（许可/禁制）→ 仪式
        ├─ 要读者跟着数 → 短篇（清单）
        └─ 要玩家跟着做 → TRPG
```

## 6. 跨媒介改编：换媒介时该改哪个参数

同一个故事换媒介，**不能只换皮**。公式里真正需要重算的是 I 和 e₁ 的形态〔C〕：

| 改编方向 | 必改参数 | 原因 |
| --- | --- | --- |
| 小说 → 电影 | e₁ 从"叙述"改为"画面"，I 从"文字留白"改为"画外空间" | 小说能写"她数了数碗"，电影必须让观众看见碗 |
| 电影 → 游戏 | e₁ 从"被动看到"改为"玩家亲手触发" | 参与度变了，观众变成了责任人 |
| 游戏 → 剧集 | I 从"玩家探索"改为"编剧配给" | 玩家原本自己控制信息量，剧集必须替观众控制 |
| 短篇 → 短视频 | R 必须压缩到 3 秒内可识别 | 90 秒里没有时间做规程展示，只能靠类型共识 |
| 任何 → 音频 | 删掉所有依赖视觉的符号组，重配声音版 | 单通道，视觉符号全部失效 |
| 任何 → 装置 | R 从"叙事规程"改为"空间规程" | 观众不走完就不算完成，空间顺序即叙事顺序 |

**最容易翻车的一格**：小说 → 游戏。小说里的 e₁ 是作者给的，游戏里的 e₁ 是玩家**可能错过**的。所以改编时必须把 e₁ 做成"必经之路"——放在主线上，不能放在支线收集品里。

## 7. 本文档边界

- 全部评级（◎○△✕）与五个控制维度为**创作化引申（C 档）**，不是媒介研究界的共识，也没有量化依据；它是给创作者用的取舍工具。
- 媒介分类是粗颗粒的："游戏"包含步行模拟、生存恐怖、叙事冒险等差异极大的子类，同一母题在不同子类里评级会移动（例如「身体异化」在生存恐怖里可以到 ◎，因为需要玩家管理身体资源）。
- 表中"短视频"特指 15–90 秒的竖屏或横屏短片，不含 3 分钟以上的短片电影。
- 引用作品（希区柯克等）仅作类型坐标，不构成对其作品的完整评价。
