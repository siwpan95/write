# M7 · 文化圈矩阵：七种「账怎么算」

> 完成：2026-11-21｜对应欠账 M7（P2）
> 04 号材料只有三条对照轴（中日／欧美哥特／克苏鲁），且写作「东方＝关系型」。
> 本表扩到七个文化圈，并且**先把那句话拆掉**——见 §0。

---

## 0. 先拆一句老话：没有「东方＝关系型」这回事

04 与 01 都写：东方偏关系型（鬼是未结清的关系），西方哥特偏历史型（祖先之罪）。

**这句话作为创作快捷方式是有效的，作为文化判断是错的。** 三个理由：

1. **东亚内部差异极大**：日本御灵信仰的制度形态（怨灵→御灵→天神，被国家收编）与中国志怪「索债可超度」不是一套账；朝鲜半岛的「恨」（한）传统又是一种。
2. **西方也有关系型**：爱尔兰、苏格兰的报丧女妖（banshee）本质是**血缘家族的传信人**，不是历史罪；东欧吸血鬼叙事里「未埋对／未办完丧仪」的债，比「祖先之罪」更接近关系型。
3. **「文化本质化」是创作陷阱**：一旦把某个文化钉成一种恐怖类型，写出来的就是该国旅游宣传片式的恐怖——所有元素都在正确位置上，但没有人真的害怕。

**本表的用法**：不是「某国恐怖是什么」，而是「**某套账本长什么样，因此能长出什么压力**」。
一个文化圈内部通常同时存在好几套账本，作者挑其中一套写即可。

> 证据档位：本表全部为 **B/C 档**（民俗综述＋创作引申），**不是人类学定论**。
> 表内具体民俗事项（节日日期、术语）有通行说法支撑，但**未逐条联网复核，不作出处断言**；若对外发表须先补核。

## 1. 七种账本

### 1.1 中日 · 关系账（原有）

| 项 | 内容 |
|---|---|
| 账怎么算 | 谁欠谁、欠多久、是否已由祭祀结清。债是**人与人之间**的，鬼只是催收员 |
| 恐怖来源 | 亏欠与羞耻：不是「它要害我」，是「我（或我家）没做该做的事」 |
| 出口 | 有——超度、谢罪、改葬、祭祀。**但可以不做**（这正是关系型的力量） |
| 最适母题 | 怨灵（4）为主，仪式（8）为流程，阈限（5）作容器 |
| 配方 | 规程（祭祀）→ 一错（供品少一份无人承认）→ 出口存在但被继承人放弃 |

### 1.2 欧美哥特 · 历史账

| 项 | 内容 |
|---|---|
| 账怎么算 | 祖先之罪记在家族档案上，后代**继承债务**而非继承财产 |
| 恐怖来源 | 档案本身：地契、血统、被涂黑的教区记录。你查得越深，越发现自己是被追债的那个 |
| 出口 | 有——驱魔、封印、焚毁。**但代价是毁掉证据，也就毁掉了自己合法性的来源** |
| 最适母题 | 未知（3）＋窥视（7）：档案即窥视装置 |
| 配方 | 一份自相矛盾的档案 → 追查者逐渐变成被记录者 → 烧掉档案＝放弃继承权 |

### 1.3 克苏鲁 · 系统账（原有）

| 项 | 内容 |
|---|---|
| 账怎么算 | **没有账本**。宇宙不记账，也不欠你。所谓「代价」只是物理后果，不是道德结算 |
| 恐怖来源 | 尺度与框架失效：理解本身造成不可逆崩解 |
| 出口 | 无——只给延缓 |
| 最适母题 | 未知（3）为主，阈限（5）与窥视（7）为辅 |
| 配方 | 三次信息，每次推翻上一次 → 专家先崩 → 结尾不给全景 |

### 1.4 拉美 · 在场账（**新增**）

| 项 | 内容 |
|---|---|
| 账怎么算 | 死者**不是离开的人，是在场的邻居**。账不是「欠」，是「你是否还留了位子」——亡灵节（11 月 1–2 日）摆供、引路、留座，是**邀请**而非祭祀；墨西哥民间对「圣死」（Santa Muerte）的崇拜则把死亡本身人格化为可交涉的对象（该信仰长期受天主教会批评） |
| 恐怖来源 | **不是被索债，是被要求参与**：死者按老规矩回来，要求你继续和他过日子；而你若不认他，他就一直在客厅里 |
| 出口 | 半有——你可以请他回去，但**必须承认他来过**。否认比驱赶更危险 |
| 最适母题 | 怨灵（4）＋镜像（6）：回来的那个「是原来的他吗」——但重点不在真假，在**要不要给他留座** |
| 配方 | 一场照常举行的家宴 → 一错（多摆了一副碗筷，没人承认是谁摆的）→ 所有人照常吃完，只有一个人没吃 |
| 与其他账本的区别 | 中日：鬼要债；拉美：鬼要**席位**。前者可以赔清，后者赔不清——因为席位是身份，不是钱 |

### 1.5 西非 / 非裔离散 · 血统账（**新增**）

| 项 | 内容 |
|---|---|
| 账怎么算 | 祖先是**制度性在场**（约鲁巴 Egun／Egungun 面具传统）；账是血统与供奉的循环——你被供养，也因此**被指派** |
| 恐怖来源 | **被选中**：不是被报复，是被征用。你要成为容器，而这件事是荣誉，所以不能拒绝 |
| 出口 | 无出口，只有**接受**。拒绝＝切断血统，比死更糟 |
| 最适母题 | 仪式（8）＋身体异化（2）：身体被让出（对应「狂喜型」温度） |
| 配方 | 一场必须参加的入族礼 → 一错（名录上多了一个名字，是活人的）→ 仪式成功，作用对象是主持者 |
| 与其他账本的区别 | 中日：你是欠债人；这里：你是**候选人**。前者要你还，后者要你上 |

### 1.6 北欧 · 产权账（**新增**）

| 项 | 内容 |
|---|---|
| 账怎么算 | 死人不放弃**产权**——draugr（古诺尔斯不死者）守墓、守财、守地界；vættir（地方灵）守的是「这块地的规矩」 |
| 恐怖来源 | **所有权不因死亡转移**：你继承的是地，不是地里的那个人；他还在，且他比你更有资格 |
| 出口 | 有——但要走**法律程序**（移葬、立界石、补偿），不是驱魔。**用错方法就变成械斗** |
| 最适母题 | 阈限（5）＋死亡（1）：门里门外、地上地下 |
| 配方 | 一份产权交割 → 一错（界石换了位置，且是旧的那块被挪回来的）→ 你打不赢，因为对方的名字还在地契上 |
| 与其他账本的区别 | 拉美：死者要席位；北欧：死者要**产权**。前者是身份，后者是物 |

### 1.7 南亚 · 未完成账（**新增**）

| 项 | 内容 |
|---|---|
| 账怎么算 | 不是「欠」，是「**没做完**」：preta（饿鬼）是有未偿之业、被卡在无法完成状态的亡者；śrāddha（祖灵祭）是让死者完成过渡的手续。vetala（尸鬼）则是「借尸者」 |
| 恐怖来源 | **永远差一步**：它饥饿、它伸手、它吃不到。恐怖不在恶意，在**无能**——而你也可能变成它 |
| 出口 | 有，但要**代它完成**。而代它完成意味着你要暂时变成它 |
| 最适母题 | 死亡（1）＋仪式（8）：饿与喂，是同一件事的两面 |
| 配方 | 一份该按时完成的祭仪 → 一错（该给的那一份，给了但没落地）→ 它吃不到，所以它一直在吃 |
| 与其他账本的区别 | 中日：债要还；南亚：活**没干完**。还债有清账日，干活没有 |

## 2. 横向对照：七种账本一张表

| 账本 | 债的主体 | 恐怖来自 | 出口形态 | 主母题 | 一句配方 |
|---|---|---|---|---|---|
| 中日 · 关系 | 人与人（家族） | 亏欠与羞耻 | 可和解但可被放弃 | 怨灵 | 少一碗，无人承认 |
| 欧美 · 历史 | 家族档案 | 你查得越深越是被追的那个 | 可驱除但要毁证据 | 未知＋窥视 | 两份盖章文件互相矛盾 |
| 克苏鲁 · 系统 | 无 | 框架失效 | 只给延缓 | 未知 | 三次推翻，永不全景 |
| 拉美 · 在场 | 席位与身份 | 死者在场，要你继续过日子 | 承认即和解，否认更危险 | 怨灵＋镜像 | 多摆一副碗筷 |
| 西非 · 血统 | 血统与指派 | 被选中（荣誉型的灾难） | 无，只有接受 | 仪式＋身体 | 名录上多一个活人的名字 |
| 北欧 · 产权 | 地契与界石 | 所有权不因死亡转移 | 走法律程序，不是驱魔 | 阈限＋死亡 | 旧界石被挪回原位 |
| 南亚 · 未完成 | 未竟之事 | 永远差一步的无能 | 代它完成，代价是变成它 | 死亡＋仪式 | 该落地的供，落不了地 |

## 3. 三条可迁移的规律

### 规律 1 · 出口的形态，决定恐怖的温度

把七种账本的出口按「能不能了结」排一条线：

```
克苏鲁（无）  <  西非（只有接受）  <  南亚（代它完成＝自己变形）  <  中日/北欧（可办但要付代价）  <  拉美（承认即和解）
   最冷                                                                                          最温
```

**这条线可以用来给作品定温度，比拍脑袋选「关系型/系统型」更硬**：
你先定「这本小说的世界里，账能不能结」，温度就自动落在某一段上。

### 规律 2 · 「被索债」和「被填位」是两种完全不同的恐怖

| | 被索债（中日／欧美／南亚） | 被填位（拉美／西非／北欧） |
|---|---|---|
| 你有主动权吗 | 有：还、赔、办手续 | 没有：位置本来就该有人坐 |
| 恐怖感 | 焦虑（我该做没做） | 窒息（我本来就不该在这儿） |
| 崩解方向 | 关系崩解 | 身份崩解 |
| 对应母题 | 怨灵／仪式 | 镜像／身体异化 |

**做长篇时，这两条不要混**：混了会让读者不知道主角该「还债」还是「让位」，两条线的解法互相抵消。
（这与 `02_母题×媒介矩阵` §6 那个「跨媒介改编必改参数」是同一类纪律：**换轴就要换解法**。）

### 规律 3 · 越接近「制度性在场」的文化，恐怖越接近喜剧

西非的 Egungun 与拉美的亡灵节，在本地语境里**首先是节庆**，恐怖是副产品。
这不是「他们不认真」，而是：**当死者被制度性地安排好了位置，恐怖就从"他会来"变成"他来了以后怎么办"**——
后者天然带喜剧性（因为要处理的是**相处**，不是**对抗**）。

**创作含义**：想写「既恐怖又好笑」的东西，不要往克苏鲁方向走，往拉美／西非方向走。
想写纯粹的恐怖，反而要**把死者的位置抽掉**（这就是哥特与克苏鲁做的事）。

## 4. 与八母题、五温度的接法

| 文化圈 | 默认温度 | 为什么 |
|---|---|---|
| 中日 | 关系型·温 | 出口存在，可被放弃 |
| 欧美哥特 | 系统型·冷（偏档案） | 出口要毁证据，毁完世界就空了 |
| 克苏鲁 | 系统型·冷／崇高型·史诗 | 无出口 |
| 拉美 | 关系型·温（偏喜剧） | 出口是「承认」 |
| 西非 | 狂喜型·ecstatic | 被选中＝转化即奖赏 |
| 北欧 | 身体型·黏（偏物） | 产权纠缠是慢的、粘的、不流血的 |
| 南亚 | 身体型·黏＋关系型·温 | 饿是身体的，未完成是关系的 |

**注意**：上表是**默认值**，不是限制。反着写往往更有力——例如北欧账本配系统型冷恐怖（产权登记系统的冷漠），
就得到一种很少见的恐怖：**没有鬼，只有不动产**。

## 5. 边界与免责

- 本表**不是**民俗学或人类学结论，是创作对照工具（C 档）。任何「某文化如何如何」的表述都应理解为**创作假设**。
- 七个文化圈内部差异极大（拉美包含原住民、天主教、非洲离散三层；「西非」本身是殖民地理概念，约鲁巴／达荷美／阿散蒂各不同）。**用之前先确定具体族群与地区**，否则写出来的是拼贴。
- 拉美「圣死」崇拜、西非祖灵仪式、南亚祖灵祭等涉及**活人信仰**。按本项目一贯纪律：**保留敬畏，恐怖来自误用而非嘲弄**。
- 具体日期与术语（11 月 1–2 日、Egun、draugr、preta、śrāddha、vetala）为通行说法，**本次未逐条联网复核**；对外发表前须补核，补核方法见 `03_M6引用核对表.md` §6。
- 本表**不得**用于「哪个文化更吓人」的比较——那是伪问题。可比的是**账本结构**，不是恐惧强度。
