## 0. 为什么改用真实作品验

M9 上一轮写完《归因》8000 字后，我列了三项余量：多 POV、跨卷、跨 Mode 转换。
当时的默认思路是"再写三个样本"——那是笨办法，而且会得到一个必然结论：我自己写的样本，当然符合我自己的框架。

**用真实作品验，才能证伪。** 仓里正好有三个现成的靶子：

| 余量项 | 目标作品 | 为什么是它 |
| --- | --- | --- |
| 多 POV | `其他项目归档/聊斋志异同人/《志异司》立项全案.docx` | 明确设计**六个 POV、三条主线**，自带群像硬指标 |
| 跨卷 | `提交确实未创建/`（120 章 / 4 卷 / 619,064 字） | 单 POV 第一人称，跑满 61.9 万字仍完稿收线 |
| 跨 Mode | 同上，**首章 vs 末章** | 首章是规则怪谈恐怖，末章是道德抉择 |

## 1. 多 POV ·《志异司》

### 1.1 目标

- 体量：120 章 / 五卷 / 约 40 万字（**立项案阶段，正文未写**）
- 类型：男频 · 古典志怪 · 群像探案 · **妖视角** · 无穿越
- 视角方案（原文）：

> 「本书不是单主角叙事。六个人轮流当叙述者，每人有自己的主问题、独立的高潮和自己的『自我欺骗』。桑七只是第一主视角，占约 **52%** 篇幅；崔九娘、沈砚各有独立线，陆判、屠三、反派各有辅线。」
> 「三条线互相牵制，不是互相帮忙——这是群像的发动机。」

它自己还定了五条「群像硬指标」：多角色等量权重、每条线独立成立、**读者比每个角色都知得多**、交棒有理由（悬念高点／信息差／情绪承接）、同时活跃 3—5 条。

### 1.2 用框架检验：e₁ 在多 POV 下会怎样

我的框架里，e₁ 是「恰好一处没照做」，靠**角色用日常动作检验**来落地。
单 POV 下这很干净：一个人做检验，一个人被推翻。

多 POV 下，同一条 e₁ 会面临三种命运：

| 命运 | 表现 | 后果 |
| --- | --- | --- |
| **A 复制** | 每个 POV 都撞见同一个异常 | **稀释**。读者会算概率，「六个人都碰上」不是恐怖，是巧合 |
| **B 分摊** | 每人只看到一部分，拼起来才是全貌 | **增强**。读者拼图，e₁ 从"某物不对"变成"世界缺了一块" |
| **C 误认** | 不同 POV 对同一异常给出不同归因 | **转移**。从"世界不对"变成"人不诚实"——这是罗生门，不是恐怖 |

**《志异司》选的是 B**，而且选得很自觉：它的第三条硬指标直接写「读者比每个角色都知得多，靠『谁不知道什么』制造张力」。

### 1.3 发现：B 路线与 horror 模式**不兼容**

这是我原本没写进 `docs/07` 的一条：

> **B 路线（分摊）会强制抬高 I。** 读者知道得比每个角色都多，等于 I 被拉到高位。
> 而 horror 要求 I 低（永不全景、三次推翻）——**两者在参数上直接冲突**。

所以一个"多 POV + 群像"的作品，**天然写不成纯 horror**。它只能落在：

- `thriller`（I 中：给线索、藏动机）——最贴《志异司》的"探案"骨架
- `drama`（I 高：全景）——最贴它的"六人各有主问题"

**修正建议（已实施于本文件，待回写 `docs/07`）**：Mode 表需要加一列「POV 结构」。

| Mode | 单 POV | 多 POV |
| --- | --- | --- |
| horror | ✅ 原生 | ✗ 参数冲突（I 被抬高） |
| thriller | ✅ | ✅ 原生（信息差就是它的引擎） |
| drama | ✅ | ✅ 原生 |
| tragedy | ✅ | ✅ |
| satire | ✅ | ✅（多视角看同一荒唐事，效果更强） |
| epic | ✅ | △ 视角一多，尺度感会被拉平 |

**一句话**：**想写恐怖，收视角；想写群像，换 Mode。** 这不是写作偏好，是 I 参数的硬约束。

### 1.4 抽样边界

本文档为立项案，**正文未写**。以上是对其**设计意图**的分析，不是对成品的评价——设计意图能不能落地，要等它真的写完 120 章才知道。

## 2. 跨卷 ·《提交确实未创建》

### 2.1 目标

- 120 章 / 4 卷 / 619,064 字，四卷各 30 章，**全书完稿**
- 类型：无限流（中式规则怪谈 × 键盘／仓黑话）
- 视角：**全书第一人称「我」，不自称姓名**
- 状态：字数越界 0 章，四条长线均已收线

### 2.2 追踪 e₁：章名本身就是一部演化史

不用读正文，光看 120 个章名就能看出 e₁ 怎么走（抽样：四卷首尾各 4 章，共 16 个章名）：

| 卷 | 首章 | 末章 |
| --- | --- | --- |
| 一 · L1 新手圈 | 001 冰箱多出来那份没写名字 | 030 这行补不补得先过判位那关 |
| 二 · L2 主城圈 | 031 判位三日里我只读记录 | 060 顶替那笔账翻出来了 |
| 三 · L3 跨界圈 | 061 跨过接缝先把旧账带上 | 090 差点把她那串数记混 |
| 四 · L4 终局圈 | 091 判位十五日只读记录 | 120 补一条还是连仓一起没有 |

中间还有几个关键节点：`010 登记处翻到底确实没有我` / `047 排班表少了一个名字` / `117 排班表终有那个名字` / `119 冰箱里那副筷子还留着`。

**读出来的东西**：

1. **e₁ 从没漂**。全 120 章只有一件事"不对"：**册子里没有「我」这一行**。
   从 001 的"多出来一份没写名字"，到 010 的"查无此行"，到 117 的"终有那个名字"，到 120 的"补一条还是连仓一起没有"——是**同一处异常的四个阶段**，不是四件怪事。
2. **收口方式回到了起点**。119 章「冰箱里那副筷子还留着」召回第一章的"多出来的那副筷子"，120 章把最初的「位置未定」变成一道**二选一的抉择**。
3. **四卷圈层＝phase 的宏观版**：L1 新手圈（设：学规则）→ L2 主城圈（压：规则加压）→ L3 跨界圈（翻：两套规矩）→ L4 终局圈（竭：用完，必须抉择）。

这直接验证了 `docs/07` §4 的 L2 编排：**phase 不只在场景层成立，在卷层同样成立**。

### 2.3 跨卷不漂的机制（可迁移的三条）

| 机制 | 该书怎么做 | 为什么有效 |
| --- | --- | --- |
| **e₁ 只有一个，但可被多次「重新解释」** | 「没有我这一行」→ 先是异常，再是查证对象，再是账目问题，最后是抉择筹码 | 同一个事实，每卷换一个**用途**，读者不腻，e₁ 不散 |
| **每卷换「圈层」，不换「轴」** | L1 新手圈→L4 终局圈，轴始终是 `registry`（在册／不在册） | 换壳不换核。换轴会让读者觉得"这不是同一本书" |
| **首尾物件呼应** | 多出来的那副筷子（001）→ 筷子还留着（119） | 给读者一个**可核对的坐标**：从哪儿来，回哪儿去 |

> 第三条值得单独说：**跨卷作品需要一个"物理锚点"**。它不是象征，是一个具体物件，在开头出现过、在结尾还在。
> 读者记不住 120 章的因果链，但记得住"那副多出来的筷子"。

### 2.4 抽样边界

读了：`作品总览.md` 的完整章节目录（120 条章名）、第 001 章前 60 行、第 120 章前 55 行。
**没读**：中间 118 章正文。所以「e₁ 未漂」的结论建立在**章名序列 + 首尾文本**上，是结构层证据，不是逐章核对。

## 3. 跨 Mode 转换 · 同一本书的首尾

### 3.1 文本证据

**第 001 章**（前 60 行抽样）的写法：

> 「你知道吗？当你连按Tab键九九八十一下，你就会成为下一个取经人。」
> 「我伸手按了第一下Alt，然后就停不下来。」
> 「盒子侧面贴了张小回执，印着登记处三个字，下面一行：位置未定。」
> 「翻到最后一页，贴着一张更小的回执，上面四个字：查无此行。」

特征：**低 I**（不给全景，只给一张便条、一张回执、一本册子）、**陌生化**（读者和角色一样不知道规则）、**检验动作是手**（摸压痕、刮纸面、数页数）。

→ 这是 **horror**，且是制度型恐怖（`registry` 轴）。

**第 120 章**（前 55 行抽样）：

> 「左边一张空白条子。纸很新，白得晃眼，末尾已经印好四个字：位置未定。右边一根细铁签……」
> 「「一条补，一条抽。」他把手收回去，插进袖子里，「挑一样，剩下那件我收走。」」
> 「「补你缺的那条。」……「押上你剩下的全部现实，换一行新的。」」
> 「「抽呢。」／「签一出来，册页就散。」……「这一层的册子，跟着一起作废。」」

特征：**高 I**（规则全摊开，代价明码标价）、**代价可计量**（押上"剩下的全部现实" vs 整层作废）、**结构是抉择**（二选一，且两个选项都贵）。

→ 这是 **drama/tragedy**，不是 horror。

### 3.2 转换点在哪

从章名推断（抽样：四卷首尾各 4 章）：转换发生在 **L3 跨界圈末 → L4 终局圈**。

- L3 的章名还在解谜（`087 空括号那页翻到了底` / `088 坏账原来从上一任起`）；
- L4 一开场就是代价（`092 四通道每一条都要付价`），末章直接是二选一。

更准确地说：**"知道真相"（L3 结束）与"为真相付账"（L4 开始）之间**。

### 3.3 跨 Mode 转换成立的条件（从这一例反推）

| 条件 | 该书是否满足 | 说明 |
| --- | --- | --- |
| **同一个 e₁，不是新开一个** | ✅ 满足 | 从头到尾都是"册子里没有我" |
| **转换由「信息量」驱动，不由「调性」驱动** | ✅ 满足 | 不是因为"写到后面想换个风格"，而是因为**谜底揭开了**，I 必然升高 |
| **转换后不能回退** | ✅ 满足 | 120 章之后没法再回到"不知道规则"的状态 |
| **转换要在驱动器上留接口** | ✅ 满足 | 前 90 章积累的"账"（坏账、遗留、顶替）正好成为末章的抉择筹码 |

**反过来说，什么情况下不该转**：

- 如果 I 的升高不是你主动设计的，而是"写到后面瞒不住了"——那不是 Mode 转换，是**失控**。
- 如果转换后 e₁ 换了（从"没有我"变成"有人要害我"）——读者会认为你换了本书。

> **一句话**：跨 Mode 转换不是换风格，是 **I 参数被迫升高之后的必然结果**。
> 你控制不了 I 什么时候升（谜底总要揭），但你可以控制**升完之后往哪个 Mode 落**。

### 3.4 抽样边界

只读了首章 60 行、末章 55 行。中间 90 章的转换过程**是推断**，依据是章名的语义变化。若要与作者核对，需要读 L3 末几章。

## 4. 三项余量的结论

| 余量项 | 结论 | 对框架的修正 |
| --- | --- | --- |
| **多 POV** | **B 路线（分摊）会强制抬高 I，与 horror 参数冲突** | `docs/07` Mode 表需加「POV 结构」列：horror 只适配单 POV；群像必须落 thriller/drama |
| **跨卷** | e₁ 可以跑满 61.9 万字不漂，**前提是每卷换用途不换轴 + 留一个物理锚点** | `docs/07` §4 补充：phase 在**卷层**同样成立（设/压/翻/竭 = 四卷圈层） |
| **跨 Mode 转换** | 成立条件是「同一 e₁ + 信息驱动 + 不可回退 + 驱动器留接口」 | `docs/07` §3 补充：转换不是选风格，是 I 升高后的落点选择 |

### 三条新增的可操作规则（已可回写 `docs/07`）

1. **视角数与 Mode 强相关**：horror 收视角，群像换 Mode。不要试图用六个 POV 写纯恐怖。
2. **跨卷不换轴，只换用途**：一条轴（如 `registry`）可以被"重新解释"四到五次，但换轴等于换书。
3. **跨 Mode 转换必须挂在一个既有的「账」上**：前文积累的未结算项，就是后文转换的接口。没有这个接口，转换会显得突兀。

## 5. 边界与未做

- 三例都是**抽样分析**，抽样范围已逐例标注。**未读全书，不下全书结论。**
- 《志异司》是立项案（正文未写），对其分析的是设计意图，不是成品效果。
- 《提交确实未创建》的跨 Mode 转换点（L3 末→L4 初）是**从章名推断**，未逐章核对。
- 本文档**不评价这三部作品的好坏**，只检验框架能否解释它们的结构。
- 反过来说也成立：**框架能解释，不等于框架正确**。这三例都是"按框架能自圆其说"的样本，缺少反例。
  真正的证伪需要找一部"e₁ 明确漂了但仍然好看"的作品——那会推翻"e₁ 唯一"这条铁律。本次没有找到，也不排除存在。
