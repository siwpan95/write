# 跨题材母题扩库（C–F 组）与四个公式变体

> 版本：v1.0 ｜ 2026-11-22 ｜ 前置：`docs/00–11`
> 本次是**扩库**，不是改造：已有 16 条（A 组本体 / B 组制度）**一字不动**，新增 16 条（C–F 组）+ 4 个公式变体。
> 证据分档沿用 `00 §4`：**A** 可核验／**B** 学界解读／**C** 创作化引申／**D** 社区共识／**❓** 未核原文（不得断言）。
> **本文全部母题与变体为 C 档**；所引理论只作"同向支撑"，**不作背书**——这句话在 `03 §3` 已经立过，此处重申。

---

## 0. 一句话

前 16 条母题回答"世界怎么构成、社会怎么运转"；新增 16 条回答**"世界怎么被计算、被消耗、被共享、被记住"**。

而四个变体的共同点，比母题更重要：

> **它们不改 I 与 E，改的是 e₁ 的形态。**
> 原式假设 e₁ 是"多了一处不该有的"（闯入）。但恐怖还有另外四种长法：**少了一处该有的**（缺席）、**差了一段量**（位移）、**说的被一字不差做到**（兑现）、**一边被越过**（越界）。

## 1. 缺口在哪，为什么是这四组

`08 §0` 自己诊断过：零件库"能造一个压得死人的衙门，造不出一具不肯腐烂的尸体"，于是补了 A/B 组。
但 A/B 组仍有一个共同坐标：**它们都是"有人负责"的世界**——要么有制度可找（B 组），要么有鬼可谈、有尸可验（A 组）。

一旦题材进入"**没有人负责**"的世界——系统、尺度、亲密关系、自己的记忆——现有 16 条会错位：

| 题材 | 现有 16 条的失效方式 |
| --- | --- |
| AI／算法／平台 | 只能套 `unknown`（"不可名状"），结果写成"神秘黑箱 AI"，落回 1950 年代科幻 |
| 气候／生态／缓慢灾难 | 只能套 `death`（"死亡"）或 `liminal`（"空间"），写不出"**地方还在，但已经不是它**" |
| 家庭伦理／亲密关系 | 只能套 `debt`（"欠债"）或 `name`（"名分"），写不出"**爱与控制同源**" |
| 记忆／注意力／语言 | 只能套 `mirror`（"分身"）或 `registry`（"记录"），写不出"**没有被改，只是被替换**" |

四组新母题，就是补这四个洞。

## 3. 公式族谱：e₁ 的五种形态（本文的核心贡献）

原式 `T = (R − e₁) × Δ − I − E`（旧记 Δm，见 `07` 记号声明 `Δ ≡ Δm`）隐含一个假设：**e₁ 是"多出来的那一处"**。
但 e₁ 可以长成五种样子，每一种对应一族作品、一个变体、一套写法。

| 形态 | 定义 | e₁ 长什么样 | 变体 | 典型体验 |
| --- | --- | --- | --- | --- |
| **① 闯入** intrusion | 多了一处不该在的 | 门后多一条走廊 | 原式 **T** | 恐惧 |
| **② 缺席** absence | 少了一处该在的，**且无人发现少了** | 办公室空无一人，灯还亮着 | **T_E** | 诡异 |
| **③ 位移** displacement | 现值与参照的差，渐进且不可逆 | 门牌没变，树换了 | **T_S** | 失所 |
| **④ 兑现** fulfillment | 说的被一字不差做到 | 愿望精确实现 | **T_B**（巴克） | 狂喜／战栗 |
| **⑤ 越界** transgression | 边界清楚，且被越过 | "为你好"越过了"不" | **T_I** | 窒息 |

**这张表解决了一个旧问题**：`07 §8` 说 T_B 是"公式的边界证明"，但没说它为什么是边界。现在清楚了——**T_B 不是边界，是第四种形态**。它之所以看起来像叛徒，是因为原式只承认一种 e₁。

**推论**：`07 §2` 的三条不变式（R 可检验／e₁ 唯一／Δ 单轴）**跨五种形态全部成立**，只需把"唯一"重新读成"**全篇只有一处形态**"——一处缺席 + 一处闯入，等于两处异常，照样降格。

## 4. C 组 · 技术层（世界如何被计算）

> 四条共用一条文明前提：**判定权已经移交给不向你解释的系统**。
> 与 B 组（制度）的区别：B 组的制度由人执行，可以找人；C 组的制度由系统执行，**找不到人**。

### 17 · `blackbox` 黑箱与不可解释

**Δ** 可解释／不可解释 ｜ **默认 I** 高 ｜ **主 Mode** thriller（次：satire）
**核心命题**：结论是确定的，依据是存在的，但依据不向你开放。

| 项 | 内容 |
| --- | --- |
| R 规程 | ①每份判定须附依据编号（可引用、可查）〔A 程序常识〕②当事人有两次申诉权，且须书面答复〔A〕③依据的调阅须在 15 个工作日内答复"可否"〔C〕④同一输入在同一版本下须得同一输出〔C〕 |
| 检验动作 | 连续两次提交**完全相同**的材料，比对编号与结论；查回执上"依据"栏是否为空；查系统版本公告的生效日期 |
| e₁ 候选（★ 载体） | 1 判定书有结论、有依据编号，但那个编号查不到对应文件 ★ **编号在，文件不在**<br>2 两次申诉的答复**一字不差，包括错别字** ★ 同一份模板<br>3 系统回复"已复核，结论不变"，但没有任何复核记录 ★ **无记录的复核**<br>4 升级公告的发布日期，**早于**它开始影响你的日期 ★ 版本号与生效日<br>5 同一份材料两次提交，一次通过一次不通过，**两个理由都成立** ★ 两份回执<br>6 你的"人工复核"获批，签字栏是一个工号，而**该工号已注销** ★ 注销工号 |
| 出口 | 可申诉（要等）；可换机构（换的那家也用同一套系统）；**不可解释**；不可自助恢复 |
| 专属反模式 | ①把黑箱写成"AI 觉醒"（I 爆表，降格为怪物）②最后给一段代码解释一切（E 写死）③让系统"有人格"（一有人格，就变成 25 号母题） |
| **与旧轴分界** | **vs `unknown`**：unknown 是"看清了也没有框架"；blackbox 是"有框架、有答案，只是不给你看"。**判据：能不能拿到一句明确的"涉密，不予提供"。** 能 → blackbox；连这句话都没有 → unknown。 |

### 18 · `proxy` 代理与代行

**Δ** 本人／代理 ｜ **默认 I** 中 ｜ **主 Mode** thriller（次：satire）
**核心命题**：你还在，但以你名义发生的事不止一份。

| 项 | 内容 |
| --- | --- |
| R 规程 | ①授权须书面、限期、可撤销〔A〕②代办须留痕：谁代、代什么、何时〔A〕③本人可随时调取"以我名义发生的一切"〔A〕④撤销后 24 小时内所有接口须停止〔C〕 |
| 检验动作 | 每周拉一次"以我名义"的操作清单；翻授权列表里有没有不认识的 App 与人；查撤销回执编号能否对上停用记录 |
| e₁ 候选（★ 载体） | 1 授权已撤销三个月，代办记录**还在增长** ★ 撤销回执 + 新增记录<br>2 有人用你的身份办事，手续齐全，**包括你本人的签字** ★ 与本人一致的签名<br>3 你的账号在你睡眠时段做了你**白天想做但没做**的事 ★ 时间戳<br>4 代办人工号属于一个**从未入职**的人 ★ 工号<br>5 你被"代为同意"了一份你没看过的协议，条款对你**有利** ★ 有利条款（更可怕）<br>6 撤销授权的入口，**需要先授权才能进入** ★ 死循环页面 |
| 出口 | 可撤销（撤了还在）；可追责（找不到主体）；**不可自证**（无法证明"那不是我"） |
| 专属反模式 | ①让代理有独立人格（一有人格就变成 `mirror`）②写成"身份被盗"的犯罪故事（那是 thriller 的事，不是恐怖） |
| **与旧轴分界** | **vs `mirror`**：mirror 是"有两个我"；proxy 是"只有一个我，但**行为**不止一份"。**判据：有没有第二个身体。**<br>**vs `name`**：name 是"别人认你到哪一级"；proxy 是"你的行为被谁执行"。判据：争的是位子还是手。 |

### 19 · `feed` 投喂与成瘾

**Δ** 我需要／它需要我 ｜ **默认 I** 中 ｜ **主 Mode** drama（次：satire）
**核心命题**：你以为你在用它，其实是它在用你的注意力过日子。

| 项 | 内容 |
| --- | --- |
| R 规程 | ①使用有明确目的与时限〔C〕②停止使用后，生活功能**不受损**〔C〕③平台不因你的停留时长获益〔B 商业常识〕④你可导出全部数据并离开〔A 合规常识〕 |
| 检验动作 | 每周"离线四小时"，记录哪几件事做不成；查屏幕使用时长；数一天里主动搜索的次数 |
| e₁ 候选（★ 载体） | 1 你关掉它三天，发现日程、联系人、付款、门禁**全在它里面** ★ 刷不开的门禁<br>2 "想看"列表里出现你**只在心里想过**的东西 ★ 无输入的行为<br>3 **停电那天**，推荐流比平时更准 ★ 离线更准<br>4 你注销的账号，**还在给别人点赞** ★ 僵尸账号<br>5 你孩子会说的第一个完整句子，是它的广告词 ★ 那句话<br>6 你算了一下：过去一年主动搜索**11 次** ★ 数字本身 |
| 出口 | 可卸载（要重装才能生活）；可断网（社会成本）；**不可退出**（退出即失能） |
| 专属反模式 | ①把算法写成反派（"它想控制人类"）②用"信息茧房"做主题（那是评论，不是故事） |
| **与旧轴分界** | **vs `assimilation`**：assimilation 是"越用越像它"（**主体**在变）；feed 是"越用它越像你"（**它**在变）。**判据：谁在变。** |

**Δ** 原件／副本 ｜ **默认 I** 中 ｜ **主 Mode** thriller（次：tragedy）
**核心命题**：原件已经不存在了，而副本正在被当作原件使用。

| 项 | 内容 |
| --- | --- |
| R 规程 | ①原件须留存，且与副本**可区分**〔A 档案常识〕②副本须标注来源与版本〔A〕③修改须留痕：谁改、改了什么〔A〕④原件与副本冲突时，以原件为准〔A〕 |
| 检验动作 | 抽查一份文件的元数据（创建时间/设备/版本）；比对两个版本的字数与修改时间；找一处"只有原件才有"的瑕疵（折角、污渍、笔压） |
| e₁ 候选（★ 载体） | 1 档案里唯一标"原件"的那份，**元数据显示它是被生成的** ★ 元数据<br>2 你记得的原话与录音不同，而录音**没有剪辑痕迹** ★ 无剪辑的波形<br>3 一份三十年前的合同，用的是**今年的字体版本** ★ 字体<br>4 所有人的证件照，背景里都有**同一片树叶** ★ 同一片树叶<br>5 你上传的原图被"优化"过，优化后**多了一个你没拍的人** ★ 多出的人影<br>6 系统提示"已恢复历史版本"，恢复出来的版本**比现在更新** ★ 版本号倒挂 |
| 出口 | 可回溯（原件已不存在）；可标注（标了无人认）；**不可证明**（没有原件就没有真相） |
| 专属反模式 | ①"其实是 AI 伪造的"作为结局（E 写死，且把恐惧让给了技术说明）②用"假视频"做视觉奇观（无 R，只有效果） |

## 5. D 组 · 生态层（世界如何被消耗）

> 四条共用一条前提：**代价不在当下结算，而在别处、别人、别的年代结算**。
> 与 B 组 `debt` 的区别：debt 是人与人之间的账，可结算；D 组是**人与自然/系统**的账，**结算方式不通用**（钱还不了）。

### 21 · `parasite` 寄生与共生

**Δ** 宿主／寄主 ｜ **默认 I** 低 ｜ **主 Mode** horror（身体型）
**核心命题**：你的身体里还有一位住户，而它认为这是共生。

| 项 | 内容 |
| --- | --- |
| R 规程 | ①身体主权归本人，任何寄居须知情同意〔A 医疗伦理〕②可移除，且移除**不致命**〔A〕③共生须双向获益且**可终止**〔C〕④定期体检可发现异常〔A〕 |
| 检验动作 | 称体重、量腰围、记食量与消耗；每月同角度拍一张照片；查体检单上的"参考值范围"是否逐年变化 |
| e₁ 候选（★ 载体） | 1 体检一切正常，但你的热量摄入**正好等于两个人的基础代谢** ★ 体检单<br>2 你胖的位置，是**另一个人的器官**该在的位置 ★ B 超图<br>3 你戒酒三年，肝功能指标仍按喝酒的人走 ★ 化验单<br>4 牙医说你多了两颗牙，位置在**颌骨内侧** ★ X 光片<br>5 你的过敏源清单，逐年变成**另一个人的** ★ 病历<br>6 伤口愈合是两个人的速度：先快后慢，**中间有停顿** ★ 愈合记录 |
| 出口 | 可切除（切了你会死）；可共存（它不害你）；**不可谈判**（它不认为这是寄生） |
| 专属反模式 | ①给寄生虫一个目的（"它在繁殖"→ 变成怪物片）②用"其实是一种病"收尾（把未知降格为病理，`01 §7` 已列为反模式） |
| **与旧轴分界** | **vs `body`**：body 是"我的身体不像我"；parasite 是"我的身体里**还有一位**"。**判据：能不能指出"多出来的那部分"。** 指得出 → parasite；指不出、只觉得整体不对 → body。 |

1. **有 5 条旧轴被两条新轴同时指向**：`mirror`（18、20）、`unknown`（17、22）、`body`（21、32）、`debt`（24、26）、`speech`（28、31）。

   - `mirror` → **"本条只管同一时刻的第二个身体。"**
   - `unknown` → **"本条只管没有框架；有答案但不给，属 `blackbox`。"**

2. **其余 11 条旧轴未被任何新母题触碰**。这说明新增是"加在空白处"，不是"重排旧图"——A/B 组的骨架不用动。
3. **14 条新母题各自只有一条最易混轴，且判据都是一句话可判**。这比现有 16 条之间的重叠度低，原因不是新增的更严谨，而是**每一条都是先想清楚"和谁像"才写的**。

## 10. 四个变体：T_E / T_S / T_I / T_W

### 10.1 统一说明

**其中 T_W 不是新造的**，是把 `00 §2.2` 已有的巴克变体（T_B）重新归类（见 §10.5）。真正新增的是 **T_E、T_S、T_I** 三个。

四个变体**都不动 R 与 Δ 的结构**，只改 e₁ 的形态与 I/E 的取法。
记号沿用 `07 §4.4` 的建议：`⊖` = 违背，`⊗` = 落在轴上（不产生数值），`⊘` = 缺席。

---

### 10.2 T_E · eerie（缺席）

```
T_E = (R_在场清单 ⊘ e₁_缺席) × Δ_代理 − I − E
```

**改动点**：`R` 从"本来应该怎样"改成"**本该有谁/有什么**"（在场清单）；`e₁` 从"多了一处"改成"**少了一处，且无人发现少了**"。

**核心不是缺席，是三件事同时成立**：

1. **缺席**：该在的人/物不在；
2. **照常运转**：灯亮着、水是热的、排班表还在更新；
3. **无人惊讶**：没有任何角色觉得"这里本来应该有人"。

三者齐备，读者会自动问出那句话：**"谁在维持它？"**——这就是 Fisher 说的 agency（代理）疑问。

**四条操作纪律**：

- **禁止出现怪物**。eerie 一出现实体，就降格为 horror（`05 §3` 症状 1：I 超支）。
- **必须给一个"仍在运转"的物证**：一盏亮着的灯、一列准点的车、一叠摆好的餐具。
- **必须有一个角色把它当正常**（服务员、保安、同事），且这个角色的反应**完全合理**。
- **结尾不给"是谁"**，只给一个"它还在运转"的新证据（灯还亮着，但换了一个房间）。

**微型场景**：

> 值夜班的保安每天巡三次楼。三层东侧的饮水机，每天换一桶新的。他从来没见过送水的人，也没见过有人喝水。他向主管报过一次，主管说："那不是很好吗，省得我们自己换。"
> 他把这一条写进交接本。第二天翻开，上一页有人用同样的笔迹写着同一句话，日期是明天。

> **诊断**：R = 有人换水、有人喝水、交接本连续；e₁ = 没人换但水在换；Δ = 有没有主体在维持。**不出现任何东西，恐怖来自"维持"这个动作本身。**

---

### 10.3 T_S · solastalgia（位移）

```
T_S = (R_参照 − 现值) × Δ_时 − I − E(不可回退)
```

**改动点**：e₁ 不是"一处异常"，是"**两次测量之差**"。所以它需要**两个时间点**，而原式只需要一个。

**三条操作纪律**：

- **必须有一个明确的参照系**：记忆、旧照片、地图、父辈的原话、合同附件。
- **差值要小**：小到可以被解释成"我记错了"，大到不能忽视。这个区间就是恐怖的操作区间。
- **不可回退**：一旦能复原，就变成"修复故事"（`05 §4` 的"换掉账本"）。

**与其他变体的分界**：T_S 不需要怪物、不需要异常事件、不需要凶手。它只需要**同一个人，在同一个地方，量了两次**。

**微型场景**：

> 她每年清明回一次老家，都在村口那棵槐树下拍一张照。今年她把照片和去年的并排放在一起，看了很久。
> 树是一样的。树皮的裂纹、朝东那根断枝、甚至钉在树干上的那块"古树名木"牌子，位置都一样。
> 她翻到十年前那张——树冠比现在小三圈。
> 她问了村里唯一还住着的老人。老人说："那棵啊，前年就死了。现在这棵是后来补的，专门找人照着老照片修的。"

> **诊断**：R = 树该长、该老、该有年轮；e₁ = 树在"长回去"；Δ = 还是不是这个地方。**没有超自然，只有一次对齐得太好的测量。**

---

### 10.4 T_I · intimate（越界）

```
T_I = (R_边界 − e₁) × Δ_关系 − I − E(不能离开)
```

**改动点**：`E` 不是"没有出口"，是"**出口存在，但走不掉**"。这是它与关系型恐怖（"可和解但被放弃"）的关键区别：那里是**主动放弃**，这里是**无法放弃**。

**出口被封死的三层**（三层都要有，否则会写薄）：

| 层 | 封死方式 | 具体物 |
| --- | --- | --- |
| 空间 | 同一个屋子／同一个村／同一份工作 | 门、车钥匙、工牌 |
| 关系 | 爱是留下来的理由 | 孩子、病中的父母、共同贷款 |
| 认知 | 怀疑是自己有问题 | "是我太敏感"这句话 |

**四条操作纪律**：

- **施害者不能是怪物**。他必须"人很好"——邻居都夸他（`05 §2.3`：被破规的人一旦可怜，恐怖变成心疼；这里更进一步：施害者一旦可恨，读者就站到了安全的一边）。
- **伤害必须渐进、可被解释为关心**。每一件单独拿出来都不值得提。
- **必须有一个外人视角，且外人看不出来**。这个外人的"看不出来"就是读者的处境。
- **出口必须真实存在**。否则就变成囚禁故事（thriller），而不是恐怖。

**微型场景**：

> 她第一次提出要出去工作，是在孩子上小学之后。他说好，然后花了一个下午，把招聘网站上所有"加班多"的岗位都截图给她看。
> 她说不去了。
> 他说："你看，我不是不让你去。"
> 这句话他说了七年。七年里她换了三次想法，每次都是这样结束的。
> 她的手机电量从来没低于 40%。她一直以为是自己习惯好。

> **诊断**：R = 成年人有择业自由；e₁ = 每一次"自由选择"都由同一个人预先铺好；Δ = 爱／占有。**没有一次暴力，没有一句威胁，恐怖全在"我不是不让你去"里。**

---

### 10.5 T_W · weird（兑现）——即巴克变体

```
T_W = (R − e₁) × Δ_ont − I_语义 + I_感官 − E⁺
```

**这一节只做一件事：指出 T_W 与原式 `T_B` 是同一个东西。**

`00 §2.2` 把巴克变体当作"公式的边界证明"，`07 §8` 也把它单列。但按 §3 的五形态表，**T_B 的改动只有一处：把 e₁ 从"违规"换成"兑现"**——愿望被一字不差地实现。
而"不该被实现的东西被实现了"，正是 Fisher 定义的 weird：**不该在场的在场**。

> 需要分清：Fisher 的 weird 同时覆盖"闯入"与"兑现"两种形态。
> 其中**闯入已由原式承担**（这正是原式的原生形态），所以 T_W 只负责**兑现**这一支。
> 也就是说：**weird 是一个体验类别，不是一种公式**——它横跨①与④两种形态。

**结论**：`T_B` 不是公式的叛徒，是**第四种形态的标准写法**。它之所以看起来特殊，是因为它的 I 是**双旋钮**（感官满／语义零），而其他四种形态的 I 是单旋钮。

**由此得到一条可操作的判断**：

> 当一个设计"规矩都对、就是不吓人"，先试**换形态**，而不是加码。
> - 加一处不该有的 → 闯入
> - 拿掉一处该有的，且当没拿 → 缺席
> - 量两次，看差值 → 位移
> - 让愿望精确实现 → 兑现
> - 让边界被一句"为你好"越过 → 越界

### 10.6 五种形态的选用表（含原式）

| 症状 | 换哪个形态 | 一句话处方 |
| --- | --- | --- |
| 规矩都对，就是不吓人 | ①→④ 兑现 | 让他的愿望**精确**实现（巴克） |

## 11. 与生成器 / 工作台的对接

`tools/generator/motifs.json` 现有字段（`group`、`cat`、`pair`、`e1[]`、`sym`、`checks`、`E`）**不用改**，只需为 16 条新母题补四个字段：

| 新字段 | 取值 | 用途 |
| --- | --- | --- |
| `group` | `"C"` / `"D"` / `"E"` / `"F"` | 工作台按题材分组显示 |
| `e1_form` | `"intrusion"` / `"absence"` / `"displacement"` / `"fulfillment"` / `"transgression"` | 决定用哪个变体算 T |
| `default_i` | `"high"` / `"mid"` / `"low"` | 模式冲突预警（见 `11 §9.4`）：默认高 I 的母题选 horror 时，强制提示"需指定压 I 写法" |
| `confusable_with` | `["unknown"]` 等 | L3 装配时，若两条互为"最易混"，**禁止同场**，比现有五对互斥更早起效 |

**三条落地约束**：

1. **先补 `default_i`，再补母题内容**。因为 49% 的模式冲突率（`00 §5.6`）主要来自默认 I 与 Mode 要求不匹配，补这一列立刻见效。
2. `e1_form` 不要做成一母题一形态。**同一母题可以有多种形态**（如 `registry` 既可"多一行"闯入，也可"少一行"缺席）——形态属于**卡**，不属于**母题**。所以最终字段应放在 `e1[]` 的每一项上，而非母题级。
3. `confusable_with` 是**建议性**的，不做硬拦截；但生成器应把两条同时抽中时标黄，并在卡片上印一句判据（§8 表里那句）。
