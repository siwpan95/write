# 恐怖美学八母题复用公式卡

> 配套《古今中外恐怖美学核心母题深研》使用。把八个母题压成同一套可反复代入的生成式：换母题只换参数，公式不变。

## 一、母公式

**一行中文版**

> 恐怖 = （本来该怎样 − 恰好一处没照做） − 看清的程度 − 能了结的程度

**符号版**

```
T = (R − e₁) × Δ_m − I − E
```

| 变量 | 名称 | 取值原则 |
| --- | --- | --- |
| R | 规程 | 先把「本来应该怎样」写全：殡葬、对称、可测量、债要结清、空间有人用、镜像同步、单向看、步骤可复述。来自民俗溯源与常识，不是道具库 |
| e₁ | 一错 | 全篇只破 R 的一条，其余全对。第二处异常出现，恐怖即降格为奇观 |
| Δ_m | 母题边界 | 八选一作主，最多一辅。决定被撬开的是哪条分类线 |
| I | 信息量 | 扣分项：不给全景、只给局部与回声、全篇三次有效信息且每次推翻上一次 |
| E | 出口 | 扣分项：越能了结越不恐怖。关系型给「可和解但被放弃」，系统型不给出口只给延缓，身体型给「代价即结局」，崇高型给「幸存但尺度认知被永久改变」 |

三条来源对齐：减信息对应伯克 1757 年「模糊、不确定、幽暗比清晰描摹更有力」；R − e₁ 对应弗洛伊德 1919 年「熟悉之物被压抑后复返」；E 的分档对应报告第十章三种温度与出口差异。

**S（符号组）不是独立加数，是 e₁ 的感官载体**：每个场景从符号库取 2–3 个跨通道符号，其中一个必须承载 e₁，其余只做氛围。单通道堆叠会变成装饰。

**填空模板**

```
在本来【R】的【场景】里，
只有【e₁】不对；
被撬开的是【Δ_m】这条边界；
观众始终【I 的减法】；
最后【E 的出口策略】。
```

## 二、八母题参数卡（换母题只换这一张）

### 1 死亡与腐朽
- Δ：生／死
- R：几日殓、谁抬棺、往哪埋，殡葬程序必须走完
- e₁：久葬不腐（身体拒绝归档）／一碰成粉（不可保存）
- S：蜡黄青灰的色温 + 殓衣受潮的摩擦声 + 棺盖被打开的整齐包装

### 2 身体异化与变形
- Δ：自我／他者
- R：身体听命于我、左右对称、镜中同步
- e₁：只动一侧肩／一侧眉／抬手慢半拍
- S：单侧不对称 + 湿滑新生组织的近景长镜（无音乐）+ 平静的叙述语气
- 附加律：写过程不写结果，变形到 80% 仍能说话、仍有礼貌最恐怖

### 3 未知与不可名状
- Δ：可知／不可知
- R：空间可测量、专家能解释、可靠档案不冲突
- e₁：走回原处门牌号变了／两份可靠来源对同一事件记录冲突
- S：雾或深水（永不散开）+ 失真录音（留韵律去语义）+ 一件日常尺度物标定巨物
- 附加律：认知预算三次为上限；让最专业的人先失控；结尾不要让主角「看懂了」

### 4 幽灵与怨念
- Δ：过去／现在
- R：谁欠谁、欠了多久、已由祭祀结清
- e₁：供品少一碗无人承认／和服下摆不动而人动
- S：日常物被占用（井、洗衣机、监控屏）+ 跑调童谣 + 半遮之面
- 附加律：不追不喊，只「必然接近」；鬼的形态最后再定，先写债

### 5 禁地与废墟／阈限空间
- Δ：内／外
- R：空间有明确用途且有使用者，过渡之后必达聚合
- e₁：广播叫到不存在的号码／门都能开但开完回到同一条走廊
- S：荧光嗡鸣与电梯到站音（门永不开）+ 跳号门牌 + 封条（理由只给一半）
- 附加律：干净的空比脏的空更恐怖；与怨灵叠用时先空够久再让人出现，顺序不能反

### 6 镜像与分身
- Δ：一／多
- R：我是唯一一个我，镜像与我同步
- e₁：人走了镜中人还在／抬手慢半拍（时间错位优于内容错位）
- S：慢半拍的反射面 + 前置摄像头／瞳孔／抛光金属 + 人称由「我」转「他」
- 附加律：镜规则先定绝不破例；分身要有「更好的地方」；收尾让观众无法确认谁被留下

### 7 窥视与被窥视
- Δ：看／被看
- R：我在安全地看，视线没有来处
- e₁：监控回放里多出一段自己不记得的影像／声源与镜头朝向相反
- S：窄画幅裁切（门缝、取景器）+ 画外呼吸 + 照片里多一人
- 附加律：先让观众享受「看」的快感，再让画面回看观众；游戏里把「看」做成消耗资源

### 8 仪式与禁忌触犯
- Δ：许可／禁制
- R：步骤可复述、聚合礼会按时到来
- e₁：清单缺了一行／结打错一个
- S：缺一行的清单（e₁ 载体）+ 红白并置的喜服与殓服 + 可记忆的钟声或口诀
- 附加律：让仪式「差点成功」比彻底失败更恐怖；身份剥夺优先于身体伤害；结局保留规程确实有效，只是作用的不是你以为的对象

## 三、温度选择器（决定 I 与 E）

| 温度 | I 减法 | E 出口 | 主辅配方 |
| --- | --- | --- | --- |
| 关系型·温 | 半遮、只响不喊、只慢不快 | 可和解但被放弃 | 怨灵 + 镜像 + 仪式（阈限作容器） |
| 系统型·冷 | 三次信息、永不全景、专家先崩溃 | 不给出口，只给延缓 | 不可名状 + 阈限 + 窥视 |
| 身体型·黏 | 近景长镜、不切、不配乐 | 代价即结局 | 异化 + 腐朽 + 分身 |
| 崇高型·史诗 | 只给局部与日常尺度参照物 | 幸存但尺度认知被永久改变 | 不可名状 + 废墟 + 巨物 |

一篇作品只以一种温度为主、另一种作点缀；三种温度等量混用会互相稀释调性。

## 四、组合规则

1. **主辅律**：1 主 + 最多 1 辅；同场景叠四个以上母题，Δ 过载、调性抵消。
2. **同族律**：前四母题（死亡、身体、未知、怨念）破坏的是「内容边界」，后四母题（阈限、镜像、窥视、仪式）是「机制层」。内容 + 机制叠用最稳，两个内容母题硬叠容易变成奇观展览。
3. **顺序律**：阈限必须先「空」，怨灵后「现」；规程必须先展示，破规后发生；先让观众看爽，再让画面回看。
4. **一错律**：e₁ 全篇唯一。想加第二个异常，就换一场、换一条 R，而不是在同一场里加码。
5. **出口律**：E 一旦给「彻底解决」，怨念降格为怪物；仪式可以暂缓，不能结清。

## 五、代入后自检（七条反模式转成校验项）

- 是否给了怪物全形与完整背景设定？→ I 超标
- 是否用 jump scare 替代阈限的「慢空」？→ I 与 Δ 打架
- 怨灵是否可被一次性驱除？→ E 给死
- 身体变异是否只做奇观、未绑机制或代价？→ 缺 R
- 镜像是否只做「镜里多一个人」？→ e₁ 选错，应换时间错位
- 是否把网络规则怪谈当真民俗引用？→ R 无根
- 是否叠了 ≥4 个母题？→ Δ 过载

## 六、两次演算（同一公式，只换参数）

### 演算 A：关系型温恐怖（怨灵主 + 镜像辅）

- R：宅中丧仪停灵七日，每日供品三碗，长女每日对镜整衣确认「自己还是自己」，七日出殡聚合
- e₁：第三日供品少一碗，无人承认（其余全对）
- Δ：过去／现在，辅以一／多
- I：鬼不现全形，只给发隙；跑调童谣；全篇三次信息，每次推翻上一次解释
- E：补一碗、谢罪、改葬即可和解，但长女为保住继承权放弃 → 「可和解但被放弃」
- S：供品少一碗（视觉·物，承载 e₁）+ 跑调童谣（听觉）+ 镜中慢半拍（视觉·形），三条不同通道

=> 场景：一切照旧，只是碗少了一只。到第七日，镜里的人先替她整好了衣。

### 演算 B：系统型冷恐怖（不可名状主 + 阈限辅）

- R：夜班监控员按路线巡查，回放与路线一一对应
- e₁：回放里每天多出一段自己不记得的巡查
- Δ：可知／不可知，辅以内／外
- I：永不给全景；三次信息依次推翻「设备故障」「有人潜入」「自己记错」
- E：不给出口，只给延缓（删掉那段录像，第二天照旧多出）
- S：监控回放（媒介，承载 e₁）+ 荧光嗡鸣与叫号屏空转（听觉）+ 门牌跳号（视觉·空）

=> 场景：广播叫号越来越像在叫他的名字；他终于走到镜前，镜中先转身。

A 与 B 的骨架完全相同，差别只在 I 与 E 两档取值——这就是公式可复用的地方。

## 七、批量生成器（做设定集 / 关卡表时套用）

```
def scene(motif, temperature, domain):
    R  = write_rules(domain)        # 写出完整规程，先别写鬼
    e1 = pick_one_error(R)          # 只破一条，全篇唯一
    D  = motif.boundary             # 主 Δ；可选一个机制层母题作辅
    I  = info_budget(temperature)   # 三次为上限，永不全景
    E  = exit_policy(temperature)   # 可和解被放弃／不给出口／代价即结局／尺度改写
    S  = pick(2, 3, distinct_channels, must_carry=e1)
    return f"在本来{R}的地方，只有{e1}不对；{D}被撬开；{I}；{E}。"
```

## 八、一句话收口

母题不是素材，是「规则 + 被打破的规则」。选一个 Δ，写清它在这部作品里的物理与道德规程，然后只破一条；剩下的恐怖会自己长出来。

---

**使用边界**：本卡是面向创作的操作性提炼，不是学界定论。R 取自民俗与信仰材料时，志怪、缘起绘卷、都市怪谈中的鬼神情节一律作文学与信仰材料处理，不作事实陈述；网络「规则怪谈」是当代虚构，不可当真民俗引用。借真实宗教仪式时保留敬畏，恐怖来自误用而非嘲弄。
